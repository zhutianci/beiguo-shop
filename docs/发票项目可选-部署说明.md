# 发票 / 收据项目可自选 · 部署说明（2026-10-09）

## 一、做了什么

买家开发票 / 收据时可以自选「项目」，批量导出的税局模板表二按所选项目写「项目名称」与「商品和服务税收编码」：

| key | 项目名称 | 商品和服务税收编码 |
|---|---|---|
| `TECH_CONSULT`（默认） | 技术咨询服务 | 3040102000000000000 |
| `INFO_SYSTEM` | 信息系统服务 | 3040203000000000000 |
| `SOFTWARE` | 软件服务费 | 3040201990000000000 |
| `SERVICE` | 服务费 | 3040203000000000000 |
| `TEST` | 测试费 | 3040201040000000000 |

编码逐字取自站长 10-09 给的清单（「信息系统服务」与「服务费」同码也是清单原样）。唯一来源 `src/lib/invoice-items.ts`，改清单只动这一个文件。

**入口（全部默认选中技术咨询服务，买家不动就和原来一模一样）：**

- 结算弹窗「同时开具增值税发票」（`purchase-modal.tsx`，草稿 `Order.invoiceInfo` 里多一个 `invoiceItem` 键）
- 我的订单：补开发票、申请收据
- 邮箱查订阅：补开发票、申请收据
- 开票填写链接（`/invoice-request/<token>`，站外客户自助选）
- 后台「发票管理 → 手动录入」

**落库与导出：**

- `invoices.invoice_item`、`receipts.invoice_item` 各一列 `VARCHAR(20) NULL`。**NULL = 上线前的历史记录**，导出按技术咨询服务（= 原来的固定值），所以历史发票导出逐字不变。
- 批量导出 `lib/invoice-export.itemRow`：名称和编码**成对**取自同一项。
- 收据「项目」一栏（`lib/receipt.receiptProjectLabel`）：不展示字眼 → 印所选项目；展示字眼 → 「项目（订阅 会员订阅）」；历史收据（NULL）逐字不变。

**接口约定：** `invoiceItem` 可选，缺省 / null / 空串按技术咨询服务（上线瞬间开着旧页面的买家提交不会被拦）；不在清单里的值直接 400。

**带出所选项目的地方：** 财务台（`/finance/<token>`）每张票一个「项目：…」标签（非默认项目紫色高亮）、后台发票详情（含编码）、收据后台「印：…」、企业微信「待开发票」与「开票填写链接」两条通知、开票填写链接提交后的回执。

**没动的：** 渠道分站对外接口（`lib/partner-services/*` 的白名单不含这个键，渠道看到的开票草稿与原来一致）；DIY 手动收据。

## 二、DDL（仅两条加列，零 DROP）

```sql
ALTER TABLE `invoices` ADD COLUMN `invoice_item` VARCHAR(20) NULL;
ALTER TABLE `receipts` ADD COLUMN `invoice_item` VARCHAR(20) NULL;
```

**顺序：先 DDL，再换镜像**（新 Prisma Client 会点名新列，新镜像跑旧库必挂 P2022；旧镜像跑新库没事）。
