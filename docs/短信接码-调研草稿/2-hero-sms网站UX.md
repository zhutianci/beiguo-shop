# hero-sms 网站 UX 调研（按用户体验逐页观察）

调研日期：2026-09-29。

**边界：** 没有登录或注册，没有提交表单，没有付款，没有调用任何取号、扣费或改状态的接口，也没有操作生产服务器。Cookie 弹窗只勾选了「严格必需」。

**方法：**
- 用内置浏览器看 `https://hero-sms.com/cn` 和英文版 `https://hero-sms.com`。桌面按 1440×900 看，手机按 375×812 看（模拟 Android），看完已恢复成 desktop。
- 登录后才能看到的部分，从以下材料还原：
  - `msg_cn.json`：中文界面的全部文案；
  - 规则页 `page_cn_rules.html.txt`；
  - 退款政策 PDF：有打开密码，用 `pdftotext` 抽出了文字；
  - 前端包 `scratchpad/js/`；
  - 「我的购买」页的前端 chunk `/_nuxt/GecWvNoL.js`：原始资料里没有这个文件，在浏览器里以只读方式打开源码查看，没有下载到本地。

**来源标注：** 【实测】= 浏览器里亲眼看到；【文案】= msg_cn.json；【代码】= 前端包；【规则】= 规则页或 PDF；【推断】= 没有直接证据。引用原文时每条不超过 15 个字，更长的内容用转述。

> 品牌红线：HeroSMS 的分销商规则**禁止复制它的名称、logo、配色**，也**禁止把买家引到 HeroSMS 客服**（见 `1-hero-sms-API参考.md` §6）。本文说的「复刻」只指交互和流程，不包括视觉品牌。

## 0. 结论速览

1. **购买入口是一个全站通用的左侧抽屉，不是一个独立页面。** 在任何页面点顶栏的「接收短信」都会拉出这个抽屉，里面按顺序是：1. 选择服务 → 2. 选择国家 → 3. 购买或自定义。选中一项后，这一项会收成一个带 × 的 chip，下一步随即展开。手机上，这个抽屉就是全屏面板。【实测】
2. **登录墙来得很早。** 未登录时可以浏览服务、国家、起价和库存，但只要点一下国家，就会弹出登录框。第 3 步（运营商、时长、数量、购买按钮）未登录完全看不到。【实测】
3. **服务搜索：** 不区分大小写和重音，排序是完全相等 > 前缀匹配 > 包含匹配；别名能命中，比如 `gpt`、`chat`、`tg` 都能搜到 OpenAI。但**中文别名一律搜不到**（「电报」「微信」都不行），也**没有拼写纠错**（telgram 搜不到）。【实测+代码】
4. **搜不到时，列表只剩一行「Any other」，下面一行灰字**：「未找到服务 "xxx"」，建议用 Any other 来激活。中英文版结构相同。【实测】
5. **国家列表每行：** 国旗、名称、库存「N 个」、起价「起 $x」，另有「仅虚拟号」的橙色标签。**不显示成功率或到达率的数字**，「质量」只体现在默认排序（按质量排序）里。排序有 5 种可切换。【实测】
6. **运营商只出现在「使用设置购买」（自定义）模式里**，默认的快速购买会把它隐藏。下拉框的默认值是「任意运营商」，每一项显示该运营商的库存，库存为 0 的置灰。**价格不随运营商变化。**【代码+4b 实测】
7. **激活面板（「我的购买」页）：**
   - 号码格式化成 `+区号 (前三位) 其余分组`，旁边一个复制按钮；
   - 倒计时每秒刷新，数据每 10 秒轮询一次，只在标签页可见时轮询；
   - 状态用彩色徽章显示；
   - 收到的短信都能展开看，验证码大字显示并可复制；
   - **买号后前 2 分钟，换号和取消按钮置灰**，只能从 tooltip 里看到原因；
   - **收到码后只剩「完成」**，「再收一条」按钮永远置灰，tooltip 写着后续短信会自动送达。【代码】
8. **「没有收到验证码?」投诉入口**买号 2 分钟后才能点。弹窗里先建议换号，再列出一组原因单选，部分原因只在特定服务下出现（Telegram 要 Premium、WhatsApp 不接受此号等）。【代码+文案】
9. **资金模式是先充值余额再按次扣：**
   - 最长 3 小时到账；
   - 退款只退回余额；
   - 提现要扣 5%–35% 手续费，处理周期 7 天到 4 周；
   - 退款政策 PDF 要求 7 天内发邮件申诉。
   这是我方（按单用支付宝直付、失败原路退）最明显能做得更好的地方。【规则】
10. **翻译和一致性问题多：**
    - 首页价格写成「到 $0.08」，抽屉里写的是「起 $0.0282」；
    - 机翻错误不少，例如「其他其他」「提前取消已完成」；
    - 首页「国家」tab 里只有一个英文的「Brazil」；
    - 忠诚计划的折扣上限，页面标题写 60%，SEO 标题写 40%。
    这些都拉低了信任感。【实测+文案】

## 1. 首页与整体布局

### 1.1 桌面（1440 宽）【实测】

**顶栏：**
- 左侧：logo、紫色主按钮「接收短信」，以及文字链接：网站联盟 / 忠诚计划（红字强调）/ 成为供应商 / API / 关于我们。
- 右侧：国旗样式的语言下拉，共 13 种语言：English、Deutsch、中文、Русский、Português、Español、Français、Tiếng Việt、bahasa Indonesia、Türkçe、日本語、한국어、العربية；再右边是「登录」按钮。
- **没有货币切换**，全站只用 USD。

**页面主体是营销落地页，不是购买界面。** 自上而下依次是：
1. Hero 区：标题是「在线接收短信」「接码平台」「API 访问」三段拼起来的，3 条卖点（基于 SMS-Activate 基础设施、180+ 国家、每日 50 万+号码），两个按钮「接收短信」「获取 API 密钥」。右侧是几张模拟短信通知的卡片（X、Facebook、Instagram、VK 的验证码示例）。
2. 「新水平的接码平台」一节：左边是一个带「找服务」搜索框的服务网格，每行是「图标 服务名 库存(99999+ 个) [到 $0.02]」，右边是「完美无缺」四条卖点。**点任意一行的价格按钮，会打开抽屉并预选这个服务**，国家按质量排序。
3. 「如何获取验证码」5 步：注册 → 充值 → 选服务和国家（找不到就选 Any Other）→ 购买号码 → 在个人账户里收码。旁边一个「立即开始」按钮。
4. 「热门服务的虚拟号码」：「服务 / 国家」两个 tab，是 24 个服务的 SEO 链接，指向 `/cn/service/telegram` 这类地址。**「国家」tab 里只有一个英文的「Brazil」**，是个 bug。
5. 用途列表、「虚拟号码与真实号码」对比表、合作软件、一次性号码与 Full Rent 的区别、「为何选择」、购买指南、FAQ（手风琴折叠）。

**Footer：**
- 关于我们、联系方式、支持、合作伙伴、协议、规则、API、网站联盟、忠诚计划、功能、移动应用、服务、国家、成为供应商、博客；
- TG 频道图标；
- 三个 App 徽章：Google Play、APK、App Store；
- 底部是 4 个 PDF 链接：条款与条件、隐私政策、两个都叫「退款政策」（一个是 return，一个是 refund）。

**Cookie 弹窗：** 首次访问时在底部弹出，有「接受所有 cookies」和「配置」两个按钮。点「配置」后出现三个勾选项：严格必需（锁定不可取消）、增强系统功能、营销，外加一个「接受」按钮（按当前勾选保存）。

### 1.2 购买抽屉的结构（所有页面通用）【实测】

点「接收短信」后，从左侧滑出一个约 350px 宽的抽屉，页面其余部分加灰色遮罩。从上到下：

| 区块 | 内容 |
|---|---|

| 最近激活（折叠） | 未登录时同上。登录后显示「最近 4 次成功的激活」【文案】 |

- **顶部是一条 sticky 横幅「下载 Android 移动应用」**，带「下载 APK」「Google Play」两个按钮和一个 ×。
- 顶栏：汉堡菜单、缩短的 logo「HS」、国旗、「登录」。
- 汉堡菜单打开后是全屏白底：一个大的紫色「接收短信」按钮，下面依次是 API、网站联盟、忠诚计划（红字）、成为供应商、关于我们。

## 2. 服务选择

### 2.1 列表与排序【实测】
- **默认按人气排序。** 实际前几位是：Full rent（长租入口，被当成一个「服务」放在第 1 位）→ Google,youtube,Gmail → Instagram+Threads → TikTok/Douyin → Whatsapp → Google Chat → facebook → Ticketmaster → WeChat → Telegram → Any other → Shopee → OpenAI → ……
- **每行的内容：**
  - 左侧是圆形品牌图标，Any other 用一个黑色的「?」；
  - 中间是服务名，下面一行是库存「119047 个」；
  - 右侧是「起 $0.0062」，保留 4 位小数。
- **库存的含义：** 显示的数字是**实体号**的数量。悬浮层里还有细分：「实体号 - N 个，虚拟号 - M 个」【页面 DOM + 文案 `COUNT_NUMBERS`】。库存状态有三种颜色【代码】：
  - 实体号 > 0：正常显示数量；
  - 只有虚拟号：橙色「仅虚拟号」（实测 Letgo、土耳其）；
  - 两者都为 0：红色「无可用号码」。
- **分页：** 先显示 5 行，每点一次「显示更多」多加载 5 行，加载时按钮里转圈。
- **没有分类筛选，也没有置顶或收藏按钮。** 收藏的单位是「服务+国家」组合，入口在第 3 步购买卡片底部的红心；收藏夹为空时的提示文案是「收藏"服务+国家"组合」【文案】。

### 2.2 搜索行为

| 输入 | 结果 | 结论 |
|---|---|---|
| `tele` | Telegram | 前缀匹配 |
| `TELEGRAM` | Telegram | 不区分大小写 |
| `douyin` | TikTok/Douyin | 在显示名内部做包含匹配 |
| `gpt` | OpenAI | **别名能命中**（OpenAI 的别名里有 ChatGPT） |
| `tg` | Telegram、OpenAI、Nttgame、Letgo | 同时匹配代码、别名和名称子串（Letgo 行带「仅虚拟号」标签） |
| `chat` | Google Chat、WeChat、OpenAI、Snapchat、MChat（还有「显示更多」） | 包含匹配，OpenAI 同样是靠别名命中 |
| `电报`、`微信` | 只剩 Any other，并提示「未找到服务」 | **中文界面也不支持中文服务名或别名** |
| `telgram` | 同上 | **没有拼写纠错** |
| `mybankxyz`（英文版） | 只剩 Any other 一行，提示 `Service "mybankxyz" was not found…` | 英文版结构相同 |

- 排序算法【代码 `D8BOb9Xg.js`】：用 `Intl.Collator` 并设置 `sensitivity:"base"`（忽略大小写和重音）；打分规则是完全相等 0、前缀 1、包含 2，然后升序排列。代码里还专门处理了**中文输入法的组字过程**：组字没结束时先不过滤，避免拼音字母触发搜索。
- 搜索时有一个短暂的转圈（约 0.5–2 秒），但**没有显示「正在搜索」之类的状态文字**。

### 2.3 搜不到时的 Any other 引导【实测+文案】
- 列表只剩一行：「? Any other，117522 个，起 $0.006」。
- 下面一行灰字：「未找到服务 "电报"」，随后建议用「Any other」来激活。文案键是 `OT_SERVICE_NOT_FOUND_HINT`。
- 站内其他地方的引导文案：
  - 首页 5 步里写「可选择任何其他（"Any Other"）」；
  - 购买指南里写成了「请选择"其他其他"（Any other）」，是一处机翻错误；
  - 卖点里写「适用于其他服务的"任何其他"选项」。
- **Any other 的适用范围没有任何说明**，没有告诉用户「已单独列出的服务不要选 Any other」。

## 3. 国家选择【实测】

- **标题行：** 「2. 选择国家」，右侧一个紫色徽章「10 个热门国家」（英文版是 Top 10 Countries）。未登录时点徽章会弹登录框。它对应统计页里「按成功率排的 Top10 国家」【文案 `StatisticsPage`】。
- **搜索：** 中文名和英文名都能搜到。`美国` 和 `usa` 都命中「美国（物理）」；`indo` 命中「印度尼西亚」；`zzzz` 显示「没有国家」。
- **排序下拉**（「排序方式」，文案来自代码 `services.filter.*`）：
  1. 按质量排序（默认，按到达率 deliverability 降序）
  2. 按受欢迎度
  3. 便宜一点（起价升序）
  4. 贵一点
  5. 按数量（实体号库存降序）
  - 下拉用的是单选圆点的样式。**换一个服务后，排序会重置为「按质量排序」**，不会记住上次的选择。
- **每行的内容：**
  - 圆形国旗，部分国旗懒加载，会先空白一下；
  - 国家名，美国分成「美国（物理）」和虚拟号两种；
  - 下面一行是库存「N 个」，或橙色的「仅虚拟号」；
  - 右侧是「起 $x」。
  - **没有成功率、到达率百分比、区号或运营商数量。**
- **库存很少的国家也照常显示**，例如 WhatsApp 按质量排序时，第 1 位是库存只有「1 个」的加拿大，没有「紧张」之类的提示。**完全没货的「服务×国家」组合不出现在列表里**（4b 实测：offers 接口只返回有货的组合）。
- **分页：** 同样是 5 行起，加「显示更多」。
- **未登录时点任一国家，直接弹出「登录账户」弹窗**（邮箱、密码、忘记密码、注册链接），抽屉保持原状。
  - 注册弹窗【文案】还有「使用 Google 注册」，并提醒不要用临时邮箱。
  - 注册后需要点邮件里的链接验证。

## 4. 运营商（号码地区）的选择——登录后，按代码还原

- **位置：** 在第 3 步。第 3 步有两种模式：
  - 默认的**快速购买**：代码里显式设置了 `hide-operator-select: true`，**看不到运营商**，只能选验证类型和时长，数量固定为 1，按钮是「以 $x 购买」；
  - 点「使用设置购买」进入自定义模式，标题变成「3. 自定义」，这时才出现运营商。点「快速购买」可以切回去。
- **「运营商」下拉【代码】：**
  - 默认值为空，也就是「任意运营商」；
  - 每一项左边是运营商名称（例如 `AXIS (XL Axiata)`），右边是该运营商的库存「N 个」；
  - **库存为 0 的运营商置灰，不能选**；
  - 在「时长」模式下，库存按所选时长分别统计（`operatorRentCountsByTime`）。
- **价格不随运营商变化：** 下拉里不显示价格。4b 实测也确认，有货的运营商起价都等于「服务+国家」的起价，运营商只用来筛库存。
- **同一块区域里的其他选项【代码+文案】：**
  - **验证类型**：「短信」或「FlashCall + 短信」，旁边的 ⓘ 分别弹出说明。短信的说明是：服务商发验证码，平台在「我的购买」里显示。FlashCall 的说明是：服务商打电话过来，平台接听并显示来电号码。选了多项服务时，FlashCall 禁用。
  - **时长**：默认 20 分钟；部分组合可以选更长的时长（按 4b 实测和 API，有 40、45、60 分钟，以及按天的租用）。每个选项显示「从 $x」；有折扣时原价划线，旁边标折后价；库存为 0 的选项置灰；**选项少于 2 个时，整个下拉禁用。**
  - **语言**：只在语音验证时出现，一定要选，否则提示「请选择验证语言」。
- **收藏夹里的组合**可以原地展开这整套选项直接购买，不必重新走 1、2 两步。

## 5. 价格展示

- **货币：** 只有 USD，没有货币切换。抽屉里保留 4 位小数，例如 `$0.0062`；首页网格和 SEO 页保留 2 位。【实测】
- **「起」和「到」不一致：**
  - 抽屉里写「起 $0.0282」（Telegram）；
  - 首页网格和服务落地页的按钮写「到 $0.08」，英文版是 `up to $0.08`；
  - 两处数值不同，**「到」让人以为是上限价**，其实两者是不同的口径。【实测】
- **价格实时变化：** 同一天多次打开抽屉，WhatsApp 的起价在 $0.0525、$0.0756、$0.0763、$0.0789、$0.0824 之间跳动。原因是上游是 P2P 行情，价格按档位库存变化。【实测】
- **忠诚计划折扣不在网站价格里体现：** 忠诚计划页自己承认，网站上显示的价格还没算进等级折扣，称之为「显示错误」，实际扣款会更低。【文案】
- **自选出价（Free Price）【代码+文案】：**
  - 有「报价列表」和「我的出价」两个 tab；
  - 「我的出价」：输入框的下限是最低一档价格，上限是能买到的最高价，旁边配一个滑杆；
  - 实时显示这个价位能买到的库存「库存 - N 个」和「过去一小时平均成交价」；
  - 没有报价时显示「目前暂无可用报价。」
- **购买汇总：**
  - 一个数量步进器，上限取该档库存和系统上限中较小的那个；总价 = 单价 × 数量；
  - 红心按钮用来收藏；
  - 按钮文字是「以 $x 购买」；
  - 成功后弹 toast「号码购买成功。{服务} 数量：N」。
  - 如果是长租，购买后会弹一次性的「重要信息」提示：号码不可用时退还剩余租期的费用，提示里带「不再显示」勾选。
- **余额不足：** 弹窗标题「您的账户余额不足」，按钮是「充值」和「取消」。【文案】
- **购买按钮下方的一句说明**【文案，两种购买模式各一句】：
  - 一种是「20 分钟未收到验证码，自动退回余额」；
  - 另一种是「可在 20 分钟内取消租用，超时不退」。

- **取消与退款：**
  - 20 分钟号码：2 分钟后可以取消；没收到码的取消退回余额；收到码不退；20 分钟没收到码自动退款；

## 9. 值得我方复刻的 UX 要点

### P0（首版必须有）
1. **三步漏斗加 chip 回退**：服务 → 国家 →（运营商）→ 确认；选中后收成 chip，点 × 回到上一步重选。我方放在导航【短信接码】这个独立页里，手机上全屏，桌面用左右两栏或分步卡片，不需要照搬抽屉。
2. **服务搜索按打分排序**：完全相等 > 前缀 > 包含，忽略大小写和重音，别名能命中；搜索时处理好输入法组字。在这些之上**加中文名、拼音、首字母和常见俗称**（电报、微信、推特、油管、谷歌、脸书、抖音等），把 hero-sms 最大的短板补上。
3. **搜不到时固定给出「其他服务（Any other）」一行，加一句引导**。另外补一句 hero-sms 没有的说明：「列表里已有的服务请选对应项，Any other 不保证能收到已单列服务的短信。」
4. **国家行显示「国旗 + 中文名 + 库存 + 起价」**。默认按质量或推荐排序，另可切换「最便宜」和「库存最多」；中英文都能搜。库存少的显示「紧张」，没货的不显示。
5. **激活面板：**
   - 大号码加一键复制，**另给一个「复制不含区号」**；
   - 倒计时每秒刷新；
   - 彩色状态徽章；
   - 验证码大字显示、一键复制；
   - 短信全文和多条短信可以展开，显示发件人。
6. **2 分钟锁**：hero-sms 只用静态 tooltip 说明，我方**直接在按钮上写「45 秒后可换号」这样的动态倒计时**，触屏也能看到。
7. **收到码后不能取消、不能换号，后续短信自动进来**。hero-sms 放一个永远置灰的「再收一条」按钮；我方改成一行说明：「还可继续接收短信（剩余 mm:ss），无需操作」。
8. **退款规则写在购买按钮下方一句话**（例如「20 分钟内没收到码，自动原路退款」），并且在激活页再写一次。
9. **只在页面可见时轮询**，多个标签页不重复请求，页面可见时加快频率（我方服务端 5 秒）。
10. **「没收到码？」引导**：先建议换号，再给常见原因单选，原因按服务显示不同选项。在我方，这一步直接等同于「换号」，同时把原因记下来统计。

## 10. hero-sms 做得不好、我方能做得更好的地方

1. **登录墙太早。** 点国家就弹登录框，看不到最终价格、时长、运营商和规则。我方可以让用户一直走到「确认页」，确认页上汇总服务、国家、运营商、价格和退款规则，到付款那一步才要求登录（按站点现有规则来）。
2. **必须先充值。** 有最低充值额，主要靠加密货币，最长 3 小时到账，退款只退回余额，提现手续费 5%–35%、处理 7 天到 4 周。我方**按单用支付宝直付，失败原路退回**，不设余额（和 `5-竞品与大厂方案.md` §5.5 一致）。
3. **中文界面搜不到中文服务名**，拼错也不纠正。我方做中文别名和拼音，再做一层轻量的编辑距离容错。
4. **价格口径混乱。** 首页「到 $x」和抽屉「起 $x」不一致，等级折扣不显示，价格一直跳。我方**只显示人民币一口价，下单时锁价，页面上显示的价格就是实付金额**。
5. **机翻错误多：** 「其他其他」、「提前取消已完成」（意思反了）、「输入你的有邮箱」、「曲奇饼」、「给恒为供应商」、「M经理工作时间」、「W钱包」。我方用原生中文，并对文案逐条审校。
6. **关键约束只写在 tooltip 里**（2 分钟锁、再收一条），触屏上看不到。我方把约束写成按钮文字或旁边的说明。
7. **复制号码只能整串复制，还带国家码**。我方提供「整号」和「不含区号」两个复制按钮，号码显示时把区号拆开（例如 `+1` 和 `555 123 4567`）。
8. **手机端 App 横幅挡住购买面板顶部。** 我方不加遮挡式横幅。
9. **国家列表加载慢，只有转圈。** 我方定时缓存价格表（4b 已建议定时拉 getPrices），用骨架屏占位，服务和国家列表秒开。
10. **只按「质量」排序，却不给质量数据。** 我方在样本足够（例如满 20 单）后显示「本站成功率高」「推荐」标签，或者直接显示成功率。
11. **没有 FAQ 页，客服只有邮件和 TG，回复要 24 小时**，申诉要自己准备录屏。我方做站内工单和订单内对话（复用现有「订单内聊天」），加企业微信推送，把 FAQ 直接放在接码页底部。
12. **小 bug 和不一致：** 首页「国家」tab 只有一个英文「Brazil」；换服务后排序被重置；列表每次只加载 5 行，热门服务要点很多次「显示更多」；库存「1 个」的国家排在第一位，却没有提示。我方首屏多显示一些，用虚拟滚动，记住用户选的排序，库存很少的降低排序权重。
13. **投诉之后没有结果反馈**：只有「已发送」，不说后续怎么处理，也没有退款时限。我方的「换号或原因」操作要立即得到结果（换号成功，或已自动退款），人工申诉写明处理时限。
