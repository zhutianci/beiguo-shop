## 0. 规则（所有包都必须遵守）

1. **文件独占**：第 13 节「文件归属总索引」里每个文件只属于一个包。别的包需要改它时，向所有者提需求，由所有者改；只 import 不算改。`prisma/schema.prisma`、共享类型与常量（`src/lib/tenant/types.ts`，含**全部渠道侧 DTO 类型**）、select 白名单（`src/lib/partner-services/selects.ts`）**只归 WP0**。设计里提到的每个需要改造的现有路径都必须出现在第 13 节（W8-9 核对）。
2. **休眠**：任何包合入后，在 `CHANNELS_ENABLED` 未设置时主站行为不变（设计 4.10）。每个包都有「对主站的影响与回归检查点」，合入前逐项跑。
3. **schema 只新增**：新表、带默认值列、可空列、索引；零 DROP / MODIFY / RENAME（设计 5.0）。只有 WP0 改 schema。
4. **金额按分整数**：新代码一律 `Int` 分，比例一律 bp；用 `src/lib/money.ts` 的 `toCents` 与 `src/lib/tenant/math.ts` 的 `mulBps / mulDivRound`（只接受非负数）；**`Order.amount` 永远不含税**。
5. **并发幂等**：唯一约束 + CAS（`updateMany where { …旧值 }`，`count≠1` 即失败）；渠道单结算状态的一切变更按 `Order.settleVersion` CAS 并 +1；幂等键来自业务事实、订单版本号或客户端 requestId；同一 eventKey 的分录腿一次 `createMany`。
5a. **渠道侧不出现自增主键**：渠道 DTO 与 URL 一律用公开编号（orderNo、listingNo、customerNo、noticeNo、requestNo、statementNo），唯一例外 `productId`（设计 6.3）。
6. **route.ts 只导出 HTTP handler**（与 `dynamic`）；实现放 `src/lib/**`。
7. **授权在路由内**：middleware 可被绕过，所有判定在 route / page 内重做（`partnerRoute`、`requirePartnerPage`、`adminGuard`）。
8. **店面解析不进 try**：`getStorefront()`、`notFound()`、`redirect()` 不包进 try；确需 try 时 catch 第一行 `rethrowNextInternal(e)`。
9. **下单事务内只用 `tx`**：读进货价、费率、listing 一律经同一个事务客户端（Dujiao #271）。
10. **运维脚本不 import `src/`**：`scripts/sql/*`、`scripts/ops/*`、`scripts/check-tenant-boundary.mjs` 只读文本或只跑 SQL。`scripts/check-*.ts`、`scripts/itest-*` 是开发期测试，可以 import `src/`。
11. **测试文件**：每个包只写自己的 `scripts/itest-tenant/wpN.ts` 与 `scripts/itest-tenant/routes/wpN.json`（本包新增的 partner / admin 路由清单）；夹具与 HTTP 客户端用 WP0 的 `_harness.ts`；跨包总扫描归 WP8。
12. **提交**：身份 `zhutianci <2236831953@qq.com>`，提交信息不加 Co-Authored-By；每包一个分支 `feat/tenant-wpN`，按第 2 节顺序合入。

`vmq.ts` 挂钩：`fulfillOrder` 的付款 CAS 赢家事务内重读订单 → `TenantListing.sales += qty`（渠道单）→ `accrueOnPaid(tx, id)`；`Payment.amount` 用重读值；发卡缺口改为 `quantity − (refundedQty ?? 0) − 已发`（主站单行为不变）；`allocateCards` 渠道单按 `splitAmount(supplyCents/100, quantity)` 分摊 `soldPrice`；`fulfillInvoice` flip 成功后 → `accrueInvoiceShare(invoiceId)`；企业微信加「[code]」标签（`notify.ts`）；渠道单 `emitTenantNotice(ORDER_PAID)`。`settleReferral` 对 `tenantId≠1` 第一行返回。

cron（`cron/crontab`）：`tenant-release` 每小时第 7 分；`tenant-reconcile` 每天 03:00；都是 `POST + x-cron-secret` 头。
