# 设计精修 · 2026-10-07（分支 `opt/design`）

> 站长原话：「以获奖作品和优秀网站风格设计，对网站进行优化美化」。
> 方向：**克制与工艺，不是堆特效**（参照 Linear / Vercel / Stripe / Raycast 的完成度）。
> 只动视觉与展示组件；业务逻辑、接口、价格、结算步骤、文案含义、metadata / JSON-LD、URL 一律不动。

## 0. 现状诊断（改动前截图走查 1440 / 375）

整站已经是统一的深色，学习平台（10-06 改版）是完成度最高的一块：发丝细线、大留白、白色药丸主按钮、克制的强调色。
前台其余页面与它不像一个产品，问题集中在五处：

1. **字体没有中文回退**：根布局只挂了 Inter（`inter.className`），font-family 里没有任何中文字体，
   中文落到浏览器默认字体（Windows Chrome 上常是宋体或雅黑，各机器不一致）。
2. **辅助文字对比度不达标**：大量正文 / 说明用 `text-white/30~45`，纯黑底上是 2.4:1~4.1:1，低于 WCAG AA 的 4.5:1。
3. **「彩色玻璃卡」**：`glass`（白 5% 半透明 + 背景模糊）压在一层渐变光晕上，光晕透过整张卡，
   商品详情的标题卡 / 价格卡、登录注册卡、关于页与客服页的底部 CTA 都成了整块洋红色，信息反而不突出。
4. **多套按钮语言并存**：白色药丸、紫粉渐变、青紫渐变、玻璃按钮各写各的，hover 有放大 105%、有发光、有变色，时长 200~500ms 不等；
   `<Link><button>` 嵌套（交互元素套交互元素）在首页出现多次。
5. **中文行距偏紧**：没写 `leading-*` 的 `text-sm` 段落行高 1.43，中文多行时很挤。

## 1. 原则

- **一个版心、一套节奏**：间距只用 4 的倍数；区块之间 96 / 128px（桌面）、64 / 80px（手机）。
- **层级靠字号与明度，不靠颜色**：颜色只留给「可点的」与「状态」。
- **一个主强调色**：紫罗兰（`#a78bfa` 系）做链接 / 焦点 / 眉标；紫粉渐变只留给**交易动作**（立即购买、提交、支付），其余主按钮用白色药丸（与学习平台一致）。
- **表面是实的**：卡片用近乎不透明的深色面 + 1px 发丝线；光晕只在边缘出现，不再透过整张卡。
- **动效有目的**：只动 transform / opacity，≤200ms，`cubic-bezier(0.22,1,0.36,1)`；尊重 `prefers-reduced-motion`；
  触屏轻量模式不新增毛玻璃 / 大面积动画渐变 / 重阴影（新增的光晕一律带 `lite:hidden`）。
- **首帧可见**：不新增任何服务端 HTML 里 `opacity:0` / 移出视口的首屏内容。

## 2. 设计令牌（`src/app/globals.css` 顶部 `:root`）

| 类别 | 令牌 | 值 |
|---|---|---|
| 字体 | `--font-inter` + `--ui-font-cjk` | Inter（西文，next/font 自托管）→ PingFang SC → HarmonyOS Sans SC → MiSans → Hiragino Sans GB → Microsoft YaHei UI / YaHei → Noto Sans CJK SC / Source Han Sans SC → system-ui |
| | `--ui-font-mono` | ui-monospace, SF Mono, JetBrains Mono, Menlo, Consolas |
| 文字明度 | `--ink-1/2/3/4` | 0.94 / 0.70 / 0.54 / 0.40（4 只用于装饰与分隔，不承载信息） |
| 发丝线 | `--line` / `--line-strong` / `--line-hover` | 白 8% / 14% / 22% |
| 表面 | `--surface-1/2/3` | `#0b0b0e` 卡片 · `#111115` 浮起 · `#17171c` 弹层 |
| 强调 | `--accent` / `--accent-soft` | `#a78bfa` / 紫 12% 底 |
| 交易渐变 | `--brand-gradient` | `#7c3aed → #c026d3 → #db2777`（100°） |
| 圆角 | `--r-sm/md/lg/xl` | 10 / 14 / 20 / 24px；胶囊 999px |
| 阴影 | `--shadow-panel` / `--shadow-pop` | 顶边 1px 内高光 + 大半径低浓度投影（只给浮层与主面板） |
| 动效 | `--ease-out` / `--dur-1` / `--dur-2` | `cubic-bezier(0.22,1,0.36,1)` / 150ms / 200ms |

**字阶（中文）**：展示 clamp(40→128px, 行高 1.0~1.08)；H1 32/40/52；H2 24/30；H3 18/20；正文 15/16 行高 1.75~1.9；
说明 13 行高 1.6；最小 12px（中文不再小于 12px）。

**全局基线**（只作用于前台外壳 `.shop-shell`，后台 / 渠道后台不受影响）：
- 没写 `leading-*` 的 `p / li / dd` 行高 1.75（`truncate` 单行除外）；标题与段落 `text-wrap: pretty`（不用 balance：会把左对齐的长中文标题压成窄条）。
- 辅助文字明度下限：`text-white/30·35·40·45` 在前台映射到 0.48 / 0.50 / 0.54 / 0.58（≥4.5:1）。
  `/20`、`/25` 保持原样（只用于分隔符与装饰）。hover / group-hover 等状态类特异度更高，照常生效。
- 键盘焦点：所有可交互元素统一 2px 紫罗兰描边 + 2px 偏移（写在 base 层，组件自带 `focus-visible:ring` 的照旧用自己的）。
- 选区、滚动条换成同一套中性色。

**组件类**（`@layer components`，工具类仍可覆盖）：
`ui-btn` + `ui-btn-primary`（白药丸）/ `ui-btn-brand`（交易渐变）/ `ui-btn-secondary`（描边）/ `ui-btn-ghost`，尺寸 `ui-btn-lg`；
`ui-panel`（实心主面板，用来替换「渐变光晕 + glass」）、`ui-card` / `ui-card-link`（发丝线卡片）、`ui-eyebrow`（眉标）、
`ui-input`（输入框）、`ui-skeleton`（骨架）、`ui-empty`（空状态）。
全局旧工具类收敛：`hover-lift` 500ms/8px → 200ms/4px；`glow-border`、`magnetic-btn` 时长 ≤200ms；
`gradient-text` 改为白色自上而下淡出（Vercel 式），`gradient-text-accent` 改为浅紫→浅粉→浅蓝（对比度更高、不刺眼）。

## 4. 刻意不动

- `src/components/live-order-notification.tsx`（逐字不变）及其懒加载外壳；`glass` / `glass-strong` 两个类本身不改（成交弹窗、页头药丸都靠它们）。
- 手机端轻量模式三处检测（`use-lite.ts`、tailwind `lite:` 变体、`globals.css` 末尾 @media 块）逐字不变；`.glass` 的轻量模式覆盖也不动。
- 渠道白标：共享组件里不写任何贝果品牌字样（页头 / 页脚的品牌分支原样保留）。
- 后台 `/admin/**`、渠道后台、`src/components/ui/*`（浅色主题、只有后台在用）。
- metadata、JSON-LD、文案、价格、URL、接口、结算流程。
- 不加新依赖、不加网页字体（Inter 仍由 next/font 自托管，中文走系统字体）。
