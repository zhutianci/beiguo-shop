# 热词教程第三轮 100 篇（2026-10-30，协调者整理）

## 依据
- 服务器统计：自然搜索访客每周 1.2–1.4 万，**九成来自 Bing→/guides**，所以本轮第一次同时采 Bing 和 Google 的下拉建议（共 1081 条，按标题 bigram 本地去重后 403 条），优先选 Bing 也有的词。
- 新文章表现（上线 2–5 天）：DeepSeek V4.1 Flash 452、DeepSeek API 充值 410、DeepSeek 提示词 286、「Selected model is at capacity」205、DeepSeek 能生成图片吗 182。老文章最高仍是报错 / 找不到 / 设置中文 / 崩了 / 额度。
- Bing 词的新特点：**大量「入口 / 官网 / 下载 / 中文版 / 怎么充值」导航词**，这是前两轮没覆盖的。

## 写法（与第二轮相同，更短）
- 标题 = 问题原话或报错原文 + 怎么办 / 在哪 + 冒号后 2–3 个要点。开头 3 行给结论。
- **1200–2200 可读字，够用就停**（用户是来解决问题的，别铺垫）；excerpt ≤150 字；2 张图，排查类必含 decide 对照图；至少 3 个站内链接。
- 官方没逐条说明的报错：开头说明「官方未单独说明」，给官方通用排查 + 报错原文，不要因此跳过。连通用排查都套不上才跳过。
- 导航类（官网 / 入口 / 中文版 / 下载）：只给官方域名和官方应用商店，讲清怎么辨别假冒，**不推荐任何第三方「中文版」「镜像」站点**。
- 充值链接：充值、订阅、额度、付费功能类在自然位置链 `/chongzhi/chatgpt-plus` 或 `/chongzhi/chatgpt-pro`；Claude → `/chongzhi/claude-pro`；Grok → `/chongzhi/grok-super`；需要谷歌账号 → `/chongzhi/google-zhanghao`。不写价格承诺。
- 写前 `ls guides | grep` 查重：**同一用途已有就跳过**（本地去重只按标题，可能漏）。不写「实测」。

## 不写
绕过地区限制、换区、跳过手机验证、接码、账号买卖 / 批发 / 账号池、合租共享、低价渠道、VPN / 代理设置、镜像站推荐、去水印、免登录第三方站。注册需要手机号这类只写官方规则。
