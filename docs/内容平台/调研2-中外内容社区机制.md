# 调研 2：中外内容社区的原创、审核、激励与推广机制

> 2026-10-06 调研。标【未核实】为二手说法或抓取失败；标【背景知识】为未专门检索。

## 一、各平台关键机制

### 少数派 sspai（Matrix）——编辑漏斗 + 分级稿费，最值得照搬
- 双通道：社区通道（门槛低，先在 Matrix 展示，非独家，基础稿费）/ 投稿通道（直上首页，要求独家首发，高级稿费）。投稿前一周内在个人博客或公众号发过、没拿过第三方报酬仍算首发。来源：https://sspai.com/post/72089
- 编辑 3 个工作日内回复；稿费每月 6 号结算，满 200 元可提现；2021 年共发稿费 90 余万。
- **默认不曝光，被选中才曝光**：Matrix 文章默认只在作者主页，被精选 / 收入专栏 / 上首页后才进对应页面和站内搜索。有二维码、粗糙推广文案的不能入选；抄袭和推广通稿删除。来源：https://sspai.com/post/35638
- 付费层 Power+ → 会员订阅。

### 掘金——数值化创作者等级
- 掘力值 = 创作行为 + 影响力（赞评藏阅）+ 质量（系统评分）− 违规；每日更新，原则只升不降。等级解锁权限（标签数、定时发布、流量包、自定义域名）。来源：https://juejin.cn/post/7125658251852513294
- 签约作者：3 篇以上原创、每篇 ≥1500 字；评审质量分 50% + 数据分 50%；权益：徽章、每篇最高 500 元、优先推荐、App 推送。
- 沸点（短动态）靠话题标签 + 活动驱动。

### 知乎
- 代用户维权、原创平台（追踪转载、媒体在线申请授权、付费转载授权自动流转）。来源：https://www.huxiu.com/article/156119.html
- 盐选：保底（按千字）+ 付费分成，头部五五分。

### 小红书
- 笔记付费：原图付费下载 / 单篇付费 / **合集付费解锁**（前几篇免费试读）。「合集」= 主页上的迷你专栏，适合系列教程。

### WaytoAGI 通往AGI之路——最贴近本站场景
- 2023-04 一份飞书公开文档起家，2–3 个月访问破百万，号称 900 万用户，无付费推广。
- 共建者靠认可不靠钱（「共建者就是社区最高荣誉」），优秀贡献者作品整理成专门文档并署名。
- 反倒卖规则：社区内容可参考，不能照搬原样去变现。
- 线下：每月最后一个周日 AI 切磋会，扩到 37+ 城市。
- 现站结构：活动、工具导航、智能体、提示词、精选 Wiki、开源 Wiki。来源：https://www.waytoagi.com/

### 人人都是产品经理
- 投稿 24 小时内审核（专栏作家 12 小时）；必须原创；**明确不收「工具/书籍推荐清单」和软文、新闻稿**；图片必须本地上传。
- 专栏作家门槛：注册 >1 月、发文 10 篇以上、篇均阅读 5K、篇均收藏 30、粉丝 200、被官方推荐 2 次以上。来源：https://www.woshipm.com/tougao

### CSDN——反面教材
- 原创/转载/翻译标记只是自愿勾选、无核验无处罚；站内搬运泛滥；付费墙让搜索用户点进来看不到；流传屏蔽 CSDN 的油猴脚本；GitCode 曾批量镜像 GitHub 并改链接刷 SEO。**短期涨量、长期品牌和搜索评级一起受损。**

### V2EX——用节点隔离推广
- `/go/promotions` 专放厂商推广；其他节点发广告处理账号。`/go/create`「分享创造」放个人作品。
- V2EX PRO：充值满 20 美元可投广告（文字 / 缩略图 / 横幅），PRO 会员可用铜币把主题顶上首页。每个节点都有「忽略此节点」。来源：https://v2ex.com/pro/about

### 小众软件
- Discourse 论坛，「发现频道」所有内容人工审核；问题求助可标最佳答案。

### ai-bot.cn AI 工具集——工具目录型 SEO
- 2025-03 约 446 万访问，87% 来自中国，**cn.bing 占 26%**【Semrush 估算】。
- 详情页 `/sites/{id}.html` 固定模板：标题+卖点 → X 是什么 → 主要功能 → 如何使用 → 使用示例 → 核心优势 → 竞品对比表 → 应用场景 → 相关工具 6 个 → 反馈。**标题即搜索词，模板化但有实质内容，竞品表与相关工具形成强内链。**

### 数字生命卡兹克
- 爆款常是可直接拿去用的提示词；第一手观察必须由人写，AI 只做扩写和整理。【部分来源为第三方整理，未核实】

### dev.to / Hashnode
- 支持 canonical_url 转载；**但 Google 2023-05 起不再推荐跨站 canonical 处理转载，推荐转载方加 noindex**。来源：https://searchengineland.com/google-no-longer-recommends-canonical-tags-for-syndicated-content-406491
- 两级治理（Trusted User 提升/降低/举报；Tag Moderator 管标签）；行为准则要求披露 AI 辅助。
- 关掉付费 Listings，改为官方审核的 Billboards 广告位，用户可关闭赞助广告。

### Medium——分发分级
- Network Only / General / Boost 三档；**赞助内容、内容营销、导流目的、未披露的 AI 内容直接降为 Network Only**；披露过的 AI 内容进不了 Boost。来源：https://help.medium.com/hc/en-us/articles/22576852947223
- Boost 提名制：独立刊物编辑提名，策展团队 1–2 天复核。

### Product Hunt / Show HN / Indie Hackers / Reddit——自我推广规矩
- Show HN：必须是自己做的、别人能上手试的东西；博客文、注册页、通讯、清单不算；不许拉票。来源：https://news.ycombinator.com/showhn.html
- Product Hunt：每日一轮，featured 人工挑选；作者首评很重要。
- Indie Hackers：Milestone 帖（公开收入/用户数）、产品页更新时间线。
- Reddit 90/10：自我推广不超过 10%，主动披露「我是作者」。
- There's An AI For That：featured 收录 199 美元，带链接 + 进周报【价格可能已变】。

### Stack Overflow
- 信誉解锁权限（15 分点赞、50 评论、125 踩……）。**警示**：新问题数比 2017 峰值跌约 75%，部分原因是管理太严、对新人不友好。

## 二、日活很小的新平台最值得照搬的（冷启动视角）
1. **默认低曝光，编辑精选后才放大**（少数派 + Medium）：未精选不进首页、不进 sitemap、noindex。站长就是编辑部。
2. **原创声明三档必填**：原创首发 / 原创非首发（附原文链接）/ 转载（附来源和授权）。只有首发能进精选拿激励；非首发和转载 noindex。
3. **相似度检测**：SimHash（海明距离 ≤3 视为近重复）+ 抽样长句搜索，命中转人工。
4. **固定模板的内容类型**：工具/应用分享、提示词、教程系列、问答、作品自荐，各有结构化表单。
5. **自我推广四件套**：隔离区 + 披露 + 比例 + 付费置顶。必须能试用；新号首帖不能是自荐；外链 `ugc nofollow`，付费位 `sponsored`。
6. **激励先荣誉署名，后发钱**；可用本站订阅抵扣券 / 余额，成本低又闭环。
7. **简化版掘力值**：被精选、被收藏、最佳答案权重高，单纯发帖权重低，每日上限，违规扣分；等级解锁真实权限。门槛别学 Stack Overflow。
8. **互动闭环一次做好**：收藏、关注、通知、每周精选周报（复用营销邮件模块）。
9. **公开规则**：审核时效、精选标准、不收什么。

## 三、应避免的坑
1. CSDN 式假原创标记 + 搬运灌 SEO + 付费墙。
2. 把 AI 批量生成的文章当原创（Medium 降级、dev.to 要求披露；国内标识办法）。
3. 推广无隔离或只靠删帖——要给出口（自荐区 + 付费位），不要只堵。
4. 现金激励开太早、规则不清 → 刷量、互赞、小号。
5. 对新人太苛刻：审核意见要具体，可退回修改，不直接删。
6. 未精选低质帖全部放给搜索引擎，拖低整站质量。
7. 跨站转载只设 canonical 就以为没事。
8. 外链默认 dofollow，招来外链贩子。
9. WaytoAGI 的「免费共建」难复制：贝果是商业站，用户会怀疑「给卖家打工」——署名、荣誉和真实回报要更实在，并明确版权归作者、平台只取得展示授权。
10. 【背景知识】国内跟帖评论服务「后台实名、前台自愿」，需内容审核与举报处置机制。
