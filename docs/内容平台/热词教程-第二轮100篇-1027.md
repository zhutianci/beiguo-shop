所以本轮 **约 80% 是「报错原文 / 找不到 / 不见了 / 打不开 / 额度 / 下载安装」**，标题第一屏就放报错原文或问题原话；场景类只留搜索量明显的几篇。

## 写法要点（爆款形状）
- 标题：问题原话或报错原文 + 「怎么办 / 怎么解决 / 在哪」 + 冒号后列 2–3 个原因或入口。
- 开头 3 行内给结论（按概率排的处理顺序），再展开；排查类必须有一张「看到什么 → 怎么办」对照图（decide 版式）。
- 报错类正文里原样写出报错英文全文（便于搜索命中），中文翻译放旁边。
- 和已有文章强互链：每篇至少 3 个站内链接，排查类都链 `/guides/chatgpt-down-check-status-page`（是不是崩了）。
- 充值链接：额度、套餐、找不到新模型、付费功能类，在自然位置链 `/chongzhi/chatgpt-plus` 或 `/chongzhi/chatgpt-pro`；Gemini 需要谷歌账号时链 `/chongzhi/google-zhanghao`。不写价格承诺。
- 官方找不到这条报错的说明时，可以写「官方未单独说明 + 官方通用排查步骤」，但要在开头说清楚；完全没有官方依据的就跳过。
