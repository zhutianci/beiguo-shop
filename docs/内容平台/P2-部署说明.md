## 一、提示词库扩容

### 三大类与新分类

- **大类**挂在模型标签上（`tags.facet`）：
  - 图像：GPT-Image-2 / Nano Banana / Midjourney / 即梦
  - 视频：Seedance / 可灵 / Veo
  - 文本：通用大模型 / ChatGPT / Claude / Gemini / DeepSeek
- **新入口**：`/prompts/image`（AI 绘画提示词大全）、`/prompts/video`（AI 视频提示词大全）、`/prompts/text`（ChatGPT 提示词大全）。
- **筛选条三行**：类型 → 模型 → 主题；进入某一类后，模型和主题只显示这一类的。
- **主题从 10 个扩到 36 个**。新增的文本类主题包括：
  - 科研数据分析、科研绘图、论文写作、文献阅读
  - 文案写作、新媒体运营、营销策划、短视频脚本
  - 编程开发、数据分析、职场办公、学习教育、翻译润色、产品与设计、求职面试

### 文本提示词与图像类的区别

- **不需要效果图**：收录门槛改成「模板 ≥40 字 + 使用说明与示例输出 ≥80 字」。
- **列表**：用文字卡片展示（领域色、等宽字体节选、变量高亮）。
- **详情页**：提示词面板居中加宽，下方是使用说明与示例输出。
- **视频提示词**：封面或关键帧可选；没有封面时说明需 ≥50 字。

### 示例图署名

来自开源仓库的示例图记在 `forum_posts.media_credit`，页面上显示「示例图来源：作者 · 许可证」。

### 种子内容

| 批次 | 内容 | 数量 |

| 第二批 | 图像提示词 101–150（gpt-image-2）、151–200（Nano Banana）；视频 201–230；文本 301–350（科研、技术）、351–410（文案、新媒体、职场等） | 见 `build-seed-bundle` 输出 |

- 示例图放在 `prisma/seed-assets/`，随 `prisma/` 进镜像。
- 每个来源仓库与许可证见 `docs/内容平台/种子内容/prompts/_来源与许可.md`。

**导入**：

```bash
npx tsx scripts/build-seed-bundle.ts           # 本地：校验并生成 prisma/seed-content.json
DATABASE_URL=... npx tsx prisma/import-seed-content.ts --author <站方编辑账号邮箱> --publish --uploads-dir <上传根目录>
```

`--publish`：图像类有示例图的、视频类、文本类直接公开；图像类缺图的、所有教程仍是待审。
**生产环境**需要在临时容器里挂载 `forum_uploads` 卷，把它的挂载点传给 `--uploads-dir`。示例图会复制到其中的 `forum/` 子目录，并登记进 `media_assets`。

## 二、P2 功能

| 功能 | 入口 | 要点 |
|---|---|---|
| 收藏 | 内容页「收藏」 | 被收藏给作者 +2 积分（同一人对同一篇只算一次） |
| 合集 | 内容页「加入合集」；`/collections/{id}` | 每人最多 50 个合集、每个最多 200 条；合集页不收录 |
| 关注作者 | 作者名旁、作者页 | 关注的作者发布提示词、教程、应用时收到通知 |
| 站内通知 | 页头头像上的小圆点；学习空间 | 被评论 / 回复、被精选、审核结果、被做同款、回答被采纳、被举报隐藏 |
| 学习空间 | 头像菜单 →「学习空间」`/learn/me` | 通知、收藏、合集、关注、我的投稿、积分与等级 |
| 积分与等级 | 学习空间、作者页 | 公开 +5、精选 +50、被收藏 +2、被做同款 +10、回答被采纳 +20、违规 −50；唯一约束保证同一件事只记一次。积分 ≥300 自动成为 L2 创作者 |
| 共建者（L3） | 作者页上的管理员按钮 | 站长邀请；也可以在这里手工调整积分 |
| 同款与二创链 | 提示词页「做同款」 | 预填原作的模型与提示词；原作页显示「同款作品」墙；原作者 +10 积分 |
| 热门 / 最新 | 列表页右上「精选 / 最热 / 最新」 | 最热 = (复制×3 + 同款×5 + 收藏×2 + 赞 + 评论×2 + 1) / (小时数 + 2)^1.2；带 sort 的页面不收录，canonical 指回原地址 |
| 站内搜索 | 学习平台首页、各列表页的搜索框；`/learn/search` | 不收录，robots 屏蔽 |
| 举报 | 内容页、每条评论 | 3 人举报自动暂时隐藏；后台「举报队列」：成立则下线并扣分，驳回则恢复 |
| 问答采纳 | 论坛讨论帖的评论 | 提问者采纳最佳回答，回答者 +20 积分；采纳后结构化数据改为 QAPage |
| 查重 | 发帖、编辑时自动 | SimHash（汉字二元组 + 英文词，64 位），距离 ≤8 视为疑似重复，非管理员转人工，审核备注写明像哪一条 |
| AI 应用与作者自荐 | `/apps`、`/apps/showcase` | 见下 |
| 每周精选邮件 | 后台论坛页「生成本周精选草稿」 | 只生成营销邮件草稿；预览、测试、受众、发送都在「营销邮件」里照常操作，退订与额度沿用营销模块 |

### AI 应用与作者自荐（设计 §5.3、§9）

- **新内容类型 `APP`**：应用名、官网、价格、平台、试用方式，正文写「我用它解决了什么」。
- **作者自荐（`selfPromo`）按设计的四件套执行**：
  1. 只放在 `/apps/showcase`，不和普通分享混排；
  2. 必须选择与产品的关系，页面上显示「作者自荐」披露条；
  3. 必须写明怎么试用；
  4. L2 创作者以上才能发、每 30 天 1 条、一律人工审核。
- **作者自荐的外链** `rel="sponsored nofollow"`；普通分享是 `ugc nofollow`。
- **作者自荐默认不收录**，被精选（确有教程价值）才放开；`/apps/showcase` 本身不收录。
- 「作者自荐」开关发布后作者不能改，只有管理员能改。

## 五、已知的、留给后面的

- **热门排序在内存里算**：取近 180 天、最多 1500 条。量级上来以后改成定时任务写分数列。
- **搜索用 LIKE**：中文全文索引（MySQL ngram）要改表，内容过万再换。
- **查重逐条比较**：2 万条以内足够快，再多改成分段索引。
- **关注者通知单次最多 2000 人**：超过时要改成订阅流。
- **示例图**：一部分来自开源仓库，标注了来源。站长有了自己的出图后，在编辑页替换即可，来源标注会随之清空。
