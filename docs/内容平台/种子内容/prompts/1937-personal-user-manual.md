prompt: |
  你是一名团队协作顾问，要通过访谈帮我写一份「个人使用说明书」（也叫与我共事指南）。它不是自我介绍，也不是简历，而是告诉同事「怎么和我合作最顺」。

  我的岗位和日常工作内容：[岗位与工作内容]
  这份说明书给谁看（新同事、下属、上级、跨部门伙伴）：[阅读对象]
  团队的协作方式（远程或现场、常用的沟通工具、开会多不多）：[团队协作方式]
  同事对我有过的评价或误解：[他人评价与误解]

  第一阶段：访谈。从下面七个方面向我提问，每次只问 3 个问题，等我回答后再问下一组。问题要逼出具体情境：不问「你喜欢怎样的沟通」，而问「上一次让你觉得合作很顺的同事，是怎么找你对接的」。
  1. 工作节奏：一天里什么时候状态最好，什么时候不适合找我做复杂判断。
  2. 沟通偏好：急事和不急的事分别怎么找我；喜欢文字还是当面；多久回复算正常。
  3. 做决定的方式：需要多少信息，需要独处想还是边聊边想。
  4. 我看重什么：哪些行为会让我特别信任一个人。
  5. 雷区与怪癖：什么会让我不舒服；我有哪些容易被误解的习惯，以及它的真实意思（如「我不说话不代表同意，通常是还在想」）。
  6. 反馈：希望别人怎么给我提意见；我在压力下会是什么样，这时怎么帮我。
  7. 我能帮上什么、不擅长什么。

  第二阶段：成文。访谈完成后整理成一页，400 字以内：
  - 每一条都写成别人可以照着做的行为，句式参考「如果……，请……」「当我……，意思是……」。
  - 删掉人人适用的空话（如「我喜欢高效沟通」「我追求卓越」）。
  - 雷区写成偏好而不是命令，语气平和，不给别人立规矩；末尾加一句「以上是我的习惯，不是要求，欢迎告诉我你的」。
  - 只使用我在访谈里说过的内容，不替我添加性格标签或性格测试类型。
  - 不写不适合公开的隐私（健康状况、家庭细节）；我提到了也请提醒我是否保留。

**怎么填变量**：[阅读对象] 决定详略：给下属看，要多写「怎么向我汇报、什么事不用问我」；给上级看，要多写「我需要什么样的信息才能把事做好」。[他人评价与误解] 是很好的素材，比如「有人说我回消息太短，显得冷淡」，说明书可以直接解释这一点。访谈时尽量举实际发生过的事，而不是描述理想中的自己。

**常见失败与调整**：
- 写成优点清单。「认真负责、善于沟通」对同事毫无用处；每条都问自己：别人看完知道该怎么做吗。
- 语气像在提要求。「不要在下班后找我」会让人反感，改成「下班后的消息我一般第二天上午回，急事请直接打电话」。
- 写的是希望成为的样子。如果你实际上常常晚回消息，就照实写，并给出别人可以用的办法。

### 示例输出

> 示例，仅供参考（虚构：数据分析师阿苗写给新同事的版本，节选）

**与我共事指南**

**找我的方式**
- 不急的需求请发文字，写清「要什么数、截止时间、用来做什么决定」，我会在当天下班前回复排期。
- 急事请直接打电话，连发几条消息不如一通电话快。

**容易被误解的地方**
- 会上我不说话，通常是还在想，不代表同意；需要我当场表态时请直接点我的名字。
- 我回消息很短，没有情绪，只是习惯。

**给我提意见**
- 请直接说哪里有问题，最好带上具体的例子，不用铺垫。
- 压力大的时候我会变得话少、回复更慢，这时问一句「要不要帮你砍掉一项」对我最有用。

**我不太擅长**：临时的口头汇报。提前半天告诉我，效果会好很多。

以上是我的习惯，不是要求，欢迎告诉我你的。
