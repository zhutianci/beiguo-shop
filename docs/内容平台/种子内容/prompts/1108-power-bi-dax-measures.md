**怎么填变量**：[数据模型] 和 [表关系] 是 DAX 写对的前提，很多「度量值不对」的问题其实是关系或日期表的问题。[指标定义] 一定要写清业务口径，例如「占比 = 当前产品销售额 ÷ 当前门店筛选下所有产品的销售额」，口径不同，用的函数完全不同。

**常见坑**：
- 没有单独的日期表，直接在事实表的日期列上用时间智能函数，结果经常是空的或不正确。要建立连续的日期表并标记。
- 占比的分母用了移除全部筛选的写法，切片器选择了某个门店后，分母仍然是全公司的销售额，占比变得很小。需要保留切片器选择时，用 ALLSELECTED 一类的写法。
- 用计算列实现本该是度量值的指标，结果不会随筛选变化，还占用模型空间。

**追问技巧**：追问「这个度量值在总计行显示的数字不对，为什么」——总计行的筛选上下文和明细行不同，这是 DAX 中最常见的困惑之一。

### 示例输出

> 示例，仅供参考（节选）

```
销售额 = SUM ( '销售'[金额] )

销售额 同比 % =
VAR 本期 = [销售额]
VAR 去年同期 = CALCULATE ( [销售额], SAMEPERIODLASTYEAR ( '日期'[日期] ) )
RETURN
    IF ( NOT ISBLANK ( 去年同期 ), DIVIDE ( 本期 - 去年同期, 去年同期 ) )

销售额 年初至今 = TOTALYTD ( [销售额], '日期'[日期] )

产品占比 % =
DIVIDE ( [销售额], CALCULATE ( [销售额], ALLSELECTED ( '产品' ) ) )
```

**解释「产品占比」**：在矩阵中「华东门店 × 产品 A」这个单元格里，筛选上下文是门店为华东、产品为 A。分母中 `ALLSELECTED('产品')` 移除了单元格本身对产品的筛选，但保留切片器的选择，因此分母是「华东门店在当前切片器选择下所有产品的销售额」。
