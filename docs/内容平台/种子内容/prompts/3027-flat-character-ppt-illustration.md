**怎么填变量**：[黑色] 和 [亮橙色] 分别控制发色和外套颜色，可以改成"[棕色]""[墨绿色]"来配合你的 PPT 主色。想要不同场景，把手持物换掉：笔记本电脑 → "一叠文件""一杯咖啡""一张图表"；漂浮的笔记本 → "灯泡""对话气泡""奖杯"，就能得到一组风格统一的人物插画。

示例图是白底上一位黑色波波头、橙色开衫、米色阔腿裤的女性，左手托着灰色笔记本电脑，右手插兜，右上方漂浮一本带白色爱心的青绿色笔记本，脸上只有简单的点眼和微笑，粗黑圆描边，几乎没有阴影。

**常见问题**：
- 想要完全无脸：示例图仍画出了简单的眼睛和嘴，可以改成"脸部留白，不画五官"。
- 风格变成美式卡通：加"日系扁平插画，参考日本商务插画素材的画风"。
- 要一组多个姿势：在同一对话里说"保持同一人物和画风，换成 XX 姿势"。

**适合**：实习 / 求职汇报 PPT、教程与文章配图、网页空状态插画、简历作品集。
