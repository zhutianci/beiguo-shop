**怎么填变量**：[研究问题] 越聚焦越好，「运动干预对老年人抑郁症状的影响」比「运动与心理健康」可做得多。[团队人数] 很重要：PRISMA 和多数方法学指南都建议筛选与提取由两人独立完成，只有一个人时，AI 会建议你如何报告这一局限。

**常见问题与调整**：
- 纳入标准太宽导致初筛几千篇 → 追问：「在不偏离研究问题的前提下，哪两条标准可以收紧？各自会排除掉哪类研究？」
- 流程图数字对不上 → 把记录表的汇总数字贴给 AI：「检查这些数字的加减关系，指出哪一步缺了记录。」
- 检索式本身怎么写，可以用本站「文献检索式怎么写」提示词；纳入研究的偏倚评价可用「文献质量评价提示词」。

**提醒**：PRISMA 是报告规范而不是做法教科书，具体方法建议参考 Cochrane 手册等权威资料；流程图模板请从 PRISMA 官方网站下载最新版本。

### 示例输出

> 示例，仅供参考（研究问题：线上正念干预对大学生焦虑的影响）

**排除理由代码表**：E1 人群不符（非大学生）；E2 非正念干预或混合干预无法拆分；E3 无对照组；E4 未报告焦虑结局；E5 会议摘要或无全文。

**流程图逐框说明（节选）**：
- 「Records identified from databases（n = __）」= 记录表中各数据库检索导出数之和；
- 「Records removed before screening: duplicates（n = __）」= 导入文献管理软件后去重删除的数量；
- 「Reports excluded（n = __）」需按 E1–E5 分别列出数量，合计应等于全文复筛排除总数。
