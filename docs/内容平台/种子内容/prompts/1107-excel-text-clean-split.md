**怎么填变量**：[数据样例] 一定要包含「有问题的行」，只贴干净的行，AI 看不出要处理什么。数据涉及姓名、手机号时，可以先把真实信息替换成假的再发给 AI，只要格式保持一致即可。

**常见坑**：
- 用 TRIM 去不掉网页复制过来的空格。那通常是不间断空格（编码为 160），需要先用 SUBSTITUTE 把它替换成普通空格。
- 文本型数字看起来正常，求和结果却是 0。用 VALUE 转换，或者用「分列」直接完成转换。
- 想用一个复杂公式把所有不规则数据一次拆好，结果总有几十行拆错。先按规律处理大部分，剩下的少数单独标出来人工处理。

**追问技巧**：追问「这些清洗步骤每周都要做一次，帮我改写成 Power Query 的步骤」（可配合 1104 号提示词），或「清洗后的数据怎么检查重复的客户」。

### 示例输出

> 示例，仅供参考（节选）

| 列 | 问题 | 处理方法 |
|---|---|---|
| 客户信息 | 「张三 13800000000 浙江省杭州市」挤在一格，用空格分隔 | Excel 365 用 `=TEXTSPLIT(TRIM(A2), " ")`；旧版本用「数据 → 分列 → 按空格」 |
| 金额 | 混有「元」、千分位逗号、全角数字、不间断空格 | 见下方公式 |
| 城市 | 「杭州」「杭州市」「杭州 」并存 | 建对照表后用 XLOOKUP 统一 |

```
=NUMBERVALUE(SUBSTITUTE(SUBSTITUTE(TRIM(SUBSTITUTE(ASC(B2), CHAR(160), " ")), "元", ""), ",", ""))
```

**解释**：`ASC` 把全角字符转为半角（WPS 与 Excel 均支持，以实际为准）；`SUBSTITUTE(..., CHAR(160), " ")` 把不间断空格换成普通空格；去掉「元」和千分位逗号后，用 `NUMBERVALUE` 转为数字。

**校验**：`=SUMPRODUCT(--NOT(ISNUMBER(C2:C3001)))` 统计转换后仍不是数字的行数，结果应为 0。
