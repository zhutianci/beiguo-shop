prompt: |
  【角色】你是一名资深 HRBP，做过数百次离职面谈，知道员工在离职时往往才会说真话，但前提是让他们感到安全。
  【背景】
  - 离职员工岗位与司龄：[岗位与司龄]
  - 离职类型：[主动离职]
  - 已知的离职原因（员工提交的或经理转述的）：[已知原因]
  - 面谈时长与形式：[时长与形式]
  - 公司近期希望了解的问题（如管理、薪酬、发展）：[关注的问题]
  【任务】
  1. 开场话术：说明面谈目的（了解真实想法、帮助改进，不是挽留或追责）、保密范围、员工可以选择不回答。
  2. 问题清单（按顺序，开放式为主）：
     - 离职决定：什么时候开始考虑、最主要的原因、有没有一件事让你最终下定决心；
     - 工作本身：工作内容、工作量、资源与工具；
     - 管理与团队：与上级的沟通、团队氛围、被认可的程度；
     - 发展与回报：成长机会、晋升、薪酬福利（只了解感受，不询问新单位具体薪资）；
     - 改进建议：如果可以改变一件事、什么情况下会考虑回来；
     - 交接与后续：工作交接、离职手续、对公司的推荐意愿。
     按我提供的已知原因，补充 2–3 个深入追问的问题。
  3. 面谈技巧：如何让员工说出真实原因（如先问事实再问感受、避免辩解）、员工情绪激动时如何回应。
  4. 记录表模板：基本信息 | 主要离职原因（编码）| 次要原因 | 关键原话 | 改进建议 | 是否欢迎回流 | 面谈人。
  5. 离职原因编码表：薪酬福利、职业发展、直属管理、工作内容、工作强度、团队氛围、个人家庭、外部机会等一级分类，每类 2–4 个二级分类。
  6. 汇总分析建议：按季度统计的维度（部门、司龄、岗位、原因编码），以及如何把发现反馈给管理层（注意匿名化）。
  【约束】
  - 面谈内容保密，汇总分析时匿名处理，不向原部门透露可以识别个人的信息。
  - 不询问与离职无关的个人隐私，不试图说服员工改变决定（除非公司明确要求挽留并另行安排）。
  【输出格式】开场话术 → 问题清单 → 面谈技巧 → 记录表模板 → 离职原因编码表 → 汇总分析建议。

**怎么填变量**：[已知原因] 写员工在离职申请中写的原因，或者经理转述的情况，比如「申请写的是个人发展，经理说可能和最近的组织调整有关」。AI 会针对表面原因和可能的真实原因设计追问。[关注的问题] 写公司近期想重点了解的方向。

**常见坑**：离职面谈变成挽留面谈或者走过场，员工只会说「个人原因」「想换个环境」。说明面谈目的、承诺保密，并让面谈人不是员工的直属上级，更容易听到真话。另一个常见问题是记录完就放进档案，从不汇总分析。按原因编码统计，才能发现「某个部门的离职原因集中在直属管理」这类问题。

**迭代追问**：积累了一个季度的记录后，可以把匿名化的记录贴进来，说「按编码汇总分析，找出前三大可控原因」（可以配合离职原因分析提示词）；员工个人的离职申请和面谈准备，可以参考离职申请书提示词。

### 示例输出

> 示例，仅供参考（岗位：前端工程师，司龄 2 年）

**开场话术**：谢谢你抽出时间。今天的谈话主要是想听听你在这里两年的真实感受，帮助我们改进，不是挽留，也不会影响你的离职手续和评价。内容会保密，汇总时会匿名处理，有不想回答的问题可以直接跳过。

| 一级分类 | 二级分类 |
|---|---|
| 职业发展 | 晋升机会少、技术成长受限、岗位调整不符合预期 |
| 直属管理 | 沟通方式、认可不足、分工不合理 |
| 工作强度 | 长期加班、频繁需求变更 |
