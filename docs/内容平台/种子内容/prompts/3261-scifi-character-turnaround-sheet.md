**怎么填变量**：[天体旅者] 可以换成任何原创角色类型，例如"深海祭司""沙漠游侠""机械修女"；[科幻奇幻] 可换"蒸汽朋克""东方仙侠"；[白色与金色] 和 [金色纹路与浮雕] 决定整体气质，换成"黑曜石色与紫水晶纹路"会变得更暗黑。示例图是纯白背景：左边三个全身像分别是正面、侧面、背面，角色披着白底金纹的长袍，身后一圈带尖芒的金色光环；最右边是大号面部特写，苍白的面具状脸上额头有一个发光的金色圆形符号。

**常见问题与调整**：
- 三个视角衣服对不上：加"三视图严格保持同一套服装、同一配饰位置，只改变朝向"。
- 背景出现场景：重复"纯白背景，无地面、无环境、无文字"。
- 想要带标注的设定稿：追问"在每个视图下方加中文小标签：正面 / 侧面 / 背面，并在右下加色板"。
- 角色太像已有作品：加"原创设计，不要模仿任何已知游戏或电影角色"。

**适合**：原创角色前期设定、小说角色视觉化、AI 视频角色参考图；不适合直接作为建模用的精确正交图。
