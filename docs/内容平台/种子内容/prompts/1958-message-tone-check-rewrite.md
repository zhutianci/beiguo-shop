prompt: |
  你是一位语气校对员。你的工作不是把话改得更客气，而是让「对方读到的意思」和「我想表达的意思」一致。请站在收件人的位置读我的消息。

  我写好的消息原文：[消息原文]
  收件人及与我的关系（上级 / 下级 / 平级 / 客户 / 亲友）：[收件人与关系]
  发送渠道（私聊、群聊、邮件）以及谁还会看到：[渠道与可见范围]
  事情的背景：[事情背景]
  我想让对方读完后知道什么、做什么：[我的真实意图]
  我现在的情绪：[我的情绪]

  请按下面的步骤输出：
  1. 收件人视角的第一印象。假设你是收件人，在忙碌中第一次读到这条消息，用两句话说出你的感受，以及你认为发件人想干什么；再与我的真实意图对比，指出偏差。
  2. 逐句标注。把原文分句，每句标一个风险等级（无 / 轻 / 重）并注明类型：
     - 生硬：命令式、没有称呼和缘由、「请知悉」、不带时间的「尽快」。
     - 甩锅：强调「我早就说过」「按你的要求」「不是我这边的问题」，或只陈述他人的失误而不提下一步。
     - 阴阳怪气：反问（「这个应该不难吧？」）、表面客气实则挖苦、「呵呵」「哦」「行吧」、省略号和连续的句号。
     - 居高临下：说教、「我是为你好」、对平级或上级用「希望你能明白」。
     - 含糊：对方看完不知道要做什么、什么时候做。
     - 过度：道歉或客套太多，把要说的事淹没了。
     每处说明为什么这位收件人可能这样理解；只是个人风格、风险不大的不必硬挑。
  3. 渠道检查。这条内容适不适合发在群里（涉及批评、责任归属的建议改私聊）；被截图转发后会不会产生歧义。
  4. 改写两个版本，都必须保留我的真实意图和全部事实信息，不替我承诺任何我没说过的事，长度不超过原文的 1.3 倍，每个版本后用一句话说明改了什么：
     - 版本一「直接清楚」：去掉情绪词和反问，结构为「事实 → 我需要什么 → 时间」。
     - 版本二「留有余地」：在版本一的基础上，加一句承认对方的处境或给对方解释的空间，但不卑微、不堆砌客套。
  5. 发送建议：现在发、冷静一小时后再发、改为打电话或当面说，三选一并给理由。我写明自己正在生气且内容涉及指责时，默认建议先不发。
  6. 如果原文本身没有问题，直接说「可以发」，不要为了改而改。

  限制：不改变事实和我的立场；不把该说清楚的问题改得含混；原文里的人名、数字、时间一个都不能改动。

**怎么填变量**：[消息原文] 原样粘贴，标点和表情都别动，生硬和阴阳怪气常常就藏在句号、省略号和引号里。[我的真实意图] 用大白话写，比如「我想让他今天下班前把表补上」，改写会以它为准。[渠道与可见范围] 写清是不是群聊、群里有谁，同一句话私聊和当着领导的面说，分量不一样。

**常见失败与调整**：
- 改得太软，问题没了。原本是要对方补交材料，改完变成「您有空的时候看看」；检查改写后对方是否仍然清楚要做什么、什么时候做。
- 模型擅自改了时间或数字。发之前对照原文核一遍事实信息。

### 示例输出

> 示例，仅供参考（虚构：项目助理小于准备发在项目群里的一条消息）

**原文**：@老何 数据表上周就说要交了。现在还没看到。。。这个应该不难吧？麻烦尽快，不然周报又要因为你这边延期了。

**收件人视角的第一印象**：感觉被当众指责拖了大家后腿，发件人像是在向群里的人说明延期不是她的责任。与真实意图（今天拿到数据表）有偏差。

**逐句标注**
| 原句 | 风险 | 类型与原因 |
|---|---|---|
| 现在还没看到。。。 | 重 | 阴阳怪气：连续句号读起来像不耐烦 |
| 这个应该不难吧？ | 重 | 阴阳怪气：反问，暗示对方能力或态度有问题 |
| 麻烦尽快，不然周报又要因为你这边延期了。 | 重 | 甩锅加含糊：在群里归责，「尽快」没有时间 |

**版本二（留有余地，私聊）**：何工，周报要用的数据表我这边还没收到，不知道是不是遇到了什么卡点？如果今天下午 4 点前能给我，我 5 点可以按时汇总；要是来不及，告诉我一声，我先在周报里标注待补。
改动：去掉反问和归责，补上具体时间，并给对方说明情况的空间。
