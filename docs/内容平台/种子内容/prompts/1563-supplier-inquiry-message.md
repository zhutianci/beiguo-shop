**怎么填变量**：[规格要求] 越具体越好，附上参考图片的描述或尺寸图；「差不多就行」最容易导致大货和样品不一致。[采购数量] 如实写首单和预计用量，工厂会据此给阶梯价。

**常见坑**：
- 第一条消息只问「这个多少钱」，工厂随便报一个价，后面还要来回问十几轮；
- 只比单价，不比起订量、交期、付款方式和是否含税含运费，最后算下来更贵；
- 让工厂做「和某品牌一样的」，可能涉及侵权，产品上架后会被投诉。

**迭代追问**：「把这条询价消息翻译成英文，用于联系海外工厂」「三家供应商的报价出来了，帮我整理比价并给出建议」「样品到了，帮我写一份样品验收清单」。
