**怎么填变量**：[服务内容] 写具体，比如「小红书账号的封面和笔记排版设计，每月套餐或单次」，比「平面设计」更容易让客户判断。[不接的类型] 很重要，提前写清楚，能帮你过滤掉大量不合适的询单，节省沟通时间。

**常见坑**：服务介绍写成个人简历，客户看不出你具体能交付什么、多久交付、怎么收费。另一个常见问题是没有流程和修改规则，结果一个小单改了十几轮。把流程和规则提前写清楚，既专业也保护自己。展示作品时，要确认客户允许公开，或者隐去客户名称和保密信息。

**迭代追问**：追问「为我的服务设计 3 档套餐（基础 / 标准 / 高级），说明每档包含什么」；报价可以用报价单提示词测算；签约前用外包服务合同要点提示词检查合同。

### 示例输出

> 示例，仅供参考（服务：中英文商务翻译）

**一句话定位**：为出海中小企业提供产品资料与官网的中英翻译，准确、地道、按时交付。

**合作流程**：需求沟通（确认用途、字数、术语表）→ 报价确认 → 预付款【我确定比例】→ 初稿 → 一次免费修改 → 终稿交付 → 支付尾款。

**询单首次回复**：您好，感谢联系！为了给您准确的报价和时间，想先确认几个问题：1. 文件类型和大概字数？2. 用途是官网、宣传册还是合同？3. 希望什么时候交付？4. 是否有已有的术语表或参考译文？
