  - 预计篇幅：[预计篇幅]（如：300 万字，约 8 卷）
  - 主角的特殊之处：[主角特殊之处]
  - 风格：[风格偏好]（如：硬核、规则清晰 / 轻松，弱化数值）

  2. 境界划分：设计 6–9 个大境界（可以再分小境界），用表格列出——境界名称（原创，与世界观呼应）| 标志性能力 | 寿命或身体变化 | 在世界中的地位与人数比例 | 主角预计在第几卷到达。

  4. 修炼资源：资源的种类、获取方式、稀缺程度，以及它们如何推动人物之间的争夺和冲突。

  6. 升级节奏：根据预计篇幅，给出主角境界提升的大致节奏，前期快、中后期放缓的分配建议。

**怎么填变量**：[世界观核心] 是让体系有新意的关键，同样是修仙，「靠吸收星光」和「靠记住别人遗忘的东西」会长出完全不同的境界和资源。[预计篇幅] 决定境界数量和升级速度，篇幅不长却设计十几个境界，主角会升级得太快，境界变得没有分量。

**常见问题与调整**：
- 境界名称不好记 → 追问：「每个境界名用两个字，并且能让读者从名字猜出大致能力。」
- 越级挑战太随意 → 追问：「设计一个越级的硬性代价，让每次越级都是一场赌博。」
- 后期没有对手 → 追问：「设计第二条力量体系或一个境界之外的威胁，让后期剧情仍有压力。」

**相关**：主角的特殊能力用本站「网文金手指设定提示词」；不同门派的修炼差异用「小说势力设定提示词」。

### 示例输出

> 示例，仅供参考（世界观：力量来自记忆，修炼即「铭刻」记忆）

| 境界 | 标志性能力 | 地位与比例 |
|---|---|---|
| 拾忆 | 能清晰回想自己经历过的每一刻 | 普通修行者，约十人中有一人 |
| 刻痕 | 能把记忆刻入物品，留下「残影」 | 小宗门的中坚 |
| 共鸣 | 能读取他人的近期记忆 | 稀少，常被各方招揽 |

**突破代价**：每次突破都要「交出」一段珍贵的记忆——主角越强大，越会忘记自己为什么出发。
