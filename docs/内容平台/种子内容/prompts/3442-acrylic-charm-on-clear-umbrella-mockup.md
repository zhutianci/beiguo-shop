**怎么填变量**：上传挂件的正面图，白底或透明底最好；[透明塑料雨伞] 可以换成"帆布包的提手""双肩包拉链头""钥匙串"，后面"位置"的描述相应调整；固定方式写你实际会用的配件；背景可换成"咖啡馆的窗边""樱花树下"。

示例图：雨天街头，一只手的指尖捏着透明雨伞的弯把，把手上用金属龙虾扣挂着一枚 Q 版男孩头像的亚克力挂件，挂件和伞柄上都是水珠，背景是红绿灯和车灯化成的彩色光斑。

**常见问题**：
- 挂件图案被重画、变了样：把第一段放在最前面，并上传分辨率更高的设计图。
- 挂件悬空或穿过伞柄：强调"通过扣环挂在把手上，受重力自然下垂"。
- 挂到了伞杆上：保留"在把手一侧、不是伞杆"这一句。

**适合**：亚克力周边 / 伞标 / 钥匙扣的商品场景图、定制周边店铺的详情页、新品预告。
