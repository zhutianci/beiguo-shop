**时长与镜头**：没有写时间码，而是"一句话一个画面"的诗意蒙太奇：模型会把每个短句当成一个镜头，自动剪成快节奏的蒙太奇。15 秒大概能出 5–7 个画面，所以真正出现的是前面几句——最想要的画面要放在前面。

**怎么用**：这种写法适合品牌情感片和公益片：把"失去的东西回来了"换成你的主题，例如"所有被遗忘的老手艺都回来了""城市里消失的星空回来了"，保持"异象出现 → 人们驻足 → 规模扩大 → 情感落点"的四步。最后一句是"情感落点"，决定整条片子的调性，要写得像一句广告文案。

**怎么填变量**：[玩具士兵] 换成"一只褪色的毛绒熊""一辆旧自行车"，开场这个具体的小物件决定了观众第一眼的情绪。

**常见失败与调整**：
- 画面太多太杂：删掉一半句子，只留 5 个最想要的画面。
- 变成灾难片：保留"惊奇与希望"，负面提示词写"灾难破坏"。
- 文字从天而降的信件上出现乱码：写"信封上没有字"。
