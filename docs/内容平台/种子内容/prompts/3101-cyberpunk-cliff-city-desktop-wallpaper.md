**怎么填变量**：[未来东方赛博朋克巨城] 可以换成"蒸汽朋克空中港口""雪山上的未来修道院"；[云层之上的橙红色日落] 换成"暴雨霓虹夜""黎明前的蓝调时刻"；画风可以改成"吉卜力式手绘背景"之外的任意原创风格（避免指名知名 IP 画风）。飞行器数量约束可以删掉，画面会更自由。

示例图是一座横跨画面的悬崖城市：左侧是挂着红灯笼和竖排招牌的多层东方楼阁，往右是高耸的科幻塔楼和平台，城市下方翻滚的云海，右侧一轮巨大的橙红夕阳，天空里散布着大大小小的飞行器。

**常见问题**：
- 招牌上的文字乱码：写"招牌只有发光色块和装饰性符号，没有可读文字"。
- 画面太暗：把夕阳写得更大更亮，或改成"天空大面积暖桃色"。
- 要手机壁纸：画幅改 9:16，并写"城市占画面下半部分，上方留天空"。

**适合**：电脑 / 平板壁纸、科幻游戏概念图、小说封面、直播背景。
