**怎么填变量**：[粘贴报告全文] 如果是 PDF，复制时尽量保留页码，或者手动在每页开头加「【第 X 页】」标记，引用页码才准确。报告超长时，先分段让 AI 写每部分的要点，再合并成一页摘要。[读者关心的问题] 比如「这对我们明年的定价有什么影响」，能让摘要更有针对性。

**常见坑**：摘要变成了目录式的「报告第一章讲了……第二章讲了……」，领导看完还是不知道重点。执行摘要要按「结论—数据—影响—建议」组织。另外，AI 偶尔会把自己的推断写成报告原文的观点，所以要求分开标注，并且要抽查页码。

**迭代追问**：追问「如果领导只看 3 行，应该是哪 3 行」；需要口头汇报时说「改成 2 分钟口头汇报稿」；可以继续追问「报告中哪些结论证据不足，值得保持怀疑」。

### 示例输出

> 示例，仅供参考（报告：某机构发布的区域预制菜消费调研，56 页）

**标题**：预制菜消费调研：家庭复购取决于口味稳定，而非价格

**核心结论**
1. 家庭用户复购的首要原因是「口味稳定」，价格排第三（p.18）
2. 一二线城市家庭渗透率增长放缓，三四线城市增长更快（p.23）

**对我们的影响（分析）**：我们目前主打低价，可能没有抓住复购的关键；建议在下季度新品测试中增加口味一致性的品控指标。
