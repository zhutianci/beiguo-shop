prompt: |
  【角色】你是一位熟悉马歇尔·卢森堡「非暴力沟通」的练习伙伴，帮我把一句带着情绪的话改写成四步表达。你只帮我把自己的意思说清楚，不帮我设计让对方就范的话术。
  【材料】
  - 我最想对对方说的原话（不用修饰，越真实越好）：[想说的原话]
  - 对方是谁、我们的关系：[对方与关系]
  - 具体发生了什么（时间、对方说了或做了什么）：[事情经过]
  - 我希望这次沟通之后发生什么改变：[期望的改变]
  - 沟通方式（当面、电话、文字消息）：[沟通方式]
  【任务】
  1. 标注原话。逐句指出其中的四类问题并说明理由：评判（给人贴标签，如「你太自私」）、夸大（总是、从来、每次）、把想法当感受（「我觉得你不尊重我」是对对方的判断，不是感受）、要求（带威胁或不容拒绝）。
  2. 观察。改写成摄像机能录到的事实：谁、什么时候、说了或做了什么、发生了几次，不带形容词和原因推测。次数、时间我没说的，问我，不要补。
  3. 感受。给出 3～4 个候选的感受词让我选（如失落、着急、委屈、担心、疲惫），避开「被忽视」「被利用」这类暗含指责的词。
  4. 需要。说出感受背后我在意的东西（如被体谅、可预期、休息、参与决定）。需要是普遍的，不指向特定的人和做法：「我需要你准时」是请求，「我需要安排可预期」才是需要。给 2 个候选。
  5. 请求。写成具体、正向、此刻可以回应的请求：说要什么，而不是不要什么；包含动作、时间或次数；以询问结尾，对方可以说不。同时写一句对方拒绝时我的回应（先听对方的难处，再一起找别的办法）。
  6. 合成两个版本：完整版（四句话，80 字以内）和口语版（不像背公式，可以调换顺序、省略部分步骤），按我的沟通方式调整语气。
  7. 自检。如果请求被拒绝我就会生气或惩罚对方，那它其实是要求，请帮我指出来。
  【约束】不揣测对方的动机；不写道德绑架、冷处理、以退为进之类的操控手法；如果事情涉及人身安全或持续的言语、肢体伤害，请建议我寻求专业人士或当地援助机构的帮助，这种情况不适用沟通技巧。
  【输出格式】原话标注 → 四步拆解表 → 完整版 → 口语版 → 被拒绝时的回应 → 自检结果。

**怎么填变量**：[想说的原话] 写气头上最想说的那句，比如「你每次都这样，根本不把我的时间当回事」，不要先自己美化。[事情经过] 写得出具体的时间和次数最好：「这个月约了三次，两次迟到半小时以上」。[期望的改变] 写你真正想要的，「以后晚到提前告诉我」比「希望他尊重我」更容易变成请求。

**常见失败与调整**：
- 感受后面跟了「你」。「我感到你不在乎我」是披着感受外衣的指责，换成「我有点失落」。
- 请求其实是要求。如果对方说「做不到」你就打算翻脸，先回到第 4 步想清楚自己的需要，可能有别的办法满足它。
- 用它来「搞定」对方。非暴力沟通的前提是对方可以拒绝，把它当话术用，对方很快就听得出来。

### 示例输出

> 示例，仅供参考（虚构：小宋想对经常迟到的朋友阿凯说的话）

**原话标注**：「你每次都这样，根本不把我的时间当回事。」
- 「每次都」：夸大，实际是三次里两次。
- 「不把我的时间当回事」：评判，是对对方动机的推测。

| 步骤 | 内容 |
|---|---|
| 观察 | 这个月我们约了三次，有两次你比约定时间晚到了半小时以上 |
| 感受 | 着急、有点失落 |
| 需要 | 安排可预期；我的时间被考虑到 |
| 请求 | 下次如果会晚到，能在出门前发消息告诉我大概几点到吗？ |

**口语版**：阿凯，上两次我在那儿等了半个多小时，说实话有点着急。以后要是会晚，出门前跟我说一声呗，我也好晚点出门。

**被拒绝时的回应**：「是时间不太好估吗？那我们以后约在你下班顺路的地方，会不会好一些？」
