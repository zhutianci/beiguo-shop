**怎么用**：在 DeepSeek 输入框下方打开「深度思考」后再发送（按钮名称以实际界面为准）。这条提示词故意不写「请一步步思考」「先分析 A 再分析 B」：带思考模式的模型会自己规划推理路径，你把目标、约束和判断标准说清楚，比替它安排步骤更有效。

**怎么填变量**：[硬约束] 写不能碰的线，如「月还款不超过 6000」「必须 11 月前上线」；[看重的因素排序] 一定要排序，「都重要」等于没说；[已知事实] 只写确定的，听说的、估计的放到「顾虑」里。

**核对思考过程**：回答上方可以展开它的思考内容。重点看两件事：它有没有把你没说过的事当成事实；它有没有漏掉你给的某条硬约束。发现了就指出来让它重算：「你假设了通勤 40 分钟，实际是 90 分钟，请重新判断。」通过 API 调用时，思考内容在 `reasoning_content` 字段里，正文在 `content` 里。

**常见问题**：
- 结论含糊 → 追问：「如果只能选一个，你选哪个？」
- 想听反方 → 追问：「假设你要说服我选另一个方案，最强的三条理由是什么？」

### 示例输出

> 示例，仅供参考（要决定的事：两个工作机会选哪个）

**推荐：选 B（本地的中型公司）。**

关键依据：
1. 你把「能陪家人」排在第一位，A 需要异地，每月只能回家两次（来自你给的事实）。
2. B 的固定薪资比 A 低约 12%，但扣除你列出的异地房租后，实际结余差距不到 3%（推断，基于你给的数字）。
3. A 的成长空间更大，但这一项被你排在第三位（来自你的排序）。

会推翻结论的条件：如果 A 可以远程办公每周三天以上，或 B 的试用期考核通过率明显偏低，结论需要重新评估。
