**为什么要记忆卡**：模型一次能看的内容有限，对话越长，早期章节越容易被忽略，人设和伏笔就开始跑偏。把「目前的故事状态」压缩成一张卡，每章随身带，比指望它记住前面几十章可靠得多。DeepSeek 写中文网文的语感不错，但同样需要这张卡来管住一致性。

**第一张卡怎么来**：第一次使用时，把已写的章节（或大纲、人物设定）贴给它，说：「请按人物状态表、伏笔表、故事时间、物品与能力四部分整理成记忆卡。」之后每章都用上一章输出的新卡。

**怎么填变量**：[本章必须发生的事] 写 2–4 件具体的事，而不是「推进剧情」；[视角与文风] 如「第三人称限知，跟随女主；短句多，少用形容词」。

**常见问题与调整**：
- 记忆卡越写越长 → 每 10 章让它精简一次：「把已回收的伏笔和已退场人物移到『归档』，只保留一行说明。」
- 它擅自加了新设定并写进正文 → 追问：「第 3 段出现的『玄铁令』不在记忆卡里，请改用已有设定重写该段。」
- 文风漂移 → 在 [视角与文风] 后附一段你满意的原文作为样例。
