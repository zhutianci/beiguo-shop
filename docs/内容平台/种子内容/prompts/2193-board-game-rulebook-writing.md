  请你作为桌游规则书的编辑，把我的规则笔记整理成一份新玩家可以独立读懂的规则书。你的任务是整理和澄清，不是修改规则：发现漏洞、矛盾或没有说明的情况时，列出来问我，不要自己补一条规则进去。

  玩家人数、适合年龄、单局时长：[人数年龄时长]
  组件清单：[组件清单]

  [规则笔记]
  目标读者：[目标读者]（例如：第一次玩桌游的家庭 / 熟悉桌游的玩家）

  第一步：通读后先给我两份清单
  1. 术语表：笔记里指同一个东西却用了不同叫法的词（如「回合 / 轮 / 一圈」「弃掉 / 丢弃 / 移除」），请为每组选定一个，并给出定义。之后全文只用选定的词。
  2. 疑问清单：规则没有覆盖的情况、前后矛盾之处、可以有两种理解的句子。常见的漏洞请逐项检查：牌库抽完怎么办、平局怎么判、同时触发的效果谁先结算、手牌上限、无法执行某个动作时怎么办、不同人数时的调整。
  等我回答后再进入第二步。

  第二步：按下面的结构撰写规则书
  1. 游戏概述：两三句话说明背景、玩家扮演谁、怎样算赢。让读者先知道目标，再学规则。
  2. 组件：逐项列出名称与数量；每类卡牌或版图配一段「怎么看这张牌」的说明，并用【图：……】标出需要配图的位置和图里应展示的内容。
  3. 游戏准备：按步骤编号，写到可以照着摆的程度；配【图：准备完成后的桌面示意】。
  4. 游戏流程：先用一小段话概括一局游戏的大致过程，再分节写回合结构。每个阶段写清：谁来做、可以做什么、必须做什么、做完之后发生什么。
  5. 各类行动与卡牌效果的详细规则。
  6. 游戏结束与计分；附一个完整的计分算例。
  7. 示例回合：用具体的玩家名和具体的牌，叙述一到两个完整回合，覆盖最容易出错的规则。
  8. 常见问题：基于疑问清单与我的回答，写成问答。
  9. 速查表：一页以内，包含回合流程、各行动的费用与效果、结束条件，供游戏时摆在桌上。
  10. 不同人数的规则调整与可选的变体规则（如有）。

  写作要求：
  - 使用第二人称与祈使句（「抽两张牌」），一句话只说一件事；
  - 「可以」与「必须」严格区分；数字用阿拉伯数字；
  - 先讲一般规则，再讲例外，例外紧跟在它所修饰的规则后面；
  - 第一次出现的术语加粗，并且在此之前不要使用还没解释过的术语；
  - 主题性的背景描写与规则文字分开，不要让读者在故事里找规则。

**规则书难写，是因为作者太熟悉自己的游戏**。当面教学时，你会看对方的表情、随时补一句「哦对了」；写成文字后这些都没有了，读者只能看到你写下来的，而你以为「显然」的东西恰恰没写。这条提示词做三件事来弥补：统一术语（同一个东西只有一个名字），系统地找漏洞（按一份常见遗漏清单逐项检查），以及用示例回合把规则演一遍。

**为什么不让它补规则**：规则空白该怎么填是设计决定——牌库抽完是洗混弃牌堆继续，还是游戏立即结束，会带来完全不同的玩法。所以提示词要求它只提问、不代你决定。

**怎么填变量**：[规则笔记] 直接贴原始笔记、聊天记录或你口述转成的文字都可以，乱一点没关系。[组件清单] 尽量写出确切数量。[目标读者] 会影响详细程度：面向第一次玩桌游的家庭，「洗牌」「弃牌堆」「顺时针」都需要解释。

**盲测是检验规则书的唯一可靠办法**。请没玩过的朋友只看规则书开一局，你坐在旁边不许说话，只记下他们在哪里卡住、哪里理解错了、翻回去找了什么。忍住解释的冲动——你每开口一次，就少发现一处规则书的问题。

**常见问题与调整**：
- 规则书太长 → 追问：「把详细规则移到后半部分作参考，前面做一个两页的快速上手，让人边玩边学。」
- 示例回合不够清楚 → 追问：「把示例回合改写成分步的表格：谁、做了什么、牌和资源的变化、依据哪条规则。」
- 要做英文版 → 先定稿中文版，再让它翻译，并要求术语表中英对照、全文一致。

**疑问清单**
1. 食材牌库抽完时怎么办？笔记未提及。（常见做法有两种：洗混弃牌堆继续，或触发游戏结束。请你决定。）
2. 笔记第 3 条写「每回合抽 2 张」，第 9 条写「回合结束补到 4 张」，两者是否同时生效？
3. 两名玩家金额相同时如何判定胜负？
4. 「把队首的客人换到队尾」是否占用本回合的行动？
5. 3 人游戏与 4 人游戏，翻开的客人牌数量是否相同？
