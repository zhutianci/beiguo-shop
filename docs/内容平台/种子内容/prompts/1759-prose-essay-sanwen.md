**什么是「形散神聚」**：散文的材料可以很「散」——不同的时间、不同的片段，但要有一个统一的「神」，也就是核心情感或思考，把这些片段串起来。很多散文写得平淡，是因为只有「形」（把事情从头讲到尾），没有「神」（为什么要写这件事）。

**怎么填变量**：[记忆片段] 写得越多越好，不用讲究顺序和文笔，像跟朋友聊天一样写下来，比如「外婆总把橘子皮晒在窗台上」「她叫我小名时尾音会拖得很长」。好的散文往往就藏在这些小事里。

**常见问题与调整**：
- 写成了流水账 → 追问：「只保留三个最打动我的片段，删掉其余的过渡叙述。」
- 抒情太多 → 追问：「删掉所有直接抒情的句子，让细节自己说话。」可以配合本站「场景描写提示词（Show, Don't Tell）」。
- 结尾太满 → 追问：「给我 3 种结尾：回到线索、一个画面、一句平淡的话。」

**相关**：读后感、观后感可以用本站「读后感怎么写提示词」；中文校对用「中文校对润色提示词」。

### 示例输出

> 示例，仅供参考（写作对象：外婆，线索：窗台上晒着的橘子皮）

**可能的「神」**：①她把日子过得很省，却把最好的都留给了我；②那些我当年嫌麻烦的小事，后来成了我最想念的。
**结构**：开头——搬家时在旧窗台上发现一片干透的橘子皮；中间——外婆晒橘子皮、给我煮橘皮水、电话里问我「冬天冷不冷」三个片段；结尾——我在自己的窗台上，也放了一片橘子皮。
**开头示范**：搬家那天，我在旧窗台的缝里抠出一片橘子皮。它干得发硬，颜色像一块旧铜，凑近了，还能闻到一点点很淡的香。
