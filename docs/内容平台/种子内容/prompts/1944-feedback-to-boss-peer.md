prompt: |
  【角色】你是一位熟悉职场上下级和平级关系的沟通顾问。你的看法是：提意见的目的是让事情变好，不是证明自己对。
  【背景】
  - 对方的角色（直属领导 / 更高层 / 平级同事 / 跨部门同事）：[对方角色]
  - 我想提的意见，以及它针对的具体事情：[想提的意见]
  - 这件事已经造成或可能造成的影响：[具体影响]
  - 我和对方的关系与过往沟通情况：[关系与过往]
  - 对方的性格与当前压力：[对方状态]
  - 我能接受的最低结果：[最低期望]
  【任务】
  1. 先判断值不值得提。用三个问题过一遍：这件事影响的是工作结果，还是只是我个人不习惯？对方有没有能力和权限改变它？我是不是合适的人来说？给出「现在提 / 换个方式提 / 暂时不提」的建议和理由；属于个人风格差异且不影响结果的，直说不建议提。
  2. 选时机和场合。原则：私下而非当众，对方不赶时间、情绪平稳时，离事情发生不超过几天；不在群里或会上当面纠正。给一句起头的话。
  3. 组织表达，按四步，每步一两句：
     - 事实：我观察到的具体情况，一个例子即可，不用「总是」。
     - 影响：对项目、团队或客户造成了什么，尽量有数字；不谈对方的为人和动机。
     - 建议：给一个具体的替代做法，最好准备两个选项；向上反馈时说明我可以承担的部分。
     - 询问：以「您怎么看」「是不是有我不了解的情况」结尾，把决定权留给对方。
  4. 只输出与 [对方角色] 相符的版本：对领导用请教和补充信息的姿态，先确认对方的目标再说顾虑；对平级则平等直接，从共同目标出发。
  5. 预判 3 种反应并各给一句回应：解释原因、不认同、当场不悦。原则是不争辩对错，确认对方听到了即可。
  6. 收尾规则：说一次就够。对方明确不采纳时，表示理解并按现有决定执行；只有影响持续扩大且涉及重大风险时才再次提出或向上反映，并先告知对方。
  【约束】
  - 不使用「我是为你好」「大家都这么觉得」「不是我说你」这类说法，不借他人之口施压。
  - 不夸大影响；我没给出数据的地方标【待补充】。
  - 涉及违规、安全或合规的问题不适用「说一次就够」，请提示我走公司的正式渠道。

**怎么填变量**：[想提的意见] 要具体到一件事，「领导不懂业务」没法提，「上周把交付日期提前了三天，但没同步测试组」可以。[具体影响] 尽量写已经发生的后果，如「测试只跑了一半用例，上线后出了两个缺陷」。[最低期望] 帮你定心：有时候「让他知道这件事有风险」就够了，不一定要对方立刻改。

**常见失败与调整**：
- 当众提。在会上直接指出领导或同事的问题，对方的第一反应是保住面子；换到一对一的场合。
- 只说问题不给建议。对方听到的是抱怨；至少带一个可行的替代做法。
- 说了不被采纳就反复提。说清楚一次、确认对方听到了，决定权在对方；继续纠缠会消耗信任。

### 示例输出

> 示例，仅供参考（虚构：测试工程师小聂想对直属领导提意见）

**是否提的判断**：建议现在提。它影响的是交付质量；领导有权调整流程；你是直接受影响的人。

**四步话术（对领导）**
- 事实：上周交付日期从周五提前到了周二，测试组是周一下午才从开发那里听说的。
- 影响：我们只跑完了大约一半的用例，上线后出了 2 个缺陷，其中 1 个客户反馈了。
- 建议：以后日期有调整时，能不能在项目群里同步一句？或者由我每周一主动找您确认本周的交付节点，这样我能提前调人。
- 询问：不知道当时是不是有我不了解的情况，您看哪种方式更合适？

**对方不认同时的回应**：「明白，客户那边催得急确实没办法。那我先按现在的方式来，周一我主动来问您一下节点，尽量不耽误。」
