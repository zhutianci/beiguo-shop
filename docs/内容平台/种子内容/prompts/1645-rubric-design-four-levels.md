prompt: |
  请帮我为一项学习任务设计评分量规（rubric）。

  任务说明：[任务说明]（学生要完成什么、成果形式、篇幅或时长）
  学科与年级：[学科与年级]
  这项任务想评价的核心能力：[核心能力]
  评价用途：[评价用途]（如：教师评分 / 学生自评互评 / 过程反馈）
  满分或等级制要求：[分值要求]

  设计要求：
  1. 维度：3–5 个评价维度，各维度之间不重叠，并说明每个维度的权重及理由。维度要指向任务的核心能力，而不是格式细节（格式可作为一个低权重维度）。
  2. 等级：4 个等级（如：优秀 / 良好 / 合格 / 待改进），每个单元格写可观察的具体表现，而不是「很好」「较好」「一般」这类程度词的递减。相邻等级的描述要能清楚区分。
  3. 分值：每个维度各等级对应的分数区间，总分符合要求。
  4. 锚点示例：为最重要的一个维度，写出「优秀」和「合格」两个等级的简短示例（可以是一段文字或一个表现描述），帮助统一评分尺度。
  5. 学生版：把量规改写成学生能看懂的「我能……」自评清单（每个维度 2–3 条），任务开始前发给学生。
  6. 使用说明：怎样用量规给出反馈（指出达到的等级 + 一条提升建议），以及多位教师共同评分时如何先试评几份作品统一尺度。

  输出为 Markdown 表格 + 学生自评清单 + 使用说明。

**怎么填变量**：[任务说明] 写得越完整，量规越贴合。比如「九年级，写一篇 600 字议论文，论题为是否应该在校园使用手机」，比「写作文」好得多。[核心能力] 帮助 AI 确定权重：议论文重在「论点与论证」，就不应让「书写工整」占太多分。

**常见问题与调整**：
- 描述写成「好—较好—一般—差」→ 追问：「每个单元格改写成具体可观察的行为，例如『论据与论点直接相关，且至少有一个论据有具体事例或数据』。」
- 维度太多评分费时 → 追问：「合并为 3 个维度，用于课堂快速反馈。」
- 学生看不懂 → 学生版用「我能……」句式，并在任务开始前发放，比事后打分更能提升作品质量。

**适合**：作文、项目式学习成果、口头报告、实验报告、手工制作、小组合作表现等。项目式学习的整体方案可参考本站「项目式学习（PBL）方案提示词」。

### 示例输出

> 示例，仅供参考（九年级议论文，维度「论证」，权重 40%）

| 等级 | 表现描述 | 分值 |
|---|---|---|
| 优秀 | 至少两个论据，事例具体，并能说明论据如何支持论点；考虑并回应了一种反对意见 | 36–40 |
| 良好 | 有两个论据且与论点相关，但对论据如何支持论点的分析较简单 | 28–35 |
| 合格 | 有论据，但部分论据与论点关系不紧密，或只有空泛的道理 | 20–27 |
| 待改进 | 缺少论据，或以复述观点代替论证 | 0–19 |

**学生版**：我能用至少两个具体事例支持我的观点；我能说清楚每个事例为什么能证明我的观点。
