prompt: |
  请帮我设计一个有说服力的反派。我希望读者即使不认同他，也能理解他。

  - 作品类型与故事简介：[故事简介]
  - 主角：[主角设定]（性格、目标、最大的弱点）
  - 反派的初步想法：[反派想法]（身份、和主角的关系、大概做了什么坏事）
  - 反派类型偏好：[反派类型]（如：理念冲突型 / 野心家 / 被扭曲的受害者 / 冷酷的体制代表 / 亲近的人背叛）

  请完成：
  1. 反派的逻辑：
     - 他最想要什么（目标）；
     - 他为什么认为自己是对的（他的信念，用他自己的口吻写一段 100 字的「自白」）；
     - 是什么经历让他成为现在的样子（不一定要悲惨身世，避免过度洗白）。
  2. 镜像关系：反派与主角在哪些地方相似（经历、能力、愿望），在哪个关键选择上走向了相反的方向；这种对照让主角的成长更有意义。
  3. 能力与边界：反派的优势（资源、智力、权力、信息），以及他的弱点和不会做的事（反派也有底线或执念）。
  4. 威胁升级：按故事阶段设计反派的 4–5 个关键行动，每一次都比上一次更逼近主角的核心，让主角付出代价。
  5. 登场方式：反派第一次出场（或第一次显露真面目）的场景设计，要让读者立刻感受到压迫感。
  6. 结局意义：最终对决不只是力量的比拼，还要解决什么问题；给出 2 种反派结局（被击败、被理解、被改变、自我毁灭等）及各自的主题含义。
  7. 避坑：列出反派常见的 3 个问题（降智、动机牵强、只是为了衬托主角）以及本设定如何避免。

  人物原创，不使用已出版作品中的反派形象；涉及暴力和犯罪的内容点到为止，不写细节过程。

**怎么填变量**：[主角设定] 必须写，好的反派往往是主角的「另一种可能」。[反派类型] 决定了冲突的性质：理念冲突型反派让读者思考，野心家让读者紧张，亲近的人背叛让读者心痛。

**常见问题与调整**：
- 反派像为了坏而坏 → 追问：「如果从反派的视角写一章，他会怎样描述主角？」
- 反派太强主角赢不了 → 追问：「给反派设计一个只有主角才能利用的弱点，并在前文埋下伏笔。」
- 反派太弱没有威胁 → 追问：「让反派在第二幕赢下一次重要的胜利，主角为此失去重要的东西。」

**相关**：主角与反派之间的对话可以用本站「小说对话怎么写」提示词打磨潜台词。

### 示例输出

> 示例，仅供参考（反派：主角的师兄，理念冲突型）

**反派的自白**：「师父说，医者不能挑选病人。可我亲眼看着那个恶人被救活，第二年就害死了一整村的人。从那天起我明白了——救谁不救谁，总得有人来决定。我只是愿意做那个人。」

**镜像关系**：两人都想「救更多的人」；主角选择相信每一个生命，师兄选择替别人判断谁值得活。
