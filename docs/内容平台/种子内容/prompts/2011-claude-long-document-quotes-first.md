  回答方式：
  1. 先在 <quotes> 标签里摘录文档中与问题直接相关的原文。每条引用前标上编号，并注明所在的章节、条款或页码（文档里能看到的话）。引用要原样摘录，不要改写或拼接。
  2. 再在 <answer> 标签里逐个回答问题。每个结论后面用括号标出它依据的是哪几条引用，例如（引用 2、5）。

  5. 最后在 <gaps> 标签里列出：为了 [阅读目的]，这份文档本应说明但没有说明的事项。

**这样排版的依据**：Anthropic 官方提示词最佳实践的「长上下文」部分给了三条建议——长文档放在提示词靠前的位置、问题和指令放在后面（官方称在其测试中，把问题放在末尾最多可让回答质量提升约三成，多文档的复杂输入尤其明显）；用 XML 标签把文档内容和元信息包起来；先让 Claude 摘录相关引用，再基于引用完成任务，这有助于它聚焦相关内容、忽略其余部分。（资料核对于 2026-10-10）

**怎么填变量**：[我的问题清单] 一次问 3–6 个具体问题，比如「提前解约要付多少违约金」「自动续约的条件是什么」；问题越具体，摘出的引用越准。[阅读目的] 会影响 `<gaps>` 的内容，例如「决定是否签字」和「写一页摘要给领导」关注的缺口不一样。

**直接上传文件时**：在 Claude 里上传 PDF 也可以用这条提示词，把开头的 `<document>` 整块删掉，改成一句「请阅读我上传的文件」，其余不变。

**常见问题与调整**：
- 引用太多太长 → 追问：「每个问题只保留最关键的 1–2 条引用。」
- 想核对引用是否真实 → 在原文里搜索引用中的一小段文字；对不上的引用连同它支撑的结论都不要采信。
- 涉及合同、法律文件 → 这是帮你定位条款和整理问题，不是法律意见，重要事项请咨询专业人士。

### 示例输出

> 示例，仅供参考（文档：房屋租赁合同；问题：提前退租怎么处理）

```
<quotes>
[1] 第七条第 2 款：「乙方提前解除合同的，应提前三十日书面通知甲方，并支付相当于一个月租金的违约金。」
[2] 第九条：「押金在乙方结清费用并交还房屋后七个工作日内无息退还。」
</quotes>
<answer>
提前退租需要提前 30 天书面通知，并支付一个月租金作为违约金（引用 1）。押金在结清费用、交还房屋后 7 个工作日内退还（引用 2）。
违约金是否可以从押金中抵扣：文档中未提及。
</answer>
<gaps>
未说明「书面通知」是否包括微信或邮件；未约定房屋交还时的验收标准。
</gaps>
```
