prompt: |
  【角色】你是一名业务数据分析师，写数据解读的原则是「先说结论，数字只是证据」，并且分清楚哪些是数据事实、哪些是推测。
  【背景】
  - 报表名称与周期：[报表名称与周期]
  - 业务背景（本期有什么活动、变化、外部因素）：[业务背景]
  - 数据表（可直接粘贴，包含本期、上期、目标或同期）：
  [粘贴数据表]
  - 读者：[读者]
  - 重点关注的指标：[关注指标]
  【任务】
  1. 计算：本期与上期的环比、与去年同期的同比（如有）、与目标的达成率；列出计算结果表，注明公式。
  2. 找重点：从所有指标中挑出 3–5 个最值得关注的变化，判断标准是「变化幅度大、偏离目标、或与其他指标走势矛盾」。
  3. 三层解读：每个重点变化写——
     - 发生了什么（数据事实）；
     - 为什么（可能原因，结合业务背景；没有证据的标「推测，需验证」）；
     - 所以呢（对业务的影响，以及建议的动作）。
  4. 异常提示：数据中看起来不合理、可能是统计口径或数据错误的地方，列出来请我核实。
  5. 写一段 100 字以内的总述，放在报表最前面。
  【约束】
  - 只使用我提供的数据，计算请核对；不编造原因，推测必须标注。
  - 不逐项复述所有指标，只写重点；用短句。
  【输出格式】总述 → 计算结果表 → 重点变化解读（发生了什么 / 为什么 / 所以呢）→ 待核实的异常 → 建议动作清单。

**怎么填变量**：[粘贴数据表] 直接从 Excel 复制即可，最好包含上期和目标两列，AI 才能判断好坏。[业务背景] 很重要，比如「本周有一场直播大促」「竞品降价」，有了背景，原因分析才不是瞎猜。

**常见坑**：数据解读写成「本周 GMV 为 120 万，环比上升 5%；订单数为 3000，环比上升 3%……」，读者看完仍然不知道该关注什么。另一个风险是 AI 给出看似合理但没有依据的原因，所以提示词要求推测必须标注，你需要用数据去验证。

**迭代追问**：追问「针对第 2 个变化，我应该拆哪些维度来验证原因」（深入排查可以用数据异动分析提示词）；做成 PPT 时说「每个重点变化写成一页的结论式标题，并推荐图表类型」。

### 示例输出

> 示例，仅供参考（电商店铺周报）

**总述**：本周销售额环比增长 12%，主要来自直播带动；但退款率升至 8.5%，高于目标 3 个百分点，需要重点关注。

**重点变化 1：退款率上升**
- 发生了什么：退款率 8.5%，上周 5.2%，目标 ≤ 5.5%。
- 为什么：本周直播订单占比从 20% 升至 45%，直播订单的冲动消费退款通常更高（推测，需验证：拆分直播与非直播订单的退款率）。
- 所以呢：如果直播退款率显著偏高，建议直播间增加尺码讲解，并在发货前短信确认。
