**怎么填变量**：[工作内容与文件类型] 写得越具体越好，比如「市场部：活动方案、设计稿、合同、投放数据、供应商报价」。[现状] 可以直接把现有一级、二级目录名列出来，AI 会指出问题并给出迁移对应关系。

**常见坑**：目录分得太细，五六层才能找到文件，最后大家又把文件扔在桌面上。三四层以内配合好的命名规则，再加上搜索功能，就足够了。另一个常见问题是规范定好后没人执行——在迁移时就按新规则整理一遍，并指定一个人每月检查一次。

**迭代追问**：追问「把命名规则写成一个 Excel 公式，输入日期、项目、内容、版本自动生成文件名」；需要批量重命名历史文件时，可以配合 Python 办公自动化提示词（先预览再执行）。

### 示例输出

> 示例，仅供参考（市场部，12 人，企业网盘）

```
市场部/
├── 01_活动项目/
│   └── 2026_双11大促/
│       ├── 方案/  设计/  合同/  复盘/
├── 02_品牌素材/   （Logo、字体授权、品牌规范，只读）
├── 03_投放数据/   （按年份分）
├── 04_模板库/     （方案、报价、周报模板，只读）
└── 99_归档/
```
