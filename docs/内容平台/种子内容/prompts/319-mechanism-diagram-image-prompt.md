prompt: |
  【角色】你是一名科学插画师兼 AI 绘图提示词工程师，懂 [学科领域] 的基本知识，擅长把复杂机制画成清晰的示意图。

  【背景】
  - 机制或流程描述：
    [机制描述]
  - 图的用途：[论文配图/汇报/海报/基金申请书]
  - 风格偏好：[如扁平矢量、白底、低饱和]
  - 计划使用的绘图工具：[生图工具或手绘软件]

  【任务】
  1. 把描述拆成结构化清单：元素（细胞、分子、器官、步骤等）→ 关系（激活、抑制、转运、转化）→ 位置（胞外、胞膜、胞质、胞核等）。
  2. 设计布局：主流向（从左到右或从上到下）、区域划分、元素大小层级、箭头类型（激活用普通箭头、抑制用平头线）。
  3. 写一段中文和一段英文的生图描述：写清主体、构图、配色、风格、背景，要求画面不出现文字和标签（标签之后在 PPT 或 Illustrator 中添加，避免 AI 生成错字）。
  4. 另给一份手工绘制方案：按图层列出要画的元素和推荐图标来源类型，便于在 BioRender、Figdraw、PPT 等工具中拼出。
  5. 列出科学准确性检查点：哪些关系必须与原文献一致。

  【约束】
  - 只使用我提供的机制信息，不添加我没提到的通路或分子；不确定之处标注「需核对」。
  - 生图描述中不得出现真实期刊或公司的商标。

  【输出格式】
  元素关系清单（表格）→ 布局方案 → 中文生图描述 → 英文生图描述 → 手工绘制图层清单 → 准确性检查点。

**怎么填变量**：[机制描述] 用你自己论文或综述里的原话最可靠，越具体越好，例如「LPS 结合 TLR4，经 MyD88 激活 NF-κB，NF-κB 入核促进 IL-6 转录」。

**追问技巧**：生图结果不理想时，把问题描述回去（「箭头方向乱了」「细胞器比例不对」），让它改写描述；复杂机制建议分成 2–3 张小图分别生成，再手工拼合。

**适合模型**：通用大模型均可；生图环节交给 gpt-image-2、即梦等图像模型。

> 部分期刊（如 Nature 系列）对论文中使用生成式 AI 图像有限制，投稿前请查阅目标期刊政策；AI 图更适合汇报、海报和草图构思。
