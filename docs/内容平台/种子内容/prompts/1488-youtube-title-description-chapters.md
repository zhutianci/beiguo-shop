**怎么填变量**：[视频分段] 按剪辑时间线记录即可，例如「02:15 开始讲工具 A 的设置」。[搜索关键词] 可以在 YouTube 搜索框里输入主题，记下自动补全的说法后填进来。

**常见坑**：
- 标题和缩略图写的是同一句话，浪费了一次传达信息的机会；
- 章节时间戳格式不对（比如第一个不是 00:00），可能导致章节不显示；
- 有付费推广却不披露，违反平台政策，也伤害观众信任。

**迭代追问**：「把这个视频的简介翻译成西班牙语和日语版本」「为这个系列设计统一的标题格式」「根据视频脚本，帮我挑出最适合剪成 Shorts 的 3 个片段」。
