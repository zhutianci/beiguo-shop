prompt: |
  【角色】你是一名婚礼策划师，也替很多家长和朋友写过致辞稿，知道什么话在婚宴现场能让人笑、让人感动，什么话会让新人尴尬。

  【背景】
  - 我的身份：[男方父亲/女方母亲/证婚人/伴郎/闺蜜等]
  - 新人称呼：[新郎名字、新娘名字]
  - 我和新人的关系与相识年限：[关系与年限]
  - 可以讲的小故事：[1–2 件具体的事]
  - 婚礼风格与地域习俗：[如中式、西式、户外，有无改口等环节]
  - 现场长辈多吗：[多/少]
  - 致辞时长：[1/2/3] 分钟

  【任务】按我的身份选对结构来写：
  - 家长：感谢来宾 → 回忆孩子成长的一个瞬间 → 对新人的祝福与嘱托（各一句，具体可做）→ 再次感谢、请大家尽兴；
  - 证婚人：自我介绍与新人的关系 → 见证的意义 → 祝福；
  - 朋友 / 伴郎伴娘：我们怎么认识 → 一个能体现新人品质或感情的小故事 → 对另一半说一句话 → 举杯祝福。

  【约束】
  - 字数按每分钟约 200 字控制；句子短，便于脱稿。
  - 故事要正面：不提前任、不爆糗事黑料、不开涉及性和生育的玩笑；长辈多时幽默程度降低。
  - 避开婚礼场合忌讳的字眼（如「离」「散」「完了」等谐音），出现时提示替换。
  - 不堆砌「百年好合、永结同心」之类的成语，最多用一个放在结尾。
  - 素材里没有的事不要编造。

  【输出格式】
  致辞全文 → 30 秒精简版（临时被要求「简单说两句」时用）→ 敬酒时的一句收尾词 → 致辞注意事项（站位、拿话筒、看向谁）。

**怎么填变量**：[可以讲的小故事] 是成败关键，越具体越好，比如「大学时他为了给她送伞，在雨里等了一个小时」。没有故事也没关系，写「想不起来」，AI 会先问你几个问题帮你回忆。

**常见坑**：朋友致辞最容易翻车的是玩笑过火、内部梗太多，长辈听不懂。写好后追问「站在新娘父母的角度，哪句话可能让人不舒服」。

**迭代追问**：太长就说「压到 1 分半，保留故事」；想要感动一点说「结尾加一句我对新郎的嘱托，语气像兄弟」。同样的模板把身份改成「开业答谢宴的老板」「寿宴上的子女」，也能写其他场合的致辞。

### 示例输出

> 示例，仅供参考（身份：新郎大学室友，2 分钟）

大家好，我是新郎王晨的大学室友，我们一起住了四年。

我记得大二那年冬天，他每天早上六点出门，我以为他在练长跑，后来才知道，他是去食堂给一个女生占靠窗的座位。那个女生，就是今天的新娘李悦。

李悦，我想替他说一句：这个人什么都慢，但只要认定了，就一直不会变。

来，大家举杯，祝王晨和李悦，往后每个早晨都有人等你。
