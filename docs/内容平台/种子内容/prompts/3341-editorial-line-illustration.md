**怎么填变量**：原文是一段纯风格描述，场景由你来定。[一位盘发女子倚在窗边……] 换成你想要的画面，比如"一个男人坐在地铁车厢里看书""女孩蹲在阳台给植物浇水""空荡的厨房和一只猫"；[一把黑色椅子和一瓶插枝] 是室内道具，换成"一盏落地灯和一摞书""木桌和一杯咖啡"。示例图是一张竖版插画：盘发女子穿白衬衫和橄榄绿短裙，背对画面倚在窗台上，窗外是一片墨绿色的枝叶剪影，右侧粉色台面上放着一只插着细枝的玻璃瓶，左下角一把黑色椅子，墙面有旧纸的颗粒感。

**常见问题与调整**：
- 颜色太多太艳：再强调"只用奶白、灰米、橄榄绿和黑四种颜色"。
- 阴影出现渐变：加"阴影是边缘锐利的纯黑块面，像剪纸"。
- 人物比例太写实：加"人物腿部和身形明显拉长，五官极简"。
- 想做书封：画幅改 2:3，并加"画面上方留出三分之一空白放书名"。

**适合**：读书 / 文学类公众号配图、独立刊物插画、书封草图、文艺类海报；不适合需要热闹、高饱和氛围的促销物料。
