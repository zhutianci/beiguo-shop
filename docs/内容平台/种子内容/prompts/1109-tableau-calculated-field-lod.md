**怎么填变量**：[数据粒度] 是 LOD 计算的基础，一定要先说清一行数据代表什么。[筛选器] 很重要：FIXED 表达式默认不受普通维度筛选器影响，很多「结果不对」都是因为没注意到这一点。

**常见坑**：
- 用 FIXED 计算占比，加了产品类别筛选器后，分母仍然包含所有类别，因为维度筛选器在 FIXED 之后才执行。需要时把筛选器添加到上下文。
- 能用表计算完成的累计、排名，硬写成复杂的 LOD，难以维护。
- LOD 的结果在视图中还会被再聚合一次（例如求和），对「每个客户的首单日期」这类结果要用最小值或属性，而不是求和。

**追问技巧**：追问「用客户首单年份做同期群分析，画出每年新客在之后各年的留存销售额」，这是 LOD 的经典应用。

### 示例输出

> 示例，仅供参考（需求：按首次购买年份把客户分为新客和老客）

```
// 客户首单日期：在客户粒度上计算，不受视图维度影响
{ FIXED [客户 ID] : MIN([订单日期]) }

// 新老客户标记：订单年份等于首单年份即为新客
IF YEAR([订单日期]) = YEAR([客户首单日期]) THEN "新客" ELSE "老客" END

// 地区销售额占全国比例：分母排除地区维度
SUM([销售额]) / SUM({ EXCLUDE [地区] : SUM([销售额]) })
```

**筛选器提示**：如果视图中有「产品类别」筛选器，并且希望「首单日期」只考虑所选类别的订单，需要把该筛选器「添加到上下文」，否则首单日期是基于全部类别计算的。
