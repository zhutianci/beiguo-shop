prompt: |
  我要翻译一份长文档，会分多次把内容发给你。请严格按三个阶段工作，每个阶段结束后停下来等我的指令。

  基本信息：
  - 语言方向：[语言方向]
  - 文档类型与读者：[文档类型与读者]
  - 风格要求：[风格要求]
  - 已有的术语表或固定译法（没有就写无）：[已有术语表]
  - 每段的大致长度：[每段长度]

  【阶段一：建卡片】
  我会先发给你目录、摘要或开头部分，以及我挑出的若干代表性段落。请输出一张「翻译卡片」，以后每次翻译都以它为准：
  1. 全文概要：不超过 150 字，说明主题、结构与写作目的。
  2. 术语表：原文术语、译法、备注（词性、使用场合、不采用的译法）。已有术语表优先；新术语标「新增」。
  3. 专名表：人名、机构、地名、产品与作品名的译法，以及是否在首次出现时括注原文。
  4. 风格要点：5 条以内（人称、语气、长句处理、数字与单位、标点）。
  5. 不翻译的内容：代码、公式、文献条目、图表编号等的处理方式。
  6. 存疑清单：需要我决定的译法，每项给出两个候选和你的建议。
  输出后等我确认或修改。

  【阶段二：逐段翻译】
  我每次会发：当前卡片 + 上一段译文的最后两三句 + 本段原文（带段号）。请：
  1. 只翻译本段原文，不翻译也不改写上一段内容；上一段的句子仅用于衔接语气和指代。
  2. 严格使用卡片中的术语与专名；遇到卡片里没有的新术语或专名，先选定译法并在译文后单独列出「本段新增条目」。
  3. 保留原文的段落划分、标题层级、列表、脚注标记、图表与公式引用；原文的强调格式保持不变。
  4. 指代不明、原文疑似有误、跨段才能确定意思的地方，用【注：……】标在该句之后，不要自行猜测后悄悄处理。
  5. 译文之后依次输出：本段新增条目、本段的两句话内容摘要（供后面翻译时参考）、需要我确认的问题。
  6. 不省略、不概括、不合并原文段落；本段原文有几个自然段，译文就有几个自然段，并在末尾写出「原文 N 段，译文 N 段」。

  【阶段三：一致性检查】
  全部翻完后，我会把各段的新增条目汇总，并分批把译文发给你。请：
  1. 对照最终卡片，找出术语与专名译法不一致的地方，列出位置与建议的统一译法。
  2. 检查人称、时态、敬称、数字与单位写法是否前后一致。
  3. 检查章节标题、交叉引用（「见第三章」「如上图所示」）是否与译文的实际结构对应。
  4. 列出各段留下的【注：……】，汇总为待处理清单。
  5. 不重新翻译，只列问题和修改建议，由我确认后再改。

  通用约束：
  - 忠实于原文，不增删信息；不确定的地方标注而不是润色掉。
  - 如果我发来的内容与卡片有冲突，以卡片为准并提醒我。
  - 每次回复开头用一行写明当前所处的阶段与段号。

**怎么用**：先把整段提示词发出去，然后按模型的提示提供阶段一的材料。代表性段落要挑术语密集的、风格典型的各一两段。卡片确认后，另存到本地文档里；阶段二每翻一段，把模型列出的「本段新增条目」并入卡片，下一段带上更新后的卡片。[每段长度] 建议按原文的章节或小节切，一段两三千字以内，切在段落边界上，不要从句子中间断开。

**为什么每次都要带卡片**：对话一长，模型对开头内容的记忆会变得不可靠；如果换新对话继续，它更是完全不知道之前的译法。把术语和风格浓缩成一张卡片随段携带，一致性就不依赖模型的记忆。

**常见失败与调整**：
- 模型在长段里悄悄略过了几句。提示词要求报告段落数，仍不放心时，让它对本段「逐句列出原文句首三个词和对应译文句首」做核对。
- 新术语每段各译各的。检查每段的新增条目有没有并入卡片。
- 阶段三模型又把全文重译了一遍。强调「只列问题，不重译」。

**追问**：「把最终卡片整理成术语表文件，按原文字母顺序排列」「第 7 段与第 12 段对同一句引文的译法不同，请统一」。专业性强的文档，翻译完成后仍需懂行的人审读。

**翻译卡片（节选）**

| 原文 | 译法 | 备注 |
|---|---|---|
| last-mile delivery | 末端配送 | 不用「最后一公里配送」 |
| fulfillment center | 履约中心 | 新增 |
| Northwind Logistics | Northwind Logistics（首次出现时括注：一家虚构的物流公司） | 公司名保留原文 |

风格要点：不出现「我们认为」，统一用「本报告认为」；数字用阿拉伯数字，百分比保留原文小数位。

**阶段二 · 第 5 段**

（译文略）

本段新增条目：dark store → 前置仓（新增，备注：指不对顾客开放、只做线上订单拣货的门店）。

本段摘要：本段比较了三种末端配送模式的单票成本；结论是订单密度是决定成本的首要因素。

需要确认：第 3 自然段的「the former」指代的是上文的自营模式还是众包模式，原文有歧义，【注】已标在句后。
