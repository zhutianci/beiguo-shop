**怎么填变量**：[白色沙漠] 可以换成"冰原裂谷""黑色火山岩海岸""盐湖"；[生物发光菌类与干枯藤蔓] 换成"发光珊瑚与海藻""水晶簇与苔藓""羽毛与光纤"；[酸性绿] 换成"冰蓝""熔岩橙"，记得同时改配色那一行。示例图是竖幅低机位：模特仰头站在白色岩石旁，礼服像层层叠叠的白色菌褶和垂落的藤丝，内部透出黄绿色荧光，左边是深蓝夜空里的一轮满月，远处是沙漠和尖石。

**常见问题与调整**：
- 光太亮像霓虹灯：加"发光只来自礼服内部的脉络，亮度柔和，整体仍是夜景"。
- 礼服看起来像怪物服：强调"仍是可穿着的高定礼服廓形，有清晰的肩线和腰线"。
- 背景杂乱：加"背景只有沙地、几块岩石和月亮，大面积留白"。
- 想要做系列：追问"保持同样配色和材质语言，换成背面全身和面料特写各一张"。

**适合**：先锋服装设计概念、艺术展 / 音乐节主视觉、奇幻题材海报；不适合当作可量产服装的款式参考。
