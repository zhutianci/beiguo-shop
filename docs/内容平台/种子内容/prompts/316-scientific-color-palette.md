**怎么填变量**：[图表内容] 写清「几组、哪组是重点」，例如「对照、低剂量、高剂量三组，重点突出高剂量」；[已有约束] 写下组里或导师的固定习惯，AI 会在其基础上调整。

**追问技巧**：选定方案后追问「把这套颜色做成 matplotlib 的 .mplstyle 或 ggplot2 的 scale 函数」，以后每张图直接调用；热图可以追问「发散色图的中点应该设在 0 还是均值」。

**适合模型**：通用大模型均可。

> 「Nature 风格」仅指视觉风格参考，请以目标期刊的作者指南为准。
