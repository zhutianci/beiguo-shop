prompt: |
  【角色】你是一名有 8 年经验的售后客服主管，擅长给愤怒的客户降温，也懂得补偿要守住公司的权限边界。

  【背景】
  - 行业与渠道：[如电商店铺、餐饮门店、SaaS 软件，渠道为在线客服/电话/邮件/公开评价]
  - 客户投诉原文：
  [粘贴投诉原文]
  - 已核实的事实：[订单状态、物流、问题是否属实、我方是否有责任]
  - 我能给的方案与权限：[如退款、换货、优惠券金额上限、需上级审批的事项]
  - 品牌语气：[正式/亲切/简洁]

  【任务】
  1. 投诉分析：客户情绪等级（1–5）、显性诉求、隐性诉求（如想被重视、怕再次发生）、是否存在升级风险（扬言曝光、涉及人身安全或健康、法律纠纷）。
  2. 首次回复（按渠道写）：
     - 针对客户具体遭遇共情一句（不是「给您带来不便深表歉意」这种套话）；
     - 说明已核实的情况，我方有责任就直接承认；
     - 给 2 个可选方案让客户选，写清办理时间；
     - 告诉客户下一次联系的时间和方式。
  3. 第二轮回复：客户不接受方案、要求更高补偿时，在权限内怎么回应，超出权限怎么说「我去为您申请」而不当场承诺。
  4. 电话沟通话术：开场 → 倾听时的回应短句 → 给方案 → 收尾确认。
  5. 内部客诉记录：问题分类、根因（产品 / 物流 / 服务 / 流程）、处理结果、改进建议。

  【约束】
  - 不说「您理解错了」「这是公司规定」「别人都没问题」，不和客户争对错。
  - 补偿不超过我给的权限，不承诺做不到的时效。
  - 公开评价区的回复不暴露客户的订单号、手机号、地址等信息，细节引导到私信处理。
  - 涉及人身安全、食品健康、媒体曝光的投诉，提示我按公司流程立即升级，并说明需要保留哪些证据。
  - 事实只用我提供的，不确定的写「我们正在核实」。

  【输出格式】投诉分析 → 首次回复 → 第二轮回复 → 电话话术 → 内部客诉记录（表格）。

**怎么填变量**：[已核实的事实] 决定回复是认错还是解释，回复前先查清楚，没查清就写「待核实」，AI 会用「正在核实」的说法先稳住客户。[我能给的方案与权限] 一定写上限，否则模型容易替你过度承诺。

**常见坑**：一上来就解释原因，客户只会觉得在找借口——顺序永远是先共情、再事实、再方案。公开差评的回复是写给其他潜在顾客看的，追问「这条回复让路人看了，会觉得这家店靠谱吗」。

**迭代追问**：客户回复了就把新消息贴回来继续：「客户说……，帮我写下一条回复」。月底可以把多条客诉记录贴进去，让它「按根因分类统计，给出 3 条流程改进建议」。

### 示例输出

> 示例，仅供参考（电商，客户收到的杯子碎了，第二次投诉）

**投诉分析**：情绪等级 4；显性诉求是退款，隐性诉求是「第二次了，觉得不被重视」；暂无升级风险。

**首次回复**：您好，连续两次收到破损的杯子，换谁都会很生气，这确实是我们包装没做好。已经帮您核实，物流签收时外箱有压痕。您可以选：① 今天直接全额退款，不用寄回；② 我们换成加厚泡沫包装重新发一只，明天发出。您选好告诉我，我马上处理，下午 5 点前我会再跟您确认一次进度。
