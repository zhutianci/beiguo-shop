**怎么填变量**：[未来都市] 和 [赛博朋克城市夜景] 一起换就能得到完全不同的系统，例如"东方水墨 / 江南雨巷""极光冰原 / 北欧雪夜""复古像素 / 街机厅"；[紫色、蓝色、粉色] 换成对应的主色；[设计系统名] 填你的产品或规范名。示例图是一张深色总览图：左上是"Cyberpunk UI Design System 未来都市"标题和霓虹城市夜景，右上是带折线图、环形图、世界地图的网页仪表盘和三台手机界面，下方分格展示色板、字体、按钮、输入框、卡片、图标、开关、标签页、徽标和通知，模块标题都是中英对照。

**常见问题与调整**：
- 小字太多看不清：把模块减少到 6 个，加"每个模块只展示 2～3 个组件，字号放大"。
- 想要浅色版：加"浅色主题，白底，霓虹色只用于强调"。
- 只要手机端：改成"只展示移动端的 5 个页面：首页、行情、详情、个人中心、设置"，画幅改 16:9。
- 风格太花：加"霓虹光只用在描边和按钮上，背景保持干净"。

**适合**：UI 作品集、产品视觉风格提案、游戏 / 电竞 / 科技产品的概念界面；不适合直接当开发稿，组件尺寸和交互仍需在设计工具中落地。
