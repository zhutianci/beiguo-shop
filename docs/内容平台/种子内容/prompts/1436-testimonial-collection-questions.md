prompt: |
  你是一名用户研究员兼文案，负责帮品牌收集真实的客户证言。你知道好的证言有三个特征：具体（有场景和数字）、可信（有人、有身份）、真实（来自客户本人的话）。

  产品 / 服务：[产品服务]
  要采访的客户类型：[客户类型]
  证言将用在哪里：[使用位置]
  采访方式：[问卷 / 电话 / 视频 / 当面]
  （拿到回答后再填）客户的原始回答：[客户原话]

  第一阶段：采访问题
  1. 设计 8–10 个开放式问题，按「使用前 → 选择过程 → 使用中 → 结果 → 推荐」排序。避免引导性问题（不问「您是不是觉得我们很好用」，而问「您第一次用的时候是什么情况」）。
  2. 每个问题附 1 个追问，用来挖出具体细节（时间、数字、场景）。
  3. 写一段采访邀请消息：说明用途、时长、会如何使用、对方可以拒绝或要求匿名。

  第二阶段：整理证言（我提供原始回答后）
  4. 从原话中提取最有说服力的片段，整理成三个版本：一句话版（30 字内）、短版（80 字内）、故事版（200 字内）。
  5. 整理原则：只做删减、调整语序和修正口误，不添加客户没说过的意思和数据；在每个版本后标注它来自原话的哪几句。
  6. 写一段给客户的确认消息：附上整理后的文字，请对方确认内容、署名方式（全名 / 姓氏 + 职位 / 匿名）和使用范围。

  原则：严禁编造或「润色出」客户没说过的好评；不对证言提供金钱或折扣作为交换（如提供感谢礼，要与评价内容好坏无关并按规定披露）；未获授权不得公开客户姓名、照片和公司名。

**怎么填变量**：第一次使用时 [客户原话] 先留空，只生成采访问题；采访完把录音转写稿或问卷回答粘进去，再生成证言。[使用位置] 会影响长度选择，详情页适合一句话版，案例页适合故事版。

**常见坑**：
- 采访问题带引导（「您觉得我们的服务是不是很贴心？」），拿到的回答空洞且不可信；
- 「润色」过度，把客户一句「挺好用的」改成「彻底改变了我的工作方式」，这就是编造；
- 没有授权就用了客户的全名和公司 logo，一旦对方不同意，会很被动。

**迭代追问**：「把这 10 个问题改成适合 5 分钟电话访谈的版本」「客户说的话里有一些负面反馈，帮我整理成产品改进建议」「为视频采访设计拍摄提纲和开场引导语」。

### 示例输出

> 示例，仅供参考（虚构：家政保洁服务的客户证言）

**采访问题（节选）**
- 第一次预约之前，您家里的清洁通常是怎么安排的？（追问：大概每周花多少时间？）
