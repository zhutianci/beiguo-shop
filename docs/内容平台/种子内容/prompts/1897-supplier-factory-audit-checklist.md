  【角色】你是有多年现场审核经验的供应商质量工程师（SQE），帮我准备一次供应商现场审核。
  【背景】
  - 供应商与供货品类：[供应商与品类]
  - 审核目的（新供应商准入 / 年度复审 / 质量问题后专项审核）：[审核目的]
  - 我方最关注的要求：[我方关键要求]
  - 审核时长与人数：[审核时长与人数]
  - 已经拿到的资料：[已有资料]
  【任务】
  1. 审核日程：首次会议、文件审查、现场巡查、记录抽查、末次会议；现场时间不少于总时长的一半。
  2. 巡查路线：按物料流动的顺序走——收货区、来料检验、原料仓、生产线、过程检验、成品检验、成品仓、出货区，再看不合格品区和计量室。
  3. 审核清单，分六个模块，每模块 6–10 条：
     - 资质与基本情况；
     - 产能与设备（实际产能、瓶颈工序、设备保养记录）；
     - 质量体系（来料、过程、出货三道检验，不合格品控制，计量器具校准，变更管理，客户投诉处理）；
     - 现场管理（标识、区域划分、先进先出、作业指导书是否在工位并与实际操作一致）；
     - 计划与交付（订单评审、物料齐套、紧急订单处理）；
     - 我方关键要求的专项检查。
     每条写四栏：检查内容、取证方式（看记录 / 看现场 / 问操作员，关键条目至少两种）、抽样要求、判定（符合 / 轻微不符合 / 严重不符合）。
  4. 追溯性测试：现场随机抽一个成品批号，要求供应商在限定时间内查出所用原料批次、生产日期与班次、检验记录、出货去向。写清记录方法和判定标准。
  5. 一票否决项：根据审核目的和我方要求列 3–5 条。
  6. 审核报告模板：总体结论（通过 / 有条件通过 / 不通过）、亮点、不符合项清单（描述、证据、等级、整改期限）、整改跟踪方式。
  【约束】
  - 检查条目要贴合我给的品类和工艺；工艺细节不清楚的标【现场确认】，不编造工艺参数。
  - 不符合项只写事实和证据，不写推测。
  - 提到管理体系标准时只写名称，不引用条款编号。
  【输出格式】审核日程 → 巡查路线 → 分模块审核清单 → 追溯性测试方法 → 一票否决项 → 报告模板。

**怎么填变量**：[供应商与品类] 写清工艺类型，如「注塑件，含喷涂」，清单才会贴合。[审核目的] 三种目的侧重不同：准入看能力和体系，复审看保持情况，专项审核只盯出问题的那条线。[我方关键要求] 例如「外观无色差」「每批提供材质证明」。

**常见失败与调整**：
- 大半天坐在会议室看文件。文件都很漂亮，真实情况在现场；先去车间走一圈，再回来对着记录核实。
- 只问管理人员、只看对方备好的记录。随机问一位操作员「这个尺寸超差了你怎么办」，自己指定日期和批号抽记录。
- 报告写「质量意识有待提高」。不符合项要写成事实：在哪里、看到什么、与哪条要求不符。

### 示例输出

> 示例，仅供参考（虚构：对一家注塑件供应商的新供应商准入审核，1 天，2 名审核员）

**审核清单：质量体系（节选）**

| 检查内容 | 取证方式 | 抽样要求 | 判定 |
|---|---|---|---|
| 来料是否按检验规范检验并留有记录 | 看记录 + 看现场 | 抽近 1 个月内 3 批原料的检验记录，核对待检区实物状态标识 | 符合 / 轻微 / 严重 |
| 不合格品是否隔离并有处置记录 | 看现场 + 看记录 | 查看不合格品区，任选 2 件追问来源和处置结论 | 符合 / 轻微 / 严重 |
| 量具是否在校准有效期内 | 看现场 | 生产线和检验室各抽 3 件量具，核对校准标签 | 符合 / 轻微 / 严重 |

**追溯性测试**：在成品仓随机抽 1 箱，记下批号，要求 30 分钟内提供该批的原料批号、注塑机台与班次、首件和巡检记录、已出货客户。30 分钟内全部查到为符合；能查到但超时为轻微不符合；任一环节查不到为严重不符合。

**不符合项写法示例**：在 3 号注塑机旁的检验台上，发现 1 把卡尺的校准标签已过期 2 个月，现场仍在用于首件检验。等级：轻微不符合。整改期限：7 天。
