**怎么用**：把两处 [巴黎] 换成同一个城市，便签内容写成你想要的日期和天气。示例图是巴黎版：埃菲尔铁塔、凯旋门、圣母院、圣心堂、卢浮宫金字塔、红磨坊、蓬皮杜中心、先贤祠排成两排，顶上是"PARIS"纪念贴和"Tues, Dec 2. 9°C Rainy, Overcast"的便签，最下面一排是雨伞、雨靴、雨衣、围巾、咖啡和雨云。

**几种玩法**：
- 天气播报：每天换城市和天气，做成系列内容，例如"[杭州] / [3月15日 18°C 晴]"，最下排就会变成墨镜、遮阳帽、冰饮。
- 文创定制提案：把"地标"换成"自家品牌吉祥物的不同动作"或"学校 / 景区的建筑"，作为冰箱贴产品的效果预览。
- 旅行纪念：去过的城市各出一张，拼成九宫格。

**常见问题**：
- 地标做得不像：模型对热门国际地标更熟悉，小众地标可以在提示词里点名列出要哪几个。
- 中文城市名写错：改成拼音或英文，或者纪念贴只放城市剪影。

**适合**：文创产品预览、旅行 / 天气类社媒内容、城市宣传物料。若用于实际生产销售，请注意地标外观与商标相关的授权问题。
