**怎么用**：上传一张背景干净的产品照。示例第 1 张是透明化结果，第 2 张是原图（一台复古胶片相机）。不想要内部结构时，删掉第二条，改成"内部完全透明、空无一物"，就是纯玻璃雕塑效果。

**常见问题**：
- 内部零件"乱编"：模型会画出看起来合理的结构，但不一定符合真实产品，宣传用途请注明"创意示意"。
- 透明度不够：写具体数值感受，如"90% 透明，像水晶一样"。
- 背景被改：加"背景与原图完全一致"。

**延伸玩法**：把材质换成"冰块""果冻""彩色玻璃""全息镭射"，或者配合 168 号"产品爆炸图"一起做成套详情页。
