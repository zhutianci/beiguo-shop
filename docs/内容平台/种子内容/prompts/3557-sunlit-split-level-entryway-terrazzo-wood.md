**怎么填变量**：地面、台阶和楼梯三处材质决定风格——"浅灰色微水泥 + 白色水磨石 + 黑色钢板楼梯"更现代，"人字拼橡木 + 米色石材 + 胡桃木楼梯"更复古；软包颜色选一个低饱和的点缀色；主绿植可换"天堂鸟""橄榄树""龟背竹"。不是错层户型，把"抬高的平台和台阶"一句删掉即可。

示例图里，阳光从正面的黑框玻璃门照进来，在木地板和浅色的水磨石台阶上留下一片片树枝的影子；左边是一段浅色的木楼梯，门两侧摆着高大的绿植，上方挂着两盆垂下来的蕨；右边靠窗是一排木质卡座，上面放着绿色的坐垫和靠枕，小几上有茶壶和茶杯。

**常见问题**：
- 树影不明显：强调"硬朗的直射阳光、清晰的枝叶投影"，时间写"上午十点"。
- 空间畸变像鱼眼：加"建筑摄影移轴校正，垂直线保持垂直"。
- 绿植过多像温室：限定"全屋不超过 5 盆植物"。

**适合**：玄关和门厅的装修灵感、室内设计提案的氛围图、家居品牌的场景图；实际落地以户型和采光条件为准。
