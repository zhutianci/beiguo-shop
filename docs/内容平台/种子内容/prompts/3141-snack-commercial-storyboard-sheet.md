**怎么填变量**：[焦糖爆米花] 在标题和信息卡两处出现，换成你的产品（"手工巧克力""冻干水果""精酿啤酒"），然后把 8 个分镜按"产品亮相 → 原料 → 制作 / 变化过程 → 质感特写 → 最终主视觉"的结构改写；[20 秒] 按实际时长改，每格时长加起来要对得上。音频那一栏可以换成"开罐声 + 气泡声"等。

示例图是深棕底的分镜表：顶部金色大字"PREMIUM GOURMET POPCORN COMMERCIAL"和四张信息卡，下面 2×4 共 8 格：爆米花桶、玉米粒入锅、爆开、焦糖淋下、微距、飞溅、糖晶特写、主视觉，每格下方三栏小字写着运镜、动作和产品说明。

**常见问题**：
- 小字说明乱码：分镜表里的文字只作版式示意；正式提案建议把文字部分在 PPT 里重排。
- 8 格风格不统一：写"8 格同一色调、同一灯光风格"。
- 拿去生成视频：可以把每格单独裁出来，作为视频模型的首帧参考。

**适合**：广告提案、短视频拍摄脚本、食品 / 饮品品牌视觉策划、分镜教学。
