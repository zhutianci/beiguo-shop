prompt: |
  请帮我设计一个悬疑推理故事的谜题和线索布局。原则是「公平」：读者拿到的线索足以推理出真相，但需要细心才能发现。

  - 故事类型：[故事类型]（如：本格推理 / 社会派悬疑 / 校园谜案 / 不涉及凶杀的日常之谜）
  - 故事背景与舞台：[故事背景]（地点、时代、人物圈子）
  - 主要人物（侦探角色、嫌疑人等）：[主要人物]
  - 我的初步构想：[初步构想]（如：一场在封闭的山间民宿中发生的失窃案）
  - 篇幅：[篇幅]

  请按「先定真相、再布线索」的顺序：
  1. 真相：写出完整的真相——做了什么、谁做的、动机、方法、时间线。方法要符合常识和物理逻辑，不依赖读者不可能知道的专业知识或巧合。
  2. 核心诡计：说明本案的关键「诡计」或认知盲点是什么（如时间差、身份混淆、视角误导、物品的双重用途），用一句话概括。
  3. 公平线索表：列出 5–8 条指向真相的线索，表格为「线索 | 指向什么 | 出现的章节或场景 | 呈现方式（藏在什么不起眼的描写里）| 读者容易忽略的原因」。
  4. 误导设计：设计 2–3 条红鲱鱼（误导线索）和一个「看起来最可疑」的嫌疑人，说明它们怎样把读者引向错误方向，以及最终如何被合理地排除。
  5. 嫌疑人表：每个嫌疑人的动机、机会、不在场证明及其漏洞。
  6. 揭晓场景：侦探角色怎样把线索串起来，揭晓的顺序和关键推理句。
  7. 逻辑漏洞检查：从读者角度提出 3–5 个「那为什么不……」的问题，给出解释或修改建议。

  内容不描写血腥细节和犯罪的具体操作方法，案件手法点到为止，重在推理逻辑；人物与诡计原创，不借用已出版推理作品的经典诡计。

**怎么填变量**：[故事类型] 影响谜题的风格：本格推理强调诡计和逻辑，社会派更重视动机背后的社会问题，「日常之谜」不涉及凶案，适合轻松的故事。[初步构想] 可以只是一个场景或一个问题。

**为什么先定真相**：推理小说是「倒着写」的——作者先知道答案，再决定读者在什么时候、以什么方式看到哪些线索。先写案件再想解法，往往会留下逻辑漏洞。

**常见问题与调整**：
- 真相太容易猜 → 追问：「把最关键的线索藏进一个看起来只是在描写环境的句子里。」
- 线索太隐蔽显得不公平 → 追问：「检查每条关键线索是否至少被侦探角色或其他人物『看到过』一次。」
- 写作中期 → 用本站「小说设定一致性检查提示词」核对时间线和人物行踪。
