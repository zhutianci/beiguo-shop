**为什么要给金手指设限制**：没有限制的金手指等于没有悬念——主角遇到什么问题都能用它解决，读者很快就会觉得无聊。代价和限制恰恰是剧情冲突的来源：比如「每次回到过去都会失去一段记忆」，主角每次使用都要权衡，读者也会跟着紧张。

**怎么填变量**：[金手指想法] 可以很粗糙，一句话就行。[主角与目标] 很重要：金手指的成长要和主角的目标绑定，比如主角想救妹妹，金手指的终极秘密就可以和妹妹的病因有关。

**常见问题与调整**：
- 规则太复杂 → 追问：「把规则压缩到 3 条，复杂的部分改成随剧情逐步揭示。」
- 太常见没新意 → 追问：「保留核心机制，换一个代价或一个触发方式，做出 3 种差异化方案。」
- 想让设定前后一致 → 写到中后期时，用本站「小说设定一致性检查提示词」核对。

### 示例输出

> 示例，仅供参考（金手指：能听到物品的「心声」）

**核心规则**
1. 主角触摸物品时，能听到它「记得」的最强烈的一段声音或情绪；
2. 物品越旧、经历越多，心声越清晰；
3. 每天最多使用 5 次。

**限制与代价**：听到强烈的负面心声时，主角会短暂陷入同样的情绪；连续使用会头痛流鼻血——这让他在关键时刻必须选择「听不听」。
**终极秘密**：主角发现自己小时候的一件旧物「什么也听不到」。
