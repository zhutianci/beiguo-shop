  翻译原则：
  1. 先理解菜：根据我提供的食材和做法，确认每道菜的主料、配料、烹饪方法（如 stir-fried 炒、braised 红烧或焖、steamed 蒸、deep-fried 炸、roasted 烤）、口味和形态；不知道做法的菜，先问我或标【请补充做法】，不要望文生义（如「夫妻肺片」「蚂蚁上树」这类名字与食材关系不直接的菜）。
  2. 为每道菜给出三种方案：
     - A 写实型：主料 + 做法 + 配料或口味（如 Stir-fried Shredded Pork with Green Peppers）；
     - B 音译 + 说明型：保留拼音菜名，后面用括号或小字简短说明（适合有特色、名字有文化意义的菜）；
     - C 描述型：一句话短描述，适合菜单副标题。
     并推荐一种最适合我的使用场景的方案。
  3. 标注：辣度、主要过敏原（如花生、坚果、海鲜、麸质、蛋、奶）、是否含猪肉或牛肉、是否素食——只根据我提供的食材标注，我没提供的写「请核实」。
  4. 避免：字面直译造成误解或不雅的译名；过长的译名；不同菜之间相同做法的译法前后不一致。
  5. 最后输出一份统一格式的菜单表：中文名 | 推荐英文名 | 简短描述 | 标注。

**怎么填变量**：[粘贴菜名清单] 尽量附上食材和做法，比如「鱼香肉丝：猪肉丝、木耳、胡萝卜，酸甜微辣的鱼香味，不含鱼」。很多中国菜的名字是比喻或典故，没有做法说明，AI 也可能翻错。[空间限制] 对印刷菜单很重要，太长的英文名会挤掉排版。

**常见问题与调整**：
- 译名太长 → 追问：「每道菜只保留主料和做法，配料放到描述里。」
- 想要统一风格 → 追问：「全部菜名按『做法 + 主料 + with 配料』的格式统一。」
- 过敏原信息 → 这关系到食客安全，务必由餐厅根据实际配方核实，AI 只能根据你提供的信息标注。

**相关**：其他中国特色词汇的翻译可以用本站「中国特色词汇怎么翻译：文化负载词英译提示词」。
