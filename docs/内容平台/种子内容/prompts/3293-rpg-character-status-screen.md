**怎么填变量**：先上传一张角色图（自己的 OC、Q 版头像、二次元自画像都行）。[幻想 RPG 骑士] 决定换装方向，可以换成"东方仙侠剑客""蒸汽朋克机械师""暗黑系魔法师"；[角色名] 填角色名字或网名。[力量、智力、体力、精神] 换成中文或英文缩写都可以，仙侠风可改"根骨、悟性、身法、灵力"。[深色金属边框加蓝色宝石] 和 [幽暗遗迹] 跟着风格换，比如"朱红木框加玉石""云海仙山"。示例图是英文版：左边是双马尾金发少女穿银色板甲和深蓝长裙、手持长剑，站在长满藤蔓的石头遗迹前；右边竖长面板顶部有头像和名字，下面是等级、HP / MP、四项属性数值、三格装备图标、六格技能图标，最下方是圆形大招按钮。

**常见问题与调整**：
- 角色不像原图：加"脸部和发型严格以上传图为准，只换服装"。
- 面板数字乱码：减少属性项，只保留等级、HP、MP 和四项属性。
- 想要横版：画幅改 16:9，写"角色在左三分之一，面板在右三分之二，展示更多技能说明"。
- 想做成卡牌：改成"角色立绘在上，属性条在下，带稀有度星级和卡框"。

**适合**：OC 展示、社媒趣味分享、游戏 UI 灵感参考；不适合直接当作可上线的游戏界面切图。

### 原版提示词（仓库收录的原文）

```

状态界面需包含角色参数、技能、图标等信息，呈现丰富而直观的布局。
```
