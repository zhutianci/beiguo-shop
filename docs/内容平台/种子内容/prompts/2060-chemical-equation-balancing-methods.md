prompt: |
  请教我配平化学方程式。我给出反应物和生成物，你负责选方法、分步演示，并保证最终结果正确。

  未配平的方程式（或反应的文字描述）：[未配平的方程式]
  学段：[学段]（初中或高中，决定能不能用化合价升降的方法）
  我自己配的结果（可选）：[我的配平结果]

  步骤 A 核对化学式
  先检查我写的每个化学式是否正确。生成物写错或缺失时先指出并向我确认，不要自行假设这个反应会生成什么。反应条件（点燃、加热、催化剂、浓或稀）会影响产物时，请问清楚。

  步骤 B 选方法并说明理由
  - 最小公倍数法：某种元素在等号两边各只出现一次，且原子个数不同。从两边原子个数的最小公倍数较大的元素入手。
  - 奇偶法：某种元素在一边的原子总数是奇数，在另一边是偶数。先在含奇数个该原子的化学式前配 2，把奇数变成偶数，再依次配其他物质。
  - 定一法：有一种物质组成最复杂时，先把它的化学计量数定为 1，再配其余，最后去分母。
  - 得失电子守恒法（高中的氧化还原反应）：标出变价元素的化合价 → 算出每个原子升高和降低的数值 → 求最小公倍数，使升降总数相等，确定氧化剂、还原剂及其产物的计量数 → 用观察法配平其余物质，通常最后配水。只有一部分参加氧化还原的物质（如既作氧化剂、又起酸的作用的硝酸），要把两部分加起来。
  初中学段不使用得失电子守恒法。

  步骤 C 分步演示
  每一步只改动一个或一组计量数，写出这一步之后的式子，并说明为什么这样改。

  步骤 D 核对表
  列表逐个元素数出左右两边的原子个数，全部相等才算完成；离子方程式还要核对两边的电荷总数。计量数化成最简整数比，然后补上反应条件，以及气体、沉淀符号。

  步骤 E 轮到我
  出 3 个适合同一种方法的方程式让我配平，先不给答案。我答完后你用核对表检查，错了只指出哪种元素不相等，让我再试一次；第二次仍然不对，再演示。

  我给了自己的配平结果时，先用核对表检查它，再决定要不要重讲。

  要求：只配平中学阶段确实存在的反应；对产物拿不准的反应要明说，不要硬配。

**怎么填变量**：[未配平的方程式] 写成「Cu + HNO3(稀) → Cu(NO3)2 + NO + H2O」这样，反应物、生成物都写全，注明浓稀和条件；[学段] 初中只会用到前三种方法；[我的配平结果] 把你配的计量数写上，AI 会先替你数原子。

**常见问题与调整**：
- 配出来的系数是分数 → 追问：「各计量数同时乘以几可以化成最简整数比？」
- 不知道为什么选这种方法 → 追问：「这个反应如果用最小公倍数法会卡在哪一步？」
- 离子方程式不会配 → 追问：「改写成离子方程式后重新配平，并核对电荷是否守恒。」

### 示例输出

> 示例，仅供参考（高一：Cu + HNO3(稀) → Cu(NO3)2 + NO↑ + H2O，用得失电子守恒法）

**步骤 C 分步演示**
1. 标变价：Cu 由 0 价升到 +2 价，每个原子失 2 个电子；N 由 +5 价降到 +2 价（生成 NO），每个原子得 3 个电子。
2. 2 和 3 的最小公倍数是 6：Cu 配 3，NO 配 2。
   3Cu + HNO3 → 3Cu(NO3)2 + 2NO↑ + H2O
3. 数氮原子：右边 3 × 2 + 2 = 8，所以 HNO3 配 8（其中 2 个被还原，6 个起酸的作用）。
4. 数氢原子：左边 8 个，H2O 配 4。
   3Cu + 8HNO3(稀) = 3Cu(NO3)2 + 2NO↑ + 4H2O

**步骤 D 核对表**

| 元素 | 左边 | 右边 |
|---|---|---|
| Cu | 3 | 3 |
| H | 8 | 4 × 2 = 8 |
| N | 8 | 3 × 2 + 2 = 8 |
| O | 8 × 3 = 24 | 18 + 2 + 4 = 24 |

全部相等，配平完成。
