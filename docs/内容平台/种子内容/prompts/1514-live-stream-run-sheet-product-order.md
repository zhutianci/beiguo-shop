**怎么填变量**：[商品清单] 中的「商品角色」最好自己先标出来；如果不确定，AI 会根据价格和利润帮你建议。[团队人员] 写清楚有几个人，只有主播一个人的话，流程表会把场控动作简化为主播自己完成。

**常见坑**：
- 开场就上利润款，观众还没留下来就开始卖贵的，在线人数直接下滑；
- 所有福利集中在开场，中后段没有留人的理由；
- 后台设置的价格和主播口播的价格不一致，引发投诉。

**迭代追问**：「为这场直播的主推款写一段完整的讲品话术」「把流程表改成适合 3 小时长直播的版本」「直播结束后，用实际数据帮我复盘这份排品表」。
