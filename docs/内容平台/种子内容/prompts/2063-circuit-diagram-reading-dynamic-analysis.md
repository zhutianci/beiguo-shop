prompt: |
  我看不懂这张电路图，请一步步带我「读」它。每做完一步，先问我的判断，再告诉我对不对。

  电路描述或题目：[电路描述或题目]
  年级：[年级]
  题目要我分析的变化：[要分析的变化]（如：滑片向右移动；闭合开关 S2）
  我的初步判断（可选）：[我的判断]

  我的描述不足以确定连接方式时先问我，例如滑动变阻器接入电路的是哪一段。

  第一步 去表
  把电流表看成一根导线，把电压表所在的支路看成断开，告诉我去掉电表之后电路里还剩下哪些元件。

  第二步 判断串并联
  从电源正极出发追踪电流：
  - 电流只有一条路径，依次流过各个用电器，是串联；
  - 电流在某一点分成几路、之后又汇合，是并联，说出分流点、汇合点和每条支路上的元件；
  - 检查有没有被导线直接短接的用电器，有没有因为开关断开而不通的支路。

  第三步 把电表放回去
  - 电流表：它和谁串联在同一条路径上，就测通过谁的电流；在干路上则测总电流。
  - 电压表：看它的两个接线端分别连到哪两个点，这两点之间夹着谁，就测谁两端的电压；夹着的是电源时测电源电压。
  这一步最容易出错，请说出每一块表的判断依据。

  第四步 等效电路
  用一两句话把化简后的电路说清楚，例如「R1 与 R2 串联，电压表测 R2 两端的电压，电流表测电路中的电流」。

  第五步 动态分析（题目有变化时）
  按因果链一环一环写，每一环注明依据：
  变化的原因（滑片移动使接入的电阻变大或变小，或者开关通断改变了电路结构）
  → 总电阻怎样变
  → 电源电压不变，总电流怎样变（欧姆定律）
  → 阻值不变的那个电阻两端的电压怎样变（U = IR）
  → 阻值变化的那个电阻两端的电压怎样变（用总电压减去前者；不要直接用 U = IR，因为它的 I 和 R 都在变）。
  并联电路还要说明：各支路互不影响，一条支路的电阻改变，不影响另一条支路的电流。
  开关通断引起的变化，要分别说出通断前后的两个等效电路，再作比较。

  结尾把电路改动一处（如给电压表换一个位置），让我重新判断。

  初中阶段默认电源电压不变，不计电源和电表的内阻；高中涉及电源内阻时，按闭合电路欧姆定律分析并说明。

**怎么填变量**：[电路描述或题目] 没法传图时按电流的走向来描述，如「电源正极 → 开关 S → 电流表 → R1 → 滑动变阻器 R2 → 电源负极，电压表并联在 R2 两端，滑片向右移动时接入的电阻变大」；[要分析的变化] 没有就写「无」，只读图。

**常见问题与调整**：
- 电压表测谁还是看不出来 → 追问：「用『移线法』：沿着导线把电压表的两个接线端滑到某个元件的两端，一步步说给我听。」
- 图太复杂 → 追问：「先只做第一步和第二步，用节点字母 A、B、C 标出每个元件接在哪两个点之间。」
- 想练动态分析 → 追问：「同一张图，把电压表改接在 R1 两端，再分析滑片向左移动的情况。」

### 示例输出

> 示例，仅供参考（九年级：电源电压不变，定值电阻 R1 与滑动变阻器 R2 串联，电流表串联在电路中，电压表并联在 R2 两端；滑片向右移动时 R2 接入的电阻变大）

**第一步至第四步**：去掉电表后，电流只有一条路径，R1 与 R2 串联；电流表测电路中的电流；电压表两个接线端之间夹的是 R2，测 R2 两端的电压。

**第五步 动态分析**
滑片右移，R2 接入的电阻变大
→ 总电阻 R1 + R2 变大（串联电路的总电阻等于各电阻之和）
→ 电源电压不变，电流 I 变小（I = U ÷ R总），电流表示数变小
→ R1 阻值不变，它两端的电压 U1 = I × R1 变小
→ R2 两端的电压 U2 = U − U1 变大，电压表示数变大。

**轮到你**：如果把电压表改接在 R1 两端，滑片仍然右移，电压表示数怎样变？
