  用途：[复习/读书/汇报/头脑风暴]

  结构规则（必须遵守，否则导入后会乱）：
  - 第一行用 `#` 写中心主题，一级分支用 `##`，二级用 `###`，更深的层级用 `-` 无序列表并缩进两个空格；
  - 每个节点是关键词或短语，不超过 [节点字数] 个字，不写完整句子，不用句号；
  - 同一层级的节点要「相互独立、合起来完整」（MECE），按逻辑顺序（时间、流程、重要程度或因果）排列，不要随意罗列；
  - 不要使用表格、代码块、加粗、链接、图片；不要在大纲前后添加任何说明文字。

  - 用途是「汇报」时，一级分支按「结论 → 原因 → 行动」组织；
  - 用途是「头脑风暴」时，最后加一个一级分支「待验证的想法」；

**怎么用**：把输出的大纲复制保存成 `.md` 文件，在 XMind 里用「导入 → Markdown」打开；或者粘贴到 markmap 的在线页面，可直接看到导图并导出为 SVG 或 HTML。幕布、飞书、Notion 等工具对 Markdown 列表的支持程度不同，导入前可以先拿一小段测试。

**怎么填变量**：[层级数] 建议 3–4 层，超过 5 层导图会很难读。[分支数] 一般 4–7 个，符合「一眼能看完」的习惯。[节点字数] 中文 8–12 字比较合适。

**常见坑**：
- 模型有时会在开头加「好的，以下是思维导图」，导入后多出一个莫名其妙的节点——模板里已经禁止，但出现时手动删掉即可；
- 不给参考资料时，内容来自模型的通用知识，复习专业课时可能与你的教材体系不一致，最好贴上目录或课件要点；
- 节点写成长句子，导图会变成「文字墙」，要求它「再压缩成关键词」。

**迭代追问**：「把『第三章』这个分支展开到第 4 层」「把这张导图改成适合 10 分钟汇报的版本，每个一级分支对应一页 PPT」。

### 示例输出

> 示例，仅供参考（主题：光合作用，用途：复习，3 层）

```markdown
# 光合作用
## 场所与条件
### 叶绿体
- 类囊体薄膜：光反应
- 基质：暗反应
## 光反应
### 产物
- O₂ 来自水 ⚠
- ATP、NADPH
## 暗反应
### 卡尔文循环
- CO₂ 固定
- C₃ 还原
## 影响因素
### 光照强度
### CO₂ 浓度
### 温度
```
