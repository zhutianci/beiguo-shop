**好的背景故事是给团用的，不是给自己看的**。主持人通常要同时照顾四五个玩家，没有精力读三千字的身世；他真正需要的是几条能编进剧情的线头。队友需要的是一个愿意合作、有辨识度的同伴。所以这条提示词的产出分成两份：一页给你扮演用的小传，一张给主持人的钩子清单，并特意检查了两个常见问题——低等级角色写成了传奇英雄，以及角色设定成拒绝与任何人同行的独狼。

**怎么填变量**：[突出的属性与技能] 别省略最低的那项，它是角色缺点的好来源：智力低可以是不识字，也可以是读得懂书却总被骗；魅力低可以是说话太直，而不一定是长得凶。[主持人的限制] 有就照抄，如「不能是贵族出身」「开场时所有人都在同一艘船上」。[字数上限] 建议 400–600。

**常见问题与调整**：
- 写得太悲惨太沉重 → 追问：「保留动机，把身世调轻一些，加一个让他显得可爱的日常爱好。」
- 动机和战役接不上 → 把主持人给的开场情境贴进去：「请把眼前的目标改成与这个开场直接相关。」
- 想和队友的背景联动 → 追问：「这是队友角色的简介，请设计两种我们之前就认识的方式，各一句话。」
- 想要扮演时的台词 → 追问：「按这个性格，给我 8 句他在战斗、讨价还价、被感谢时会说的话。」

**提醒**：规则书和官方战役设定中的专有名称、种族与职业的官方描述文字受版权保护，这里只借用你自己和主持人的设定；规则细节以你们使用的规则书为准。

### 示例输出

> 示例，仅供参考（DND 5E，一级人类战士，力量最高、智力最低；想扮演嘴硬心软的退伍兵；港口城市战役；节选）

**一句话**：一个被遣散的边境守卫，想攒够钱把战友的遗物送回他老家，却总是把钱借给更缺钱的人。

**来历**：在北边的哨所守了六年城墙，没打过什么大仗，最常干的活是修栅栏和赶走偷羊的狼。哨所裁撤后拿了一小笔遣散费，同铺的战友病死在回程路上，托他把一枚铜哨带给住在【待主持人确认：某个渔村】的母亲。

**性格落到行为上**
- 有人求助时，他会先骂一句「关我什么事」，然后跟上去。
- 看不懂契约和告示，从不承认，总说「你念给我听，我眼睛花」。
- 紧张时会摸挂在脖子上的那枚铜哨。

**秘密**：遣散费早就花光了，他一直对别人说钱「存在可靠的地方」。

**给主持人的钩子**
1. 那枚铜哨上刻着一个他不认识的徽记。
2. 当年哨所的军需官欠他三个月的饷，据说现在在港口做起了生意。
3. 战友的母亲是否还在世，留给主持人决定。
