**怎么填变量**：[受邀对象] 写清楚关系很重要——给老客户的邀请和给陌生行业嘉宾的邀请，开头完全不同；[参会价值] 是很多邀请函缺失的部分，要回答「我为什么要花半天时间来」。[正式版字数] 一般 300～500。

**常见坑**：
- 信息不全：漏写结束时间、具体楼层、停车方式，受邀者还得来回问；让 AI 最后对照清单检查一遍；
- 回执收集一大堆用不到的信息（身份证号、家庭住址），既增加填写负担也带来隐私风险；
- 嘉宾还没确认就写进邀请函，临时变动会很被动。

**迭代追问**：「为 VIP 客户再写一版，加入专属接待安排」「把正式版翻译成英文，用于邀请海外合作伙伴」「写一封活动结束后的感谢邮件，附资料下载说明」。

### 示例输出

> 示例，仅供参考（虚构：某软件公司年度客户答谢会）

**轻松版**：王总好，我们 11 月 22 日下午在滨江会展中心办年度客户交流会，会有产品团队分享明年的路线图，还安排了几位客户聊他们的实践。想邀请您来坐坐，报名链接在这里，11 月 15 日前回复就行，到时候我在门口接您。

**回执字段（节选）**
| 字段 | 必填 | 原因 |
|---|---|---|
| 姓名、单位、职务 | 是 | 制作胸牌 |
| 手机号 | 是 | 发送入场提醒 |
| 饮食禁忌 | 否 | 安排茶歇 |
