**怎么填变量**：[联盟名称] 写你的项目或机构名，比如"长三角高校联盟""某某供应链"；图例类别换成你的实体类型，例如"总部、分公司、门店、合作方"；枢纽名称写最重要的 3～5 个主体，越短越好。示例图是深色背景上的英文网络图：顶部标题，左上角四色图例，右上角统计卡写着 Nodes 36 / Edges 92 / Density 0.146，五个带图标的大圆形枢纽围着中央的总节点，底部一排带头像图标的顾问人名。示例图是英文版，中文版标签越多越容易出错字。

**常见问题与调整**：
- 标签重叠挤成一团：把节点数降到 20 左右，加"小节点只画点不写名字"。
- 看起来像随机散点：要求"按类型分区，同类节点聚成一簇，枢纽之间用粗线连接"。
- 汇报 PPT 是浅色主题：把背景改成"米白色"，节点颜色改为"深蓝、橙、灰"。
- 想突出某一个主体：加"[某节点]放在正中央，尺寸最大，周围有光晕"。

**适合**：汇报封面、科普文章配图、概念示意；不适合当作真实数据分析结果，图里的数字和连线不代表任何实际统计。
