**怎么填变量**：[二十多岁的短卷发女生] 换成你想要的模特形象，如"黑色长直发的亚洲女生""银发的中年男士"；[钴蓝、玫红、亮橙、青绿、紫色] 是建筑的配色，可以收窄成两三种颜色做更克制的撞色；服装一栏写清"上装 + 下装"的颜色和款式，颜色最好从环境配色里挑两种，画面才有呼应。

示例图是一位棕色卷发的女生站在蓝、粉、橙、青拼色的建筑转角前，右侧是映着彩色倒影的玻璃幕墙；她穿钴蓝色粗花呢短外套、橙色衬衫和橙色阔腿裤，斜挎紫色小包，脚上是蓝粉撞色运动鞋，镜头从低处仰拍。

**常见问题**：
- 人物被拍得很小：把"占画面高度的 70%～80%"那一句放到提示词最前面再强调一次。
- 颜色太多显得乱：把建筑配色减到 3 种，服装只用其中 2 种。
- 脸部变形：去掉"仰拍"的夸张程度，写成"略低于视平线"。

**适合**：穿搭账号封面、服装品牌社媒图、配色练习参考；不适合需要还原具体真实服装款式的场景。
