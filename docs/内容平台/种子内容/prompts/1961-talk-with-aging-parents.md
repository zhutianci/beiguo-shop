**怎么填变量**：[父母的做法与原话] 写他们的原话最有用，比如「人家小张比你还关心我」「我身体好着呢，查什么查」，里面藏着真正的原因。[父母信任的人] 认真想一想：老同事、社区医生、某位亲戚，有时同样一句话换个人说就听得进去。[以往劝说经过] 把自己说过的话也写上，包括气头上的那句「那都是骗子」。

**常见失败与调整**：
- 一上来就否定。「那是骗人的」等于说「你被骗了、你糊涂」，父母为了面子只会更坚持；先问、先听。
- 只拦不替。不让买保健品，却没人陪他们说话；销售员填补的是陪伴，这个需要得有别的东西接上。
- 想一次谈成。这类事通常要提好几次，每次往前一小步就行。

### 示例输出

> 示例，仅供参考（虚构：小严想劝独居的母亲别再从上门推销的店里买保健品，并和她约定防诈骗规则）

**可能的原因**
- 可能是店员每天打电话问候，她觉得被惦记。了解方式：「妈，那家店的小姑娘平时都跟你聊些啥？」

**新的说法**
- 先肯定：「你一直挺注意保养的，这点比我强。」
- 换成「我」：「就是你同时还吃着降压药，我不懂这些能不能一起吃，心里没底。」
- 小提议：「下周三我休息，陪你去社区医院复查，顺便把这几瓶带上让医生看一眼，行不行？要不要继续吃，听完你自己定。」

**电话旁的提示卡**
1. 要转账的，先挂电话。
2. 验证码谁也不给。
3. 让下载软件、共享屏幕的，挂断。
4. 说是警察、法院、客服的，挂断后自己查号码打回去。
5. 说是孩子换了号码的，先问暗号。
6. 拿不准，先给小严打电话。被骗不丢人，早说早拦。
