**怎么填变量**：[粘贴摘要] 用最终版摘要，关键词要和摘要内容一致。[关键词要求] 去期刊的作者指南（Guide for Authors）里找，有的期刊要求关键词不能与标题重复，有的要求用 MeSH 词，有的限制总字符数。

**常见问题与调整**：
- 给的英文关键词不地道 → 追问：「对比这 3 个英文写法在本领域文献中的常见程度，并告诉我怎样在数据库里自己验证。」最可靠的方法是到 Web of Science、Scopus 或 PubMed 里分别检索，看哪种写法结果更多、更贴合。
- MeSH 词看起来很像但对不上 → MeSH 有正式主题词（Heading）和入口词（Entry Term）之分，AI 可能把入口词当成主题词，到官方 MeSH Browser 里查一下就清楚。
- 关键词太多 → 追问：「只保留 4 个，删掉检索作用重叠的词。」

**适合**：期刊投稿、毕业论文、会议摘要。中文期刊的关键词规范以期刊稿约为准。

### 示例输出

> 示例，仅供参考（题目：社区老年人的步行速度与跌倒风险：一项前瞻性队列研究）

| 候选词 | 类型 | 在题目中 | 英文 | MeSH 建议 |
|---|---|---|---|---|
| 步行速度 | 变量 | 是 | gait speed / walking speed | Walking Speed（请到 MeSH 官方词表核实） |
| 意外跌倒 | 结局 | 是（作「跌倒」） | accidental falls | Accidental Falls（请核实） |
| 衰弱 | 相关概念 | 否 | frailty | Frailty（请核实） |

**推荐关键词**：步行速度；意外跌倒；衰弱；老年人；队列研究
