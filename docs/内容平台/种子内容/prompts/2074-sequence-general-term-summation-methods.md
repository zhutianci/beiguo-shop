**怎么填变量**：[数列题目] 下标用下划线写清楚，如「a_1 = 1，a_(n+1) = 2a_n + 1」，避免 AI 把 a_(n+1) 看成 a_n + 1；[我的判断与做法] 写上「我觉得用累加」之类的判断；[已学范围] 如「学过等差、等比和错位相减，没学过数学归纳法」。

**常见问题与调整**：
- 构造法里加的那个数怎么来的 → 追问：「设 a_(n+1) + k = p(a_n + k)，展开后和原式比较，把 k 求给我看。」
- 错位相减总算错 → 追问：「把相减那一步上下对齐写出来，标出哪些项是等比部分、共几项。」
- 只想练识别 → 追问：「出 10 个递推式或通项，我只回答方法名称。」

### 示例输出

> 示例，仅供参考（高二：已知 a_1 = 1，a_(n+1) = 2a_n + 1，求通项；学生判断「用累加法」）

**识别**：累加法要求相邻两项的差只与 n 有关。这里 a_(n+1) − a_n = a_n + 1，右边还含有 a_n，所以不是累加。再看一眼：它是 a_(n+1) = p·a_n + q 的形式，其中 p = 2，q = 1，对应构造法。

**第一步（请你先写）**：两边同时加上 q ÷ (p − 1) = 1 ÷ (2 − 1) = 1。

**接着讲**
a_(n+1) + 1 = 2a_n + 2 = 2(a_n + 1)。
所以数列 {a_n + 1} 是等比数列，首项 a_1 + 1 = 2，公比为 2。
a_n + 1 = 2 × 2^(n−1) = 2^n，于是 a_n = 2^n − 1。

**验证**：由递推关系得 a_2 = 2 × 1 + 1 = 3，a_3 = 2 × 3 + 1 = 7；由通项得 2² − 1 = 3，2³ − 1 = 7，一致。

**易错处**：新数列的首项是 a_1 + 1 = 2，不是 a_1 = 1。
