**怎么填变量**：[真实细节] 是好诗的起点。比起「思念家乡」，「外婆家灶台上那只缺了口的搪瓷杯」更能写出动人的诗。[风格描述] 用描述来说你喜欢的感觉，不需要写诗人名字。

**常见问题与调整**：
- 诗太直白 → 追问：「把第 2 节里所有直接说出情绪的词删掉，只留下画面。」
- 分行没有感觉 → 追问：「同一段文字给出两种分行方式，说明它们的节奏和意思有什么不同。」
- 结尾太满 → 追问：「给我 3 种不同的结尾，分别用画面、问句和转折收尾。」

**相关**：古典诗词创作可以用本站「古诗词创作提示词」；想写成歌词可以用「歌词创作提示词」。

### 示例输出

> 示例，仅供参考（主题：离家多年后回到老房子）

**意象清单（节选）**：门框上的身高刻痕（时间、成长）；落满灰的搪瓷杯（被遗忘的日常）；窗台上已经干掉的蒜苗（停止的生活）

**开头示范（原创）**
门框上的刻痕
停在我十二岁那年
后来的我
都长在了别处
