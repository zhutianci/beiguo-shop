**怎么填变量**：[你的原始想法] 怎么想就怎么写，比如「这个函数太长了看不下去，而且没处理空数组」，AI 会拆成两条分量不同的评论。贴上相关代码，评论才能具体到行。

**常见坑**：
- 评审意见不标分量，作者分不清哪条必须改、哪条只是个人偏好，结果要么全改、要么全不改。所以模板要求每条先标「必须 / 建议 / nit / 提问」。
- 一条评论里塞好几个问题，作者回复时很难逐条对应，最好一条只讲一件事。
- 作为作者，不同意时只说「我觉得没必要」很难说服人，带上依据（例如「这个列表最多 20 条，复杂度不是瓶颈」）。

**追问技巧**：评论太多时，追问「只保留会阻断合并的意见，其他合并成一条总结」；团队有新人时，追问「改写成带一点讲解的版本，帮助对方理解背后的原则」。
