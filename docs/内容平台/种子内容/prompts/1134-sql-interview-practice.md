**怎么填变量**：[我的水平] 写得越准，题目难度越合适。[使用的数据库方言] 很重要，日期函数、字符串函数在 MySQL 和 Hive 中写法不同，面试时通常会说明使用哪一种。

**常见坑**：
- 直接看答案「刷题」，看懂了却写不出来。这条提示词要求先作答再批改，练习效果好得多。
- 只关注结果对不对，忽略面试官更看重的思路表达。作答时可以先用一两句话说明思路，让 AI 一起点评。
- 连续登录、留存这类题目，边界情况（同一天多次登录、跨月、断一天）最容易出错，批改时特别留意。

**追问技巧**：练完一轮后追问「把我这轮写错的题目整理成错题本，附正确写法和易错点」，或「同一道题如果数据量是十亿行，面试官会怎么追问性能优化」。窗口函数的系统讲解可配合 1040 号提示词。

### 示例输出

> 示例，仅供参考（第一题）

**业务背景**：某 App 记录了用户每次登录的时间，产品想知道每个用户最长连续登录了多少天。

```sql
CREATE TABLE user_login (user_id INT, login_time DATETIME);
INSERT INTO user_login VALUES
(1, '2026-09-01 09:00:00'), (1, '2026-09-01 21:00:00'), (1, '2026-09-02 10:00:00'),
(1, '2026-09-03 08:00:00'), (1, '2026-09-05 12:00:00'),
(2, '2026-09-01 11:00:00'), (2, '2026-09-03 15:00:00');
```

**要求**：输出每个用户的最长连续登录天数。注意同一天多次登录只算一天。

**期望输出**：

| user_id | max_consecutive_days |
|---|---|
| 1 | 3 |
| 2 | 1 |

请写出你的 SQL。
