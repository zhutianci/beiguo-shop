**怎么填变量**：[示例数据] 最关键，复制几行真实格式的数据（敏感信息替换掉），AI 才能看出日期是不是文本、编号有没有前导空格等问题。[需求描述] 用「按……统计……」的句式最清楚。

**追问技巧**：公式报错时，把报错单元格的值和公式一起贴回去；需求变化时追问「再加一个条件：只统计华东区」。

**适合模型**：通用大模型均可。

> 公式结果请抽查几行手工核对后再使用。

### 示例输出

> 示例，仅供参考（需求：按产品编号从「产品表」查单价，找不到显示「未找到」）

```
=XLOOKUP(A2, 产品表!A:A, 产品表!C:C, "未找到")
```

旧版本写法：

```
=IFERROR(INDEX(产品表!C:C, MATCH(A2, 产品表!A:A, 0)), "未找到")
```

**解释**：在产品表的 A 列找 A2 的编号，返回同一行 C 列的单价；找不到时显示「未找到」。
