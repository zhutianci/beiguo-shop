**怎么填变量**：[运行环境] 和 [改动目的] 能大幅减少误报；贴 diff 时最好附上被调用函数的签名。一次贴 300 行以内效果最好，太长就按文件分批。

**追问技巧**：对某条问题有疑问，追问「给出能复现这个问题的输入或测试用例」；修完后把新代码贴回去，说「只检查上次指出的问题是否修复」。

**适合模型**：通用大模型均可；Claude、GPT 的推理模式在并发和安全问题上更细致。

> 不要把密钥、内网地址或公司保密代码贴给外部模型，先遵守所在团队的数据安全规定；AI 审查不能替代人工审查和测试。
