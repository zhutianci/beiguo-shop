  - 图表是否按规定的方式编号，正文是否先提到再出现，题注位置是否符合我贴的要求；
  - 参考文献条目的要素是否齐全、标点是否统一，正文引用与文后列表是否一一对应；
  - 中英文摘要的内容是否对应，关键词的个数与分隔符；
  - 全角与半角、数字与单位之间的空格、中英文标点混用。

**怎么填变量**：[学校格式要求] 从研究生院或教务处发布的撰写规范里复制原文，太长就分几次贴，每次说明「这是第几部分」。[论文片段与设置] 建议一次贴一类内容，比如第三章的全部标题、全部图表题注，或者参考文献列表加上正文里对应的引用句，核对更集中。[排版工具] 写 Word、WPS 或 LaTeX，AI 会给对应的批量检查办法。

**常见问题与调整**：
- 清单里出现了规范原文没有的数值 → 追问：「逐条标出每个规定值在我贴的原文中的位置，找不到出处的改为『规定未说明』。」
- 只想查参考文献 → 追问：「只做任务二的第三项：列出正文引用了但文后没有的，以及文后有但正文没引用的。」

**提醒**：AI 看不到你的页面，页眉、页码、分页、图的清晰度这些只能自己翻着看；学院提供官方模板的，以模板和学院最新通知为准。排版操作本身可配合本站 1243 号「Word 排版提示词」。
