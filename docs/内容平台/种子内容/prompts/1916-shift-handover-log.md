prompt: |
  请帮我做两件事：先为我的岗位设计一份交接班记录模板；再把我口述的本班情况整理成一份填好的记录。

  岗位与班次安排：[岗位与班次安排]
  生产线、设备或负责的区域：[产线或设备]
  交接时必须确认的事项：[交接必查项]
  本班发生的情况（口述或流水记录）：[本班情况]
  以往交接出过的问题：[以往交接问题]

  一、模板设计。按接班人最需要先知道的顺序排，分六栏：
  1. 安全事项（放在最前）：正在进行的检修、已挂牌上锁或断电的设备、临时拆除或停用的防护装置、现场的临时危险、本班发生的险情。没有也要写「无」，不能留空。
  2. 生产：计划与实际产量、正在做的订单或批次及进度、下一步要做什么、物料够用到什么时候。
  3. 设备：各设备的运行状态；异常写「现象 + 已采取的处理 + 目前情况」；关键参数填实际数值，不写「正常」。
  4. 质量：本班的不良情况、已隔离的产品及存放位置、调整过的工艺参数（从多少调到多少、为什么调）。
  5. 未完成事项：每条写清四点——做到哪一步、下一步做什么、要注意什么、有问题找谁。
  6. 上级指示与其他：临时通知、借出的工具等。
  末尾：交班人与接班人签名、交接时间；接班人确认栏写「已到现场核对以下事项」并列出必查项。

  二、整理记录。把我口述的情况逐条归入上面六栏：
  - 我说得含糊的地方（如「机器有点问题」「差不多做完了」），不要替我补全，在该处标【需交班人补充：具体要问什么】；
  - 口述里没有涉及的栏目，写「未提及，请交班人确认是否为无」；
  - 数字、设备编号、时间按我说的原样记录，不改写、不估算；
  - 把接班后一小时内必须先做的事，在记录最上方单独列出，不超过 3 条。

  三、交接规则：在现场交接，不在休息室；接班人对安全事项和未完成事项逐条复述一遍；记录上没写的，视为没有交接；接班人有疑问可以暂不签字，先找班组长。

  四、针对我提到的以往交接问题，说明模板里哪一栏、哪条规则是用来防止它的。

  约束：模板控制在一页纸内；不用只能勾「正常 / 异常」的选项代替具体描述。

  输出：空白模板 → 接班后优先事项 → 填好的本班记录 → 交接规则。

**怎么填变量**：[本班情况] 想到什么写什么，或者把语音转成文字直接贴进来，不用自己分类。[交接必查项] 写接班人必须亲眼看一遍的东西，如「烘箱温度、冷库门、原料余量」。[以往交接问题] 例如「夜班调了参数没说，白班做出一批不良品」。

**常见失败与调整**：
- 记录上全是「正常」「无异常」。出了问题无从追查；参数要填数字，异常要写现象和已做的处理。
- 口头说了，记录上没写。事后一方说讲过、一方说没听到；约定「没写的就是没交接」，双方都会认真写。
- 未完成事项只写「继续做某订单」，而且是在休息室里交接的。写清四点，并到现场去交，挂着牌的设备才会被看到。

### 示例输出

> 示例，仅供参考（虚构：某食品厂烘焙线，白班交夜班；交班人口述：「2 号烤炉下午有点问题，调了一下，现在可以了。订单差不多做完了，还剩一点。1 号搅拌机在修，没修好。」）

**接班后优先事项**
1. 到 1 号搅拌机确认挂牌上锁状态，修好前不得送电；
2. 查看 2 号烤炉的当前温度并持续观察。

**交接班记录**

| 栏目 | 内容 |
|---|---|
| 安全事项 | 1 号搅拌机检修中，未修复。【需交班人补充：是否已断电并挂牌上锁？钥匙在谁手里？维修人员是否还在现场？】 |
| 生产 | 当前订单「差不多做完」。【需交班人补充：订单号、计划数量、已完成数量、剩余数量】 |
| 设备 | 2 号烤炉下午出现异常，经调整后恢复。【需交班人补充：具体现象？调整了什么参数、从多少调到多少？目前温度读数？】 |
| 质量 | 未提及，请交班人确认是否为无。【建议确认：2 号烤炉异常期间的产品是否已隔离检查】 |
| 未完成事项 | 1 号搅拌机维修。【需交班人补充：修到哪一步、下一步做什么、找哪位维修人员】 |
| 上级指示与其他 | 未提及，请交班人确认是否为无。 |
