  ### 你的任务
  为我的网站整理并撰写一份常见问题（FAQ）页。你是一位内容设计师，坚持一个原则：FAQ 是回答用户的问题，不是换个形式继续打广告。

  ### 我提供的资料
  - 网站 / 产品：[网站与产品]
  - 用户类型：[用户类型]
  - 原始问题来源（客服聊天记录、销售常被问到的问题、评论区提问，直接粘贴）：[原始问题]
  - 必须准确说明的政策（价格规则、退款、隐私、发货、售后）：[政策信息]
  - 网站上已有的相关页面：[已有页面]

  ### 请这样做
  1. 归并：把原始问题里意思相同的合并，保留用户最常用的说法作为问题标题；列出合并关系。
  2. 补漏：按购买旅程（了解 → 比较 → 购买 → 使用 → 售后）检查缺了哪些用户必然会问的问题，补充进来，并标「补充」。
  3. 排序：每个分类内按提问频率或重要性排序，最多 [每类数量] 条。
  4. 写答案：每条答案第一句直接回答（是 / 否 / 具体数字或步骤），再补充细节；超过 3 步的写成编号步骤；涉及政策的原样引用我给的内容，不自行解释或扩大。
  5. 内链：每条答案标注建议链接到的已有页面；没有合适页面的，建议是否需要新建。
  6. 页面结构：分类导航、搜索框建议、「没找到答案？」的联系入口文案。
  7. 列出答案中我需要核实的事实。

  ### 注意
  不编造政策和数字；不确定的写「【待确认】」；问题标题用用户的语言，不用内部术语。

**怎么填变量**：[原始问题] 是这条提示词的核心，客服后台导出最近一两个月的高频问题最好，哪怕格式乱也没关系，AI 会负责归并。[政策信息] 请贴正式条款原文，FAQ 只是用更好懂的话讲出来，不能和条款不一致。[每类数量] 一般 5～8 条。

**常见坑**：
- 问题写成「我们的产品有哪些优势？」这种用户根本不会问的问题，FAQ 就变成了广告页；
- 答案绕了三句话还没回答「能不能退」，用户会直接去找客服；要求第一句直接回答；
- FAQ 和服务条款说法不一致，发生纠纷时很被动。

**迭代追问**：「把这份 FAQ 改写成客服可以直接复制的快捷回复」「挑出 5 个最适合做成短视频讲解的问题」「把 FAQ 整理成适合添加 FAQ 结构化数据的问答格式」。

### 示例输出

> 示例，仅供参考（虚构：在线定制相册网站）

**分类：购买与付款**
- **下单后多久能收到？**
  一般 5～7 个工作日。制作需要 3 个工作日，快递 2～4 天；大促期间可能延长，下单页会显示预计送达日期。（内链：配送说明页）

- **照片分辨率太低会怎样？**
  上传后系统会提示哪几张可能印出来模糊，你可以替换，也可以坚持使用。（补充）
