  [申请书草稿]

  1. 一句话科学问题：从草稿中提炼出「本项目要回答的核心科学问题」，如果提炼不出来，或提炼出的是技术问题、应用问题而非科学问题，直接指出——这是最常见的致命伤。
  2. 立项依据：是否说清「为什么要做、价值何在」；研究现状是否有针对性（而非教科书式综述）；从现状到「尚未解决的关键问题」的推理是否成立；前期发现是否自然引出本项目假说；参考文献是否新、是否包含本领域核心团队的工作。
  3. 研究内容：研究内容之间的逻辑关系（递进、并列还是支撑）；每项内容是否都在回答第 1 步的科学问题；内容数量与资助周期、经费是否匹配，有没有「大而全」；研究方案是否具体到能让同行判断可行性。
  4. 研究基础：前期结果是否直接支撑核心假说；团队与平台条件能否完成研究内容。
  5. 结构与格式：对照我粘贴的当年提纲，逐项列出缺项、错位或篇幅明显失衡的部分；提纲有页数限制的，提醒我核对。
  6. 函评视角打分：假设你是函评专家，从「创新性、科学价值、研究方案可行性、研究基础」四方面写出你最可能给出的 2 条肯定和 3 条质疑。

**先看当年提纲**：基金委每年都可能调整申请书撰写提纲。据公开报道，2026 年度面上项目和青年科学基金项目（C 类）的正文调整为立项依据、研究内容、研究基础三部分，不再预设「研究目标」「拟解决的关键科学问题」「技术路线」等小标题，并设置了页数上限。所以模板没有写死栏目，而是要你从基金委当年的撰写提纲里复制栏目贴进 [当年提纲栏目]——用旧模板写新申请书，很容易在形式审查或评审时吃亏。

**怎么填变量**：[申请书草稿] 可以分部分贴，先贴立项依据检查第 1、2 步，再贴研究内容。[科学问题属性] 没选好的话也可以让模型根据草稿给出判断理由。

**为什么不代写**：申请书的科学思想必须是你自己的，评审专家看重的是你对问题的理解深度；AI 写出的文字往往四平八稳、缺少真正的研究洞见，也存在学术诚信风险。请遵守基金委和所在单位关于申请材料使用生成式人工智能的相关规定。

**迭代追问**：「我按你的意见改了立项依据最后一段，请只检查从研究现状到科学问题这一段推理是否成立」「列出评审专家最可能质疑我研究方案可行性的 3 个点，以及我需要补充的预实验数据」。

### 示例输出

> 示例，仅供参考（医学科学部，面上项目，草稿节选）

**1. 一句话科学问题**：从草稿中提炼出的是「建立一种早期诊断方法」——这是技术目标，不是科学问题。建议回到机制层面，例如句式：「X 通过何种途径调控 Y，从而导致 Z？」

**3. 研究内容（节选）**
- 位置：研究内容三 → 问题：「开发智能诊断平台」与前两项机制研究关系弱，看起来是另一个项目 → 方向：删除或改为机制研究的验证性内容。
