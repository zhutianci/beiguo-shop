**怎么填变量**：[粘贴初步评估] 用编号代替姓名，比如「A07 / 绩效高 / 潜力初评高 / 事例：主动接手跨部门的会员项目并按期上线」。潜力评价一定要配事例，这是盘点结果能否站得住的关键。[盘点目的] 会影响后续行动计划的重点。

**常见坑**：把绩效好等同于潜力高——很多绩效优秀的专业骨干并不适合或不愿意走管理路线。潜力的判断要看行为事例，而不是印象。另一个常见问题是盘点完就结束了，没有任何后续行动，员工也感受不到变化。盘点结果要转化成具体的发展计划和继任梯队。

**迭代追问**：追问「为九宫格中『明星』格的 3 位员工各写一份个人发展计划框架」；也可以说「为部门经理岗位设计继任者评估表」。能力行为描述可以配合职级晋升标准提示词。

### 示例输出

> 示例，仅供参考（部门：运营中心，20 人）

| 格子 | 绩效 / 潜力 | 特征 | 策略 |
|---|---|---|---|
| 明星 | 高 / 高 | 结果突出，主动承担更大责任，能带动他人 | 给予挑战性项目、列入继任梯队、重点保留 |
| 专业骨干 | 高 / 中 | 本岗位表现稳定出色，扩展意愿或能力一般 | 专业序列发展、给予认可与专家角色 |
| 待观察 | 低 / 高 | 潜力评价高但近期结果不佳 | 了解原因，可能是岗位不匹配，考虑调整 |

**需要校准讨论**：A11 绩效为中，潜力初评为高，但只有「学习能力强」的评价，无具体事例【依据不足】。
