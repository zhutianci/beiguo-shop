**怎么填变量**：[题目要求] 把中文提示和要点原样贴上，包括「开头已给出」之类的说明；[年级与词数] 如「高二，80 词左右」；[我的习作] 第一次填「未写」，写完再发过去。

**常见问题与调整**：
- 句型太高级用不来 → 追问：「只留基础档，每种功能给一句我这个年级能背下来的。」
- 要点都写了但词数超了 → 追问：「标出我习作里可以删掉又不丢要点的句子。」
- 想换一种文体练 → 追问：「同样的情境改成一则通知，重新给审题表和格式要点。」

### 示例输出

> 示例，仅供参考（高一，题目：外教 Mr. Smith 想学中文，来信询问建议，请你回信，80 词左右；以下为阶段一节选）

**审题表**
- 文体：建议信（回信）
- 对象与身份：写给外教，我是学生李华，语气礼貌、略正式
- 时态人称：一般现在时为主，第一、二人称
- 要点：① 表示乐意提建议；② 给出两到三条学中文的建议并说明理由（需要自己补充细节）；③ 希望建议有帮助

**提纲**
第一段：得知您想学中文，我很高兴，愿意提几条建议。
第二段：建议一，多和中国学生用中文聊天，因为……；建议二，看带字幕的中文节目，因为……
第三段：希望这些建议对您有用，期待您的进步。

**句型库（提出建议）**
- 基础：You'd better … / It's a good idea to …
- 进阶：It would be helpful if you could … / I would suggest that you (should) …
对外教用进阶档更得体；You'd better 语气偏直接，对长辈和老师慎用。
