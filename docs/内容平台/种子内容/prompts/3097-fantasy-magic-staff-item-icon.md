**怎么填变量**：这条没有方括号变量，想换道具时按"材质主体 → 顶端主装饰 → 宝石数量 → 小装饰 → 风格"的顺序改写，例如"一把冰霜长剑：银白剑身、冰蓝水晶护手、剑格嵌 3 颗蓝宝石、剑柄缠白色皮革"。同一套提示词的结构反复用，就能做出风格统一的一整套道具。

示例图是白底上斜放的一根魔法杖：深色扭木杖身缠着金色藤蔓，顶端金色月牙里嵌着发光的紫色五角星，下方挂着一颗紫色水滴吊坠，杖身点缀紫色小宝石，底部是金饰和紫色宝珠。

**常见问题**：
- 宝石数量多了少了：数量约束对图标影响不大，可以删掉只保留描述。
- 背景有阴影：写"纯白背景，无投影"。
- 要像素版：把最后一段换成"32×32 像素风道具图标"。

**适合**：RPG 道具图标、卡牌插画、游戏商城素材、设定集。
