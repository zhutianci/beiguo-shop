**怎么填变量**：[我的思路或代码] 哪怕是错的也贴上——AI 指出你的思路错在哪，比看一份标准答案收获大得多。[模式] 刚学某类题型时用「引导模式」；复习或时间紧时用「直接讲解模式」。

**常见坑**：
- 题面最好完整粘贴（或至少写清题号和题名），只凭记忆描述题目，条件一变解法就完全不同。
- AI 给的复杂度分析偶尔会出错，尤其是均摊复杂度和递归，可以追问「一步步推导这个复杂度」。
- 推荐的题号要自己到 LeetCode 上核对一下。

**追问技巧**：做完后让它「把这道题的条件改一下出一道变式题」，检验是否真的掌握；或者每周把做过的题贴给它，问「按题型归类，指出我最薄弱的类型」。

### 示例输出

> 示例，仅供参考（LeetCode 3. 无重复字符的最长子串，Python）

**关键观察**：暴力解枚举所有子串需要 O(n²) 甚至更多；其实右边界每往右走一步，左边界只需要向右跳过重复字符，不需要回退——这就是滑动窗口。

```python
def lengthOfLongestSubstring(s: str) -> int:
    last = {}            # 字符 -> 最近一次出现的下标
    left = best = 0
    for right, ch in enumerate(s):
        # 只有重复字符落在当前窗口内，才需要移动左边界
        if ch in last and last[ch] >= left:
            left = last[ch] + 1
        last[ch] = right
        best = max(best, right - left + 1)
    return best
```

**复杂度**：每个字符最多被访问一次，时间 O(n)；字典大小不超过字符集大小，空间 O(字符集)。

**必测用例**：`""` → 0，`"bbbbb"` → 1，`"abba"` → 2（漏掉 `last[ch] >= left` 判断时，左边界会回退，这个用例会得到错误的 3）。
