**怎么填变量**：[软件与版本] 非常关键：动态数组函数需要较新的版本（Excel 365、Excel 2021 及之后），较老版本完全没有。WPS 新版本支持部分函数，以实际为准。[需求] 写清楚「输入什么条件、输出哪些列、怎么排序」。

**常见坑**：
- 公式结果要往下溢出，但下方单元格有内容，于是显示溢出错误。确保结果区域是空的。
- 多条件筛选时用 AND 函数连接条件，结果不对。AND 会把整个数组合并成一个值，要用乘号逐行相乘。
- 明细数据新增了几行，公式里写死的范围没有包含进来。把数据转换为表格，用结构化引用。

**追问技巧**：追问「在这个筛选结果的基础上，再用一个公式按销售员汇总金额并排名」，或「把这张自动报表做成可以选择月份的下拉菜单」。

### 示例输出

> 示例，仅供参考（Excel 365；明细已转换为表格「销售」，H1 输入区域，H2 输入月份）

```
=LET(
  区域, 销售[区域],
  月份, TEXT(销售[日期], "yyyy-mm"),
  结果, FILTER(销售, (区域 = H1) * (月份 = H2), "无匹配数据"),
  SORTBY(结果, INDEX(结果, , 6), -1)
)
```

**逐段解释**：
- `(区域 = H1) * (月份 = H2)`：两个条件逐行相乘，两者都成立的行为 1，其余为 0，相当于「且」；
- `FILTER(..., "无匹配数据")`：保留满足条件的整行，没有结果时显示提示文字；
- `SORTBY(结果, INDEX(结果, , 6), -1)`：按结果的第 6 列（金额）降序排列。

**不支持动态数组时**：用数据透视表，把区域和月份放进筛选器，金额降序排序，数据更新后点击刷新。
