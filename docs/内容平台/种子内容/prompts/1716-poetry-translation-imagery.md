**为什么要先直译**：诗歌翻译常说「译诗难」，因为意思、意象、节奏、音韵很难同时保留。先看直译稿，你才知道诗化译稿为了「好听」改动了多少；取舍说明则帮助你理解译者的选择，而不是只看结果。

**怎么填变量**：[优先保留] 最多选两项，全都要的结果往往是全都打了折扣。比如翻译李白的五言绝句，优先保留意象和情感，通常比强求英文押韵更能传达原诗。[翻译目的] 影响译稿的风格：帮助理解时可以多加注释，作为诗作发表时注释要少。

**常见问题与调整**：
- 诗化稿太自由 → 追问：「在诗化稿和直译稿之间折中，再给一版更忠实的译文。」
- 中译英押韵生硬 → 追问：「放弃押韵，改用自由体，保留意象和节奏感。」
- 想学诗歌翻译方法 → 追问：「对比这首诗的两种不同英译思路，说明各自的翻译理念。」

**版权提醒**：现代诗人的作品通常受版权保护，译文请仅用于个人学习；古典诗词属于公版内容，可以自由翻译。

### 示例输出

> 示例，仅供参考（自编两行中文诗：「夜深灯未灭，窗外一枝梅」，中译英，优先保留意象与节奏）

**直译稿**：Night is deep, the lamp not yet out; / outside the window, one branch of plum.
**诗化译稿**：Late night, my lamp still burning bright— / a sprig of plum outside, in white.
**取舍说明**：保留了「灯」「梅」两个核心意象；为了押韵加入了原诗没有的 bright 与 white（梅花颜色原诗未说明），这是为音韵付出的代价，若追求忠实可回到直译稿的结构。
