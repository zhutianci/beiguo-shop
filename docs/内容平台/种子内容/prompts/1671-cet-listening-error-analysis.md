**怎么填变量**：[粘贴听力原文] 一般真题或练习材料都附有录音文本。[我的笔记] 非常有用，哪怕只写「只听到了 library 和 Tuesday」，AI 也能判断你是语音问题还是被原词误导。

**常见问题与调整**：
- 分析太笼统（「需要多听」）→ 追问：「针对第 3 题，具体是哪个词或哪个语音现象导致我没听出来？」
- 想练精听 → 追问：「把错题对应的原文句子按难度排序，做成一份逐句听写的练习单。」
- 发音也弱 → 听不出来的音往往是自己读不准的音，可以用本站「英语发音纠正提示词」和「影子跟读材料生成提示词」配合练习。

**提醒**：考试题型与分值以全国大学英语四、六级考试官方说明为准；听力原文请使用正规渠道获得的材料。

### 示例输出

> 示例，仅供参考

**第 5 题**
原文：I was going to take the train, but it turned out the bus was cheaper and faster.
我的答案：A（By train）｜正确答案：C（By bus）
失分原因：解题层面——听到了 train 就选，没有抓住 but 之后的转折。
信号词：but it turned out（表示实际情况与原计划不同）。
语音提示：turned out 连读成 /tɜːndaʊt/。
