**怎么填变量**：[本课核心问题] 是导入设计的终点——好的导入最后一定落在「所以今天我们要弄清楚……」。[学生特点] 决定风格：同样讲浮力，给三年级可以用「乒乓球为什么浮起来」的小实验，给高一学生更适合「万吨巨轮为什么不沉」的认知冲突。

**常见问题与调整**：
- 导入太长占用新课时间 → 追问：「每种方案压缩到 3 分钟以内，删掉与核心问题无关的环节。」
- 导入和正课脱节 → 追问：「导入中提出的问题，请在本课结束前设计一个回扣环节。」
- 史料或故事有错 → 涉及人物、年代、数据的内容，请对照教材和可靠资料核实后再用。

**配合使用**：导入确定后，可以接着用本站「课堂提问设计提示词」设计正课的问题链。

### 示例输出

> 示例，仅供参考（初中物理「大气压强」，导入 3 分钟）

**认知冲突导入**
- 教师话术：「我在杯子里装满水，盖上一张硬纸片，倒过来——大家猜，水会不会洒出来？」
- 学生活动：举手预测，教师演示。
- 过渡句：「纸片没有掉下来，是谁在托着它？今天我们就来找这个『看不见的力』。」
- 不适合：没有演示条件时，可改用视频，但效果会减弱。
