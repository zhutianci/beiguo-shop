  2. 课前预习（约 10–15 分钟可完成）：

**怎么填变量**：[学情概述] 影响问题的难度和支架数量，比如「学生预习习惯较差、阅读速度慢」，预习部分就要更短、更聚焦。[栏目要求] 很多学校有统一模板（如「自主学习—合作探究—展示交流—检测反馈」），把栏目名称贴进来，AI 会按模板调整。

**常见问题与调整**：
- 变成了填空背书 → 追问：「把课堂探究中的填空题改为需要学生观察、比较或解释的问题。」
- 一页放不下 → 追问：「压缩到 A4 正反面，删掉重复检测同一目标的题目。」
- 层次不够 → 可以把本站「分层教学设计提示词」中的三层任务嵌入课堂探究部分。

**提醒**：导学案只是工具，课前收上来看一看学生的「我的疑问」，往往比课堂上统一讲解更有针对性。

### 示例输出

> 示例，仅供参考（八年级物理「光的反射」，学生版节选）

**学习目标**：我能通过实验说出反射角和入射角的关系；我能用光的反射解释生活中的现象。

**课堂探究 · 任务一：反射光往哪里走？**
材料：激光笔、平面镜、可折转的光屏。
1. 改变入射光的方向，反射光的方向怎样变化？
2. 测量 3 组入射角和反射角，填入表格。你发现了什么规律？
3. 把光屏的一半向后折，还能看到反射光吗？这说明了什么？
【方法点拨】入射角是入射光线与法线的夹角，不是与镜面的夹角。
