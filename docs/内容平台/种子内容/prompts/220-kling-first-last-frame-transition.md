**首尾帧是什么**：可灵的图生视频可以同时上传"开始画面"和"结束画面"，模型负责补出中间的运动。它最适合"同一个地方 / 同一个东西，状态发生变化"的场景。

**两张图怎么准备**：构图、机位、主体位置尽量一致，只改你想变化的部分。最省事的方法是拿一张照片，用图像模型改出"变化后"的版本（换季节、换颜色、换装修），这样两张图天然对齐。

**怎么填变量**：
- 产品换色：首帧"[白色运动鞋]"，尾帧"[同款黑色运动鞋]"，过渡方式写"颜色从鞋头向鞋跟像墨水一样蔓延"。
- 装修前后：首帧"[毛坯房]"，尾帧"[装修好的客厅]"，过渡方式写"家具一件件从地面升起就位"。
- 人物换装：首帧和尾帧是同一个人的两套穿搭，过渡方式写"原地转一圈，衣服随转身变换"。

**常见失败与调整**：
- 中间帧像融化、建筑扭曲：两张图差异太大，把变化拆成两步，用"首帧→中间图""中间图→尾帧"分两条生成。
- 直接从首帧跳到尾帧：在"节奏"里写清每个阶段的秒数，并选更长的时长。
- 冒出新物体：在负面提示词里点名"多余的人物、车辆"。
