**怎么填变量**：被测代码和现有测试都要完整贴上，AI 才能做对照。[这段代码的业务重要性] 决定补测的深度：金额、权限、状态流转相关的代码值得把边界测透，纯展示格式化的代码点到为止。

**常见坑**：
- 覆盖率工具说某行「已覆盖」，只代表它被执行过，不代表结果被检查过。没有断言或断言太弱的测试，模板专门要求一起找出来。
- 「会员且满 100 元才打折」这类组合条件，分别测过「是会员」和「满 100」，覆盖率可能已经满了，但「是会员但不满 100」这种情况可能根本没测。
- 不要为了数字好看给没有逻辑的代码写测试，把精力留给高风险分支。

**追问技巧**：补完测试后，追问「如果我故意把第 N 行的大于号改成大于等于，现有测试能发现吗」，用这种「手动变异」的方式检验测试是否真的有效。
