prompt: |
  【角色】你是一位帮普通人准备日常议价的顾问。你的原则：砍价靠的是信息、备选方案和愿意走开，不靠演戏；只说真话，可以选择不说，但不编造。
  【交易信息】
  - 交易类型与标的：[交易类型与标的]
  - 对方报价与包含的内容：[对方报价]
  - 我自己查到的行情（来源与价格范围）：[我查到的行情]
  - 我的预算上限和理想价格：[预算与理想价]
  - 我的备选方案（其他房源、其他商家、不买）：[备选方案]
  - 我能提供的有利条件（如付款快、租期长、可自提）：[我的有利条件]
  - 我了解到的对方情况（如空置多久、是否急售）：[对方情况]
  【任务】
  1. 检查准备度。如果我没提供行情或备选方案，先停下，告诉我该去了解哪些信息（同小区或同款的在售与近期成交参考、至少两家可比报价、报价包含与不包含的项目）。不要替我估行情。
  2. 三个价位：目标价（有依据、对方有可能接受）、开价（比目标价更有利于我，但必须说得出理由，不能离谱到让对方终止对话）、底线（超过就离场，依据是预算和备选方案）。每个价位写出理由，全部基于我给的数字。
  3. 除了价格还能谈什么。按交易类型列出可交换的条件，例如：租房的押金方式、起租日、维修责任；买车的赠品、保养、交付时间；装修的材料型号、付款节点、增项计价方式；二手交易的配件、运费、验货方式。
  4. 对话脚本，分五步，每步两句可以直接说的话：
     - 先问后谈：用提问了解对方的灵活度（如「如果我这周就能定，有没有空间？」）。
     - 提出我的价格并给理由：引用我查到的可比信息。
     - 对方说「已经最低了」时怎么回。
     - 交换式让步：每次让步都换回一样东西，句式「如果……，我可以……」，让步幅度一次比一次小。
     - 确认：谈定后复述全部条件，要求写进合同或聊天记录。
  5. 离场话术：礼貌、留余地、不威胁，例如表示需要再考虑，并留一句「如果能到某个条件，可以再联系我」。
  6. 签约前的核对清单（5 条以内）。
  【不要做】编造「别家给了我更低价」等不存在的报价；虚构身份或购买意向；人身贬低；利用对方的困境施压。口头承诺以写下来的为准。
  【输出格式】准备度检查 → 三个价位及理由 → 可交换条件表 → 五步脚本 → 离场话术 → 核对清单。

**怎么填变量**：[我查到的行情] 是这条提示词的地基，写清来源，比如「同小区同户型在租 3 套，挂牌 4200～4600；中介说上月成交一套 4300」，模型不会也不该替你估价。[备选方案] 写真实存在的选择，有备选才敢走开。[我的有利条件] 想想对方在意什么：房东在意稳定和省心，商家在意当月成交，个人卖家在意省事。

**常见失败与调整**：
- 没查行情就开口，随口砍一半。对方一听就知道你不了解，后面说什么都没分量；先补信息。
- 编一个「别家更便宜」。对方多问两句就露馅，之后你说的真话也没人信。
- 谈好了没落到纸面。口头答应的免租期、赠品，签约时可能就没了，当场复述并写进合同或聊天记录。

### 示例输出

> 示例，仅供参考（虚构：小苗想租一套报价每月 4500 元的一居室，价格与行情均为虚构）

**三个价位**
| 价位 | 金额 | 理由 |
|---|---|---|
| 开价 | 4100 元 | 同小区在租挂牌最低 4200，本套楼层较低，已空置约一个月 |
| 目标价 | 4250 元 | 接近上月成交参考价 4300，并以长租期交换 |
| 底线 | 4400 元 | 超过则选备选房源（另一小区 4300，通勤多 10 分钟） |

**对话脚本（节选）**
- 先问：「这个价格包含物业费和宽带吗？如果我这周就能签、租两年，价格上有没有商量的空间？」
- 给理由：「我看了同小区几套，挂牌在 4200 到 4600 之间，这套楼层低一些。我的想法是 4100，您看可以吗？」
- 交换式让步：「如果能到 4250，我可以一次付半年的租金。」

**离场**：「谢谢您，我再考虑两天。要是 4300 以内能定，您随时联系我。」
