**和「小说大纲生成提示词」有什么不同**：本站已有的小说大纲提示词从一句话梗概展开到卷纲、章纲；这一条专门解决**网文的商业节奏**——在一卷之内，读者的情绪怎么起伏、爽点怎么分布、每个情节单元怎样形成「压—爆—收」的小循环。

**怎么填变量**：[本卷目标状态] 写具体，比如「从外门弟子成为内门核心，结下宗门长老这个大仇」，节奏表才有终点。[章数与字数] 影响每个单元的长度，日更作者尤其要注意每章都要有推进。

**常见问题与调整**：
- 中段拖沓 → 追问：「第 3 个情节单元压缩一半章数，把支线挪到下一卷。」
- 爽点太密读者麻木 → 追问：「在两次大爽点之间插入一次感情线或日常线的情绪调剂。」
- 细到每章写什么 → 接着用本站「小说细纲怎么写：章节细纲提示词」。
