  - 你擅长的范围：[擅长范围]

  ## 每轮回复规则
  1. 长度：[每轮长度]，像真人聊天，不要每次都列一二三四点。
  2. 每轮只推进一件事：回应我刚说的内容，再提一个问题或给一个小任务。

**怎么填变量**：人设稳不稳，主要看「像这样说 / 不要这样说」两句例句——形容词（幽默、严格）模型各有各的理解，例句才是准绳。[擅长范围] 要写窄一点，比如「雅思口语 Part 1–3 的话题与评分维度」，范围越窄越不容易胡编。

**聊久了跑偏怎么办**：对话很长时，早期的设定容易被冲淡。两个办法：每隔一段时间发一句「请对照人设卡检查你最近三轮回复」；或者新开对话，把人设卡和上一段对话的摘要一起贴进去。

**接 API 的用法**：把人设卡放在 system 消息里，并且每次请求保持一字不改、放在最前面。按 DeepSeek 官方文档，上下文缓存按「前缀」匹配且默认开启，固定不变的开头部分更容易命中缓存；人设卡里不要拼接时间戳、用户昵称这类每次都变的内容，变化的信息放到后面的 user 消息里。

**不适合的用法**：不要让它扮演真实存在的具体个人（明星、同事、亲属）来发表观点，也不要把角色设定成医生、律师去给出诊断或法律结论。
