**怎么填变量**：[作业要求] 直接贴老师发的原文，评分标准也一起贴，AI 会据此判断哪些部分值得多花时间。[组员情况] 一人一行，比如「小林：会做数据分析，周三周五晚上有空；小吴：这两周有竞赛，只能做轻量任务」。实际情况写得越诚实，分工越能执行。

**常见问题与调整**：
- 分工看着平均但有人明显更累 → 追问：「按预计小时数重新平衡，谁超过平均值 30% 就拆一部分出去。」
- 只剩三天了 → 追问：「按只剩 3 天重排，砍掉可以不做的任务，告诉我哪些必须保留。」
- 话术太生硬 → 追问：「第二层级的话改得更口语一点，像同学之间私聊。」

**使用提醒**：把分工表和时间线发到群里请每个人回复确认，比组长单方面安排更容易落实；贡献说明怎么交，以课程要求为准。

**任务清单（节选）**

**轻提醒话术**：小吴，问卷那部分原定昨天汇总，现在还差你负责的 3 题。今晚 10 点前能给吗？来不及的话告诉我一个新的时间，我好调整后面的安排。
