**怎么填变量**：[需要记录的信息] 可以先乱列，比如「设备名、型号、买的时间、多少钱、谁在用、放在哪、坏没坏」，AI 会帮你规整成字段。[统计需求] 一定要写——台账最终是为了回答问题的，比如「每个部门有多少台电脑、哪些超过 5 年需要更换」，会反过来决定要记录哪些字段。

**常见坑**：表头做成两三行的合并单元格，看起来漂亮，但无法排序、筛选和做透视表。另一个常见问题是让人手填「状态」，结果出现「已完成」「完成」「OK」好几种写法，下拉菜单可以彻底解决。多人填写的台账建议放在在线表格里，并设置好编辑权限。

**迭代追问**：追问「为这份台账设计一个月度统计看板，包括 3 个图表」；也可以说「把台账改成适合飞书多维表格 / 钉钉在线表格的字段配置」。整行变色提醒可以接着用条件格式提示词设置。

### 示例输出

> 示例，仅供参考（IT 资产台账）

| 字段名 | 类型 | 必填 | 填写规范与示例 | 自动生成 |
|---|---|---|---|---|
| 资产编号 | 文本 | 是 | IT-年份-四位序号，如 IT-2026-0012 | 否 |
| 资产类别 | 下拉 | 是 | 笔记本 / 台式机 / 显示器 / 打印机 | 否 |
| 购入日期 | 日期 | 是 | 2026/03/15 | 否 |
| 使用年限 | 数字 | — | =DATEDIF([@购入日期],TODAY(),"y") | 是 |
| 使用部门 | 下拉 | 是 | 引用参数表「部门」列 | 否 |

**防重复**：选中 A 列 → 数据验证 → 自定义 → 公式 =COUNTIF($A:$A,A2)=1，出错提示「资产编号已存在」。
