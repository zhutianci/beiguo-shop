**这个功能是什么（以 Gemini API 官方文档为准）**：Veo 3.1 可以接收最多 3 张参考图，图片内容是**同一个人物、角色或产品**，Veo 会在生成的视频里保留这个主体的外观；参考图模式下视频时长只能是 8 秒。它和"图生视频"的区别是：图生视频把图片当作**第一帧**，场景就被定死了；参考图模式只锁主体，场景可以完全由提示词决定——同一件产品可以出现在露营地、办公室、海边。

**参考图怎么选**：3 张图分别是正面、侧面、细节（按键、接口、标识），背景最好是干净的纯色，模型更容易分清"哪部分是产品"。如果产品有文字标识，生成后的文字仍可能变形，重要的品牌字样建议后期贴片。

**怎么填变量**：[便携咖啡机] 换成你的产品；[清晨的露营地] 换成目标用户的使用场景。可以保持其他文字不变、只改场景，批量做出一组"同一产品、不同生活方式"的广告素材。

**常见失败与调整**：
- 产品被"改款"了：参考图换成更清晰的白底图，并在提示词里点名关键细节（"顶部圆形按键、侧面银色把手"）。
- 出现两台产品：写"画面中只有一台"。
- 手部操作穿模：把按键动作删掉，改成"咖啡已经流进杯子里"。
