**怎么填变量**：[剧本类型] 决定设计重点：推理本重线索和逻辑，情感本重人物关系和故事，欢乐本重机制和互动。第一次写，建议从 4–6 人、时长 3–4 小时的推理本开始。[使用场景] 也很重要：朋友聚会可以简单一些，发行的剧本需要更完整的物料和测试。

**常见问题与调整**：
- 有的角色没戏 → 追问：「给第 4 号角色增加一个与其他两人相关的秘密任务。」
- 真相太容易猜 → 追问：「增加一条指向另一个人的强误导线索，并设计它如何被合理地推翻。」
- 写角色本正文 → 追问：「按第一人称写 3 号角色的角色本前半部分，只写他知道的信息。」

**提醒**：剧本完成后最好找朋友实际玩一次（测本），根据反馈调整线索和平衡；线索与时间线可以参考本站「悬疑推理小说诡计与线索布局提示词」。
