**怎么填变量**：[嵌入内容] 是让对联「独一无二」的关键，比如把新人名字的一个字分别嵌入上下联开头，或者把店名嵌进去，比通用的吉祥话更有意义。[避免内容] 可以写你不喜欢的俗套说法。

**基本规则（简要）**：对联最核心的是「对」——字数相等、词性相对、结构相同；常见的平仄规则是上联末字仄声、下联末字平声，所以分辨上下联最简单的方法就是看末字的声调。注意：AI 判断平仄有时会出错，尤其是古今读音不同的字。

**常见问题与调整**：
- 对仗不工整 → 追问：「逐字列出上下联的词性对照，修改对不上的地方。」
- 太俗套 → 追问：「不用『福』『财』『春』这些常见字，写一副更有新意的春联。」
- 想要书法用的格式 → 追问：「把对联排成竖排，标明上联、下联、横批的位置。」
