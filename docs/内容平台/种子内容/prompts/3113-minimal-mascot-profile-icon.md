**怎么填变量**：[对话气泡角色] 换成和你的产品或账号有关的形象，例如"一朵白云""一个灯泡""一个代码括号 { }"；[圆角矩形小设备] 可以换成"一只小机器人""一个咖啡杯"。黑底可以改成你的品牌色，保持"两个角色 + 一大一小 + 极简五官"的结构就行。

示例图是黑底上占满大半画面的白色圆润对话气泡，两只竖椭圆黑眼睛和粉色腮红，右下角一个灰色小方块设备，屏幕上画着点点眼和笑脸，构图被裁得很满，适合圆形头像裁切。

**常见问题**：
- 画面太复杂：保留"极简扁平、没有阴影和纹理"。
- 两个角色比例失衡：写"主角占画面 70%，小角色占 25%"。
- 做 App 图标：画幅保持 1:1，并写"四周留出 10% 安全边距"。

**适合**：社交头像、AI 工具 / 聊天产品图标初稿、技术博主头像、贴纸。
