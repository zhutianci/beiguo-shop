**怎么用**：先在 DeepSeek 输入框下方打开「联网搜索」（按钮名称以实际界面为准），再粘贴提示词。[今天日期] 一定要填——模型的训练数据有截止时间，不告诉它今天是哪天，它容易把旧信息当成最新的。

**怎么填变量**：[要查的问题] 写成能回答「是 / 否 / 多少 / 什么时候」的具体问题，比如「2026 年个人所得税专项附加扣除有哪些调整」，而不是「个税」。[优先来源] 按问题类型选：政策类优先政府网站，产品类优先官方公告和文档。

**常见问题与调整**：
- 给的链接打不开或内容对不上 → 这类情况确实会出现，重要结论一定要点开核对；可以追问：「第 2 条的来源我打不开，请换一个来源，找不到就把这条移到『未找到』。」
- 结果全是自媒体转载 → 追问：「只保留政府网站和官方公告的结果，其余删掉。」
- 想继续深挖 → 追问：「针对『有分歧』的那一条，再搜一次，看哪种说法有原始文件支持。」

**边界**：涉及医疗、法律、财务决策的内容，搜索结果只能帮你整理信息和准备问题，最终要以专业人士和官方文件为准。
