**怎么填变量**：[从外滩眺望黄浦江对岸的陆家嘴] 换成任何"视角 + 地点"，写清站在哪里看哪里效果最好，例如"从断桥眺望西湖和保俶塔""从大雁塔北广场看大雁塔""自家小区门口的街道"。[樱花] 可按地方特色换成"桃花""油菜花""玉兰"。示例图是原作者生成的外滩版本：左边雪后的万国建筑群和冰封江面，中间樱花和夏日绿树，右边东方明珠前的秋叶夕阳。

**常见问题**：
- 四季分成了四个硬切的竖条：加"四季之间无缝渐变，像同一张照片里的颜色慢慢变化"，或改成"从上到下 / 从近到远过渡"。
- 地标长得不对：模型对国内地标的还原度不稳定，可以上传一张该地点的实拍照片，开头加"以上传照片的构图和建筑为准"。
- 想做竖版海报：画幅改成 3:4 或 9:16，四季改为"从上到下"排列。

**适合**：城市 / 文旅宣传、二十四节气或年度回顾封面、地产与酒店宣传图、电脑和手机壁纸。
