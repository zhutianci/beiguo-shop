**怎么填变量**：[猕猴桃] 可以换成"西瓜""菠萝""椰子""橙子"，泳池、瀑布和切片装饰会跟着换成对应的果汁和果肉；度假村名称和木牌文字按你的品牌或心情写。木牌文字越短越不容易出错，五个打勾牌可以减到三个。

示例图是半个猕猴桃变成的小岛：顶上茅草屋和吊床里拿着绿色饮料的女子、旁边的小狗，左侧木牌上五行打勾的英文，中间绿色果汁泳池和木栈道，一道绿色瀑布从果肉流进海里，右下小木船，背景是夕阳和远处的海岛（原提示词默认英文木牌，本站已改为中文）。

**常见问题**：
- 木牌文字乱码：中文木牌每块 4～6 字，数量控制在 3～4 块。
- 场景太乱：删掉一部分道具（躺椅、黑板），保留"小屋 + 泳池 + 瀑布"三个核心。
- 人物比例不对：写"人物和小狗都是微缩比例，约占猕猴桃高度的十分之一"。

**适合**：水果 / 饮品品牌创意海报、社媒趣味图、手机壁纸、电商活动头图。
