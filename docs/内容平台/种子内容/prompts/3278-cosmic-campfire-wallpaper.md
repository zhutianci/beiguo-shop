**怎么填变量**：两个角色是这张图的灵魂，换成任何有反差的组合都行：[一名宇航员] + [一个年轻男子] 可以换成"古代书生 + 现代程序员""小女孩 + 一只大熊""机器人 + 老奶奶"，服装跟着改；[旋涡星系] 可换成"极光""星云""流星雨"。示例图是竖版、几乎全黑的画面：左边白色宇航服的宇航员坐在灰石上举着木棍烤棉花糖，右边穿红黑格子衬衫的男子坐在折叠椅上伸手烤火，中间篝火的火星向上飘散，上方悬着一个蓝白色的旋涡星系。

**常见问题与调整**：
- 背景出现地面或星空：重复"纯黑背景，除了篝火光照到的地面一小圈，其他全黑"。
- 火焰和星系是两样东西：写"火焰顶端直接卷成星系的旋臂，中间没有断开"。
- 做电脑壁纸：画幅改 16:9，两个角色拉开距离，星系横向展开。
- 人物太小：改成"中景，两个角色占画面高度的三分之一"。

**适合**：手机 / 电脑壁纸、文章与播客封面、情绪类海报；不适合需要明亮背景的场景。
