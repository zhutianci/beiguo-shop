**怎么填变量**：[粘贴素材清单] 尽量写清每个素材从哪里来，比如「海报背景图：某免费图库，页面写『可免费商用』，没有截图保存」「标题字体：电脑自带，不知道是否可商用」。[使用场景与用途] 很重要，同一个素材，个人学习使用和用于商业广告的要求可能完全不同。

**常见坑**：觉得「网上能下载到的就能用」，或者「我只用了一点点、改过了就不算侵权」，这些都是常见误区。字体是最容易被忽视的风险点之一，很多常见的中文字体商用都需要授权。另外，图片中出现的真人肖像和品牌商标，还涉及肖像权和商标问题。保留授权证明截图，是日后被质疑时最重要的依据。

**迭代追问**：追问「帮我把高风险素材替换成自己可以拍摄或制作的方案」；收到侵权通知时，可以用收到律师函怎么办提示词梳理；PPT 字体选择可以参考 PPT 配色方案提示词中的字体授权提醒。

> 本提示词输出内容仅为信息整理，不构成法律意见，重要事项请咨询律师。
