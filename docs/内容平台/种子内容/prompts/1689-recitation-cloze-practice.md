prompt: |
  请帮我背诵下面这段内容。

  原文（以教材为准，请完整粘贴）：
  [粘贴背诵原文]
  背诵要求：[背诵要求]（如：全文背诵并默写 / 只背第 2–4 段 / 能流利复述大意即可）
  我的情况：[我的情况]（如：意思懂了但总是串句 / 有几个字老写错）

  请按以下步骤：
  1. 分段与线索：按意思把原文分成若干小段，每段用一个短语概括段意，再把段意串成一条「背诵线索」（如：写景 → 抒情 → 议论），帮我记住先后顺序。
  2. 关键词：每段标出 2–4 个「提示词」，只要想起这几个词，就能想起整句。
  3. 挖空练习（由易到难，每一轮等我作答后再出下一轮）：
     - 第 1 轮：每句挖掉 1 个关键词，用（　　）表示；
     - 第 2 轮：每句挖掉一半；
     - 第 3 轮：只给每句的第一个字；
     - 第 4 轮：只给段意线索，我默写整段。
     我作答后，逐处对照原文标出错误。
  4. 易错字提醒：列出原文中容易写错的字（形近字、同音字、通假字），说明区分方法。
  5. 复习安排：建议今天、明天、三天后各做哪一轮练习。

  所有挖空和对照都必须严格依据我粘贴的原文，不得改动原文的任何字词或标点；如果我粘贴的原文可能有错，提醒我对照教材核实，但不要替我修改。

**怎么填变量**：[粘贴背诵原文] 务必从教材或权威版本复制，不要让 AI 凭记忆写出原文——古诗文的个别字词版本不同，背错了更难改。[我的情况] 写清楚问题在哪，比如「总是把第三段和第四段的顺序弄反」，AI 会在线索部分重点强调。

**常见问题与调整**：
- 挖空太简单 → 追问：「直接从第 3 轮开始。」
- 总是串句 → 追问：「把容易混淆的两句放在一起对比，说明它们的区别。」
- 想结合理解背 → 先理解再背效果更好，文言文可以先用本站「文言文翻译提示词」弄懂每句意思。

**提醒**：AI 对照时也可能出错，默写完成后最好再对照教材检查一遍。
