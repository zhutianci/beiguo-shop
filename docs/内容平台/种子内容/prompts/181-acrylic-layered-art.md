**怎么用**：上传自己的插画（人物、风景都行，色彩鲜明的效果最好）。示例图是一张彩虹发色的人物插画做成亚克力挂画后的效果，注意墙上的彩色投影。[冷色调] 换成"午后暖阳"，投影会变成温暖的金色调。

**常见问题**：
- 画风被改：这是这条提示词的核心难点，原作者把"严格保留原始画风"放在了第一句，不要删。
- 插画超出底板：在构图规则里强调"边距至少为画面宽度的 8%"。
- 投影太弱：加"光线角度约 45°，投影清晰可见"。

**适合**：周边预售效果图、画师作品集、展会海报；请只使用自己拥有版权的插画，知名动漫 / 游戏角色的图仅供学习交流。

### 原版（仓库收录的中文译文）

```
产品摄影，正面正视图。关键：必须严格保留输入插图的原始艺术风格、线条和人物特征。请勿对图画本身进行抽象或简化。
作品为实体多层结构，安装于白色墙面上。
构图规则：
1. 最终产品摄影的宽高比和方向应与输入源图像的尺寸一致。
2. 使用可见的金属支架固定一块大型透明底板。
3. 至关重要的是，整个模切插图（所有图层）必须完全包含在底板的边界内。
4. 插图边缘与底板边缘之间应留有适当的清晰边距。
材料物理原理（高透光率）：
在底板上，使用超透明、高亮度着色亚克力板重建图案，这种亚克力板专为最大限度透光而设计。
1. 颜色为透明材料本身的颜色（玻璃般），而非涂绘。
2. 皮肤/白色区域：必须使用纯净、无色、超透明的玻璃状亚克力板。
3. 彩色区域（头发/衣物）：使用高透光率的彩色亚克力板。颜色鲜艳，但透光性极佳，允许大量光线通过。
光照与阴影：
强烈的冷色调斜射光能够穿透高度透明的画面。光线不会形成浓重的阴影，而是在墙面上投射出明亮、闪耀、高度半透明的彩色光晕，展现出墙面的纹理。阴影区域应感觉轻盈通透，将墙面原有的色彩以明亮的投影形式呈现出来。8K分辨率，超高清细节。
```
