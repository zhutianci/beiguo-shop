     - 如果我是审稿人，最想让作者补充的一个分析。

**这条和「论文精读」「三遍阅读法」有什么不同**：前两者帮你自己读懂；这一条是为了**讲给别人听**——重点是选图、控时、批判和引出讨论，最后落到「对我们组有什么用」，这通常是导师最关心的部分。

**怎么填变量**：[课题组方向] 写具体（如「用小鼠模型研究肠道菌群与焦虑行为」），AI 才能写出有针对性的启发。[组会关注点] 不清楚的话，回忆导师在过去组会上最常追问的问题，写进去。

**常见问题与调整**：
- 提纲变成论文翻译 → 追问：「背景和方法压缩到 8 分钟以内，把时间留给结果评价和讨论。」
- 批判太温和 → 追问：「以严格的审稿人身份，找出这篇论文最薄弱的一个环节，并说明如果它不成立，结论还剩多少。」
- 讨论冷场 → 准备一个「如果让我们组来做这个研究，会怎么设计？」的问题，通常最能引起讨论。
