  【角色】你是一名主持过上百场企业年会和颁奖典礼的活动主持人兼撰稿人，熟悉双人主持的台词分配和现场节奏控制。

  - 活动名称与主题：[活动名称与主题]
  - 时间地点与总时长：[时间、地点、总时长]

  [按顺序粘贴流程：环节名称、表演者或嘉宾、时长]
  - 需要介绍的领导嘉宾：[职务 + 姓名，按出场顺序]
  - 风格：[正式庄重/轻松幽默/温情]
  - 必须提到的内容：[如年度业绩关键词、公司口号]

  【任务】
  1. 开场白：问候 → 点题（今年的关键词）→ 介绍到场领导嘉宾 → 宣布开始，控制在 2 分钟内。
  2. 逐环节串词：每段串词「承上」一句回应上一个节目，「启下」一句引出下一个节目，并准确报出节目名称、表演者部门和姓名；领导致辞前的介绍要写全职务。
  3. 抽奖 / 颁奖环节：写清奖项名称、颁奖嘉宾上台、宣读获奖名单、合影的口令，避免冷场。
  4. 结束语：感谢 → 回顾 → 祝福 → 合影或退场指引。
  5. 备用词：节目延误、设备故障、抽奖等待、冷场各准备 2 条 30 秒以内的救场词或互动小游戏。

  【约束】
  - 台词口语化，每段串词 60–120 字，双人主持交替说话，避免一人独白过长。
  - 领导嘉宾的职务、姓名只用我提供的，不确定的用【核对职务】标出。
  - 幽默只用自嘲和场内梗，不拿同事外貌、婚恋、地域开玩笑。
  - 合计时长和流程表核对，超时的地方提示我删减。

  【输出格式】

**怎么填变量**：[节目单 / 流程] 直接把活动执行表粘进来，越完整越好——表演者部门、节目类型（歌舞、小品、颁奖）都会影响串词怎么写。[必须提到的内容] 填今年的业绩关键词或口号，AI 会把它们埋进开场和结束语。

**常见坑**：领导职务报错、节目临时调整后串词对不上。建议定稿前让 AI 输出「需要核对的信息清单」，主持人和导演逐条确认；流程改了就把新流程贴回去说「只更新受影响的串词」。

**迭代追问**：觉得太官方，说「开场加一段和观众的互动问答」；需要手卡时说「把每段串词压缩成手卡版，每张不超过 50 字」。
