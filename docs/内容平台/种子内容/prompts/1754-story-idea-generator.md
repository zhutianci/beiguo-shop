**怎么填变量**：[模糊想法] 哪怕只是「一个总在凌晨三点醒来的人」也很有用，AI 会从这个点延伸出不同方向。[避免套路] 写上你看腻了的设定，比如「重生复仇」「霸总」，创意会更新鲜。

**常见问题与调整**：
- 创意都很普通 → 追问：「每个创意再加一个让人意外的限制条件或代价。」
- 喜欢某个创意但觉得太小 → 追问：「把第 5 个创意扩展成一个长篇故事的世界观和三幕结构。」可以接着用本站「世界观设定提示词」「救猫咪节拍表提示词」。
- 想写短篇 → 选好创意后用本站「短篇小说写作提示词」设计反转与结构。

**提示**：AI 生成的创意是起点，真正让故事独特的，是你加进去的个人经历和观察。

**What if · 创意 2**
- 梗概：一个失业的配音演员，被雇来每天给一位失明老人「读」小区里发生的事——但他读的全是自己编的。
- 核心冲突：谎言越编越温暖，老人越来越快乐；直到有一天，老人说要请小区里「那些好心人」吃饭。
- 读者想知道：他该怎么收场？老人到底知不知道？
- 适合：短篇小说 / 短剧
