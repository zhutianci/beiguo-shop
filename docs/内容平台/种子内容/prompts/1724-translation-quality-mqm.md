**MQM 是什么**：多维质量指标（Multidimensional Quality Metrics）是翻译行业用来评估译文质量的一套错误分类框架，常用于本地化项目和机器翻译评估。它的核心思路是「按类别和严重程度标注错误，再加权计分」，比「感觉翻得好不好」更客观、可比较。具体的类别体系和计分方法可以参考 MQM 官方资料，团队可以按项目需要裁剪。

**怎么填变量**：[风格要求] 和 [术语表] 有的话一定要贴，否则「术语」和「风格」两类错误无法判断。[文本类型与用途] 决定严重程度的标准：同样一个漏译，在药品说明书里可能是严重错误，在营销文案里可能只是主要错误。

**常见问题与调整**：
- 标注太严苛 → 追问：「只保留严重和主要错误，次要的问题合并说明。」
- 想比较多份译文 → 对每份译文分别评估，并使用相同的权重和标准，再比较分数。
- 机器翻译的译后编辑 → 可以先用本站「翻译腔怎么改」润色，再用这条评估质量。
