**怎么填变量**：[子图清单] 按「A｜Western blot 条带｜图片｜重要」这样一行一个写，AI 才能判断谁该放大、谁该放补充材料。

**追问技巧**：拿到网格草图后，可以说「C 和 D 要直接对比，请上下对齐并共用 x 轴」；也可以追问「这张图放到 PPT 汇报里要怎么拆成 3 页」。

**适合模型**：通用大模型均可。

> 图像类数据（如电泳条带、显微照片）的裁剪与调整须遵守期刊图像完整性规定。

### 示例输出

> 示例，仅供参考

```
+-------+-------+-------+
|   A   |   B   |   C   |
|       +-------+-------+
|       |       D       |
+-------+-------+-------+
|   E   |   F   |   G   |
+-------+-------+-------+
```

A 跨两行（主结果），D 跨两列。

```python
fig, axd = plt.subplot_mosaic("ABC;ADD;EFG", figsize=(183/25.4, 140/25.4))
```

规范：标号 8 pt 加粗，统一放在各子图左上角外侧。
