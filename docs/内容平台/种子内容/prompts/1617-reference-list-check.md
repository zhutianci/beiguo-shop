  检查项目：
  1. 字段完整性：逐条检查作者、年份、题名、期刊或出版者、卷期页码、DOI 等是否缺失；缺失的字段用「【缺】」标出。
  2. 格式一致性：作者姓名写法（全名/缩写、名在前/姓在前）、大小写、斜体要求、标点、期刊名是否缩写、DOI 写法是否统一。
  3. 正文与列表对应：正文引用了但列表中没有的、列表中有但正文没引用的、作者或年份对不上的（如正文写 2019、列表写 2020），全部列出。

  5. 核实途径：为每条文献给出建议的核实方式（用 DOI 在 doi.org 解析、在 Google Scholar / Web of Science / PubMed / 知网中检索题名），尤其提醒：凡是由 AI 工具生成或推荐的文献，都必须逐条找到原文。

**为什么要强调核实**：大模型可能生成看起来完全正常、实际上并不存在的文献（作者、题名、期刊都像真的）。这条提示词的定位是「格式与一致性检查员」，它会把缺失字段标【缺】而不是补上——自己补上的信息如果是猜的，比缺失更危险。

**怎么填变量**：[引用格式] 写具体版本，GB/T 7714 和 APA 对作者数量、「et al.」的使用规则不一样。[粘贴正文引用] 可选但很有价值，正文与列表对不上是最常见的退修原因之一。

**常见问题与调整**：
- 列表太长一次检查不完 → 分批贴，每批 20–30 条，最后再整体检查正文对应关系。
- 想批量统一格式 → 更可靠的做法是把文献导入 Zotero、EndNote 等管理工具，选择对应的引用样式自动生成；AI 适合检查工具生成后的残留问题。
- 格式转换可以用本站「参考文献格式转换提示词」。
