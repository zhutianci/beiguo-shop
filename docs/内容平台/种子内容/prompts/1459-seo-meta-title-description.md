**怎么填变量**：[页面内容要点] 要写页面上真实有的东西，例如「对比了 8 款入门咖啡机，含价格和优缺点表」，AI 才能写出准确又具体的标题。[标题长度] 和 [描述长度] 可以参考搜索引擎官方文档和你常用的 SEO 工具的建议值填写。

**常见坑**：
- 所有页面用同一套标题模板，只改一个词，搜索引擎和用户都分不清页面差别；
- 标题里塞进三四个关键词（「咖啡机推荐_咖啡机品牌_咖啡机价格」），可读性差，也不符合搜索引擎指南；
- 描述写得很诱人但页面里没有对应内容，用户点进来马上离开，反而伤害表现。

**迭代追问**：「为这 20 个产品页设计一个能体现各自差异的标题模板」「检查我现有页面的标题，找出重复和过长的」「把这些标题改写成适合社交平台分享卡片的版本」。
