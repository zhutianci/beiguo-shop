**怎么填变量**：[分段内容] 剪辑完后看一遍时间线，按「几分几秒 + 讲了什么」记下来，章节时间轴会非常准确，观众体验也好很多。[UP主风格] 会影响标题的语气，严肃干货类标题就不要硬加梗。

**常见坑**：
- 标题和封面都在卖关子，点进去发现内容很浅，B 站观众会直接在评论区和弹幕里吐槽；
- 恰饭视频不说明，一旦被发现，口碑损失远大于广告收入；
- 简介里什么都没写，观众想找视频里提到的资料还得在评论区问。

**迭代追问**：「把这期视频的内容整理成一篇专栏文章」「根据弹幕里的高频问题，写一条补充动态」「为这个系列想 3 个统一格式的标题模板」。
