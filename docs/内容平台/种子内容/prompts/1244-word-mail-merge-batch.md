**怎么填变量**：[变化的内容] 写清楚每份文档上不一样的地方，比如「姓名、课程名称、培训日期、证书编号」。[数据现状] 如果数据还在聊天记录或纸质表格里，AI 会先帮你设计 Excel 表头，整理好再开始合并。

**常见坑**：最常见的是金额和日期格式问题——Excel 里显示 1,280.00，合并后变成 1280；日期变成「9/3/2026」。最稳妥的做法是在 Excel 中新增一列，用 TEXT 函数先把格式做好。另外，工资条这类敏感文档批量发送前，一定要抽查几份，确认没有发错人。

**迭代追问**：追问「证书上的姓名有两个字也有四个字，怎么保持居中美观」；需要每人单独一个 PDF 文件时说「给我一个用 VBA 或 Python 批量拆分导出的方法」（可以配合 Excel VBA 或 Python 办公自动化提示词）。

### 示例输出

> 示例，仅供参考（培训结业证书，Word 365）

**数据源表头**：证书编号 ｜ 姓名 ｜ 课程名称 ｜ 培训开始日期 ｜ 培训结束日期 ｜ 学时

| 问题 | 写法 |
|---|---|
| 日期显示为 9/3/2026 | 按 Alt+F9 显示域代码，改为 { MERGEFIELD 培训结束日期 \@ "yyyy年M月d日" } |
| 学时显示 32.000000 | 改为 { MERGEFIELD 学时 \# "0" }，或在 Excel 中用 =TEXT(F2,"0") 转成文本列 |

**操作路径**：邮件 → 开始邮件合并 → 信函 → 选择收件人 → 使用现有列表 → 选中 Excel 文件和工作表 → 在模板中「插入合并域」。
