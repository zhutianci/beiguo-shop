prompt: |
  你是一位专职的会议引导师。请为我准备一份主持人手卡，上面全是可以直接照着说的话，不要讲理论。

  会议目的与必须产出的结果：[会议目的与产出]
  议题与总时长：[议题与时长]
  参会人（角色、彼此的关系、谁话多谁话少、谁有决定权）：[参会人情况]
  我在会上的身份（主持兼参与者 / 纯主持 / 职级低于多数参会者）：[我的身份]
  本次会议的决策方式（负责人决定 / 协商一致 / 表决）：[决策方式]
  会议形式（线上 / 线下）：[会议形式]

  手卡包含以下部分：
  1. 开场 90 秒（逐字稿）：这次会要决定什么、几点结束、今天不讨论什么；宣布三条规则——一次一人发言、与议题无关的内容记入「停车场」会后处理、每个议题结束前要有结论或明确的下一步。说明我作为主持会打断，请大家谅解。
  2. 议题卡。每个议题一张：目标（讨论 / 决定 / 告知）、分配的分钟数、一个开启讨论的问题、一个推进到收敛的问题、到时间时的提醒句。议题时间之和不得超过总时长的 85%，超了就指出该删或移到会后的议题。
  3. 控场话术，每种状况给 2 句，礼貌而明确：
     - 跑题：肯定其价值，记入停车场，拉回当前议题。
     - 一人长时间发言：在其换气处插入，概括他的观点，再把话交给别人。
     - 两人争执不下：把双方观点各用一句话复述，指出分歧点，问「需要什么信息才能判断」，必要时请有决定权的人裁定或会后小范围解决。
     - 无人回应：换成更具体的问题；让大家先各自写两分钟再轮流说；线上则请大家在聊天框打字。
     - 请安静的人发言：点名时给台阶，如「小周，这块你接触得最多，想听听你的观察」，不问「你有什么意见吗」；允许对方说「暂时没有」。
     - 超时：给出「再给 5 分钟 / 会后解决 / 现在定」三选一，当场决定。
  4. 收敛。从「讨论」转到「决定」的 3 句过渡语；确认结论的句式：「我复述一下，我们决定……，由谁在什么时间前完成，对吗？」；无法达成一致时如何记录分歧和下一步。
  5. 收尾 2 分钟（逐字稿）：逐条复述结论和待办（事项、负责人、截止日期），过一遍停车场事项的处理人，说明纪要何时发出。
  6. 按我的身份给一条提醒：主持兼参与者要区分「主持人的话」和「我个人的观点」；职级较低时借议程和时间来打断，而不是靠个人权威。

  要求：所有话术对事不对人，不讽刺、不让人当众难堪；不替我编造议题和参会人；线上会议补充静音、举手、聊天框的使用约定。

**怎么填变量**：[会议目的与产出] 写成会后能检查的结果，如「定下下个版本做哪 3 个需求」，而不是「讨论下个版本」。[参会人情况] 写清谁爱长篇发言、谁从不开口、谁拍板，手卡里的话术会对应到人。[我的身份] 很关键：职级比参会者低的主持人，打断别人要借「时间」和「议程」的名义。

**常见失败与调整**：
- 开场不说规则，中途想打断就显得突兀。开头先说明「我会打断」，后面拉回跑题才名正言顺。
- 讨论热烈但没有结论。每个议题结束前都要说出「我们决定了什么、谁、什么时候」，没说就等于没定。

### 示例输出

> 示例，仅供参考（虚构：产品经理小郭主持 60 分钟的需求评审会，8 人参加，线下）

**开场（节选）**
「谢谢大家准时到。今天这个会要定一件事：下个版本做哪 3 个需求。我们 11 点整结束。今天不讨论具体的交互方案，那个放到周四。说三条规则：一次一个人讲；跟今天无关的问题我会记在白板右边的停车场，会后处理；每个需求讨论完要有『做、不做、待定』的结论。时间紧，我可能会打断大家，先说声抱歉。」

**控场话术（节选）**
- 跑题：「这个问题很重要，但不属于今天要定的范围，我先记到停车场，会后我来约时间。我们回到需求 A。」
- 一人长时间发言：「老秦，我打断一下。你的意思是性能风险要先评估，对吗？我记下了。小周，这块接口是你在维护，想听听你的判断。」

**收尾（节选）**
「我复述一下结论：A 做，小周周五前给出工作量；B 不做；C 待定，等老秦周三的性能评估。纪要今天下班前发到群里。」
