**怎么填变量**：[售后政策] 越详细越好，尤其是「哪些情况运费由店铺承担」「客服最多可以补偿多少」，这决定了话术能给出什么方案。[常见售后问题] 可以从售后工单的分类统计里直接粘贴。

**常见坑**：
- 一上来就解释「这不是我们的问题」，买家情绪更大；
- 只说「我们会尽快处理」，不给具体时间，买家只能反复来问；
- 用「给个好评就补偿你」换好评，违反平台规则，也可能被认定为诱导评价。

**迭代追问**：「把话术库整理成表格，方便导入客服系统」「为大促后的售后高峰写一份简化版处理流程」「根据这批售后工单，统计问题类型并给出减少售后的改进建议」。

### 示例输出

> 示例，仅供参考（虚构：家居用品店，质量问题场景）

**话术**：「真不好意思，收到的杯子有裂纹，换谁都会不开心。麻烦您拍一张裂纹的照片和外包装的照片发给我，我马上给您登记。您看是想重新发一个新的，还是直接退款呢？选好后我今天内就给您处理。」

**处理要点**：有照片凭证的质量问题，客服可直接补发或全额退款，无需买家退回；同一订单第二次出现质量问题，升级给主管并记录批次号。
