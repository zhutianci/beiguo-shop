**怎么填变量**：[四季] 可以换成"十二星座里的四个""春日花园""海洋"；四件首饰的款式分别改，例如把春换成"铃兰胸针"、冬换成"雪花耳钉"；主石写"某某质感的晶体"比直接写宝石名更不容易出现奇怪的切工。只想要一件，就保留对应的那一条并把画幅改成 1:1。

示例图第一张是俯拍陈列：左边丝绸上是一对粉紫色花瓣耳环，中间是一颗泛着彩虹光的水滴吊坠，旁边木托盘上放着橙红枫叶戒指，右边是银色雪花吊坠靠在透明亚克力块上，底下铺着向日葵花瓣。第二张是同一提示词的另一种结果：四件水滴形吊坠并排，分别封着粉色花枝、向日葵、红枫和雪花，顶部各有一个金色蝴蝶结和对应的花。

**常见问题**：
- 四件挤在一起分不清季节：写"四件从左到右依次排列，每件下方的底材不同"。
- 金属结构不合理（戒圈断开、链子穿模）：加"首饰结构真实可佩戴，戒圈完整，链条连续"。
- 太像插画：强调"真实珠宝的微距摄影，浅景深"。

**适合**：饰品设计提案、手作 / 文创上新预告图、礼盒概念图、小红书种草封面。这是概念图，实际打样时材质与工艺以工厂确认为准。
