**怎么填变量**：[生产能力] 一定要实事求是，比如「1 个人，每周最多 2 期」，栏目更新节奏要能长期坚持。[已有内容] 里如果有某类视频数据明显更好，可以作为栏目方向的依据。

**常见坑**：
- 栏目上线时只准备了一期，第二周就断更，观众的追更习惯根本建立不起来；
- 结构不固定，每期都重新设计，生产效率低，观众也没有熟悉感；
- 栏目名起得太抽象（「灵感时刻」），观众看不出讲什么。

**迭代追问**：「按固定结构写出第 1 期的完整脚本」「为栏目设计一个 5 秒的片头文案和画面」「栏目做了 8 期，数据在下滑，帮我分析并调整」。

### 示例输出

> 示例，仅供参考（虚构：职场类账号的 Excel 栏目）

**栏目名称**：「一分钟表格急救」
**一句话介绍**：每期解决一个让人加班的表格问题，一分钟内学会。

**固定结构**
| 段落 | 时长 | 要点 |
|---|---|---|
| 钩子 | 0–5 秒 | 展示问题表格：「这种表，你是不是还在一个个手动改？」 |
| 演示 | 5–45 秒 | 3 步操作，屏幕录制 + 放大 |
| 总结 | 45–55 秒 | 一句话记住快捷键或公式 |
| 预告 | 55–60 秒 | 「下期：合并单元格怎么快速拆开」 |

**标题格式**：一分钟表格急救 Vol.01｜一键删除所有空白行
