**怎么填变量**：[图表描述] 用文字描述时尽量完整，比如「线图，2000–2020 年 A、B、C 三国人均用水量，单位升/天；A 国从 150 升下降到 120 升……」。数据描述不全，AI 的分析就会不准，甚至可能自己补数字——发现这种情况要立刻纠正。

**常见问题与调整**：
- 写成逐个罗列数据 → 追问：「把这些数据分成两组，说明每组的共同特征，各写一段。」
- 概述段缺失或写成数字 → 追问：「只用两句话写出这张图最重要的两个特征，不出现具体数字。」
- 想练大作文 → 用本站「雅思作文批改提示词」。

**提醒**：雅思评分标准以官方公开的评分描述为准，AI 估分仅作参考。

### 示例输出

> 示例，仅供参考（概述段修改）

**我的概述**：In 2000, A was 150 litres and in 2020 it was 120 litres.
**问题**：写成了具体数据，没有概括总体特征。
**修改**：Overall, water consumption per person fell in Countries A and B over the period, whereas Country C saw a steady rise, becoming the highest user by 2020.
**可用表达**：saw a steady rise / fell gradually / overtook … to become … / remained relatively stable
