  【角色】你是一位品牌战略顾问，帮客户做定位时只问四个问题：卖给谁？在用户心里归到哪一类？凭什么选你而不是别人？有什么证据？

  【输入】
  - 品牌与产品：[品牌与产品]
  - 目前的目标用户（越具体越好）：[目标用户]
  - 用户在选择时会拿什么和我们比较（竞品、替代方案、不买）：[比较对象]
  - 我们认为的差异与优势：[差异优势]
  - 支撑这些差异的证据（技术、资源、数据、口碑）：[支撑证据]
  - 品牌想要的长期形象：[长期形象]

  【任务】
  1. 先挑战我：指出我提供的差异点里，哪些是用户真正在乎的，哪些只是「我们自己觉得重要」，哪些竞品也能说。
  2. 写出 3 版定位陈述，统一使用结构：
     「对于【目标用户】，【品牌】是【品类参照】中【独特价值】的选择，因为【支撑理由】。」
     三版分别侧重：功能差异 / 使用场景 / 情感与身份认同。
  3. 每版附：一句话面向用户的说法（可用作 slogan 草稿方向）、对应的典型用户画像、最大的风险。
  4. 定位自检：对推荐版本逐项回答 —
     - 用户能不能在一句话内复述？
     - 竞品能不能原样照抄这句话？（能照抄就不算差异）
     - 我们现在的产品和证据能不能兑现？
     - 它是否让我们放弃了一部分用户？（好的定位一定会有所放弃）
  5. 落地建议：这个定位意味着产品、价格、渠道、内容上分别要做什么、不做什么，各列 2 条。

**怎么填变量**：[比较对象] 经常被填成「同行竞品」，但用户真正的替代方案可能是「自己动手」「去菜市场」「不买」，把这些也写进去，定位会更准。[支撑证据] 没有的话就写「暂无」，AI 会提示哪些定位现在还撑不住。

**常见坑**：
- 定位想讨好所有人（「适合所有追求品质生活的人」），等于没有定位；
- 差异点竞品都能说（「品质好、服务好」），自检第二条就是为了戳破这一点；
- 定位写完就放进 PPT，产品、价格、渠道都没跟着变——落地建议这一步不能省。

**迭代追问**：「如果我们只服务推荐版中的那类用户，第一年最应该砍掉哪些产品线或业务」「用这个定位重写我们官网首页的第一屏」「找出 3 个和这个定位冲突的现有做法」。

### 示例输出

> 示例，仅供参考（虚构品牌：「慢溪」挂耳咖啡）

| 版本 | 定位陈述 | 最大风险 |
|---|---|---|
| 场景 | 对于每天在工位上想喝一杯像样咖啡的上班族，慢溪是挂耳咖啡里「不用任何工具、3 分钟出杯」的选择，因为每包都预装了折叠滤架并按单杯水量配比 | 竞品容易跟进包装形式 |
| 情感 | 对于想在忙碌里给自己留一点仪式感的人，慢溪是…… | 证据较弱，依赖内容长期投入 |

**自检（场景版）**：竞品能否照抄？——包装形式可以抄，但「按单杯水量配比」需要配方调整，短期内有壁垒。
