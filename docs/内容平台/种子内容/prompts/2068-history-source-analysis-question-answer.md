prompt: |
  我在练历史材料解析题，请按「先判断答案从哪里来，再动笔」的思路带我。你可以帮我读材料、搭结构、挑错，但论点和文字由我自己来写。

  材料（含出处）：[材料与出处]
  设问与分值：[设问与分值]
  年级与学过的相关内容：[年级与所学内容]
  我的答案（可以先不写）：[我的答案]

  一、看设问的提示语，判断答案来源
  「根据材料」「材料反映了」：答案就在材料里，需要提取并概括，不能照抄长句，也不必补充课本内容；
  「根据材料并结合所学知识」：材料信息与课本知识都要用；
  「结合所学知识」：主要靠课本，材料只提供情境；
  「谈谈认识」「得到什么启示」：从史实中引出观点，要有概括性。
  再看设问的关键词是「原因、背景、特点、变化、影响、评价」中的哪一个，以及限定的时间和空间。

  二、读材料
  1. 看出处：时间、作者、文献类型（当时人的记录、后人的研究、官方文件、图片或数据）。出处往往提示了时代背景和立场。
  2. 划关键词，按句号或分号分层，每层用自己的话概括成一个短语。
  3. 材料是文言文时，先帮我疏通大意，有歧义的地方请说明。
  读完请我先说出每层的概括，你再订正。

  三、作答与检查
  请我作答，然后逐点检查：
  - 来源对不对：该提取的地方有没有去抄课本，该结合所学的地方有没有只抄材料；
  - 是否论从史出：每个结论后面有没有依据；
  - 表述是否有历史感：有没有交代时间和主体，有没有用今天的标准苛求古人，评价是否兼顾积极作用与局限；
  - 要点个数是否与分值相称。

  四、小论文题（题目要求「自拟论题」「加以论述」时使用）
  帮我搭三段结构，内容由我来填：
  论点：一个明确的判断句，来自材料，范围不要过大；
  论据：2–3 条史实，每条写成「时间 + 事件 + 它怎样证明论点」，最好来自不同的方面或不同的阶段；
  结论：回扣论点，可以点出局限或启示，不要重复论点原话。
  我填好后，你检查史实是否准确、是否紧扣论点、有没有只罗列不分析。

  约束：史实（时间、人物、事件、因果）必须准确，你拿不准的地方请标出「需对照课本」，不要编造；课本上没有的学术观点不必引入；不对现实政治作延伸评论。

**怎么填变量**：[材料与出处] 材料后面括号里的出处一定要一起贴，如「——摘编自某某《中国近代史》」；[设问与分值] 原样照抄，「根据材料」和「结合所学」差几个字，答法完全不同；[年级与所学内容] 写上相关单元名称，AI 不会用你没学过的史实。

**常见问题与调整**：
- 文言史料看不懂 → 追问：「先逐句翻译这段材料，再标出与设问有关的两句。」
- 小论文不会拟论点 → 追问：「不要给我论点。请问我三个问题，帮我从材料里找到一个可以论证的判断。」
### 示例输出

> 示例，仅供参考（八年级小论文，学生自拟论点「洋务运动是中国近代化的开端」，论据写了：1861 年曾国藩创办安庆内军械所；1872 年轮船招商局在上海成立；洋务运动很有意义）

**论点**：是明确的判断句，范围合适。注意「近代化」在这里主要指学习西方技术、创办近代工业，论据要往这上面靠。

**论据检查**

| 你的论据 | 史实 | 是否证明论点 |
|---|---|---|
| 1861 年曾国藩创办安庆内军械所 | 准确 | 只摆了事件。请补一句：它是洋务派创办的第一个近代军事工业，说明开始引进西方技术 |
| 1872 年轮船招商局在上海成立 | 准确 | 可以补：它属于民用企业，说明洋务运动由「自强」扩展到「求富」，与上一条不在同一方面，搭配得好 |
| 洋务运动很有意义 | 不是史实 | 属于空泛评价，请换成一条史实，例如教育方面（京师同文馆等新式学堂） |

**结论提示**：可以点出局限——没有使中国走上富强道路，甲午中日战争中北洋舰队全军覆没；但它在客观上起到了什么作用？请你用自己的话写。
