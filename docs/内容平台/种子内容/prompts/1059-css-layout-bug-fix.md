**怎么填变量**：[相关的 HTML 结构] 尽量精简到能复现问题的最小片段，并且一定要带上父元素和祖先元素的样式，很多问题（比如 z-index 不生效）根源在祖先元素上。截图无法直接贴时，用文字描述「哪个元素在哪里、应该在哪里」。

**常见坑**：
- 弹窗被遮住时不断调大 z-index，改到 99999 也没用。原因通常是它的某个祖先元素创建了层叠上下文，在这个上下文里再大的 z-index 也无法超过外面的元素。
- flex 布局中，长文本或长链接把子项撑宽，加了 overflow 也不生效，因为 flex 子项默认的最小宽度是内容宽度，需要设置最小宽度为 0。
- 用 `100vh` 做全屏高度，在手机浏览器中会被地址栏遮住一部分，可以考虑新的动态视口单位（注意浏览器兼容性）。

**追问技巧**：修复后追问「这个修改在 Safari 和旧版浏览器中是否有兼容问题」，或「把这个布局改成响应式：桌面三列、平板两列、手机一列」。

### 示例输出

> 示例，仅供参考（现象：卡片中的长文件名把卡片撑宽，右侧按钮被挤出容器）

**原因**：`.file-name` 是 flex 容器的子项，flex 子项的最小宽度默认等于其内容的宽度，所以长文件名无法收缩，`text-overflow: ellipsis` 也不会生效。

```css
.card { display: flex; align-items: center; gap: 8px; }
.file-name {
  flex: 1;
  min-width: 0;              /* 关键：允许子项收缩到比内容更窄 */
  overflow: hidden;
  white-space: nowrap;
  text-overflow: ellipsis;
}
.card button { flex-shrink: 0; }   /* 按钮不被压缩 */
```

Tailwind 写法：`<span class="flex-1 min-w-0 truncate">`，按钮加 `shrink-0`。

**验证**：在开发者工具中选中 `.file-name`，查看「计算样式」中的 min-width，修改前为 auto。
