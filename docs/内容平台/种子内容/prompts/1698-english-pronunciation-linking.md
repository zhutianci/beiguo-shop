**为什么先说明「AI 听不到」**：纯文字对话时，AI 无法判断你实际读得对不对，它能做的是讲清规则和设计练习。如果你使用的是支持语音对话的 AI 应用，可以让它听你读一遍，但发音评价仍然仅供参考，最好结合录音自查和老师反馈。

**怎么填变量**：[练习文本] 可以选你最常说的自我介绍、工作中常用的句子，练了马上能用。[方言背景] 有些发音问题和母语方言有关，写上会让练习更有针对性。

**常见问题与调整**：
- 标注太密看不清 → 追问：「每句只标重音和连读，其他现象下一轮再练。」
- 想提升听力 → 很多「听不出来」的词，正是连读弱读后的样子，可以接着用本站「影子跟读材料生成提示词」和「四六级听力错题分析提示词」。

### 示例输出

> 示例，仅供参考（I want to check it out.）

**标注**：I WANT to CHECK‿it‿OUT. ↘
- want to 在口语中常弱化为接近 /ˈwɑːnə/（美式口语中常写作 wanna，正式书面不用）；
- check it out 三个词连读，听起来像一个词 che-ki-tout；美式发音中 it 末尾的 /t/ 夹在两个元音之间，常发成闪音，听起来更接近 che-ki-dout。

**最小对立词对（th 练习）**：think / sink；thank / sank；mouth / mouse
发音要点：/θ/ 舌尖轻放在上下齿之间，送气，声带不振动；/s/ 舌尖不伸出。
