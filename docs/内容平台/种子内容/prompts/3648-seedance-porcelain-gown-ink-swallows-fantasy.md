**时长与镜头**：15 秒三个镜头，每个镜头都写清"机位—动作—效果"三件事，这是特效类提示词最好用的格式：机位管怎么拍，动作管人做什么，效果管特效怎么变。三个镜头的机位从"低角度仰拍"到"面部特写"再到"高空俯拍旋转"，景别大开大合，节奏感很强。

**怎么填变量**：[青花瓷] 可以换成"流动的金箔""液态翡翠""冰裂纹汝瓷"；[水墨燕子] 换成"红色锦鲤""金色蝴蝶""宣纸折的仙鹤"；[天空之镜盐湖] 换成"雪原""黑色火山沙滩"。保持"材质礼服 → 一个动作触发 → 化为群体生物 → 世界溶解"的四步。

**常见失败与调整**：
- 礼服看起来像普通印花布：强调"坚硬、反光的瓷器质感，走动时有陶瓷碰撞声"。
- 燕子散开后模特消失或换人：第二段写"模特本人保持站立，只有礼服化为燕子"，并穿上一层"白色紧身打底"避免裸露。
- 溶解段太乱：缩短到 3 秒，或单独生成。
