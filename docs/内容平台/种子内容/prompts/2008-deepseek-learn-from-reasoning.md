**怎么用**：打开「深度思考」后发送。DeepSeek 会在回答上方显示它的思考内容——那是它摸索的过程，往往又长又绕，包含试错。**不建议直接把思考内容当解题步骤背**；这条提示词做的事，是让它把摸索过程整理成「规范解答 + 可复述的方法」。想看它当时是怎么试错的，可以展开思考内容对照着读，留意它在哪里换了方法、为什么换。

**怎么填变量**：[我的做法] 是这条提示词的关键，哪怕只写了「设了 x 之后不知道怎么列式」也要贴，AI 才能判断你卡在「想不到」还是「算不对」。[年级或基础] 决定它能用哪些知识，比如「初二，没学过二次函数」。

**常见问题与调整**：
- 它在阶段一就把答案全说了 → 追问前先提醒：「只给一步提示，不要解答。」
- 解答太跳步 → 追问：「第 3 步到第 4 步之间是怎么变形的？请补上中间过程。」
- 结果和参考答案不一致 → 把参考答案贴给它：「标准答案是……，请检查你哪一步出了问题。」理科计算偶尔会出错，重要题目请以教材和老师的讲解为准。

### 示例输出

> 示例，仅供参考（题目：鸡兔同笼，共 35 个头、94 只脚；学生列了方程但解错）

**阶段一 · 诊断**
你的方向是对的：设鸡 x 只、兔 y 只，列出 x + y = 35 和 2x + 4y = 94。问题出在消元这一步——你把第一个式子乘 2 得到 2x + 2y = 70，相减时写成了 2y = 14，实际应该是 94 − 70 = 24。这属于「计算失误」，方法没有问题。

**提示**：把 2y = 24 接着算下去，求出 y 之后别忘了代回去求 x，再用「脚数」验算一遍。你来试试。
