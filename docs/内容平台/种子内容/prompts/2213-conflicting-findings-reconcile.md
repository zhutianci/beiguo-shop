  【角色】你是一位方法学功底扎实的综述作者。面对相互矛盾的研究，你不急着判断谁对谁错，而是先问：它们测的是同一件事吗？
  【输入】
  - 存在分歧的问题：[分歧问题]
  - 各项研究的要点（每篇含代号、样本与人群、自变量与因变量怎么测、研究设计、主要结果与效应方向）：[各研究要点]
  - 我自己的研究打算做什么：[我的研究计划]
  - 这段文字的用途与篇幅：[用途与篇幅]
  【任务】
  1. 先把各研究按结论方向分组（支持、不支持、混合或有条件），列出分组表。
  2. 逐层对比，找出各组之间系统性的差别：
     - 人群与样本：年龄、基线水平、样本量与统计功效、抽样方式；
     - 概念与测量：同一名称的变量是否用了不同量表或操作定义，测的是短期还是长期结果；
     - 研究设计：实验还是相关研究、对照条件是什么、干预强度与时长、是否控制了关键混杂；
     - 情境：国家地区、时间、实施条件；
     - 分析：效应量大小而不仅是显著与否、是否做了多重比较、是否存在选择性报告的迹象。
     每一层写清：哪些研究在这一点上不同，这种不同是否与结论方向对应。
  3. 提出 2–4 个可以解释分歧的假说（例如「效应只在基线水平低的人群中出现」「短期有效而长期消退」），每个假说标注：支持它的研究、与它不符的研究、还需要什么数据才能检验。
  4. 判断分歧的性质：是真正的结论相反，还是效应量大小不同但方向一致，或只是「显著」与「不显著」的差别（后者可能只是功效问题）。
  5. 写一段综述文字：先客观陈述两方面证据，再给出最有依据的解释，最后指出尚未解决的问题；用限定语表达不确定性。
  6. 如果我提供了研究计划，指出我的研究可以怎样设计来直接检验其中一个假说。
  【约束】
  - 只依据我给的研究要点；不补充其他文献，不编造效应量。信息不足的对比项写「要点中未提供」。
  - 不以「多数研究认为」这种数票的方式下结论。
  - 综述段落里的引用用我给的代号，由我替换为正式引用。

**怎么填变量**：[各研究要点] 是这条提示词的全部依据，每篇至少写清四样：谁（样本）、怎么测（量表或指标）、怎么做（设计与时长）、结果（方向与大小）。例如「S3：大学生 120 人，随机对照，干预 4 周，用自编问卷测学习投入，干预组更高，d = 0.21」。只写「S3 发现有效」是不够的。可以先用文献矩阵提示词把要点整理出来再贴过来。

**常见失败与调整**：
- 模型得出「需要更多研究」这种放之四海皆准的结论。追问第 3 步，要求每个假说都点名支持与不符的研究。
- 把「不显著」直接当成「无效」。让它专门输出各研究的样本量和效应量，看是不是功效不足。
- 综述段落明显偏向一方。要求「先用相同的篇幅陈述两方面证据，再给解释」。

**追问**：「把候选解释整理成一张调节变量表，列出每个调节变量在各研究中的取值」「按第一个假说，帮我想三个可以写进研究假设的表述」。

### 示例输出

> 示例，仅供参考（虚构：课堂使用平板电脑是否提高学习成绩，研究代号 S1–S5）

| 层面 | 支持组（S1、S2） | 不支持组（S3、S4） | 是否与结论对应 |
|---|---|---|---|
| 干预时长 | 一学期以上 | 4–6 周 | 是 |
| 成绩测量 | 教师自编单元测验 | 标准化统考 | 是 |
| 设计 | 准实验，无随机分配 | 随机对照 | 是 |
| 学段 | 小学 | 小学、初中 | 否 |

**候选解释**：一是测量差异——自编测验与教学内容贴合，更容易检出效果，而标准化考试覆盖面广；支持这一解释的是 S1–S4，S5 两种测量都用了，要点中未提供分项结果，是关键的待查信息。二是设计差异——支持组均无随机分配，不能排除教师自选带来的偏差。

**综述段落（节选）**：现有研究对这一问题的结论并不一致。采用教师自编测验且干预持续一学期以上的研究报告了正向效果（S1、S2），而采用随机对照设计和标准化考试的研究未观察到差异（S3、S4）。这一分歧可能更多反映了测量工具与研究设计的不同，而不是干预效果本身的不稳定……
