**怎么填变量**：[目标岗位与年限] 影响难度，写成「中级前端，3 年经验」这样即可。[主攻框架与版本] 写你实际在用的，例如「React 18」或「Vue 3」，AI 会按这个版本的机制来问。[想练的范围] 一次选一两项效果更好，范围太大每个点都只能浅问。[相关项目] 填了之后，追问会往你的项目上引。

**常见问题与调整**：
- AI 一次把题目和答案全给了 → 追问：「请回到规则 1，一次只出一道题，等我回答后再继续。」
- 追问太浅 → 追问：「这一题请再往下追问一层，问到实现机制为止。」
- 想换成另一种练法 → 追问：「改成我来讲一个知识点，你扮演面试官不断打断提问。」

### 示例输出

> 示例，仅供参考（3 年经验，React 方向，范围选「渲染机制」，第 1 题节选）

**面试官**：看这段代码，点一次按钮后，控制台打印什么？按钮上显示几？为什么？

```jsx
function Counter() {
  const [n, setN] = useState(0)
  const onClick = () => {
    setN(n + 1)
    setN(n + 1)
    console.log(n)
  }
  return <button onClick={onClick}>{n}</button>
}
```

**我**：打印 0，显示 2，因为 setState 是异步的。

**面试官（追问）**：先不说对错。这次点击里，两次 `setN` 拿到的 `n` 分别是多少？

**点评（追问结束后）**：结论 2 分，打印 0 说对了，但按钮显示的是 1。原理 2 分，「异步」这个说法不准确：`n` 是本次渲染的快照，两次调用都是 0 + 1；想连加两次，应传入函数 `setN(x => x + 1)`。
