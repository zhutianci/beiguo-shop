prompt: |
  请把我上传的这张生活照做成[一寸]证件照，要求：
  1. 人物身份不变：脸型、五官、肤色、发型保持原样，不要美颜、不要瘦脸、不要改变年龄；
  2. 正脸，双眼平视镜头，表情[自然平静]；头部居中，头顶留少量空白，露出眉毛和双耳；
  3. 服装换成[深色西装配白衬衫]，领口整齐对称；
  4. 背景为纯色[白色]，均匀无渐变、无阴影、无杂物；
  5. 光线为正面柔光，脸部两侧亮度均匀，眼镜和额头不反光；
  6. 竖版构图，人像约占画面三分之二，不加任何文字、边框或水印。

verify:

  - gpt-image-2 当前可选的画幅比例（以 OpenAI 官方帮助文档为准），能否直接输出接近 5:7 的证件照比例
  - 一寸 / 二寸照常用像素尺寸，写进正文前找一个权威来源核对

**怎么填变量**：[一寸] 可换成"二寸""小二寸"；[白色] 建议写具体颜色，例如"浅蓝色"，比"蓝底"更稳定；[深色西装配白衬衫] 可改成"白色衬衫""校服"等。

**常见失败与调整**：
- 脸被美化或"换了个人"：在第 1 条后追加"与原图逐一对比五官，不得改变"，再重新生成；原图越清晰、越正脸，成功率越高。
- 头顶或耳朵被裁掉：强调"头顶到画面上沿留出约一成空白"。
- 尺寸不对：AI 输出的像素尺寸不一定符合证件规格，生成后用修图工具按需要的尺寸裁剪。

**适合 / 不适合**：适合简历、内部工牌、非官方报名表。身份证、护照、签证等正式证件通常要求未经修饰的真实照片，AI 生成的照片可能不被接受，请以办理机构的要求为准。
