prompt: |
  我想设置 ChatGPT 的自定义指令（Custom Instructions），请帮我写一份适合我本人的。不要直接给通用模板，先了解我。

  我的套餐对应的字符上限：[字符上限]
  我主要用 ChatGPT 做的事：[主要用途]

  第一步：采访
  向我提 8 个问题，一次列完，等我回答。问题应覆盖：
  1. 我的职业、行业和专业程度（决定解释的深浅）；
  2. 最常让你做的三类任务；
  3. 我喜欢的回答长度和结构（先结论还是先过程、要不要分点）；
  4. 语言习惯（简体中文、是否保留英文术语、称呼）；
  5. 最让我反感的回答方式（举一个真实例子）；
  6. 不确定的时候希望你怎么做（直接说不知道、给出把握程度、还是先问我）；
  7. 涉及代码、数据、引用时的固定要求；
  8. 有没有只在某类任务里才适用的习惯。

  第二步：生成指令
  根据我的回答输出可直接粘贴的指令文本，要求：
  - 用简短的陈述句，一行一条；
  - 分两块：「关于我」（帮助你理解我的背景）和「回答方式」（我希望你怎么回答）；
  - 只写会改变你回答方式的内容，客套话和人人适用的常识不写；
  - 只在特定任务适用的习惯，写成「当……时，……」的条件句，避免影响其他对话；
  - 不要写入我的真实姓名、手机号、住址、账号等隐私信息；
  - 全文不超过我给的字符上限，并在末尾告诉我实际用了多少字符。

  第三步：补充建议
  - 我的偏好里，哪些其实更适合用设置里的「个性」预设或「特征」开关（如语气冷暖、表情多少、标题列表多少）来调，而不是写进指令；
  - 哪些要求只属于某一个长期任务，更适合放进对应的项目（Projects）指令；
  - 给 3 个测试问题，用来检验新指令是否生效。

**先知道三层设置各管什么**（据 OpenAI 帮助中心，详见本站「ChatGPT 自定义指令怎么设置」教程，资料核对于 2026-10-10）：自定义指令是写给 ChatGPT 的长期说明——你是谁、希望它怎么回答；「个性（Personality）」是整体语气预设；「特征（Characteristics）」可以单独微调温度感、热情程度、标题与列表多少、表情多少。入口在 设置 → 个性化，需要先打开「启用自定义」。字符上限按套餐不同，具体数字见上述教程，以官方说明为准。

**所以有些话不必写进指令**：「少用表情」「别那么热情」「少分点」这类偏好，直接调特征开关更省事，也不占字数。提示词的第三步会帮你分出来。

**怎么填变量**：[字符上限] 填你的套餐对应的数字；不确定就填 1500，生成的内容在任何套餐下都放得进去。[主要用途] 写两三件最常做的事，如「写周报、查 Excel 公式、改英文邮件」。采访里第 5 题请举真实例子，例如「我问一个公式，它先讲了三段原理」。

**常见问题与调整**：
- 设了之后所有回答都变得很短 → 把「回答简短」改成条件句：「当我问事实性问题时，先用一两句话直接回答；当我要求写文档时，按任务需要的篇幅来写。」
- 指令和某次需求冲突 → 在当次对话里直接说明即可，当前对话中的明确要求会优先。
- 效果不明显 → 检查是否写了太多形容词（专业、严谨、有洞察）。换成可以检查的行为：「给出结论时同时给出依据和把握程度。」

### 示例输出

> 示例，仅供参考（用户：跨境电商运营，常用于数据分析与英文邮件）

**关于我**
- 我做跨境电商运营，熟悉广告投放和 Excel，不熟悉编程。
- 我的英文读写够用，但不地道。

**回答方式**
- 用简体中文回答；专业术语保留英文并在第一次出现时加中文解释。
- 先给结论，再给依据；除非我要求，不讲基础概念。
- 当我要 Excel 公式时，直接给公式，再用一句话说明每个参数。
- 当我让你改英文邮件时，给出改后的全文，并单列三处最重要的修改及原因。
- 不确定时直接说不确定，并告诉我可以去哪里核实。

（实际使用时，这里会报告全文的字符数）

**更适合用开关调的**：「不要表情」「少用标题和列表」——在特征里调低即可。
