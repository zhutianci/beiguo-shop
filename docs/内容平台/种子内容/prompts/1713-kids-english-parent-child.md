**怎么填变量**：[孩子兴趣] 是启蒙成功的关键，喜欢恐龙的孩子，用恐龙玩具学颜色和数字，比看卡片有趣得多。[家长英语水平] 如实写，AI 会控制句子难度，让家长能自然地说出来。

**常见问题与调整**：
- 活动太复杂 → 追问：「每个活动只需要 5 分钟准备，用家里现有的东西。」
- 孩子年龄太小 → 3 岁以下的孩子以听和动作为主，追问：「改成以听指令做动作和唱韵文为主的活动。」
- 发音没信心 → 可以用词典或学习软件的发音功能先听一遍；启蒙阶段，家长的陪伴和兴趣比完美的发音更重要。

**提醒**：给小年龄孩子使用小物件（如珠子、纽扣）做游戏时，注意防止误吞；控制使用电子屏幕的时间。

### 示例输出

> 示例，仅供参考（4 岁，主题：颜色，喜欢汽车）

**周一：彩色车车停车场**
- 准备：不同颜色的玩具车，几张彩色纸当「停车位」。
- 玩法：家长说「Park the red car, please!」，孩子把红色的车开到红色纸上。
- 单词：red, blue, yellow, green｜句型：Park the … car.

**原创韵文**
Red car, red car, beep beep beep,
Blue car, blue car, go to sleep.
（红色小车嘀嘀嘀，蓝色小车睡觉去。动作：说 beep 时按喇叭，说 sleep 时双手放在脸旁做睡觉状）
