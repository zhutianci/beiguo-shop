**怎么填变量**：[候选关键词] 尽量来自广告报告中真实产生过点击和订单的搜索词，比关键词工具里的猜测更可靠。[长度上限] 请查 Seller Central 当前说明，注意它可能按字节而不是字符计算。

**常见坑**：
- 把标题里已有的词再重复填一遍，浪费有限的长度；
- 填了竞品品牌名，可能导致 Listing 被投诉或搜索词失效；
- 用逗号分隔还加了很多标点，不同站点的处理方式可能不同，按当前说明填写最稳妥。

**迭代追问**：「根据这份 Search Terms，帮我设计手动广告的关键词分组」「把这份关键词改成西班牙站的版本」「我的产品有新的使用场景，帮我补充相关词」。
