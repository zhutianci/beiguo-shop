> 同时检查 README 中的版权声明 / 免责声明，看是否与 LICENSE 文件冲突。**本文件不是法律意见**，站长上线前请自行判断。

## 一、总体风险提示（必读）

本次用到的仓库**全部是"收录型"仓库**：提示词原本由 X（Twitter）等平台上的第三方作者发布，仓库维护者收集整理后，给整个仓库加上了许可证。
仓库许可证由维护者授予，**维护者未必拥有每条提示词的著作权**，因此仓库许可证不一定能覆盖原作者的权利。本站的应对：

1. 每条都保留原作者和原帖链接，并写明修改内容；
2. 只选短小、偏功能性的提示词，并做了翻译、变量化和较大幅度的改写；
3. 每条的 `verify` 都加了"确认原帖仍可访问、作者未另行声明保留权利"；
4. 原作者提出异议时直接下架。

如果站长希望零风险，可以只上线 `source: null` 的 5 条原创（01、14、22、23、24），其余在核对原帖后再发布。
