**怎么填变量**：[PastelSoft] 换成你的品牌名（英文最稳，中文品牌名可以写"中文宋体细字，字距宽"）。海豚和波浪可以换成与品牌相关的点缀：咖啡店写"一缕上升的热气线 + 一颗咖啡豆"，花店写"一条藤蔓线 + 一朵小花"，摄影工作室写"一道光线 + 一个小光圈"。颜色两处一起改。

示例图是白底上深蓝色的细衬线字"PastelSoft"，字下一条从左到右渐细的淡蓝波浪线，最右侧一只浅水绿色的小海豚跃出波浪，整体非常留白。

**常见问题**：
- 字母拼错或字体变粗：强调"纤细高对比衬线体，逐字准确"。
- 点缀图形太大：写"图形高度不超过字母高度"。
- 正式使用：AI 生成的是位图和方向稿，正式 Logo 需要设计师矢量化，并做商标近似查询。

**适合**：工作室 / 个人品牌 Logo 初稿、社团标志、小程序和公众号头像、名片设计。
