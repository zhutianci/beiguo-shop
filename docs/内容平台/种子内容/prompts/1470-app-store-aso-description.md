**怎么填变量**：[用户与搜索词] 可以从用户访谈、客服记录、应用商店搜索框的联想词中收集；用户实际说的「记账」「花钱记录」和你内部叫的「个人财务管理」往往不一样。字符上限请查阅目标商店的最新规定后填写。

**常见坑**：
- 把标题写成「记账 预算 理财 存钱 账本」这种关键词串，用户看起来不可信，也可能被审核拒绝；
- 描述的前三行在讲公司愿景，用户在折叠前看不到任何有用信息；
- 截图只放界面截图没有标题，用户滑过去也不知道这个功能有什么用。

**迭代追问**：「为英文市场重写一版，并说明关键词选择与中文版的差异」「为 5 张截图写出设计 brief」「根据最近 50 条用户评价，找出值得写进描述的真实优点」。

### 示例输出

> 示例，仅供参考（虚构 App：「小账本」记账，App Store 中国区）

**名称方案**：小账本 - 记账与月度预算
**副标题**：拍小票自动记一笔

**描述前三行**：每天花 10 秒，知道钱都去哪了。小账本可以拍小票自动识别金额，也可以语音记一笔，月底自动生成消费分析。

**截图文案（前 3 张）**
1. 拍一下小票，自动记账
2. 一眼看清这个月花在哪
3. 超出预算前提醒你
