  书名与作者：[书名与作者]

  形式与总时长（线上 / 线下）：[形式与时长]
  我希望大家带走什么：[希望的收获]

  1. 破冰（占总时长约一成）：2 个备选问题，要求每人 30 秒内能答、没读过书也能答、与本书主题有关联。
  2. 讨论题分三层，每层 3～4 题，并为每题配一个追问：
     - 第一层 文本：书里说了什么。针对具体的情节、观点或段落提问，帮大家把内容对齐。
     - 第二层 理解：作者为什么这么写、你同意吗。要有能引出不同意见的题。
     - 第三层 联系：和我们自己的生活、工作有什么关系。从个人经历切入，不要求分享隐私。
     每道题都要是开放式的，不能用「是不是」「对不对」回答；避免「这本书告诉我们什么道理」这类总结式提问。
  3. 时间表：按总时长排出各环节的起止分钟，标出时间不够时可以先砍的题。
  4. 现场应对：冷场、有人长时间发言、跑题、两人争执、有人没读完，各给一句可以直接说的话。
  5. 收尾：一个 5 分钟的结束方式（如每人说一句「我带走的一句话」），以及会后发到群里的简短纪要模板。

**怎么填变量**：[讨论范围与要点] 最重要。把你读书时划的线、章节标题、想讨论的两三个点贴进来，模型据此出题；只给书名的话，它可能凭印象编造情节。[参与者情况] 里「多少人读完了」直接影响题目：读完的人少，第一层题要多带一点内容回顾。[希望的收获] 可以很小，比如「每人愿意去读下一章」。

**常见失败与调整**：
- 题目太大。「你怎么看待自由」没人接得住，改成「主人公在第三章做的那个选择，换作你会怎么选」。
- 所有题都指向同一个「正确理解」。第二层至少留一道可以不同意作者的题。
- 题目里出现了书中没有的情节。这是模型编的，对照原书逐条核对后再用。

> 示例，仅供参考（虚构：某公司读书小组，8 人，线下 90 分钟，共读费孝通《乡土中国》前四篇，领读人已提供要点）

**破冰（8 分钟）**
- 在你老家的村子或小区里，邻居之间互相怎么称呼？

**第一层 文本**
1. 作者用「水波纹」的比喻来说明什么？【待填原文】
   追问：在这个比喻里，圆心是谁？

**第二层 理解**
2. 作者把这种关系格局和「团体格局」对比，你觉得这个对比今天还成立吗？哪里不太一样了？

**第三层 联系**
3. 你在工作中有没有遇到过「先看是谁的事、再决定怎么办」的情况？当时你是怎么处理的？

| 第一层 | 8–30 分钟 | 最后一题可砍 |
| 第二层 | 30–60 分钟 | 重点 |
| 第三层 | 60–82 分钟 | |
| 收尾 | 82–90 分钟 | 每人一句话 |
