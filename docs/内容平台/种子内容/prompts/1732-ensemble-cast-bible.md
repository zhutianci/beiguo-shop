**和「人物小传」有什么不同**：本站「人物小传怎么写提示词」是为一个角色写深度设定；这一条解决的是**一群人之间的差异和关系**——群像故事最常见的问题，是每个角色单独看都挺好，放在一起却分不清谁是谁。

**怎么填变量**：[角色清单] 哪怕只有名字和「沉默的大个子」「爱说话的小姑娘」这种印象也可以。[核心事件] 很重要，角色的差异要在面对同一件事时才能显现出来。

**常见问题与调整**：
- 说话方式还是很像 → 追问：「给每个角色设定一个『绝对不会说的话』，以及一个只有他会用的比喻方式。」
- 角色太多 → 追问：「哪两个角色可以合并？合并后的角色会更有意思吗？」
- 写对话时 → 可以接着用本站「小说对话怎么写：潜台词与人物口吻区分提示词」。

### 示例输出

> 示例，仅供参考（情境：探险队发现一笔不属于他们的钱）

| 角色 | 第一反应 |
|---|---|
| 老周（队长，谨慎） | 「先别碰。谁放在这儿的，比钱多少重要。」——把手电光扫向四周 |
| 阿禾（缺钱，冲动） | 「见者有份吧？」——已经蹲下去数了 |
| 林医生（理想主义） | 「这可能是谁的救命钱。」——看向老周，等他表态 |
| 小满（年纪最小） | 一句话没说，悄悄把这一幕拍了下来 |

**检验结果**：四人反应各不相同；小满的沉默动作埋下了伏笔，值得在后文回收。
