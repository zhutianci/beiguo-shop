**怎么填变量**：[化学计算题] 把题目给的相对原子质量也一起贴上；[年级与已学内容] 如「高一，刚学物质的量和气体摩尔体积，没学物质的量浓度」；[我的解法] 写到哪一步卡住就贴到哪一步，AI 会告诉你问题出在第几栏。

**常见问题与调整**：
- 不会判断过量 → 追问：「把两种反应物都换算成物质的量，除以各自的计量数后比较，演示给我看。」
- 守恒法看不懂 → 追问：「同一道题先按方程式一步步算，再用守恒法算，对比哪几步被省掉了。」
- 初中生想用 → 追问：「不用物质的量，改用质量比按初中的格式写：设、写、找、列、答。」

### 示例输出

> 示例，仅供参考（高一：5.6 g 铁与足量稀盐酸完全反应，生成的氢气在标准状况下的体积是多少？Fe 的相对原子质量为 56）

**桥梁**：物质的量。先把铁的质量换算成物质的量，再通过方程式得到氢气的物质的量。

**第一栏**：n(Fe) = 5.6 g ÷ 56 g/mol = 0.1 mol；盐酸足量，铁完全反应。

**第二栏**：Fe + 2HCl = FeCl2 + H2↑，n(Fe) : n(H2) = 1 : 1。

**第三栏**
设生成 H2 的物质的量为 x。
Fe + 2HCl = FeCl2 + H2↑
1 mol　　　　　　　1 mol
0.1 mol　　　　　　x
x = 0.1 mol
V(H2) = 0.1 mol × 22.4 L/mol = 2.24 L

**第四栏**：标准状况下生成氢气 2.24 L。检查：氢气在标准状况下是气体，可以用 22.4 L/mol。

**易错点**：如果题目改成「常温常压下」，就不能直接用 22.4 L/mol。
