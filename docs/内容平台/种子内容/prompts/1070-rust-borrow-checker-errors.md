**怎么填变量**：[粘贴报错] 要完整复制，Rust 编译器的报错会用箭头标出「这里借用了」「这里又借用了」「借用在这里结束」，这些信息对分析至关重要。[我的水平] 决定讲解深度，初学者模式下会更多解释所有权本身。

**常见坑**：
- 遇到借用报错就加 clone，代码能编译了，但可能在热点路径上复制大量数据，也错过了理解所有权的机会。
- 一遇到问题就上 Rc 加 RefCell，借用检查从编译期推迟到运行期，用错了会在运行时 panic。这是设计上的改变，要想清楚再用。
- 给函数加了一堆生命周期标注试图「骗过」编译器。生命周期标注只是描述引用之间的关系，并不能延长任何值的寿命。

**追问技巧**：追问「给我出两道同类型的小练习，我改完后你来检查」，或「这个结构体如果要在多线程中共享，应该怎么改」。

### 示例输出

> 示例，仅供参考（错误 E0502：遍历 Vec 的同时向它 push）

**报错翻译**：你在 `for` 循环中不可变地借用了 `scores`，循环体内又想可变地借用它来添加元素，同一时间不能既有不可变借用又有可变借用。

| 行 | 操作 | 借用状态 |
|---|---|---|
| 3 | `for s in &scores` | 不可变借用开始，持续到循环结束 |
| 5 | `scores.push(s * 2)` | 需要可变借用，与第 3 行冲突 |

**为什么拒绝**：向 Vec 添加元素可能触发扩容、整个数组搬到新的内存位置，正在遍历的引用就指向了已释放的内存。

**推荐改法**：先收集要添加的元素，循环结束后再追加。

```rust
let extra: Vec<i32> = scores.iter().map(|s| s * 2).collect();
scores.extend(extra);
```
