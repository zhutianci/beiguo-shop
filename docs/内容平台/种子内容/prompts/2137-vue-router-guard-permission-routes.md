**常见问题与调整**：
- 刷新后进了 404 → 追问：「按我的代码检查通配路由的添加时机，以及守卫里添加完动态路由后是否重新导航到了原地址。」

### 示例输出

> 示例，仅供参考（后端返回权限码，前端按权限码过滤路由，守卫节选）

判断流程：公开页直接放行 → 没有令牌则去登录页并带上回跳地址 → 有令牌但路由未加载，先加载并添加，再重新导航 → 其余放行。

```ts
router.beforeEach(async (to) => {
  const user = useUserStore()                 // 在守卫内部获取 store
  if (to.meta.public) return true
  if (!user.token) return { path: '/login', query: { redirect: to.fullPath } }
  if (!user.routesLoaded) {
    const routes = await user.loadRoutes()    // 拉取权限并生成路由记录
    routes.forEach((r) => router.addRoute('layout', r))
    return to.fullPath                        // 重新走一次导航，让新路由生效
  }
  return true
})
```

注意：`loadRoutes` 失败（如令牌过期）时要清掉令牌并跳登录页，否则会在这里反复重试；404 通配路由在动态路由添加完之后再加。
