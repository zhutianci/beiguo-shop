**怎么填变量**：[已掌握的语言] 越具体越好，AI 会用你熟悉的概念来解释新语言，学习速度会快很多。[学习目的] 决定后半段的练习内容：要接手微服务，就多练接口、数据库和并发；要写数据脚本，就多练文件处理和数据结构。

**常见坑**：
- 用旧语言的思维写新语言，例如在 Go 里模仿 Java 的类继承层次、在 Python 里写满 getter 和 setter。对照表和「最容易踩的坑」就是为了避免这一点。
- 只看不写。计划中每天都安排了必须动手的练习，跳过练习的效果会大打折扣。
- 一开始就钻研语言最深的特性。先掌握日常工作中 80% 会用到的部分，深入的特性在遇到时再学。

**追问技巧**：学习过程中可以随时把自己写的练习代码贴回去，说「用新语言的地道写法帮我改写，并说明为什么」；也可以说「今天的检查点，开始考我」。

### 示例输出

> 示例，仅供参考（Java 转 Go，对照表节选）

| 方面 | Java | Go |
|---|---|---|
| 错误处理 | 异常与 try / catch | 返回值中的 error，调用处立即检查 |
| 面向对象 | 类、继承、接口需显式声明实现 | 结构体与组合；接口隐式实现，由使用方定义 |
| 并发 | 线程池、锁、并发包 | goroutine 与 channel，配合 context 取消 |

**最容易踩的坑（节选）**：
1. 为每个结构体先定义一个接口再写唯一实现——Go 中通常直接返回具体类型；
2. 忽略返回的错误，或用 panic 代替返回错误；
3. 启动 goroutine 后不考虑它如何退出，导致泄漏。

**第 1 天**：安装工具链，跑通第一个模块；练习：实现一个读取文件并统计单词频率的命令行程序；自查：`go mod` 的作用是什么？
