**怎么填变量**：[划线与摘录] 可以直接从微信读书、Kindle 的笔记导出里复制，带页码或章节号最好，这样笔记里每个论点都能回查原文。[阅读目的] 决定了行动清单是否有用：「想提升带团队的能力」和「准备读书会分享」得到的笔记重点完全不同。

**为什么强调只依据摘录**：模型对冷门书、新书甚至畅销书的具体内容都可能记错，最常见的是编造书中不存在的案例或引用。用你自己的摘录做材料，笔记才可靠，也更像「你的」笔记。

**版权提醒**：读书笔记是写给自己的。要公开发布（公众号、小红书）时，原文引用保持少量并注明出处，主体用自己的话写。

**迭代追问**：「把这份笔记压缩成 300 字，用于读书会开场分享」「用这本书的观点，分析我现在遇到的这个问题：……」「把论点地图改成思维导图的 Markdown 大纲」。

### 示例输出

> 示例，仅供参考（某本关于习惯养成的书，第 1–3 章）

**核心问题**：为什么下定决心改变往往失败，而微小的习惯能带来长期变化？

**论点 1**：结果来自系统，而不是目标。
- 作者论证：用同一目标下有人成功有人失败的对比说明目标不是区分因素（摘录 P23）。
- 我的复述：大家都想赢，决定输赢的是每天在做什么。

**批判性思考**：书中案例多为成功者回顾，存在幸存者偏差；对需要短期冲刺的任务（如一个月后考试），「只管系统」未必够用。
