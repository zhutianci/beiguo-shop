**怎么填变量**：[熟悉的路线] 用你闭着眼睛也能「走」一遍的地方，比如自己家、每天上学的路、宿舍楼。位置要有固定顺序，数量和要记的项目一样多或更多。[要记的内容] 一次 7–15 项最合适，太多就分成几组放进不同的「房间」。

**常见问题与调整**：
- 画面不够离奇记不住 → 追问：「把第 4、6 项的画面改得更夸张、加上声音或气味。」
- 谐音太牵强 → 追问：「换一个更贴近原词读音、更好笑的谐音。」
- 记住了顺序却不懂内容 → 记忆术适合记「必须准确记住」的内容，对于需要理解的知识，先用本站「费曼学习法提示词」弄懂，再用记忆术记要点。

**复习**：记忆宫殿同样需要复习，可以配合本站「艾宾浩斯复习计划提示词」，在第 1、2、4、7 天各「走」一遍。

### 示例输出

> 示例，仅供参考（记住「马斯洛需要层次」五层，从低到高；路线：家门口 → 鞋柜 → 沙发 → 餐桌 → 冰箱）

1. 家门口（生理需要）：门口堆满了热腾腾的包子，一开门香味扑鼻，你饿得直接咬了一口。
2. 鞋柜（安全需要）：鞋柜变成了一个银色保险箱，上面挂着三把大锁，咔哒咔哒响。
3. 沙发（爱与归属）：沙发上挤满了朋友，大家抱成一团合影。
4. 餐桌（尊重需要）：餐桌上摆着奖杯，所有人起立为你鼓掌。
5. 冰箱（自我实现）：冰箱门一打开，你站在里面的山顶上画完了一幅画。

**自测**：鞋柜上的画面代表第几层需要？
