**怎么填变量**：[真实体验] 是脚本的全部依据，建议在使用期间随手记录，例如「第 3 天发现充电口有点松」「地铁里降噪效果明显，但风大时有风噪」。[来源与合作] 一定如实填写，AI 会在脚本中加入合作说明。

**常见坑**：
- 开箱环节拍太久，观众最想看的「好不好用」到第 3 分钟才出现；
- 缺点写得轻描淡写（「唯一的缺点就是太好用了」），观众一眼识破；
- 拿别的产品做对比时贬低对方，容易引起争议。

**迭代追问**：「把这期测评改成 60 秒的竖屏精华版」「为这期视频写一段 B 站简介和章节时间轴」「根据评论区的追问，写一期补充测评的脚本」。
