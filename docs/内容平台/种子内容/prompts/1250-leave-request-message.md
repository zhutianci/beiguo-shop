**怎么填变量**：[请假原因] 写真实情况即可，比如「孩子发烧需要去医院」，AI 会写成得体的表述；不想透露细节的，可以写「家中有事」。[手头工作] 尽量列全，请假期间最怕的就是某件事到期了没人知道。

**常见坑**：只给领导发一句「我明天请假」，领导第一反应就是担心工作。把交接安排一起说清楚，批假会顺利很多。另一个常见问题是编造请假理由，一旦被发现会严重影响信任。另外，年假、病假、婚假等假期的天数和工资待遇以公司制度和当地规定为准，请假前最好看一下员工手册或问 HR。

**迭代追问**：临时突发请假（比如当天早上生病）时，追问「改成早上 8 点发的紧急请假消息，简短一点」；长假（如产假）可以说「我要休 3 个月，帮我写一份完整的工作交接文档」（可以配合工作交接文档提示词）。
