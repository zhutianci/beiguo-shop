**怎么填变量**：[粘贴游戏文本] 用表格形式最好，尤其要写「上下文说明」——同一个英文单词「Charge」，在技能名里是「冲锋」，在商店里可能是「收费」，在电池图标旁是「充电」。[角色设定] 写清每个角色的性格和说话方式，台词才不会千人一面。

**常见问题与调整**：
- 占位符被改动 → 立刻纠正并要求逐条核对；交付前最好用脚本检查每条译文的占位符与原文一致。
- 界面文字超长 → 追问：「为所有标【超长】的条目给出 3 种更短的译法。」
- 梗翻译不好笑 → 追问：「为这条台词给出 3 个目标语言玩家能懂的替代梗，保持原来的笑点结构。」

**相关**：App 和网站界面的本地化可以用本站「出海本地化翻译提示词」；术语库建立用「翻译术语表提取提示词」。
