**为什么用 example 标签和 3–5 篇**：Anthropic 官方提示词最佳实践认为示例是引导输出格式、语气和结构最可靠的方式之一，建议示例要贴近真实场景、彼此有差异、并用 `<example>` 标签（多个时套在 `<examples>` 里）与指令分开，数量以 3–5 个为宜。样文只给一篇时，模型学到的往往是那篇的题材和结构，而不是作者的风格；几篇题材不同的样文放在一起，共同点才是风格。（资料核对于 2026-10-10）

**怎么填变量**：样文尽量选不同主题、你自己满意的三到五篇，每篇 300–1000 字即可，多了就照格式增加 `<example>` 块。[样文作者说明] 如「我本人，写给同行看的公众号文章」。[要点与素材] 要给实在的内容——事实、数据、你的观点；素材空，风格再像也是空话。

**风格卡值得保存**：确认过的风格卡可以存成一份文档，以后直接贴「按这张风格卡写」，或放进 Claude 项目的指令里长期使用，不必每次重贴样文。

**常见问题与调整**：
- 像是像，但太用力（口头禅每段都出现）→ 追问：「把标志性的说法出现的频率降到和样文差不多，样文里平均多少字出现一次，新稿照这个密度。」
- 风格卡太泛（「语言生动」）→ 追问：「每一条都要有样文原句作证据，没有证据的删掉。」

**使用边界**：请只用于自己的文字，或已获授权的品牌既有内容。不要用它模仿他人的文风去冒充对方发布内容，也不要拿受版权保护的他人作品做样文来生成替代品。

### 示例输出

> 示例，仅供参考（样文为三篇个人公众号短文；风格卡节选）

**句子**：短句为主，常用一个很短的句子单独成段来转折。证据：「但没用。」
**用词**：口语，爱用「说白了」「其实」，几乎不用成语。证据：「说白了，就是没想清楚要给谁看。」
**开头**：从一个具体的小场景切入，不铺垫背景。证据：「周二下午三点，客户把方案退回来了。」
**不会出现的写法**：「在当今快速发展的时代」「综上所述」「让我们一起」这类套话；连续三个以上的排比。

**需要你确认**：样文二用了小标题，另外两篇没有。新稿以哪种为准？
