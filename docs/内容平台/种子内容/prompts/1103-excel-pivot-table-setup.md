**怎么填变量**：[原始数据样例] 直接从表格复制前 5 到 10 行，包括表头。很多透视表问题出在数据源本身，看到样例 AI 才能判断。[想要的报表] 可以画个草图描述「行是什么、列是什么、格子里是什么数」。

**常见坑**：
- 原始数据是「每个月一列」的二维表，直接做透视表，得到的是十二个独立的字段，没法按月份分析。要先转换为一维表（可以用 Power Query 的逆透视）。
- 用计算字段算毛利率时，透视表会先把每行的利润和收入分别求和再相除，这通常就是想要的结果；但如果在原始数据中先算好每行的毛利率再求平均，结果就是错的。
- 日期列中有一个单元格是文本或空白，整列都无法按月分组。

**追问技巧**：追问「每月都要做这张表，原始数据每月新增一个文件，怎么做到一键刷新」，通常会引向 Power Query（可配合 1104 号提示词）。

### 示例输出

> 示例，仅供参考（第二步节选：行为区域、列为月份、值为销售额，附同比）

| 区域 | 设置 |
|---|---|
| 行 | 区域 |
| 列 | 日期（分组为「年」和「月」） |
| 值 | 销售额：求和；再拖一次销售额，「值显示方式」设为「差异百分比」，基本字段选「年」，基本项选「上一个」，得到同比 |
| 筛选 | 产品类别（或改用切片器） |

**分组路径**：在透视表的任一日期上右键 →「组合」→ 同时选中「月」和「年」。如果提示「选定区域不能分组」，说明日期列中存在文本或空白，需要回到数据源修正。
