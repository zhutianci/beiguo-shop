**怎么填变量**：[我的想法] 用大白话写就行，不需要懂技术术语。[我的技术水平] 一定要诚实填写，AI 会据此选择你能维护的技术方案，并决定解释得多细。[运行方式] 写「在自己电脑上用」时，AI 通常会推荐纯本地的方案，省去服务器和部署的麻烦。

**常见坑**：
- 第一次就想做出「完整产品」，让 AI 一口气生成几十个文件，结果跑不起来，也不知道错在哪里。先砍需求，再一步步来。
- AI 只给代码片段，让你自己找位置插入，非常容易出错。模板要求每次给出完整的文件内容。
- 能运行就直接给别人用。涉及登录、存储个人信息、对外公开时，要先请懂行的人检查安全问题。

**追问技巧**：某一步出错时，把完整的报错信息和你执行的操作贴回去，说「先别加新功能，帮我把这个问题修好」。如果用的是能直接读写项目文件的编程智能体（如 Claude Code、Codex、Cursor），可以把这段提示词作为任务说明直接交给它，并要求它每完成一步就停下来等你验证。

### 示例输出

> 示例，仅供参考（第一步节选）

**一句话**：让家里人能随手记下每笔开销，月底看到各类别花了多少。

| 第一版做 | 第一版不做 |
|---|---|
| 添加一笔开销（金额、类别、日期、备注） | 多人账号与登录 |
| 按月查看开销列表 | 导入银行账单 |
| 按类别显示饼图 | 预算提醒 |
| 数据导出为表格文件（备份用） | 手机 App |

**验收标准（节选）**：打开页面 → 填写金额 35、类别「餐饮」→ 点「保存」→ 列表顶部出现这条记录，刷新页面后仍然存在。

**推荐方案**：单个网页文件 + 浏览器本地存储，双击即可打开，不需要安装任何东西。缺点：只保存在这台电脑的这个浏览器里，所以第一版就提供导出备份功能。
