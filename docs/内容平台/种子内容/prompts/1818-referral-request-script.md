**怎么填变量**：[理想客户] 要具体到让老客户一下想起某个人，「和您一样开了三家店以上的餐饮老板」比「有需要的朋友」有效得多。[老客户情况] 里写一件最近的具体成果，话术会从这件事切入，而不是凭空开口求介绍。

**常见失败与调整**：
- 话术像在做任务：如果出现「麻烦您帮我介绍几个客户」这种句子，让 AI 改成先讲成果、再描述想认识的人。
- 让客户自己去写介绍：一定要用第 3 步那段可转发的文字，替对方省事。
- 介绍之后不反馈：介绍人最在意朋友有没有被打扰、事情办得怎么样，按第 5 步给反馈，才有第二次介绍。

### 示例输出

> 示例，仅供参考（虚构：做企业财税代理的顾问，老客户为一家设计工作室的创始人）

**开口话术 · 微信版**
「林总，上周季度申报顺利过了，比去年同期少跑了两趟税务所，我也松了口气。想请您帮个小忙：您身边如果有刚成立一两年、还在自己兼着记账的工作室老板，方便的话可以把我推给他。我写了一小段介绍，您觉得合适直接转就行；不方便完全没关系。」

**可转发的介绍**
「这是帮我们工作室做财税的周老师，合作两年了。主要是把记账、报税和发票这些事理顺，我现在每个月只需要花十来分钟确认一下。你之前说自己弄报税头疼，可以先问问她。」

**给被介绍人的第一条消息**
「陈总好，我是林总介绍的周敏，帮他们工作室做财税。林总说您目前是自己在处理报税，不知道最让您费时间的是哪一块？我先听听情况，不一定需要找代理。」
