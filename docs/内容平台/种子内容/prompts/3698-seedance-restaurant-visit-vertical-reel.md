**时长与镜头**：12 秒四个镜头：门头（在哪）→ 后厨（现做、烟火气）→ 上菜（招牌菜长什么样）→ 第一口（好不好吃）。探店视频的说服力来自"过程"和"反应"：后厨的火焰证明现做，顾客第一口的表情代替了所有夸奖文案。

**怎么填变量**：[酸菜鱼] 和 [鱼片] 换成你的招牌菜和"最能拉丝 / 冒热气"的那一口，例如"火锅 / 毛肚""拉面 / 面条""芝士焗饭 / 拉丝芝士""手冲咖啡 / 拉花"。咖啡馆、甜品店没有后厨火焰，可以把第二镜换成"咖啡机萃取""奶油裱花"。

**合规提醒**：菜品画面要与实际出品一致，不要用 AI 把分量和卖相夸大；有条件的话，第三镜直接用实拍素材。

**常见失败与调整**：
- 菜品和参考图不一样：第三镜单独用菜品照片走图生视频。
- 顾客表情太夸张像演戏：写"自然的满足表情，轻轻点头"。
- 招牌和菜单出现乱码：保留"不要生成文字"，店名和价格后期加。
