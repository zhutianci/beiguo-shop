**怎么填变量**：[商品与周期] 决定发送时机——护肤品可能要用两周才有感受，手机壳签收当天就能评价。[联系渠道] 只写平台允许的渠道，比如亚马逊卖家通常只能通过平台的消息系统联系买家。

**常见坑**：
- 包裹卡写「五星好评截图返现 5 元」，这是最常见也最容易被处罚的违规；
- 「如果不满意请先联系我们，不要给差评」听起来像是在阻止差评，要改成中性的「遇到问题我们会尽快解决」；
- 对同一个买家反复发索评消息，造成骚扰。

**迭代追问**：「把这份消息翻译成英文，用于亚马逊美国站」「为不同商品写 3 套使用提示 + 评价邀请的包裹卡」「检查我现在用的包裹卡文案是否合规」。

### 示例输出

> 示例，仅供参考（虚构：手工皂店铺，签收后第 10 天发送）

**站内信**：您好，感谢您选择我们的手工皂。用了一段时间，不知道它适不适合您的肤质？如果方便，欢迎在评价里分享您真实的使用感受，满意的地方和需要改进的地方，对我们和其他买家都很有帮助。如果使用中遇到任何问题，可以直接在这里给我们留言，我们会尽快处理。

**合规检查**：未提供任何奖励 ✓；未指定星级 ✓；未区分满意与否发送 ✓。
