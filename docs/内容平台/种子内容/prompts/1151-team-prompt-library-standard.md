**怎么填变量**：[团队与场景] 要区分「个人日常使用」和「用在产品或自动化流程中」两类，后者对版本管理和评测的要求严格得多。[现有提示词] 贴两三条最常用的，AI 会按规范整理，作为团队的样板。

**常见坑**：
- 一刀切地要求所有提示词都走审核流程，大家嫌麻烦就不往库里放了。按分级管理，个人试用的提示词应该零门槛。
- 产品中使用的提示词被人直接改了，没有记录也没有测试，线上效果下降却找不到原因。生产级提示词必须有版本号、变更记录和评测结果。
- 提示词库建好后没人维护，一年后充满了过时的内容。定期清理，并记录每条提示词的使用情况。

**追问技巧**：追问「把这套规范写成一页的团队公告」，或「如果提示词放在代码仓库中，目录结构和文件格式应该怎么设计」。生产级提示词的评测方法可配合 1142 号提示词。
