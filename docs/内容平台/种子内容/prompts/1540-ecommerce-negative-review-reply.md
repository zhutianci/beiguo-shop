  你是一名店铺口碑运营。你知道差评的公开回复其实是写给两个人看的：写差评的买家，和之后每一个翻评价的潜在买家。

  店铺与商品：[店铺与商品]
  差评原文（可以一次粘贴多条）：[差评原文]

  平台：[平台]
  回复字数上限：[回复字数]

  请为每条差评完成：
  1. 类型判断：质量问题 / 物流问题 / 描述不符或预期落差 / 服务态度 / 尺码不合适 / 恶意或与事实不符。
  2. 公开回复：
     - 第一句：感谢反馈或致歉（根据情况真诚表达，不用套话）；
     - 中段：简短说明情况或改进（不推卸、不争辩细节）；
     - 解决方案：告诉买家可以如何联系解决（只引导到平台内的客服渠道）；
     - 对潜在买家有用的信息（如尺码建议、使用注意事项），如果合适。
  3. 私下跟进话术：联系买家处理问题时说什么。
  4. 对于与事实明显不符或涉嫌恶意的差评：给出克制、只陈述事实的回复，以及向平台申诉的步骤要点（以平台规则为准）。
  5. 汇总：这批差评反映出的共性问题，建议反馈给哪个部门改进。
  约束：
  - 公开回复中不出现买家的姓名、电话、地址、订单号等个人信息；
  - 不与买家争吵、不嘲讽、不威胁；
  - 不以退款、补偿、红包为条件要求买家修改或删除评价（违反多数平台规则）；
  - 不承诺做不到的事。

**怎么填变量**：[真实情况] 非常重要，比如「已核实是快递运输中压坏，已为买家补发」，回复才能具体、可信。[回复字数] 按平台限制填写。

**常见坑**：
- 回复里和买家逐条争论「我们没有错」，潜在买家看了只会觉得这家店难沟通；
- 为了显示诚意贴出订单信息或买家昵称以外的个人信息，侵犯隐私；
- 私下联系买家「给你返现，把差评删了」，可能被平台处罚。

**迭代追问**：「把这批回复改得更简短、更口语」「根据差评中的共性问题，写一份给产品团队的改进建议」「为这类差评写一份客服处理 SOP」。

> 示例，仅供参考（虚构：服装店，差评「尺码偏小，穿不上，失望」）

**类型**：尺码不合适 / 预期落差

**公开回复**：谢谢您的反馈，没能让您穿上合适的尺码真的很抱歉。这款版型确实偏修身，我们已经在详情页的尺码表上方加了提示。您可以在订单页直接申请换大一码，来回运费由我们承担。也提醒其他朋友：平时穿 M 码、胸围 90cm 以上的，建议选 L 码。
