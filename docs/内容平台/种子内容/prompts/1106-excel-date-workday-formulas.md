**怎么填变量**：[日期格式] 很重要：从系统导出的日期常常是文本或像 20261007 这样的数字，看起来像日期却无法计算，第一步就要转换。[节假日处理] 如果需要扣除法定节假日，节假日和调休补班的具体日期请按当年官方公布的安排自己整理成一列，AI 不应替你编造。

**常见坑**：
- 用两个日期直接相减算「工作日」，把周末也算进去了。工作日要用 NETWORKDAYS 一类的函数。
- 只扣除了法定节假日，忽略了周末调休上班的日子，算出来的工作日少了一两天。
- 账龄的基准日用 TODAY，每天打开表格数字都不同，月底对账时和财务口径对不上。月度报表一般用固定的统计截止日。

**追问技巧**：追问「把账龄分段的结果做成按客户汇总的透视表，并标出 90 天以上的客户」，或「每年的节假日列表怎么维护，公式才不用每年改」。

### 示例输出

> 示例，仅供参考（H 列为节假日列表，I 列为调休补班日列表，统计截止日放在 K1）

| 需求 | 公式 |
|---|---|
| 文本日期 20261007 转为日期 | `=DATE(LEFT(A2,4), MID(A2,5,2), RIGHT(A2,2))` |
| 开票到回款的工作日（扣节假日，加回补班日） | `=IF(B2="", "未回款", NETWORKDAYS(A2, B2, $H$2:$H$40) + COUNTIFS($I$2:$I$10, ">="&A2, $I$2:$I$10, "<="&B2))` |
| 未回款的账龄天数 | `=IF(B2<>"", "", $K$1 - A2)` |
| 账龄分段 | `=IF(C2="", "", IF(C2<=30, "0-30 天", IF(C2<=60, "31-60 天", IF(C2<=90, "61-90 天", "90 天以上"))))` |
| 所属月份（用于汇总） | `=TEXT(A2, "yyyy-mm")` |

说明：补班日本身是周末，NETWORKDAYS 不会计入，所以用 COUNTIFS 把区间内的补班日加回来。
