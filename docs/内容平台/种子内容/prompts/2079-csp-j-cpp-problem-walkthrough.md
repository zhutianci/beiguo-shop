### 示例输出

> 示例，仅供参考（题目：输入一个正整数 n，输出 1 + 2 + … + n 的和，n 不超过 10 的 9 次方；学生的思路是用 for 循环累加，变量用 int）

**三、思路评价**
- 正确性：累加的思路是对的。
- 时间：n 最大是 10 亿，循环 10 亿次，超过了「一秒约一亿次」的估计，可能超时；改用求和公式 n × (n + 1) ÷ 2，只算一次。
- 部分分：循环加 int 的写法，只能通过 n 较小的那部分数据。

**四、代码**
```cpp
#include <iostream>
using namespace std;

int main() {
    long long n;                    // n 本身不超过 int 范围，但下面要做乘法
    cin >> n;
    cout << n * (n + 1) / 2 << endl;
    return 0;
}
```

**五、常见错误清单（节选）**
- 该用 long long 的地方用了 int：有这个风险。n 取最大值时，n × (n + 1) 约为 10 的 18 次方，远远超过 int 的上限（约 21 亿），所以 n 必须定义成 long long，让乘法在 long long 范围内进行。
- 边界数据：n = 1 时输出 1，正确。
