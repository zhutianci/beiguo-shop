> 本文根据腾讯元器官网与官方帮助中心（操作指南、API 额度说明）整理，资料核对于 2026-10-11。功能和额度变化快，以官网为准。

## 是什么

腾讯元器是腾讯推出的智能体创作与分发平台，官网标题写的是「腾讯官方智能体平台」。它的卖点很明确：**不用写代码，就能做出一个可以挂在微信公众号、微信客服里的 AI 助手**。对已经在运营公众号的个人和商家来说，这是把历史文章变成「可对话的知识库」最省事的路径之一。

平台做过一次大改版，帮助中心有专门的《从旧版元器迁移智能体到新版元器》说明，网上的老教程可能对不上现在的界面。

## 能做什么

- **搭建智能体**：写设定和提示词，选择模型，配置开场白与示例问题。
- **知识库**：上传文档，或一键拉取公众号历史群发文章作为知识库。
- **工作流**：用可视化方式编排多步骤流程。
- **插件广场**：使用官方和第三方插件，也可以自己创建；支持接入 MCP 插件，帮助中心提到了微信支付 MCP 插件。
- **多智能体协作**：帮助中心提供多智能体应用的协作技巧。
- **发布渠道**：腾讯元器自身、微信公众号 / 服务号、微信客服、企业微信、应用宝，以及小米应用商店、荣耀 YOYO 智能体平台等。
- **API**：把智能体发布成 API 服务，接入自己的系统。

## 怎么上手

1. 打开 yuanqi.tencent.com，登录后点「新建我的智能体」。
2. 写清楚智能体的身份、能回答什么、不回答什么。
3. 添加知识库：上传资料，或授权公众号拉取历史文章。
4. 在右侧预览窗口反复提问测试，按帮助中心的《对话效果调优技巧》调整。
5. 在「发布」里选择渠道，按指引完成公众号或企业微信的授权绑定。

## 免费与付费

官方《API 额度说明》（更新于 2025-12-29）写明：新元器每月提供 100 万 token 的模型调用额度，后续会提供 API 调用 token 的购买；在元器网页端、元宝小程序、微信客服、微信公众号、微信服务号、企业微信等渠道内使用**不限 token**。也就是说，在腾讯自家渠道里用目前不收费，额度限制主要针对 API 调用。之后是否调整以官方公告为准。

## 适合谁 / 不适合谁

**适合：**
- 公众号、服务号运营者，想给粉丝一个能回答常见问题的 AI 助手；
- 用微信客服、企业微信接待客户的小商家；
- 没有开发资源、想零成本试水智能体的个人。

**不适合：**
- 主要阵地在抖音、小红书、飞书等非腾讯生态的团队；
- 需要复杂业务逻辑、深度定制界面的产品，建议用 Dify 等开发平台；
- 对模型选择有特殊要求的开发者。

## 注意事项

- **发布到元宝的规则有变**：帮助中心有《发布到元宝渠道变更说明》通知，发布前先看最新说明。
- **审核**：发布到公开渠道的智能体需要通过平台审核，名称、头像和回答内容要符合规范。
- **知识库内容自查**：导入公众号文章时，注意过期信息和不宜对外的内容。
- **API 额度**：在「系统管理—调用统计」里可以查看剩余额度，超出后的处理方式以官方说明为准。
