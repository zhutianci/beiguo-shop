## 是什么

Recraft 是一个面向设计师、营销人员和电商卖家的 AI 图像平台，主打「有品味的」图像模型和设计工作流。与大多数只输出位图的生图工具不同，它的一大特色是**直接生成可编辑的 SVG 矢量图**，路径干净、可无限缩放，适合 Logo、图标、插画和印刷物料。

按官方文档，Recraft 已发布 V2、V3、V4、V4.1 四代自研模型：V4（2026 年 2 月发布）和 V4.1 都有位图与矢量（Vector / Pro Vector）版本，V4.1 Flash 是官方所说速度最快、成本最低的型号；另有 V4 Styles 用参考图锁定风格。创作平台 **Recraft Studio** 同时接入了 Nano Banana、GPT Image、Seedream、Flux 等外部模型。Studio 提供画布，左侧 Chat 里可以让智能体（Agent）帮你出图，也可以切到 Create 标签自己设置模型、风格和参数。

## 能做什么

- **矢量生成**：一句话生成 SVG 图标、Logo、扁平插画，可在内置矢量编辑器里改颜色和路径。
- **位图转矢量**：把 PNG / JPG 转成可编辑 SVG（Vectorize）。
- **品牌风格**：用 1–10 张参考图定义自己的风格，后续生成保持统一画风；可设置品牌配色。
- **自然语言改图**：选中画布上的图片，用文字描述修改，或抠图、擦除、放大、扩图。
- **样机（Mockup）**：把设计一键放到 T 恤、包装等实物效果图上。
- **多端与插件**：iOS / 安卓 App 与网页同步账号和积分；Figma 插件可直接把 SVG 结果作为图层使用，另有 Framer、Chrome 扩展、Google Docs / Slides 插件；API 支持生成、矢量化、批量任务。

## 怎么上手

1. 打开 recraft.ai，点「Start now free」，用邮箱（一次性验证码）、Google、Discord 或 Apple 登录，新账号自带免费积分。
2. 点「Create new project」打开空白画布。
3. 在左侧 Chat 里描述需求让智能体生成，或切到 Create 标签，选择 V4 Vector 等模型并设置风格、比例、数量。
4. 选中结果，用自然语言编辑、去背景或矢量化，然后导出 SVG、PNG、PDF 等格式。

可以这样开始：`一套 8 个线性风格的咖啡店图标，包括咖啡杯、咖啡豆、甜甜圈、外带袋，统一 2px 线宽，深棕色`

## 免费与付费

官方文档《Paid plans》列出（官方文档定价，2026-10 查询；年付约省 20%）：

- **Free**：每日有限积分，每天最多上传 3 张图，每次最多出 2 张；作品公开。
- **Basic**：月付 12 美元，年付折合每月 10 美元；每月 1,000 积分。
- **Pro**：2,000 积分档月付 20 美元、年付折合每月 16 美元，另有 4,000 / 8,000 / 16,000 积分档。
- **Teams**：2,000 积分档月付 22 美元、年付折合每月 18 美元，含共享风格、集中管理和 SSO。

付费方案均为私密生成并拥有商用权；另购的充值积分永不过期。

## 适合谁 / 不适合谁

适合：
- 需要 Logo、图标、扁平插画、可印刷矢量素材的平面设计师。
- 要保持品牌视觉统一、批量出营销图的品牌和电商团队。
- 在 Figma 里工作、希望 AI 结果直接成为可编辑图层的 UI 设计师。

不适合：
- 免费用户想商用：免费生成的图归 Recraft 所有且不可商用。
- 主要做写实视频或长视频的创作者。
- 对复杂矢量路径要求极高的专业插画，仍需人工整理节点。

## 注意事项

- **所有权**：按官方定价页 FAQ，免费方案的图片归 Recraft、公开展示在社区画廊；付费期间生成的图片即使取消订阅也仍归你所有、可商用。
- **退款**：官方说明在最近一次付款 30 天内且未使用积分等条件下可酌情退款，删除账号后无法处理退款。
- 设计 Logo 前建议做商标检索，避免与已有品牌雷同。
