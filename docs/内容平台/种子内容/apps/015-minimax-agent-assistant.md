## 是什么

MiniMax Agent 是 AI 公司 MiniMax 推出的通用智能体（App Store 开发者显示为 Shanghai Xiyu Technology）。它和「海螺AI」的关系需要先说清：

- MiniMax 早期的 AI 对话助手叫**海螺AI**；据媒体报道，这款对话 App 后来改名为「MiniMax」，并升级为现在的 **MiniMax Agent**，手机上的应用名是「MiniMax - 通用AI Agent」。
- **海螺**这个品牌保留给视频生成业务，现在 hailuoai.com 是「海螺视频」，属于另一个产品。

旧的对话入口 chat.minimaxi.com 现在会跳转到 MiniMax Agent；官网 agent.minimax.io 在国内访问会跳转到 agent.minimax.cn。它基于 MiniMax 自研的 M3 系列模型，网页版当前默认显示 M3.1-Flash-Preview。

## 能做什么

- **长程复杂任务**：在多智能体系统支撑下，把一个需求拆成多个子任务并行执行，最后交付完整结果。
- **深度研究与分析**：整合全网信息，生成深度研究报告；另有办公、金融、编程等「专家套组」。
- **专业演示文稿**：一键生成内容完整、视觉丰富的 PPT。
- **全栈应用与代码**：从前端到后端搭建可运行的网页应用，也能写代码、调试和测试。
- **多模态生成**：在任务里生成视频、音频和图片。
- **技能与记忆**：持续记住你说过的事，把重复流程沉淀成专属技能；支持定时任务和插件。
- **桌面端与手机远程控制**：桌面版可组建 Agent 团队、自动化重复工作；手机 App 能远程连接桌面端 Agent，查看回复、终端输出和代码改动，并处理权限审批。

## 怎么上手

1. 打开 agent.minimax.io（国内访问会跳转到 agent.minimax.cn），或在应用商店搜索「MiniMax」，认准开发者为 Shanghai Xiyu Technology。
2. 注册登录后，先在首页选一个任务类型：调研报告、AI PPT、制作网页、视频生成等。
3. 把需求写成「目标 + 交付物 + 约束」，例如页数、受众、风格、截止日期。
4. 任务运行中可以看到它的规划和步骤，需要时补充信息或纠正方向。
5. 经常在电脑上工作的，下载桌面端（Windows / macOS），可以让 Agent 处理本地文件，再用手机远程查看进度。

可以这样开始：「帮我调研国内宠物食品市场 2026 年的主要品牌和价格带，输出一份 12 页的 PPT，最后一页给出新品牌切入建议。」

## 免费与付费

按 MiniMax 付费服务协议：

- 付费服务包括基础会员、专业会员等订阅计划，具体价格和权益以产品页面为准；网页版近期推出了 M Plan，承接原 Token Plan，并与 Agent 统一计费。
- 订阅后**积分按月发放**，每次发放的积分有效期一个月，过期作废，已付费用不退。
- 音乐和语音服务中标有「商用许可」的套餐，订阅期间生成的音乐和音频可用于商业用途。

免费用户能做多少任务、各任务消耗多少积分，以页面显示为准。

## 适合谁 / 不适合谁

**适合：**
- 想把调研、做 PPT、搭网页这类「整件事」交给 AI 的职场人和创业者。
- 需要在一个地方同时生成文字、图片、视频、音频的内容团队。
- 开发者：桌面端加手机远程控制，适合跑长时间的编程任务。

**不适合：**
- 只想简单聊天、问几个问题的用户，积分制对轻度使用不够直观。
- 专门找海螺视频生成的用户，应去海螺视频（hailuoai.com）。
- 不希望 AI 访问本地电脑文件的人，可只用网页版。

## 注意事项

- **积分清零**：每月发放的积分一个月内有效，大任务前先看余额，别囤积分。
- **账号限制**：付费服务协议规定不得出借、转让账号，可能限制同一账号的登录设备数。
- **桌面端权限**：让 Agent 操作电脑和终端前看清授权内容，删除、付款等关键操作要人工确认。
- **核对输出**：自动生成的研究报告和代码要抽查来源和运行结果。
