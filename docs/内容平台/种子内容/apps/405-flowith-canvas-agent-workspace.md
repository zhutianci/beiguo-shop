## 是什么

Flowith 官网给自己的定位是「Agentic Workspace」。和常见的一问一答聊天框不同，它的主界面是一张**画布**（官方叫 Flow）：每次提问、每个生成结果都是画布上的一个节点，可以从任意节点分叉出新的方向、把几个结果放在一起对比，适合发散式地推进一个想法。

官网首页显示，同一个输入框可以切换「对话、图像、视频、幻灯片、网页、Neo Agent」几种模式；侧边栏有画布管理、媒体历史、**知识花园**（把自己的资料整理成可检索的知识库）和知识市集。模型方面走的是聚合路线，页面上列出了 Seedream 5.0、Nano Banana 系列、GPT Image 2 / 2.5、Grok Image 2.0、Seedance 2.5、Kling 等图像和视频模型，定价页称可用 40 多款模型。

## 能做什么

- **画布式对话**：分支提问、并排比较不同模型的回答。
- **图像与视频生成**：在同一处切换多家模型，支持批量生成。
- **成品类输出**：幻灯片、网页。
- **Neo Agent**：把多步骤任务交给智能体规划执行。
- **小应用**：首页列出了背景移除、照片重打光、高清放大、裁切改尺寸、社媒配图、壁纸生成等一键工具。
- **知识花园**：上传资料后在创作中引用。

## 怎么上手

1. 打开 flowith.io，用邮箱等方式注册（界面可切换中文）。
2. 新建一个 Flow，在底部输入框选好模式和模型，输入需求。
3. 对满意的节点继续追问，对不满意的节点换模型重新生成，或从上一步分叉。
4. 需要长任务时切到 Neo Agent，把目标、素材和交付格式写清楚。

## 适合谁 / 不适合谁

**适合：**
- 做方案、策划、视觉探索时喜欢「铺开来比较」的创作者和产品经理；
- 想在一个账号里试用多家图像、视频模型的人；
- 需要把资料沉淀成知识库再反复调用的研究型用户。

**不适合：**
- 只想快速问一句话的人，画布反而多一步操作；
- 只认准某一家模型、已经订阅其官方会员的用户；
- 需要桌面离线使用的场景——它是纯在线的网页产品。

## 注意事项

- **积分消耗因模型而异**：视频和高分辨率图像消耗远高于文字，生成前留意提示的消耗。
- **聚合模型的可用性会变**：某个模型是否可用、是否打折取决于平台当期配置。
- **生成内容的版权与商用**：除了 Flowith 的条款，还要遵守对应模型提供方的使用政策。
- 上传到知识花园的资料存储在云端，敏感文件请谨慎。
