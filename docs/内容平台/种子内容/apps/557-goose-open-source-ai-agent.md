## 是什么

goose 是一个开源的 AI 智能体，用 Rust 编写，采用 Apache-2.0 许可，仓库约有 5.51 万星标。README 的介绍是：在你本机运行，能处理编程、调研、写作和自动化等各类任务。

关于归属：这个项目最初由 Block 公司开源（老教程里的仓库地址是 block/goose），现在仓库位于 **aaif-goose/goose**，README 写明 goose 是 Linux 基金会旗下 Agentic AI Foundation（AAIF）的一部分。访问旧地址会跳转到新仓库。

它和 Claude Code、OpenCode 这类编程智能体的差别在于**定位更通用**：除了写代码，也被用来整理文件、跑脚本、做资料收集，而且同时提供图形界面，不要求用户熟悉终端。

## 能做什么

- **两种使用形态**：桌面应用（macOS、Linux、Windows）和终端里的命令行工具；另外提供可嵌入其他程序的 API；
- **模型自由**：支持 15 家以上的模型服务商，README 列举了 Anthropic、OpenAI、Google，以及用 Ollama 运行的本地模型；
- **MCP 扩展**：通过 Model Context Protocol 连接 70 多个扩展，让智能体操作开发工具、浏览器、文档、数据库等外部系统；
- **本地执行**：读写文件、运行命令都发生在你的机器上。

## 怎么上手

1. 在仓库的 Releases 页面或官方文档中下载桌面应用安装包；习惯终端的，运行 README 提供的命令行安装脚本。
2. 首次启动时选择模型服务商并填入 API Key（或指向本机的 Ollama）。
3. 选择一个工作目录，用自然语言下达任务，例如：

```text
把这个文件夹里所有 CSV 的表头统一成英文小写下划线格式，生成一份改动清单，先给我看方案，确认后再执行。
```

4. 在扩展设置里按需启用 MCP 扩展，比如访问代码托管平台或浏览器自动化。

## 免费与付费

goose 完全免费开源。花费只来自模型：按所选服务商的 API 用量计费；用本地模型则没有调用费，但效果取决于模型能力和电脑配置。

## 适合谁 / 不适合谁

**适合：**
- 想要一个不绑定厂商、可审计源码的通用智能体的开发者和技术爱好者；
- 希望用图形界面体验「让 AI 在自己电脑上干活」的人；
- 想用 MCP 把智能体接进自己工作流的团队。

**不适合：**
- 不愿意自己准备模型 API Key 的用户；
- 需要云端并行执行、手机上查看进度等托管能力的人；
- 对本机文件安全非常敏感、又不打算花时间配置权限的用户。

## 注意事项

- **它真的会改文件、跑命令**：先在测试目录里试用，重要数据提前备份，执行破坏性操作前要求它先给方案。
- **扩展权限**：每启用一个 MCP 扩展，就多给了智能体一类能力，只开需要的。
- **本地小模型的工具调用能力有限**，复杂任务容易失败，建议先用能力较强的云端模型跑通流程。
- **仓库迁移**：旧教程里的安装地址可能已变化，以当前仓库 README 为准。
