## 是什么

Fish Audio 是 Hanabi AI Inc. 推出的 AI 语音平台，做的是「让 AI 声音不像 AI」：文字转语音、声音克隆、语音转文字、变声、配音翻译都能在一个站里完成。官网有**简体中文界面**，对中文用户比较友好。

目前官网主推的语音模型是 **Fish Audio S2.1 Pro**，API 文档里同时列出 s2-pro、s1 等模型，语音转文字用 transcribe-1-pro。团队还在 GitHub 上开源了 **Fish Speech** 项目，可以自行部署研究（许可证条款以仓库说明为准）。

## 能做什么

- **文字转语音**：选择音色、输入文案，生成旁白、有声书、角色对白。
- **情绪与语气标签**：在文本里插入 [whispering]、[laughing]、[pause] 这类标签，控制耳语、笑声、停顿等表现。
- **声音克隆**：用一段本人录音快速克隆；付费档提供「专业音色」，需要通过声音所有者验证。
- **Voice Design**：用一句文字描述生成一个全新的虚构音色，不需要任何真人录音（Plus 起）。
- **语音转文字**：转写多人对话、长录音，可带时间戳。
- **故事工作室、变声、人声分离、音频翻译**：适合做有声书、短剧配音和多语种视频。
- **API 与 MCP**：开发者可通过 REST API、官方 SDK 接入，也支持实时流式输出给语音助手用。

## 怎么上手

1. 打开 fish.audio，页面底部的语言选项可切换为简体中文，点「免费注册」创建账号（无需信用卡）。
2. 进入「文字转语音」，从语音库里挑一个音色，或使用自己克隆的声音。
3. 输入文案，需要情绪时在句子前加标签，再点生成试听。
4. 想要专属音色但不想用真人声音，可以试 Voice Design：用文字描述「沉稳的中年男声，语速偏慢，适合纪录片旁白」。
5. 开发者在控制台申请 API Key，按 docs.fish.audio 的 Quick Start 调用。

可以这样开始：

```
[soft] 夜深了，城市终于安静下来。[pause] 我想给你讲一个关于灯塔守护人的故事。
```

## 适合谁 / 不适合谁

**适合：**
- 做有声书、短剧、游戏角色配音，需要情绪表现力的创作者。
- 想用中文界面、又想要多语种配音的个人和小团队。
- 需要 API 或想研究开源语音模型的开发者。

**不适合：**
- 免费额度下长期出内容的人：每月约 7 分钟，且不能商用。
- 想直接用社区里名人、主播音色做商业内容的人，授权风险很高。
- 对中文方言有特殊要求的场景，先试听再决定。

## 注意事项

- **克隆声音的同意规则**：官方要求你确认对所克隆的声音拥有必要的权利、同意和披露，并遵守当地关于姓名、肖像和 AI 内容的法律；官方最佳实践写明只克隆有明确许可的声音（本人、已同意的人、合法授权音色），**不要未经许可使用名人或公众人物的声音**。专业音色必须由声音所有者本人通过实时验证。
- **社区音色库**：语音库里有大量用户上传的音色，官方不预先审核每个用途，违规内容和账号可能被删除。使用他人上传的音色前，确认其授权情况，商用尤其要谨慎。
- **商用范围**：官方 FAQ 说明付费订阅者可将**已验证**的音色用于商业用途，免费用户仅限个人非商业使用，详见服务条款。
- **标注 AI 生成**：配音内容发布到国内平台时，按规定标注 AI 生成。
