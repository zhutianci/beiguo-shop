## 是什么

DeepL 是德国科隆的 DeepL 公司推出的机器翻译服务，用自研的神经网络和大语言模型做翻译，常被拿来和谷歌翻译比较，优势是译文读起来更像人写的。除了翻译器本身，它还有一个写作工具 **DeepL Write**，用来改正拼写语法、替换更合适的词句、调整文风语气，官方页面称支持 23 种语言，其中包括中文。

DeepL 面向个人和企业都有产品：个人可以免费用网页版和客户端，付费的 DeepL Pro 解锁更大用量和数据保护；企业还能用 API 把翻译接进自己的系统。

## 能做什么

- **文本翻译**：粘贴或输入文字即时翻译，可以点选单词查看备选译法，按语境替换。
- **整份文档翻译**：上传 Word、PowerPoint、PDF 等文件，尽量保留原排版输出译文。
- **术语表**：固定某些专有名词的译法，例如公司名、产品名统一翻成指定说法。
- **DeepL Write 写作润色**：改正拼写语法标点，给出词句替换建议，切换正式、轻松等文风（风格规则等高级功能属于 Pro）。
- **桌面端快捷翻译**：Windows / Mac 客户端可以在任意软件里选中文字后用快捷键翻译。
- **插件与集成**：浏览器插件翻译网页，Word、Google Workspace、Microsoft 365 等也有集成。

## 怎么上手

1. 打开 deepl.com，直接在网页翻译框里粘贴文字即可使用，不登录也能翻译短文本。
2. 注册免费账户（邮箱即可）后，可以使用文件翻译和术语表等功能。
3. 常用电脑办公的话，在官网下载 Windows 或 Mac 客户端，或安装 Chrome / Firefox / Edge 插件。
4. 第一次可以试试点选替换：翻译一句话后，点击译文里的某个词，看 DeepL 给出的其他译法。
5. 写英文邮件时切到 DeepL Write，先用中文想好意思、翻成英文，再让 Write 帮你调成更正式的语气。

## 免费与付费

**免费版**（官网定价页，2026-10 查询）：每月 5 万字符，每月 1 个文件翻译（最大 5MB），1 个术语表、每个语言对 5 条。

**DeepL Pro** 面向个人和团队分为 Individual、Team、Business、Enterprise 等档位。以官网欧元标价为例：Individual 按年付费约 7.49 欧元/月（每月 30 万字符、3 个文件），Team 约 24.99 欧元/人/月（每人每月 100 万字符、20 个文件），Business 约 49.99 欧元/人/月（字符不限、100 个文件），Enterprise 需联系销售。DeepL Write Pro 在 Individual 和 Team 档为加购项，Business 及以上包含。不同国家地区显示的币种和价格可能不同，以你所在地区的页面为准。

## 适合谁 / 不适合谁

**适合：**
- 需要阅读或撰写外文邮件、合同、论文的职场人和研究生，看重译文自然度。
- 要整份翻译 PPT、Word 并保留排版的团队。
- 外语学习者：用点选替换对比多种译法，体会用词差别。

**不适合：**
- 需要翻译大量机密、个人信息但只用免费版的人——条款不允许，见下文。
- 冷门小语种需求较多的人，DeepL 支持的语种数量不如部分综合翻译工具多，使用前先确认语言列表。

## 注意事项

- **免费版与 Pro 的数据差别**：DeepL 免费版使用条款写明，可以在有限时间内处理你上传的文本和译文，用于训练和改进模型，并且**不允许**用免费版处理含机密或个人数据的内容；Pro 用户的文本不会用于训练，只在技术必要时临时存储并随后删除。
- DeepL 官方称其通过 ISO 27001 和 SOC 2 Type II 认证，企业采购前可在信任中心查看详情。
- 机器翻译仍会出错，尤其是数字、否定句、专业术语和长难句；用于合同、出版、医疗等场景时一定要人工校对。
