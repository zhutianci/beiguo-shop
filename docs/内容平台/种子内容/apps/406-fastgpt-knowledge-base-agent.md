## 是什么

FastGPT 是一个基于大模型的知识库平台和 AI Agent 构建工具，仓库为 labring/FastGPT（GitHub 星标约 2.98 万），官网页脚的版权方为广州环际云计算有限公司。官网现在的口号是「构建安全、可控的企业级 AI Agent」。

它最常见的用法是**企业知识库问答**：把产品手册、制度文档、常见问题导进去，配置好检索和回答流程，再通过分享链接、网页嵌入或 API 给员工、客户使用。

## 能做什么

- **应用编排**：可视化工作流，支持对话工作流与插件工作流、Agent 技能、双向 MCP，以及辅助生成工作流。
- **知识库**：支持 TXT、MD、PDF、DOCX、CSV、XLSX 等多种文件，可从网址导入，提供混合检索与重排，也能对接外部 API 知识库。
- **调试**：知识库搜索测试、完整调用链日志、应用评测和调试模式，方便排查「为什么答错」。
- **模型管理**：兼容多种模型，带调试与审计能力。
- **运营**：免登录分享页、iframe 嵌入、对话记录查看与标注。
- **权限**：官网介绍企业场景下支持 SSO 与基于角色的权限。

## 怎么上手

**先体验**：在官网进入云服务注册（README 中海外云服务地址为 fastgpt.io，国内入口见官网），新建一个知识库、上传几份文档，再建一个「知识库问答」应用绑定它。

**自部署**：README 给出的方式是运行官方安装脚本拉取配置文件，然后：

```bash
docker compose up -d
```

启动后访问 `http://localhost:3000`。也可以在 Sealos 上一键部署。部署后需要自己配置模型（对话模型、向量模型、重排模型）。

## 免费与付费

- **开源版**：按 FastGPT Open Source License 免费使用，可自部署。
- **云服务**：按套餐与用量收费，具体档位和价格以官网定价页为准。
- **商业版**：功能更多并带技术支持，需联系官方获取报价。

## 适合谁 / 不适合谁

**适合：**
- 想给公司做内部知识库问答、售前售后客服机器人的技术团队；
- 需要把数据留在自己服务器上的企业；
- 想看清检索过程、精细调优回答效果的开发者。

**不适合：**
- 没有任何技术人员、也不想碰 Docker 的小团队，可先用云服务或其他托管平台；
- 只需要个人聊天助手的用户；
- 想把它直接当成 SaaS 转售的公司，这不在开源许可允许的范围内。

## 注意事项

- **许可证限制**：README 写明代码可作为后台服务商用，但**不允许用它提供 SaaS 服务**；其他商业用途需保留版权信息，或购买商业授权。
- **效果取决于数据**：文档切分、清洗质量直接影响回答准确率，上线前用真实问题做搜索测试。
- **模型成本另算**：自部署时对话、向量化、重排都要消耗模型额度。
- **分享页的访问控制**：免登录分享方便，但要注意知识库里是否有不宜公开的内容。
