## 是什么

Make 是一款无代码 / 低代码自动化平台，早年叫 Integromat，后来改名为 Make。它的流程叫「场景」（Scenario）：在画布上把一个个圆形模块连起来，数据从左往右流动，中间可以分支、循环、过滤和做错误处理。相比 Zapier 的线性步骤，Make 的画布更适合表达复杂逻辑。

## 能做什么

- **连接应用**：内置大量应用模块，也可以用 HTTP 模块调用任意 API。
- **Make AI Agents**（定价页标注为 beta）：在 Make 里创建和管理智能体，可以使用 Make 提供的模型，也可以填自己的大模型密钥；所有档位可用。
- **Make AI Toolkit**：在流程里插入总结、分类、提取等 AI 步骤，所有档位可用。
- **其他 AI 能力**：定价页还列出了 Maia by Make、AI 应用、MCP server、AI Content Extractor、AI Web Search（beta）等，具体哪些档位包含以官网为准。
- **Make Code App**：在流程里运行代码，按执行时间折算积分。

## 怎么上手

1. 在 make.com 注册免费账号。
2. 新建一个场景，添加第一个模块作为触发器（如「表格新增一行」「收到 Webhook」）。
3. 继续添加动作模块并授权对应账号，点「Run once」逐步测试，观察每个模块的输入输出气泡。
4. 测试通过后打开调度开关，设置运行频率。

第一个场景可以做这样一条：新邮件到达 → 用 AI 模块判断是否为询价 → 是的话写入表格并通知到聊天群。

## 适合谁 / 不适合谁

**适合：**
- 流程里有分支、循环、数据转换等较复杂逻辑的自动化需求；
- 想用图形方式看清数据怎么流动的运营和业务人员；
- 需要在自动化里穿插 AI 处理、但不想自己维护服务器的小团队。

**不适合：**
- 只需要两三步简单联动的人，Zapier 上手更快；
- 需要自托管、数据不出内网的企业，可考虑 n8n；
- 主要使用国内应用的团队，现成模块有限，需要自己对接 API。

## 注意事项

- **积分怎么扣**：定价页说明积分按「模块动作」计，流程里每执行一个模块动作就消耗积分，循环处理大量数据时消耗很快，先用小数据量测试。
- **AI 用量**：使用 Make 提供的模型会额外消耗积分，用自己的密钥则由模型厂商计费。
- **错误处理要配置**：给关键模块加上错误处理路线，否则一次失败可能让场景停用。
- **改名说明**：搜「Integromat」找到的老教程界面与现在差别较大，以当前官网文档为准。
