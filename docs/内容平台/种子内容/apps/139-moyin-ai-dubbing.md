## 是什么

魔音工坊是 AI 语音公司**出门问问**推出的 AI 配音产品，App 开发者为北京小问智能科技有限公司。它的定位很直接：把文字变成接近真人的配音，主要服务短视频解说、影视剪辑、有声书、新闻播报和外语出海这类内容创作。

官方介绍声音库有 800 多款声音、1000 多种说话风格，包括多款方言音色、老人 / 少女等不同年龄音色，以及德、俄、法、韩、日等外语发音人。公开报道提到其声音克隆依托出门问问的「序列猴子」大模型。海外版叫 DupDub。

## 能做什么

- **文字转配音**：粘贴文案，选发音人和说话风格，一键合成音频。
- **细调发音**：调语速、调停顿、插入静音，多音字可手动选读音，解决「读错字」这个配音老大难。
- **方言与外语**：东北话、北京话、台湾腔等方言音色，以及多种外语发音人，适合做搞笑解说或出海视频。
- **字幕与打轴**：会员可下载配音对应的 SRT 字幕文件、自动打轴，省掉剪辑时对字幕的时间。
- **文案提取**：从视频里提取文案，再改写后重新配音。
- **声音克隆**：用一段本人录音生成专属发音人（付费功能，需按平台要求授权）。

## 怎么上手

1. 电脑上打开魔音工坊官网 moyin.com（网页版），手机上在 App Store 或安卓应用商店搜索「魔音工坊」，也可以用微信小程序。
2. 按页面提示注册登录（同一账号多端通用），进入配音工作台。
3. 把文案粘贴进编辑区，从声音库里按场景（解说、广告、有声书、方言、外语）挑一个发音人试听。
4. 对读错的多音字、需要停顿的地方单独设置，再整体调整语速。
5. 合成后试听，满意再下载音频；会员可同时下载 SRT 字幕。

可以这样开始（一段影视解说开头）：

```
这部电影只用了一个场景，却让无数观众看完后久久说不出话。今天，我们就用三分钟，讲清楚它到底好在哪里。
```

## 免费与付费

- 可以免费注册、试听声音；但合成下载、高级声音等权益主要面向会员。开通前建议先在 App 内看清免费能做到哪一步。
- 官方说明魔音会员可在电脑、手机 App、微信小程序三端通用，权益包括免费合成次数、不限次数下载音频、下载字幕 SRT、文案提取、自动打轴等。
- 会员档位、声音克隆是否单独收费等**以官网会员中心为准**，App 内为自动续订时注意续费日期。

## 适合谁 / 不适合谁

**适合：**
- 抖音、快手、视频号上做影视解说、知识科普、带货口播的创作者。
- 需要批量出有声书、课程音频的团队。
- 中文配音为主、对多音字和停顿有较高要求的人。

**不适合：**
- 只想偶尔配一两句、又不想付费的人。
- 主要做英文等外语长内容的人，可以同时对比海外语音工具。
- 需要开放 API 深度集成的开发者，企业接入以官方商务渠道为准。

## 注意事项

- **声音克隆必须取得本人同意**：只克隆你自己的声音，或取得声音主人明确授权后再使用。《互联网信息服务深度合成管理规定》要求，提供人声等生物识别信息编辑功能时，应提示使用者依法告知被编辑的个人并取得其单独同意。不要用明星、主播或身边人的录音去做克隆。
- **平台内的明星音色**：声音库里的明星大咖音色为官方合作入驻，使用范围以平台授权说明为准，不等于可以随意商用。
- **标注 AI 生成**：AI 配音的视频发布时，按《人工智能生成合成内容标识办法》及平台规则标注。
- **核对文案**：AI 只负责「读」，内容准确性要自己把关，尤其是数字、人名和专业术语。
