## 是什么

Clipdrop 是一个在线的 AI 图像处理工具集，官网自称「视觉创作平台」。它没有复杂的图层和面板，而是把常见的修图需求拆成一个个单独的小工具：进去、上传图片、点一下、下载。对不会用 Photoshop 的人来说，这是处理「帮我把背景去掉」「把这行字抹掉」这类小活最快的方式之一。

关于归属：官网页脚的版权方写的是 InitML，而客服邮箱和招聘链接使用的是 jasper.ai 域名，搜索下拉里也有「Clipdrop by Jasper」的说法。归属关系以官网当前说明为准。

## 能做什么

官网定价页列出的工具：

- **Background Removal**：一键抠图。
- **Cleanup**：涂抹掉画面里的路人、杂物、瑕疵。
- **Text Remover**：去掉图片上的文字。
- **Uncrop**：向外扩展画面，改变构图比例。
- **Replace Background**：把主体换到新的背景里。
- **Relight**：给照片重新打光。
- **Image Upscaler**：高清放大，免费版 2 倍，Pro 最高 16 倍。
- **Text to image**：文字生成图片。
- **Universal resizer**：一次性改成各平台常用尺寸。

## 怎么上手

1. 打开 clipdrop.co，在工具列表里点进需要的工具。
2. 上传或拖入图片。
3. 根据工具做一步操作：比如 Cleanup 用画笔涂掉不要的部分，Uncrop 选择目标比例。
4. 预览后下载结果。大部分工具不注册也能试，登录后可以看到用量。

一个常见的电商流程：先用 Background Removal 抠出商品 → Replace Background 换成场景背景 → Relight 统一光线 → Image Upscaler 放大到平台要求的尺寸。

## 免费与付费

- **免费版**：定价页显示 Background Removal、2 倍 Upscaler、Cleanup、Relight 每 24 小时各 20 次，Text Remover 50 次；Text to image、Uncrop、Replace Background 未标注次数上限。
- **Pro**：免排队、各工具提供高分辨率版本，多数工具每 24 小时 1,000 次，放大最高 16 倍，并有免费试用。核对时页面未显示 Pro 的具体金额，**价格以官网定价页为准**。
- **API**：按用量计费，价格与文档单独列出。

## 适合谁 / 不适合谁

**适合：**
- 电商卖家、自媒体作者日常处理商品图和配图；
- 不会专业修图软件、只想快速解决单个问题的人；
- 想把抠图、清除等能力通过 API 接进自己应用的开发者。

**不适合：**
- 需要精细控制图层、蒙版和色彩管理的专业修图；
- 要一次处理上千张图片的批量任务（应使用 API 或专门的批处理工具）；
- 希望使用中文界面和国内支付方式的用户，可以看美图、稿定等国内工具。

## 注意事项

- **去文字、清除功能不要用来抹掉他人作品的署名或版权标识**，这可能构成侵权。
- **免费版分辨率有限**，要印刷或大尺寸展示需要高分辨率版本。
- **隐私**：图片会上传到服务器处理，含个人信息或未公开的商品图请先评估。
- **AI 扩图和重打光属于生成内容**，细节可能与真实场景不符，用于商品展示时注意不要造成误导。
