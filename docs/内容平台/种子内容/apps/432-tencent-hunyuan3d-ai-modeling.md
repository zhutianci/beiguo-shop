> 本文根据腾讯混元3D 官网与官方 GitHub 仓库 Tencent-Hunyuan/Hunyuan3D-2.1 的 README 整理，资料核对于 2026-10-11。在线版的功能与额度需登录后查看，以官网为准。

## 是什么

腾讯混元3D 是腾讯混元大模型家族里负责 3D 生成的产品。它有两种形态，适合的人群完全不同：

- **在线版**：打开 3d.hunyuan.tencent.com 登录后直接在浏览器里生成，不需要显卡，适合设计师和普通用户；
- **开源版**：腾讯在 GitHub 的 Tencent-Hunyuan 组织下开源了多个版本的模型。本文核对的 Hunyuan3D 2.1 仓库（约 4,200 星标）称其公开了完整的模型权重和训练代码，可用于微调，适合开发者和研究者。

## 能做什么

以开源的 Hunyuan3D 2.1 为例，README 介绍它是一套 3D 资产创作系统，由两部分组成：

- **Hunyuan3D-Shape-v2-1**（约 33 亿参数）：从图片生成三维形体；
- **Hunyuan3D-Paint-v2-1**（约 20 亿参数）：为形体合成贴图，采用基于物理的渲染（PBR）材质，在不同光照下更真实。

在线版在此基础上提供图形化操作。官网登录页之外的具体功能模块（如文生 3D、多视图输入、专业工作台等）需要登录后才能看到，这里不逐项罗列，以登录后的实际界面为准。

腾讯还开源了面向「3D 世界 / 场景」生成的 HunyuanWorld 系列，与单个物体的 Hunyuan3D 是不同的项目。

## 怎么上手

**在线使用：**

1. 打开官网，按页面提示登录并阅读服务协议。
2. 上传一张主体清晰、背景简单的图片（或按界面提示输入文字）。
3. 生成后在预览中旋转检查，再选择需要的格式导出。

**本地部署（开发者）：**

1. 准备带大显存显卡的机器。README 给出的显存参考：只生成形体约 10 GB，只生成贴图约 21 GB，两者一起约 29 GB。
2. 按仓库 README 克隆代码、安装依赖并下载权重。
3. 运行仓库提供的示例脚本或 Gradio 界面。

## 适合谁 / 不适合谁

**适合：**
- 想用中文界面、国内网络直接访问的 3D 生成用户；
- 游戏、电商、文创行业做前期原型的设计师；
- 想在自己的显卡上跑开源 3D 模型、做二次开发的开发者。

**不适合：**
- 显存不足 10 GB 又想本地跑的用户；
- 需要精确尺寸的工程建模；
- 期望生成结果不经修整直接进入高标准生产管线的团队。

## 注意事项

- **版本很多，别装错**：仓库按版本分开（2.0、2.1 等），不同版本的依赖和权重不通用，教程要对应版本。
- **开源不等于随意商用**：README 页面只给出了 License 链接，具体条款务必打开原文阅读。
- **输入图决定上限**：遮挡多、透视夸张或背景杂乱的图片容易生成变形的模型。
- **内容合规**：官网登录页提示「所有内容均由 AI 生成仅供参考」，不要上传他人肖像或受保护的形象。
