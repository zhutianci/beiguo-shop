## 是什么

Chatbox（官网称 Chatbox AI）是一款跨平台的 AI 客户端。和只做桌面端的同类工具相比，它的特点是**平台最全**：Windows、macOS、Linux、iOS、安卓和网页版都有，适合想在电脑和手机上用同一个工具的人。

它有两种用法，新手最容易搞混：

- **自带 API Key**：应用免费，你填入自己在各模型厂商申请的密钥，费用由厂商按量收取；
- **Chatbox AI 订阅**：付费给 Chatbox，由它提供模型额度，不用自己申请和配置密钥。

## 能做什么

- **多模型对话**：官网列出的服务商包括 OpenAI、Google Gemini、Anthropic、DeepSeek、xAI、Mistral，以及 OpenRouter、AWS Bedrock 等聚合与云平台。
- **读文件**：理解文档、图片、代码等文件内容。
- **联网搜索与网页浏览**：实时获取信息。
- **AI 绘图**：在对话里生成图片。
- **排版渲染**：Markdown 与 LaTeX 公式。
- **桌面端知识库**：用私有文档建立知识库。
- **Agent 模式**：代码执行、技能、MCP 服务器、知识库选择；订阅用户还有集成的 MCP 服务。

## 怎么上手

1. 在官网下载对应平台的版本，或直接打开网页版。
2. 首次打开会让你选择模型来源：选「Chatbox AI」需要登录并订阅；选其他服务商则填入 API Key 和（如有需要）接口地址。
3. 新建对话，选模型开始使用。
4. 在设置里可以调整默认模型、字体、语言（支持中文界面）等。

## 适合谁 / 不适合谁

**适合：**
- 想在手机和电脑上用同一个 AI 客户端的人；
- 已有 API Key、想要一个简洁好用的界面的开发者和进阶用户；
- 不想折腾密钥、愿意付一份订阅同时用多家模型的人。

**不适合：**
- 重度依赖某一家官方应用独有功能的用户；
- 需要团队统一管理账号和权限的企业场景；
- 对「点数」这种间接计量不放心、希望按 Token 明细对账的用户——这种情况用自己的 API Key 更清楚。

## 注意事项

- **两种模式的账单分开**：自带密钥产生的费用在模型厂商那边，订阅费在 Chatbox 这边，别重复付费。
- **点数消耗因模型而异**：同样一段对话，用高级模型扣得更多。
- **密钥安全**：API Key 存在设备本地，不要在不信任的设备上登录或粘贴密钥。
- **下载渠道**：只从官网和官方应用商店页面安装，警惕同名山寨应用。
