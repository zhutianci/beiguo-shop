## 是什么

扣子（Coze）是字节跳动旗下的 AI Agent 平台，官网页脚的运营主体为北京春田知韵科技有限公司。很多人对它的印象还停留在「零代码搭聊天机器人」，但现在官网的定位已经变成「职场 AI 伙伴」：你说清楚想完成什么，Agent 带着资料和工具把事情一步步做出来。

目前官网把产品分成几块：

- **扣子**：面向个人和团队的办公 Agent，有网页版、桌面端（Windows / macOS）和手机 App（iOS / 安卓），多端数据同步；
- **扣子编程**：用自然语言对话开发智能体、工作流、网页应用和移动应用，并一键部署；
- **扣子罗盘**：面向开发者的调试、观测类工具；
- **扣子开源**：开源版本，可自行部署。

## 能做什么

- **交付成果型任务**：写报告、做 PPT、做表格和数据分析、平面设计、播客、把脚本做成短视频等，官网演示的都是「交代任务—拿到文件」的流程。
- **给 Agent 配设备**：可以授权 Agent 使用你的电脑处理本地文件，也可以给它分配云端服务器，或配一台云手机去操作 App。
- **定时任务**：把任务放进日程，Agent 到点在云端自己开工，电脑和手机离线也不影响。
- **会议旁听**：手机 App 的「旁听」可识别多人发言、生成纪要，会后继续追问。
- **在聊天软件里使用**：官网展示了在飞书和微信里直接给扣子派任务。
- **云盘**：资料、过程文件和成果在本地、云端和手机之间同步。

## 怎么上手

1. 打开 coze.cn，注册或登录（可直接用网页版，也可以下载桌面端 / App）。
2. 在输入框里把任务说完整：目标、材料、输出格式、截止要求。
3. 等 Agent 规划并执行，过程中可以追加指令；完成后下载成果文件。
4. 想做应用或工作流，进入「扣子编程」，用对话描述需求再逐步修改。

可以这样开始：

```text
我上传了 3 份竞品介绍 PDF。请对比它们的定价、目标用户和核心功能，做成一份 10 页以内的 PPT，最后一页给出我们可以差异化的 3 个方向。
```

## 适合谁 / 不适合谁

**适合：**
- 想把「整理资料—出文档 / PPT / 视频」这类成套工作交给 AI 的职场人和自媒体作者；
- 不写代码但想搭一个内部小工具或智能体的运营、产品同学；
- 已经在用飞书、剪映等字节系产品的团队。

**不适合：**
- 只想简单问答的人，直接用豆包等聊天助手更省事；
- 对数据出境、私有化有硬性要求的企业，需要先评估企业版或开源版；
- 希望完全免费跑大量视频、PPT 任务的用户——这类任务消耗积分较快。

## 注意事项

- **认准官网域名**：本文核对的是国内站 coze.cn；搜索结果里其他域名的同名站点，账号与功能是否相通以官方说明为准。
- **积分是核心计量**：不同任务消耗差别很大，开始大任务前先看一下预计消耗。
- **授权电脑要谨慎**：让 Agent 操作本地文件前，确认工作目录范围，重要文件先备份。
- **产品形态变化快**：老教程里提到的「Bot 商店」「扣子空间」等入口可能已经调整，以当前官网为准。
