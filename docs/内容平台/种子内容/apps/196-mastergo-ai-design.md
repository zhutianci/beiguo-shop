## 是什么

MasterGo（中文名「莫高设计」）是国产的在线界面设计、交互原型和研发交付平台，官网定位是「AI 时代的数字界面生产平台」。官网页脚显示运营主体为**北京创作美好科技有限公司**——经常有人搜「MasterGo 是哪家公司的」，答案就在官网底部。

它支持导入 Figma、Sketch、Axure 等文件，产品经理用原型文件、设计师用设计文件、工程师用研发模式查看标注和代码，适合企业团队一体化协作，也提供私有化部署和信创适配。

**MasterGo AI** 覆盖产设研全链路，官方把它分成四大能力：AI 快搭、AI 设计助手、AI + D2C PRO、MCP 支持。

## 能做什么

- **AI 快搭（对话生成 UI）**：用自然语言、参考图或 design.md 生成完整界面、局部组件或页面框架，支持局部修改，生成结果可插入画布变成可编辑的矢量图层和组件。
- **同步生成前端代码**：根据设计生成 Vue、React 等主流框架代码，可快速导出代码片段。
- **AI 设计助手**：调用团队现有的设计系统（样式、组件、图标）生成符合规范的页面；还能生成图片、风格化、抠图、扩图。
- **文案与数据填充**：改写文案、一键翻译多语种版本，自动生成数据图表和图标。
- **设计规范检查**：根据图层信息生成设计规范，检查图层是否符合团队库标准。
- **D2C PRO**：把设计稿转成 React、Vue、小程序等技术栈的生产级代码，可对接 Design Tokens 和企业组件库（更新日志显示已对企业版全量开放）。
- **MCP**：让 Cursor、Codex 等 AI 编程工具通过 MCP 协议直接在 MasterGo 画布上创建图层、修改属性和布局。

## 怎么上手

1. 打开 mastergo.com，点「免费注册」；也可以下载 Windows / Mac 客户端。
2. 新建原型文件或设计文件，从画布里打开 AI 功能。
3. 先试 AI 快搭：用一段话描述页面，或上传一张参考截图。
4. 把生成的界面插入画布，按团队规范调整组件和样式；需要代码时查看生成的 Vue / React 代码。
5. 团队协作时邀请成员评论，工程师进入研发模式查看标注、复制 CSS 等代码片段。

可以这样开始：

```
生成一个 SaaS 后台的「客户列表」页面：左侧导航，顶部搜索和筛选，中间表格包含客户名、负责人、状态标签、最近跟进时间，右上角「新建客户」按钮，使用浅色主题
```

## 免费与付费

定价页（2026-10 查询）列出四种版本：

- **初创版（免费）**：个人草稿箱 10 个文件、团队最多 3 人、每个文件 3 页、页面图层上限 1 万、不支持标注模式。
- **团队版**：文件、页面、成员等基本不限，支持标注模式、团队字体库、自定义切图规范等。
- **企业版**：在团队版基础上增加研发模式、企业管理后台、SSO、操作日志、权限管控等。
- **私有部署版**：本地部署，可选网络隔离、资产迁移、设计系统咨询等服务。
- 席位分设计席位、产品席位、研发席位。具体价格以官网定价页为准，企业客户可电话或在线咨询。

## 适合谁 / 不适合谁

**适合：**
- 国内中大型企业的设计团队，需要设计系统、权限管控和私有化部署。
- 前端团队想减少「切图还原」工作，用 D2C 和 MCP 打通设计和代码。
- 产品经理想用 AI 快速出高保真原型去评审。

**不适合：**
- 个人重度使用但不想付费的人：免费初创版的文件数和页数限制较紧。
- 主要做平面海报、运营图的用户。
- 依赖大量海外插件生态的团队。

## 注意事项

- **生成代码要评审**：AI 生成和 D2C 输出的代码进入生产前，仍需前端工程师审查结构、可访问性和安全性。
- **设计系统是前提**：「生成即合规」依赖团队已有规范完整的组件库，规范不全时生成结果也会偏离。
- **保密项目**：未发布产品的设计稿可考虑企业版的权限、IP 访问限制或私有部署。
- **素材授权**：AI 生成的图片和图标商用前确认符合服务协议。
