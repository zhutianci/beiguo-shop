## 是什么

Relume 是一款面向网站设计师和 Webflow 开发者的 AI 工具。它最早以「全球最大的 Webflow 组件库」出名，后来加入 AI，把建站前期最费时间的规划工作——页面结构怎么排、每页放哪些区块——自动化。它生成的不是一张图，而是由真实组件拼出来的线框图，可以带进设计和开发流程。

## 能做什么

定价页列出的功能：

- **Brief → Sitemap → Wireframe → Designs**：从一段需求简报生成完整的站点结构，再逐页生成线框图和设计。
- **Style guide**：统一设置颜色、字体和间距等设计变量。
- **Component library**：1,000 多个现成组件，有 Webflow 和 React 两种版本。
- **Relume Export**：把项目导出到 Figma、Webflow 或 React。
- **Relume Publish**（测试中）：直接上线，提供托管、自定义域名和访问统计。
- **AI Agents**：负责策略、文案、设计和数据分析的专门智能体，它们提出修改建议，由你批准后生效。
- **Library MCP**：把 Relume 组件库接入你的 AI 编辑器。
- **协作**：付费方案可以邀请不限数量的编辑者，不按席位另收费。
- **表单**：内置表单收集咨询信息。

官网说明组件库与 Finsweet 的 Client-First 规范兼容；复制组件功能支持 Chrome、Firefox、Edge，不支持 Safari。

## 怎么上手

1. 在 relume.ai 注册免费账号。
2. 写一段简报：公司做什么、目标客户是谁、网站要达成什么目的。
3. 检查生成的站点地图，增删页面和区块，再生成线框图。
4. 设置风格指南后，导出到 Figma 做视觉细化，或导出到 Webflow / React 进入开发。

## 免费与付费

定价页（美元，2026-10 查询）：

- **Free**：永久免费、无需绑卡。网站数量不限；可用 30 个 Webflow 组件和 30 个 React 组件；发布在 relume.live 子域名下，始终显示 Relume 标识；每月 1,500 次页面浏览、20 条表单提交；私密分享最多 3 人。
- **付费方案**：页面分两条产品线标价——组件库方向的 Pro「14 美元/月起」；建站方向的 Starter「18 美元/月起」、Pro「40 美元/月起」、Team「36 美元/月起（至少 3 人）」；另有「12 美元/项目/月起」的上线托管附加项和定制报价的 Enterprise。

「起」之后的实际金额与月付、年付差异，以官网定价页为准。

## 适合谁 / 不适合谁

**适合：** 接企业官网项目的设计师和 Webflow 开发者；需要在提案阶段快速给客户看站点结构的代理公司；用 React 搭营销站的前端。

**不适合：** 想要一键生成并长期免费托管正式网站的人；做复杂 Web 应用界面的团队（它面向的是营销型网站）；主要使用 Safari 的用户。

## 注意事项

- AI 生成的文案是占位性质的，正式上线前需要重写。
- 导出到 Webflow 需要相应的 Webflow 账号与权限，费用另算。
- 各方案的 AI 用量有上限，大型站点在生成前先规划好页面数量。
