> 本文根据 Deepgram 官网定价页整理，资料核对于 2026-10-11。这是一条面向开发者的简介，模型与价格以官网为准。

## 是什么

Deepgram 是一家做语音 AI 的公司，面向开发者提供 API：语音转文字、文字转语音、语音智能体和音频理解。普通用户接触到的会议转写、电话客服机器人、语音助手，背后往往就是这类接口。Deepgram 的特点是低延迟的实时流式能力，适合对话类产品。

## 能做什么

定价页列出的产品与模型：

**语音转文字（Speech-to-Text）**

- **Nova-3**：官方称性能最高、推荐用于大多数场景的模型。
- **Flux**：面向实时语音智能体的对话式识别模型，内置「说话轮次」检测——能判断对方是不是说完了。

**文字转语音（Text-to-Speech）**

- **Flux TTS**：最新的语音合成模型。
- **Aura-2 / Aura-1**：面向语音助手的低延迟合成。

**Voice Agent API**

- 构建实时对话式 AI 智能体的一体化接口，能处理用户打断。

**Audio Intelligence（音频理解）**

- 摘要、主题检测、情绪分析和意图识别。

## 怎么上手

1. 在 deepgram.com 注册，获取赠送额度和 API Key（不需要信用卡）。
2. 在官网的在线试用界面上传一段录音，查看转写效果和延迟。
3. 按官方文档调用接口：录音文件用预录制接口，实时场景用流式接口。
4. 要做电话或语音助手类产品，直接评估 Voice Agent API，省去自己拼接识别、大模型和合成三段。

## 适合谁 / 不适合谁

**适合：** 开发会议转写、字幕、电话客服、语音助手的团队；需要实时、低延迟语音能力的产品；想用赠送额度做原型的开发者。

**不适合：** 不写代码、只想把录音转成文字的普通用户（用现成的转写应用更方便）；以中文方言或小语种为主的业务（各语言的支持与准确率需自行测试）；数据不能出境的场景。

## 注意事项

- 流式与预录制、单语种与多语种的单价不同，按实际调用方式估算。
- 语音数据包含个人信息，注意录音告知、存储与删除策略。
- 转写不可能百分之百准确，涉及法律、医疗等记录时需要人工校对。
