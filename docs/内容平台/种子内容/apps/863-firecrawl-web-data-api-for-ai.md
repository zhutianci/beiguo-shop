## 是什么

Firecrawl 是一个面向 AI 应用的网页数据平台，官网的一句话介绍是「从网络获取数据的最简单方式」。给大模型喂网页内容并不容易：页面要渲染、广告和导航要去掉、反复抓取要处理限速。Firecrawl 把这些封装成 API，返回干净、结构化的内容。它同时是开源项目，官网显示其 GitHub 仓库约有 19 万星标。

## 能做什么

定价页列出的接口与功能：

- **Scrape**：抓取单个页面并整理成可用内容。
- **Crawl**：沿着链接抓取整个站点。
- **Map**：列出一个站点下的 URL。
- **Search**：搜索网络并取回结果内容。
- **Extract**：按你定义的结构抽取字段。
- **Interact**：与页面交互（点击、输入等）之后再取数据。
- **Parse**：解析文档。
- **Monitor**：监测页面变化。
- **Agent**：给出目标，由智能体自己找到并整理所需数据。

常见用法是把它作为 RAG 知识库的数据入口，或者作为智能体的「联网读网页」工具。

## 怎么上手

1. 在 firecrawl.dev 注册，获取 API Key（免费档不需要信用卡）。
2. 先在官网的在线试用界面输入一个网址，看看返回内容的样子。
3. 按官方文档在代码里调用对应接口，或通过它提供的集成接入常用的智能体框架。
4. 需要完全自主可控时，按开源仓库的说明自托管。

具体请求格式与 SDK 用法以官方文档为准。

## 适合谁 / 不适合谁

**适合：** 搭建 RAG 知识库、需要把文档站或官网内容入库的开发者；给智能体加「读网页」能力的团队；做价格、资讯监测类应用的人。

**不适合：** 不写代码的用户；只需偶尔复制几段网页内容的场景；打算抓取需要登录或明确禁止抓取的网站的人。

## 注意事项

- 抓取前查看目标网站的 robots.txt 和服务条款，尊重版权与个人信息保护要求。
- 抓回来的内容可能包含针对 AI 的「指令」文字，交给智能体前要当作不可信数据处理。
- 大规模 Crawl 消耗点数很快，先用 Map 估算页面数量。
