## 是什么

Fireworks AI 是一家提供模型推理服务的公司，主要售卖**开源模型的 API 访问**。它和 Together AI、Groq 等属于同一类「推理云」：帮你把开源模型部署好、优化好速度，你按用量付费调用。对开发者来说，选这类平台通常是为了三件事——比自建便宜、比自建快、不用管运维。

## 提供什么

官网定价页分成三块：

- **Serverless Inference（无服务器推理）**：按 Token 计费，分别统计输入、输出和缓存命中的 Token；采用预付费的用量制，可以开启自动充值，也可以设置每月消费上限。
- **On-Demand Deployments（按需部署）**：给你独占的 GPU，按 GPU 秒计费，启动不额外收费。定价页举例：H100 80 GB 为每小时 8.00 美元。
- **Training（训练 / 微调）**：托管的 LoRA 监督微调，16B 参数以内的模型为每百万训练 Token 0.50 美元。

向量模型的示例价格：1.5 亿参数以内的嵌入模型每百万输入 Token 0.008 美元。各对话模型的具体单价见官网模型库。

## 怎么上手

1. 在 fireworks.ai 注册，进入控制台充值并创建 API Key。
2. 在模型库里挑选模型，用 Playground 测试。
3. 使用官方 SDK 或兼容 OpenAI 的接口调用（接口地址和模型标识以官方文档为准）。
4. 先设置好每月消费上限，再接入正式流量。

## 免费与付费

全部按用量计费，没有固定月费的个人订阅。定价页没有写明新账号的赠送额度，是否有试用金以注册后控制台显示为准。企业客户可以联系销售谈预留容量和折扣。

## 适合谁 / 不适合谁

**适合：**
- 在产品里大量调用开源模型、对响应速度和成本敏感的开发团队；
- 需要把自己微调后的模型托管上线的团队；
- 流量波动大、想先用无服务器模式起步，再平滑切到独占 GPU 的项目。

**不适合：**
- 不写代码的普通用户；
- 只需要闭源旗舰模型的团队；
- 数据必须境内存储处理的业务。

## 注意事项

- **预付费模式**：余额用完请求会失败，生产环境要配置自动充值或余额告警，同时设好消费上限防止异常流量。
- **缓存 Token 单独计价**：合理利用提示词缓存可以明显降低成本。
- **独占部署按秒计费但不会自动消失**：不用时记得缩容或删除部署。
- **同一模型在不同平台的表现有差异**：上下文长度、工具调用支持、量化精度都要自己验证。
