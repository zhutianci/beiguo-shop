> 本文根据 fal 官网与定价页整理，资料核对于 2026-10-11。模型与价格变化快，以官网为准。

## 是什么

fal 是一个**生成式媒体平台**：把市面上主流的视频、图像、音频和 3D 生成模型做成统一的、按次付费的 API。很多 AI 修图、AI 视频类的应用和网站，后台调用的就是这类平台，而不是自己部署模型。

和 Replicate 相比，fal 更聚焦在媒体生成这一类，并强调推理速度；和各模型的官方 API 相比，它的好处是一个账号、一套接口就能切换不同厂商的模型。

## 提供什么

官网定价页列出的产品：

- **Model APIs**：按产出单位计费的模型接口；
- **Serverless & Compute**：无服务器部署自己的模型，或直接租用 GPU；
- **Enterprise**：企业方案。

## 怎么上手

1. 在 fal.ai 注册并登录，在模型库里找到要用的模型。
2. 每个模型页都有在线试用区和参数说明，先在网页上试效果。
3. 创建 API Key，按模型页的示例代码调用（提供 JavaScript、Python 等客户端）。
4. 视频等耗时任务使用队列模式：提交请求，之后轮询状态或用 Webhook 接收结果。

## 免费与付费

模型 API 按产出计费。定价页上的例子（美元，2026-10 查询）：

| 模型 | 计费 |
| --- | --- |
| H3 Max 文生视频 | 每秒视频 0.05 美元 |
| Nano Banana 2 | 每张图 0.08 美元 |
| ElevenLabs TTS Multilingual v2 | 每 1,000 字符 0.10 美元 |

GPU 算力按小时计费，页面写明 H100 最低 2.49 美元/小时起，其他规格的标价在 4.00 至 12.99 美元/小时之间。定价页没有提到免费额度，新账号是否有试用金以注册后显示为准。

## 适合谁 / 不适合谁

**适合：**
- 开发 AI 图片、视频、配音类应用的团队和独立开发者；
- 需要在多个视频 / 图像模型之间做 A/B 对比的产品；
- 用 ComfyUI、自动化工具搭工作流，需要通过 API 调用云端模型的创作者。

**不适合：**
- 不写代码、只想生成内容的用户——直接用各模型的官方应用；
- 主要需求是文本大模型的团队；
- 预算固定、希望包月不限量的个人创作者。

## 注意事项

- **视频很贵**：按秒计费的视频模型，一条十几秒的高规格视频就可能花掉不少钱，批量跑之前先小量测试。
- **同一个模型有多个变体**：标准版、快速版、不同分辨率的单价不同，调用前看清模型标识。
- **内容与版权责任**：平台只提供接口，生成内容的合规和商用授权取决于各模型提供方的条款。
- **结果文件要自己保存**：返回的文件链接不保证长期有效。
