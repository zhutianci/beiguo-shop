> 本文根据即时设计官网首页整理，资料核对于 2026-10-11。功能和价格变化快，以官网为准。

## 是什么

即时设计（js.design）是一款国产的专业 UI 设计工具，官网的介绍是「可云端编辑的专业级 UI 设计工具，为中国设计师量身打造」，还有一句更直白的定位：「Windows 也能用的协作版 Sketch」。它和 Figma 属于同一类产品——文件存在云端，浏览器里打开就能画，多个人可以同时编辑同一份设计稿。

官网写明支持网页端、macOS、Windows、Linux、iOS、安卓和微信小程序，登录方式包括微信和飞书。

## 能做什么

**设计与协作（主体功能）：**

- **实时协同**：多位设计师同时创作；产品经理评审、评论；研发查看实时更新的设计稿，获取切图、标注和代码样式。
- **文件迁移**：导入 Figma、Sketch、XD 等格式，也能导出 Sketch 文件。
- **组件系统与原型交互**：把设计图做成可点击的高保真交互演示。
- **资源社区**：官网称有数千款设计资源、设计规范和 Mockup 可直接使用，另有插件广场。
- **数据安全**：自动保存、历史记录、可保存离线文件；提供私有化部署咨询。

**AI 相关：**

- 官网首页有「AI 设计纪元」板块，入口指向 **A1.art**——官方介绍为 AI 图像生成应用平台，一张图或一个词即可生成图像，可免费体验。
- 插件广场里有 AI 类插件，例如首页展示的「快速翻译」（文本和提示词中英互译，标注免费）和「标签识别」（识别图片中的文字并生成可编辑的文字图层，支持横排竖排）。

需要说明的是：即时设计的核心仍然是设计协作工具，AI 是辅助能力。如果你要的是「一句话生成整套界面」，请以官网当前实际提供的功能为准，不要只看第三方文章的描述。

## 怎么上手

1. 打开 js.design，用微信或飞书扫码注册登录。
2. 新建文件，或从资源社区复制一份模板、设计规范开始。
3. 已有 Figma / Sketch 文件的，用导入功能迁移过来。
4. 点右上角分享，邀请同事协作或给研发发只读链接看标注。
5. 在插件广场搜索并运行需要的 AI 插件。

## 免费与付费

官网首页多处标注「免费使用」，个人注册即可使用。团队版的成员数、项目数限制和价格，以及私有化部署的报价，核对时未在首页列出，以官网定价页或销售沟通为准。A1.art 的生成额度同样以其页面为准。

## 适合谁 / 不适合谁

**适合：**
- 国内的 UI / UX 设计师和产研团队，尤其是使用 Windows 的成员较多的团队；
- 想从 Sketch、XD 迁到在线协作工具的团队；
- 学习界面设计的学生，中文资源和社区模板多。

**不适合：**
- 已经深度使用 Figma 及其插件生态、团队也都能顺畅访问的公司；
- 主要需求是 AI 直接生成界面或网页代码的人；
- 做印刷品、复杂插画的设计师，应使用矢量或位图类专业软件。

## 注意事项

- **导入不是百分之百还原**：复杂的自动布局、特殊字体和插件生成的内容，迁移后要逐页检查。
- **字体版权**：商用设计稿里使用的字体要自行确认授权。
- **分享链接的权限**：对外分享前确认是「可查看」还是「可编辑」，离职成员要及时移出团队。
- **AI 生成图片的版权与合规**由使用者负责，商用前阅读对应平台的条款。
