> 本文根据 Hedra 官网首页与定价页整理，资料核对于 2026-10-11。功能和价格变化快，以官网为准。

## 是什么

Hedra 是一家做视觉生成模型的公司，官网的自我介绍是：构建能「生成、感知并预测视觉世界」的模型，以及把这些模型跑在生产环境里的平台。不少创作者是因为它的角色说话视频（给一张角色图和一段声音，生成角色对着镜头讲话的片段）知道它的；现在官网展示的范围更大，覆盖图像、视频和音频的整套生成流程。

## 有哪些产品

官网当前列出的几块：

- **Creative Studio**：面向创作者的在线创作台，定价页的各档方案对应的就是它；
- **Hedra Agent**：一个创作智能体，能规划并执行多步骤的图像、视频和音频工作——你描述想要的成片，它把任务拆开逐步生成；
- **Developer API**：当前为 API v3，采用异步的生成任务方式，并提供模型目录；定价页称它为各家主流模型提供统一的推理入口；
- **Hedra MCP server**：让开发者把视觉生成能力接入自己的应用和智能体；
- **Enterprise**：企业方案。

## 怎么上手

1. 在 hedra.com 注册并进入 Creative Studio。
2. 准备素材：角色或产品图片、台词或音频、参考画面。
3. 选择生成类型和模型，提交任务后等待结果；视频类任务需要排队，付费档速度更快。
4. 想省事可以把整体需求交给 Hedra Agent，让它分步骤完成，再对不满意的环节单独重做。
5. 下载素材，在剪辑软件里合成、加字幕。

做角色口播类内容时，图片用正面、五官清晰的角色图，台词写成口语化的短句、每段十几秒以内，成功率更高。

## 适合谁 / 不适合谁

**适合：**
- 做角色类短视频、虚拟形象口播、动画短片的创作者；
- 想把音频内容做成有画面的视频的人；
- 需要通过 API 或 MCP 在产品里集成图像、视频生成的开发团队。

**不适合：**
- 需要长时间、多镜头连贯叙事的成片——目前仍以片段生成为主，要靠后期拼接；
- 想要标准化企业培训视频的团队，HeyGen、Synthesia 这类数字人平台的模板和多语言流程更成熟；
- 希望长期免费大量生成的用户。

## 注意事项

- **肖像与声音授权**：不要使用未经本人同意的真人照片或声音；他人作品中的角色同样有侵权风险。
- **AI 生成内容标识**：在国内平台发布时，按平台规则添加 AI 生成标识。
- **积分消耗与时长、分辨率和所选模型有关**，生成前留意提示的消耗。
- **商用范围**以所购方案的条款为准；平台接入的第三方模型还可能有各自的限制。
