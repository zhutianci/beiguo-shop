> 本文根据讯飞星火官网和 App Store 应用介绍整理，资料核对于 2026-10-07。功能和价格变化快，以官网为准。

## 是什么

讯飞星火是科大讯飞推出的 AI 助手，基于讯飞自研的星火认知大模型，官网 xinghuo.xfyun.cn（网页对话入口在官网「立即对话」）。App Store 介绍称它是国内主流大模型中唯一基于全国产算力训练的通用大模型，最新的星火 X2 在数学、语言理解、推理、翻译上全面升级，官网的 API 页面已列出新一代旗舰「星火深度推理模型 X2.5」。

讯飞以语音技术起家，星火的特色也很鲜明：语音对话自然、能切换方言和情感风格，多语种翻译覆盖 130 多种语言。

## 能做什么

- **求职全流程**：汇总招聘信息，按岗位生成匹配的简历，多种模板可选；还有一对一虚拟人模拟面试。
- **学术论文辅助**：选题、开题报告、文献深度研读、学术搜索，以及文本润色、逻辑梳理和 AIGC 检测。
- **多语种翻译**：支持 130 多个语种，官方称拉美、东盟等地区语种效果在国内领先。
- **深度推理与研究**：把数学、编程等复杂问题逐步拆解；深度调研可聚合全网信息生成万字行业报告。
- **内容写作**：从小红书笔记到会议纪要、视频脚本、营销方案，60 多种文案风格。
- **语音交互与录音纪要**：超拟人语音可随时打断、切换方言；录音实时转文字并提炼会议重点。
- **PPT 生成、图像生成、拍照解题**：一键生成 PPT，文字生成多风格图片和虚拟人祝福视频，拍照解题给出思路。

## 怎么上手

1. 打开 xinghuo.xfyun.cn 点「立即对话」，或在应用商店搜索「讯飞星火」，认准开发者信息与官网一致。
2. 按页面提示注册登录。
3. 首页按场景选入口：深度研究、写作润色、解疑答惑、精准翻译、全能阅读。
4. 找工作的话进入简历优化，上传旧简历和目标岗位描述，再做一轮模拟面试。
5. 开会时打开录音纪要，会后让它整理要点和待办。

可以这样开始：「我想应聘新媒体运营，附件是我的简历和岗位 JD，请按 JD 改写简历，突出数据成果，并给我 5 个面试可能被问到的问题。」

## 免费与付费

- **免费**：对话、写作、翻译、文档问答、PPT、拍照解题等功能可以免费使用。
- **求职 AI 助手会员**：App 内另有求职类会员，价格以 App 内订阅页为准。
- **开发者**：星火 API 提供深度推理、场景化 API 和模型微调，按官网开放平台价格计费。

其他功能是否另设会员和额度，以 App 内显示为准。

## 适合谁 / 不适合谁

**适合：**
- 求职者：简历改写加模拟面试，一个 App 走完准备流程。
- 需要多语种翻译、外语陪练的外贸人员和语言学习者。
- 经常开会、听讲座的人：录音纪要是讯飞的老本行。

**不适合：**
- 想要大量生成高质量图片、视频的创作者。
- 需要 AI 深度操作电脑、长时间自动执行任务的用户。
- 只用英文工作、需要英文资料检索的人。

## 注意事项

- **医疗内容**：讯飞官方在介绍里写明，医疗方面的建议不能替代专业医生的诊断和治疗，紧急健康问题应及时就医。
- **论文与 AIGC 检测**：AI 辅助写作要遵守学校和期刊规定，检测结果仅供参考。
- **录音合规**：录制会议、访谈前取得参与者同意。
- **自动续费**：会员到期前 24 小时自动扣费，不需要时到 iPhone「设置 → Apple ID → 订阅」中取消。
