> 本文根据 Vidu 官网（国内版 vidu.cn、国际版 vidu.com）、官方定价说明和 App Store 介绍整理，资料核对于 2026-10-07。功能和价格变化快，以官网为准。

## 是什么

Vidu 是 **北京生数科技有限公司**（ShengShu Technology）推出的 AI 视频生成平台。国内用户用 vidu.cn，海外用户用 vidu.com（国际版），手机端有官方「Vidu AI」App。

当前主力模型是 **Vidu Q3**：官网称它支持 16 秒「音画同出」，即一次生成同时给出画面和声音，并支持「智能切镜、一键直出」，覆盖动画、真人、广告和短片。此外还有官网称为「全球首个实时交互模型」的 **Vidu S**（毫秒级响应、边说边生成）：据生数科技 2026 年 7 月 3 日通过美通社发布的新闻稿，Vidu S1 可以用一张图创建可实时对话、受语音控制的角色视频。

## 能做什么

- **参考生视频**：上传多张参考图（如角色、场景），让生成的视频保持角色和风格一致；官网展示的创作者评价里，多主体参考是被提到最多的功能，常用于漫剧和动画。
- **图生视频**：上传一张图，让画面动起来。
- **文生视频**：直接用文字描述生成带运镜的片段。
- **16 秒音画同出**：Q3 一次生成就带声音，App 介绍称自动生成的音效与画面同步，导出即可发布。
- **参考生图 / 文生图**：先生成角色设定图和分镜图，再拿去生成视频。
- **Vidu Agent**：从一句话需求出发，由 Agent 协助完成整条作品。
- **AI 模板与工具**：大量现成特效模板，选好即用。

## 怎么上手

1. 打开 vidu.cn 点「立即体验」，或在 App Store 搜索「Vidu AI」（开发者为北京生数科技有限公司），按页面提示登录。
2. 先试「参考生视频」：上传同一角色的几张参考图（角度不同更好），再写动作描述。
3. 按页面选项选择 Q3 模型、时长和画面比例等参数，在描述里写明想要的声音效果。
4. 生成后对比几个版本，挑选角色最稳定的一条；不理想就补充参考图或简化动作描述。
5. 多段视频导出后，在剪辑软件里拼接、加字幕。

可以这样开始：

```
参考生视频：参考图中的少女剑客站在竹林里，风吹动竹叶，她缓缓拔剑转身，镜头从远景切到面部特写，国风动画风格，带风声和拔剑音效
```

## 免费与付费

Vidu 用积分计费。官方定价说明把积分分成三类：**订阅积分**（随套餐发放，30 天有效）、**购买积分**（按需加购，2 年有效）、**奖励积分**（活动、比赛或创作者计划获得，2 年有效）；注册赠送、每日登录和参与活动也能拿到积分。订阅分个人版和企业版多个档位，**具体价格以官网订阅套餐页为准**。开发者可在 Vidu API 开放平台按量调用。

## 适合谁 / 不适合谁

**适合：**
- 做 AI 漫剧、动画短片的创作者，需要多张参考图锁定角色形象。
- 二次元、国风风格内容创作者，官网和用户评价都强调动画表现。
- 社媒和电商运营，需要 16 秒左右、带声音的现成短片。

**不适合：**
- 需要一次生成一分钟以上长镜头的人，仍需分段生成。
- 对写实真人广告有极高要求的项目，建议多平台对比后再定。
- 只想偶尔玩一下、不愿意研究参考图的用户，模板类 App 更省事。

## 注意事项

- **参考图的版权和肖像**：参考图里的角色、人物需是你自己创作或已获授权的；不要用明星、公众人物照片生成视频，也不要用知名 IP 角色做商用内容。
- **商用条款**：生成内容的商用范围以官网《服务协议》和所购套餐说明为准。
- **积分有效期**：订阅积分 30 天过期，按需使用，避免囤积浪费。
- **国内版与国际版**：两个版本账号、价格和功能上线节奏可能不同，按你所在地区选择官方入口。
- **AI 标识**：发布到国内平台时按规定标注 AI 生成。
