## 是什么

invideo（常被搜作 Invideo AI）是 **Invideo Inc**（App Store 开发者名）推出的 AI 视频创作平台，官网 invideo.io。官方现在把它定位为「为认真创作者打造的 Agent 视频编辑器」：由 AI Agent 处理繁琐的剪辑工作，人来负责导演和把关。

核心是名为 **Agent Two** 的编辑 Agent：你用日常语言告诉它要做什么或改什么，它会在一条真实的多轨时间线上完成剪辑，你可以在任意一帧接手手动修改。App Store 介绍称平台集成了 200 多个 AI 模型，可生成图像、视频、配音、音效和音乐。

## 能做什么

- **Agent Two 对话式剪辑**：用一句话描述剪辑需求，比如「把所有停顿剪掉、统一调色」，Agent 一次应用到时间线上的全部镜头。
- **素材记忆检索**：编辑 Agent 会「看过」每段素材并记下内容，你描述某个画面就能找到对应片段。
- **脚本与分镜**：在 invideo 里写脚本，可让 AI 协助写作；把脚本或想法拆成逐镜头的分镜，确认后再生成。
- **专业时间线**：多轨时间线编辑，带调色、音频和 3D 等专业工具。
- **多人协作**：实时协作，能看到其他成员的光标和评论。
- **自定义 Agent**：搭建「编剧」「摄影指导」「音效师」「调色师」等角色 Agent，也可以把外部 AI Agent 接入 invideo 编辑器。
- **多模型生成**：调用 Seedance 等视频模型和 Nano Banana Pro 等图片模型补充画面。

## 怎么上手

1. 打开 invideo.io 点 Sign up 注册，或在 App Store 下载「invideo: AI Video Editor」。
2. 先到定价页选择适合的套餐（定价页列出的是付费档，没有标出免费档）。
3. 新建项目，上传一段你拍好的素材，或直接输入一个视频创意。
4. 在对话框告诉 Agent Two 你想要的效果，让它先出一版粗剪。
5. 在时间线上检查每一处修改，手动调整节奏、字幕和音乐后导出。

可以这样开始（对 Agent Two 说）：

```
把这段 10 分钟的产品讲解剪成 60 秒竖屏广告：保留三个核心卖点，去掉所有停顿和口误，加上节奏明快的背景音乐和大字幕，结尾放购买引导。
```

## 适合谁 / 不适合谁

**适合：**
- 有大量原始素材要剪的创作者和广告团队，想把重复性剪辑交给 Agent。
- 做微短剧、系列广告的团队，需要在多集、多版本里保持角色和风格一致。
- 小团队协作剪片，需要实时多人编辑和评论。

**不适合：**
- 只想免费试试的人：定价页没有列出免费档。
- 以中文口播为主的创作者：官网以英文内容为主，中文素材的识别和剪辑效果需先小范围测试。
- 预算紧、生成量大的个人，积分按月清零。

## 注意事项

- **换脸类工具慎用**：官网工具列表里有 Face Swap（换脸）等功能，只能用于你本人或已取得对方明确同意的人像，不要用于明星、公众人物或任何冒充他人的内容。
- **积分不结转**：每月积分到期清零，大项目集中在一个计费周期内完成更划算。
- **AI 剪辑要复核**：Agent 批量修改可能误伤镜头，导出前完整回看。
- **素材版权**：上传的素材和使用的库存素材要确认授权范围，商用以服务条款为准。
- **地区与支付**：以官网支持的地区和支付方式为准；发布到国内平台时按规定标注 AI 生成。
