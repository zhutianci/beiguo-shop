## 是什么

TRAE 是字节跳动旗下的 AI 开发工具品牌（国内版运营主体为北京引力弹弓科技有限公司，企业版分别通过火山引擎和 BytePlus 提供）。现在官网把产品分成两条线：

- **TraeCode**：AI 编程工具，即大家常说的“Trae IDE”，此外还有 TraeCode Plugin（装进 VS Code、JetBrains 等现有 IDE）和 TraeCode CLI；
- **TraeWork**：新上线的 AI 办公平台，有网页、桌面和手机端，设有 Work、Code、Design 三种模式。

TRAE 分 **国内版（trae.cn）** 和 **国际版（trae.ai）** 两个站点，账号、模型和计费都分开：国内版内置字节跳动 Seed 系列、GLM、DeepSeek 等国产模型，按人民币“积分”计费；国际版提供 Auto 模式和更多模型选择，按美元订阅。官方文档还说明 TraeCode 支持通过 API Key 接入自定义模型。

**和同类的区别**：TRAE 是本批工具里少有的提供完整中文界面、中文文档、国内可直接付款并内置国产模型的 AI IDE；免费档就开放全部功能。它的 SOLO 模式则让 AI 主导从需求到预览的全过程，介于 Cursor 式编辑器和 Lovable 式应用生成器之间。

## 能做什么

- **IDE 模式**：保留编辑器、终端、调试、插件、Git 等熟悉的工作流，适合需要精细控制改动的场景。
- **SOLO 模式**：用文字或语音描述需求，AI 自动规划任务，推进代码生成、测试、预览和变更总结。
- **CUE 智能补全**：代码补全、多行修改、修改点预测与跳转，在 Python、TypeScript、Go 项目中还能辅助导入依赖和重命名。
- **自定义智能体**：为智能体配置提示词、MCP Server 和工具集，适配不同任务；可把文件、终端输出、文档集、网页等作为上下文。
- **代码审查与远程开发**：总结并审查未提交变更或分支差异；支持 Remote SSH 和 WSL。
- **插件版**：不想换编辑器，可在 VS Code、JetBrains 系列、Android Studio 中安装 TraeCode Plugin，使用补全、解释、生成单测等功能。

## 怎么上手

1. 国内用户打开 www.trae.cn，进入“下载中心”，选择 TraeCode 的 macOS（12.0+，Apple Silicon）、Windows（10/11，x64）或 Linux（.deb / .rpm）版本；海外用户使用 www.trae.ai。
2. 安装后登录 TRAE 账号。国内版下载页写明新用户下载登录可获赠积分（以活动页面为准）。
3. 打开一个项目文件夹，先在 IDE 模式下用对话面板让 AI 解释代码结构。
4. 想让 AI 全程主导时切换到 SOLO 模式，用一句话描述要做的东西。
5. 在设置中按需开启隐私模式和沙箱运行。

可以这样开始（SOLO 模式）：

```text
做一个记账网页：可以添加收入和支出、按月份统计、用饼图展示分类占比，数据先保存在浏览器本地。完成后运行并给我预览。
```

## 适合谁 / 不适合谁

**适合：**
- 希望中文界面、人民币付款、国内网络环境下直接使用的开发者和学生；
- 想低成本试用 AI IDE 的人——国内版免费档开放全部功能；
- 想让 AI 一句话做出原型的产品、运营人员（SOLO 模式）。

**不适合：**
- 需要固定使用 Claude、GPT 等海外模型的人——国内版内置的是国产模型（可自配 API Key，但需自行解决对应服务的合规与可用性）；
- 对代码数据出境或供应商有严格合规要求、但尚未评估 TRAE 企业版的团队；
- 只在 Xcode 等未被插件支持的 IDE 中开发的人。

## 注意事项

- **两版不互通**：国内版和国际版是两个独立站点，账号、积分、模型列表和价格不同，购买前确认自己用的是哪个版本。
- **隐私模式**：官方文档说明，开启隐私模式后，TraeCode 不会把你的对话、代码片段和 AI 输出用于数据分析、产品优化或模型训练，代码库文件始终保存在本地。
- **沙箱运行**：智能体生成的命令可以放在受限环境执行，并拦截高风险命令，建议开启。
- **设备数量**：官方文档对单账号可登录的设备数量有限制，多台电脑使用前先查看说明。
- **核对 AI 产出**：SOLO 模式生成的项目同样需要人工检查逻辑、安全和依赖许可。
