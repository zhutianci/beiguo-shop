## 是什么

n8n 是一个工作流自动化平台，仓库 n8n-io/n8n 在 GitHub 上约有 20.7 万星标。它的界面是一张节点画布：每个节点代表一个触发器、一个应用操作或一段代码，把节点连起来就是一条自动运行的流程。官方现在把它定位为「搭建 AI 智能体与工作流自动化」的平台，既有可视化操作，又允许在流程里写代码。

它和 Zapier、Make 的最大区别是**可以自托管**：把 n8n 跑在自己的服务器上，数据不经过第三方，执行次数也不按条收费。

## 能做什么

- **连接应用与 API**：README 写明有 1500 多个集成和 9,000 多个模板，没有现成节点时可以用 HTTP 请求节点调用任意接口。
- **AI 原生流程**：用自己的数据、模型和工具搭多步骤智能体，可接 OpenAI、Anthropic、Google 或开源模型，换模型不用重搭流程。
- **写代码**：在流程里插入 JavaScript 或 Python，引入 npm 包。
- **触发方式**：定时、Webhook、应用事件、聊天消息等。
- **企业能力**：自托管、基于角色的权限、审计日志等。

## 怎么上手

**想先试试**：在 n8n.io 注册云端试用，从模板库挑一个接近需求的模板改。

**自部署**（README 提供的 Docker 方式）：

```bash
docker volume create n8n_data
docker run -it --rm --name n8n -p 5678:5678 -v n8n_data:/home/node/.n8n docker.n8n.io/n8nio/n8n
```

然后在浏览器打开 `http://localhost:5678`。第一个流程建议做简单的：「定时触发 → 抓取一个 RSS → 让大模型总结 → 发到邮箱或群」。

## 适合谁 / 不适合谁

**适合：**
- 有一点技术基础、想把重复的跨系统操作自动化的运营、增长和开发人员；
- 需要把数据留在内网的团队；
- 想用可视化方式搭 AI 智能体、又希望随时能写代码兜底的人。

**不适合：**
- 完全没有技术背景、也不想了解 API 和 JSON 的用户，上手会比 Zapier 吃力；
- 不愿意维护服务器又嫌云端版贵的个人；
- 想把 n8n 嵌进自己产品里对外收费的公司——需要先确认许可范围。

## 注意事项

- **不是传统意义的开源许可**：n8n 采用 fair-code 模式，使用 Sustainable Use License 与 n8n Enterprise License，源码可见、可自托管，但商业再分发有限制。
- **凭据安全**：流程里会保存各平台的密钥，自部署务必开启访问控制、做好备份并及时更新版本。
- **模型费用另算**：AI 节点调用的大模型按各家 API 计费。
- **按执行次数计费**：云端版以「一次流程执行」计数，高频触发的流程要估算好用量。
