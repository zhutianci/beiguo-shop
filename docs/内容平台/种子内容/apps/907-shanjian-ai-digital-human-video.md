> 本文根据闪剪官网首页整理，资料核对于 2026-10-11。以官网为准。

## 是什么

闪剪 AI 是深圳市趣推科技有限公司运营的短视频创作工具，官网给自己的定位是「短视频营销 AI 创作工具」。它最主要的用途是**数字人口播**：不用真人出镜，输入一段文案，选一个数字人形象和配音，就能生成一条可以直接发布的口播短视频。

视频创作的网页工作台已经搬到 app.shanjian.tv，官网首页有跳转入口；另外有手机 App。

## 能做什么

- **智能成片**：官网的说法是输入一句话，即可生成可直接发布的短视频。
- **公共数字人和配音**：官网称提供 1000 多个公共数字人、500 多种公共配音，直接选用。
- **数字人定制**：上传约 30 秒的视频，可以复刻自己的形象和声音；也可以用一张图片快速定制「图生数字人」。定制 4K 数字人需要专业版卡位，并提交 4K 的训练视频。
- **直播切片**：把长直播自动剪成多条短视频。
- **照片数字人、AI 消除、视频加字幕** 等单项工具。
- **闪剪 Agent 与开放平台**：面向企业和开发者，可通过 API 接入，或部署成自有品牌的小程序。

## 怎么上手

1. 打开 shanjian.tv，进入工作台（app.shanjian.tv）或下载 App，注册登录；
2. 先用公共数字人试一条：粘贴文案，选形象和配音，生成后预览；
3. 效果合适再考虑定制自己的数字人——按页面要求录制并上传训练视频；
4. 成片导出后，按发布平台的要求添加 AI 生成内容的标识。

口播文案可以先让聊天助手帮你写：

```text
帮我写一条 40 秒的口播文案，主题是「小户型客厅显大的 3 个办法」，开头 3 秒要有钩子，每个办法一句话说清，结尾引导评论。口语化，不要书面词。
```

## 免费与付费

闪剪采用会员制，官网提到**基础版**和**专业版**两档，首页没有列出具体金额，请以官网价格页为准。需要注意官网的一条说明：**会员到期后，定制的数字人无法正常使用，续费后才能继续用**。开放平台的 API 另行计费。

## 适合谁 / 不适合谁

**适合：**
- 需要批量出口播视频的门店商家、知识类博主和企业新媒体团队；
- 不方便或不愿意出镜，但想持续更新短视频的人；
- 做直播、想把回放再利用成短视频的团队。

**不适合：**
- 追求电影感画面或复杂剪辑的创作者，这类需求用专业剪辑软件更合适；
- 只偶尔做一两条视频的人，会员制不一定划算。

## 注意事项

- **只能定制自己或已获授权的形象和声音**：用他人肖像、声音做数字人涉及肖像权和个人信息保护。
- **各平台对 AI 生成内容有标识要求**，发布前按规定标注。
- **数字人和会员绑定**：停止续费前想清楚已定制的形象是否还要用。
- **行业内容有合规红线**：金融、医疗健康等领域的口播内容，发布前先对照平台规则。
