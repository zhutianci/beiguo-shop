> 本文根据通义听悟官网、官网帮助中心和阿里云帮助中心整理，资料核对于 2026-10-07。额度与价格以官网为准。

## 是什么

通义听悟是阿里巴巴推出的「工作学习 AI 助手」，基于通义大模型，专做**音视频转文字和内容整理**。它面向两类人：普通用户在网页上直接用，开发者和企业则可以通过阿里云调用它的 API，把转写、总结能力接进自己的系统。

和单纯的「语音转文字」工具相比，它多了一层大模型整理：转写完会自动给出全文概要、章节速览、发言人总结、关键词和待办事项，还能从课程视频里提取 PPT 页面。

## 能做什么

- **实时记录**：开会、上课时打开实时记录，边说边出文字，可以用关键词搜索、点文字回放对应音频。
- **文件批量转写**：一次可上传 50 个本地音视频文件，也能直接转写阿里云盘里的文件和播客链接，自动区分发言人。
- **智能总结**：全文概要、章节速览、发言总结、问答回顾，长录音也能快速抓重点。
- **提取视频 PPT**：网课、讲座视频里出现的幻灯片会被截取出来并配上摘要，适合复习。
- **中英互译**：实时转写过程中和结束后都能一键开启中英互译。
- **标记与导出**：高亮重点、问题、待办；原文和译文可导出 Word、PDF、SRT 字幕，也可导出笔记和音视频。
- **自定义专有词汇**：把行业术语、人名加进词表，减少识别错误。

## 怎么上手

1. 用电脑浏览器打开 tingwu.aliyun.com，点「免费体验 / 立即体验」，按页面提示登录。
2. 开会或上课时，点「开始记录」进入实时记录，选择语言，允许浏览器使用麦克风。
3. 已有录音的，选择「上传音视频」，一次可拖入多个文件，或选择从阿里云盘导入。
4. 转写完成后在「我的记录」里打开，查看概要、章节和待办；人名或术语识别错的地方直接编辑修正。
5. 用「导出」生成 Word / PDF / 字幕文件，或通过链接分享给同事。

## 免费与付费

- **网页版**：普通用户可免费体验，官网另有「权益」页面领取和查看额度；各项权益的时长、次数官网会调整，**以登录后显示为准**。
- **阿里云 API 版**：面向开发者，按量计费。阿里云帮助中心写明新开通用户可免费试用 90 天；新版接口的音视频文件转写、实时记录均为 0.6 元 / 小时，大模型功能 0.064 元 / 小时，各能力叠加计费（阿里云帮助中心计费说明，2026-10 查询）。

## 适合谁 / 不适合谁

**适合：**

- 学生：网课、讲座录音转文字，配合 PPT 提取复习；
- 做访谈、调研、咨询的人：批量转写、区分发言人能省下大量整理时间；
- 需要把会议沉淀成文档的职场人，尤其是常用阿里云盘、钉钉的人；
- 想在自己产品里接入转写和总结能力的开发者（API）。

**不适合：**

- 主要在手机上随手录音的人：官网目前主推电脑端网页；
- 需要中英以外多语种同传的场景；
- 内容不能上传到云端的保密会议。

## 注意事项

- 录制他人讲话前先征得同意，涉及公司内部会议的遵守单位规定。
- 分享记录时注意链接权限，公开链接任何拿到的人都能打开。
- 大模型生成的概要、待办可能遗漏或误读，关键数字和结论回听原音核对。
- 阿里近年在整合 C 端 AI 产品（通义 App 已改名「千问」），听悟的入口和形态以后可能调整，以官网为准。
