## 是什么

Meshy 是一套生成式 AI 的 3D 工具箱，官网说明它面向 3D 美术、游戏开发者和 3D 打印爱好者。和只做「一键出模型」的工具相比，它的功能链条更长：从生成模型，到给已有模型重新上贴图，再到给角色自动绑定骨骼、套用动画，都在同一个网站里完成。

## 能做什么

- **Text to 3D（文生 3D）**：用文字描述生成模型。
- **Image to 3D（图生 3D）**：上传图片生成模型。
- **AI Texturing（AI 贴图）**：给你自己上传的模型生成贴图，支持上传 FBX、OBJ、STL、glTF、GLB。
- **AI Auto Rigging（自动绑定）**：给人形等角色自动加骨骼。
- **Animation（动画）**：为绑定好的角色套用动作。
- **导出格式**：文生 3D 与图生 3D 的结果可下载为 FBX、OBJ、USDZ、GLB、STL 或 BLEND。
- **插件与集成**：官方 FAQ 提到 Blender 和 Unity 插件，网站还列出了 Bambu Studio、Creality Print、OrcaSlicer、Unreal Engine 等集成，对做 3D 打印的人很方便。

## 怎么上手

1. 在 meshy.ai 注册免费账号（不需要信用卡）。
2. 进入工作台选择 Text to 3D 或 Image to 3D，输入提示词或上传图片。
3. 先看预览结果，满意后再做细化和贴图。
4. 角色类模型可以继续做自动绑定和动画。
5. 按用途选择导出格式：游戏引擎常用 FBX / GLB，3D 打印用 STL。

## 免费与付费

官网有 Free、Pro、Studio、Enterprise 四档。核对时定价页的价格卡片未能完整显示金额，这里只写页面明确的权益，**具体价格以官网定价页为准**：

- **Free**：每月 100 积分，每月 1 日（UTC 0 点）重置；生成的资产按 **CC BY 4.0** 授权，可以商用但必须署名；排队优先级低于付费用户。
- **Pro**：每月 1,000 积分（不累积到下月）；资产完全私有、归你所有；含 API 访问，官网称生成速度更快，最多 10 个并发任务。
- 页面显示新用户首月月付或年付有折扣，属于促销，不是长期标价。

## 适合谁 / 不适合谁

**适合：**
- 需要快速产出道具、角色原型的独立游戏团队；
- 已经有模型、只想让 AI 帮忙上贴图的美术；
- 用拓竹、创想三维等切片软件的 3D 打印玩家。

**不适合：**
- 需要精确工程尺寸的工业建模；
- 对拓扑和 UV 要求严格、不接受后期修整的正式项目；
- 不愿意署名又想商用免费档成果的用户——那需要升级付费档。

## 注意事项

- **免费档授权要看清**：CC BY 4.0 意味着别人也能看到并在署名前提下使用你的免费生成结果，保密内容不要用免费档做。
- **积分不结转**：当月没用完的订阅积分不会累积。
- **自动绑定有适用范围**：对标准人形效果较好，异形生物、复杂服饰常需要手动调整。
- **版权**：不要用受保护的角色或他人作品的图片生成后商用。
