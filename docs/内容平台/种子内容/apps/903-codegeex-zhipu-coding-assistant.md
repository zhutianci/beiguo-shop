> 本文根据 CodeGeeX 官网首页整理，资料核对于 2026-10-11。以官网为准。

## 是什么

CodeGeeX 是北京智谱华章科技股份有限公司（智谱）推出的智能编程助手，官网自我介绍是「基于大模型的全能的智能编程助手」。它不是独立的编辑器，而是装在你现有 IDE 里的插件：写代码时给补全建议，侧边栏里可以对话提问。

## 能做什么

官网列出的四项核心功能：

- **代码生成与补全**：根据自然语言注释生成代码，或根据已有代码续写，补全当前行或接下来的若干行。
- **自动添加注释**：给代码加行级注释，对没有注释的老代码尤其有用。
- **代码翻译**：在多种编程语言之间做语义级互译，比如把一段 Python 改写成 Java。
- **智能问答**：不离开 IDE 直接提问技术问题。

此外可以通过快捷命令解释选中的代码、修正 bug 等。

**支持的 IDE**：Visual Studio Code、IntelliJ IDEA、PyCharm、WebStorm、GoLand、PhpStorm、Android Studio、Visual Studio、HBuilderX，官网还提到 Vim。**支持的语言**：Python、Java、C++/C、JavaScript、Go 等。

**开源**：官网写明 CodeGeeX4-ALL-9B 模型权重已开源，有能力的团队可以自己部署。智谱开放平台的模型列表里也有 CodeGeeX-4，可通过 API 调用。

## 怎么上手

1. 在官网的下载页，或直接在 IDE 的插件市场搜索 CodeGeeX 并安装；
2. 按插件提示登录；
3. 打开代码文件，写一行说明意图的注释，等它给出补全建议；
4. 选中一段代码，用插件提供的命令做解释、加注释或翻译。

## 免费与付费

官网首页没有列出个人版的价格表，是否收费、有无用量限制请以官网常见问题和插件内说明为准。面向企业另有**企业版**，官网列出的卖点包括：软硬一体机开箱即用、代码仓库级补写与问答、检索增强、企业级管理平台、本地或云端私有化，以及从硬件到模型的信创方案。

## 适合谁 / 不适合谁

**适合：**
- 想在熟悉的 IDE 里加一个补全和问答助手、不想换编辑器的开发者；
- 用 HBuilderX 等国内常见 IDE 的前端开发者；
- 对代码不出内网有要求、需要私有化或自部署开源模型的团队。

**不适合：**
- 想要能自己规划任务、跨文件改代码的智能体式工具的人——官网介绍的重点仍是补全、注释、翻译和问答；
- 追求最新模型效果的用户，可以对比文心快码、CodeBuddy、TRAE 等产品。

## 注意事项

- **看清更新状态**：官网首页内容更新不算频繁，安装前到插件市场看一下最近的版本日期。
- **补全不等于正确**：生成的代码要自己读一遍、跑测试，特别是涉及边界条件和安全的逻辑。
- **开源模型的许可**：自行部署 CodeGeeX4 前先读仓库的许可证条款。
