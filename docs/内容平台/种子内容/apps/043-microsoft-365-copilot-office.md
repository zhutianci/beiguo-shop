## 是什么

Microsoft 365 Copilot 是微软为 Office 套件（Word、Excel、PowerPoint、Outlook、Teams 等）打造的 AI 助手，2023 年起面向企业提供。它和普通聊天机器人最大的不同，是能通过 Microsoft Graph 读取**你有权限访问的**邮件、日程、聊天、会议和文档，结合这些工作上下文来回答和起草内容。

名字容易混，先分清三样东西：

| 名称 | 是什么 |
| --- | --- |
| 消费者版 Copilot（copilot.microsoft.com 和 Copilot App） | 用个人微软账号的通用 AI 助手，类似 ChatGPT，可免费用 |
| Copilot Chat（工作版） | 企业员工用工作账号登录即可用的 AI 聊天，带企业数据保护，不额外收费 |
| Microsoft 365 Copilot（本文） | 嵌入 Office 应用、能调用企业数据的完整版，需要付费许可 |

微软近期在统一品牌：Microsoft Learn 文档注明，Microsoft 365 Copilot 现更名为 **Microsoft Copilot**，Microsoft 365 Copilot Chat 更名为 **Microsoft Copilot Chat**，过渡期内许可和界面仍可能出现旧名；原来的 Microsoft 365（Office）App 也已改名为 Microsoft Copilot App。微软文档还写明，Copilot 中可由管理员选择启用 OpenAI 和 Anthropic 提供的模型。

## 能做什么

- **Word**：根据要点或引用其他文档起草报告、改写段落、总结长文档。
- **Excel**：用自然语言提问分析数据、生成公式和图表、找出异常值。
- **PowerPoint**：根据 Word 文档或一句提示生成演示文稿，整理现有幻灯片。
- **Outlook 和 Teams**：总结长邮件串、起草回复，回顾会议要点和待办。
- **智能体**：商业版和企业版包含 Researcher（研究）、Analyst（分析）等预置智能体，企业版还能用 Copilot Studio 搭建自定义智能体。

## 怎么上手

1. 先确认账号类型：公司或学校账号由管理员分配 Copilot 许可；个人可订阅含 Copilot 的 Microsoft 365 家庭版套餐。
2. 打开 Word、Excel 或 PowerPoint 桌面端（或网页版），用对应账号登录，在功能区点击 Copilot 图标打开侧栏。
3. 在 Word 里可以这样开始：「根据 /季度会议纪要.docx 写一份给管理层的一页总结，列出三项风险」。
4. 在 Excel 里先把数据设为表格，再问 Copilot：「按区域汇总销售额，并标出同比下降的区域」。
5. 生成结果后逐条检查，再用「更简洁」「换成要点列表」等追问继续调整。

## 免费与付费

以下价格均来自微软美国官网（2026-10 查询），其他地区以当地页面为准：

- **企业版**：Microsoft 365 Copilot 为每用户每月 30 美元（按年付费），需另有符合条件的 Microsoft 365 许可；Copilot Chat 对符合条件的订阅用户免费。
- **中小企业**：Microsoft 365 Copilot Business 加购许可每用户每月 18 美元（按年付费，官网标注为截至 2026 年 12 月的促销价，原价 21 美元）；也可以直接购买「含 Copilot」的 Business Standard（23.50 美元）或 Business Premium（32 美元）套餐。
- **个人与家庭**：Microsoft 365 Personal（9.99 美元/月）、Family（12.99 美元/月）、Premium（19.99 美元/月）的桌面版 Word、Excel、PowerPoint、Outlook 均集成 Copilot，档位越高用量越多；官网注明 AI 功能只给订阅所有者使用，不能共享给家庭成员。

## 适合谁 / 不适合谁

**适合：**
- 公司已经全面使用 Microsoft 365，邮件、文档、会议都在微软体系里的团队。
- 每天处理大量邮件和会议、需要快速出汇报材料的管理者和项目经理。
- 经常用 Excel 做分析但不熟悉公式的业务人员。

**不适合：**
- 主要使用 WPS 或 Google Workspace 的个人和团队。
- 只想偶尔问问题的人——免费的消费者版 Copilot 或 Copilot Chat 已经够用。

## 注意事项

- **数据训练**：Microsoft Learn 文档写明，提示词、回复以及通过 Microsoft Graph 访问的数据**不会用于训练基础大模型**；交互记录按企业对 Microsoft 365 内容的合同承诺存储，用户可在「我的帐户」门户删除 Copilot 活动历史。
- **权限即边界**：Copilot 只展示用户至少有查看权限的内容，所以企业上线前应先清理 SharePoint 等处的过宽共享权限。
- **地区可用性**：微软支持文章说明，中国（不含香港特别行政区）和受禁运市场属于 Copilot 不提供或不支持的地区。
- 生成内容不保证 100% 正确，微软也提醒发送前要人工审阅；生成结果的版权归属，微软声明不主张所有权。
