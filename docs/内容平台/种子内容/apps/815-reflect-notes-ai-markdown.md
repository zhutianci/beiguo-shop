> 本文根据 Reflect 官网首页整理，资料核对于 2026-10-11。产品形态与早期相比变化较大，以官网当前说明为准。

## 是什么

Reflect 是一款笔记应用，官网现在的介绍是：开源、带每日笔记和反向链接、使用本地 Markdown 文件的笔记应用，运营主体为 Reflect App, LLC。老资料里它是一款按年订阅的云端笔记；核对时官网的说法已经变成 Mac 版免费下载、笔记存在你自己选定的文件夹里。

## 能做什么

官网列出的功能：

- **Daily notes（每日笔记）**：每天从当天的笔记页开始记录。
- **Networked notes（网状笔记）**：用反向链接把笔记连起来，形成一张想法网络。
- **Local files（本地文件）**：笔记以 Markdown 形式保存在你指定的文件夹。
- **同步方式自选**：通过 iCloud Drive 或 Git 同步。
- **Instant capture**：剪藏网页、录制语音备忘；Mac 上有 Chrome 扩展可以抓取链接、文字和截图。
- **搜索**：检索过往的笔记和想法。
- **Open source**：代码在 GitHub 上公开。

**可选的 AI 功能**（官网原文称 Optional AI）：

- 向你的笔记提问，回答会链接到来源笔记；
- 转写语音笔记（使用你自己的服务商）；
- 修正语法拼写、改进文字；
- 保存自己的常用提示词；
- 从会议记录里列出要点和待办。

官网说明，标记为私密的笔记不会提供给 AI。

## 怎么上手

1. 在 reflect.app 下载 Mac 版，选择一个本地文件夹存放笔记。
2. 从当天的每日笔记写起，用链接把人名、项目、概念连起来。
3. 需要多设备使用时，选 iCloud Drive 或 Git 同步；iPhone / iPad 版在 App Store 下载。
4. 想用 AI，就在设置里填入自己的 API Key。

## 免费与付费

- **Mac 版**：免费，无需订阅。
- **iPhone 与 iPad 版**：付费订阅，价格因地区而异，官网让用户到 App Store 查看当地价格。
- **AI**：需要自备 API Key，费用由模型服务商另行收取。

## 适合谁 / 不适合谁

**适合：** 想要双链笔记、又希望文件掌握在自己手里的 Mac 用户；习惯每日笔记工作法的人；已经有模型 API Key、想按需用 AI 的人。

**不适合：** Windows 和安卓用户（官网未列出这些平台）；需要多人实时协作的团队；不想自己申请 API Key 的用户。

## 注意事项

- 使用 AI 时，相关笔记内容会发送给你所选的模型服务商，敏感笔记记得标记为私密。
- 用 Git 同步需要一点技术基础，普通用户选 iCloud Drive 更省事。
- 网上很多教程写的是旧版 Reflect（云端订阅制），功能和价格已不适用。
