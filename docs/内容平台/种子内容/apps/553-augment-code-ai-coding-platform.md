> 本文根据 Augment Code 官网与定价页整理，资料核对于 2026-10-11。功能和价格变化快，以官网为准。

## 是什么

Augment Code 是一个 AI 编程平台，官网强调它是为**生产规模的代码库**而建的。它的差异化卖点叫 **Context Engine**（上下文引擎）：对整个仓库乃至多个仓库建立索引和理解，让智能体在几十万、上百万行的老项目里也能找对位置、沿用已有的写法，而不是只看当前打开的几个文件。

## 能做什么

官网当前列出的产品：

- **Context Engine**：代码库级别的上下文检索，是其他能力的基础。
- **CLI**：在终端里使用的编程智能体。
- **Cloud Agents**：把任务交给云端智能体异步完成。
- **Software Factory**：面向团队的自动化软件生产流程。
- **Code Review**：对 GitHub 上的 Pull Request 做 AI 代码审查，定价页说明所有套餐都包含。

## 怎么上手

1. 在 augmentcode.com 注册并选择套餐。
2. 按官方文档安装命令行工具（或官网当前提供的其他客户端），登录账号。
3. 打开项目，等待 Context Engine 完成首次索引（大仓库需要一些时间）。
4. 先用提问验证它对代码库的理解，例如「订单状态是在哪些地方被修改的」，再交给它具体的改动任务。
5. 需要自动审查时，在 GitHub 上安装并授权它的应用。

## 免费与付费

官网定价页（美元，月付，统一价格、不按席位另收，2026-10 查询）：

| 方案 | 价格 | 包含用量 | 席位上限 |
| --- | --- | --- | --- |
| Standard | 20 美元/月 | 20 美元用量 | 最多 50 席 |
| Business | 100 美元/月 | 100 美元用量 | 最多 50 席 |
| Enterprise | 联系销售 | 定制用量与加购 | 不限 |

用量以美元计量，涵盖大模型调用、Context Engine 和计算资源。套餐用量用完后可以按量加购，加购额度自购买起 12 个月内有效。免费试用的具体条件核对时未在定价页写明，以官网为准。

## 适合谁 / 不适合谁

**适合：**
- 代码库庞大、历史包袱重、模块之间依赖复杂的工程团队；
- 希望把 AI 代码审查接进 GitHub 流程的团队；
- 觉得通用编程助手「不懂我们项目」的资深开发者。

**不适合：**
- 做小型个人项目或学习编程的人，通用工具的免费档就够用；
- 希望长期免费使用的用户；
- 代码不允许离开内网、又没有企业版预算的团队。

## 注意事项

- **用量制要算账**：同样的月费，选的模型越贵、任务越长，用量消耗越快；先用小任务观察消耗速度。
- **代码会被索引**：使用前确认公司是否允许把代码发送给第三方服务，并查看官方的安全与合规文档。
- **产品线调整较多**：老资料里的功能名和套餐名可能与现在不同，以官网当前页面为准。
- **审查建议仅供参考**：AI 审查不能替代人工评审和测试。
