> 本文根据万相官网、阿里云百炼官方帮助文档与 Wan-Video 官方 GitHub 仓库整理，资料核对于 2026-10-07。功能和价格变化快，以官网为准。

## 是什么

万相是阿里巴巴通义旗下的 AI 创意创作平台，早期叫「通义万相」，现在官网标题已改为「万相」，英文品牌为 Wan。官网介绍它「通过人工智能技术降低创作门槛」，提供文生图、图生图、文生视频、图生视频、图像编辑等创作场景；国际版网站为 wan.video。

背后是阿里自研的 **Wan 系列模型**：
- **视频**：阿里云百炼文档显示 Wan 系列当前推荐的视频模型是 **wan3.0-video**（另有提速的 wan3.0-video-prime），支持文生视频、首帧 / 首尾帧图生视频和参考生视频，单次最长 30 秒，可选 480P / 720P / 1080P。
- **图像**：阿里云百炼文档显示当前图像模型为万相 2.7（wan2.7-image 与 wan2.7-image-pro），支持文生图、组图生成、多图参考和图像编辑，Pro 版文生图最高可出 4K。
- **开源**：Wan2.1（2025 年 2 月）和 Wan2.2（2025 年 7 月 28 日）视频模型已在 GitHub 以 Apache-2.0 许可证开源，2025 年 9 月又开源了角色动画模型 Wan2.2-Animate-14B。

## 能做什么

- **文生图**：中文描述生成海报、插画、产品图，支持多种比例。
- **图像编辑**：在已有图片上改局部、换风格、多图融合。
- **文生视频**：一句话生成带运镜的短视频，wan3.0-video 单次最长 30 秒。
- **图生视频**：上传首帧（或首尾帧）图片让画面动起来，适合产品展示和氛围片。
- **多素材参考**：参考人物、场景、风格等素材生成更可控的视频。
- **API 调用**：企业和开发者可在阿里云百炼（Model Studio）按量调用万相图像、视频模型。

## 怎么上手

1. 浏览器打开 tongyi.aliyun.com/wan，点击登录，按页面提示注册或登录。
2. 首页选择「图片生成」或「视频生成」，先浏览页面上的示例作品，熟悉模型、比例和时长等参数。
3. 写清主体、动作、场景、镜头和风格，选择模型版本、比例与时长后生成。
4. 视频建议先用图片生成确定画面，再用图生视频，画面更容易控制。
5. 需要批量生产或接入产品时，到阿里云百炼控制台开通模型服务、获取 API Key。

可以这样开始：`古镇雨夜，石板路倒映红灯笼，一只橘猫慢慢走过，镜头低角度跟拍，电影感`

## 免费与付费

网页版使用「灵感值」计费，生成图片、视频等会消耗灵感值，因内容安全原因生成失败时灵感值会自动退还。开通**万相会员**可获得更多权益，官网对部分功能提示「仅限万相会员使用，并且只支持使用付费购买的灵感值进行生成」。免费额度有多少，以登录后页面显示为准。会员价格、灵感值数量以官网为准。API 在阿里云百炼按调用量计费，价格见百炼模型计费页。

## 适合谁 / 不适合谁

适合：
- 需要中文提示词生成短视频、氛围片和产品展示视频的内容创作者。
- 电商、广告团队批量出图出视频，或通过 API 接入业务系统。
- 想研究或本地部署开源视频模型的开发者（使用开源 Wan2.x）。

不适合：
- 需要手机 App 一站式操作的用户：本文核对时官网以网页版为主，未查到独立的官方 App 入口。
- 对每一帧都要精确控制的专业影视后期，仍需配合剪辑软件。
- 不想注册账号、也不想为积分付费的重度用户。

## 注意事项

- **AI 标识**：官网公告称，按《人工智能生成合成内容标识办法》，平台对生成的图像、视频等内容添加「AI生成」显式标识，并在内容元数据中嵌入隐式标识。
- **开源许可**：Wan2.1、Wan2.2 为 Apache-2.0，可商用，但仍需遵守法律和模型使用说明；网页版生成内容的使用规则以用户协议为准。
- **肖像与版权**：上传他人照片做参考生成视频，需取得授权。
- 名称变化：搜索「通义万相」「万相」「Wan」指的是同一系列产品。
