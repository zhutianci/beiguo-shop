## 是什么

商汤小浣熊（Raccoon Work）是商汤科技出品的 AI 办公产品，官网口号是「能搞定工作的 AI 助手」。它目前有两条产品线：

- **办公小浣熊**：面向普通职场人，处理表格、文档、汇报这类日常工作；
- **代码小浣熊**：面向研发团队，官网称其为「AI 驱动的全生命周期研发伙伴」。

官网还预告了一款规划中的新产品，暂未开放。

## 能做什么

办公小浣熊在官网上主推四项能力：

- **数据分析智能体**：上传数据后自动清洗、分析、出图表，还可以做趋势预测，并一键生成报告，省去手动算数和整理。
- **AI PPT 生成**：一句话生成结构完整的 PPT，支持单页对话式修改，图片、文案、图表可以在线编辑，也能上传自己的模板和素材。
- **专属知识库**：上传文档资料后，用 @ 的方式直接向资料提问，再让它基于资料找信息、写邮件、编文案。
- **深度思考 + 任务规划**：把模糊的目标或复杂任务拆成可执行的步骤，最后输出方案。

代码小浣熊则覆盖代码生成、审查等研发环节；官网的用户评价里多次提到它可以在内网运行、连接企业自己的知识库。

## 怎么上手

1. 打开 xiaohuanxiong.com，选择体验网页版，或下载客户端；
2. 注册登录后，先拿一份不敏感的表格试试：上传文件，直接说想看什么（如「按月份汇总销售额并画趋势图」）；
3. 分析结果满意后，让它整理成报告或 PPT；
4. 资料多的话建一个知识库，把常用文档放进去再提问。

可以这样开始：

```text
这是今年 1–9 月的门店销售明细。请先检查有没有缺失值和明显异常，再按门店和月份汇总，找出增长最快和下滑最明显的 3 家店，并用图表展示。
```

## 免费与付费

官网首页标注「免费使用」，没有公开的价格表；是否有付费套餐、免费额度多少，以登录后的说明和官网为准。企业可以咨询本地化 / 私有化部署，官网称已与 2000 多家企业合作，并按采购、人力、市场营销、电商、财务、销售等行业场景给出了方案。

## 适合谁 / 不适合谁

**适合：**
- 经常要对着 Excel 做汇总、出图、写分析结论，但不会写公式和代码的职场人；
- 需要把数据分析结果快速做成汇报材料的运营、市场、财务岗位；
- 对数据安全有要求、希望私有化部署的企业。

**不适合：**
- 只想闲聊或写短文案的人，通用聊天助手更合适；
- 需要严谨统计建模的专业分析师——自动分析的结论仍需要自己复核口径。

## 注意事项

- **先核对口径再用结论**：让它说明用了哪些列、怎么处理缺失值，再决定是否采信。
- **敏感数据谨慎上传**：客户名单、财务明细等先脱敏，或了解企业版方案。
- **名字别混**：「小浣熊」是产品家族名，办公和代码是两条不同的产品线，入口也不同。
