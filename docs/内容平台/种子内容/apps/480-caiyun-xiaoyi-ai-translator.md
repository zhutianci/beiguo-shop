> 本文根据彩云小译官网网页版整理，资料核对于 2026-10-11。功能和价格变化快，以官网为准。

## 是什么

彩云小译是一款国产 AI 翻译产品，官网域名与「彩云天气」同属 caiyunapp.com。它在国内用户里比较知名的用法有两个：一是**翻译整份文档**，二是装上**浏览器插件**后把外文网页变成中外文对照的双语页面，读英文资料时可以一眼对照原文。

## 能做什么

官网网页版当前提供的功能入口：

- **文字翻译**：粘贴文本即时翻译，可自动识别源语言；
- **文档翻译**：上传文档整篇翻译；
- **PDF 链接**：直接粘贴一个 PDF 的网址进行翻译，适合读在线论文；
- **图片翻译 / 图文翻译**：识别图片里的文字并翻译；
- **译文调整**：对结果不满意时让它换一种译法或风格；
- **添加术语**：维护自己的术语库，保证专有名词前后译法一致；
- **多模型模式**：用多个模型翻译同一段内容，对比着看；
- **浏览器插件**：网页翻译与双语对照；
- **移动应用**；
- **翻译 API**：给开发者把翻译能力接入自己的产品。

## 怎么上手

1. 打开 fanyi.caiyunapp.com，注册并登录。
2. 短文本直接粘贴到文字翻译框。
3. 长文档点「文档翻译」上传；在线 PDF 用「PDF 链接」粘贴网址。
4. 经常读外文网页的，从官网的「浏览器插件」入口安装扩展，打开外文网页后点击插件图标，页面会变成原文与译文逐段对照。
5. 翻译专业资料前，先在「添加术语」里录入本领域的固定译法。

## 免费与付费

可以免费使用基础的文字翻译；文档翻译的页数、字数额度以及会员权益和价格，核对时未在首页直接列出，**以登录后的会员页面为准**。翻译 API 另行计费，见官方的 API 说明。

## 适合谁 / 不适合谁

**适合：**
- 需要读英文论文、技术文档、海外资讯的学生和研究人员；
- 想要网页双语对照、边读边学的外语学习者；
- 翻译时需要统一术语的专业领域使用者。

**不适合：**
- 合同、专利、医疗等需要承担法律责任的正式翻译——机器翻译只能作参考，需要专业译员审校；
- 需要翻译小语种文学作品并保留文风的场景；
- 已经在用沉浸式翻译等同类插件并且满意的人，功能有不少重合。

## 注意事项

- **机器翻译会出错**：数字、否定句、专业术语和长难句是高发区，重要内容对照原文检查。
- **文档格式**：复杂排版（多栏、公式、表格）的文档翻译后可能有错位，下载后检查。
- **隐私**：上传的文档会在云端处理，未公开的论文稿、合同和内部资料请谨慎。
- **多模型模式是用来对比的**：几种译法不一致的地方，往往就是需要人工判断的地方。
