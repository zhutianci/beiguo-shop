> 本文根据 MaxKB 官方 GitHub 仓库 README 与官网整理，资料核对于 2026-10-11。开源项目变化快，以官方仓库为准。

## 是什么

MaxKB 的全称是 Max Knowledge Brain，README 把它定义为构建企业级智能体的开源平台，仓库 1Panel-dev/MaxKB 约有 2.29 万星标，采用 GPL-3.0 许可。它在国内企业和政务、教育单位里比较常见，原因很实际：**安装简单、界面中文、能直接接国产模型**，适合想在内网里快速搭一个知识库问答助手的团队。

## 能做什么

README 列出的能力：

- **RAG 管线**：上传文档或自动爬取网页，自动完成文本切分和向量化；
- **工作流引擎**：内置函数库，可以编排复杂的业务流程，并支持调用 MCP 工具；
- **零代码嵌入**：把问答助手嵌入到第三方业务系统里，不需要改造原系统；
- **模型支持**：私有部署的模型（如 DeepSeek、Llama、Qwen）和公有模型（如 OpenAI、Claude、Gemini、MiniMax）都能接；
- **多模态**：原生支持文本、图片、音频、视频的输入输出。

## 怎么上手

README 提供的启动命令：

```bash
docker run -d --name=maxkb --restart=always -p 8080:8080 -v ~/.maxkb:/opt/maxkb 1panel/maxkb
```

启动后访问 `http://服务器地址:8080`，用 README 写明的默认账号登录：用户名 `admin`，密码 `MaxKB@123..`。**登录后第一件事就是修改默认密码。**

接下来：

1. 在「模型设置」里添加模型供应商和 API Key（或本地模型地址）；
2. 创建知识库，上传文档或填入要爬取的网址；
3. 创建应用，关联知识库和模型，在调试窗口里测试；
4. 通过分享链接或嵌入代码把助手放到业务系统中。

## 免费与付费

开源版免费，遵守 GPL-3.0 许可即可使用。官方是否提供功能更多的专业版 / 企业版及其价格，以官网为准。模型调用和服务器成本自理。

## 适合谁 / 不适合谁

**适合：**
- 需要在内网私有化部署知识库问答的企业、学校和机构；
- 运维资源有限、希望一条命令就能跑起来的小团队；
- 想把 AI 问答嵌进现有 OA、客服、官网系统的开发者。

**不适合：**
- 想把它改造成闭源商业产品再分发的公司——GPL-3.0 有开源传染性要求，需先评估许可或咨询官方商业授权；
- 只需要个人聊天助手的用户；
- 文档解析要求极高（大量扫描件、复杂表格）的场景，可以对比 RAGFlow。

## 注意事项

- **务必改掉默认密码**：默认账号密码是公开信息，搜索下拉里就有「MaxKB 默认密码」「MaxKB 漏洞」这样的查询，说明暴露在公网的实例是被重点扫描的对象。
- **不要直接暴露在公网**：需要外部访问时放在反向代理之后，开启 HTTPS 并限制来源。
- **及时升级**：关注官方的版本和安全公告。
- **数据卷备份**：知识库和配置保存在挂载目录 `~/.maxkb`，升级前先备份。
