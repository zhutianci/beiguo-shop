> 本文根据海螺视频官网（国内版 hailuoai.com、国际版 hailuoai.video）和 App Store 官方介绍整理，资料核对于 2026-10-07。本文只介绍视频生成部分。功能和价格变化快，以官网为准。

## 是什么

海螺视频是 AI 公司 **MiniMax** 旗下的 AI 视频创作平台，官网首页标题是「海螺视频：每个想法都是一部大片」，App Store 上的官方 App 也叫「海螺AI - 视频创作工具」。国内版入口 hailuoai.com，海外用户用国际版 hailuoai.video（Hailuo AI）。

当前主力模型是 **MiniMax H3**，官网首页写着「MiniMax H3 正式上线」，介绍为原生多模态理解与生成、精准编辑与控制、商用级多场景内容生成；App Store 更新说明称 H3 支持文本、图片、音频、视频多模态创作。国际版首页还设有 H3 的开放权重项目与实战教程专区（Open-Weight Projects）。具体分辨率、时长等参数以创作页面显示为准。

## 能做什么

- **文生视频**：输入一段文字描述，生成带运镜和情绪表演的视频。
- **图生视频**：把一张照片或插画变成动态镜头，适合让角色、商品「动起来」。
- **主体参考**：上传人物或物品的参考图，让多个镜头里的主体形象保持一致，方便做连续剧情。
- **运动控制**：App 更新说明提到支持推拉摇移、镜头跟随等运镜效果，增强画面节奏和电影感。
- **全能参考**：用参考素材让构图和主体对齐，结果更一致、更可控（官网创作框里就有「全能参考」入口）。
- **AI 广告生成器**：App 更新说明称只需输入产品图片，即可生成多条短视频广告，适配不同平台和营销场景。
- **海螺 Agent 与模板**：用对话方式让 Agent 帮你规划成片；首页按「广告电商」「萌宠」「风格转绘」等分类提供可「做同款」的模板。

## 怎么上手

1. 电脑打开 hailuoai.com（国内）或 hailuoai.video（海外），或在 App Store 搜索「海螺AI - 视频创作工具」，按页面提示登录。
2. 先在首页「推荐」里找一个和你需求接近的作品，点进去看提示词和参数。
3. 点「创作视频」，选择 H3 模型；新手先用图生视频，上传一张主体清晰的图片。
4. 写一句动作 + 镜头的描述，按页面选项设置画面比例等参数，确认消耗的积分后生成。
5. 需要人物前后一致时，换用「主体参考」，用同一张参考图生成多个镜头，再到剪辑软件里拼接。

可以这样开始：

```
图生视频：一只橘猫趴在窗台上，听到门铃后抬头竖起耳朵，镜头从侧面缓慢推到正脸，午后暖光，竖屏 9:16
```

## 免费与付费

海螺视频用积分计费（站内叫「贝壳」），不同模型、时长和分辨率消耗不同。官网首页有参与调研赢取贝壳奖励等活动；页面上设有「会员」入口，开通会员可获得更多积分和会员权益。会员档位、价格和每档积分**以官网会员页为准**（本文未能核实具体数字，所以不写）。

## 适合谁 / 不适合谁

**适合：**
- 电商和品牌运营，需要用商品图快速生成广告短片和种草素材。
- 短视频、新媒体创作者，想要表情和情绪表演自然的人物镜头。
- 做连续故事、AI 短剧的创作者，需要主体参考保持角色一致。

**不适合：**
- 想一键出完整长片的人：单次生成的是短片段（时长上限以创作页面为准），长内容仍要分段生成再剪辑。
- 想完全免费长期使用的人，免费积分有限，高分辨率消耗快。
- 需要对字幕、Logo 文字精确还原的场景，后期仍需人工替换。

## 注意事项

- **肖像权**：上传真人照片前确认是你本人或已获授权；不要生成冒充明星、公众人物的视频，也不要用他人形象做误导性内容。
- **商用与协议**：生成内容能否商用、会员权益细则，以官网《用户协议》《服务协议》为准。
- **隐私**：上传的图片、视频会被平台处理，敏感素材（证件、未公开产品）谨慎上传；数据处理方式见官网隐私政策。
- **AI 标识**：发布到国内平台时，按《人工智能生成合成内容标识办法》等规定标注 AI 生成。
- **检查细节**：手部、文字和快速动作容易出错，商用前逐帧检查。
