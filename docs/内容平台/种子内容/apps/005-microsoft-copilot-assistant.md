> 本文根据 Microsoft Copilot 官网、微软个人版定价页、微软支持文章和 App Store 页面整理，资料核对于 2026-10-07。功能和价格变化快，以官网为准。

## 是什么

Microsoft Copilot 是微软的 AI 助手。本文说的是**个人版**：用 Outlook、Hotmail 等微软个人账号登录 copilot.microsoft.com、Copilot App 或 Windows 里的 Copilot。

要注意区分：用公司或学校账号登录时，你用的是企业版「Microsoft 365 Copilot」，由单位管理员控制，数据与个人版分开。新版 Copilot App 内置账号切换器，两种账号可以在同一个 App 里切换，但聊天记录和文件互不相通。

## 能做什么

- **日常问答与写作**：联网回答问题、写邮件、改简历、做旅行计划，回答附来源链接。
- **生成图片**：免费版就能文字生图，订阅后额度更高。
- **语音 + 摄像头**：手机上开启语音对话后，可打开摄像头对准物体或文件，边看边问，适合识别说明书、植物、外文菜单。
- **Pages 页面**：把聊天里的内容整理成可继续编辑的页面，可用「缩短这一页」之类的指令修改，并保存到 OneDrive。
- **在 Office 里用**（需 Microsoft 365 个人版订阅）：Word 起草、Excel 分析数据、PowerPoint 从提示生成演示文稿、Outlook 总结邮件。
- **Researcher 与 Analyst**（Premium 和 Pro）：推理型智能体，前者做资料研究，后者分析数据；订阅用户还可试用 Office Agent、Word / Excel 的 Agent 模式等实验功能。

## 怎么上手

1. 打开 copilot.microsoft.com，或在应用商店下载开发者为「Microsoft Corporation」的 Microsoft Copilot。
2. 用微软个人账号登录（没有可以免费注册），登录后记录会在各设备同步。
3. 直接在输入框用中文提问；想生图就说「画一张……」，想语音就点麦克风图标。
4. 已订阅 Microsoft 365 的话，在 Word、Excel 等应用里点 Copilot 按钮，基于当前文档提问。
5. 公司电脑上若看到的是工作账号界面，用账号切换器切到个人账号即可。

可以这样开始：「我上传了一张家电说明书的照片，帮我用三步说清楚怎么设置定时开机。」

## 免费与付费

按微软个人版定价页（美国区，2026-10 查询）：

| 方案 | 价格（美元/月） | Copilot 相关权益 |
|---|---|---|
| 免费 | 0 | 有限的聊天和生图，视服务容量而定 |
| Microsoft 365 Personal | 9.99（月付；年付 99.99/年） | 高于免费版的聊天和生图额度，Office 应用内可用 Copilot（1 人） |
| Microsoft 365 Family | 12.99（月付；年付 129.99/年） | 同上，最多 6 人共享，但 Copilot 只给订阅所有者 |
| Microsoft 365 Premium | 19.99（月付；年付 199.99/年） | 更大用量、有限的智能体功能、Researcher / Analyst |
| Microsoft 365 Pro | 99.99（仅月付） | 最高用量与高峰优先 |

原来的 Copilot Pro 已停止销售，官方建议改订 Microsoft 365 Premium。各地区价格不同，以当地官网为准。

## 适合谁 / 不适合谁

**适合：**
- 已经订阅 Microsoft 365、每天用 Word / Excel / PowerPoint 的人，加一个 AI 不用换工具。
- 想先免费试用、额度不够再按需升级的普通用户。
- 需要拍照识别、看图问答的普通用户。

**不适合：**
- 想要独立深度研究工具的个人用户：消费者版的 Deep Research 已于 2026-08-18 下线。
- 主要用 WPS 或 Google 文档办公的人，Office 联动用不上。
- 公司账号受管理员限制、想用个人功能的人，需要另用个人账号。

## 注意事项

- **功能下线**：官方公告 2026-08-18 起个人账号的群聊、播客和 Deep Research 功能停用；Copilot Pro 的服务支持已于 2026-08-01 结束。
- **地区**：中国区 App Store 上架了微软官方的 Microsoft Copilot（2026-10 查询），但各项功能和 Microsoft 365 订阅在不同地区的开放情况不一样，以官方页面为准。
- **隐私**：个人版的数据用途以微软隐私声明和 Copilot 设置页为准；工作账号的数据由单位的安全与合规策略管理，官方说明个人与工作体验按设计相互隔离。
- **核对输出**：生成的 Excel 公式、数据结论要自己抽查，PPT 里的事实也要核对。
