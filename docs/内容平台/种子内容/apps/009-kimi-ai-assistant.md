## 是什么

Kimi 是北京月之暗面科技有限公司（Moonshot AI）推出的 AI 助手，官网 kimi.com。它起步时以长文本阅读见长，现在已经发展成一个以智能体（Agent）为核心的工作平台。

2026-07-16，月之暗面发布 Kimi K3 模型：官方介绍总参数 2.8 万亿、原生多模态、支持百万 token 上下文，主打长程编程和端到端知识工作。Kimi 产品家族目前包括 Kimi（网页 / App / 桌面端）、Kimi Work、Kimi Code、Kimi 浏览器扩展和 Kimi Claw。

## 能做什么

- **读长文件**：一次上传多个文档，快速摘要、翻译、答疑，也能整理发票、会议记录这类杂乱资料。
- **深度研究**：全网搜索整合信息，输出带来源的研究报告。
- **Agent 集群**：大型任务（海量文献综述、长篇行业研报）可现场调度大量「分身」并行处理，官方称最多 300 个子智能体。
- **PPT、文档、表格**：一键生成排版专业的 PPT，可上传视觉参考定制风格；PPT、Word、Excel、PDF 互转，自动写 Excel 公式和图表。
- **构建网站与视觉编程**：上传设计稿、手绘图甚至录屏，生成可部署的网页代码。
- **专业数据插件**：接入万得、同花顺、标普等数据源，做金融和行业分析。
- **Kimi Code 与 Kimi Claw**：前者是编程助手（含命令行工具），后者可部署专属助理并接入飞书、拉群协作。

## 怎么上手

1. 打开 kimi.com，或在应用商店搜索「Kimi」（开发者为北京月之暗面科技有限公司）；电脑端可从官网下载 Windows / macOS 客户端。
2. 按页面提示注册登录，手机、电脑、网页的对话、文件与工作进度会同步。
3. 普通问题直接在输入框问；要读资料就把 PDF、Word 拖进来。
4. 复杂任务在输入框里描述目标，选择 PPT、深度研究、文档等入口，或直接「做个 Agent 任务」。
5. 常用流程可以存成「项目」或设成定时任务，按时自动推送结果。

可以这样开始：「附件是三家公司的 2025 年年报，请对比营收、毛利率和研发投入，做成一页表格，再写 300 字结论。」

## 免费与付费

按 Kimi 帮助中心（2026-10 查询），会员分四档，均可连续包月或包年：

| 套餐 | 连续包月 | 定位与主要区别 |
|---|---|---|
| Andante | 49 元 | 日常使用：Office 文件处理、深度研究、网站部署、Kimi Code 可调用 |
| Moderato | 99 元 | 约 2 倍 Agent 额度，可用 Agent 集群、多任务并行 |
| Allegretto | 199 元 | 约 4 倍额度，增加目标模式、专属 Kimi Claw |
| Allegro | 699 元 | 约 10 倍额度，支持百万 token 超长对话 |

所有会员功能（网站部署、深度研究、PPT、Kimi Code、Kimi Work、Kimi Claw 等）共用一个额度池，按实际 token 消耗扣减，每个计费周期刷新、不结转；Kimi Code 另有 5 小时 / 周限额。额度不够可买加油包。年付更便宜。

## 适合谁 / 不适合谁

**适合：**
- 经常读论文、研报、合同的学生、研究员、分析师。
- 做 PPT、写报告的职场人，以及需要金融数据插件的投研人员。
- 想用国产模型写代码、做网页的开发者。

**不适合：**
- 只是偶尔聊聊天的用户，会员体系对轻度用户偏复杂。
- 对生图、生视频有大量需求的创作者，这不是 Kimi 的主打。
- 期待会员「不限量」的人：所有功能都扣同一个额度池，重度 Agent 任务消耗很快。

## 注意事项

- **订阅变动**：2026 年 7 月 K3 上线后，月之暗面曾因算力紧张暂停新用户订阅，并表示会拆分 Kimi 主权益和 Kimi Code 权益；目前帮助中心已列出完整套餐，能否订阅以订阅页实际显示为准。
- **额度规则**：帮助中心写明额度到期清零，「1 个月会员等值额度」之类的活动奖励是额度数量而非固定天数。
- **取消续费**：在 Kimi 设置 → 订阅管理，或微信、支付宝、Apple ID 的自动扣款设置里关闭。
- **核对输出**：长文总结可能漏掉细节，引用的原文页码和数据要回到文件里核对。
