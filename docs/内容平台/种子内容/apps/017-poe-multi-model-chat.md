> 本文根据 Poe 官网、Poe 创作者平台官方文档和 App Store 页面整理，资料核对于 2026-10-07。功能和价格变化快，以官网为准。

## 是什么

Poe 是问答网站 **Quora** 推出的 AI 聚合平台，有网页版 poe.com 和手机 App。搜「Poe」时常会混进同名游戏《流放之路》（Path of Exile），本文说的是 AI 平台。

Poe 本身不主打自研大模型，而是把多家公司的模型放到同一个界面里：文本模型、生图模型、视频和语音生成模型都能在这里找到，每个模型或定制助手在 Poe 上叫一个「Bot（机器人）」。具体有哪些模型、每个模型消耗多少积分，以 Poe 的模型列表为准，新模型通常上线较快。

## 能做什么

- **一个账号用多家模型**：不用分别注册各家服务，在同一个 App 里切换不同的聊天、生图、生视频模型。
- **同屏对比**：在同一个对话里 @ 多个机器人，让它们分别回答，比较哪个更准、更好用；也能把不同机器人组合起来用。
- **上传文件、联网搜索**：和 PDF、图片对话，用搜索类机器人查最新资讯。
- **自建机器人**：最简单的 Prompt Bot 只需写好指令、选一个基础模型，一分钟就能做出专用助手（如学习计划生成器）；还可以加知识库。
- **进阶创作**：Server Bot（接自己的服务器）、Script Bot（Poe 托管的 Python 机器人）、Canvas App（交互式小网页）、API Bot（把任意兼容接口的模型接到 Poe）。
- **创作者分成**：做的机器人有人用，可以通过官方创作者变现计划按消息获得收益。
- **API**：用 Poe API Key 在自己的程序、脚本或 IDE 里调用 Poe 上的机器人，扣自己账号的积分。

## 怎么上手

1. 打开 poe.com，或在应用商店下载开发者为「Quora, Inc」的 Poe – Fast AI Chat。
2. 按页面提示注册登录（可选的登录方式以登录页为准）。
3. 在机器人列表里找到想用的机器人，进入后直接聊；输入 @ 可以把其他机器人拉进同一个对话。
4. 看每个机器人页面上标注的每条消息积分消耗，便宜的模型适合日常，贵的模型留给难题。
5. 想自建机器人，按 Poe 创作者文档创建 Prompt Bot：写好指令、选择基础模型、按需加知识库后发布。

可以这样开始：先用一个便宜模型问「帮我把这段产品介绍改得更口语化」，再 @ 另一个模型给同样的要求，对比两版取长补短。

## 免费与付费

Poe 按**积分（points）**计费：

- **免费**：可以使用部分机器人，免费额度规则以官网为准。
- **订阅**：订阅后每月获得更多积分，可使用更多付费模型；在 poe.com/subscription_plans 查看各档价格。
- **附加积分**：额度用完可以单独购买。官方文档写明，免费用户不能通过 API 调用付费模型，必须有订阅或附加积分。

不同模型、不同长度的消息积分消耗差别很大，生成图片和视频通常比文字贵得多。具体价格以官网为准。

## 适合谁 / 不适合谁

**适合：**
- 想横向比较多家模型、找到最适合自己任务的那一个的人。
- 写提示词、做 AI 小工具的爱好者和创作者，可以发布并获得分成。
- 不想同时订阅多个 AI 服务、只偶尔需要用高级模型的用户。

**不适合：**
- 重度使用某一家模型全部功能的人：Poe 上通常只有对话能力，原厂 App 的专属功能（如项目、智能体模式等）用不到。
- 希望「不限量」的用户：积分制下贵模型消耗很快。
- 处理高度机密资料的场景，数据会经过 Poe 和对应模型提供方。

## 注意事项

- **数据流向**：你的消息会发给你选择的模型提供方处理，上传敏感信息前先看 Poe 和该提供方的隐私政策。
- **第三方机器人**：平台上有大量用户创建的机器人，质量参差，官方文档提醒通过 API 调用非官方机器人时要谨慎，它们可以消耗你账号的积分。
- **地区**：中国区 App Store 没有官方 Poe App（2026-10 查询），名字相近的「中文版」应用不是 Quora 出品。
- **核对输出**：不同模型可能给出相互矛盾的答案，对比时以可核实的来源为准。
