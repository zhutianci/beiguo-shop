> 本文根据 OpenRouter 官网、官方文档（快速入门、FAQ）与服务条款整理，资料核对于 2026-10-07。功能和价格变化快，以官网为准。

## 是什么

OpenRouter 是一个**大模型 API 聚合平台**，运营方是 OpenRouter, Inc.，服务条款注明公司地址在美国纽约。它把 OpenAI、Anthropic、Google、DeepSeek、Meta、Mistral、阿里千问等众多厂商的模型统一到一个接口后面：你只需要一个 API Key、一份余额，就能切换调用数百个模型，不用分别去各家注册和充值。

它的接口与 OpenAI 的 Chat Completions 格式兼容，原本用 OpenAI SDK 写的代码，改一下 base URL 和模型名就能接入。很多编程工具、聊天客户端也直接内置了 OpenRouter 选项。

## 能做什么

- **一个接口调用数百个模型**：模型 ID 形如「厂商/模型名」，在模型列表页可按价格、上下文长度、能力筛选。
- **自动路由和兜底**：同一个模型往往有多家服务商提供，OpenRouter 会在服务商出故障时自动切换，并可按价格或速度优先选择。
- **免费模型**：部分模型标注为免费，适合学习和原型验证。
- **在线 Chat 对比**：网页上的 Chatroom 可以同时向多个模型提问，直观比较效果。
- **用量排行榜**：Rankings 页面展示各模型和各应用的 token 使用量，可以看出开发者实际在用什么。
- **统一账单和用量分析**：所有模型的花费集中在一个账户里查看。
- **自带 Key（BYOK）**：也可以绑定你在各厂商的 Key，通过 OpenRouter 统一调用。

## 怎么上手

1. 打开 openrouter.ai 注册账号。
2. 在 Credits 页面充值（官方 FAQ 写明支持主流信用卡、支付宝和 USDC 加密货币），想先试用可以只用免费模型。
3. 在 Keys 页面创建 API Key，并可为它设置花费上限。
4. 在你的代码或工具里把接口地址设为 `https://openrouter.ai/api/v1`，填入 Key 和模型 ID。
5. 先用网页 Chatroom 对比几个模型，再决定在项目里用哪个。

可以这样开始：在 Chatroom 里同时选三个模型，输入「用 Python 写一个读取 CSV 并按某列分组求和的函数，并解释思路」，比较回答质量和速度。

## 免费与付费

- **模型价格**：官方 FAQ 表示推理价格按各服务商原价透传、不加价，每个模型的输入输出单价在模型页公开。
- **充值手续费**：官方 FAQ 写明用银行卡（Stripe）充值收取 5.5%（最低 0.80 美元），加密货币充值收取 5%（官网 FAQ，2026-10 查询）。
- **免费模型额度**：未购买额度时，免费模型每天可调用 50 次；累计购买至少 10 美元额度后提升到每天 1000 次（官网 FAQ，2026-10 查询）。

## 适合谁 / 不适合谁

适合：
- 需要在多个模型之间对比、切换的开发者和 AI 应用团队。
- 不想分别在每家厂商注册、绑卡、充值的个人开发者。
- 给编程工具、聊天客户端配置模型来源的进阶用户。

不适合：
- 只用一家模型且用量很大的企业，直连厂商可能更便于谈折扣和合规。
- 对数据经过第三方中转有严格限制的场景。
- 不写代码、只想聊天的普通用户。

## 注意事项

- **数据与日志**：官方 FAQ 表示默认不记录提示词和回复；你可以主动开启日志换取 1% 的使用折扣。不同上游服务商的数据政策不同，可在设置里限制只用不训练数据的服务商。
- **年龄与地区**：服务条款要求用户年满 18 岁；部分模型由上游厂商按国家或机构限制访问，条款明确禁止用代理等方式规避这些限制。
- **免费模型不稳定**：免费模型可能限流、下线或被替换，生产环境不要依赖。
- **保护 API Key**：为 Key 设置花费上限，不要写进前端代码或公开仓库。
