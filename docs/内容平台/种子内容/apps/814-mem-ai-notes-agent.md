## 是什么

Mem 是一款 AI 笔记产品，官网现在的口号是「你的 AI 幕僚长」（Your AI chief of staff）。它由两部分组成：

- **Mem Workspace**：以笔记为基础的「记忆库」，把笔记、会议和想法整理成有条理、可搜索的内容；
- **Mem Agent**：从你保存的内容里了解任务、项目和目标，适时发来提醒和下一步建议。

和传统笔记软件相比，它不要求你先建文件夹、打标签，重点是「先丢进来，需要时它帮你找出来」。

## 能做什么

官网列出的功能：

- **Push-to-Remember**：按住快捷键说出一个想法，Mem Agent 会判断它该归到哪里、什么时候再提醒你（页面注明支持 Mac 和 Windows）。
- **Voice Mode**：在任意笔记里录下会议或口述内容，生成结构化的转写并整理成笔记。
- **Web Clipper**：一键保存网页资料，供 Agent 之后调用。
- **Chat**：向 Mem Agent 提问，它会用已掌握的上下文来回答。
- **Calendar**、**Heads Up**：日历与主动提醒相关功能，页面只列了名称。
- 定价页还提到可以通过 WhatsApp 和邮件给 Mem 发消息，以及与 Gmail、Slack、Todoist 等的 Connections（连接）。

## 怎么上手

1. 在官网点 Sign up 注册，或下载应用。
2. 把手头的笔记、网页剪藏和会议记录放进去，先不用整理。
3. 用 Chat 问一个需要跨多条笔记才能回答的问题，感受检索效果。
4. 习惯之后再试 Push-to-Remember 和 Voice Mode。

## 适合谁 / 不适合谁

**适合：** 信息来源杂、懒得整理的人；会议多、需要把口头内容快速沉淀下来的管理者和创业者；希望工具能主动提醒待办的人。

**不适合：** 喜欢自己搭建严密目录和双链体系的重度笔记用户；要求数据只存本地的人；免费额度明显不够用、又不想订阅的用户。

## 注意事项

- 笔记内容存放在云端并交给 AI 处理，工作机密和个人隐私信息要先确认是否合适。
- Agent 的提醒依赖你存进去的内容是否完整，不能当作唯一的待办系统。
- 套餐档位较多，按实际用量从低档开始。
