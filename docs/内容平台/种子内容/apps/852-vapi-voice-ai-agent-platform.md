> 本文根据 Vapi 官网定价页整理，资料核对于 2026-10-11。这是一条面向开发者和企业的简介，价格以官网为准。

## 是什么

Vapi 是 Vapi, Inc. 提供的语音 AI 智能体平台，口号是「拥有你自己的语音智能体」。一个能打电话的 AI 需要把三样东西实时串起来：语音转文字、大语言模型、文字转语音，还要处理打断、延迟和电话线路。Vapi 把这套基础设施托管起来，开发者选择各环节用哪家的模型，再通过 API 或控制台配置智能体。

## 能做什么

定价页列出的特点：

- **智能体数量不限**：可以按需创建任意多个智能体。
- **模型按成本转付**：各家模型的费用直接透传，官方称不加价。
- **测试与模拟**：在电话真正打到客户之前先模拟通话。
- **监控与可观测性**：跟踪你最关心的问题，监测效果与合规情况。
- **托管平台**：基础设施由 Vapi 负责；同时强调智能体、模型和数据由你掌控。
- **多种接入方式**：Vapi Telephony / SIP、Vapi WebSockets、Daily WebRTC，也可以接 Twilio、Vonage、Telnyx 等电话服务商。

## 怎么上手

1. 在 vapi.ai 注册，领取起步额度。
2. 在控制台创建一个智能体：写好系统提示词，选择转写、大模型和语音三个环节的服务商。
3. 用网页通话先测试对话效果和打断处理。
4. 绑定电话号码或接入自己的电话线路，再通过 API 把它嵌进业务流程。

## 免费与付费

| 方案 | 价格 |

附加项：额外并发线路 10 美元/条/月；HIPAA 合规 2,000 美元/月。电话线路费由服务商另收，例如页面列出 Twilio 呼入 0.008 美元/分钟、呼出 0.014 美元/分钟。

**实际每分钟成本 = 托管费 + 转写 + 大模型 + 语音 + 线路**，页面提供了计算器。

## 适合谁 / 不适合谁

**适合：** 要做电话客服、预约提醒、外呼筛选等语音产品的开发团队；希望自由更换底层模型的技术团队。

**不适合：** 不写代码、想要开箱即用客服系统的企业；通话量很小的个人项目；对语音数据出境有严格限制的场景。

## 注意事项

- 自动外呼在很多国家和地区受法律约束，需要取得被叫方同意并表明是 AI 通话。
- 各环节叠加后的成本可能数倍于托管费，上线前用计算器估算。
- 通话录音和转写含个人信息，注意存储期限与脱敏。
