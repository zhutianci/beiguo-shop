## 是什么

Modal 是一个无服务器（serverless）的 AI 计算平台。定价页的核心一句话是「GPU 和 CPU 按秒付费」，并说明平台会即时自动扩容和缩容——没有请求时缩到零，不为空闲机器付钱。它面向的是写代码的开发者：把函数或模型部署上去，由平台负责容器、调度和显卡。

## 能做什么

定价页列出的产品方向：

- **Inference（推理）**：部署大语言模型以及图像、视频、音频模型，从实时请求到批量任务都可以。
- **Sandboxes（沙箱）**：给编程智能体、强化学习采样和不可信代码用的隔离运行环境。
- **Training（训练）**：在几秒内拉起的 GPU 上做微调、强化学习和模型评测。
- **Notebooks、Batch**：页面列了名称，分别对应交互式笔记本和批处理。
- 页面还提到 Volumes（存储卷）、Scheduled Functions（定时函数）和共享端点等配套能力。

## 怎么上手

1. 在 modal.com 注册账号（Starter 档不收月费）。
2. 按官方文档安装 Python 客户端并完成登录认证。
3. 从官方示例开始：把一个函数部署成可调用的端点，观察冷启动时间和计费明细。
4. 再换成自己的模型和依赖，按需选择 GPU 型号。

安装与部署的具体命令请以官方文档为准。

## 适合谁 / 不适合谁

**适合：** 会写 Python、想快速把开源模型变成 API 的开发者；流量波动大、不想为空闲 GPU 付费的应用；需要给智能体跑代码的沙箱的团队。

**不适合：** 不写代码、只想要一个现成聊天界面的用户；GPU 全天满载的稳定负载（包月或预留实例可能更划算）；对数据驻留地有严格要求、需要自有机房的场景。

## 注意事项

- 无服务器有冷启动，大模型首次加载可能要等待，延迟敏感的服务要评估保活成本。
- 按秒计费看起来单价很低，长时间运行的任务仍要自己算总账，并设置用量上限提醒。
- 赠送额度按月发放，是否累积以官网说明为准。
