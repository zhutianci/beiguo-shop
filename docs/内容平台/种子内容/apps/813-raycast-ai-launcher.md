> 本文根据 Raycast 官网的 AI 功能页与定价页整理，资料核对于 2026-10-11。功能与价格以官网为准。

## 是什么

Raycast 是一款用键盘操作的效率启动器：呼出一个输入框，就能打开应用、搜文件、管理剪贴板历史、调整窗口、运行各种扩展。**Raycast AI** 是它内置的一组 AI 功能，好处是不用切到浏览器，在任何应用里都能随手调用。

## 能做什么

AI 功能页列出的能力：

- **Quick AI**：随时随地提问，处理一天里的各种小问题。
- **AI Commands**：把常用提示词存成命令，用快捷键触发，比如改语法、缩短邮件、调整语气；有内置命令，也可以自定义。
- **AI Extensions**：连接 Linear、Slack、Notion、GitHub、日历等日常工具，让 AI 直接在这些工具里办事。
- **Custom Agents**：拥有各自指令和模型的自定义智能体。
- **Automations**：按计划定时运行的智能体，处理重复性任务。
- **Projects**：带专属指令和记忆的智能体工作区。
- **Screen Awareness**：把屏幕上的内容作为上下文提供给智能体。

模型方面，页面提到 OpenAI、Anthropic、Google、Perplexity 等提供方。还可以**自带模型**：连接自己的 Claude 或 ChatGPT 订阅，或填入 OpenAI、Anthropic、Google 的 API Key，这样不消耗 Raycast 的 AI 额度；本地模型通过 Ollama 集成使用。

## 怎么上手

1. 在 raycast.com 下载安装。官网页面注明 macOS 版需要较新的系统和 Apple 芯片；Windows 与 iOS 版本见官网对应页面。
2. 用快捷键呼出 Raycast，输入问题后按页面演示的方式（Tab 键）交给 Quick AI。
3. 把高频操作存成 AI Commands 并绑定快捷键。
4. 不想订阅的话，在设置里接入自己的 API Key 或 Ollama。

## 适合谁 / 不适合谁

**适合：** 习惯键盘操作的 Mac 用户；每天要在多个应用之间反复做改写、翻译、总结的人；已经有 API Key 或订阅、想找个顺手入口的用户。

**不适合：** 很少用快捷键的人；只在手机上使用 AI 的人；需要长篇文档协作的场景（专门的写作或笔记工具更合适）。

## 注意事项

- Screen Awareness 和各类扩展会读取屏幕或第三方应用里的内容，开启前确认授权范围。
- 自带 API Key 时费用由模型厂商另算。
- Windows 版功能与 macOS 版不一定一致，以官网说明为准。
