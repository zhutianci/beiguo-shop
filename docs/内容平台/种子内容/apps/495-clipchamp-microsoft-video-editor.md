## 是什么

Clipchamp 是微软旗下的视频剪辑工具。很多 Windows 用户是在电脑里看到这个应用才知道它的——它是微软官方的软件，不是捆绑的第三方程序。它有两种用法：在浏览器里直接打开网页版（不需要下载），或者使用 Windows 应用，用个人 Microsoft 账号登录。

它的定位是**轻量、够用**：时间轴剪辑、模板、素材库和几项实用的 AI 功能，适合做工作汇报视频、课程录屏、社交媒体短片，而不是专业影视后期。

## 能做什么

官网定价页列出的功能：

- **基础剪辑**：裁剪、分割、旋转、调整画面尺寸；
- **AI 字幕**：自动识别语音生成字幕；
- **AI 配音**：把文字转成旁白语音；
- **静音移除**：自动找出并删除长时间停顿；
- **素材库**：免版税的视频、音乐和图片素材；
- **Premium 增加**：4K 导出、高级素材、高级滤镜与特效、品牌套件（统一的 Logo、字体和配色）。

官网说明免费版和 Premium 都提供 AI 视频与音频编辑工具；完整的高级功能和「AI 视频创作」在工作场景下需要 Copilot 许可。

## 怎么上手

1. 打开 clipchamp.com 或 Windows 里的 Clipchamp 应用，用个人 Microsoft 账号登录。
2. 新建视频，把素材拖进媒体库，再拖到时间轴上。
3. 剪掉多余部分；在侧边栏打开字幕功能，选择语言后自动生成字幕并校对。
4. 需要旁白时，用文字转语音输入文案、选择声音。
5. 点击导出，选择 1080p（免费）或更高分辨率。

## 免费与付费

- **免费版**：视频数量不限，导出最高 1080p、**没有水印**，包含 AI 字幕、AI 配音和静音移除。
- **Premium**：4K 导出、高级素材与特效、品牌套件。定价页没有单独列出金额，而是说明 Premium **包含在 Microsoft 365 个人版和家庭版**订阅中。
- **工作 / 学校账号**：部分商业版和教育版许可包含标准的工作版 Clipchamp，功能与个人版不完全相同。

## 适合谁 / 不适合谁

**适合：**
- 用 Windows、偶尔需要剪视频的上班族、老师和学生；
- 已经订阅 Microsoft 365 个人版或家庭版、想把附带权益用起来的人；
- 需要快速给视频加字幕和旁白的内容作者。

**不适合：**
- 做抖音、小红书等国内平台内容的创作者，剪映的模板、特效和发布流程更贴合；
- 需要多机位、调色、复杂特效的专业剪辑；
- 网络环境较差的用户——网页版对网络和浏览器性能有要求。

## 注意事项

- **账号类型不同功能不同**：个人账号和工作 / 学校账号是两套版本，教程要看对版本。
- **素材授权**：库里的素材分免费和高级，高级素材需要 Premium 才能导出。
- **AI 字幕要校对**：专有名词、中英混说容易识别错。
- **AI 配音的使用范围**：用于商业视频前，查看微软的服务条款。
- **项目与媒体的保存位置**：留意素材是保存在本机还是云端，换电脑前确认已备份。
