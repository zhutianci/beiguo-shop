## 是什么

Zed 是一款开源的代码编辑器，官网的介绍是「快速、开源、支持多人协作」。它不是基于 VS Code 改的，而是从头写的原生应用，所以启动、打开大文件、滚动和输入的响应速度是它最常被提到的优点。

AI 方面，Zed 的思路比较开放：既提供自家托管的模型和编辑预测，也让你**用自己的 API Key**，还可以把其他厂商的命令行智能体接进编辑器里当面板用。

## 能做什么

- **编辑预测（Edit Predictions）**：边写边预测下一处修改，按 Tab 采纳。
- **内置智能体**：在侧边面板用自然语言让 AI 读代码、跨文件修改。
- **外部智能体**：官网提到可以使用 Claude Agent、Codex CLI 等外部智能体。
- **自带密钥**：支持 Anthropic、OpenAI、Google AI、Ollama 等服务商，用自己的 Key 不经过 Zed 计费。
- **多人协作**：共享项目、实时共同编辑。
- **编辑器本体**：语法高亮、语言服务器、Git 集成、终端、扩展等。

## 怎么上手

1. 在 zed.dev 下载安装包并安装。
2. 打开一个项目文件夹。
3. 登录 Zed 账号可以使用托管模型和编辑预测；不想登录也可以在设置里填入自己的 API Key，或指向本机的 Ollama。
4. 打开智能体面板，先让它解释项目结构，再交给它一个小改动。
5. 界面语言、主题和按键习惯在设置里调整；从 VS Code 迁移的用户可以启用相应的按键映射。

## 免费与付费

官网定价页（美元，月付，2026-10 查询）：

| 方案 | 价格 | 包含内容 |

## 适合谁 / 不适合谁

**适合：**
- 觉得基于 Electron 的编辑器不够流畅、追求响应速度的开发者；
- 想自由组合「编辑器 + 自己的模型密钥 / 本地模型 / 外部智能体」的人；
- 需要实时结对编程的小团队。

**不适合：**
- 重度依赖 VS Code 特定扩展的用户，Zed 的扩展生态规模较小；
- 希望一个订阅包揽大量顶级模型用量的人——Pro 档自带的模型额度不多；
- 需要完整中文界面的用户，下载前先确认当前版本的本地化情况。

## 注意事项

- **用量计费方式**：Pro 档超出赠送额度后按 API 标价上浮 10% 计费，重度使用建议直接填自己的密钥对比成本。
- **编辑预测会发送代码上下文**：涉及保密代码时，查看官方的隐私与数据设置。
- **外部智能体各自计费**：接入的第三方智能体按其自身的订阅或 API 规则收费。
- **版本更新频繁**：AI 相关的设置项和面板位置变化较快，以当前官方文档为准。
