> 本文根据百度智能云千帆大模型平台产品页整理，资料核对于 2026-10-11。模型与价格变化快，以官网为准。

## 是什么

千帆大模型平台是百度智能云旗下的模型与应用开发平台，官网现在的定位是「以 Agent 为核心的一站式企业级大模型服务平台」。它和面向普通用户的「文心」聊天助手不同：文心是直接对话的产品，千帆是给企业和开发者调用模型、搭建智能体用的云服务。

## 能做什么

产品页列出的能力大致分两块：

- **模型服务**：按量调用百度自家的文心（ERNIE）系列，以及平台接入的其他模型。页面展示的有 ERNIE-5.0、ERNIE-5.0-Thinking-Preview、ERNIE X1.1 Preview、ERNIE 4.5 Turbo、ERNIE 4.5 Turbo VL（看图）、开源的 ERNIE-4.5-VL-28B-A3B，以及 DeepSeek-V3.1、DeepSeek-V3.1-Think。
- **企业级 Agent 构建**：多智能体协同 Agent、自主规划 Agent、工作流 Agent、知识库 RAG，并提供全链路可观测（看得到每一步调用了什么、花了多少）。
- **Skill 与 MCP 服务**：页面强调「独家优质 Skill 与精选 MCP 服务」，百度搜索、百度百科等组件标注可免费试用，方便让智能体联网查资料。

部署方式上，页面写明公有云「适合需要快速获取定制大模型服务的企业」，私有化部署「适合对数据私密性和控制性要求较高的企业」。

## 怎么上手

1. 用百度智能云账号登录千帆控制台（新账号通常需要先完成实名认证，以控制台提示为准）；
2. 在控制台创建调用凭证，挑一个模型，先在在线体验里试效果；
3. 按官方文档用 API 或 SDK 接入自己的程序；
4. 想做智能体或知识库应用，在平台的应用开发模块里按引导创建。

## 免费与付费

千帆按调用量计费。产品页模型卡片上的标价（单位：元 / 千 tokens，输入 / 输出，2026-10 查询）：

| 模型 | 输入 | 输出 |
| --- | --- | --- |
| ERNIE-5.0 | 0.006–0.01 | 0.024–0.04 |
| ERNIE X1.1 Preview | 0.001 | 0.004 |
| ERNIE 4.5 Turbo | 0.0008 | 0.0032 |
| ERNIE 4.5 Turbo VL | 0.003 | 0.009 |

DeepSeek 系列在该页没有标价，免费额度页面也没写明，这两项以控制台和官方价格文档为准。

## 适合谁 / 不适合谁

**适合：**
- 已经在用百度智能云、希望模型和云资源走同一套账单的企业；
- 需要把百度搜索等能力接进智能体的团队；
- 有私有化部署、数据不出域要求的单位。

**不适合：**
- 只想聊天的个人用户，直接用文心 App 就行；
- 想零门槛试玩的新手——云平台的概念多（凭证、计费项、实名），上手比聊天产品复杂。

## 注意事项

- **注意计价单位**：页面按「千 tokens」标价，和不少平台的「百万 tokens」不同，比价时先换算。
- **同名产品多**：百度还有文心智能体平台、秒哒等面向不同人群的产品，别混在一起。
- **按量计费要设预算**：调试循环调用、长上下文都会让费用快速累积，建议先设额度提醒。
