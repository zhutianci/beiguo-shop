## 是什么

HeyGen 是 **HeyGen Technology Inc.** 推出的 AI 数字人视频平台。核心思路是「不用每次都出镜」：用一段短视频或几张照片生成你自己的数字分身（Avatar），之后只要输入文字脚本，数字人就会用你的形象和声音把内容讲出来。

官网首页主推的最新数字人模型是 **Avatar V**（HeyGen Research 2026 年 4 月 8 日发布技术报告，用一段参考视频和驱动音频生成任意长度的数字人视频，强调多角度一致和口型准确）；定价页里各套餐列的则是 **Avatar IV** 的生成用量。除了数字人，HeyGen 的另一大用途是 **视频翻译**：把已有视频翻译成其他语言，同时保留原声音色并重新对口型。官方还提供了 Video Agent（一句话生成整条视频）、ChatGPT 插件和 API。

## 能做什么

- **自定义视频数字人**：录一段短视频，捕捉你的外形、声音和表情，生成可反复使用的数字分身。
- **照片数字人**：用照片生成会说话的数字人视频（免费版最多 3 个照片数字人，付费版不限）。
- **现成数字人素材库**：免费版可从 500 多个、付费版可从 700 多个现成视频数字人里挑选。
- **脚本转视频**：输入文字脚本、选数字人和声音，生成口播、讲解、产品介绍视频。
- **视频翻译**：把视频翻成 175 种以上语言和方言（免费版 30+ 种语言），保留原声并对口型；免费版只能有限试用口型同步翻译，Pro 起可编辑和校对翻译稿。官方还单独上架了「HeyGen: Translate Video」App。
- **Video Agent**：描述需求，由 Agent 写脚本、配画面、合成视频。
- **团队与 API**：Business 档支持团队协作、SSO；开发者可通过 API 批量生成。

## 怎么上手

1. 打开 heygen.com 点 Get started 免费注册（官方写明免费版不需要信用卡），或在 App Store 下载 HeyGen 官方 App。
2. 先用素材库里的现成数字人，粘贴一段 100 字左右的脚本，选声音，生成第一条视频熟悉流程。
3. 想用自己的形象：按指引录一段本人出镜的短视频，并完成平台要求的同意/验证步骤，生成自定义数字人。
4. 要做多语言版本，进入视频翻译，上传原视频，选择目标语言生成。
5. 导出前预览口型和发音，免费版导出带水印。

可以这样开始（脚本示例）：

```
大家好，我是小王。今天用一分钟讲清楚我们新上线的会员积分规则：第一，消费一元积一分；第二，积分可以抵扣运费；第三，每年十二月三十一日清零。
```

## 适合谁 / 不适合谁

**适合：**
- 需要频繁出镜但没时间拍摄的创业者、讲师、销售和房产经纪人。
- 做出海内容的团队，一条视频快速翻成多语言版本。
- 企业做产品介绍、内部通知、培训短视频。

**不适合：**
- 需要电影感画面和复杂剧情的创作，HeyGen 主打口播类视频。
- 不愿意上传自己面部和声音数据的人。
- 想在未获本人明确同意的情况下用别人的形象做视频的人——这在官方政策里是被禁止的。

## 注意事项

- **必须取得本人同意**：官方内容审核政策规定，创建自定义数字人必须获得被呈现者（官方称 Actor）的**明确同意**，未经明确同意为他人创建数字人严格禁止；被呈现者可随时要求删除其形象，你需要配合下架相关内容。
- **禁止冒充名人和公众人物**：政策明确禁止在未获明确同意的情况下呈现真实个人，包括名人和公众人物，也限制政治竞选类内容。
- **生物特征数据**：隐私政策说明，创建数字人时用于唯一识别个人的生物特征数据处理以你的明确同意为依据（在创建流程中确认），可随时联系官方撤回，撤回后可能无法继续使用需要生物特征验证的功能。
- **商用与版权**：你对自己创建的照片或自定义数字人享有权利，但需确保使用方式不侵犯第三方权利，具体以服务条款为准。
- **地区与支付**：HeyGen 是海外服务，以官网支持的地区和支付方式为准；发布到国内平台时按规定标注 AI 生成或深度合成内容。
