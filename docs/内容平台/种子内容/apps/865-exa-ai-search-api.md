## 是什么

Exa 是一家做「给 AI 用的搜索引擎」的公司。它的 API 按量付费，覆盖网络搜索、网页正文获取、基于搜索结果的问答、定时监测，以及一个可以异步执行深度调研、整理名单和补全信息的 Agent。开发者通常把它接进智能体，作为联网检索工具；它与 Tavily、Firecrawl 属于同一类基础设施，各有侧重。

## 能做什么

定价页列出的接口：

- **Search**：网络搜索，分为 Instant、Fast、Auto 几种速度与质量档位。
- **Deep Search**：更深入的搜索变体，单价更高。
- **Contents**：获取网页的正文内容。
- **Answer**：直接返回基于搜索结果、由大模型生成的答案。
- **Monitors**：按计划定期运行的监测任务。
- **Agent**：异步智能体，用于深度调研、构建列表和信息补全。

## 怎么上手

1. 在 exa.ai 注册，领取免费额度并创建 API Key（不需要绑定支付方式）。
2. 在官网的在线试用界面输入一个查询，对比不同档位返回的结果。
3. 按官方文档在代码里调用 Search，再用 Contents 取回需要的页面正文。
4. 需要长时间调研或批量整理名单时，再使用 Agent。

## 免费与付费

定价页（美元，2026-10 查询）：

| 接口 | 价格 |
| --- | --- |
| Search（Instant） | 每 1,000 次请求 4 美元起 |
| Search（Fast / Auto） | 每 1,000 次请求 7 美元 |
| Deep Search | 每 1,000 次请求 12–15 美元 |
| Contents | 每 1,000 个页面 1 美元 |
| Answer | 每 1,000 次请求 5 美元 |
| Monitors | 每 1,000 次请求 15 美元 |
| Agent | 固定强度下每次请求 0.012–1.00 美元，或按用量计费 |

**免费额度**：注册送 10 美元（官方称最多相当于 2,500 次 Instant 搜索），每月重置为 10 美元；完成新手引导另有一次性 10 美元奖励。企业方案需联系销售。

## 适合谁 / 不适合谁

**适合：** 给智能体或 RAG 应用加联网检索能力的开发者；需要批量调研公司、人物、论文等名单的增长与研究团队；想用免费额度做原型的个人开发者。

**不适合：** 不写代码的普通用户；只需要偶尔搜索一下的场景；主要面向中文内容检索的应用（效果需自行验证）。

## 注意事项

- Deep Search 和 Agent 的单价明显更高，默认先用便宜的档位，确有必要再升级。
- 搜索到的内容应作为不可信输入处理，避免被网页中的恶意指令影响。
- 使用返回的网页正文时注意版权与引用规范。
