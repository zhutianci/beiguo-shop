## 是什么

Warp 最初是一款「更好用的终端」，现在官网把它定位为**面向智能体编程的现代终端**。它包含三样东西：

- **终端本体**：命令分块显示、像编辑器一样的输入区、命令补全和历史搜索；
- **编程智能体**：官网称为 Warp Agent CLI，在终端里用自然语言让它读代码、执行命令、修改文件；
- **Warp Factories**：在软件开发各环节里运行成批编程智能体的服务，面向团队。

支持的系统：macOS 10.14 及以上；Linux（.deb、.rpm、AppImage、Arch，x64 与 ARM64）；Windows 10 / 11（x64 与 ARM64）。

## 能做什么

- **用自然语言操作终端**：不记得命令时直接描述要做的事，由智能体给出并执行命令。
- **在终端里改代码**：智能体读取项目、提出修改并展示 diff。
- **云端智能体**：把任务放到云端运行（免费档数量有限）。
- **自带模型推理**：免费档即可接入自己的模型推理；Business 档支持自带 API Key 和自定义推理端点。
- **团队能力**：共享命令和工作流、统一计费与管理。

## 怎么上手

1. 在 warp.dev 下载对应系统的安装包。
2. 首次打开按提示登录（部分功能需要账号）。
3. 像普通终端一样使用；需要 AI 时在输入区切换到智能体模式，或直接用自然语言输入。
4. 让智能体执行会改动系统或文件的命令前，先看清它要运行的内容再确认。

试试这样问：

```text
查看当前目录下占用空间最大的 10 个文件夹，并按大小排序输出。
```

## 适合谁 / 不适合谁

**适合：**
- 每天大量使用命令行的开发者、运维和数据工程师；
- 记不住复杂命令、希望用自然语言驱动终端的人；
- 想在终端里统一使用编程智能体的团队。

**不适合：**
- 只想要一个轻量、无需登录的传统终端的用户；
- 在严格隔离的内网环境工作、不能连接外部服务的场景；
- 已经订阅其他编程智能体、不想再多付一份用量费的人（可只用免费档的终端功能）。

## 注意事项

- **命令是真的会执行**：让智能体自动执行命令前检查内容，尤其是删除、覆盖、权限相关的操作。
- **用量按 API 价折算**：套餐里的「20 美元用量」花得多快取决于你选的模型。
- **数据与隐私**：终端输出可能包含密钥和内部信息，使用 AI 功能前查看官方的数据处理说明和脱敏设置。
- **界面以英文为主**，中文显示与输入法兼容性以当前版本为准。
