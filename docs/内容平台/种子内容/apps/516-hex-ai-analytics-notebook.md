## 是什么

Hex 是一个在线的数据分析工作平台，官网现在的定位是「AI 分析平台」。它的基础形态是**协作式笔记本**：像 Jupyter 一样一格一格地写，但同一个笔记本里可以混用 SQL、Python 和图表、输入控件等无代码单元，直接连接公司的数据仓库，多人同时编辑。做完的分析可以一键发布成带筛选器的交互式数据应用，给不写代码的同事使用。

## 能做什么

官网列出的三块核心能力：

- **智能体笔记本（agentic notebooks）**：Hex agent 根据你的描述写 SQL 和 Python、生成图表、解释和修正报错；
- **Threads（对话式自助分析）**：业务人员用自然语言提问，在数据团队设定好的数据范围内直接得到答案；
- **交互式数据应用**：把笔记本发布成看板或小工具，支持定时运行（Team 及以上）。

## 怎么上手

1. 在 hex.tech 注册 Community 免费账号。
2. 新建项目，上传一个 CSV 文件，或配置数据库 / 数据仓库连接。
3. 新建 SQL 单元查询数据，再用图表单元可视化；不熟悉语法时让 Hex agent 根据需求生成。
4. 把关键图表和说明拖进应用布局，发布并分享链接。

## 适合谁 / 不适合谁

**适合：**
- 有数据仓库、数据分析师和数据科学家协作的公司；
- 既写 SQL 又写 Python、希望在一个地方完成取数、分析和分享的人；
- 想让业务同事自助查数、减少临时取数需求的数据团队。

**不适合：**
- 只有几张 Excel 要处理的普通办公用户，表格类 AI 工具更直接；
- 数据不允许连接海外云服务的企业；
- 没有任何 SQL 或 Python 基础、也没有数据团队支持的个人。

## 注意事项

- **按「编辑者」收费**：只查看应用的同事通常不占编辑者席位，规划好角色能省不少钱。
- **数据库权限**：连接数据仓库时使用只读、最小权限的专用账号。
- **AI 生成的查询要审核**：指标口径、表关联条件可能与公司定义不一致，关键报表需要人工复核。
- **额度**：Hex agent 的使用按额度计，重度使用前了解各档的额度差异。
