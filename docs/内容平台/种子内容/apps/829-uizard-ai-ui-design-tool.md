## 是什么

Uizard 是一款 AI 辅助的界面设计工具，官网的口号是「借助 AI，几分钟内从想法到设计」。它的目标用户不是专业设计师，而是产品经理、创业者、开发者这些「需要一份看得懂的原型、但不会用专业设计软件」的人。

## 能做什么

定价页列出的功能：

- **Autodesigner 2.0**：用文字描述生成项目、页面和主题——比如一句话描述一个订餐应用，得到一组互相关联的界面。免费档使用的是较早的 Autodesigner 1.5。
- **Screenshot Scanner**：把应用或网页截图转换成可以编辑的设计稿。
- **Wireframe Scanner**：把手绘的线框图拍照后变成数字线框图。
- **Design Assistant**：一组 AI 小工具，包括文字生成单个页面、主题与品牌套件、图片生成、热力图预测、设计评审，以及文字和图片助手。
- **基础设计能力**：UI / UX 设计、线框图、视觉稿和可点击原型。
- **协作与交付**：多人实时协作、评论、团队素材库；开发交付支持导出 CSS 和 React 组件。

## 怎么上手

1. 在 uizard.io 注册免费账号。
2. 新建项目，选择用 Autodesigner 从文字开始，或上传截图 / 手绘草图。
3. 在编辑器里调整文字、颜色和组件，把页面之间的跳转连起来，做成可点击的原型。
4. 把链接分享给同事评论；需要交给开发时，使用导出与交付功能。

## 适合谁 / 不适合谁

**适合：** 需要快速把想法画出来给团队或投资人看的产品经理和创业者；想把竞品截图改成自己方案的人；课程作业里需要原型的学生。

**不适合：** 追求像素级精确和完整设计系统的专业 UI 设计师（Figma 一类工具更合适）；需要直接产出可上线代码的人；免费档的页面数量撑不起完整项目。

## 注意事项

- 用别人产品的截图做参考可以，直接照搬界面去商用有侵权风险。
- AI 生成的界面常有布局重复、文案空泛的问题，需要人工梳理信息结构。
- 导出的代码片段适合做起点，不能直接当成生产代码。
