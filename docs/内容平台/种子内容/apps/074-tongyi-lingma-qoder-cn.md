## 是什么

**通义灵码** 是阿里云推出的 AI 编程助手，过去以 VS Code、JetBrains 插件形式为主，后来又推出了独立的 Lingma IDE。根据阿里云帮助中心的计费说明，**2026 年 5 月 20 日起，通义灵码正式更名为「Qoder CN」**，同时启用 Credits（额度点数）计费。

更名后它从单一的编码插件扩展成一组产品：

- **Qoder CN**：编码主产品，含桌面 IDE 和 JetBrains 插件；
- **Qoder CLI CN**：终端里的命令行智能体；
- **QoderWork CN**：面向日常办公的桌面应用；
- **Qoder CN Mobile**：手机端，用来查看和管理任务。

它和阿里面向海外的 **Qoder**（qoder.com）同属一个产品家族，但 Qoder CN 是国内版，独立官网、独立账号和计费，用人民币付费，模型以国产大模型为主。

## 能做什么

- **代码补全**：行级、函数级实时补全，结合当前文件和跨文件上下文。
- **智能体编程**：描述需求后，它能自己规划步骤、读写多个文件、在终端执行命令，并以 Diff 形式让你审阅改动。
- **研发问答**：解释代码、回答框架和阿里云产品相关问题。
- **报错排查**：结合报错信息定位问题并给出修复建议。
- **单元测试与注释生成**：为选中的代码生成测试用例和注释。
- **多模型切换**：官方介绍可在千问、GLM、DeepSeek、Kimi、MiniMax 等模型间切换，付费档开放更多模型选项。

## 怎么上手

1. 打开官网 qoder.cn，下载 Qoder CN 桌面 IDE；习惯 JetBrains 的用户，可在 IDE 插件市场搜索安装对应插件。
2. 按页面提示注册并登录。老的通义灵码用户需要按官方指引重新安装或更新插件 / 客户端，再重新登录，原有配置可以迁移。
3. 打开项目，先试补全：写一个函数名和注释，看它给出的建议，按 Tab 接受。
4. 在对话面板里切换到智能体模式，描述一个小任务，审阅它给出的多文件 Diff 后再接受。
5. 需要在终端或办公场景使用时，再安装 Qoder CLI CN 或 QoderWork CN，同一账号的 Credits 共用。

可以这样开始：「给这个 Spring Boot 项目加一个分页查询订单的接口，先列出要改的文件和方案，等我确认后再改。」

## 免费与付费

帮助中心计费说明列出的版本（官网定价页，2026-10 查询）：

| 版本 | 价格 | 每月 Credits |
|---|---|---|
| 个人免费版 | 0 | 2 周试用 + 300 Credits（一次性体验额度） |
| 个人专业版 | 59 元/月 | 2,000 |
| 个人高级版（Pro+） | 169 元/月 | 6,000 |
| Teams | 99 元/席位/月 | 3,000/席位 |
| 企业标准版 | 149 元/席位/月 | 3,000/席位 |
| 企业 VPC 版 | 199 元/席位/月 | 3,000/席位 |

个人和企业都可加购资源包。官方说明自 2026-06-20 起，个人订阅的 Credits 在桌面端、JetBrains 插件、QoderWork CN、CLI 和手机端之间共享。

## 适合谁 / 不适合谁

适合：
- 国内开发者，想要人民币付费、国产模型、阿里云账号体系的 AI 编程工具。
- 用 Java / Spring 等技术栈、经常查阿里云产品文档的后端团队。
- 有合规要求、需要 VPC 部署的企业。

不适合：
- 主力编辑器是 VS Code 的用户：计费说明注明 VS Code 插件已停止演进，后续能力以桌面 IDE 和 JetBrains 插件为主。
- 只想长期免费用的人：免费版只是有限体验额度，补全次数也有限。

## 注意事项

- **改名带来的混淆**：网上很多「通义灵码免费无限用」的老教程已过时，以 2026-05-20 之后的计费说明为准。
- **Credits 消耗**：不同模型、智能体任务消耗不同，长任务注意查看剩余额度；个人资源包有有效期。
- **代码安全**：上传到云端分析的代码涉及公司资产时，先确认团队的数据政策，企业可考虑 VPC 版。
- **核对生成结果**：AI 写的代码和测试都要人工审阅、本地跑通再合并。
