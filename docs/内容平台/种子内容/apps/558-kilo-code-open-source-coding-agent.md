> 本文根据 Kilo Code 官方 GitHub 仓库 README 与官网整理，资料核对于 2026-10-11。开源项目变化快，以官方仓库为准。

## 是什么

Kilo Code 是一个开源的 AI 编程智能体，仓库 Kilo-Org/kilocode 约有 2.75 万星标，采用 MIT 许可。它属于 Cline 这一脉的「编辑器内智能体」：装成 IDE 插件后，在侧边栏里用自然语言描述任务，它来读代码、改文件、跑命令。

对正在找同类工具的人，有一条背景值得知道：同类的 Roo Code 已于 2026 年 5 月停止维护、仓库归档（其仓库页面把 Cline 等列为替代选择），选型时可以把它从候选里划掉。

## 能做什么

README 列出的能力：

- **跨文件生成与修改代码**；
- **内联自动补全**：边写边提示，不只是对话式智能体；
- **自检**：完成后检查自己的修改；
- **操作终端和浏览器**：运行命令、打开页面验证效果；
- **模型切换**：可在 500 多个模型之间选择，并且可以在任务中途更换；
- **多个运行位置**：VS Code、JetBrains 系列 IDE、命令行；
- **Cloud Agent 与自动代码审查**：把任务放到网页端的云端智能体执行，并对代码改动做自动审查。

## 怎么上手

1. 在 VS Code 扩展市场或 JetBrains 插件市场搜索 Kilo Code 安装；命令行版按 README 说明安装。
2. 登录 Kilo 账号。官方说明开始使用不需要自备 API Key；也可以在设置里填入自己的模型密钥。
3. 打开项目，在侧边栏的对话框里描述任务。
4. 它会列出计划并在执行每一步前请求许可；熟悉后可以对读取文件等低风险操作开启自动批准。
5. 任务完成后查看 diff，再决定是否保留。

## 免费与付费

- **软件本身**：开源免费。
- **模型费用**：README 的说法是「开源、定价公开」，你支付的是模型服务商的价格，**Kilo 不加价**；使用自己的 API Key 时直接由服务商计费。
- 团队与企业功能、云端智能体的收费方式，以官网为准。

## 适合谁 / 不适合谁

**适合：**
- 想在现有的 VS Code 或 JetBrains 里使用智能体、不愿换编辑器的开发者；
- 希望自由选择模型并且清楚每一笔花费的人；
- 原 Roo Code 用户寻找仍在维护的替代品。

**不适合：**
- 想要固定月费、不操心用量的人——按量计费的账单会随使用强度波动；
- 完全没有编程基础的用户；
- 需要厂商提供合规承诺与专属支持的大型企业（可咨询其企业方案）。

## 注意事项

- **按量计费要设上限**：让智能体长时间自主运行、选用高价模型时花费增长很快，建议设置预算提醒。
- **自动批准要谨慎**：不要对执行命令、删除文件这类操作开启无条件自动批准。
- **代码会发送给模型服务商**：公司代码使用前确认合规要求。
- **在 Git 仓库里使用**，改动前先提交，便于回滚。
