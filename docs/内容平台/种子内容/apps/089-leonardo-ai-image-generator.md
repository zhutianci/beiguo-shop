> 本文根据 Leonardo.Ai 官方帮助中心和 App Store 官方应用页整理，资料核对于 2026-10-07。功能和价格变化快，以官网为准。

## 是什么

Leonardo.Ai 是 Leonardo Interactive Pty Ltd（App Store 上的开发者名称）推出的 AI 内容生成平台，与在线设计平台 Canva 打通：官方功能「Edit in Canva」可以把生成的图片一键送到 Canva 账号继续编辑，个人用户免费可用（团队版暂不支持）。官方 FAQ 的定位是「把多种生成式 AI 技术整合进同一个可投入生产的平台」，覆盖图片、视频、设计和动效。

它既有自研模型——**Phoenix**（官方称为 Leonardo 的基础模型，有 0.9 和 1.0 两个版本，所有网页方案含免费版都能用）、**Lucid Origin** 等——也接入了 Google Veo 3 / 3.1、Nano Banana 等第三方模型，在一个界面里切换使用。

## 能做什么

- **图片生成**：选择模型、风格预设和画幅，批量生成角色、场景、道具和概念图。
- **视频生成**：文生视频或图生视频，支持设置首帧和尾帧控制镜头走向。
- **Blueprints 蓝图**：官方预设好模型、提示词和参数的一键工作流，如产品摄影，只需上传图片即可出图出视频。
- **自定义模型训练**：上传数据集训练 Elements（LoRA），保持角色或画风一致。
- **画布编辑**：Canvas 编辑器做局部重绘和扩图；Realtime Canvas 边画草图边实时出图。
- **放大与 3D**：Pro Upscaler 提升分辨率；3D 生成可把角色图片转成可下载的 .glb 模型（由 Hyper3D 的 Rodin V2 驱动，400 Token 起）。
- **API**：通过 API 方案调用模型，接入自己的产品。

## 怎么上手

1. 打开 leonardo.ai 注册账号，或在 App Store 下载「Leonardo.Ai - Image Generator」。
2. 首次进入先看首页的 Blueprints，挑一个和目标相近的模板体验一次完整流程。
3. 进入 Image 生成页，选模型（如 Phoenix 或 Lucid Origin），写英文提示词，设置数量和比例。
4. 对满意的图做放大、编辑，或点生成视频；付费用户可打开 Private Mode 私密生成。
5. 有固定角色需求时，准备一组同角色图片训练 Elements。

可以这样开始：`fantasy game character concept sheet, young alchemist with brass goggles, front and side view, clean background`

## 免费与付费

官方帮助中心列出的方案与每月 Token（2026-10 查询）：

- **Free**：每天 150 个 Token，当天用不完不累积；作品公开，不能私密生成。
- **Essential**：每月 8,500 Token，可私密生成。
- **Premium**：每月 25,000 Token。
- **Ultimate**：每月 60,000 Token。

付费方案没用完的 Token 会进入「Rollover Bank」，最多存 3 个月的量；付费用户还可以购买不过期的充值 Token，部分方案在 Token 用完后可继续无限生成（以方案说明为准）。订阅可选月付或年付，用 PayPal 或银行卡支付。团队版有 Starter、Growth 档（至少 3 个席位）；API 另有 Basic、Standard、Pro、Custom 等 API 方案。各档具体价格请以官网定价页为准。

## 适合谁 / 不适合谁

适合：
- 独立游戏开发者、游戏美术，需要批量出角色、道具和场景概念。
- 需要固定角色形象的绘本、漫画和 IP 创作者。
- 已在用 Canva、希望把 AI 图片接着放进设计稿的用户。

不适合：
- 对隐私敏感却只用免费版的人：免费版作品默认公开。
- 只需要偶尔出一张图的轻度用户，学习曲线比对话式工具高。
- 需要中文提示词稳定出图的用户，官方示例以英文为主。

## 注意事项

- **公开作品的授权**：按官方帮助中心，未设为私密的图片，Leonardo 及其他用户可在服务内使用；付费用户私密生成的作品归用户所有。
- **商用**：官方 FAQ 写明免费用户生成的图片也可商用，但须遵守服务条款。
- **Private Mode 仅付费可用**，切回免费版后之前私密生成的作品权益不变。
- 内容须遵守平台使用政策，不得生成违法或侵权内容。
