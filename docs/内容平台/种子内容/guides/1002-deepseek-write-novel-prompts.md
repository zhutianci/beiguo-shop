## 适用于谁

- 搜「deepseek写小说指令」「deepseek 写 小说 提示 词」的人；
- 想用 DeepSeek 连载网文、写短篇、写同人，又总写到一半人设崩了、前后矛盾的人；
- 不确定一次该让它写多长的人。

## 结论先说

1. **长篇写作的关键是「每次都把设定带上」**。官方文档说明，API 是无状态的，多轮对话要自己把历史消息拼接起来再发给模型（网页版 / 客户端会替你保存对话，但对话太长时同样会有上限）。所以设定写在一张固定的「设定卡」里，每一轮都能看到，比指望它「记住前面」可靠。
2. **一章一章写，比一次写完更容易控制**。官方价格页写明 1M 上下文、最大输出 384K（2026-10 查询），数字很大，但更长的单次输出意味着更难中途纠偏。
3. **指令里要同时给：设定、任务、约束、格式**，缺了哪样模型就按自己的习惯补。
4. **官方没有给「写小说」的专门模板**。官方提示库里与写作相关的是「散文写作」「诗歌创作」「文案大纲生成」「角色扮演（自定义人设）」「角色扮演（情景续写）」等样例，思路可以借鉴。

## 一、先写设定卡

设定卡是整个项目的「圣经」，每次请求都贴在最前面。下面是一个模板，把括号里的内容换成你自己的：

```
【设定卡】
书名：（暂定）
题材与基调：（例如：现代都市悬疑，克制、冷静）
叙述视角：（第三人称有限视角，跟随主角）
主要人物：
- 林远，32 岁，法医，话少，习惯用数据说话，怕麻烦别人
- 周岚，28 岁，记者，嘴快心软，与林远是旧同学
世界观与规则：（时代、地点、不能违反的设定）
文风：（短句为主，少用形容词，对话占三成；范文见下）
禁区：不写血腥细节描写，不出现「命运的齿轮」这类套话
篇幅：每章约 2500 字，共 20 章
```

设定卡越短越好用，控制在一页之内。人物太多时只写本章会出场的人。设定卡里有哪些必须写的内容，见下图：

## 二、让它出分章大纲

```
下面是设定卡。请根据它写一份 20 章的分章大纲：
每章写「章名 + 一句话梗概 + 本章要埋的伏笔 / 要回收的伏笔」。
第 1 章要有一个能抓住读者的开场事件；第 10 章左右出现转折；结尾要回收主要伏笔。
先只给大纲，不要写正文。

【设定卡】……
```

大纲出来后，**你来改**：删掉不喜欢的情节，调整顺序，再让它输出修订版。大纲是你对故事走向的控制权，不要整份照单全收。

## 三、逐章续写的指令

每写一章，都用同样的结构：

```
【设定卡】……（贴最新版）
【本章大纲】第 5 章：……
【上一章结尾】（贴最后 300 字左右）

请写第 5 章，约 2500 字。
要求：
1. 严格遵守设定卡，人物说话方式不变；
2. 开头自然衔接上一章结尾，不要重复上一章的内容；
3. 只写本章大纲里的情节，章末留一个悬念，不要提前写后面的章节；
4. 直接输出正文，不要加说明。
```

注意「只写本章」这一条：不写，模型常常急着把故事收尾。

## 四、每写完一章做一次小结

让模型把刚写的章节总结成一小段「进度记录」，再并进设定卡：

```
请根据刚才写的第 5 章，更新设定卡里的「当前进度」：
人物当前状态、新出现的人物与关系、已经埋下但尚未回收的伏笔、时间线。
只输出更新后的「当前进度」部分，不超过 300 字。
```

这样设定卡不会越来越长，而且模型每次看到的都是最新状态。如何分段喂长文档，见 [/guides/long-document-prompting-tips](/guides/long-document-prompting-tips)。

## 五、思考模式要不要开

DeepSeek 的思考模式会在输出最终回答前先产生思维链。官方文档提醒：**思考模式不支持 temperature、presence_penalty、frequency_penalty 参数**，设置了也不会生效（不会报错）。所以如果你通过 API 写作并想靠调 temperature 控制文风的发散程度，需要关闭思考模式（`thinking: {"type": "disabled"}`）；网页版的开关位置见 [/guides/deepseek-deep-thinking-web-search](/guides/deepseek-deep-thinking-web-search)。写大纲、理清伏笔时开思考模式有用，写正文时是否开，可以两种都试一次，选你喜欢的。

## 六、常见问题

**Q：写到后面人物性格变了怎么办？**
先检查设定卡有没有贴在请求里；然后把人物的说话习惯写成具体例子（「他从不说『我觉得』，只说『数据显示』」），比形容词有效。必要时把前两章里最有代表性的一段对话附上做示范，见 [/guides/few-shot-prompting-examples](/guides/few-shot-prompting-examples)。

**Q：一次能写多长？**
官方价格页写最大输出 384K，但这是上限，不是建议。实际使用中按章节写更容易修改；网页版的单次回复长度以界面为准。

**Q：它总是写套话、爱写总结陈词怎么办？**
在「禁区」里列出具体的词和句式，并明确「章末不要总结，不要抒情升华」。

**Q：和 ChatGPT 写小说有什么区别？**
本站另有一篇 [/guides/chatgpt-write-novel](/guides/chatgpt-write-novel)，设定卡和分章写作的方法同样适用。

**Q：AI 写的小说能直接发布吗？**
各平台对 AI 生成内容有自己的规定和标注要求，请以发布平台的规则为准；版权归属也以相关法律和平台协议为准。
