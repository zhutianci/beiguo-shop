## 适用于谁

- 搜「千问怎么上传文件」「千问上传文件限制」「千问一次可以上传多少文件」「千问只能上传一个文件吗」的人；
- 手里有论文、合同、报告、表格，想让千问读完后总结、对比或提取数据的人；
- 遇到「上传失败」「解析失败」，想先自查的人。

本文根据千问官网上传入口的界面说明和 App Store 应用介绍整理，资料核对于 2026-10-11。官方没有公开更细的规则（比如字数上限），没写明的地方本文不猜，以实际界面提示为准。

## 结论先说

1. **入口**：输入框左侧的「+」，里面有「上传文档」和「上传图片」。
2. **数量和大小**：界面说明是可同时上传 10 个文件，每个 100 MB。不是只能传一个。
3. **格式**：PDF、Word、Excel、PPT、EPUB、Mobi、txt、Key、Numbers、JSON、Java、SQL 等。
4. **长文档**：App Store 应用介绍写的是可处理 500 页超长文，支持快速总结、数据分析、翻译。
5. **想要好结果，关键在提问**：说清你是谁、要拿结论做什么、要什么格式，并要求它标出依据在原文哪里。

## 步骤

### 1. 找到上传入口

打开 qianwen.com 并登录，点输入框左侧的「+」，菜单里有四项：

- **上传文档**：读 PDF、Word、表格等文件；
- **上传图片**：读截图、照片、扫描件；
- **共享屏幕和应用**、**截屏提问**：针对屏幕上正在看的内容提问。

鼠标停在「上传文档」上，会显示官方的限制说明：可同时上传 10 个文件（每个 100 MB），支持 PDF / Word / Excel / PPT / EPUB / Mobi / txt / Key / Numbers / JSON / Java / SQL 等多种格式。

手机 App 的入口位置不同，但应用介绍里写的口径一致：一次可上传 10 个文档或图片。

### 2. 上传前先处理一下文件

官方给的是数量、大小、格式三条限制。下面几条是让解析更顺的通用做法，不是官方规定：

- **扫描件**：如果 PDF 是一页页图片（不能选中文字），识别效果取决于清晰度。能拿到文字版就用文字版；
- **大文件拆开**：超过 100 MB 的文件按章节拆成几个；一本书里只需要其中两章，就只传那两章；
- **表格**：一个工作表只放一张表，第一行是表头，合并单元格尽量取消；
- **文件名写清楚**：比如「2025 年报」「2026 半年报」，多文件对比时它和你都不容易弄混。

### 3. 三类最常用的提问写法

上传后在同一条消息里写要求。只发文件不说话，得到的往往是一份泛泛的摘要。

**总结一份长文档**

```
这是一份 80 页的行业研究报告。我是做采购的，只关心供应端。
请按下面的结构输出：
1. 三句话概括全文结论
2. 与「原材料价格」「产能」「交期」有关的要点，每条注明所在章节或页码
3. 报告里没有回答、但我做采购决策需要知道的问题
不要补充报告以外的信息；不确定的地方直接说不确定。
```

**对比多份文件**

```
我上传了两份合同：A 是去年的版本，B 是对方今年发来的版本。
请用表格列出两者的差异：条款名称 / A 的写法 / B 的写法 / 这个变化对乙方（我方）是有利、不利还是中性。
只列有实质变化的条款，措辞微调不用列。
```

**从表格里取数**

```
这是今年 1–9 月的销售明细表。
请先告诉我你识别到了哪些列、一共多少行，我确认无误后再继续。
然后按月汇总销售额，并指出环比下降超过 10% 的月份。
```

第三个例子里「先复述识别结果」这一步很有用：表格读错列、漏行时，在这里就能发现。

### 4. 追问和核对

- **追问细节**：「第 3 条的依据在原文哪一段？把原句引给我」；
- **换角度**：「如果我是投资人而不是采购，重点会有什么不同？」；
- **核对数字**：凡是要写进正式材料的数字、日期、金额、条款编号，回原文对一遍。模型有可能把相邻段落的数字张冠李戴，要求它给出页码再去翻是最省事的核对方式。

### 5. 需要成品文件时

按 App Store 的应用介绍，千问有「智能编辑器」，可以在对话里编辑生成的内容并保存下载，支持 PDF、Word、PPT、Excel 多格式互转；要直接产出一份 PPT、Word 或表格，可以切到「工作」页签用工作助理。具体按钮位置以实际界面为准。

## 常见问题

**Q：千问只能上传一个文件吗？**
不是。界面说明是可同时上传 10 个文件，每个不超过 100 MB。

**Q：能读多长的文档？**
应用介绍的说法是可处理 500 页超长文。官方没有公布按字数计算的上限；文件特别长时，建议先让它列出目录和各章要点，再分章细问。

**Q：上传失败或提示解析失败怎么办？**
官方没有公开逐条的原因说明。可以按顺序自查：格式是否在支持列表里；单个文件是否超过 100 MB；文件是否加了打开密码或损坏（本地能否正常打开）；是否一次传了超过 10 个。都没问题就刷新页面重传，或换 App / 电脑客户端试一次。

**Q：提示文件不合规？**
这是平台的内容审核提示，说明文件内容触发了审核规则。官方没有公开具体判定标准，本文不提供规避办法；可以确认文件本身没有问题后通过反馈入口申诉。

**Q：上传的文件安全吗？**
文件会上传到服务端处理。涉及个人隐私、公司机密、未公开合同的材料，先看一遍官网底部的用户协议和隐私政策，再决定传不传；能脱敏的先脱敏。

**Q：和 Kimi 读长文档比哪个好？**
两家的数量、大小限制和处理方式不一样，可以对照《Kimi上传文件读长文档》那篇的官方数字，按自己手头文件的情况选。
