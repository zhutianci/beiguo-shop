## 适用于谁

- 搜「kimi 深度研究」「kimi深度研究怎么用」「kimi深度研究额度用完了怎么办」的人；
- 要写行业研究、课题综述、竞品调研，想让 AI 先跑一遍资料的人。

本文根据 Kimi 官方帮助中心的深度研究文章和 kimi.com/deep-research 页面整理，资料核对于 2026-10-11。

## 结论先说

1. **入口**：网页版打开 kimi.com/deep-research，或在首页输入框下方点「深度研究」；App 里在工具栏切换到深度研究。
2. **一次研究通常要 10–25 分钟**，期间可以离开页面，任务在后台跑，完成后有通知。
3. **产出两份东西**：一份带内嵌引用的长篇文字报告，一份可交互、可分享的可视化网页报告。
4. **额度消耗大**：官方给的参考是一次约消耗 5–10% 的月度额度（以 Moderato 套餐为参考）。任务一旦启动，中途停止也算已消耗。
5. **不适合简单问题**。一句话能答的事用普通会话更快。

## 它到底做了什么

官方介绍，深度研究由 Kimi 自研的研究模型驱动，自己完成从规划到交付的全过程。帮助中心给了一组平均数据，可以帮你理解它和「联网搜索一下」的差别：

- 澄清意图后平均进行 23 步推理；
- 平均规划 74 个关键词，找到 206 个网址，从中筛出质量最高的约 3.2% 来用；
- 文字报告平均万字以上，平均引用约 26 个信源，引用内嵌在正文里，点击可以跳到原文并高亮对应段落。

## 步骤

### 1. 写一个边界清楚的问题

官方的建议是限定时间范围、地域范围和来源类型；范围太大的问题拆成几个子问题分别研究。对比一下：

- 模糊：`研究一下新能源汽车`
- 清楚：

```
研究 2023 年至今中国新能源乘用车在东南亚市场的出口情况：
1. 各年出口量和主要目的国；
2. 主要车企的本地化建厂进展；
3. 当地关税和补贴政策的变化；
资料优先采用政府统计、行业协会和上市公司公告，媒体报道作为补充。
```

官方同时提醒：问题过长或表意不清会导致方向偏差，所以写清边界即可，不要把背景故事全塞进去。

### 2. 认真回答澄清问题

发送后，Kimi 通常会先反问几个问题来确认方向。这一步决定了后面二十分钟花在哪里：

- 回答要**简洁、指向明确**，官方说明回复过长或偏离原问题可能让研究跑偏；
- 把**不需要的方向**直接说出来，例如「不需要技术原理部分」「不看 2022 年以前的数据」；
- 没有特别要求时，可以点「做个全面的研究」跳过。

### 3. 等它跑完

研究过程中可以实时看到它用了哪些检索关键词、怎么推理、访问了哪些网址。两条官方提醒：

- 界面长时间没刷新不代表中断。可以刷新页面，或者先去做别的，稍后回来；
- **不要点「停止输出」**。任务启动后算力即被占用，主动停止或关闭页面都视为已消耗额度。

### 4. 读报告：先核对引用

研究完成后得到两份成果：

- **深度研究报告**：长篇文字，适合精读和引用；
- **可视化报告**：网页形式，有结构化排版和思维导图，适合快速浏览和分享给别人。

读的时候抽查关键结论的引用——点开内嵌的引用标记，看原文是否真的支持这句话。用在论文、投资、对外发布的内容里的数字，必须回到原始来源核对。

### 5. 导出和分享

- **文字报告**：点右上角「下载」或「复制」，可导出 PDF、Word；
- **可视化报告**：点「预览」→「分享」→「复制链接」得到公开分享链接；在浏览器中打开后可以「另存为」保存成 HTML 或 PDF；也可以在代码模式下复制 HTML 源码。

### 6. 接着往下做

报告出来后可以在同一个会话里继续：

```
基于这份报告，把「政策变化」一章单独展开成 1500 字，并列出还缺哪些数据。
```

官方说明研究模型的上下文长度为 128K token，单次输出通常在 8K–16K token 左右；报告没写完时，回复「继续」或要求它分章节生成。想把结论做成汇报材料，可以把报告交给 PPT 助手，见《Kimi PPT 助手怎么用》。

## 适合与不适合

官方列出的适用场景：投资分析、行业研究、学术课题、战略规划这类专业研究；法规梳理、多来源信息汇总；教学准备和前沿领域梳理。

官方明确说不适合的：创意写作（网文、剧本、歌词）；娱乐类问题（排盘、运势、取名、预测彩票号码）；固定模板类产出（简历、固定格式表单、可编辑 PPT）。

## 常见问题

**Q：深度研究卡住、一直没结果？**
通常需要 10–25 分钟。先刷新页面；还没有就检查网络后继续等，也可以离开会话稍后回来。

**Q：研究方向跑偏了怎么办？**
官方的处理方式：点页面底部「👎」说明问题类型和偏差，平台会在 1–3 个工作日内核查，属实的自动退还本次额度。下次提问时限定时间、地域和来源类型，并在澄清环节说明不要的方向。

**Q：任务失败了还扣额度吗？**
官方说明：因工具调用失败等原因导致任务失败、没有返回有效结果的，不扣额度（自动返还）。但自己主动停止的任务按已消耗处理。

**Q：额度用完了怎么办？**
深度研究和其他会员功能共用一个额度池，按实际 token 消耗扣除，按计费周期刷新。可以在「我的」→「设置」→「订阅」里查看剩余额度；用完后等刷新，或按官方会员计划页面升级。

**Q：能指定只用某些来源吗？**
可以在问题里写明来源类型偏好（如「只采用官方统计和上市公司公告」）。它会尽量遵循，但不保证百分之百，读报告时仍要看引用来源。
