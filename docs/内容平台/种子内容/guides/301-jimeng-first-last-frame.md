## 适用于谁

- 搜「即梦首尾帧怎么用」「即梦首尾帧在哪里」，想用两张图做变身、转场、穿越类视频的人；
- 发现「首尾帧不见了」「首尾帧不能用了」，不知道是功能下线还是自己操作问题的人。

本文根据即梦网页版界面和火山引擎 Seedance 官方文档整理，资料核对于 2026-10-07；界面以你实际看到的为准。

## 结论先说

1. **首尾帧 = 你给开头和结尾两张图，模型生成中间的过渡**。入口在「视频生成」里，选好模型后切到「首尾帧」方式上传。
2. **不是所有模型都支持**。按核对时的页面说明，较新的 Seedance 2.x 系列支持首尾帧，部分旧模型只支持首帧或走「智能多帧」（以实际界面提示为准）。找不到首尾帧，先换模型。
3. **两张图比例要相同**，最好主体也相同，再用一句话写清「怎么从 A 变到 B」。

## 步骤

### 1. 找到首尾帧入口

1. 打开 jimeng.jianying.com，在首页输入框的「创作类型」里选 **视频生成**；
2. 点模型名，选一个支持首尾帧的模型（如 即梦 Seedance 2.5 或 Seedance 2.0 系列）；
3. 在生成方式里选 **首尾帧**（同一位置还有「全能参考」「智能多帧」等，以实际界面为准）；
4. 先上传 **首帧图**，再上传 **尾帧图**。界面会提示「上传与首帧同比例的尾帧」。

如果选的模型不支持，界面会显示「当前模型不支持尾帧」，这时只能传首帧——这正是很多人以为「首尾帧没了」的原因。

### 2. 准备两张合格的图

- **比例一致**：首尾两张图要同比例，否则会提示「请上传比例相同的首尾帧图片」。官方文档还说明：输入图片和输出视频宽高比不一致时，可能出现画面拉伸、压缩的「跳变」。Seedance 2.5 做首尾帧时会自动让输出比例跟随首帧图；
- **主体一致**：界面给的提示是「首帧图和尾帧图，尽量都包含同样的主体」。同一个人 / 物在两个场景、两套衣服、两种状态之间变化，效果最稳；
- **清晰度够**：官方提示词建议里提到，图生视频请尽量上传高清图片，图片质量对结果影响很大；
- **画面是你的**：用自己拍的、自己生成的或已获授权的图。用真人照片前，确认是本人或已取得授权。

一个省事的做法：先用即梦「图片生成」做首帧，再用同一张图做参考生成尾帧（换衣服、换场景、换季节），两张图天然同主体同风格。

### 3. 写过渡提示词

即梦给的示例是「可爱的南极小企鹅，在冰上晃晃悠悠地走」——也就是**写清主体，再写怎么过渡**。可以按这个结构：

```
主体 + 从首帧到尾帧发生了什么 + 镜头怎么动 + 节奏/氛围
```

示例：

```
同一个女孩站在原地，衣服从冬季大衣自然变换为夏季连衣裙，背景从雪地过渡到海边，
镜头缓慢环绕半圈，光线由冷变暖，转场流畅
```

```
镜头从咖啡豆特写缓慢拉远，咖啡豆旋转融化，过渡为一杯冒热气的拿铁，固定机位，柔和光线
```

写法要点：

- **一个镜头只指定一种运镜**。Seedance 2.0 提示词指南提醒，同时要求推拉摇移会增加画面不稳定；
- **用具体动作替代抽象词**。「很梦幻」不如写「花瓣从下往上飘起，画面逐渐变亮」；
- **两张图差别太大时加「中间发生什么」**，比如穿过一扇门、被一阵烟雾遮住、镜头推进到某个物体再拉出，模型更容易做出合理过渡。更多运镜写法见《AI视频运镜提示词》。

### 4. 设置时长、分辨率后生成

在输入框下方设置时长和分辨率（可选范围随模型变化），确认积分后生成。生成后不满意，可以「重新编辑」改提示词，或「再次生成」多抽几次。

## 进阶：首尾帧接龙做长视频

单段视频时长有限，可以把**上一段的尾帧当下一段的首帧**接着生成，再在剪辑软件里拼起来，画面就能连贯。火山引擎文档也把「用上一个视频的尾帧作为下一个视频的首帧」列为生成连续视频的方法。

如果用的是 Seedance 2.5，也可以直接试试单段更长的生成和「视频延长」，详见《Seedance 2.0 怎么用》。

## 常见问题

**Q：即梦首尾帧在哪里？我只看到上传首帧。**
在「视频生成」里，且要先选支持首尾帧的模型。Seedance 1.0 等模型只支持首帧，换成 Seedance 2.0 / 2.5 系列后再找「首尾帧」。

**Q：即梦首尾帧不能用了 / 不见了，是下线了吗？**
截至资料核对时（2026-10-07），网页版页面里仍有「首尾帧」方式。常见原因是：当前模型不支持尾帧；在「数字人」「动作模仿」等其他创作类型里（它们没有首尾帧）；或者 App 和网页版功能上线节奏不同，可以先在网页版试。

**Q：首尾帧和智能多帧有什么区别？**
首尾帧只有两张图；智能多帧可以按顺序放多张图，每两张之间写一段运镜描述，适合一镜到底的连续镜头。哪些模型支持智能多帧，以模型切换时的提示为准。

**Q：生成的视频中间有一下突然变形、拉伸？**
多半是首尾帧和输出比例不一致。把两张图裁成同一比例，并让输出比例跟首帧一致后重新生成。

**Q：上传两张图后提示不合规或生成失败？**
检查图片里是否有他人肖像、知名 IP 角色或违规内容，排查方法见《即梦视频未通过审核 / 生成失败怎么办》。
