## 结论先说

1. **AI 浏览器大致两类**：一类是以 AI 为核心设计的新浏览器（Perplexity Comet、Opera Neon、Dia）；另一类是在现有浏览器里加 AI 助手（Chrome 里的 Gemini、Edge 里的 Copilot、Brave 的 Leo，以及 Claude in Chrome 这样的扩展）。
2. **Comet**：官方说是基于 Chromium 的浏览器，把 Perplexity 的 AI 搜索作为主搜索引擎，带 Comet Assistant 助手侧边栏。官方公告说已向全球开放免费下载。
3. **Opera Neon**：官方自述是「为行动而生」的浏览器，可以接 MCP 和 CLI；官方页写明订阅后才激活 agent 功能，每月 19.90 美元。
4. **Dia**：The Browser Company 做的浏览器，官方页写着可以免费下载，支持 macOS 和 Windows。
5. **Brave Leo**：Brave 浏览器内置的 AI 助手，官方说不需要账号，不保留或共享聊天，Leo 免费，另有付费 Premium。
6. **ChatGPT Atlas** 官方已停用，见 [/guides/chatgpt-atlas-retired](/guides/chatgpt-atlas-retired)。

## 一、Perplexity Comet

- **是什么**：官方帮助中心说，Comet 是基于 Chromium 的浏览器，集成了 Perplexity 提供的 AI 能力，同时有书签、网页翻译，并支持大多数 Chrome 扩展；
- **官方列的主要特点**：把 Perplexity 的 AI 搜索作为主搜索引擎；Comet Assistant 的「个人搜索」会分析你的浏览历史来找相关信息；Gmail 连接器；针对已打开网页提问的助手面板；一键总结按钮；内置广告拦截；语音模式；
- **助手侧边栏与快捷键**：官方快速上手文章说，助手在可折叠的侧边栏里（Alt + A），能理解你浏览的每个网页，支持跨标签页比较、写邮件、自动操作网页；总结快捷键 Alt + S，语音 Shift + Alt + V；
- **下载**：官方说在 perplexity.ai/comet 点下载，页面会自动推荐 Mac 或 Windows 版安装包；安装时会请求钥匙串访问，用来存密码和自动填充信息；可以在设置里导入其他浏览器的书签、密码、扩展和历史；
- **平台与价格**：首页写 Mac、Windows、iOS 和 Android；快速上手文章写 macOS 和 Windows 10/11；官方 2025-10-02 的公告说开放全球免费下载。

## 二、Opera Neon

官方页面的描述：Neon 是「为行动而生」的浏览器，它处理你的任务、理解网页、管理标签页、按你的指令行动。官方说里面有不同分工的 agent：有的帮你拟一个会议议程，有的去浏览网页，有的做深度研究或生成文档；你也可以通过 MCP 和 CLI 把自己的 agent 连进 Neon。

上手三步（官方写法）：下载并登录；已经在用 agent 的话，通过 MCP 或 CLI 连接；订阅 Neon，激活 agent 功能和各家顶级大模型，官方页写明是 **19.90 美元/月**。Neon 由 Opera 出品，官方说 2025-09-30 发布。

## 三、Dia

Dia 是 The Browser Company of New York 做的浏览器，官方页写着「免费下载，支持 macOS 和 Windows」。官方介绍的重点是它能在你的标签页和工具之间读取上下文：早间简报（日历、邮件、关键链接）、汇总 Slack、Notion、Teams 等工具里的内容、给标签页分组命名、分屏、从上下文生成幻灯片等。隐私设置里可以控制是否记忆偏好、是否分享内容数据；官方说你的数据不会被出售或用于建立广告画像，开启同步时端到端加密。

## 四、Brave Leo

- 在 Brave 浏览器的地址栏输入后选「Ask Leo」，或点工具栏的 Leo 图标；
- 官方说可以和任意标签页聊天：总结网页、生成内容、翻译、分析文本，还能分析 PDF、Google Docs 和 Sheets；
- **隐私**：官方说 Leo 不保留或共享聊天，也不用聊天来训练模型，**不需要账号或登录**；
- **自带模型**：可以运行你自己的本地或远程模型；
- **平台**：Brave 的桌面版（macOS、Windows、Linux）和手机版（Android、iOS）；
- **价格**：Leo 免费可用，也有付费的 Premium，可用更多模型、速度更快。

## 五、Edge 里的 Copilot

Microsoft 官方页说，Copilot 内置在 Edge 里，有两种入口：点窗口右上角图标打开的 Copilot 侧栏（总结、对比、不离开页面直接问），和 Copilot 新标签页（输入问题、搜索或网址，由 Copilot 路由）。官方介绍的功能有：用你的标签页做对比和总结、Journeys（把相关页面、搜索和聊天按主题归组）、Copilot 连接器、写作辅助、图像生成。页面没有写单独的价格，高级额度和 Microsoft 365 相关，见官方页。

## 七、用 AI 浏览器前要注意的

![AI 浏览器怎么选](seed:g948-ai-browsers-decide.png)
*图：本站根据上述各产品官方页面整理的示意图*

1. **账号和数据**：这类浏览器会读你的标签页、历史、邮箱日历，登录和授权前看清楚它读什么、存在哪；
2. **让 AI 代你操作网页要谨慎**：官方在 Claude in Chrome 的说明里提醒，网页里藏的指令可能诱导 AI 做你没让它做的事，涉及付款、账号和敏感资料的页面，别让 AI 自动操作；
3. **先试免费部分**：Comet、Dia 官方页都是免费下载，Leo 免费，Neon 的 agent 功能要订阅；
4. **别在来路不明的安装包上装**：只用官方域名下载。

## 常见问题

**Q：Comet 免费吗？**
官方 2025-10-02 的公告说免费向全球开放下载；高级功能（比如邮件助手）面向订阅用户，以官方页面为准。

**Q：Comet 和 Chrome 能共用扩展吗？**
官方帮助中心说，Comet 支持大多数 Chrome 扩展，并可以一键导入 Chrome 的书签、密码、扩展和历史。

**Q：哪个最好？**
官方页面不会给出这样的结论，本文也不排名；按你的系统、预算和隐私要求，对照官方页面选。
