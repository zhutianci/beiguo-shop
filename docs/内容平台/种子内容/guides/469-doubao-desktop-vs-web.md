## 结论先说

1. **官方入口**：网页版是 doubao.com/chat，电脑版在 doubao.com/download/desktop 下载，运营方是北京春田知韵科技有限公司（字节跳动旗下）。不要从来路不明的下载站装。
2. **只是聊天、查资料、生成图片：网页版就够了**，不用安装。
3. **电脑版多出来的是「操作本机」的能力**：官网介绍的「工作」模式可以在本地电脑上协助处理事务、操作电脑与浏览器，这类事只有装了客户端才做得了。
4. **部分能力属于付费订阅**。App Store 页面列出了订阅套餐，官网下载页也写着限时领取订阅权益的活动；具体权益和价格以官方购买页为准。

## 网页版和电脑版的区别

| | 网页版 | 电脑版（桌面客户端） |
| --- | --- | --- |
| 入口 | 浏览器打开 doubao.com/chat | 官网下载安装 |
| 安装 | 不需要 | 需要 |
| 对话、写作、生图等基础功能 | 有 | 有 |
| 操作本地电脑与浏览器 | 浏览器环境受限 | 官网介绍的重点能力 |
| 适合 | 临时用、公司电脑不便装软件 | 天天用、想让它处理本机文件和多步骤任务 |

官网下载页对电脑版的描述是让 AI 从「问答助手」变成「干活搭子」，列出的能力包括：

- **交付成品**：从一个想法出发写文档、做表格、做 PPT、生成图片、制作视频、搭网页；
- **操作电脑与浏览器**：在不影响你正常使用电脑的情况下操作虚拟桌面完成任务，过程可以实时查看，也可以随时暂停或接管；
- **AI 编辑**：在文档、PPT、网页里选中想改的位置，让它只改那一处；
- **接入飞书**：基于飞书里的会议结论、群聊、文档来完成总结和方案（面向企业场景）。

## 步骤

### 1. 先用网页版熟悉一遍

浏览器打开 doubao.com/chat。不登录也能看到首页，但发送消息或点任何功能都会要求登录。核对时的登录方式有：手机号登录、飞书账号一键登录、抖音一键登录，以及用豆包或飞书 App 扫码登录。

页面上的几个区域：

- **左侧栏**：「新工作任务」「新对话」和历史记录；「更多」里还有「AI 创作」等入口；
- **中间的「对话 / 工作」切换**：对话是一问一答；工作是把一件事交给它分步完成；
- **输入框下方的技能入口**：PPT 生成、图像生成、帮我写作、视频生成、录音转写、音乐生成，以及「更多」；
- **输入框右侧**：模型 / 模式选择（核对时默认显示「豆包 快速」）和语音输入按钮。

### 2. 下载并安装电脑版

1. 打开 doubao.com/download/desktop，点「下载豆包桌面版」；
2. 运行安装包，按提示完成安装；
3. 用和网页版相同的账号登录，历史对话会跟着账号走。

网页版右上角也有「下载电脑版」的按钮，指向同一个官方下载页。

### 3. 「对话」里把话说具体

日常提问直接在「对话」里发。想让结果可用，说清三件事：给谁看、要什么形式、有什么限制。

```
帮我写一份给部门同事的通知：下周三下午 2 点到 4 点系统升级，期间无法提交报销。
语气正式但不生硬，不超过 150 字，最后提醒大家提前提交。
```

需要特定产出时先点对应的技能入口再描述需求，例如点「PPT 生成」后输入主题和页数，点「帮我写作」后选文体。

### 4. 用「工作」模式交办多步骤任务

「工作」适合「目标明确、步骤多」的事，比如「把这个文件夹里的 12 份周报汇总成一张表，再写一页总结」。交办时建议写清：

```
目标：把桌面「周报」文件夹里的周报汇总成一份月度总结。
材料：文件夹里的 12 个 Word 文件。
要求：按项目归类，每个项目列进展、风险、下月计划；输出一份 Word 和一张汇总表。
注意：不要修改原文件；遇到看不懂的缩写先列出来问我。
```

官网说明操作过程可以实时查看，需要时可以暂停或接管。**让 AI 操作本机时，建议先在不重要的文件上试**，涉及删除、发送、付款这类不可撤销的动作，自己确认后再执行。

### 5. 订阅信息去哪看

App Store 页面（2026-10-11 核对）显示豆包 App 本身免费、含 App 内购买，内购项目里有按月和按年的订阅套餐以及创作额度包，例如其中的标准套餐连续包月标价为 68 元。不同档位的权益、电脑版与手机端是否通用、活动赠送的订阅时长，都以豆包官方的订阅页面和购买时的说明为准，本文不逐项列出。

## 常见问题

**Q：豆包电脑版支持 Mac 吗？**
下载页会按你当前的系统显示下载按钮（核对时在 Windows 电脑上显示的是 Windows 版）。Mac 版是否提供，以你在 Mac 上打开官方下载页看到的为准。

**Q：电脑版和手机 App 的记录互通吗？**
用同一个账号登录即可同步对话记录。本机文件类的工作任务产物保存在电脑上。

**Q：公司电脑不让装软件怎么办？**
直接用网页版。需要操作本机文件的任务，把文件上传到对话里处理。

**Q：豆包网页版怎么删除对话？**
登录后在左侧历史记录里对某条对话打开菜单进行删除，以实际界面为准。

**Q：以前的「智能体」入口找不到了？**
豆包的产品形态调整较多，核对时网页版首页以「对话 / 工作」和技能入口为主。某项功能是否保留，以官方公告和当前界面为准。
