## 适用于谁

- 搜「扣子怎么用」「扣子怎么创建智能体」「扣子怎么创建 bot」「扣子智能体搭建」的人；
- 照着旧教程找「人设与回复逻辑」页面，却发现打开的是「扣子编程」、界面完全对不上的新用户；
- 已经有低代码智能体、想知道旧入口还在不在的老用户。

本文根据扣子官方文档（docs.coze.cn）和扣子编程首页整理，资料核对于 2026-10-11。两套平台登录后的界面都没有逐屏核对，按钮名称来自官方文档，以实际界面为准。

## 结论先说

1. **扣子现在是三块**：扣子（coze.cn，和 Agent 协作办公）、扣子编程（code.coze.cn，用对话开发智能体、工作流和应用）、扣子开发平台（低代码，旧版）。
2. **低代码平台不再向新注册用户开放**。官方文档的原话是由于产品方向调整；开发智能体、工作流、应用请去扣子编程，只想使用 Agent 去扣子。
3. **新用户的做法**：扣子编程首页点「智能体」，用一段话描述需求，AI 会设计、写代码、自测，几分钟后在右侧预览里直接对话。
4. **老用户的做法**：扣子编程首页右上角「回到旧版」，创建智能体后在编排页写「人设与回复逻辑」、加技能、右侧调试。
5. **人设提示词的官方示例结构是三段**：角色、技能、限制。

## 步骤

### 1. 先确定自己该走哪条路

| 你的情况 | 去哪里 |
| --- | --- |
| 新注册，想做一个自己的智能体 | 扣子编程 code.coze.cn |
| 以前在扣子开发平台做过智能体 | 扣子编程首页右上角「回到旧版」 |
| 不想开发，只想用现成的 Agent 干活 | 扣子 coze.cn |

网上大量教程讲的是拖拽式的低代码做法。官方文档把它定位为扣子编程较早期的版本，按文档的说法，新注册用户已经用不了。照旧教程找不到入口，不是你操作错了。

### 2. 新用户：在扣子编程里生成智能体

1. 打开 code.coze.cn 并登录，在首页输入框上方点「智能体」；
2. 在文本框里写需求。官方建议尽量写清功能、业务逻辑和约束；
3. 按需设置：上传附件、选择协作模式、添加技能、选择编程模型。默认是 Agent 模式；需求还没想清楚时，可以先切到问答模式和它讨论方案；
4. 提交。AI 会设计智能体、创建项目并自动命名，官方说通常需要几分钟，完成后给出一份开发完成总结。

需求可以这样写：

```
做一个「合同初审助手」智能体。
用户：公司法务以外的业务同事。
功能：用户粘贴或上传一份采购合同，助手逐条检查付款条件、违约责任、
争议解决、保密条款是否缺失或明显不利于采购方，并用表格列出风险和修改建议。
约束：只做初步提示，每次回复末尾提醒「以法务意见为准」；
不回答与合同无关的问题；不编造法律条文编号。
```

官方文档提到扣子编程已接入 Doubao、GLM、Kimi、DeepSeek 等编程模型，系统会自动选择，也可以自己选。

### 3. 预览、修改和回滚

- **预览**：AI 会自动生成测试用例并跑一轮测试。之后在右侧「预览」里像普通用户一样和智能体对话；
- **出错**：点「一键修复」，或把报错信息粘到左侧对话里让它修；
- **改需求**：直接在左侧对话框用自然语言说要改什么；
- **改系统提示词**：在预览窗口点模型名称，右侧会出现「系统 Prompt」文本框，改完重新测试；
- **换模型和参数**：同一位置可以切换模型，并调整随机性、Top P、最大回复长度等；
- **回滚**：点「版本历史」，在目标版本右侧点回滚。

要接数据库、对象存储或飞书消息这类能力，官方的做法是先在对话区的「技能」里确认相应技能已添加，再用自然语言描述需求。

确认没问题后点「部署」，智能体会成为一个可通过 API 调用的服务，部署成功后可以用右上角「分享」发给别人。

### 4. 老用户：在旧版里创建低代码智能体

1. 登录扣子开发平台，或在扣子编程首页右上角点「回到旧版」；
2. 页面顶部选好工作空间，左侧导航点「创建」再点「创建智能体」；
3. 填名称和功能介绍，图标可以点「生成」自动出一个；也可以切到「AI 创建」，用自然语言描述让它代填；
4. 确认后进入编排页面：左边「人设与回复逻辑」，中间「技能」，右边「预览与调试」。

### 5. 写人设与回复逻辑

官方对这一栏的说明是：它会持续影响智能体在所有会话里的回复，建议写清模型的角色、回复的语言风格、回答范围的限制。写完可以点自动优化，让模型把它整理成结构化的格式。

官方示例用的是「角色 / 技能 / 限制」三段，照这个骨架填即可：

```
# 角色
你是一家宠物用品店的售前顾问，语气亲切、回答简短。

## 技能
### 技能 1：推荐商品
先问清宠物种类、年龄和预算，再从知识库里挑不超过 3 件商品，说明理由。
### 技能 2：解答喂养问题
用知识库里的内容回答；知识库没有的，明确说不确定并建议咨询兽医。

## 限制
- 只回答宠物用品和日常喂养相关的问题
- 不给出疾病诊断和用药建议
- 不承诺价格和库存，以店铺页面为准
```

### 6. 加插件和知识库

**插件**：在「技能」区域点「插件」旁的加号，搜索并添加。官方特别提醒，添加后要在人设与回复逻辑里引用这个插件（在合适的位置输入 `{` 选择插件），否则智能体可能不会按预期调用。文本模型本身读不了 PPT、图片这类内容，需要绑定相应的多模态插件。

**知识库**：在编排页面的「知识」区域点加号，添加事先建好的知识库。官方文档写明的要点：

- 扣子知识库有文本、表格、照片三种；数据可以来自本地文档、在线数据、Notion、飞书文档等；
- 单个低代码智能体最多绑定 150 个知识库；
- **调用方式**二选一：自动调用是每轮对话都检索；按需调用是让模型自己判断，这时要在人设里写清什么情况下查哪个知识库；
- **检索设置**：搜索策略有混合、语义、全文三种，专有名词、缩写、编号这类关键词用全文更合适；还可以调最大召回数量和最小匹配度；
- **无召回回复**：没检索到内容时说什么，可以自定义；
- **显示来源**：把引用的原文片段展示给用户，默认关闭。

此外还可以配置开场白、用户问题建议、快捷指令、背景图片和语音。

### 7. 调试和发布

在右侧「预览与调试」里把你能想到的问法都试一遍，重点试三类：范围内的正常问题、范围外的问题（看它是否按限制拒绝）、需要查知识库或调插件的问题。

满意后点右上角「发布」，填发布记录、选发布渠道。各渠道的条件和审核见《扣子智能体怎么发布》；想把固定流程做成工作流，见《扣子工作流怎么搭建》。

## 常见问题

**Q：新注册的账号找不到「创建智能体」的低代码页面？**
官方文档已说明扣子开发平台（低代码）不再向新注册用户开放。新用户请用扣子编程的「智能体」入口。

**Q：扣子编程里做智能体要钱吗？**
官方文档写明会消耗积分的操作有三类：编程任务（每轮对话）、内置集成（大模型、联网搜索、图像生成等）、部署上线后的服务托管。各套餐送多少积分、怎么计费，以官网的订阅套餐和定价页面为准。

**Q：加了插件但智能体不调用？**
先检查人设与回复逻辑里有没有引用这个插件，并写清什么情况下用它。

**Q：知识库里明明有，却答不出来？**
官方给的排查方向：检查知识库的名称和描述是否清楚、人设里的调用条件是否写明；按需调用召回不到时，建议改成自动调用。

**Q：单 Agent 不够用怎么办？**
旧版低代码默认是单 Agent 模式，官方文档说明任务复杂时可以切换到多 Agent 模式，给不同的 Agent 配不同的提示词，把任务拆开。

**Q：想让智能体定时做事？**
旧版低代码里有「触发器」，可以在指定时间或事件发生时自动执行任务。按官方的渠道能力对比，触发器只在飞书渠道可用。
