## 适用于谁

- 搜「扣子 发布」「扣子发布到豆包」「扣子智能体 api」「扣子智能体商店」的人；
- 智能体已经调试好，想让同事在飞书里用、让粉丝在公众号里用，或接进自己系统的人；
- 发布后一直显示「审核中」，想知道要等多久的人。

本文根据扣子官方文档（docs.coze.cn）「发布」一栏的文章整理，资料核对于 2026-10-11。发布页面登录后才能看到，实际可选的平台列表以你账号里显示的为准。

## 结论先说

1. **官方默认渠道**：扣子商店、飞书（含飞书多维表格）、微信（客服、服务号、订阅号）、小程序（抖音、微信）、API、Chat SDK。文档里掘金标注为暂不支持，模板渠道暂未对智能体开放。
2. **发布要过三步**：打包 → 扣子平台审核 → 渠道审核。任何一步没过都要改完重新提交。
3. **首次发布到小程序、微信订阅号、微信客服、飞书多维表格需要人工审核**，官方说通常 1–7 个工作日。
4. **不同渠道能用的功能不一样**：比如微信渠道不支持流式输出，触发器只在飞书可用。
5. **以上说的是旧版低代码智能体**。在扣子编程里做的智能体，对应的动作是「部署」成 API 服务再分享。

## 步骤

### 1. 先看自己的智能体属于哪一种

- **旧版低代码智能体**（在扣子开发平台里用「人设与回复逻辑」搭的）：走本文第 2–6 步的「发布」；
- **扣子编程里生成的智能体**：点右上角「部署」，它会成为可访问的 API 服务，通过 OpenAPI 集成到你的应用；部署成功后右上角有「分享」按钮。官方的开发智能体文档里没有列出飞书、微信这类渠道。

官方文档已说明低代码平台不再向新注册用户开放，新用户看到的会是第二种。两种智能体怎么建，见《扣子怎么创建智能体》。

### 2. 通用发布步骤（旧版低代码）

1. 登录扣子开发平台（或在扣子编程首页右上角点「回到旧版」），页面顶部选好工作空间；
2. 在「项目开发」页面打开要发布的智能体，进入编排页；
3. 点右上角「发布」，填写发布记录（这次改了什么）；
4. 在「选择发布平台」里勾选渠道。有的渠道要先点「配置」完成授权；
5. 点「发布」。结果和历史版本在编排页右上角的「发布历史」里看。

官方把之后的过程分成三段：**打包**（把智能体用到的工作流等资源打在一起）、**扣子审核**（按平台的内容发布标准）、**渠道审核与发布**（各渠道标准和时效不同）。

### 3. 发布到飞书

1. 在发布页勾选「飞书」，首次发布按引导完成授权；
2. 点「发布」；
3. 如果你所在的飞书企业是第一次发布扣子智能体，你会收到飞书消息提醒：显示审核通过就能直接用，否则要等企业管理员审核。

让同事也能用，有两种官方办法，都只限同一个飞书企业内：

- 在飞书里点智能体头像再点分享，对方点链接申请，你通过后即可使用；
- 登录飞书开发者后台，进入这个智能体应用的「版本管理与发布」，创建版本，在「可用范围配置」里添加人员，然后申请上线。

官方提示的两个坑：回复里带邮箱、电话这类隐私信息时，飞书可能拦截消息，表现为一直显示正在回复，建议在提示词里约束智能体不输出这类信息；飞书里的回答和在扣子里调试时不一致，可以先输入 `/clear` 清掉历史消息再试。

### 4. 发布到微信订阅号

前提是你已经有一个微信订阅号。

1. 登录微信开发者平台，在「我的业务」的公众号页面找到开发者 ID（AppID）；
2. 回到扣子的发布页，找到「微信公众号（订阅号）」，点「配置」，填入 AppID 并保存；
3. 页面跳到公众平台账号授权，用公众号管理员的个人微信扫码，在手机上选择这个订阅号并确认授权；
4. 回到发布页，勾选该渠道，填发布记录，点「发布」。

官方写明的限制：

- 一个智能体只能发布到一个微信订阅号；
- 首次发布显示「审核中」，通常 1–7 个工作日；
- 从用户发消息到回复完成超过 15 秒，用户会收到让他回复「继续」的提示。所以要在提示词里控制回复长度；
- 每次回复只能带一张图片，且不超过 10 MB；文字和图片同时出现时图片会变成链接。

服务号、微信客服各有单独的渠道和文档，注意别把服务号绑到订阅号渠道上——官方列出的常见报错之一就是公众号类型选错。扫码时提示缺少必须权限，重新扫码并勾选全部权限。

### 5. 发布为 API

1. 先创建个人访问令牌（官方要求发布前必须先有）；
2. 发布页的「选择发布平台」里选「API」，点「发布」；
3. 之后用 OpenAPI 的方式调用智能体。鉴权方式和接口说明在官方的 API 文档里。

要嵌到自己的网页上，用 Chat SDK 渠道，它会以网页悬浮窗的形式提供对话。

### 6. 发布前对照一遍渠道差异

按官方的《发布渠道能力差异》：

| 能力 | 不支持的渠道 |
| --- | --- |
| 上传文件 | 微信 |
| 流式输出 | 微信、飞书多维表格、掘金 |
| 语音输出、语音通话 | 微信、飞书、飞书多维表格、掘金、小程序 |
| 用户问题建议 | 微信、飞书多维表格、掘金 |
| 触发器 | 只有飞书支持 |
| 卡片效果 | 智能体发布到 Chat SDK、小程序、微信、飞书、多维表格、掘金时均不支持 |

上传图片、快捷指令、清除上下文各渠道都支持。另外，工作流里用输出节点提前发消息的做法，在微信服务号、订阅号、客服里不生效，只会汇总后一次性输出。

如果你的智能体依赖卡片或流式输出，发到微信之前要先改成纯文本也能用的形式。

### 7. 更新、解绑和下架

- **更新**：改完智能体后再点一次「发布」；
- **暂停某个渠道**：在发布页该渠道右侧解绑；
- **下架**：官方另有「下架智能体」文档；飞书渠道也可以在飞书开放平台删除对应的应用。

## 常见问题

**Q：扣子智能体能发布到豆包吗？**
官方的低代码快速开始文档在讲发布时写到「支持飞书、微信、抖音、豆包等渠道」，但核对时「发布」一栏的渠道文档里没有豆包的专门文章，渠道总览表里也没有单列。能不能发、有什么条件，以你发布页面里实际显示的平台列表为准。

**Q：审核要多久，哪些渠道要审核？**
官方的发布常见问题写明：智能体首次发布到抖音小程序、微信小程序、微信订阅号、微信客服或飞书多维表格时需要审核，人工处理，通常 1–7 个工作日，结果在发布历史或发布页面查看。

**Q：抖音企业号渠道找不到了？**
官方说明该渠道已于 2025 年 3 月 13 日下线。

**Q：只想让指定的人用，不公开？**
官方给了两个办法：发布到飞书，只允许组织内成员访问；或发布为 API，在自己的系统里做访问控制。

**Q：能把智能体发布成模板吗？**
暂不支持，目前只有应用可以发布为模板。

**Q：能发到手机厂商的智能体平台吗？**
官方文档的「发布到公共渠道」里有小米、OPPO、vivo、荣耀、联想、中兴等渠道的文章。这类属于公共渠道，需要先在工作空间的发布渠道管理里开启，具体条件看对应文档。

**Q：审核方要算法备案材料怎么办？**
官方的说法是可以在火山引擎控制台的合同管理页面申请带备案号的合同，有前提条件；使用 DeepSeek 等第三方模型需要自行处理备案。发布对外服务时也要留意《AI生成内容标识规定》里的标识要求。
