> 本文根据 OpenAI 帮助中心《What is ChatGPT: FAQ》《ChatGPT capabilities overview》《Does ChatGPT tell the truth?》《What is ChatGPT?》整理，资料核对于 2026-10-14。这几篇官方文章没有配界面截图，文中配图为本站整理的示意图。

## 适用于谁

- 刚听说 ChatGPT，想弄清楚它到底是什么的人；
- 搜「ChatGPT 是什么」「ChatGPT 是哪家公司的」「ChatGPT 能干什么」的人；
- 在犹豫要不要用、担心它「靠不靠谱」的人。

第一次打开该点哪里，见 [/guides/chatgpt-how-to-use-beginner](/guides/chatgpt-how-to-use-beginner)；这篇先回答「它是什么」。

## 结论先说

1. **它是一个 AI 助手**。官方的定义是：可以用在日常任务上的 AI 助手，包括头脑风暴、写作、学习、规划、数学、编程、分析图片和文件等等，被训练成能在对话里**照你的指令做事**。
2. **是 OpenAI 的产品**。你访问的官方帮助中心是 help.openai.com，里面的隐私政策、使用政策都是 OpenAI 的。
3. **怎么用**：网页 chatgpt.com（官方说在支持的地区甚至可以不注册账号试用），以及 iOS 和安卓 App，还有桌面 App。
4. **怎么开始**：打开 ChatGPT，在输入框里写你要的，发送；随时可以点 **New chat** 开新对话。
5. **它会出错**。官方的原话是：ChatGPT 很有用，但并不总是对的；有时听起来很自信，却是错的。重要信息一定要去可靠来源核对。
6. **免费可以用**，有基本限额；付费套餐（Plus、Pro 等）有更新的模型、更高的限额和更多工具。开通见 [/chongzhi/chatgpt-plus](/chongzhi/chatgpt-plus)。

## 它不能干什么：用之前要知道的

官方《Does ChatGPT tell the truth?》说得很清楚：

- **可能编造**：包括不对的定义、日期和事实，编造引用、研究和不存在的来源，对含糊或复杂的问题过度自信；
- **有知识截止**：模型只用到某个时间点的数据训练，不开工具时回答不包含之后的事件；
- **信心不等于可靠**；
- **可能读不到某些网页**：技术问题、付费墙或网站的爬虫设置都可能让它拿不到信息；
- **可能有偏见或过度简化**：把一种观点当成绝对真理，简化复杂问题。

官方给的使用建议：

1. 把 ChatGPT 当**初稿**，不要当最终来源；
2. 引用、数据、技术信息、对外部文档的引用，一定要核对；
3. 对准确性要求高时，用搜索或 Deep research，并点开来源链接自己看；
4. 在教育场景里，多鼓励批判性思考。

## 隐私：谁看得到我的对话

- 官方说，使用面向个人的服务时，OpenAI 可能用你的内容训练模型；你可以在数据控制里关闭，关闭后新对话不再用于训练。设置见 [/guides/chatgpt-data-controls-privacy](/guides/chatgpt-data-controls-privacy)。
- **临时聊天（Temporary Chat）**：不出现在历史里、不使用也不产生记忆、不用于训练，需要额外隐私时在模型菜单里开启，见 [/guides/chatgpt-temporary-chat](/guides/chatgpt-temporary-chat)。
- 官方还特别说：**无法从历史中单独删除某一条提示**，所以请不要在对话里分享敏感信息。
- 想导出或注销：**Settings → Data Controls → Export**；注销账号可在 Settings 里或通过 Privacy Portal，且删除是永久的。见 [/guides/chatgpt-export-chat-history](/guides/chatgpt-export-chat-history) 和 [/guides/chatgpt-delete-account](/guides/chatgpt-delete-account)。
- 官方《What is ChatGPT?》写明：在遵守内容政策和条款的前提下，你拥有你用 ChatGPT 生成的输出，包括转载、出售和商品化的权利，不管是免费还是付费方案。

## 常见问题

**Q：ChatGPT 和 OpenAI 是什么关系？**
ChatGPT 是 OpenAI 的产品。如果你想用 API 开发应用，那是另一套东西，官方帮助中心里有单独的 API 文章，见 [/guides/openai-api-key](/guides/openai-api-key)。

**Q：ChatGPT 能联网吗？**
能。官方说 ChatGPT 需要最新信息时可以搜索网页并引用来源；也可以点搜索图标，或在支持的界面里用 `/Search`。注意：不开搜索时，回答基于训练数据。

**Q：免费版够用吗？**
官方说 Free 提供核心的 ChatGPT 功能和基本限额。额度会随时间调整，具体看 [/guides/chatgpt-free-plan-limits](/guides/chatgpt-free-plan-limits)。

**Q：ChatGPT 生成的图片怎么标识是 AI 做的？**
官方《What is ChatGPT: FAQ》说，ChatGPT 生成的图片包含 C2PA 来源元数据（内容凭证）。

**Q：我问了一个问题，答案是错的怎么办？**
官方在《What is ChatGPT?》里建议：发现答案不对，用回答下面的「踩（Thumbs Down）」按钮反馈；同时核对重要信息。
