> 本文是一套工作流程，产品功能部分依据 OpenAI 与 Anthropic 官方帮助中心（项目、定时任务、数据控制），资料核对于 2026-10-11。提示词可以直接复制后按自己的岗位修改。

## 适用于谁

- 每周五对着空白文档想不起这周干了什么的人；
- 搜「ai 写周报」「ai 写月报」的人；
- 让 AI 写过周报，结果全是「积极推进」「持续优化」这类空话的人。

## 结论先说

1. **AI 写不出你没告诉它的事**。周报空洞的原因几乎都是素材太少：只给一句「帮我写周报」，它只能编套话。
2. 所以流程的重心在**平时记**：每天花一分钟往同一个地方丢几行流水账，周五让 AI 整理。
3. 用**项目**（ChatGPT 项目 / Claude Projects）把周报模板、岗位背景、历史周报放在一起，每周不用重新交代。
4. 生成后必须自己改三样：**数字、结论、下周计划**。
5. 工作内容可能涉及公司信息：先看公司规定，关掉「用于改进模型」的开关，客户名称和金额该脱敏就脱敏。

## 第一步：建一个「周报」项目（只做一次）

**ChatGPT**：新建一个项目。官方对项目的定义是一个文件夹 + 一份专属说明 + 一块共享上下文，同一项目里的对话共享你上传的文件和写好的说明。见[《ChatGPT 项目功能怎么用》](/guides/chatgpt-projects)。

**Claude**：新建一个 Project，把模板放进项目知识库、把要求写进项目指令。注意官方说明：同一项目里的对话之间默认不共享上下文，要让每次对话都知道的东西必须放进知识库或项目指令。见[《Claude Projects 怎么用》](/guides/claude-projects-guide)。

在项目说明 / 项目指令里写上（按自己的情况改）：

```text
你帮我写工作周报。背景：
- 我的岗位：[岗位]，所在团队：[团队]，汇报对象：[上级的角色]
- 上级最关心：[例如 项目进度是否按期、风险、需要他协调的事]
- 本季度我的重点目标：[目标 1]、[目标 2]

写作要求：
- 只使用我提供的素材，不要补充我没说过的工作、数字和结论
- 素材里缺信息的地方，用「【待补：……】」标出来，不要自己编
- 每条写「做了什么 → 结果或进展 → 对目标的意义」，不用空泛的形容词
- 语气平实，总长控制在 400 字以内
```

再上传一份你们公司的周报模板或一篇你满意的旧周报当格式参考。

## 第二步：平时攒素材（每天一分钟）

在这个项目里开一个对话专门当流水账，随手发：

```text
周二：和设计对齐了会员页改版方案，定了周五出高保真；
线上订单导出的 bug 修了，原因是时区；
客户 A 提了批量开票的需求，还没排期。
```

不用成句，不用分类。也可以记在备忘录、日历或任务工具里，周五一起贴过来。手机上用语音输入更快。

## 第三步：周五生成

把本周的流水账、日历里的会议、完成的任务清单贴进去：

```text
以下是我本周的工作记录：
[粘贴流水账]

请按项目里的模板生成周报，分成：
一、本周完成（按重点目标归类，和目标无关的放「其他」）
二、进行中与进度（写明完成到哪一步、预计何时完成）
三、问题与风险（每条写清影响和我需要的支持）
四、下周计划（3–5 条，按优先级）
缺少数据或结果的地方用【待补】标出。
```

示例输出节选（示例，仅供参考）：

```text
一、本周完成
【会员体系改版】与设计确认改版方案，高保真稿定于周五交付【待补：是否已交付】。
【稳定性】修复订单导出时间错位问题（原因：时区处理），已上线。

三、问题与风险
客户 A 提出批量开票需求，尚未排期。影响：【待补：客户期望时间】。
需要支持：请确认是否纳入本月迭代。
```

## 第四步：自己改三样

1. **补【待补】**。数字、日期、是否完成，以你手里的真实情况为准。
2. **检查它有没有「润色过头」**。把「修了个 bug」写成「显著提升系统稳定性」这类拔高要改回去。AI 可能给出看似可信但不准确的表述，这是官方自己提醒的。
3. **下周计划你来定**。它只能从素材里推测，优先级是你的判断。

然后可以让它换个角度再过一遍：

```text
假设你是我的上级，读完这份周报最想追问的 3 个问题是什么？我应该在周报里提前回答哪些？
```

## 第五步：月报从周报汇总

月底把四份周报贴进同一个对话（或放进项目文件里）：

```text
以下是本月的四份周报：
[粘贴]

请汇总成月报：
1. 本月关键成果（不超过 5 条，每条带结果数据；周报里没有数据的标【待补】）
2. 各重点目标的进度：月初状态 → 月末状态
3. 反复出现的问题（在两份以上周报里出现过的）及我的应对
4. 下月重点
不要逐周罗列，要合并同类项。
```

月报的价值在「合并」和「趋势」，这正是 AI 擅长的整理工作；而成果的轻重判断仍然要你来把关。

## 第六步：设一个每周提醒（可选）

ChatGPT 的定时任务可以直接用一句话创建，例如对它说「每周五下午 4 点提醒我写周报，并列出本周我在这个项目里记录的内容」，也可以在侧边栏的 Scheduled 页面管理。官方说明任务数量和频率按套餐不同，并且要在 Settings → Notifications 里打开通知，否则任务跑完你可能不知道。见[《ChatGPT 定时任务怎么设置》](/guides/chatgpt-scheduled-tasks)。

## 隐私与公司规定

- **先看公司制度**。有的公司禁止把内部信息输入外部 AI 工具，有的提供了企业版。
- **关训练开关**。ChatGPT：Settings → Data controls 里关闭「为所有人改进模型」，见[《ChatGPT 隐私设置》](/guides/chatgpt-data-controls-privacy)；Claude：Settings → Privacy，见[《Claude 隐私设置》](/guides/claude-privacy-delete-account)。企业版和团队版的内容默认不用于训练。
- **脱敏**。客户名称、合同金额、未公开的数据，用「客户 A」「某金额」代替，生成后再填回去。
- 更完整的清单见[《AI 使用隐私与数据安全清单》](/guides/ai-privacy-data-safety-checklist)。

## 常见问题

**Q：这周真没干什么大事，怎么写？**
如实写小事，按「做了什么 → 结果」写清楚，比编出来的大词有说服力。可以让 AI 帮你把零散的支持性工作归类，但不要让它虚构成果。

**Q：能让它直接读我的日历、邮件、任务工具吗？**
ChatGPT 和 Claude 都有连接器功能，可以连接部分日历、邮箱和办公工具，见[《ChatGPT 连接器怎么用》](/guides/chatgpt-plugins-connected-apps)和[《Claude Connectors 怎么用》](/guides/claude-connectors)。连接前同样先确认公司是否允许。

**Q：有现成的周报提示词吗？**
本站[提示词库](/prompts)的「职场办公」分类里有按岗位区分的周报、月报、述职模板。
