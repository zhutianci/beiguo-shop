## 适用于谁

- 搜「豆包生图怎么用」「豆包生图提示词」「豆包生图指令」「豆包图生图怎么用」「豆包p图指令」的人；
- 用豆包出过图，但总是「差一点」——文字乱、改图把别的地方也改了、系列图风格不统一的人。

本文根据豆包官网页面和火山引擎 Seedream 官方提示词指南整理，资料核对于 2026-10-11。提示词写法来自模型官方指南，对豆包里的图像生成同样适用；入口名称以实际界面为准。

## 结论先说

1. **入口**：网页版和电脑版在输入框下方点「图像生成」；手机 App 里也可以直接在对话中说「帮我画……」，或使用「豆包 P 图」相关功能（以 App 实际界面为准）。
2. **背后是字节跳动的 Seedream 系列生图模型**。豆包官网下载页提到客户端「依托专业版 Seedream 5.0 生图」。
3. **提示词用连贯的自然语言写「主体 + 行为 + 环境」**，比堆一串关键词效果好——这是官方指南的第一条建议。
4. **要出现在图里的文字放进双引号**；改图时写清「改什么 + 什么保持不变」。
5. **次数和额度官方没有公布固定数字**，以 App 内显示为准；生成的图片带有 AI 生成标识，本文不提供去除标识的方法。

## 步骤

### 1. 找到入口，先出一张

1. 打开 doubao.com/chat 登录，点输入框下方的 **图像生成**；
2. 输入描述，选择比例等参数（可选项以界面为准）；
3. 发送，等待出图；不满意就在同一个对话里继续说怎么改。

### 2. 文生图：一句完整的话胜过一串词

官方指南给的对比很直观：

- 推荐：`一个穿着华丽服装的女孩，撑着遮阳伞走在林荫道上，莫奈油画风格。`
- 不推荐：`一个女孩，撑伞，林荫街道，油画般的细腻笔触。`

可以套这个结构：

```
[主体是谁 / 是什么] + [在做什么] + [在什么环境里]，
[风格]，[色彩 / 光线]，[构图 / 画幅]
```

例如：

```
一只柴犬戴着黄色安全帽坐在工地的木箱上啃骨头，背景是傍晚的脚手架和夕阳，
写实摄影风格，暖色逆光，浅景深，竖版构图
```

官方还提醒两点：新版模型理解能力强，**简洁精确的描述通常优于重复堆叠华丽辞藻**；有明确用途时把用途写出来，比如「设计一个游戏公司的 logo」「做一张小红书封面」，模型会按该类型的常见版式来出。

### 3. 图里要有字：放进双引号

```
生成一张咖啡店开业海报，标题为"周末见"，副标题为"全场第二杯半价"，
手绘插画风格，奶油色背景
```

官方指南明确建议把要生成的文字内容放在双引号里，可以提高文字渲染的准确度。字越少越稳；出现错字时把那行字单独再强调一次重新生成。

### 4. 改图：说清改哪里、哪里不变

上传一张图（或直接对刚生成的图）下指令。官方把改图分成增加、删除、替换、修改四类，写法都是「简洁明确地指出对象 + 变化」：

- 增加：`给图中女生增加银色耳线和项链`
- 删除：`去掉女生的帽子`
- 替换：`把最大的那个面包人换成牛角包形象，保持动作和表情不变`
- 修改：`把三个机器人改成透明水晶材质，颜色从左到右分别为红、黄、绿`

两条关键规则：

- **不要用「它」「这个」这类指代模糊的词**。官方的例子是把「让它穿上粉色衣服」改成「让图中最高的那只熊猫穿上粉色的京剧服饰并戴上头饰，并保持动作不变」；
- **想让其余部分不动，就明说**「其他内容保持不变」。

画面复杂、文字说不清位置时，可以先在图上用箭头、线框或涂鸦标出位置，再写「把红框位置的标题放大」「在红色涂抹处放一台电视」。

### 5. 参考图：指明「参考什么」和「生成什么」

想保持同一个角色、同一种风格或同一款产品，上传参考图，并在提示词里写清两部分：

```
参考图中的线性简约风格，设计 9 个应用图标：音乐、天气、日历、相机、聊天、
地图、闹钟、购物车、笔记本，保持一致的配色
```

多张图一起用时逐张点名：`让图一的人物穿上图二的服装`、`参考图二的风格，对图一进行风格转换`。

上传真人照片只用本人或已获授权的照片。

### 6. 一次出一套：组图

需要分镜、表情包、成套物料时，在提示词里写「一系列」「一套」「组图」，或直接写数量：

```
参考这个 LOGO，做一套户外运动品牌的视觉物料，品牌名为"GREEN"，
包括包装袋、帽子、卡片、手环，绿色主色调，简约现代
```

官方说明模型支持生成角色连贯、风格统一的图像序列。

## 常见问题

**Q：豆包生图是免费的吗？次数用完了怎么办？**
豆包 App 可免费使用，App Store 页面同时列出了订阅套餐和创作额度包。每天能生成多少张，官方没有公布固定数字，以 App 内提示为准；额度用完可以等待刷新，或按官方页面的说明选择订阅。

**Q：生成的图片有水印 / AI 标识，能去掉吗？**
标识是按国家网信办等四部门《人工智能生成合成内容标识办法》（2025-09-01 起施行）添加的，办法禁止恶意删除、篡改、伪造、隐匿标识。本文不提供去除方法；对外发布 AI 图片时应保留标识，详见《AI 生成内容标识规定》。

**Q：生成的人手、文字总出错？**
减少画面里的元素，文字用双引号并缩短；人物改成半身或让手自然下垂。局部有问题用改图指令单独修，不必整张重来。

**Q：提示「无法生成」？**
多半是描述或上传的图片触发了内容规则，比如涉及真实人物、未成年人不当内容、知名 IP 角色等。换成原创角色和中性描述再试。

**Q：豆包生图和即梦有什么关系？**
两者都是字节跳动旗下产品，图片模型同属 Seedream 系列。即梦是专门的创作工具，参数和模型选择更细，见《即梦AI怎么用》；豆包胜在对话式修改方便。
