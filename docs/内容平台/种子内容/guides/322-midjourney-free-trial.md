## 适用于谁

- 搜「Midjourney 免费吗」「Midjourney 免费试用」「Midjourney 免费次数用完」的人；
- 想先试试再决定买不买、买哪一档的人；
- 订阅后 Fast 时间很快见底，想知道怎么省、怎么补的人。

本文根据 Midjourney 官方帮助中心整理，资料核对于 2026-10-07。价格与套餐内容随时可能调整，**一切以官方 Manage Subscription 页面显示为准**。

## 结论先说

1. **网页版和 Discord 目前没有免费试用**。官方唯一提到的试用是 **niji·journey 手机 App**（iOS / Android）上的有限试用。
2. **所有方案都是自动续费的订阅**，分 Basic、Standard、Pro、Mega 四档，年付比月付便宜 20%（官方默认选中年付，想月付要手动点「Monthly Billing」）。
3. **选档的关键**：要不要无限 Relax 出图（Standard 起）、要不要隐身模式和 Relax 生成视频（Pro 起）、是不是年收入超过 100 万美元的公司（必须 Pro 或 Mega）。
4. **网上所谓「免费 Midjourney」「Midjourney 中文版免费」多是第三方套壳**，并非官方服务，账号与数据安全没有保障。

## GPU 时间是怎么算的

Midjourney 卖的是「GPU 时间」，不是张数。官方给的大致消耗：

- 一次 SD 出图（4 张）约 0.8 分钟，HD 约 1.3 分钟；
- Creative / Subtle 放大约 2 分钟；
- 一批 4 条 SD 视频约 8 分钟，HD 约 26 分钟。

换算一下：Basic 的 200 分钟 Fast 时间，大约够两百多次 SD 出图，但做视频会快得多地用完。**Fast 时间每次续费时重置，不会累积到下个月**。剩余时间可在 Manage Subscription 页面查看，Discord 里可用 `/info`。

## Fast 时间用完了怎么办

1. **切到 Relax 模式**（Standard 及以上）：不消耗 Fast 时间，排队等待时间官方说在 0～30 分钟之间，用得越少排得越快。Relax 下不能用 repeat、排列组合和 HD 视频。
2. **购买额外 Fast 时间**：在 Manage Subscription 页面购买，官方标价 $4 / 小时。
3. **免费赚 Fast 时间**：
   - 每天给图片打分最多的前 2000 名用户，会获得 1 小时免费 Fast 时间（约在 UTC 午夜通过 Discord 私信通知）；
   - 偶尔参与官方问卷也有奖励，在网站 Tasks 页查看；
   - 注意：奖励时间需要**有效订阅**才能用，发放后 30 天过期。
4. **省着用**：用 `--draft` 草稿模式先试构图（官方称 V7 草稿约一半 GPU 成本），视频用 `--bs 1` 只生成 1 条，确定满意再 HD 或放大。

## 订阅步骤简述

1. 在 midjourney.com 用 Google 或 Discord 账号登录；
2. 进入 **Manage Subscription** 页面，向下找到方案区，选好月付 / 年付后点 **Subscribe**；
3. 通过 Stripe 结账。官方说明可用 Stripe 支持的主流信用卡、借记卡，以及部分地区可用的 Apple Pay、Google Pay、支付宝（Alipay）等，具体以结账页显示为准；不支持 PayPal。

## 常见问题

**Q：以前有免费试用，现在还能领吗？**
官方帮助中心写明：目前网页版和 Discord 都没有免费试用，只有 niji·journey App 提供有限试用。

**Q：订阅后不满意能退款吗？**
官方规定只有账号**累计使用 GPU 时间少于 20 分钟**（Fast、Turbo、Relax 都算）才有资格退款；符合条件时，取消订阅的页面会自动出现退款选项，看不到就说明不符合。因违规被封禁的账号不适用。

**Q：取消订阅后还能用吗？**
可以用到当前计费周期结束。官方说明：在 Manage Subscription 页面点 **Cancel Plan**，取消在本周期末生效，在此之前所有功能（包括剩余 Fast 时间）照常可用；取消不会删除作品和账号记录，私密图片仍保持私密。如果之前安排了升级或降级，要先点 **Cancel Change** 撤销再取消。

**Q：支付失败怎么办？**
先确认卡或钱包是否在结账页的可选列表里、是否支持境外支付；官方提示如果出现错误可以等一小时再试（可能续费款还在处理），仍不行就联系官方账单支持。

**Q：Basic 够用吗？**
只是偶尔出图、不做视频的话可以先从 Basic 月付开始；经常出图建议 Standard（有无限 Relax）；要保密或团队商用看 Pro。
