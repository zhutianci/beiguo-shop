## 适用于谁

- 搜「AI商品图制作」「AI产品图生成」「AI电商图片生成」「AI商品图免费」的人；
- 淘宝、拼多多、抖店、独立站的中小卖家，没预算请摄影棚但想要像样主图的人；
- 已经在用 ChatGPT / Gemini 做图，但总出现「瓶子上的字变了」「颜色不对」的人。

本文根据 OpenAI 图像提示指南、Google Gemini 图像生成文档等官方资料整理，资料核对于 2026-10-07。各电商平台对主图尺寸、背景、文字的具体要求以平台后台规则为准，本文不替代平台规范。

## 结论先说

1. **AI 最擅长「换背景、造场景」，最不擅长「准确复刻商品细节」**。所以流程的核心是：**用真实商品照片做输入**，让 AI 只改背景和氛围，并明确要求商品的形状、颜色、标签文字保持不变。
2. **推荐流程**：实拍原图 → 抠图 / 白底图 → 场景图 → （服装类）模特上身 → 逐项核对 → 后期加文字。
3. **真实性是底线**：《广告法》规定广告不得含有虚假或引人误解的内容；商品性能、规格、成分等信息与实际不符、对购买有实质性影响的构成虚假广告。AI 图可以美化场景，**不能改变商品本身**。

## 第 1 步：拍一张好原图

AI 编辑的上限取决于原图。用手机就够，注意：

- 自然光或台灯柔光，避免强烈反光和杂乱阴影；
- 背景尽量干净（白纸、纯色桌面）；
- 商品端正、完整、对焦清晰，标签文字能看清；
- 多拍几个角度（正面、侧面、细节）。

Google 官方建议：做参考素材时，**主体或商品放在纯色或干净背景上**效果最好。

## 第 2 步：抠图 / 白底图

在 ChatGPT 里上传商品照片，套用 OpenAI 官方的「透明背景商品抠图」写法（意译）：

```
把图中的商品抠出来，放在完全透明的背景上。商品居中，轮廓清晰，没有白边或光晕。
商品的形状和标签文字保持完全一致，只做轻微润色。
不要加纯色背景、棋盘格、场景或阴影，不要改变商品造型。
```

需要白底图时把「透明背景」换成「纯白背景，带自然的接触阴影」。

## 第 3 步：做场景图

把白底图（或原图）作为输入，描述场景、布光和机位。Google 官方的商品摄影模板（意译）：

```
一张高分辨率的影棚商品照：[商品描述]，放在[台面/背景]上。
布光为[如三点柔光箱]，以[营造柔和高光、消除硬阴影]。
机位为[如略高的 45 度]，突出[卖点]。超写实，焦点清晰地落在[关键细节]。[画幅]。
同时：商品的形状、颜色、logo 和标签文字与输入图片完全一致。
```

几个好用的场景方向：

| 品类 | 场景建议 |
| --- | --- |
| 护肤 / 香氛 | 浅色石材台面、绿植叶影、清晨窗边光 |
| 食品 / 饮品 | 木质桌面、原料点缀、暖色侧光、蒸汽 |
| 数码 | 深色桌面、冷色轮廓光、极简留白 |
| 家居 | 真实客厅 / 卧室场景，与家具比例协调 |

OpenAI 官方还演示了「多轮迭代」：先把商品放进日落高速公路的广告牌，再只说「改成下雪的冬夜」，其余不变——同一套场景可以快速出多个季节版本。

## 第 4 步：模特图（服装、配饰）

OpenAI 和 Google 都给出了「虚拟试穿」写法：上传服装图和模特图，明确「只换衣服，不改人」。OpenAI 官方句式的要点（意译）：

```
用提供的服装图片给图中人物换装。不要改变人物的脸、五官、肤色、体型、姿势和身份。
只替换衣服，让衣服自然贴合现有姿势，面料表现真实；光线、阴影、色温与原照片一致。
不要改背景、机位和构图，不要添加配饰、文字、logo 或水印。
```

模特请用**自有版权的模特照片**（签了肖像授权），或者直接用 AI 生成虚拟模特。不要用网上找的明星、网红照片。

## 第 5 步：逐项核对（最重要）

出图后拿原图逐项比对：

- [ ] 外形、比例、结构有没有变；
- [ ] 颜色是否一致（AI 常会「美化」颜色）；
- [ ] logo、标签文字、规格数字是否正确、没有多字少字；
- [ ] 配件数量是否和实际发货一致（场景里加的道具别让人误以为是赠品）；
- [ ] 有没有画出商品没有的功能（比如本来不防水的包被放进水里）。

OpenAI 官方提醒：多轮编辑可能改动你想保留的细节；**必须像素级不变的区域，应把满意的修改合成回原图**，而不是只靠提示词。对于标签、包装这类关键区域，最稳的做法是用 PS 等工具把原图的商品部分贴回去。

## 第 6 步：加文字和卖点

主图上的价格、卖点文案建议在设计工具里用真实字体添加，不要让 AI 直接写——中文容易写错，且无法修改（见《ChatGPT 生成图片中文乱码怎么办》）。

## 合规提醒

- **《广告法》第四条**：广告不得含有虚假或者引人误解的内容，不得欺骗、误导消费者。**第二十八条**列举的虚假广告情形，包括商品性能、功能、规格、成分等信息与实际情况不符、对购买行为有实质性影响，以及虚构使用商品的效果。
- **AI 内容标识**：《人工智能生成合成内容标识办法》要求发布 AI 生成内容时主动声明，不得恶意删除标识；具体到电商平台如何标注，以平台规则为准。
- **第三方权利**：场景里别出现别人的品牌 logo、明星形象、受版权保护的角色。

## 常见问题

**Q：有免费的 AI 商品图工具吗？**
ChatGPT、Gemini 的免费版都能做基本的抠图和换背景，只是额度有限；各电商平台也有自带的 AI 作图工具。选择时优先看能否保持商品细节不变。

**Q：AI 场景图可以当主图吗？**
大多数平台允许使用经过处理的图片，但要求真实反映商品。具体规则（如是否必须白底、能否加文字）以各平台官方规则为准。

**Q：为什么商品上的字总是变？**
文字是 AI 最容易改动的部分。在提示词里强调「标签文字完全一致」，不行就把原图的标签区域合成回去。

**Q：做出来的商品图能商用吗？**
用你自己拍摄的商品照片加工而成的图，一般可以用于自家商品宣传；但要遵守所用工具的服务条款，并避免侵犯他人权利。详见《AI生成图片有版权吗、能商用吗》。
