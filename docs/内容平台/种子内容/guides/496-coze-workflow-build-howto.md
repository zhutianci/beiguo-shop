## 适用于谁

- 搜「扣子工作流怎么搭建」「扣子怎么创建工作流」「扣子工作流入口」「coze工作流在哪」「扣子工作流教程」的人；
- 想把「搜资料 → 整理 → 生成文案」这类固定流程做成一键运行的人；
- 工作流跑到一半超时、代码节点报错，想知道官方限制的人。

本文根据扣子官方文档（docs.coze.cn）整理，资料核对于 2026-10-11。登录后的画布界面没有逐屏核对，按钮名称来自官方文档，以实际界面为准。

## 结论先说

1. **入口有两个**：新用户在扣子编程（code.coze.cn）首页点「工作流」，用文字描述让 AI 生成；老用户在旧版低代码的「资源库」里新建，自己拖节点。官方文档写明低代码平台不再向新注册用户开放。
2. **每个工作流都从开始节点进、从结束节点出**，中间的节点靠「引用上游节点的输出」连成链。
3. **最常用的三个节点**：大模型（写、改、判断）、代码（算、拆、拼）、选择器（if-else 分支）。
4. **提示词里引用变量的写法是 `{{变量名}}`**，对象和数组可以写成 `{{变量名.子变量名}}`、`{{变量名[数组索引]}}`。
5. **官方限制要记住几条**：同步运行整体超时 10 分钟；每个工作流最多 1000 个节点、50 个代码节点；代码节点单次最长 60 秒。

## 步骤

### 1. 新用户：在扣子编程里生成工作流

1. 打开 code.coze.cn 并登录，首页输入框上方点「工作流」；
2. 写需求，尽量把功能、业务逻辑和输入输出说清楚；
3. 可选：上传附件、选协作模式（默认 Agent 模式，需求不明确时先用问答模式讨论）、添加技能、选编程模型；
4. 点运行。AI 会写出工作流的完整代码，自动生成测试用例并测试，通过后把整体结构和节点关系画在画布上。

需求可以这样写：

```
做一个「竞品动态周报」工作流。
输入：竞品名称列表（数组）、时间范围（默认最近 7 天）。
流程：对每个竞品联网搜索新闻 → 去重并过滤广告软文 → 
按「产品更新 / 融资与合作 / 负面舆情」分类 → 每类写不超过 3 条摘要并附来源链接。
输出：一份 Markdown 周报；某个竞品没有新闻时写「本周无动态」，不要编造。
```

生成之后怎么看、怎么改：

- **看懂它**：点画布上的节点查看输入、输出和配置；框选几个节点点「解释」，会得到节点说明、执行逻辑和出错时的降级策略；
- **用嘴改**：在对话框直接说要改什么；或框选节点点「引用」，再输入修改指令；
- **手动改**：在画布上点加号新增动作、条件或并发节点，然后点右上角「发送并执行变更」。官方提示手动编排本身不会直接更新代码，要发送之后才生效；
- **改代码**：点「文件树」进入代码编辑器，改完切回预览刷新画布；
- **试运行**：点「试运行」，填好参数后再点一次。运行时能看到进度、每个节点的耗时和输入输出；
- **出错**：点「一键修复」，或把报错贴进对话。反复修不好就回滚到之前正常的版本。

确认无误后点右上角「部署」，工作流会变成一个可调用的 API 服务。

### 2. 老用户：在旧版低代码里新建

1. 登录扣子开发平台（或在扣子编程首页右上角「回到旧版」），选好工作空间；
2. 左侧进入「资源库」，右上角点「+资源」选「工作流」；
3. 填名称和描述后确认。官方提醒名称和描述要清晰，因为大模型靠它们理解这个工作流是干什么的；
4. 进入编辑页，画布上默认已有「开始」和「结束」两个节点；
5. 从底部面板添加节点，按执行顺序连线，逐个配置输入和输出。

先分清两种类型：**工作流**处理功能型请求，按顺序执行节点，适合生成报告、海报这类自动化任务；**对话流**基于对话场景，适合客服、助手这类一问一答的应用。

### 3. 配置开始、结束和变量

- **开始节点**：定义启动工作流需要的输入参数，比如 `topic`（主题）、`word_count`（字数）；
- **结束节点**：定义返回什么结果；
- **连接方式**：下游节点的输入「引用」上游节点的输出，画布上两者就连起来了；
- **变量类型**：官方列出 String、Integer、Number、Boolean、Object、File、Array，节点之间不需要额外转换。

### 4. 三个核心节点怎么配

**大模型节点**

- 选模型，可调整模型配置；
- **输入参数**：给参数起名，值可以是固定值，也可以引用上游输出；
- **系统提示词**写人设和风格，**用户提示词**写本次任务，两处都用 `{{变量名}}` 引用输入参数；
- **输出格式**有文本、Markdown、JSON 三种。后面要接代码节点或选择器时选 JSON，可以导入一段样例自动生成结构；
- **技能**：可以给这个节点加插件、工作流或知识库，由模型自己判断何时调用；
- **超时与异常**：整体超时默认 180 秒，可设到 600 秒；默认不重试，可设为重试 1 次并指定备选模型；出错时可以选择中断流程、返回预设内容或走异常分支。

一个用户提示词的例子：

```
请根据以下资料写一段不超过 {{word_count}} 字的摘要，面向 {{audience}}：
{{search_result}}
只使用资料里的信息，不要补充。
```

**代码节点**

- 支持 JavaScript 和 Python；
- 输入通过 `params` 读取，结果必须 `return` 一个对象，对象里的字段名和类型要和节点配置的输出参数完全一致——哪怕只有一个值也要包成对象；
- 可用的第三方库很少：JavaScript 内置 dayjs 和 lodash，Python 内置 requests_async 和 numpy，引入其他依赖不会生效；
- 单次执行最长 60 秒；Python 环境不支持多进程、多线程等模块。

官方给出的 Python 入口形式如下，函数体是本文的示例：

```python
async def main(args: Args) -> Output:
    text = args.params['text']
    lines = [s.strip() for s in text.split('\n') if s.strip()]
    return {"lines": lines, "count": len(lines)}
```

**选择器节点**

就是 if-else：满足「如果」里的条件走对应分支，否则走「否则」分支。一个分支里可以加多个条件并用「且」「或」组合；可以加多个分支，拖动调整优先级，按顺序逐个判断，都不成立才走「否则」。

其余常见节点按官方文档的分类有：插件、子工作流、循环、批处理、变量与变量聚合、意图识别、问答、知识库写入与检索、数据库的增删改查、图像生成、视频生成等。

### 5. 试运行和发布（旧版）

1. 点「试运行」，按提示填输入。有图片、视频这类文件参数时，可以上传文件或填文件 URL；
2. 运行成功的节点边框会变绿，点节点右上角能看到这次的输入和输出，据此定位问题；
3. 没问题后点「发布」，可以选一个保存过的测试集作为默认测试集，同空间的其他人就能用它试跑。

### 6. 在智能体里用上工作流

1. 进入智能体编排页，在「工作流」区域点加号；
2. 在「添加工作流」对话框里从「我创建的」中选择；
3. 在「人设与回复逻辑」里写明什么情况下调用，并引用工作流的名称。

如果工作流跑得久，在智能体的工作流设置里可以开「异步运行」并填一句回复内容：默认同步运行，超过约 10 分钟对话可能超时；开启后超时时间延长到 24 小时。官方同时说明异步运行只在调试和商店对话时生效，飞书等渠道暂不支持。

## 常见问题

**Q：新注册账号找不到拖拽式的工作流画布？**
官方文档写明扣子开发平台（低代码）不再向新注册用户开放。新用户用扣子编程的「工作流」入口，生成后同样能在画布上看到节点结构。

**Q：工作流有哪些硬限制？**
按官方的使用限制文档：同步运行整体 10 分钟、异步 24 小时；每个工作流最多 1000 个节点，一次运行最多执行 1000 个节点（循环次数和子工作流里的节点都算）；代码节点最多 50 个；节点输入、输出上限各 10MB，代码节点和插件节点的入参上限 2MB。

**Q：单个节点超时怎么办？**
大模型和插件节点默认 3 分钟、最长可设 10 分钟；HTTP 节点默认 2 分钟；代码、数据库、意图识别节点是 1 分钟。官方建议没开异步时把整体执行时间控制在 5 分钟内。超时了优先拆任务：把一次生成很长的内容拆成几步。

**Q：代码节点想 `import` 别的库？**
旧版低代码的代码节点只能用内置的那几个库。需要更多依赖时，扣子编程生成的工作流是完整代码项目，自带代码编辑器和 Web 终端，更适合这种需求。

**Q：运行失败还会扣费吗？**
官方文档写明：工作流整体失败时，已经成功运行的付费节点仍会计费。调试阶段先用短输入试。

**Q：做好的工作流怎么给别人用？**
挂到智能体上再发布，渠道和审核见《扣子智能体怎么发布》；智能体本身怎么建见《扣子怎么创建智能体》。
