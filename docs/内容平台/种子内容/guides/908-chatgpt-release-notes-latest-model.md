> 本文根据 OpenAI 帮助中心《ChatGPT release notes》《Model Release Notes》和《Managing usage with GPT-6 Astra in Work and Codex》整理，资料核对于 2026-10-14。这些页面是纯文字，没有界面截图，配图为本站整理的示意图。**发布说明几乎每周更新，请直接打开官方页面看最新内容**；模型的名字和区别见 [/guides/chatgpt-gpt6-sol-terra-luna-astra](/guides/chatgpt-gpt6-sol-terra-luna-astra)。

## 适用于谁

- 想知道 ChatGPT 最近更新了什么功能的人；
- 搜「ChatGPT 最新模型」「ChatGPT 最新版本」，想知道官方的答案在哪的人；
- 看到别人说有新功能，自己却没有，想弄清是不是更新问题的人。

## 结论先说

1. **官方的更新日志不止一份**：最主要的是帮助中心的 **ChatGPT release notes（发布说明）**，按日期倒序，记录功能和产品的更新；模型的发布、能力更新、退役，在 **Model Release Notes** 里。
2. **「最新模型」要看两处**：官方没有给「哪个最新、最好」的排名；ChatGPT 发布说明和 Model Release Notes 的更新节奏不一样，**要对照着看**。
3. **每条更新都会写明「适用于谁」**：适用的套餐、平台，以及是否在逐步推出。看到新功能先看这一句，往往就知道你有没有。
4. **你账号里有没有，以你看到的为准**：官方说，模型和功能是否出现，取决于套餐、平台、地区、工作区设置和推送进度；去**模型选择器**里看实际显示的模型。
5. **桌面 App 先更新**：官方说，没看到新模型时，先在桌面 App 里 **Menu → Check for Updates**，装完**完全退出再打开**，再检查一次，见 [/guides/chatgpt-desktop-app-wont-open-update](/guides/chatgpt-desktop-app-wont-open-update)。
6. **企业用户看自己的那份**：Business 和 Enterprise/Edu 各有自己的更新日志，功能是否可用还要看管理员的设置。

## 一、各份更新日志在哪、看什么

### ChatGPT release notes（发布说明）

标题是「ChatGPT release notes」，副标题是「Review the latest updates and release notes for ChatGPT」。内容是按日期倒序排的更新条目，每条一个标题和一段说明，常见的有：新功能上线、适用的套餐和平台、逐步推出的范围、功能的调整或下线，条目里常带「了解更多」的链接，指向对应的帮助文章。

### Model Release Notes（模型发布说明）

官方说明它的内容是：模型的发布、能力更新、模型的退役，以及 **Model Spec**（官方描述模型预期行为的文档）的变化。要看一个模型在 ChatGPT 里什么时候上线、给哪些套餐，也在这里和 ChatGPT release notes 里互相印证。

### 工作区和桌面 App 的更新日志

帮助中心还有这些单独的更新日志（核对时只确认了它们存在及标题，没有逐条读）：

- **ChatGPT Business release notes**：面向 Business 工作区的更新；
- **ChatGPT Enterprise and Edu release notes**：面向 Enterprise 和 Edu 工作区的更新；
- **ChatGPT macOS app release notes**、**Windows App - Release Notes**：桌面 App 的版本更新；
- **Codex changelog**：Codex 的更新记录，官方在发布说明里指向 developers.openai.com/codex/changelog。

这些页面在帮助中心搜索标题就能找到，也可以从 ChatGPT release notes 的条目里点链接进去。

## 三、怎么确认自己有没有新功能或新模型

![想知道自己有没有新功能或新模型：看发布说明、看模型选择器、桌面 App 检查更新、工作区看管理员设置](seed:g908-new-feature-check.png)
*图：本站根据 [OpenAI 帮助中心：ChatGPT release notes](https://help.openai.com/en/articles/6825453-chatgpt-release-notes) 与 [Managing usage with GPT-6 Astra in Work and Codex](https://help.openai.com/en/articles/20001516-managing-usage-with-gpt-6-astra-in-work-and-codex) 整理的示意图*

1. **读发布说明里的适用范围**：条目里会写适用的套餐、平台、地区，以及是否在逐步推出；
2. **看你账号里的模型选择器**：以实际显示的为准；
3. **桌面 App 检查更新**：官方的步骤是 **Menu → Check for Updates**（Mac 用屏幕顶部菜单栏里的 App 菜单），安装更新，完全退出再打开，**再检查一次**；官方说，更新有助于 App 显示你账号可用的功能，但**不会改变你的资格**，模型访问仍取决于套餐、工作区权限和推送范围；
4. **用工作区账号的话**，去看 Business 或 Enterprise/Edu 对应的更新日志，并问管理员有没有开启；
5. **手机 App**：到应用商店更新到最新版本。

如果看了发布说明，你的账号仍然没有，见 [/guides/chatgpt-cant-find-new-model-gpt-6-codex](/guides/chatgpt-cant-find-new-model-gpt-6-codex)。

## 四、模型里常见的更新类型

官方 Model Release Notes 里的条目大致有几类（核对当天的页面里能看到）：

- **新模型上线**：比如「Introducing GPT-5.6 Sol in ChatGPT（2026-07-09）」这类条目，写明开始推送、面向哪些付费套餐，「Free、Go 和未登录用户不包括在内」「推送期间可用性可能不同」「受管理工作区的访问取决于管理员设置」；
- **已有模型的调整**：比如「GPT-5.5 Instant Update（2026-05-28）」，说明对回答风格和质量的改进，以及随之带来的功能变化（那一条里提到 canvas 不再在对应模型里提供）；
- **Model Spec 更新**：比如 2026-08-18 的条目，说明官方对模型预期行为的描述文档做了哪些调整；
- **模型退役**：模型下线、退役的时间和替代方案也会写在这里或 ChatGPT 发布说明里。

模型的名字很多，GPT-6、Sol、Terra、Luna、Astra 的关系见 [/guides/chatgpt-gpt6-sol-terra-luna-astra](/guides/chatgpt-gpt6-sol-terra-luna-astra)；在聊天里怎么选档位，见 [/guides/chatgpt-model-picker-thinking](/guides/chatgpt-model-picker-thinking)。

## 常见问题

**Q：ChatGPT 现在最新的模型是哪个？**
官方没有给统一的「最新」排名，而且发布说明每周更新。截至本文核对的 2026-10-14，ChatGPT 发布说明里最近一次关于模型的大更新是 2026-10-07 的 GPT-6 和 Intelligent UI（见上表）。你账号里能用什么，以模型选择器为准。

**Q：为什么别人有的功能我没有？**
官方在每条更新里都会写适用的套餐、平台和地区，并且很多是逐步推出。可能是你的套餐、地区、客户端版本或工作区设置还不满足，也可能是还没推到你的账号。

**Q：更新日志有中文版吗？**
帮助中心有多种语言版本，但各语言版本的更新可能不同步，建议以英文页面为准（这是本站的建议）。

**Q：怎么知道一个功能什么时候要下线？**
发布说明和 Model Release Notes 里会写功能或模型的调整、退役。已经下线的例子，在站内文章里也有说明，比如 [/guides/chatgpt-group-chats-retired](/guides/chatgpt-group-chats-retired)。

**Q：我只想知道 Codex 更新了什么。**
看 Codex 的 changelog（developers.openai.com/codex/changelog），ChatGPT 发布说明里也会有与 Codex 相关的条目。Codex 的入门见 [/guides/codex-getting-started](/guides/codex-getting-started)。

**Q：付费才能用新功能吗？**
看具体条目写的适用套餐。套餐的区别见 [/guides/chatgpt-plans-comparison](/guides/chatgpt-plans-comparison)；要开通 ChatGPT Plus，可以看 [/chongzhi/chatgpt-plus](/chongzhi/chatgpt-plus)。
