> 本文根据 Google 官方 Gemini 帮助中心整理，核对日期 2026-10-10。技能的入口、Gems 迁移时间表和文件限制，本站《Gemini 使用技巧：Gems 改为 Skills、Deep Research 与上传文件怎么用》已有介绍；本文专讲**怎么把技能写好**。文中的技能示例为本站按官方规则编写，仅供参考。

## 适用于谁

- 搜「gemini 怎么用 skill」「gemini skills 如何使用」「gemini skills 教学」的人；
- 已经建过技能，但发现 Gemini 不调用它，或调用了也不按要求做的人；
- 准备把常用提示词、原来的 Gems 改造成技能的人。

## 结论先说

1. **技能是「小抄」，不是「手册」**：一个技能只管一类事，写清步骤、格式规则和常见错误，越短越聚焦越好。
2. **名称和描述决定它会不会被用**：Gemini 判断是否调用时，**只看名称和 1～2 句描述**；描述写得笼统，它就想不起来用。
3. **描述的官方句式**：第三人称说明它能做什么，再接一句「Use when…（在……时使用）」列出具体场景；上限 1024 个字符。
4. **指令的松紧要匹配任务**：创意类少管，数据和格式类写成一步步的硬规定。
5. **四个提分项**：给输出模板、列「常见错误」、长流程给清单、写明缺信息时怎么办。
6. **使用条件**：年满 18 岁、个人 Google 账号、开启「保留活动记录」；不需要订阅。

## 一、先判断：这件事值不值得建技能

官方给的判断标准——

**适合建技能**：

- **重复的提示词**：同一套要求你一遍遍地打，尤其是又长又复杂的；
- **反复改格式**：每次都要让它把版式、风格调成你要的样子；
- **跨应用拼步骤**：需要在 Gmail、文档、日历之间手动接力。

**不必建技能**：

- **一次性的事**；
- **Gemini 本来就做得好**，不给额外指导结果也符合预期；
- **规则老在变**，技能更新跟不上。

## 二、技能是怎么被调用的

为了保持速度，Gemini 不会一上来就把所有技能读一遍，而是分三步：

1. **判断相关性**：只看每个技能的**名称和描述**；
2. **读取并执行**：认为相关，才去读完整指令；
3. **按需打开文件**：技能里带的模板、风格指南、表格等参考文件，用到时才打开。

这解释了两件事：为什么名称和描述最关键；以及为什么可以放心把细节放进参考文件——不用的时候它不占地方。

调用方式有两种：在对话或任务里输入 `/`（更新后为 `@`）手动选；或者让已启用的技能在相关时被自动使用。一个任务可以叠加多个技能，技能的指令里也可以引用其他技能。

## 三、写好名称

| 规则 | 说明 |
| --- | --- |
| 用动词开头 | 说它「做什么」，而不是它「是什么」 |
| 避开空泛的词 | 比如 helper、tools、data |
| 遵守格式 | 全小写，单词之间用连字符，例如 `my-new-skill` |

官方示例：用 `plan-meal-from-recipe`，不要用 `recipe-data`。

## 四、写好描述

三条规则：

1. **以第三人称的能力陈述开头**：写「它做什么」，不要写「我可以帮你……」或「你可以用它来……」；
2. **列出具体的使用场景**：用「Use when…」起句，告诉 Gemini 什么情况下该用；
3. **保持聚焦**，不超过 1024 个字符。

官方示例（原文为英文）：

> Categorizes recipes, scales ingredient portions, and generates grocery lists from selected meals. Use when saving a new recipe, adjusting the serving size for a meal, or creating a shopping list from a meal plan.

对应到中文可以写成：「对菜谱分类、按人数换算食材用量，并根据选定的菜单生成采购清单。在保存新菜谱、调整某顿饭的份量、或根据一周菜单列购物清单时使用。」

## 五、写好指令

**1. 教「一类任务」，不是「一个任务」**

- 不好：只对一个结果有效，比如「给周二的意大利面列采购清单」；
- 好：说明如何根据你的口味生成**任何**一份菜单和清单。

**2. 决定管多严**

| 任务类型 | 写法 | 例子 |
| --- | --- | --- |
| 创意类，答案不唯一 | 给方向即可，留出发挥空间 | 想博客选题、写社交媒体标题 |
| 严格 / 关键类，错一点就算错 | 写清楚每一步，要求严格照做 | 按固定版式誊抄财务数据、只用要点列表总结会议纪要 |

**3. 给出格式和输出模板**。官方示例：

```
客户报告一律包含以下部分：「执行摘要」「主要发现」「建议」「下一步」。
```

```
写社交媒体帖子时使用这个模板：
标题：[标题]
正文：[正文]
话题标签：#[标签1] #[标签2] #[标签3]
```

**4. 加一节「常见错误」**。例如：

- 删除个人信息：除非任务明确要求，报告里不要出现姓名、邮箱、电话；
- 免责声明用公司模板里的标准版本，不要自己另写。

**5. 长流程给清单**，让它边做边勾，避免漏步骤：

```
复制这份清单并跟踪进度：
[ ] 第 1 步：分析上传的银行对账单
[ ] 第 2 步：提取每笔交易的日期、摘要和金额
[ ] 第 3 步：给每笔交易分类
[ ] 第 4 步：整理成表格
```

**6. 写明缺信息时怎么办**，防止它编造或跳过：

- 「如果邮件里没有活动日期，问我要，不要猜，也不要省略。」
- 「表单里有空着的字段时，停下来让我补，不要自己编答案。」

## 六、一个完整示例

按上面的规则，把「周报」写成技能（本站示例）：

- **名称**：`write-weekly-report-from-notes`
- **描述**：把零散的工作记录整理成固定结构的周报。在用户提供本周工作笔记、聊天记录或任务清单并要求写周报、周总结时使用。
- **指令**：

```
## 步骤
[ ] 1. 通读用户提供的全部材料，按项目归类。
[ ] 2. 每个项目提取：本周完成、进行中、受阻事项。
[ ] 3. 按下面的模板输出。

## 输出模板
### 本周完成
- [项目名]：[结果，尽量带数字]
### 进行中
- [项目名]：[当前进度] → [预计完成时间]
### 风险与需要的支持
- [问题]：[需要谁做什么]
### 下周计划
- [事项]

## 常见错误
- 不要把「开了会」「在跟进」当成果，写不出结果的放进「进行中」。
- 不要补充材料里没有的数字。
- 全文不超过 400 字，不写开场白和结束语。

## 缺信息时
- 没有提到完成时间的进行中事项，标注「时间待确认」并在最后列出来问我。
```

这个例子对应了官方的每一条建议：动词开头的名称、带使用场景的描述、清单、模板、常见错误、缺信息处理。

## 七、创建、测试与维护

创建入口在网页版（或 Mac 版）侧边栏「设置 → 技能（Skills）」，可以让 Gemini 陪你创建、改推荐模板、手动填写，或上传 SKILL.md 文件 / 含 SKILL.md 的文件夹和 .zip。也可以在任意对话里说「根据以下要求创建一个技能：……」。

几条维护要点（操作入口来自帮助中心，测试方法是本站的建议）：

- **测试自动调用**：开一个新对话，不点名技能，直接说一个它应该处理的需求，看它用没用。没用上，多半是描述里的场景不够具体，回去改「Use when…」；
- **停用而不删除**：技能页点开技能 →「更多 → 停用（Deactivate）」，Gemini 就不会再自动使用它；手动点名时会问你要不要重新启用；
- **编辑**：直接改描述和指令；或「更多 → 让 Gemini 帮忙编辑」；要更新参考文件，必须把整个技能连同文件重新上传（「更多 → 替换技能」）；
- **下载备份**：「更多 → 下载」得到一个 .zip。想自己手写 SKILL.md，最稳妥的办法是先在页面上建一个，下载下来照着官方生成的结构改；
- **删除不可撤销**，而且只能在技能页删，不能在对话里删。

上传文件的硬限制：只支持纯文本类文件（.txt、.md、.csv、.json、.py 等）以及 PDF 和图片，不支持 .docx、.xlsx；总大小不超过 100 MB；脚本不能访问外部网站。上传前检查文件夹里有没有 .DS_Store、.pyc 这类隐藏的二进制文件，它们可能导致上传失败。

## 常见问题

**Q：技能和「给 Gemini 的指令」有什么区别？**
固定指令对**每一个**对话都生效，适合「永远用中文回答」这类全局偏好；技能只在相关任务里被调用，适合某一类具体工作。

**Q：技能要付费吗？**
帮助中心明确写：技能不需要 Google AI 订阅，可以在普通对话里使用。需要订阅的是 Gemini Spark 的任务和日程。

**Q：我的 Gems 怎么办？**
Gems 下线时会被自动重建为技能；想提前迁移，可以手动重建，步骤见本站《Gemini 使用技巧：Gems 改为 Skills、Deep Research 与上传文件怎么用》。

**Q：Gemini 的 SKILL.md 和 Claude、Codex 的技能通用吗？**
Gemini 帮助中心明确写：可以把在其他平台创建的技能，通过上传它们的 SKILL.md 文件导入进来（上传入口目前仅网页版和 Mac 版）。不过各家支持的能力不完全相同——比如 Gemini 的技能脚本不能访问外部网站，参考文件也不支持 .docx、.xlsx——导入后要实际跑一遍。另见本站《Claude Skills 是什么、怎么装、推荐哪些》《ChatGPT Skills 怎么用：创建、@调用与推荐（附哪些套餐能用）》。
