## 适用于谁

- 搜「可灵首尾帧」「可灵的首尾帧是什么意思」「可灵首尾帧提示词」「可灵首尾帧功能」的人；
- 想用两张图做变装、转场、物体变形这类「从 A 到 B」的视频，或者想让视频精确停在某个画面上的人；
- 发现加了尾帧后有些选项自动变了、用不了了，想知道原因的人。

本文根据可灵官方的 Start and End Frames 指南、开放平台图生视频接口文档、视频能力地图和网页版界面说明文字整理，资料核对于 2026-10-11。界面以你实际看到的为准。

## 结论先说

1. **首尾帧 = 你给开头和结尾两张图，可灵生成中间的过渡**。它不是单独的功能页，而是图生视频里的一个选项：先传首帧，再加一张尾帧。
2. **不是所有模型都支持**。按官方视频能力地图（2026-05-19 更新），视频 3.0、3.0 Omni、O1、2.6、2.5 Turbo 支持首尾帧，其中 2.6 和 2.5 Turbo 只在 1080P 下支持；3.0 Turbo 不支持。
3. **两张图越像越稳**。官方原话的意思是：尽量选主题相同、画面相近的两张图，差别太大容易变成切镜头。
4. **尾帧和运镜控制、运动笔刷三选一**，多镜头模式下也不能设首尾帧。

## 步骤

### 1. 找到入口

1. 打开 klingai.com 进入创作平台，选「AI 视频」，切到图生视频；
2. 选一个支持首尾帧的模型；
3. 先上传首帧图，再点添加尾帧的位置上传第二张图。官方指南的描述是在图生视频功能区点「增加尾帧」，界面文字还提示可以把已上传的首帧交换到尾帧位置（按钮名称以实际界面为准）。

注意两点：按能力地图，目前各模型都**不支持只传尾帧**，界面会提示「请上传首帧图」；在视频 3.0 Omni 这类多模态输入框里，首尾帧和参考图、主体是放在同一个输入区里选择用途的。

### 2. 准备两张图

![可灵官方首尾帧指南里的示例：两张主体相同、姿势略有变化的小猫图片，分别作为首帧和尾帧](seed:g485-kling-start-end-kitten.jpg)
*图片来源：[可灵 AI 官方快速入门 · Start and End Frames](https://klingai.com/quickstart/ai-video-start-end-frames)*

上图是官方指南用的例子：同一只小猫、同一个雪景，只是姿势和角度变了。选图可以照这个标准：

- **同主体、同场景、同风格**。官方指南提到很多用户的做法是：先用可灵的图片生成做出几张相近的图，从里面挑两张当首尾帧；
- **格式和大小**：接口文档要求 JPG / JPEG / PNG，不超过 10MB，宽高不小于 300px；
- **比例一致**。官方文档没有给出两张图比例不同时的处理规则，稳妥的做法是先把两张图裁成同一比例再上传；
- 用自己拍的、自己生成的或已获授权的图。

### 3. 写过渡提示词

界面给首尾帧输入框的说明是：用文字描述**场景过渡、运镜轨迹或角色动作**。也就是告诉模型「怎么从第一张变到第二张」。接口文档里的示例只有一句：

```
镜头拉远，女生微笑
```

可以按「主体怎么动 + 镜头怎么动 + 中间发生什么」来写：

```
小猫放下左爪，抬头看向右上方飘落的雪花，镜头缓慢向右环绕小半圈
```

```
同一位女孩原地转身，外套从米色大衣自然变为红色羽绒服，镜头固定，背景保持不变
```

写的时候注意：

- **只写一个主要变化**。时长只有几秒，变装、换景、运镜全塞进去，模型多半用一次硬切解决；
- **两张图差别大时，补一个「中间环节」**，比如被一阵烟雾遮住、走过一扇门、镜头先推到某个物体再拉开；
- 提示词上限，接口文档写的是 2500 个字符，足够用，不必写长。

### 4. 选参数并生成

加了尾帧后，可选项会比普通图生视频少，界面会自动调整并弹提示。按能力地图和界面文字，常见的限制有：

- 视频 2.6：首尾帧只支持 1080P，且只能生成无声视频；
- 视频 2.5 Turbo：首尾帧只支持 1080P；
- 部分模型加尾帧后不能选较长的时长，界面会自动切回较短档；
- 音画同步、动作控制等功能和尾帧不兼容时，界面会提示「暂不支持尾帧」或「仅支持首帧图」。

确认灵感值消耗后生成。不满意就改提示词重新生成，或者换一张更接近首帧的尾帧。

## 哪些功能不能和尾帧一起用

| 功能 | 能否与尾帧同时使用 | 依据 |
| --- | --- | --- |
| 运镜控制（含大师运镜） | 不能，三选一 | 接口文档：尾帧、运动笔刷、运镜控制不能同时使用 |
| 运动笔刷 | 不能，三选一 | 同上 |
| 多镜头 / 自定义分镜 | 不能 | 接口文档：开启多镜头时不支持设定首尾帧 |
| 动作控制 | 不能 | 界面提示：动作控制目前仅支持首帧图 |
| 提示词里写镜头运动 | 可以 | 运镜写进文字描述不受上述限制 |

## 常见问题

**Q：可灵的首尾帧是什么意思？**
把两张图分别当作视频的第一帧和最后一帧，中间的画面由模型补出来。适合变装、转场、物体变化，也适合需要视频精确停在某个构图上的情况。

**Q：可灵只能用首尾帧吗？**
不是。只传一张首帧就是普通的图生视频，尾帧是可选的；不传图就是文生视频。想让角色在多个镜头里保持一致，还可以用主体库。

**Q：为什么找不到添加尾帧的地方？**
先看模型：3.0 Turbo 不支持首尾帧，2.6 和 2.5 Turbo 要切到 1080P。再看有没有开着多镜头、运镜控制或运动笔刷，它们和尾帧互斥。

**Q：生成的视频中间「啪」地切了一下？**
两张图差别太大。换成更接近的两张图，或在提示词里补上中间环节；实在差得远，就拆成两段，各自用首尾帧生成后再剪到一起。

**Q：想做更长的连续视频怎么办？**
通用做法是把上一段的最后一帧当作下一段的首帧接着生成，再用剪辑软件拼起来。即梦里的同类用法见《即梦首尾帧怎么用》。

**Q：过渡提示词里的镜头术语怎么写？**
见《可灵运镜提示词怎么写》和《AI视频运镜提示词》。
