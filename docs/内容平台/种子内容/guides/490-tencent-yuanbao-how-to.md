## 适用于谁

- 搜「腾讯元宝怎么用」「腾讯元宝网页版入口」「腾讯元宝电脑版下载」的人；
- 平时在微信里刷到过元宝，想弄清它除了聊天还能干什么的人。

本文根据元宝官网网页版（未登录状态下可见的界面）和 App Store 官方页面整理，资料核对于 2026-10-11。元宝登录后才能使用，登录后的界面本文没有逐项核对，**菜单名和入口以你实际看到的为准**。

## 结论先说

1. **官方入口**：网页版 yuanbao.tencent.com；手机 App 叫「元宝」（App Store 名称为「元宝-腾讯全能AI助手」，提供者是腾讯科技（深圳）有限公司）；电脑版在网页版右上角的「安装电脑版」或下载中心获取。
2. **必须登录才能提问**。网页版支持微信扫码、手机号、QQ 三种登录方式。
3. **它的特点是接了腾讯生态**：官方介绍联网搜索会用到微信公众号、视频号等信源，还能联动微信、腾讯文档等。
4. **App 免费，核对时 App Store 页面没有列出内购项目**。
5. 复杂任务用「专家模式」。App 更新说明提到新模型处理复杂任务仅支持专家模式。

## 步骤

### 1. 打开并登录

**网页版**：浏览器打开 yuanbao.tencent.com，页面会弹出登录窗口：

- **微信**：用微信扫二维码；
- **手机**：手机号加验证码；
- **QQ**：QQ 登录。

页面提示扫码即视为已阅读并同意用户服务协议和隐私协议，登录前可以点开看一下。未登录时输入框显示「请登录后输入内容」。

**手机 App**：应用商店搜索「元宝」，认准腾讯出品。iPhone 需要 iOS 15.0 或更高版本。

**电脑版**：网页版右上角有「安装电脑版」，左下角有「前往下载中心」，按提示下载安装即可，不要从第三方下载站获取。

### 2. 认识网页版界面

未登录状态下能看到的布局：

- **左侧栏**：搜索（搜历史对话）、「元宝」（对话主界面）、「AI 创作」、「全部收藏」；
- **中间**：欢迎语和「你可以这样问」的示例；
- **底部输入框**：右侧有「+」按钮用来添加文件等内容。

### 3. 搜索问答：让它带上来源

直接提问即可，需要最新信息时它会联网。官方介绍的卖点是可以搜到微信公众号、视频号等腾讯生态里的内容，所以查公众号文章里才有的信息（政策解读、行业观点、活动通知）时比较占优势。

提问时写明范围和要求：

```
搜索近三个月关于「灵活就业人员社保缴费」的政策解读，优先采用政府部门公众号和权威媒体，
按「变化点、对谁有影响、怎么办理」三部分整理，每条后面给出来源。
```

回答里的来源点开核对一下再用。公众号文章的质量参差不齐，涉及政策、医疗、理财的内容以官方原文为准。

### 4. 读文档

点输入框的「+」上传文件。App Store 页面的官方介绍写明「文档精读助手，可识别 36 种文件类型」，更新说明里还提到文件支持一键导出为 PDF、DOCX 等常用格式并直接分享给微信好友，以及导出到腾讯文档。

官方介绍还提到与微信、腾讯文档等生态联动，手机上处理微信里收到的文件会更顺手，具体入口以 App 内的实际选项为准。

读长文档时先确认它读全了：

```
先列出这份文件的章节标题，再用 200 字概括核心结论，最后列出文中所有的时间节点和金额。
```

### 5. 学习类：拍题、精讲

官方介绍的学习功能有：

- **拍题答疑**：拍照或截图搜题，多学科覆盖；
- **AI 精讲**：拍题或输入文字后，用动态板书加语音讲解一步步讲题。更新说明提到精讲支持历史记录和倍速播放。

给孩子用的时候，建议让它「先给思路，不要直接给答案」。

### 6. 办公类：录音转写、写作、代码

- **AI 录音笔**：官方介绍为「转写翻译不限时，精准总结录音内容」；近期更新增加了边录边拍的「图片记录」，录音、画面、文字自动关联。开会录音前先征得与会者同意；
- **写作**：报告、文案、总结都可以让它起草；
- **代码**：官方介绍代码能力支持 Python、C++ 等语言的运行。

### 7. 创作类：图片和视频

左侧「AI 创作」和对话里都可以发起。官方介绍包括：一句话 P 图、AI 绘图、让图片动起来、AI 生成视频。提示词写法可以参考《AI绘画提示词怎么写》；生成内容会带 AI 标识，对外发布时的要求见《AI 生成内容标识规定》。

### 8. 选对模式

App 更新说明（2026 年 9 月）提到接入了新的 Hy4 preview 模型，Agent 能力升级，并注明处理复杂任务仅支持专家模式；同月还在专家模式里接入了旅游助手等场景助手。因此：

- 日常问答、闲聊：默认模式即可；
- 多步骤的复杂任务（做行程、写长报告、综合多方资料分析）：切到专家模式。

模式的名称和位置以实际界面为准。

## 常见问题

**Q：腾讯元宝要付费吗？**
App Store 页面显示应用免费，核对时没有列出内购项目。个别功能是否有次数限制，以 App 内提示为准。

**Q：元宝里能用 DeepSeek 吗？**
App Store 页面的用户评价里有人提到元宝同时提供混元和 DeepSeek 模型，但当前官方介绍正文没有逐一列出模型名，近期更新说明里提到的是 Hy 系列新模型。现在能选哪些模型，以你在输入框附近看到的模型选项为准。

**Q：网页版、电脑版、手机 App 记录互通吗？**
用同一个账号登录即可同步。注意微信登录、QQ 登录、手机号登录如果没有绑定在一起，可能是不同的账号，换端时用同一种方式登录。

**Q：元宝派是什么？**
App Store 的介绍里提到「元宝派」开启公测，是可以和朋友一起玩的 AI 互动玩法，具体以 App 内说明为准。

**Q：提示无法使用或一直加载？**
先检查网络并刷新；网页版换用最新版 Chrome 或 Edge；App 更新到最新版本。仍有问题通过 App 内的反馈入口提交。

**Q：上传的文件会被别人看到吗？**
数据的使用方式以元宝的用户服务协议和隐私协议为准。合同、证件等敏感文件上传前先打码，单位内部资料按单位规定处理。
