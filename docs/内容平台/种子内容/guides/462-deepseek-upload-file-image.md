## 适用于谁

- 搜「deepseek 上传文件」「deepseek 上传文件 限制大小」「deepseek 识图模式」，想让 DeepSeek 读 PDF、表格或图片的人；
- 文件传不上去、传上去了却说「未提取到文字」的人。

本文根据 DeepSeek 网页版界面提示、官方常见问题、App Store 版本记录和官方 API 文档整理，资料核对于 2026-10-11。

## 结论先说

1. **支持的格式很多**：界面提示写的是「支持 PDF、DOC、XLSX、PPT、图片、文本、代码等」。
2. **文档是「提取文字」来读的**。上传按钮的提示里有「仅识别文字」的说明，所以扫描件、纯图片型 PDF 里如果抽不出文字，就会失败。
3. **图片能不能真正「看图」取决于版本**：App 在 2026 年 6 月加入「识图模式」，9 月更新说明写「快速、专家、识图模式合并升级」；同月发布的 DeepSeek-V4.1-Flash 模型具备原生视觉理解能力。你当前看到的是「只提取文字」还是「能看懂画面」，以上传按钮旁的提示为准。
4. **上传文件时不能开联网搜索**，两者互斥。

## 步骤

### 1. 上传：点附件按钮或直接拖拽

网页版可以点输入框旁的附件按钮，也可以把文件直接拖进页面（界面提示「文件和图片拖动到此处即可上传」）。上传后会显示「解析中」，解析完成才能发送。

数量和大小限制显示在上传按钮的悬停提示里，格式是「最多 × 个，每个 × MB」。核对时网页版的提示文案里还有一条「每个对话可上传 50 个文件」。这些数字可能随版本调整，以你界面上的提示为准。

### 2. 读文档：先让它交代读到了什么

文档较长时，界面可能提示「DeepSeek 只能阅读全部文件的 ×%」，意思是内容超出了模型一次能读的长度，后面的部分没有读到。所以第一步先确认它读全了没有：

```
这份文件一共有几个章节？请列出章节标题，并告诉我你读到了哪里。
```

确认之后再问具体问题，并要求标注出处：

```
基于这份合同，列出所有涉及付款时间和违约金的条款，逐条写明所在章节和原文关键句，
不要补充文件里没有的内容。
```

文件太长读不全时，把它拆成几个文件分别上传分别问，或者只上传相关章节。

### 3. 读表格：说清你要哪种结果

XLSX 这类表格是按文字内容读入的。让它算数时，最好要求列出计算口径，方便你回头核对：

```
这是 1–9 月的销售表。按「区域」汇总销售额，给出占比和环比变化，
用表格输出，并写明你用了哪几列、怎么算的。
```

数字很多、结果很重要时，用 Excel 自己复算一遍关键数字。

### 4. 传图片：看清是「识图」还是「提取文字」

- 上传按钮提示「仅识别文字」时，图片会被当作文字来源处理：截图、拍下来的文档、带字的海报没问题，纯风景照这类没有文字的图会失败。官方常见问题列出的图片失败原因之一就是「系统未从图片中检测到可提取的文字」；
- 界面出现识图相关的入口或提示时，才可以问「图里是什么」「这张图表说明了什么趋势」这类需要理解画面的问题。

API 文档对视觉能力的说明可以作参考：`deepseek-flash` 模型支持输入图片，可用于描述图片、识别截图文字、分析图表，支持 JPEG、PNG、GIF、WebP 格式。聊天产品里的具体表现以实际界面为准。

### 5. 需要联网时的做法

文件和搜索不能同时用：带着文件去开搜索会提示「请先删除文件再开启联网搜索」。需要两者结合时，先在一个对话里让它读文件、输出要点，再新开一个对话打开搜索，把要点贴进去继续问。

## 常见问题

**Q：图片上传失败是什么原因？**
官方常见问题列了四种：图片格式暂不支持；系统未从图片中检测到可提取的文字；图片大小超过上传限制；图片内容不符合平台使用规范。

**Q：提示「上传的文件包含暂未支持的文件格式」？**
把文件转成界面列出的格式再传，例如把 Pages、Numbers、WPS 专有格式另存为 PDF、DOCX、XLSX。

**Q：选择文件后没有任何反应？**
官方的说法是先检查当前网络环境——公司或学校的内部网络可能限制了文件上传，换个网络再试。

**Q：提示「未提取到文字」或「解析失败」？**
多见于扫描版 PDF、加密文档和纯图片文件。先用 OCR 工具把扫描件转成可复制文字的 PDF，或者把内容复制成文本再发。

**Q：提示「图片或文件可能违反使用规范」？**
内容触发了平台的内容规则，换一份不含敏感内容的文件；涉及他人隐私的材料不要上传。

**Q：上传的文件别人能看到吗？**
分享对话时，界面提示「分享中的文件不支持展示」，即分享出去的链接里不展示你上传的文件本身。数据如何存储和使用，以 DeepSeek 的隐私政策为准；合同、证件这类敏感文件建议先打码再传。
