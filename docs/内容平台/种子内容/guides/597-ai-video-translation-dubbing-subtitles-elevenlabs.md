## 适用于谁

- 搜「视频翻译 ai」「ai 字幕生成」「ai 配音翻译」，想把自己的视频做成多语言版本的人；
- 想弄清「翻译字幕」和「翻译配音」是两件不同的事、各自该用什么工具的人。

本文以 ElevenLabs 为例，根据其官方文档整理，资料核对于 2026-10-11。界面为英文，按钮名保留原文。只需要中文会议或课程的转写和字幕，国内的通义听悟等工具更顺手，见站内对应教程。

## 结论先说

1. **视频翻译有两条路**：只翻译字幕（原声不变，加译文字幕）；或者翻译配音（把人声换成目标语言，尽量保留原说话人的音色和情绪）。前者便宜快速，后者观看体验更好。
2. **ElevenLabs 的 Dubbing 做的是第二种**：官方描述是把视频原有的音频翻译并替换成新语言，同时保留原说话人的声音特征，支持 90 多种语言。
3. **操作很短**：上传文件或粘贴视频链接 → 选目标语言 → 确认费用 → 生成 → 下载。
4. **所有方案都能用，包括免费档**，但免费档生成的配音会自动加水印，无法去除；付费订阅没有水印。
5. **按源视频的分钟数计费，每多选一种语言就多收一份**。
6. **翻译别人的视频要先取得授权**。工具支持粘贴链接，不代表你有权翻译和再发布那条视频。

## 先选路线

| | 只做字幕 | 翻译配音（Dubbing） |
| --- | --- | --- |
| 产出 | 原视频 + 译文字幕文件 | 换成目标语言人声的新音轨或新视频 |
| 成本 | 低 | 较高，按分钟和语言数计 |
| 可控性 | 字幕文本可以逐句校对 | 自动模式下不能在应用里修改内容（见下文） |
| 适合 | 教程、访谈、会议记录、对准确性要求高的内容 | 面向海外观众的短视频、播客、宣传片 |

对准确性要求高的内容（法律、医疗、合同讲解等），建议走字幕路线并人工校对，不要直接发布自动配音的结果。

## 步骤

### 路线一：自动翻译配音（Dubbing）

官方指南的流程：

1. 在导航菜单里进入 **Dubbing**；
2. 上传视频或音频文件；或者切到 **Paste URL** 标签，粘贴视频链接；
3. 选择要翻译成的语言，可以多选；
4. 需要的话点 **Speaker similarity** 调整配音与原说话人的相似程度；
5. 点生成按钮提交。**这时会显示费用并要求你确认**；
6. 完成后在配音列表里下载。

几个官方说明的细节：

- **文件限制**：官方文档两处写法不一致。产品指南的常见问题写的是网页端使用 Dubbing v2 时上限 2 GB、180 分钟，两项都不能超；功能概览页写的是应用内最多 1 GB、180 分钟。稳妥起见按较小的 1 GB 准备，以上传时的界面提示为准；
- **Speaker similarity**（官方也称 Cloning strength）：0 到 10 的刻度，默认 7，官方称适合大多数内容。数值越高越贴近原说话人的声音；
- **自动识别多个说话人**，包括有重叠说话的情况；背景音乐和环境音会保留，不需要重新混音；
- **不能在应用里编辑**：默认使用最新的 Dubbing v2 模型，生成是全自动的，应用内没有修改译文的入口。官方说明，通过 API 编辑转写、译文并重新生成音频的能力仅限企业版；
- 想要逐句编辑，官方的旧工具 Dubbing Studio 仍可使用：选择 Dubbing v1 模型，再选 Dubbing project。它支持编辑转写文本、重新分配说话人、逐段重新生成，文件上限 1 GB、45 分钟。但官方注明 Dubbing Studio 处于维护模式，只修复严重问题。

### 路线二：转写并生成字幕

**第一步：转写**

1. 进入 **Speech to Text** 页面，点 **Transcribe files**，上传音频或视频（官方说明音视频都支持，单个文件最大 3 GB）；
2. 选择音频的主要语言；不确定就保持 **Detect** 自动检测；
3. 可选项：
   - **Tag audio events**：标注笑声、掌声等声音事件；
   - **Keyterm prompting**：添加最多 1000 个词或短语，让模型更倾向于把它们转写正确。产品名、人名、专业术语放这里，效果立竿见影；
   - **Include subtitles**：创建转写的同时生成字幕；
4. 点 Upload files 提交。完成后点文件名查看结果，点某个词可以从那个位置开始播放。

**第二步：编辑字幕**

打开转写结果，用顶部的标签在「转写」和「字幕」两种模式之间切换。创建时没勾选字幕的，可以在右侧面板点 Subtitles 旁边的加号补上。

官方字幕编辑器的功能：

- **格式规则实时提示**：用红色和绿色提示每条字幕是否符合规则（每行字符数、同屏行数、每条时长）。点 Subtitles 旁的三个点 → Edit rules 可以修改这些规则；
- **所见即所得**：点哪里改哪里；
- **调时间**：在时间轴上拖动字幕条两端，或在右侧面板直接输入精确的时间戳；
- **拆分与合并**：在要拆开的位置按回车拆分；用 merge cues 按钮合并两条。

一个官方特别提醒的点：**转写和字幕是完全独立的两份内容**。你在字幕里改的时间和文字不会同步到转写里，反过来也一样。先把转写校对好再生成字幕，可以少改一遍。

**第三步：导出**

点右上角的 **Export**，选择需要的格式下载。字幕文件导入剪辑软件或上传到视频平台即可。

**译文字幕怎么来**：把校对好的原文字幕交给大模型翻译是最常见的做法。提示词里要求「逐条翻译、保留序号和时间轴不变、每条译文不超过若干字」，再人工通读一遍。站内提示词库（/prompts）的翻译润色分类里有现成的字幕翻译提示词。

## 费用与水印

官方文档的说明：

- Dubbing 在所有方案上可用，包括免费档；
- **免费档生成的配音自动带水印，没有去除的选项**；付费订阅不加水印；
- 计费方式：按**源媒体的分钟数**收费，**每一种目标语言各算一次**，具体费率取决于使用的配音模型，见官网定价页。应用内提交前会显示总费用让你确认。

所以控制成本的办法很直接：先剪掉不需要的片段再上传；先只选一种语言验证效果，满意后再加其他语言。

## 常见问题

**Q：能把英文视频配成中文吗？**
官方称支持 90 多种语言的输出，目标语言列表以应用内的选择器为准。

**Q：译文里专有名词翻错了怎么办？**
自动模式下应用内不能修改译文。可选的办法：改用 Dubbing Studio（v1）逐句编辑；或者改走字幕路线，在字幕里人工修正。

**Q：粘贴别人视频的链接来翻译，可以吗？**
技术上工具支持粘贴链接，但翻译、配音和再发布他人的视频属于对作品的改编和传播，需要取得权利人的授权。配音还涉及模仿原说话人的声音，同样要注意对方是否同意。只处理你自己拥有或已获授权的内容。

**Q：做好的翻译视频发到国内平台有什么要求？**
AI 生成或合成的音频、视频内容需要按规定添加标识，见站内《AI 生成内容标识规定》。

**Q：口型能对上吗？**
本文核对的官方 Dubbing 文档描述的是音频层面的翻译与替换（保留音色、情绪、时间节奏），没有提到修改画面里的口型。
