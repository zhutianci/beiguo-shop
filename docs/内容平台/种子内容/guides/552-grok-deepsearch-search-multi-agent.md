> 本文根据 Grok 官网产品页（x.ai/grok）和官方文档整理，资料核对于 2026-10-11。网上很多教程还在讲 DeepSearch、DeeperSearch、Think 这几个按钮；官方页面现在的叫法已经不同，本文以官方当前的写法为准。

## 适用于谁

- 打开 Grok 找不到 DeepSearch 按钮的人；
- 搜「grok deepsearch」「grok deepsearch 和 think 的区别」的人；
- 想用 Grok 追热点、做调研，但不确定该用哪个模式的人。

## 结论先说

1. **官方现在的写法里没有 DeepSearch 这个名字**。官网产品页把相关能力分成三块：**Search**（搜索）、**Deep reasoning**（深度推理）、**Multi-agent**（多智能体）。
2. **Search**：实时搜索网页和 X，回答带来源引用，可以连续追问。
3. **Deep reasoning**：把思考过程一步步展示出来，你可以跟着看、逐步核对。
4. **Multi-agent**：多个智能体并行处理子问题，各自展示推理，最后合并成一份带引用的回答。官网写的是 SuperGrok 提供。
5. 以前「让 Grok 花更长时间查很多来源、写一份报告」的用法，现在对应的是 **搜索 + 多智能体**。
6. X 上的帖子是**信息线索，不是结论**。Grok 给的每一条引用都要点开看原文。

## 三种能力对照

| | Search | Deep reasoning | Multi-agent |
| --- | --- | --- | --- |
| 官方描述 | 实时搜索网页和 X，回答反映「此刻」正在发生的事，而不是训练数据里的旧信息 | 可以跟随并验证的分步思考 | 多个智能体并行工作，在最难的问题上给出更深入的回答 |
| 你看到的 | 带引用的回答；可继续追问深入 | 推理步骤 | 每个智能体的推理过程（可展开审查），以及合并后的带引用结论 |
| 适合 | 突发新闻、趋势、「大家在聊什么」、查最新事实 | 需要推导的问题：比较方案、算账、排查原因 | 要从多个角度拆解的复杂问题：行业调研、多方观点梳理 |
| 谁能用 | 免费可用，有额度限制 | 官网列为基础能力 | 官网写「SuperGrok：更高上限、优先访问和多智能体」 |

三者可以叠加：一个调研类问题通常既要搜索，又要推理。

## 怎么用搜索：三类典型问题

**追热点**——Grok 相比其他助手的特点是能实时检索 X：

```text
过去 24 小时，X 上关于「某款新手机发布」的讨论主要有哪些观点？
分成正面、负面、中立三类，每类给 2–3 条有代表性的帖子链接，
并标出哪些说法目前只有单一来源。
```

**查最新事实**——要求给出来源和时间：

```text
某开源项目最近一个大版本是什么时候发布的？有哪些不兼容的改动？
只引用官方仓库、官方文档或官方博客，每条注明发布日期。
```

**追问深入**——官方说搜索支持「连续追问往下钻」：

```text
针对上面的第 2 点，找出最早提出这个说法的来源，以及有没有官方回应。
```

## 怎么用多智能体：让它分工

多智能体适合「一个人查要半天」的问题。提问时把**拆分方式**写出来，结果会更可控：

```text
调研「小型团队该不该自建向量数据库」。请分三个方向并行研究：
1. 主流托管服务的官方定价与限制；
2. 自建方案的运维成本与常见故障（只引用官方文档和一手工程博客）；
3. 实际迁移案例里的教训。
最后合并成一页结论：适合自建的条件、不适合的条件、仍不确定的地方。
每个结论后面标注来源。
```

官方强调每个智能体的推理都是「透明、可审查」的。实际用的时候**展开看一眼**：哪个方向查得浅、哪个结论只有一个来源，再针对性追问。

## 核对 X 上的信息

Grok 的实时性来自 X，而 X 上的内容鱼龙混杂。几条实用的做法：

1. **区分「有人这么说」和「事实如此」**。让 Grok 明确标注：这是官方账号的公告、媒体报道，还是普通用户的转述。
2. **点开每一条引用**。看原帖的发布时间、账号是谁、有没有被后续更正。
3. **重要信息找第二个独立来源**。官方公告、监管文件、公司官网优先于帖子。
4. **留意时间**。突发事件早期的说法经常被推翻，隔几小时再问一次。
5. **让它列出不确定的地方**：

```text
上面的总结里，哪些结论只有一个来源支持？哪些说法之间互相矛盾？逐条列出。
```

更完整的核查方法见[《AI 搜索怎么核实信息》](/guides/ai-search-verify-sources-hallucination)。

## 省额度的用法

付费用户的搜索、聊天、Imagine、语音、Build 共用一个每周额度池，官方说明不同操作消耗的算力不同。经验上可以这样安排：

- 简单问题用普通对话或搜索，不必每次都开多智能体；
- 问题写完整再发，减少来回；
- 一个主题一个对话，结论拿到后开新对话；
- 在 Settings → Usage 里看各产品占用的比例。

额度规则见[《Grok 怎么用》](/guides/grok-how-to-use-x-account-weekly-usage)。

## 常见问题

**Q：DeepSearch 是被取消了吗？**
官方文档里没有找到关于它去向的说明。可以确定的只有：核对当天，官网产品页和官方 FAQ 都不再使用这个名称，对应的能力以 Search、Deep reasoning、Multi-agent 的形式呈现。你的 App 里如果还有同名入口，按界面使用即可。

**Q：和 ChatGPT 的深度研究、Claude 的 Research 有什么不同？**
思路相近——都是多轮检索后给出带引用的长回答。Grok 的差异点是能实时检索 X 上的讨论。另外两家的用法见[《ChatGPT 深度研究怎么用》](/guides/chatgpt-deep-research)和[《Claude Research 怎么用》](/guides/claude-research-mode)。

**Q：能搜到微信公众号、小红书这些国内平台吗？**
官方的说法是搜索网页和 X。国内平台上的内容大多不在公开网页检索范围内，不要指望它覆盖。

**Q：搜索结果能直接引用到报告里吗？**
先核对。把它给的链接逐个打开，确认原文确实这么写，再引用原始来源而不是 Grok 的转述。
