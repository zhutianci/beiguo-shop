## 结论先说

1. **有免费档**：官方写「Free to try」。价格页写的是免费档的聊天和智能体请求**有限量**，具体次数官方没有逐项列出。
2. **付费档（2026-10 查询，页面标 $，未写明币种，不含税费）**：
   - **Plus**：$8 每月，页面写共享的用量池，含 Grok API 访问、Cursor；
   - **Premium**：$30，官方说用量是 Plus 的 4 倍，含 Grok Bot、更快的聊天响应、图像和视频生成、云端智能体；
   - **Super**：$100，用量是 Plus 的 15 倍，高峰时段优先使用模型；
   - **Ultra**：$200，用量是 Plus 的 50 倍，是个人用户的最高档；
   - **Teams**：每人 $30 起，集中计费、SSO、审计日志；**Enterprise**：定制报价。
3. 官方写明：**价格不含适用的税费**（例如增值税），随时可以取消，**续订前至少 24 小时取消**才能避免再次扣费；价格可能调整。
4. 订阅里包含 Grok API 访问，但 **API 用量单独按标准模型价格计费**，不占套餐用量池；在 Cursor 里使用第三方模型也需要另外购买，按 API 标价计费。
5. 老名字 **SuperGrok** 现在对应哪一档，见 [/guides/chatgpt-plus-vs-supergrok-which](/guides/chatgpt-plus-vs-supergrok-which)，Heavy 的说法见 [/guides/grok-supergrok-heavy-what-is](/guides/grok-supergrok-heavy-what-is)。

## 一、免费版能做什么

官方产品页只写了「网页和 App 里免费试用」，价格页写免费档是**有限的聊天和智能体请求**，在 X 上可以发帖、回复、关注。具体每个功能的免费次数官方没有列出，详见本站 [/guides/grok-free-usage-how-much](/guides/grok-free-usage-how-much)。

## 二、各付费档的差别

价格页列出的功能（摘要）：

- **Plus**：Grok Chat、语音、Imagine 和 Build；Grok API 访问；Cursor；在 X 上有认证标志、更少的广告等；
- **Premium**：包含 Plus 的一切，另有 Grok Bot、更快的聊天响应、图像和视频生成、带 AI 代码评审的代码托管、云端智能体和自动化；
- **Super**：包含 Premium 的一切，另有高峰时段的模型优先访问；
- **Ultra**：包含 Super 的一切，单个用户的用量上限最大。

用量按倍数写（相对 Plus），官方没有给出具体消息条数；用量怎么算、用完怎么办，见 [/guides/grok-usage-limit-weekly-pool-why](/guides/grok-usage-limit-weekly-pool-why)。
