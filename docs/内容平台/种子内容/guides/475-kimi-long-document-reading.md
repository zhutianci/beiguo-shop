## 适用于谁

- 搜「kimi 上传文件限制」「kimi读论文」「kimi总结文献指令」的学生、研究人员和要啃长报告的职场人；
- 遇到「只能阅读全部文件的 ×%，请删减后发送」这类提示，不知道怎么办的人。

本文根据 Kimi 官方帮助中心整理，资料核对于 2026-10-11，入口名称以实际界面为准。

## 结论先说

1. **能传什么**：PDF、Word、Excel、PPT、图片、TXT、视频等常见格式；也可以直接给网址或公众号文章链接让它读。
2. **能传多大**：官方说明单个文件不超过 100MB，单次最多 50 个文件。
3. **能读多长取决于模型**：K2.6 单轮上下文约 128K token（约 5–6 万汉字）；K3 提供 100 万 token 上下文，但需要最高档会员权益。文件加起来超过上下文，后面的内容就读不到。
4. **读得准的关键是提问方式**：先确认它读到了哪里，再分块问，要求标出处。

## 步骤

### 1. 上传文件

- **网页版**：点输入框的「+」，选择文件或图片；
- **手机 App**：点输入框的「+」，可以选照片、本地文件或微信文件。微信里收到的文档可以直接从这里选，不用先另存。

多份文件可以一次传上去（单次最多 50 个）。只需要其中一两份时就别全传——无关内容会占用上下文，还会分散它的注意力。

### 2. 先估算能不能一次读完

官方给的换算：K2.6 的 128K token 大约相当于 5–6 万汉字。可以这样粗估：

| 材料 | 大致字数 | K2.6 能否一次读完 |
| --- | --- | --- |
| 一篇期刊论文（10–20 页） | 1–2 万字 | 可以 |
| 一份行业报告（50 页） | 3–5 万字 | 接近上限 |
| 一本书（300 页） | 15 万字以上 | 不行，需要拆分或用更大的上下文 |

超出时界面会提示只能阅读文件的一部分。这时有三个办法：

- **只传需要的章节**（用 PDF 工具拆分）；
- **分批读**：一次传一部分，每部分让它输出摘要，最后把几份摘要合起来再问；
- **换 K3 并使用更大的上下文**（按官方说明，100 万 token 上下文属于最高档会员权益）。

### 3. 第一问：让它交代读到了什么

不要一上来就问结论。先发：

```
请列出这份文件的章节结构（标题 + 起止页码），并告诉我你完整读到了哪一章。
如果有读不到的部分，请明确说明。
```

这一步能及时发现「只读了前半本」的情况，避免它拿前半部分的内容回答关于全书的问题。

### 4. 读论文的提问模板

```
请按下面的结构总结这篇论文，每一点都注明所在章节或页码：
1. 研究问题：作者想解决什么问题，为什么重要；
2. 方法：数据来源、样本量、核心方法或模型；
3. 主要结果：列出 3–5 个关键发现，带上具体数字；
4. 局限：作者自己承认的局限，以及你认为还存在的问题；
5. 与我的课题的关系：我的课题是 [一句话描述]，这篇论文哪些部分可以引用。
不要补充论文里没有的内容；不确定的地方写「原文未说明」。
```

读完后继续追问细节比重新总结更有效，例如「第 3 条里的效应量是怎么算的，把相关公式和表格位置指给我」。

### 5. 多份文献一起比较

一次上传几篇相关论文后：

```
把这 5 篇文献做成对比表：列为「研究问题、数据与样本、方法、主要结论、局限」，
行为每篇文献（用第一作者 + 年份标识）。表格后用 200 字说明它们的共识与分歧。
```

注意核对它有没有把 A 文献的结论安到 B 文献头上——多文档对比是最容易张冠李戴的场景，关键数字回到原文确认。

### 6. 表格、图片和视频

- **Excel 表格**：Kimi 内置了运行 Python 的工具，可以直接让它「按月汇总并画折线图」，并要求它说明计算口径；
- **图片**：截图、拍照的文档、图表都可以传，问「这张图说明了什么趋势」；
- **视频**：官方说明支持上传视频，单个不超过 100M。

### 7. 让它读网页

官方说明 Kimi 内置访问指定网址的工具，支持普通网页和公众号文章链接。直接把链接贴进去并说明要它做什么：

```
读一下这篇文章：[链接]
用 5 条要点概括，并指出其中哪些说法没有给出数据来源。
```

需要登录才能看的页面它读不到，把内容复制出来或存成 PDF 再传。

## 常见问题

**Q：提示只能阅读全部文件的百分之几？**
文件内容超过了当前模型的上下文长度。按上面第 2 步处理：删减、分批，或使用更大上下文的模型。

**Q：扫描版 PDF 能读吗？**
图片类内容 Kimi 可以识别，但扫描质量差、手写体、复杂表格容易出错。重要文件先用 OCR 工具转成可复制文字的版本更稳妥。

**Q：聊着聊着它忘了文件前面的内容？**
会话轮次太多时早期内容可能被压缩。官方建议超过 20 轮后主动让它总结关键信息；也可以新建会话重新上传文件，并把之前的结论贴进去。

**Q：上传的文件安全吗？**
数据如何使用以 Kimi 的隐私政策和帮助中心「数据使用」说明为准。合同、证件、未公开的研究数据等敏感材料，上传前先确认是否符合你所在单位的规定，必要时打码。

**Q：它总结的内容能直接用在论文里吗？**
不要直接用。AI 的总结可能有遗漏或错误，页面底部也有「内容由 AI 生成，请仔细甄别」的提示。把它当成帮你快速定位的工具，引用时回到原文。
