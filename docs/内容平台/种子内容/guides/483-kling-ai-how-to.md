## 适用于谁

- 搜「可灵怎么用」「可灵ai怎么用」「可灵ai网页版」「怎么用可灵做视频」，第一次打开可灵不知道从哪下手的人；
- 想用可灵做短视频或图片，但分不清模型、分辨率、灵感值这些选项的人。

本文根据可灵官网的快速入门文档、开放平台文档、灵感值规则和网页版的界面说明文字整理，资料核对于 2026-10-11。可灵更新很快，文中的菜单名、模型名**一切以你实际看到的界面为准**。

## 结论先说

1. **网页版地址是 klingai.com**（旧地址 klingai.kuaishou.com 会跳转过来），手机上有「可灵AI」App。按《可灵AI用户服务协议》，可灵由北京快手科技有限公司及其关联公司提供。
2. **主入口就两个：AI 视频和 AI 图片**。视频里再分文生视频、图生视频（含首尾帧），其余对口型、数字人、视频延长等在「全部工具」里。
3. **每次生成先选模型，再写描述，再定分辨率和时长**。官方给的文生视频提示词公式是：主体 + 运动 + 场景，再按需加镜头语言、光影和氛围。
4. **生成消耗灵感值**。官方规则写明：点击生成时扣除，生成失败退回；具体每次扣多少，看提交按钮旁的提示。

## 步骤

### 1. 打开网页版或 App 并登录

电脑浏览器打开 klingai.com 并登录，进入创作平台（地址栏是 klingai.com/app）；手机在应用商店搜「可灵AI」（App Store 页面显示开发者为 Beijing Kwai Technology Co., Ltd.）。官网的说明是 App 与 Web 端资产互通，两边生成的内容都能看到。

灵感值规则里写着「仅限绑定快手账号的用户」获得和使用灵感值，所以登录后账号会和快手账号体系关联。面向海外的站点是 kling.ai，本文只讲国内站。

### 2. 认识几个入口

按核对时的界面文字，创作平台里常用的是这几项（以实际界面为准）：

- **AI 视频**：文生视频、图生视频、首尾帧都在这里；
- **AI 图片**：文生图和带参考图的生图、改图；
- **全部工具**：对口型、数字人、视频延长、AI 音效、AI 试衣、特效等单项功能；
- **资产**：生成过和上传过的素材；
- **主体库**：把角色或物品存成「主体」，之后反复调用，保持形象一致；
- **创意圈**：别人的公开作品，可以参考提示词。

### 3. 做第一条文生视频

1. 进入「AI 视频」，先选模型。核对时页面里能看到视频 3.0、视频 3.0 Omni、视频 2.6、视频 O1 等名称，具体有哪些以列表为准；
2. 在创意描述里写提示词（写法见下一步）；
3. 选分辨率、时长和画面比例；
4. 看一眼提交按钮旁显示的灵感值消耗，再点生成。

几个参数的含义：

- **分辨率**：界面的说明是「720p：生成速度更快」「1080p：画面质量更佳」，视频 3.0 系列另有 4K；
- **时长**：按可灵开放平台的视频能力地图（2026-05-19 更新），3.0 系列为 3～15 秒，2.6 与 O1 为 3～10 秒，2.5 Turbo 为 5 秒或 10 秒；网页端可选项以界面为准；
- **比例**：官方文档列出的是 16:9、9:16、1:1；
- **不希望呈现的内容**：可选的负面描述框，界面给的例子是「模糊、变形、低质量」这类词。

界面里还有「AI 润色」开关：开启时模型会自动优化你的描述；关闭后严格按你的原文生成，官方提示这时需要写得更细。

### 4. 按官方公式写提示词

可灵官方文生视频指南给的公式：

```
提示词 = 主体（主体描述）+ 主体运动 + 场景（场景描述）+（镜头语言 + 光影 + 氛围）
```

括号里的是可选项，最基本的是**主体、运动、场景**三样。官方用的例子是从「一只大熊猫在咖啡厅里看书」一步步加细节，可以照这个思路写成：

```
中景，背景虚化，氛围光。一只戴黑框眼镜的大熊猫坐在咖啡厅靠窗的位置看书，
书放在桌上，旁边一杯咖啡冒着热气，电影感调色
```

官方的几条提醒：用简单的词和句子；内容控制在几秒内能演完的范围；模型对数量不敏感，「沙滩上有 10 只小狗」这种很难数对；球的弹跳、高空抛物这类复杂物理运动目前不容易做好。

### 5. 图片生成

进入「AI 图片」，直接描述画面即可出图；也可以上传参考图做改图、多图融合或风格变换（界面说明里写的是可上传多张参考图，上限以界面为准）。官方图片指南给的参考图要求是 JPG / PNG 格式、不超过 10MB、尺寸不小于 300px。

出图后可以点「生成视频」，这张图会被直接带到图生视频里当首帧。先出图、再让图动起来，是可灵里最常见的做法，详见《可灵图生视频怎么用》和《可灵首尾帧怎么用》。

### 6. 弄清灵感值

按官网《「灵感值」规则说明》（核对于 2026-10-11）：

- 灵感值是用来兑换平台功能使用权的虚拟道具，生成动作发生时扣除，**生成失败会退回**；
- 来源有会员权益、活动赠送和购买等几类，有效期各不相同：会员按月发放的灵感值自发放日起 1 个月有效，购买的灵感值自充值日起 2 年有效；
- 消耗时先用快到期的；
- 购买的标准定价为 1 元 = 10 灵感值，且不支持退款或提现。

会员有哪些档位、每档送多少灵感值、各模型每次扣多少，变化频繁，以官网会员页和提交前的提示为准，本文不列。

## 常见问题

**Q：可灵AI是哪个公司的？**
快手。用户服务协议的签约主体是北京快手科技有限公司及其关联公司。

**Q：可灵是免费的吗？**
生成要消耗灵感值。免费账号能拿到多少灵感值、能用哪些模型和分辨率，官方调整过不止一次，以登录后看到的账户页和会员页为准。

**Q：网页版和 App 有什么区别？**
同一个账号，资产互通。页面文字显示部分功能在手机浏览器里不可用，会提示改用电脑浏览器或 App；新功能两端上线时间也可能不同。

**Q：提示词用中文可以吗？**
可以。界面里的输入提示和开放平台文档的示例都是中文。

**Q：生成很慢或者一直排队怎么办？**
排队时长和当前人数、账号身份有关，界面会显示是否在排队。先确认任务没有失败（失败会退回灵感值），再决定等待还是换个时段。

**Q：想让镜头动起来怎么写？**
见《可灵运镜提示词怎么写》；通用的运镜术语对照见《AI视频运镜提示词》。
