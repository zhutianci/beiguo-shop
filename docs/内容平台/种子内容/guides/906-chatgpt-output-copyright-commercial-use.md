> 本文根据 OpenAI 使用条款（2026 年 1 月 1 日生效）和《共享与发布政策》整理，资料核对于 2026-10-14，并参考 ChatGPT Business 概览里关于适用条款的一句话。这些官方文件没有界面截图，配图为本站整理的示意图。**本文只转述官方条款的说法，不构成法律意见**；图片相关的版权问题见 [/guides/ai-image-copyright-commercial](/guides/ai-image-copyright-commercial)。

## 适用于谁

- 用 ChatGPT 写文章、文案、代码，想知道内容版权归谁的人；
- 想把 ChatGPT 生成的内容用在商业用途，比如发布、出版、做产品的人；
- 担心「别人是不是也能得到一样的内容」的人；
- 想知道官方对发布 AI 生成内容有什么要求的人。

## 结论先说

1. **官方条款这样写**：在你和 OpenAI 之间，**在适用法律允许的范围内**，你 (a) 保留对**输入**的所有权，(b) 享有对**输出**的所有权；OpenAI 把它就输出享有的全部权利、所有权和权益（**如有**）**转让给你**。
2. **条款没有说输出一定受版权保护**：注意措辞——「在适用法律允许的范围内」「如有」。AI 生成的内容在你所在的国家或地区能不能受版权保护，由当地法律决定，官方条款没有回答。
3. **输出未必唯一**：官方明确说，由于服务和人工智能技术的固有属性，输出未必具有唯一性，**其他用户也可能得到相似的输出**；这种权利转让**不适用于其他用户的输出或任何第三方输出**。
4. **条款没有单独写「禁止商用」**：个人服务条款里的「禁止行为」列的是侵权、逆向工程、自动提取输出、冒充人类生成、规避限制、用输出开发竞争模型等，没有一条是「不得商用」。但商用时仍受这些限制和使用政策约束。
5. **你要对内容负责**：输入和输出统称「内容」，你要确保内容不违反任何适用法律或本条款，并保证你有权把输入提供给服务。
6. **使用前要核实**：官方明确说输出不一定准确，**不应作为唯一的事实依据，也不应替代专业建议**；在使用或分享输出之前，你必须评估它的准确性和适当性，**适当时进行人工审核**。

## 一、版权归谁：官方条款的「内容」部分

官方条款把你给服务的内容叫**输入**，服务按输入给你的内容叫**输出**，两者合称**内容**。关键几句话的意思如下：

- **你的内容**：你应对内容承担责任，包括确保它不违反适用法律或条款；你声明并保证，你拥有向服务提供输入所需的全部权利、许可和授权。**所以别把你没有权利使用的东西（比如别人的付费文章、保密资料）贴进去。**
- **内容所有权**：你保留输入的所有权，享有输出的所有权；OpenAI 把它就输出享有的权利（如有）转让给你。这些都是「在适用法律允许的范围内」。
- **内容相似性**：输出未必唯一，其他用户可能得到相似的输出；转让的效力不适用于其他用户的输出或第三方输出。也就是说，**你对「ChatGPT 给你的这一份输出」享有条款里写的权利，但不能据此阻止别人也得到相似内容，或主张对别人的输出有权利**。
- **OpenAI 对内容的使用**：官方说他们可以使用内容来提供、维护、开发和改进服务、遵守适用法律、执行条款和政策、保障服务安全。如果你不希望内容被用于模型训练，可以按官方的指引选择退出，见 [/guides/chatgpt-data-controls-privacy](/guides/chatgpt-data-controls-privacy)。

**第三方服务和输出**：官方说，服务里可能含有第三方软件、产品或服务，以及它们的输出（比如浏览功能里引用的网页内容），这些**受它们自己的条款约束**，OpenAI 不对其负责。也就是说，ChatGPT 引用网页上的原文，版权仍属于原来的权利人，不在上面那条转让之内。

## 二、能不能商用

官方个人服务条款里没有「不得商用」这一条，也没有「可以随意商用」的保证。实际要看这几件事：

1. **条款里的禁止行为你有没有碰**：比如侵犯第三方权利、自动提取输出、把非人类生成的输出说成人类生成的、绕过限制、用输出开发和 OpenAI 竞争的模型。逐条见下一节；
2. **使用政策有没有碰**：政策里禁止的用途，商用也一样禁止，见 [/guides/chatgpt-account-banned-reasons-usage-policy](/guides/chatgpt-account-banned-reasons-usage-policy)；
3. **你的账号类型适用哪套条款**：官方说，**商业条款**适用于 ChatGPT Enterprise、API 和面向企业与开发者的其他服务；帮助中心说明 ChatGPT Business 遵循商业条款。如果你是用公司的 Business 或 Enterprise 账号，请看你们适用的商业条款和合同，见 [/guides/chatgpt-enterprise-vs-business-team](/guides/chatgpt-enterprise-vs-business-team)；
4. **你所在地的法律**：AI 生成的内容能否受版权保护、能否登记、侵权怎么认定，官方条款不回答。重要的商用（比如出版、授权给别人、做成商品）建议咨询当地的专业人士。

## 三、条款里和输出有关的禁止事项

按官方个人服务条款的「禁止行为」，和输出有关的有：

- 以**侵犯、盗用或侵害任何第三方权利**的方式使用服务；
- **自动或以编程方式提取**服务中的数据或输出；
- 就**非人类生成的输出**，作出该内容**系人类生成**的虚假陈述；
- 规避速率限制或其他限制条件，绕过保护措施或安全防护；
- 利用输出内容**开发与 OpenAI 构成竞争关系的模型**。

另外，条款在「准确性」一节里还有一条：**不得将与特定个人相关的输出，用于可能对该个人产生法律或实质性影响的用途**，例如就其信用、教育、就业、住房、保险、法律、医疗或其他重要事项作出决策。

## 四、发布前要注意什么

官方有一份《共享与发布政策》，对社交媒体、直播、演示和出版给出了要求。注意它的页面标注的更新日期较早（2022 年 11 月，示例里还是早期模型），但官方使用条款仍要求你遵守它，下面是其中的原则：

### 分享到社交媒体、直播和演示时

- **共享前或直播过程中，人工审核每次生成的内容**；
- 明确指出内容的创作者是你本人或你的公司；
- 以最直白的方式，在**清晰醒目的位置**标明「**内容由 AI 生成**」；
- 不得共享违反内容政策或可能冒犯他人的内容；
- 如果接受观众提出的提示词请求，要审慎判断，避免输入可能违反政策的提示词。

### 出版借助 OpenAI API 完成部分创作的书面内容（如书籍、短篇小说集）时

官方的要求（针对 API 的创作者）：

- 明确指出出版内容由你本人或你的公司创作；
- 以醒目易懂的方式**明确指出 AI 在内容生成中的作用**；
- 内容主题不得违反内容政策或使用条款；
- 要在**前言或引言（或类似位置）**详细说明起草、编辑等环节的具体分工；
- **不得把内容表述为完全由人类创作或完全由 AI 生成**，并且人类要对出版内容承担**最终责任**。

官方还给了一个标准表述的例子，大意是：作者在创作时部分使用了某模型；生成草稿后，作者按自己的喜好审阅、编辑和修订，因而对出版内容承担最终责任。你可以参照这个思路，但**要确保你写的描述是准确的**。

## 常见问题

**Q：ChatGPT 生成的文章，我能说是我写的吗？**
条款里的禁止行为之一是：就非人类生成的输出，作出该内容系人类生成的虚假陈述。如果你在发表或提交时说明作者，要如实说明 AI 的参与。是否需要披露，还要看你所在的学校、平台或行业的规定。

**Q：别人用同样的提示词，会得到一样的内容吗？**
官方说输出未必唯一，其他用户可能得到相似的输出，条款里的权利转让不涵盖别人的输出。

**Q：ChatGPT 生成的内容有版权吗？**
官方条款说的是：在适用法律允许的范围内，你享有输出的所有权，OpenAI 把它就输出享有的权利（如有）转让给你。内容能不能受版权保护，由法律决定，官方没有保证，本文也不判断。

**Q：能把输出用来训练我自己的模型吗？**
条款禁止利用输出开发与 OpenAI 构成竞争关系的模型。具体是否构成竞争，请看条款原文，必要时咨询专业人士。

**Q：图片的版权呢？**
这篇讲的是文字内容；图片相关的版权和商用说明见 [/guides/ai-image-copyright-commercial](/guides/ai-image-copyright-commercial)，图片上的来源标识见 [/guides/chatgpt-image-watermark-provenance](/guides/chatgpt-image-watermark-provenance)。

**Q：用 API 或企业版，规则一样吗？**
不一样。官方说商业条款适用于 ChatGPT Enterprise、API 和面向企业与开发者的其他服务，请看你们适用的商业条款。
