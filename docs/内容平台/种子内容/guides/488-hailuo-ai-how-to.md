## 适用于谁

- 搜「海螺ai怎么用」「海螺ai视频」「海螺ai图生视频教程」「海螺ai是哪个公司的」，第一次打开海螺不知道从哪开始的人；
- 用过可灵、即梦，想再试一个国产 AI 视频工具的人。

本文根据海螺 AI 官网（hailuoai.com）的页面说明文字和 MiniMax 开放平台的视频生成文档整理，资料核对于 2026-10-11。起草时没有登录查看完整的创作界面，界面相关的说法取自官网页面里的说明和提示文字，**菜单名、模型名以你实际看到的界面为准**；开放平台文档里的参数限制是给开发者的，网页端可能略有不同。

## 结论先说

1. **官网是 hailuoai.com**，打开后是「海螺视频」创作站，出品方是 MiniMax；手机上有海螺 AI App。
2. **做视频有三种给素材的方式**：只写文字（文生视频）；上传首帧、尾帧或首尾帧（图生视频）；用参考图、参考视频、参考音频做「全能参考」。另有针对人物的「主体参考」。
3. **先选模型再创作**。核对时官网主推 MiniMax H3，此外还有 Hailuo 2.3、Hailuo 02 等，不同模型支持的功能不一样。
4. **运镜可以用指令控制**。除了自然语言，海螺支持在提示词里插入 [推进]、[左摇] 这样的运镜指令。
5. **生成消耗贝壳**，页面提示生成失败会退还。价格和会员档位以官网为准。

## 步骤

### 1. 打开官网，认识入口

浏览器打开 hailuoai.com 并登录。按核对时的页面文字，顶部和首页有这些入口（以实际界面为准）：

- **创作视频 / 创作图片**：两个主入口；
- **视频、图片、音频**：对应三类生成能力；
- **模板**：上传照片套用现成玩法的特效模板；
- **资产**：生成过的内容；
- **工具**、**海螺 Agent**：单项小工具，以及用对话和画布方式做多镜头长视频的 Agent。

官网底部的介绍写明：MiniMax 成立于 2021 年 12 月，基于自研大模型推出了海螺 AI、星野等应用。所以搜「海螺ai是哪个公司的」，答案是 MiniMax。

### 2. 文生视频：一段文字出片

1. 进入「创作视频」，选模型；
2. 在输入框里描述画面。官网给的示例是「一个孩子在公园里放风筝，金色阳光，镜头上移」——**主体 + 动作 + 环境 + 镜头**；
3. 选分辨率、时长和比例后生成。

可选的时长和分辨率跟模型有关。MiniMax 开放平台文档给出的规格是：

| 模型 | 分辨率 | 时长 |
| --- | --- | --- |
| MiniMax H3 | 768P / 2K | 4～15 秒 |
| Hailuo 2.3、Hailuo 02 | 768P | 6 秒或 10 秒 |
| Hailuo 2.3、Hailuo 02 | 1080P | 6 秒 |

网页端能选哪些档位以界面为准。输入框附近有提示词优化的开关（页面文字是「启用优化」「自动优化」）；开放平台文档说明这个优化默认开启，关掉可以更精确地按你的原文生成。

### 3. 图生视频：首帧、尾帧、首尾帧

官网的说明是「支持首帧、尾帧、首尾帧三种图生视频方式」：

- **只传首帧**：让一张图动起来，最常用；
- **只传尾帧**：指定视频结束在哪个画面；
- **首尾帧都传**：生成从第一张到第二张的过渡，输入框的提示是「描述两帧之间如何过渡」。

要注意的几条（来自页面提示和接口文档）：

- 两张图比例不同时，尾帧会按首帧的比例自动裁切，生成的视频尺寸跟随首帧；
- 不是所有模型和分辨率都支持尾帧，界面会提示「该模型暂不支持首尾帧」或「512p 不支持尾帧」，按提示切换即可；
- 开放平台对图片的要求是：JPG、JPEG、PNG、WebP 格式，小于 20MB，短边大于 300px，长宽比在 2:5 到 5:2 之间。

提示词只需要写图里的主体怎么动，通用写法见《图生视频提示词怎么写》。

### 4. 用运镜指令控制镜头

官网的说明是「可以通过自然语言 / 运镜指令，增加对视频的运镜控制」，并且可以在文本的多个位置用光标插入运镜指令。开放平台文档列出了 15 种指令：

| 类别 | 指令 |
| --- | --- |
| 左右移 | [左移]、[右移] |
| 左右摇 | [左摇]、[右摇] |
| 推拉 | [推进]、[拉远] |
| 升降 | [上升]、[下降] |
| 上下摇 | [上摇]、[下摇] |
| 变焦 | [变焦推近]、[变焦拉远] |
| 其他 | [晃动]、[跟随]、[固定] |

用法规则：

- **组合运镜**：同一个方括号里写多个指令会同时生效，如 [左摇,上升]，文档建议不超过 3 个；
- **顺序运镜**：前后出现的指令依次生效，如「……[推进]，然后……[拉远]」；
- 也可以直接用自然语言写镜头，但文档说明用标准指令响应更准确。

示例：

```
清晨的湖边，一位老人坐在木船上收网，薄雾贴着水面流动 [拉远]，
随后镜头转向远处的雪山 [右摇,上升]
```

文档注明支持指令语法的是 Hailuo 2.3、Hailuo 02 和带 Director 字样的模型；H3 的文档也提到可以在关键描述后加运镜指令。界面里没有插入按钮时，说明当前模型或模式不支持。

### 5. 主体参考与全能参考

- **主体参考**：上传人物照片，让生成的视频保持同一张脸。页面对照片的要求是每张仅一人、正面看向镜头、面部无遮挡。开放平台对应的 S2V-01 模型目前只支持单个主体、类型为人物面部。使用前要同意《主体参考功能使用须知》，其中要求你对上传的肖像享有权利或已取得授权——只用本人或已获同意的照片；
- **全能参考**：官网的说明是「支持文字、图片、音频、视频等多种方式参考生成视频」，用来参考角色、动作、镜头、风格或声音。MiniMax H3 的文档给的上限是图片不超过 9 张、视频不超过 3 段、音频不超过 3 段，合计不超过 12 个文件。页面提示参考视频需要使用 H3，且不能和首尾帧同时使用。

### 6. 贝壳、下载与内容规则

- **贝壳**：国内站的点数叫贝壳，每次生成按模型、分辨率和时长扣除。页面提示「生成失败，扣除的贝壳已退还」，会员贝壳按月重置，奖励贝壳有有效期。具体每次扣多少、会员有哪些档位，以官网会员页为准，本文不列；
- **下载与标识**：使用须知写明平台有权在输出内容中添加标识和水印；
- **内容规则**：提示「该内容违反社区规范，请更换提示词重新生成」时，换掉可能有问题的描述或图片再试。本文不提供绕过审核的办法。

## 常见问题

**Q：海螺 AI 是哪个公司的？**
MiniMax。视频模型在开放平台上的名字是 MiniMax-Hailuo 系列和 MiniMax H3。

**Q：海螺 AI 免费吗？**
生成消耗贝壳。新用户和免费账号能拿到多少、能用哪些模型，官方会调整，以登录后的账户页和会员页为准。

**Q：找不到尾帧 / 运镜指令的入口？**
多半是当前模型或分辨率不支持。页面在切换模型时会提示「所选模型不支持尾帧和运镜，切换后相关输入会被移除」，换回支持的模型即可。

**Q：提示词写中文可以吗？能写多长？**
可以写中文。开放平台文档里，Hailuo 系列的提示词上限是 2000 字符，H3 是 7000 字符；实际上把主体、动作、场景、镜头写清楚，几十到一两百字就够了。

**Q：海螺和可灵、即梦怎么选？**
三者基础功能相近。可以用同一张首帧和同一句提示词各生成一次再比较，方法见《可灵和即梦哪个好用》。
