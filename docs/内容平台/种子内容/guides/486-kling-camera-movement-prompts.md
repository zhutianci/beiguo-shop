## 适用于谁

- 搜「可灵运镜提示词」「可灵 运镜控制」「可灵 运镜技巧」「可灵提示词」「可灵负面提示词」的人；
- 用可灵生成的视频镜头要么不动、要么乱动，想知道官方到底支持哪些运镜的人；
- 想用视频 3.0 做多镜头短片，不清楚分镜该怎么写的人。

本文根据可灵官方的 Text-to-Video 提示词指南、Camera Movement 指南、VIDEO 3.0 使用指南和开放平台接口文档整理，资料核对于 2026-10-11。只写官方文档里有的内容；界面上的按钮名称以实际为准。

## 结论先说

1. **官方提示词公式**：主体（主体描述）+ 主体运动 + 场景（场景描述）+（镜头语言 + 光影 + 氛围），括号里是可选项。
2. **「镜头语言」和「运镜控制」是两回事**。镜头语言是景别、角度、焦段这些，写在提示词里；运镜控制是一个单独的参数面板，用来指定镜头往哪个方向动、动多少。
3. **运镜控制面板有 6 种基础运镜和 4 种大师运镜**，一次只能选一种，而且只在部分模型下出现。
4. **用视频 3.0 这类新模型时，运镜直接写进提示词**，还可以按「镜头 1、镜头 2……」写分镜。
5. **负面提示词是可选的**。接口文档的建议是优先在正向提示词里用否定句说明不要什么。

## 一、官方提示词公式

```
提示词 = 主体（主体描述）+ 主体运动 + 场景（场景描述）+（镜头语言 + 光影 + 氛围）
```

各部分官方的解释，归纳如下：

| 部分 | 写什么 | 例子 |
| --- | --- | --- |
| 主体 + 主体描述 | 人、动物、物体，以及外貌、服饰、姿态等细节，用几个短句列出 | 一只戴黑框眼镜的大熊猫 |
| 主体运动 | 在做什么，动作要简单到几秒内能完成 | 低头翻书 |
| 场景 + 场景描述 | 所处环境，前景和背景，不用写太满 | 咖啡厅靠窗的位置，桌上一杯冒热气的咖啡 |
| 镜头语言（可选） | 超广角、背景虚化、特写、长焦、仰拍、俯拍、航拍、景深等 | 中景，背景虚化 |
| 光影（可选） | 环境光、晨光、夕阳、光影交错、丁达尔效应、人造光等 | 氛围光 |
| 氛围（可选） | 想要的整体情绪和质感 | 电影感调色 |

最基本的三样是主体、运动、场景。图生视频更简单，官方公式是「主体 + 运动，背景 + 运动」，因为场景已经在图里了，详见《可灵图生视频怎么用》。

## 二、运镜控制面板：6 种基础运镜 + 4 种大师运镜

官方 Camera Movement 指南的说法是：运镜控制用「绝对指令」控制画面里的镜头运动，并通过调整位移参数来选择幅度。下面的中文名称取自开放平台接口文档：

| 类型 | 镜头怎么动 | 参数方向 |
| --- | --- | --- |
| 水平运镜 | 镜头左右平移 | 负值向左，正值向右 |
| 垂直运镜 | 镜头上下平移 | 负值向下，正值向上 |
| 水平摇镜 | 机位不动，镜头左右转 | 负值向左转，正值向右转 |
| 垂直摇镜 | 机位不动，镜头上下转 | 负值向下，正值向上 |
| 旋转运镜 | 画面绕镜头轴线滚转 | 负值逆时针，正值顺时针 |
| 变焦（推进 / 拉远） | 改变焦距，视野变小或变大 | 负值视野变小，正值视野变大 |

接口文档写明：这六项的取值范围都是 -10 到 10，**六选一**，一次只能有一项不为 0。

四种大师运镜是预设好的组合动作，不需要调参数：

| 大师运镜 | 效果 |
| --- | --- |
| 左旋推进 | 先向左旋转，再向前推进 |
| 右旋推进 | 先向右旋转，再向前推进 |
| 推进上移 | 镜头前进并上仰 |
| 下移拉远 | 镜头下压并后退 |

使用时要知道的限制：

- **只在部分模型下可用**。界面的提示文字写的是运镜控制仅支持早期的 1.0 模型；官方视频能力地图（2026-05-19 更新）列出的现行模型里没有这一项。所以选了较新的模型后看不到这个面板是正常的，改用下一节的办法；
- **和尾帧、运动笔刷三选一**，接口文档写明三者不能同时使用；
- **不指定也可以**。界面说明是：未指定运镜方式时，模型会根据图片或描述智能匹配。

## 三、新模型：把运镜写进提示词

VIDEO 3.0 官方指南里的示例提示词，镜头运动都是直接用文字写的。从这些示例里可以归纳出三种写法。

**1. 一句话里交代镜头**

```
低角度跟拍，镜头跟在骑手身后向前推进，摩托雪橇驶入雪原深处，
镜头逐渐升高，露出两侧被雪覆盖的森林
```

**2. 长镜头按时间点写。** 官方 15 秒长镜头的示例用的是「第 4 秒……第 8 秒……第 12 秒……」这种结构，每个时间点写清镜头和人物各做什么：

```
一个不剪辑的长镜头。开场超广角横向跟拍，女孩在月光下的草坪上奔跑；
第 4 秒，镜头随她加速前移；第 8 秒，镜头推到中景并绕到她正前方；
最后 3 秒，镜头继续向前，她的身影逐渐占满画面
```

**3. 多镜头按「镜头 N」写。** 视频 3.0 有多镜头开关：打开后模型自动安排分镜；再点自定义分镜，可以逐个填写每个镜头的内容和时长。官方示例的格式是：

```
镜头 1，司机的侧面中景，手持感；
镜头 2，方向盘上双手的特写；
镜头 3，副驾驶座位上一张旧照片的特写
```

接口文档给的限制是最多 6 个分镜，各分镜时长之和等于视频总时长。

官方 Text-to-Video 指南的示例里出现过的镜头写法，可以直接借用：航拍、第一人称视角高速飞行、镜头缓慢向前推进、环绕镜头、对称构图、运动模糊。更完整的中英文运镜术语表见《AI视频运镜提示词》。

## 四、负面提示词怎么填

网页端的负面输入框叫「不希望呈现的内容」，界面给的例子是模糊、变形、低质量、扭曲、拼贴、标志这类词。使用上注意三点：

- 它是可选项，留空也能生成；
- 接口文档的建议是：**优先在正向提示词里用否定句补充**，比如「画面中没有文字和水印标志，人物不看镜头」；
- 负面词只管「不要出现什么」，管不了「动作做错了」。动作不对，要回去改主体运动那一句。

另外还有一个相关的参数：创意相关性（接口里叫自由度，取值 0 到 1），值越大越严格按提示词来。文档注明 2.x 系列模型不支持这个参数。

## 常见问题

**Q：写了运镜，镜头还是不动？**
先确认提示词里有没有明确的「镜头 + 方向 + 速度」，比如「镜头缓慢向左平移」。图生视频里如果只写了镜头、没写主体动作，模型有时会两头都不做，补上「主体 + 运动」。

**Q：镜头乱晃、一条视频里换了好几种运镜？**
一条几秒的视频只保留一个主要运镜。需要多个镜头时，用视频 3.0 的多镜头或自定义分镜，而不是把所有运镜塞进一句话。

**Q：想让镜头完全固定怎么写？**
在提示词里写「固定机位，镜头不动」。支持运动笔刷的模型，界面还提示可以用静态笔刷涂抹需要保持静止的区域。

**Q：「AI 润色」要不要开？**
界面说明是：开启时模型会自动优化你的描述；关闭后严格按原文生成，需要你把描述写得更细。想精确控制镜头时可以试试关闭后对比。

**Q：提示词里的数量、文字能控制吗？**
官方提醒模型对数字不敏感，「10 只小狗」这类很难数对。分屏可以用「4 个机位，分别表现春夏秋冬」这种写法。
