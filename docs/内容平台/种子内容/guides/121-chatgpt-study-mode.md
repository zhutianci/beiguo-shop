> 本文根据 OpenAI 帮助中心《Using study mode in ChatGPT》和 ChatGPT 发布说明（2026-08-14 交互式测验、2026-09-22 闪卡）整理，资料核对于 2026-10-07。文中提问模板为本站编写。

## 适用于谁

- 学生想用 ChatGPT 学懂知识点、而不是直接抄答案；
- 备考、复习课堂笔记，想让它出题考自己的人；
- 搜「ChatGPT 学习模式不见了」，在菜单里找不到 Study 的人。

## 结论先说

1. **所有套餐都能用**，网页、iOS、安卓都有，支持所有模型。
2. **开启**：网页版在输入框输入 **@study**（或点 **+** 后搜「study」），选 **Study**；也可以直接打开 [chatgpt.com/studymode](https://chatgpt.com/studymode)。手机上点 **+**，选或搜索 **Study**。
3. **找不到 Study 的头号原因**：你在**临时聊天、GPT 或项目**里——这三个地方不能开学习模式，换到普通对话即可。
4. **它怎么教**：先问你已经会什么、卡在哪，再分层讲解，用提问检查你是否真懂，而不是一上来就给答案。
5. **配合复习工具**：2026 年起可以让 ChatGPT 生成**交互式测验**（直接在对话里作答）和**闪卡**（点击翻面，✔ 记住 / ❌ 再练，自动保存到文件库）。

## 步骤

### 1. 开启学习模式

**网页版**（需登录）：

1. 新开一个普通对话；
2. 在输入框输入 `@study`，或者点 **+** 后输入「study」搜索；
3. 从建议里选 **Study**，输入框里会出现 Study 标记。

或者直接访问 chatgpt.com/studymode，打开就是学习模式。

**iOS**：点 **+** → 选 **Study**（没看到就在菜单里搜索）。

**安卓**：点 **+** → 搜索并选择 **Study**。

**关闭**：把输入框里的 Study 标记删掉——光标放在它旁边按退格键，或点它的 ×。

### 2. 第一条消息写清楚这几件事

官方建议在第一条消息里说明：

- 你的水平（初中、高中、大学、入门、进阶）；
- 学科和具体知识点；
- 目标（解一道题、准备考试、读懂一篇文章）；
- 已经懂了哪些，哪怕只有一点；
- 截止日期或考试形式；
- 相关资料（笔记、讲义、PDF、题目照片）。

可以直接套用这几个模板：

```
我是高二学生，正在学 [三角函数的诱导公式]，下周三月考。我能背公式但不会判断符号。请一次只问我一个问题，等我回答后再讲解，错了告诉我该复习什么。
```

```
我上传了 [第三章课堂笔记]。请先用 5 句话概括核心内容，然后帮我做一个到周五的复习计划，每天 30 分钟。
```

```
答案是 B，但我不明白为什么。别直接重复答案，用提问一步步带我推理出来。
```

```
我只有 20 分钟复习 [细胞呼吸]。先列出最重要的 5 个点，然后出 5 道题测我。
```

### 3. 用资料学习

学习模式可以引用你上传的课堂笔记、教学大纲、练习卷、课件、教材节选、数学题照片等。如果它漏看了内容：

- 换一张更清晰的图片或 PDF；
- 把最关键的文字直接粘贴进对话；
- 指明要看第几页、第几题、哪一节；
- 先让它复述一下看到了什么，再开始讲。

### 4. 生成测验和闪卡复习

- **交互式测验**（2026-08-14 起，所有个人套餐和 Edu，网页和手机）：说「就这一章出 10 道题考我」，可以直接在对话里作答。
- **闪卡**（2026-09-22 起，所有套餐，网页和手机）：说「把我的笔记做成闪卡」或「做一套关于 [主题] 的闪卡」。点卡片翻面，记住了点 ✔，没记住点 ❌ 之后再练；可以打乱顺序。闪卡自动保存在**文件库（Library）**，下次从那里打开，或者让 ChatGPT 帮你复习。

## 调整讲解节奏

| 问题 | 可以这样说 |
| --- | --- |
| 讲得太快 | 「当我是零基础，每讲完一步停下来问我懂了没有」 |
| 太简单 | 「基础我懂了，讲得深入一点，再出几道难题，讲讲常见陷阱」 |
| 直接给了答案 | 「先别给答案，给我一个提示」 |
| 没用上我的文件 | 「请只根据我上传的第 2 页回答」 |

学习模式偶尔也会直接给出答案，提醒它改用提示、测验或分步引导就行。

## 学习模式找不到的排查顺序

1. **确认是普通对话**：临时聊天、GPT、项目里都没有 Study 选项；
2. 在菜单里用搜索找「study」，或者直接打开 chatgpt.com/studymode；
3. **手机 / 电脑 App**：更新到最新版，彻底关闭再打开，必要时退出重新登录；
4. **网页版**：强制刷新，清除 chatgpt.com 的网站数据，或用无痕窗口并停用浏览器扩展（尤其是广告拦截、脚本拦截类），也可以换个网络试试；
5. 还是不行，联系客服，附上设备、App 版本、浏览器、你在哪里找的，以及截图。

另外两种情况：使用「青少年版」的账号，家长可能设置了 **Study hours（学习时段）**，到点新对话会自动进入学习模式；部分 Edu 学校工作区由管理员强制开启学习模式，这时不显示 Study 选择器。

## 常见问题

**Q：学习模式会多给我额度吗？**
不会。它和普通对话使用相同的套餐、模型和额度规则，不会绕过限额。

**Q：能用学习模式写作业交上去吗？**
官方明确提醒：学习模式是用来学懂知识的，涉及计分作业要遵守学校、老师的 AI 使用规定。它也会出错，作业、考试等重要内容要自己核对。

**Q：记忆会影响学习模式吗？**
开着记忆的话，ChatGPT 可能记住你的学习目标、喜欢的讲解方式和学过的主题，让讲解更贴合你；关掉记忆也能正常用，只是个性化少一些。

**Q：能用语音提问吗？**
可以，支持听写的设备上可以用语音输入问题。
