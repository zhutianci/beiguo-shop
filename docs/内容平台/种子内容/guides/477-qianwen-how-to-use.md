## 适用于谁

- 搜「千问怎么用」「通义千问怎么用」「通义改名千问」，想知道现在该从哪里进、界面上那些按钮是干什么的人；
- 以前用通义 App 或 tongyi.com，发现名字和网址都变了的老用户。

本文根据千问官网（未登录状态下能看到的界面文案）、电脑端下载页和 App Store 应用介绍整理，资料核对于 2026-10-11。登录后才出现的界面没有逐一核对，以实际界面为准。

## 结论先说

1. **入口**：网页版是 qianwen.com；老域名 tongyi.com 现在会自动跳转过去。手机在应用商店搜「千问」，电脑还有 Windows / macOS 客户端和 Chrome、Edge 插件。
2. **「通义」「通义千问」「千问」是同一个助手的不同名字**，不用重新找别的产品；账号沿用情况以登录后为准。
3. **模型有三个可选**：Qwen3.7-千问（默认，综合问答）、Qwen3.7-Max（代码和复杂任务）、Qwen3.6-Flash（简单任务、响应快）。
4. **模式有两个**：「快速」适合大多数情况；「思考研究」对应深度搜索和深度研究。
5. **左上角有「日常」和「工作」两个页签**：日常是聊天问答，工作是「办公助理」，用来交付文件和处理任务。

## 步骤

### 1. 找到入口并登录

- **网页版**：浏览器打开 qianwen.com。首页不登录也能看到，但点功能时会弹出登录窗口。
- **登录方式**：登录窗口提供手机号加验证码，以及用千问 App 扫码；窗口下方还有其他快捷登录图标，以登录页显示为准。
- **电脑端**：官网右上角「下载电脑端」进入下载页，有 Windows 版、macOS 版，另有 Chrome 插件和 Edge 插件。
- **手机端**：App Store 里的名称是「千问 - 阿里AI助手」，开发者显示为上海智信普惠科技有限公司。同名或近似名称的应用不少，下载时核对开发者。

### 2. 选模型

点页面顶部的模型名称会展开列表，核对时有三项，说明是界面原文的意思：

| 模型 | 官方说明 | 什么时候选 |
| --- | --- | --- |
| Qwen3.7-千问 | 综合 AI 助手，回答工作、学习、生活各类问题 | 默认就用它 |
| Qwen3.7-Max | 擅长代码编写、处理复杂任务 | 写代码、多步骤推理、长任务 |
| Qwen3.6-Flash | 适用于简单任务，响应速度快 | 翻译一句话、改个措辞这类小事 |

模型会随版本更新换名字，以你看到的列表为准。

### 3. 选模式：快速还是思考研究

输入框左下角的下拉里有两个选项：

- **快速**：界面说明是「适用于大多数情况」，日常提问用它；
- **思考研究**：界面说明是「深度搜索、深度研究」。电脑端下载页对它的介绍是把复杂问题逐层拆解、多轮检索并校对结论，适合要查很多资料才能回答的问题，耗时也更长。

一个简单的判断办法：一句话能说清答案的问题用「快速」；需要比较多个方案、要有出处的问题用「思考研究」。

### 4. 认识输入框下面的功能

输入框下方直接排着几个入口：**工作助理、AI生视频、PPT创作、AI生图**，点「更多」还有**代码、翻译、AI写作、录音纪要、研究、千问高考、音视频速读**。

输入框左侧的「+」展开后是四项：**上传文档、上传图片、共享屏幕和应用、截屏提问**。文档怎么传、有什么限制，见《千问怎么上传文件》。

这些入口的本质是「先告诉千问你要做哪类事」，它会切到对应的工具。不选也可以直接打字提问。

### 5. 「日常」和「工作」有什么不同

- **日常**：左侧栏是新对话、云空间、千问创作、定时任务。就是通常意义上的聊天助手。
- **工作**：页面标题变成「千问，你的办公助理」，左侧栏是新任务、技能、连接、项目、本地工作助理、定时任务；输入框下方可以选「云端」「连接」「技能」，核对时这里默认的模型是 Qwen3.7-Max。

按 App Store 的应用介绍，工作助理的定位是从「回答问题」升级为「完成任务」，可以直接交付网页、应用、PPT、Word、Excel、图片等成品文件。所以：问个问题去「日常」；要它做出一份能直接用的文件，去「工作」。

### 6. 第一次用可以这样问

把背景、目标、格式一次说清，比反复追问省事：

```
我是一家 30 人电商公司的运营，要给老板写一份「双十一活动复盘」。
已有数据：销售额、客单价、各渠道流量（稍后上传表格）。
请先给我一个 5 部分的提纲，每部分写清要回答的问题；
我确认提纲后你再逐部分写正文，语气务实，不要空话。
```

## 常见问题

**Q：通义、通义千问、千问到底是什么关系？**
是同一个阿里 AI 助手先后用过的名字。现在官网和 App 都叫「千问」，tongyi.com 会跳转到 qianwen.com。改名的来龙去脉见《千问是什么、怎么用》。

**Q：通义听悟、通义万相也改名了吗？**
核对时，音视频转写工具的官网仍叫「通义听悟」；图片和视频生成平台的页面标题是「万相」，原来的通义万相地址会跳转过去。千问首页里的「录音纪要」「AI生视频」「AI生图」是千问自己的入口。分别见《通义听悟怎么用》和《通义万相怎么用》。

**Q：千问要钱吗？**
日常问答可以直接用。App Store 页面列出了工作助理套餐、千问创作会员、视频生成额度等内购项目，说明这些方向有付费档位；具体价格和权益以 App 内会员页为准。

**Q：千问突然用不了怎么办？**
官方没有公开统一的排查文档。可以先做几件通用的事：刷新页面或重新登录；换一个浏览器或关掉浏览器插件再试；网页不行就换 App 或电脑客户端。仍然不行，在登录窗口或 App 的反馈入口提交问题。

**Q：千问有 API 吗？**
官网右上角有「API 服务」入口，开发者调用走阿里云百炼，做法见《千问 API Key 怎么获取》。
