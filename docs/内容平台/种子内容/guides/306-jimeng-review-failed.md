## 适用于谁

- 在即梦里遇到「视频未通过审核」「参考图包含人脸信息」「参考图涉及版权」「图片生成失败」「视频下载失败」等提示的人；
- 想知道问题出在提示词、参考图还是模型设置，以及怎么合规地改。

本文根据即梦用户服务协议、即梦网页版页面中的提示文字和火山引擎 Seedance 官方文档整理，资料核对于 2026-10-07。文中引用的提示语为核对时的写法，**确切措辞以你实际看到的为准**。

> 审核是平台依法进行的内容安全管理。本文只讲找出原因、修改内容后正常生成，不提供任何绕过审核的办法。

## 结论先说

1. **先看提示文字属于哪一类**：内容不合规（提示词 / 参考图）、人脸或版权受限、模型不支持当前功能、素材规格不对、服务繁忙或网络问题。
2. **内容类问题只有一个解法：改内容**。换掉他人肖像、知名 IP 和违规描述，用自己拥有或已获授权的素材。
3. **失败一般会返还积分**，页面提示为「使用失败，积分已返还」（以实际为准）。
4. **反复失败又确认内容合规**，通过即梦的意见反馈入口或用户协议里列明的官方联系方式反馈。

## 按提示排查

### 1. 「未通过审核」「内容不合规」类

即梦会对输入（提示词、参考图、参考视频、音频）和输出结果都做安全审核，所以有时提交成功，结果仍被拦下。用户协议第 4 条列出了不得输入、生成的内容，包括违法有害信息、侵害他人名誉权 / 肖像权 / 知识产权的内容、谣言和不实信息等。

常见提示和处理：

- **「你输入的文字包含不合适内容，请返回修改」**：检查提示词或配音文案里有没有暴力、色情、侮辱、政治敏感、真实人物负面描述等，换成中性、具体的画面描述；
- **「你上传的图片不符合平台规则，请修改后重试」**：换一张不含违规元素、他人隐私信息的图；
- **结果视频被拦**：通常是生成画面本身触发规则，比如动作描述过于激烈、人物过于暴露、撞脸公众人物。调整描述后重新生成。

### 2. 参考图包含人脸 / 真人肖像

Seedance 2.0 在即梦里的模型说明直接写着「**暂不支持真人人脸**」；火山引擎文档也说明，Seedance 2.5 和 2.0 系列不支持直接上传含真人人脸的参考图 / 视频。使用部分模型时，网页版还会弹出「安全确认」，要求你使用本人照片 / 视频或取得充分授权。

合规的做法：

- **换成虚构角色**：先用即梦图片生成做一个 AI 角色，再拿它当参考图；
- **用插画、动漫、3D 风格**的人物形象；
- **数字人、动作模仿等功能**支持真人照片，但只能用本人或已获授权的照片（见《即梦对口型与数字人怎么用》）；
- 不要上传明星、网红、他人的照片，也不要描述「长得像某某明星」。

### 3. 参考图涉及版权 / 知名 IP

即梦用户协议要求：输入内容为你原创或已获合法授权，不得侵犯他人著作权、商标权等。上传影视剧截图、动漫角色、品牌 Logo、他人摄影作品，都可能被拦截。处理方法：

- 用自己拍摄、绘制或生成的素材；
- 有正式授权的商业素材，保留授权证明；
- 提示词不写具体 IP 角色名和品牌名，改为描述风格特征，例如「复古日式动画风格、明亮配色」。

另外，如果作品里的音频可能含有版权内容，即梦可能会先把视频静音处理。

### 4. 角色参考不准，中途「变脸」

Seedance 2.0 官方提示词指南提到一种情况：角色的面部参考不准确，视频中途长相发生变化，生成结果因此与他人相似而被拦下。根因是面部参考和全身照、服装图混在一张里，面部占比太小。这是参考素材的准确性问题，官方给的做法（用于你自己的虚构角色或已获授权的形象）是：

1. 额外准备一张**只含头部的角色大头照**（无表情最佳，少背景）；
2. 提示词里分开写：「面部特征参考 图片1（大头照），妆造参考 图片2（全身照）」；
3. 越需要精准参考的素材，在提示词里越靠前；不要用同一人物的多视图拼图。

### 5. 「当前模型不支持……」与规格问题

这类不是审核问题，而是设置不匹配：

- **「当前模型不支持尾帧」「当前模型不支持全能参考」「当前模型不支持智能多帧」**：换支持该功能的模型；
- **「请上传比例相同的首尾帧图片」**：把两张图裁成同一比例；
- **「该模型不支持参考图片」**：换模型或去掉参考图；
- **素材尺寸 / 时长不符**：按火山引擎文档，Seedance 参考图宽高比需在 0.4～2.5 之间、边长 300～6000 像素；Seedance 2.0 参考视频单段 2～15 秒。即梦界面会提示具体要求，按提示调整即可。

### 6. 服务繁忙、排队失败

高峰期可能出现「对口型服务繁忙」「高峰期加速拥挤，免费次数已返还」等提示。稍后再试，或换一个负载较轻的模型。

### 7. 视频下载失败、下载后打不开

- **下载失败**：刷新页面后重试；使用无水印下载失败时，页面提示为「下载失败，权益已返还」（以实际为准）；
- **4K 视频打不开**：Seedance 2.0 的 4K 输出是 10bit、H.265 编码，部分浏览器和播放器无法直接播放。火山引擎文档推荐 Windows 上用 VLC、mpv，Mac 上用 Safari、QuickTime、VLC；
- 剪辑软件导入报错时，也可能是同样的编码兼容问题，先转码或换播放器确认文件本身没问题。

### 8. 账号被限制

如果提示「系统检测到您有多次违规，无法使用该功能」或账号被封禁，可在消息中心查看解封时间；对处理有异议，通过意见反馈页面申诉。

## 常见问题

**Q：审核没通过，积分会扣吗？**
即梦对失败任务通常会提示「使用失败，积分已返还」。如果没看到返还，可在积分详情里核对，再通过意见反馈联系官方。

**Q：换个说法、加符号能不能过审？**
不要这样做。用户协议明确禁止刻意使用字符组合逃避技术审核，可能导致账号受限。正确做法是把内容改到合规。

**Q：为什么同样的提示词，别人能生成我不能？**
参考素材、模型、具体措辞都会影响审核结果；输出结果也会单独审核，所以每次生成都可能不同。按上面的分类逐项排查。

**Q：图片生成失败但没有任何提示？**
多为网络或服务临时异常，刷新后「再次生成」；仍失败就换个模型试试，并检查参考图格式和大小。
