## 适用于谁

- 搜「豆包生成视频提示词」「豆包图生视频怎么用」「豆包生成视频是免费的吗」「豆包生成视频次数」的人；
- 想用豆包把一句话或一张图变成短视频，但出来的画面乱动、不听指挥的人。

本文根据豆包官网页面、App Store 页面、字节跳动 Seed 官方博客和火山引擎 Seedance 官方文档整理，资料核对于 2026-10-11。入口名称以实际界面为准。

## 结论先说

1. **入口**：网页版 / 电脑版在输入框下方点「视频生成」；手机 App 里在对话中发起，或使用图片动起来一类的功能（以实际界面为准）。
2. **用的是字节跳动的 Seedance 系列视频模型**。App Store 页面的应用介绍写明图片和视频生成基于 Seedance 模型，Seed 官方博客也说明 Seedance 2.0 可在豆包 App 中使用，官网下载页提到客户端支持「专业版 Seedance 2.5」。
3. **提示词写「主体 + 动作 + 场景 + 镜头」**，一个镜头只安排一种运镜，动作写具体。
4. **图生视频更可控**：先有一张满意的图，再让它动起来。
5. **次数和额度没有官方固定数字**；生成的视频带 AI 生成标识，本文不提供去除方法。

## 步骤

### 1. 找到入口

1. 打开 doubao.com/chat 并登录，点输入框下方的 **视频生成**；
2. 输入文字描述，或先上传一张图片再描述希望它怎么动；
3. 选择比例、时长等参数（可选项因模型和账号而异，以界面为准），发送后等待生成。

视频生成比出图慢得多，高峰期需要排队，这是正常现象。

### 2. 文生视频：按「谁、做什么、在哪、镜头怎么动」写

Seedance 官方提示词建议的核心是**把动作和镜头写具体**。可以套这个结构：

```
[主体] + [具体动作] + [场景 / 环境]，[镜头运动]，[光线 / 氛围 / 风格]
```

例如：

```
一只橘猫从窗台跳到书桌上，碰倒了一支铅笔，铅笔滚到桌边停住；
室内下午的自然光；固定机位，中景；画面安静温馨，写实风格
```

对照检查三点：

- **动作可被看见**：「很开心」不如「咧嘴笑着原地跳了两下」；
- **一个镜头一种运镜**。官方提示词指南提醒，同一镜头里同时要求推、拉、摇、移会让画面不稳定。想要多个镜头，就按「镜头 1 / 镜头 2 / 镜头 3」分开写；
- **不要塞太多主体**。一条短视频里主角一两个，背景元素点到为止。

### 3. 图生视频：让图「动起来」而不是「重画一遍」

上传图片后，提示词只需要写**变化的部分**——图里已经有的外观不用再描述一遍：

```
女孩缓缓转头看向镜头并微笑，头发被微风吹动；背景的树叶轻轻摇晃；
镜头缓慢向前推进
```

官方文档给的两条建议：

- 图生视频尽量上传**高清图片**，图片质量对结果影响很大；
- 输入图片的宽高比和输出视频的宽高比不一致时，可能出现画面被拉伸、压缩的「跳变」。所以先把图裁成目标比例（竖屏 9:16、横屏 16:9）再上传。

一个稳妥的流程：先用豆包的「图像生成」做出满意的首帧（见《豆包生图怎么用》），再拿这张图生成视频。

### 4. 台词、声音和字幕

Seedance 2.x 能生成带声音的视频。按官方提示词指南的写法：

- 人物要说的话放进花括号，例如 `她抬头说：{今天天气真好}`；
- 不想要字幕，就在提示词末尾加一句「保持无字幕」。

具体模型是否支持音频，以你在豆包里实际选到的模型为准。

### 5. 不满意时怎么改

- **动作不对**：把动作拆得更细，写清先后顺序（「先……然后……最后……」）；
- **人物变形**：减少大幅度动作，改成半身或中景；图生视频换一张更清晰、正面的图；
- **镜头乱晃**：明确写「固定机位」；
- **想保留开头和结尾**：用首帧 + 尾帧的方式生成过渡，写法见《即梦首尾帧怎么用》。豆包里是否提供首尾帧入口以界面为准，没有的话可以到即梦里做。

## 常见问题

**Q：豆包生成视频是免费的吗？每天几次？**
豆包 App 本身免费。App Store 页面同时列出了订阅套餐和「创作额度包」这类内购项目，说明视频这类高消耗功能存在额度。免费用户每天能生成几条、订阅后有多少额度，官方没有公布固定数字，以 App 内的提示和官方订阅页面为准。

**Q：生成的视频有「AI生成」标识，能去掉吗？**
标识是按《人工智能生成合成内容标识办法》（2025-09-01 起施行）添加的，办法禁止恶意删除、篡改、伪造、隐匿标识，本文不提供去除方法。发布到短视频平台时，按平台要求勾选或声明内容由 AI 生成，详见《AI 生成内容标识规定》。

**Q：可以上传真人照片生成视频吗？**
只用本人或已获授权的照片。Seedance 2.0 发布时官方说明暂不支持直接用真人人脸做参考，用 AI 生成的人物或动漫形象更顺利；当前规则以界面提示为准。

**Q：最长能生成多少秒？**
取决于模型。火山引擎文档写明 Seedance 2.0 支持的输出时长为 4～15 秒，Seedance 2.5 发布时官方介绍单段最长 30 秒；豆包里实际可选的时长以界面为准。更长的片子用多段拼接。

**Q：豆包和即梦生成视频有什么区别？**
模型同源，都是 Seedance 系列。即梦是专门的创作工具，「全能参考」、首尾帧、智能多帧等方式更全，见《Seedance 2.0 怎么用》；豆包适合随手生成和对话式修改。

**Q：提示生成失败或内容不合规？**
检查提示词和图片里是否有真实人物、知名 IP 角色、暴力等内容，换成原创角色和中性描述再试。
