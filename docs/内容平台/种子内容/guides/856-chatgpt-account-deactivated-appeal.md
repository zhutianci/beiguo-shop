> 本文根据 OpenAI 帮助中心《Why was my OpenAI account deactivated?》《Troubleshooting "deleted or deactivated" account errors》等文章整理，资料核对于 2026-10-13；截图引用自 OpenAI 帮助中心，为英文界面。本文只说明官方的申诉流程，不提供任何规避停用的办法。

## 适用于谁

- 登录时看到「You do not have an account because it has been deleted or deactivated」的人；
- 收到 OpenAI 的警告邮件（warning），担心下一步被停用的人；
- 账号被停用，觉得是误判，想知道去哪申诉、要写什么的人；
- 想知道等 30 天账号会不会自己恢复的人。

## 结论先说

1. 这句提示有两种可能：**你自己删除了账号**，或者**账号被 OpenAI 停用**。两者的出路完全不同，先去邮箱（含垃圾邮件）找 OpenAI 的邮件确认。
2. **自己删除的**：无法恢复；彻底删除满 30 天后，可以用同一个邮箱重新注册一个新账号。
3. **被停用的**：**等 30 天没有用**，停用的账号不会自动恢复。认为是误判，就走申诉。
4. **申诉入口按优先级有三个**：停用通知邮件里的申诉链接 → 找不到邮件时用 `openai.com/form/appeal` 表单 → 没收到任何邮件却登不进去，用帮助中心的聊天窗口联系客服。
5. 因为**没按时完成年龄或身份验证**被停用的，不用申诉，按验证邮件完成验证即可。

## 一、先分清：删除还是停用

![ChatGPT 账号「已删除或已停用」的几种情况与对应做法对照图](seed:g856-deleted-vs-deactivated.png)
*图：本站根据 [OpenAI 帮助中心：Troubleshooting "deleted or deactivated" account errors](https://help.openai.com/en/articles/8958977-troubleshooting-deleted-or-deactivated-account-errors) 整理的示意图*

| 情况 | 邮箱里会有什么 | 能不能恢复 |
| --- | --- | --- |
| 自己申请了删除 | 确认收到删除请求、删除完成的邮件 | 不能。满 30 天后可用同一邮箱新注册，但聊天记录、文件和记忆不会回来 |
| 被官方停用 | 说明停用的通知邮件，通常带申诉链接 | 走申诉，由官方审核 |
| 未完成身份 / 年龄验证 | 验证邮件 | 按邮件完成验证；找不到邮件可联系客服重发 |

官方特别强调：如果不是你自己删的，**等 30 天并不会让停用的账号恢复**。

顺带一提，被划入「ChatGPT for Teens（青少年体验）」本身不等于停用，官方说明这只是使用体验上的调整，见 [/guides/chatgpt-age-verification](/guides/chatgpt-age-verification)。

## 二、官方列出的五类停用原因

1. **违反使用政策（Usage Policies）**：官方举例包括色情内容、涉及未成年人的剥削内容、暴力与自残、欺骗与诈骗、仇恨骚扰与垃圾信息、其他不当或违法内容、侵犯知识产权等；
2. **违反服务条款（Terms of Service）**：例如**绕过安全或访问限制**、**不当共享账号或 API Key**、以可能伤害他人或破坏服务完整性的方式使用；
3. **安全问题或未授权访问**：系统发现账号疑似被盗用时，可能**临时停用**以保护你，官方建议修改密码、轮换 API Key；
4. **收到警告后仍反复违规**；
5. **没有完成身份或年龄验证**。

另外，《ChatGPT Supported Countries》开头写明：在官方支持的国家和地区之外访问或向他人提供访问，可能导致账号被封锁或停用。支持范围见 [/guides/chatgpt-supported-countries](/guides/chatgpt-supported-countries)。

这里要提醒一点：**不当共享账号**是官方明确点名的违规情形。想长期稳定使用，账号只给自己用。

## 三、只是收到警告（warning）怎么办

官方的定性是：**警告是通知，不是立刻停用**，是让你检查并调整用法的机会；警告之后继续违规，可能导致进一步限制或永久停用。

常见触发原因有三类：内容违规、**试图绕过安全系统**（规避内容过滤、利用漏洞生成不允许的内容）、滥用 API 或平台（自动化垃圾信息、钓鱼、API Key 被未授权共享、异常的用量模式）。

收到警告后该做的：

- 读一遍使用政策和服务条款，对照自己最近的用法；
- 停掉可能生成违规内容的提问方式；
- 检查账号活动，**确认只有你自己在用**（改密码、登出其他设备，见 [/guides/chatgpt-account-security-mfa](/guides/chatgpt-account-security-mfa)）；
- 认为警告发错了，同样可以通过邮件里的链接申诉。

## 四、怎么申诉

![ChatGPT 账号停用申诉的步骤示意图](seed:g856-appeal-steps.png)
*图：本站根据 [OpenAI 帮助中心：Why was my OpenAI account deactivated?](https://help.openai.com/en/articles/10562188-why-was-my-openai-account-deactivated) 整理的示意图*

**入口（按顺序）**

1. **停用通知邮件里的申诉链接**——官方首选，理由是这样能把请求准确分派、审核更快；
2. 找不到那封邮件：填写申诉表单 `https://openai.com/form/appeal/`；
3. 没有收到任何通知邮件，但就是登不进去：到 [help.openai.com](https://help.openai.com/) 用聊天窗口联系客服，见 [/guides/chatgpt-contact-support](/guides/chatgpt-contact-support)。

**官方要求附上的内容**

- 要申诉的 **User ID 和 Org ID**（有的话）；
- 和你的使用情况有关的背景说明；
- 怀疑账号被盗的话，写明**大致的时间范围**；
- 如果发现了不认识的扣费：扣费日期、金额、卡号后 4 位、卡组织（Visa、Mastercard 等）、发卡行名称、账单邮编；
- 你已经采取了哪些处理措施（改密码、轮换 Key 等）。

写的时候实事求是、说清时间线即可。官方只承诺「尽快审核并回复」，没有给出时限，也不保证恢复。

## 五、因为年龄验证被停用

这是唯一可以自己「解开」的一种。官方说明：错过年龄验证期限被停用的，用账号关联的重新激活或验证链接完成验证；提交后处理可能需要几天，不一定马上收到确认邮件。18 岁以上的用户自己验证，13–17 岁的需要家长或监护人用该用户的邮箱完成。

官方文章里给出具体自助入口的是**意大利**的强制年龄验证：登录后在停用页面点 **Verify your age**。其他情况找不到验证邮件时，联系客服重发。详见 [/guides/chatgpt-age-verification](/guides/chatgpt-age-verification)。

## 常见问题

**Q：账号被停用了，订阅还会继续扣费吗？**
官方的停用文章没有直接回答。帮助中心在别处提到，登不进账号又需要处理账单时，联系客服并提供相关的账单和付款信息；通过 App Store 或 Google Play 订阅的，可以直接在应用商店里取消。

**Q：能不能直接换个邮箱重新注册？**
官方只说明了自己删除账号后 30 天可以重新注册。被停用的账号走申诉流程；如果停用是因为违规，重新注册并不改变原因本身。

**Q：我没做任何违规的事，为什么会被停用？**
可能是第 3 类：系统怀疑账号被盗用而临时停用。申诉时把你知道的异常情况（陌生登录提醒、不认识的扣费）写清楚。也可以先看看 [/guides/chatgpt-suspicious-activity-alert](/guides/chatgpt-suspicious-activity-alert)。

**Q：申诉要多久？**
官方未公开。
