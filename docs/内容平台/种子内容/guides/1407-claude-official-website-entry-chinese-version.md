## 适用于谁

- 搜「claude官网入口」「claude官网中文版」，想确认官方地址的人；
- 想把 Claude 界面改成中文，却找不到选项的人；
- 担心点到仿冒站、想知道怎么核对的人。

## 结论先说

1. **官方站点是 [claude.com](https://claude.com/)**，里面有产品介绍、定价、下载页和帮助中心入口。
2. **网页版登录入口是 [claude.ai](https://claude.ai)**。官网上的「Login」指向 claude.ai/login，「Try Claude」指向 claude.ai。
3. **官方下载页是 [claude.com/download](https://claude.com/download)**；帮助中心是 [support.claude.com](https://support.claude.com/en/)；服务状态在 status.anthropic.com。
4. **没有单独的「中文官网」**。官网语言选择器当天列出的是英语、日语、德语、法语、韩语、意大利语和西班牙语，没有中文。
5. **但可以直接用中文聊天**。官方帮助中心写明：Claude 会用你输入的语言回答，不受界面显示语言限制。
6. **界面语言列表里没有简体中文**：帮助中心列出的界面语言是 11 种（英语、法语、德语、印地语、印尼语、意大利语、日语、韩语、巴西葡萄牙语、拉美西班牙语和西班牙本土西班牙语）。

| 入口 | 地址 | 说明 |

| 官方站点 | claude.com | 产品、定价、下载 |

## 三、想要中文，该怎么做

### 用中文对话：直接打字

不用设置。官方说明里写的是：Claude 会用你使用的语言回应，你可以用任何语言聊天，和界面显示语言无关。

### 改界面语言

按帮助中心的步骤，网页版和桌面版里：点击左下角头像，进入「Language」，选择列表里有的语言，界面会自动更新。**简体中文不在官方列表里**，所以界面按钮目前不能切成简体中文，以后是否增加以官方为准。

### 语音模式有单独的语言设置

官方写明，语音模式的语言和界面语言是分开的，在设置里的语音选项下选择「口语语言」。详见 [/guides/claude-voice-mode](/guides/claude-voice-mode)。

### 帮助文章有中文菜单吗

帮助中心页眉的语言菜单里有简体中文，但那是帮助网站自己的菜单，不属于 Claude 应用界面。部分文章是否有中文翻译，以页面显示为准。

## 四、怎么认出假冒网站

官方没有专门写过这一点，下面是通用做法：

1. **只认 claude.ai 和 claude.com 两个域名**（以及 support.claude.com 这样的子域名）；
2. 从 claude.com 顶部的「Login」「Download apps」进入，不点搜索广告里的「Claude 官网中文版」「Claude 免费镜像」；
3. 不在陌生页面输入账号密码和验证码；
4. 不推荐任何第三方汉化版、镜像站，本文也不给出这类链接；
5. 登录遇到问题，看 [/guides/claude-login-errors-table](/guides/claude-login-errors-table)；怀疑官方故障，看 [/guides/claude-down-check-status-page](/guides/claude-down-check-status-page)。
