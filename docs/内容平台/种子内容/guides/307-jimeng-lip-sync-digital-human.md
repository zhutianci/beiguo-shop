## 适用于谁

- 搜「即梦数字人」「即梦对口型在哪」「即梦数字人教程」，想让一张人物图开口说话、唱歌、做口播的人；
- 想让照片里的人物跟着一段参考视频做动作（动作模仿）的人；
- 遇到「对口型失败」「视频不满足对口型条件」的人。

本文根据即梦网页版页面中的说明文字和 IT之家、智东西对即梦官方的报道整理，资料核对于 2026-10-07。文中的入口名称、时长和文件大小限制为核对时的页面提示，**以你实际看到的界面为准**。

## 结论先说

1. **数字人 = 一张角色图 + 说话内容（文字或音频）→ 口型匹配的说话视频**。入口在首页「创作类型」里的「**数字人**」。
2. **对口型有两种场景**：用「数字人」从一张图生成说话视频；或在已生成的视频上用「**对口型**」工具重新配音。
3. **动作模仿 = 一张人物图 + 一段动作视频 → 图中人物做出同样的动作**，入口是「创作类型」里的「**动作模仿**」。
4. **用真人照片必须是本人或已获授权**，界面上也会提醒「请确保所有素材为本人所有或已获得合法授权」。

## 背景：这几个功能从哪来

- 2025 年 3 月 7 日，即梦数字人上线「**大师模式**」，由字节跳动自研的 OmniHuman-1 模型驱动：输入一张图和一段音频，就能让人物做出匹配音频的演讲、唱歌、演奏等动作，支持肖像、半身、全身图，也支持动漫、3D 卡通形象；
- 2025 年 3 月 5 日，即梦上线「**动作模仿**」，上传人物图和参考视频，让图中人物模仿视频里的动作和表情；
- 两项功能上线时官方都表示会进行安全审核，并给输出视频加「AI 生成」水印。

## 步骤一：用「数字人」做说话视频

### 1. 选入口和模式

在即梦首页输入框的「创作类型」下拉里选 **数字人**。数字人有不同的生成模式（界面上可见「大师模式」「快速模式」等，名称和效果说明以实际界面为准）：大师模式效果更好，快速模式出片更快、成本更低。

### 2. 上传角色图

界面提示「**支持真人 & 动漫**」「**清晰的正脸，生成效果更佳**」。准备图片时：

- 人物正脸清楚，五官不被头发、手、墨镜遮挡；
- 光线均匀，分辨率不要太低；
- 一张图里有多个人时，可以选择让哪个角色说话（界面有「选择角色说话」）；
- 上传后会进行「角色检测」，检测不到人物会提示失败，换一张主体更清楚的图。

### 3. 输入说话内容

两种方式任选：

- **输入文字 + 选音色**：在「说话内容」里写台词（有字数上限，界面会提示），点「音色」挑选；也可以在「我的音色」里上传 5～30 秒、包含清晰人声的音频创建自己的音色。注意部分音色是 VIP 音色；
- **上传音频**：直接上传一段配音或歌曲。

还可以在「动作描述」里补充动作和镜头（可选），界面示例是：

```
镜头推进，他摘下眼镜，对着镜头笑着说
```

### 4. 生成并检查

生成前界面会计算所需积分。生成后重点看口型、牙齿和嘴角是否自然，不满意就调整角色图或台词节奏后再生成。

## 步骤二：给已有视频「对口型」

在已生成的视频作品上找到「**对口型**」工具（位置以实际界面为准），可以给视频里的人物重新配音：

- 输入文字生成配音，或上传音频；
- 配音不能比视频长。比如视频 5 秒，界面会提示「请将配音裁剪至 5s 以内」，你可以用「音频裁剪」截取，或删减文字、加快朗读速度后重新配音；
- 上传的音频有最短和最长时长限制，超出范围会提示。

## 步骤三：用「动作模仿」让人物动起来

1. 「创作类型」切到 **动作模仿**；
2. **角色**：上传人物图，界面提示「支持全身 / 半身图片」「人物比例尽量与动作模板一致」。图片在 20MB 以内、分辨率不超过 4K，太小会提示分辨率过小；
3. **动作**：「选择动作模版」用官方模板，或「上传参考视频」。参考视频 1～30 秒、50MB 以内，超过 30 秒会自动裁剪；
4. 选择模型（界面为「大师」「生动」「快速」三档，分别对应效果最佳、不限画幅动效更真、更快更便宜），生成。

上传参考视频的官方建议：

- **镜头**：保持一镜到底，不要运镜；
- **稳定**：镜头稳定，避免晃动；
- **画质**：人物清晰，画幅不限；
- **版权**：确保素材为你所有或已获合法授权。

## 对口型、数字人失败的常见原因

| 提示 / 现象 | 原因与处理 |
| --- | --- |
| 视频不满足对口型条件 | 官方未列明具体条件，常见情况是画面里没有清晰的人脸，或人物太小、侧脸、被遮挡；换人物脸部清晰的片段再试 |
| 现仅支持用「中文」配音对口型 | 给已有视频对口型时，上传的配音需为中文；换中文配音 |
| 你输入的文字包含不合适内容 | 修改台词后重新配音 |
| 所选音色不支持您输入的语言 | 换支持该语言的音色，或检查文字里是否有无效字符 |
| 未检测到人物 | 换主体更清楚、人物更完整的图 |
| 对口型服务繁忙 / 服务发生错误 | 稍后重试 |
| 视频暂时静音 | 音频可能含有版权内容，换成你有权使用的音频 |

更多审核和失败问题见《即梦视频未通过审核 / 生成失败怎么办》。

## 肖像与授权：一定要注意

- **只用本人照片，或已取得当事人明确同意的照片**。即梦用户协议要求输入内容为本人所有或已获合法授权，不得侵害他人肖像权、声音权益、名誉权；
- **不要用明星、网红、他人照片做数字人**，也不要克隆别人的声音；
- 涉及未成年人的肖像、声音，需要取得监护人的全部合法授权；
- 生成的视频带有「AI生成」标识，发布时还要主动声明是 AI 生成内容（见《即梦怎么去水印》）。

## 常见问题

**Q：即梦对口型在哪？**
两个地方：首页「创作类型」里的「数字人」（从一张图生成说话视频），以及已生成视频上的「对口型」工具（给视频重新配音）。

**Q：动漫、宠物、卡通形象能做数字人吗？**
界面写明支持真人和动漫；官方报道也提到对动漫、3D 卡通等非真人图片支持较好。非人类形象效果以实际生成为准。

**Q：能用一段英文歌做数字人吗？**
「现仅支持中文配音」是给已有视频对口型时的提示；数字人从图片生成时支持哪些语言，以界面和音色说明为准，建议先短音频试一次。

**Q：数字人和 Seedance 2.0 的全能参考有什么区别？**
数字人专注「一张图开口说话 / 唱歌」，口型对齐是核心；Seedance 2.0 全能参考更适合多镜头叙事，且暂不支持真人人脸参考。用法见《Seedance 2.0 怎么用》。
