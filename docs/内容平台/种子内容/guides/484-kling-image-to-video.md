## 适用于谁

- 搜「可灵图生视频」「可灵图生视频教程」「可灵图生视频提示词」，想让一张照片或一张 AI 图动起来的人；
- 试过几次，结果要么画面几乎不动、要么突然换了个镜头，不知道问题出在哪的人。

本文根据可灵官方的 Image-to-Video 指南、VIDEO 3.0 使用指南、开放平台图生视频接口文档和网页版界面说明文字整理，资料核对于 2026-10-11。接口文档里的限制是给开发者看的，网页端通常一致但不保证完全相同，**以你上传时界面的提示为准**。

## 结论先说

1. **入口在「AI 视频」里的图生视频**：上传一张图当首帧，再写一句描述；也可以在「AI 图片」出图后直接点「生成视频」。
2. **提示词只要写「谁 + 怎么动」**。官方公式是：主体 + 运动，背景 + 运动。场景已经在图里了，不用再描述一遍。
3. **描述要贴着图写**。官方提醒：描述和图片差得太远，模型容易直接切到另一个镜头。
4. **尾帧、运动笔刷、运镜控制是三选一**，接口文档写明不能同时使用。

## 步骤

### 1. 准备一张合格的图

可灵开放平台图生视频接口对图片的要求是：

- 格式：JPG / JPEG / PNG；
- 大小：不超过 10MB；
- 尺寸：宽和高都不小于 300px；
- 宽高比：在 1:2.5 到 2.5:1 之间，太细长的图会被拒。

除了硬性要求，选图时还可以注意两点：主体清楚、留出动作空间（比如要让人物抬手，手不要贴着画面边缘）；用自己拍的、自己生成的或已获授权的图，上传真人照片前确认是本人或已取得同意。

### 2. 上传并选模型

1. 打开 klingai.com 进入创作平台，选「AI 视频」，切到图生视频；
2. 点「添加首帧图」上传图片（界面文字，以实际为准）；
3. 选模型。各模型支持的功能不同，按可灵开放平台的视频能力地图（2026-05-19 更新）：视频 3.0 和 3.0 Omni 支持多镜头、首尾帧、主体控制和音画同出；视频 2.6 支持首尾帧和音画同出，但不支持多镜头。网页端能选哪些以列表为准。

### 3. 按「主体 + 运动」写提示词

官方给图生视频的公式：

```
提示词 = 主体 + 运动，背景 + 运动 ……
```

有几个主体就依次写几句。官方举的例子很说明问题：想让一幅肖像画里的人戴上墨镜，只写「戴上墨镜」，模型不知道是谁戴、怎么戴，往往按自己的理解生成，甚至把画当成展品，做一个平移镜头——这也是照片容易生成「静态视频」的原因。改成「画中的女士用手戴上墨镜」，再加一句「背景出现一束光」，模型就容易照做。

可以直接套用的写法：

```
小猫抬起右爪去够飘落的雪花，尾巴轻轻摆动，背景的雪持续落下
```

```
模特微笑着转头看向镜头，头发被风吹起，背景的树叶轻微晃动
```

官方的几条提示：

- 用简单的词和句子，不要写得很绕；
- 动作要符合物理规律，最好是图里「本来就可能发生」的动作；
- 描述和图片差别太大，可能引发镜头切换；
- 球的弹跳、高空抛物这类复杂物理运动目前不容易做好。

想加镜头运动，直接写进提示词即可，写法见《可灵运镜提示词怎么写》。

### 4. 设置参数

- **分辨率 / 模式**：接口文档把生成模式分为标准（720P，性价比高）、高品质（1080P，质量更好）和 4K 三档；界面上的说明是「720p：生成速度更快」「1080p：画面质量更佳」；
- **时长**：视频 3.0 系列 3～15 秒，2.6 与 O1 为 3～10 秒（能力地图注明这两款部分情况下只有 5 秒和 10 秒），2.5 Turbo 为 5 秒或 10 秒；
- **创意想象力 / 创意相关性**：对应接口里的自由度参数，取值 0 到 1，值越大越贴近你的提示词，值越小模型越自由发挥。文档注明 2.x 系列模型不支持这个参数，界面上没有这个滑杆属于正常情况；
- **不希望呈现的内容**：负面描述框，可留空。接口文档的建议是，优先在正向提示词里用否定句把不要的东西说清楚；
- **声音**：支持音画同出的模型可以同时生成声音。能力地图注明视频 2.6 在 720P 下只支持无声视频。

设置好后，看清提交按钮旁的灵感值消耗再生成。

### 5. 进阶：绑定主体、多镜头、延长

- **绑定主体**：视频 3.0 的官方指南介绍，上传首帧后可以再绑定主体库里的主体，用来在推拉摇移时稳住角色长相。接口文档写的上限是 3 个参考主体；
- **多镜头**：视频 3.0 可以打开多镜头开关，让模型自动安排分镜，或用自定义分镜逐个填写每个镜头的内容和时长。接口文档写明最多 6 个分镜，各分镜时长之和要等于总时长；多镜头模式下不能再用首尾帧；
- **视频延长**：官方「视频延长」指南介绍，生成后的视频可以继续延长，分自动延长和自定义创意延长两种，自定义时提示词要延续原视频里的主体和动作。哪些模型的视频能延长、每次延长几秒，以界面为准。

## 常见问题

**Q：生成的视频几乎不动，像在拍一张照片？**
多半是提示词只写了结果、没写「谁在做什么」。按「主体 + 运动」补全；如果图本身是画作、海报、截图，在提示词里明确写主体的动作，避免模型把它当成一张要展示的图。

**Q：视频中途突然换了个画面？**
官方指南的解释是描述和图片偏离太大时容易触发切镜。把动作改成从当前画面能自然发生的，或者拆成两段分别生成。

**Q：上传图片失败？**
对照第 1 步检查格式、大小、尺寸和宽高比。超长截图、WebP 或 HEIC 格式的图，先转成 JPG 或 PNG 再传。

**Q：同时想用尾帧和运镜控制，为什么一选另一个就没了？**
接口文档写明尾帧、运动笔刷、运镜控制三者只能选一个，界面上也会提示互斥。镜头运动可以改为写在提示词里。

**Q：提示「未通过审核」或生成失败？**
前者是内容规则问题，换掉可能有问题的图或描述后再试；后者按灵感值规则会退回本次消耗。本文不提供绕过审核的办法。

**Q：第一次用可灵，入口都找不到？**
先看《可灵AI怎么用》；通用的图生视频提示词思路见《图生视频提示词怎么写》。
