## 适用于谁

- 搜「豆包怎么删除对话记录」「豆包怎么清空聊天记录」「豆包怎么批量删除对话」的人；
- 在公用电脑上用过豆包，想清理历史的人；
- 删了对话，却发现豆包还「记得」内容，想弄明白为什么的人。

## 结论先说

1. **主应用**：官方隐私政策写的方法是 **点击对话框 → 点击单个对话 → 删除**。如果这样做不了，可以按政策里的方式联系官方（见文末参考资料）。
2. **豆包工作桌面端**：鼠标悬停在对话上，点三点图标，选 **删除**，会**彻底清除该对话的所有相关数据，且不可恢复**；不想彻底删就选 **归档对话**，只是从最近对话列表隐藏，不清除数据。
3. **批量删除**：悬停在对话列表或分组名上 → **历史对话管理** → 右上角图标 → **批量删除对话** → 勾选 → 删除并确认。
4. **删了聊天记录不等于删了记忆**。豆包的记忆要在 **设置 → 记忆** 里另外处理。
5. 官方说，不主动删除或注销账号，聊天记录会一直保存。

## 一、删除、归档有什么区别

| 操作 | 效果 | 能恢复吗 |
| --- | --- | --- |
| 归档对话 | 从最近对话列表隐藏，不清除对话数据 | 可以，在已归档里查看（悬停列表名 > 对话筛选 > 已归档，或左下角设置 > 已归档内容） |
| 删除 | 从列表中删除，彻底清除该对话的所有相关数据 | **不可恢复** |

所以只是不想让别人一眼看到，用归档；确定不要了，再删除。

## 二、单条删除

**豆包工作桌面端**：在对话列表中把鼠标悬停在对话上，点三点图标（也可以在对话详情页点上方中央的对话名称），在更多操作里选 **删除**。

**主应用**：按隐私政策的说明，点击对话框，点开单个对话，选择删除。

## 三、批量删除（豆包工作桌面端）

![豆包工作里批量删除对话](seed:g1441-batch-steps.png)
*图：本站根据 [豆包工作帮助中心：新建和管理对话](https://www.doubao.com/work/docs/zh-cn/articles/628589138051-chats) 整理的示意图*

1. 鼠标悬停在左侧导航栏下方的对话列表或分组名称上（如「置顶」「项目」「最近」）；
2. 点右侧图标，选择 **历史对话管理**；
3. 在页面右上角点图标，选择 **批量删除对话**；
4. 勾选需要删除的对话，点 **删除**，在弹窗里确认。

删除前先想清楚，**批量删除同样不可恢复**。如果你的对话里有想留的成果（文档、PPT），先另存。

## 四、删了对话，豆包为什么还「记得」

豆包有记忆功能：会把你聊天中提到的兴趣、偏好等整理成记忆，作为以后回答的背景。官方 FAQ 明确说：

- **仅删除聊天记录，不代表删除了豆包在这些聊天中记住的内容**；
- **仅关闭记忆开关，也不会自动删除已有记忆**，以后重新打开，没删的记忆会再被参考。

想真正清掉，在客户端 **设置 → 记忆** 里操作：

| 想做什么 | 做法 |
| --- | --- |
| 删单条记忆 | 在记忆页面左滑单条删除 |
| 删全部记忆 | 点页面右上角「···」删除全部 |
| 在聊天里让它忘 | 直接对豆包说「请忘记……」 |
| 不再记新内容 | 关闭记忆开关（关闭后也不再响应「请记住」） |

两点提醒：记忆删除后，需要一定时间才会停止被参考，不是实时生效；如果你删光记忆但开关仍然开着，豆包还会形成新的记忆。

另外，从聊天中提取的是文本内容，官方说明不包括你上传的图片、文件、链接和视频通话画面。

## 常见问题

**Q：能一键清空所有历史对话吗？**
官方这几篇文档没有写这个入口。豆包工作桌面端可以用批量删除一次选多条；主应用按隐私政策只写了逐个删除。

**Q：删除后对方的分享链接还能打开吗？**
官方这几篇文档没有说明，如果你之前分享过对话链接，删除前建议先确认。

**Q：想把对话导出留存？**
官方这几篇没有写导出方法，需要留存的话，可以先把重要内容复制保存，再删除。
