## 适用于谁

- 搜「ChatGPT 官网」出来一堆结果，不知道哪个是真的人；
- 想在手机或电脑上装官方 App，担心下到山寨应用的人；
- 收到一封自称来自 OpenAI 的邮件，想确认真假的人；
- 帮家人、同事装 ChatGPT，想要一份可以照着核对的清单的人。

## 结论先说

1. **ChatGPT 官网：`chatgpt.com`**。开发 ChatGPT 的公司是 OpenAI，公司官网是 **`openai.com`**。
2. **官方 App 的发布者都是 OpenAI**。在 App Store 和 Google Play 里，官方建议搜索「**openai chatgpt**」，并确认发布者是 OpenAI。
3. **桌面应用**从 `chatgpt.com/download` 下载；Windows 版也在 Microsoft Store 上架。
4. **官方邮件**只会来自 `openai.com` 及其子域名（下文有完整清单）。
5. 判断真假最可靠的一条：**看浏览器地址栏里的域名**，而不是看页面长得像不像。

## 一、官方网站有哪些

| 域名 | 用途 |
| --- | --- |
| `chatgpt.com` | ChatGPT 网页版，聊天、设置、订阅管理都在这里 |
| `openai.com` | OpenAI 公司官网；新闻在 `openai.com/news` |
| `help.openai.com` | 官方帮助中心与客服入口 |
| `status.openai.com` | 服务状态页，查是否有故障 |
| `platform.openai.com` | 开发者平台（API Key、API 账单） |
| `auth.openai.com` | 登录时会跳转到的身份验证域名 |

补充两点：

- `chat.openai.com` 是早期的 ChatGPT 网址，官方的网络放行清单里仍然列着它，属于官方域名；
- 官方说明 ChatGPT 是**可以免费使用**的，而且在支持的国家和地区，打开 chatgpt.com **不注册也能直接试用**（未登录时一次只能有一个对话，聊天记录不会保存）。

所以，遇到一打开就要求先付费、域名又不在上表里的「ChatGPT 官网」，就要当心了。带有「ChatGPT」字样但域名不属于上表的网站，是第三方做的，不是 OpenAI 的官方服务。

## 二、官方 App 怎么认

![各平台 ChatGPT 官方应用下载入口对照图](seed:g859-official-apps.png)
*图：本站根据 [OpenAI 帮助中心：Verifying Communications from OpenAI](https://help.openai.com/en/articles/11725090-verifying-communications-from-openai) 与各平台下载说明整理的示意图*

**iPhone / iPad**

- 打开 App Store，搜索「openai chatgpt」；
- 确认发布者是 **OpenAI**；
- 官方直达链接的应用编号是 `id6448311069`（apps.apple.com/app/openai-chatgpt/id6448311069）；
- 官方对图标的描述：**白色背景上的黑色 OpenAI 标志**。

**安卓**

- 打开 Google Play 商店，搜索「openai chatgpt」；
- 确认发布者是 **OpenAI**；
- 官方应用的包名是 `com.openai.chatgpt`（play.google.com/store/apps/details?id=com.openai.chatgpt）。

官方只提供了 Google Play 这一个安卓下载入口。从其他地方得到的安装包，官方无法保证是原版。

**Mac / Windows**

- 官方下载页：**`chatgpt.com/download`**。页面会自动识别你的 Mac 是 Apple 芯片还是 Intel 处理器，给出对应的安装包；
- 2026 年 7 月 9 日起，新版桌面应用把 Chat、Work 和 Codex 合在一起，支持 macOS 和 Windows；之前的 Mac 应用改名为 **ChatGPT Classic**，仍然可用；
- Windows 版在 **Microsoft Store** 也有上架；
- 系统要求、安装步骤见 [/guides/chatgpt-desktop-app](/guides/chatgpt-desktop-app)。

官方 App 只在支持的国家和地区的应用商店提供，范围见 [/guides/chatgpt-supported-countries](/guides/chatgpt-supported-countries)。手机 App 的用法见 [/guides/chatgpt-mobile-app-tips](/guides/chatgpt-mobile-app-tips)。

## 三、官方邮件长什么样

官方列出的邮件域名：

- `@openai.com`
- `@email.openai.com`
- `@mail.openai.com`
- `@tm.openai.com`（工作区邀请、GPT 邀请等，发件人是 `noreply@tm.openai.com`；登录验证码也会从这个域名发出）
- `@sales.openai.com`
- `@ads.openai.com`
- `@c-openai.com`

另外，登录验证码还可能来自 `otp@tm1.openai.com`，台湾地区的电子发票来自 `noreply@tax.openai.com`，它们都是 `openai.com` 的子域名。

看邮件真假时注意两个细节：一是看 **@ 后面的完整域名**，像 `openai.com.xxx.com`、`0penai.com` 这种都不是；二是**不要点邮件里的登录链接**，自己在地址栏输入 chatgpt.com 再登录最稳妥。

## 四、防假冒检查清单

![辨别 ChatGPT 假冒网站、假冒应用和假客服的检查清单](seed:g859-anti-phishing-checklist.png)
*图：本站根据 [OpenAI 帮助中心：Verifying Communications from OpenAI](https://help.openai.com/en/articles/11725090-verifying-communications-from-openai) 整理的示意图*

1. **看域名**：地址栏是不是 `chatgpt.com` 或 `openai.com` 的子域名；
2. **看发布者**：应用商店里的开发者是不是 OpenAI；
3. **看邮件域名**：是不是上一节清单里的域名；
4. **社交平台不谈账号**：官方说明，绝不会在社交平台上讨论你的账号细节；有账号私信你要登录信息或说要帮你处理账号，不要回应；
5. **官方不会主动来电**：OpenAI 不会主动给你打电话或发起聊天；
6. **不交出密码和验证码**：官方客服指引里明确写着不要发送密码和一次性验证码；
7. **付款只在官方页面**：官方提醒不要把银行卡信息输入到 ChatGPT 的对话里，付款使用指定的安全支付页面。

已经在可疑页面输过密码的，马上改密码、开两步验证、登出所有设备，步骤见 [/guides/chatgpt-suspicious-activity-alert](/guides/chatgpt-suspicious-activity-alert)。

## 常见问题

**Q：ChatGPT 有中文官网吗？**
没有单独的中文域名。官网就是 chatgpt.com，界面语言可以在设置里改成中文，见 [/guides/chatgpt-language-settings](/guides/chatgpt-language-settings)。

**Q：ChatGPT 有官方 App 吗？**
有，iOS、安卓、macOS、Windows 都有，发布者均为 OpenAI。

**Q：微信小程序、公众号里的「ChatGPT」是官方的吗？**
OpenAI 帮助中心列出的官方渠道里没有这些。官方渠道以本文第一、二节的清单为准。

**Q：1-800-ChatGPT 是真的吗？**
是。官方说明这是一个实验性功能，可以通过电话或 WhatsApp 向 1-800-CHATGPT（+1 (800) 242-8478）提问，不需要账号。它和客服不是一回事，联系客服见 [/guides/chatgpt-contact-support](/guides/chatgpt-contact-support)。

**Q：怎么举报假冒 OpenAI 的网站或账号？**
官方提供了内容举报表单（openai.com/form/report-content），商标仿冒另有专门的表单。
