## 适用于谁

- 对话里突然看到「记忆已满」（Memory full）之类的提示，新内容记不进去了；
- 想在清空记忆之前先留一份备份；
- 打算换号、换到 Claude / Gemini，想把 ChatGPT「了解你的那部分」带过去；
- 不想让 ChatGPT 记住任何东西，想彻底关掉。

本文按 Plus 账号的界面来写，Free 账号的入口基本相同，但可用的记忆功能可能更少（待实测）。

## 结论先说

1. ChatGPT 的「记忆」其实有两层：**已保存的记忆**（一条条能看到、能删的事实）和**参考聊天记录**（从过往对话里自动提炼、不逐条展示的上下文）。「记忆已满」说的是前者。
2. OpenAI 在 2026 年上线了记忆**自动整理**：会把更常用、更新的内容放在前面，把不常用的移到「后台」，目的就是减少「记忆已满」。所以现在遇到满了的情况比以前少，但仍建议定期清理。
3. 正确顺序是：**先导出 → 再清理 → 需要的话迁移 → 不想用就关闭**。删除是不可恢复的，别跳过第一步。

## 步骤

### 第一步：看看现在记住了什么

打开 ChatGPT，点左下角头像 → **设置** → **个性化**，找到「记忆」区域。这里一般有「参考已保存的记忆」「参考聊天记录」两个开关，以及一个「管理」按钮。

【截图：设置 → 个性化 → 记忆 区域】

点「管理」会弹出一个列表，每条是 ChatGPT 记下的一句话，比如你的职业、写作偏好、常用语言等。

【截图：「管理记忆」弹窗】

### 第二步：先导出备份

官方目前**没有**「一键导出记忆」的按钮，可以用两种方式组合备份：

- **让 ChatGPT 自己列出来**：新开一个对话，发「请把你记住的关于我的所有信息逐条列出来，保持原意，不要概括」。把回复复制到本地文档。这份是「已保存的记忆」最直观的备份。
- **导出账号数据**：设置 → **数据控制** → **导出数据**。系统会把一个 ZIP 下载链接发到你的邮箱，里面是聊天记录等账号数据。注意它导出的是**对话原文**，不是整理好的记忆，但以后想重建记忆时可以当素材。

【截图：设置 → 数据控制 → 导出数据】

### 第三步：清理

在「管理记忆」列表里：

- 过时的（比如旧工作、旧项目）、重复的、说错的，点单条右侧的删除图标；
- 想从头来过，用列表底部的「清除」把全部已保存记忆删掉。

也可以直接在对话里说「忘掉我之前说过的 XX」，ChatGPT 会删除对应记忆。删完回到列表确认一下是否真的没了。

一个实用建议：把真正长期有效的偏好（语气、格式、身份背景）写进**自定义指令**（设置 → 个性化里的「自定义 ChatGPT / 自定义指令」），不占记忆位置；把某个课题、某个客户的资料放进**项目**，不要全部堆进全局记忆。

### 第四步：迁移到别的地方

- **换 ChatGPT 账号**：把第二步得到的清单，挑出想保留的内容，在新号里说「请记住：……」，或者直接粘进自定义指令。
- **搬到其他 AI**：Claude、Gemini 等产品都提供了导入或粘贴「关于我」信息的入口。把清单整理成一段「我是谁、我的偏好、我在做什么」的说明粘进去即可。各家入口位置不同，以对方官方帮助为准。
- **只想在某个课题里用**：新建项目时可以选择「仅项目记忆」，这样项目内的对话互相参考，但不会和全局记忆混在一起。

### 第五步：关闭记忆

- **完全关闭**：设置 → 个性化，把「参考已保存的记忆」和「参考聊天记录」都关掉。关闭后 ChatGPT 不再使用、也不再新增记忆；但**已保存的内容不会自动删除**，想删干净还要回到第三步清除。
- **只是这一次不想被记**：用**临时聊天**。临时聊天不会使用记忆，也不会产生新记忆，不会出现在历史记录里。

## 常见问题

**Q：提示满了，但我没手动让它记过东西？**
A：ChatGPT 会在觉得有用时自动保存一些信息。可以在对话里明确说「这段不要记」，或者在「管理」里定期删。

**Q：删掉记忆后，它为什么还「知道」我？**
A：大概率来自「参考聊天记录」。那部分不是逐条显示的，要关掉对应开关，或删除相关的历史对话。

**Q：记忆最多能存多少条？**
A：官方没有公布具体上限（待实测）。现在有自动整理机制，满的概率比以前低。

**Q：Free 号有记忆吗？**
A：有基础的记忆功能，但部分能力按套餐和地区分批开放（待实测）。如需开通 Plus，可前往 /chongzhi/chatgpt-plus。
