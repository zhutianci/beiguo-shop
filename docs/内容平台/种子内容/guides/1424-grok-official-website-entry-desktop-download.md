## 适用于谁

- 搜「grok官网入口」，想确认哪个是官方地址的人；
- 搜「grok下载电脑版」，想知道有没有 Windows、Mac 客户端的人；
- 分不清 Grok、Grok in X、Grok Bot 的人。

## 结论先说

1. **官方网页版是 [grok.com](https://grok.com)**。官方产品页写的是：在网页打开 grok.com，或下载 iOS 和 Android App，「Free to try」，免费可以试用。
2. **手机**：产品页给出了 iOS（App Store）和 Android（Google Play）的 Grok 应用链接。
3. **在 X 里使用**：官方称为 Grok in X，入口是 x.com/i/grok；在 X 内使用的权益由 X 平台决定。
4. **没有看到电脑版 Grok 聊天的安装包**：官方产品页的入口列表里没有 Windows 或 Mac 的桌面安装包，用电脑直接打开 grok.com 即可。官方建议在 Chrome 或 Chromium 浏览器里使用 grok.com，不要用 grok.x.ai（见 [/guides/grok-how-to-use-x-account-weekly-usage](/guides/grok-how-to-use-x-account-weekly-usage)）。
5. 官网另有 **Grok Bot**，是智能体产品，和聊天不是一回事，它的页面提供了 Linux 安装包。

## 二、「电脑版」到底有没有

- **聊天**：官方产品页只写了网页和手机 App，**没有列出桌面客户端**。电脑上最直接的做法就是用浏览器打开 grok.com。
- **Grok Bot**：官方说明它是一组在你的工具里干活的 AI 智能体，在共享的云端电脑上运行。页面提供了 Linux 的安装包（.deb、AppImage 或 .rpm，x64 和 arm64），页面 FAQ 提到可以在 macOS 或 Windows 桌面使用，但没有给出直接的下载链接。想了解它，请直接看官方页面。

所以搜到的「Grok 电脑版下载」，如果不是来自 x.ai 或 grok.com，先不要下载。

## 三、怎么辨别假冒

![想在电脑上用 Grok](seed:g1424-desktop-decide.png)
*图：本站根据 [Grok 官方产品页](https://x.ai/grok) 整理的示意图*

官方没有写专门的防假冒说明，下面是通用做法：

1. 只认 **grok.com**、**x.ai**、**x.com** 这几个域名；
2. 应用只从官方产品页给的应用商店链接进入；
3. 不推荐任何第三方「Grok 中文版」「镜像」「破解版」，本文也不给出这类链接；
4. 不在陌生页面输入 X 账号、邮箱密码；
5. 已经运行过不明程序：改密码并用杀毒软件检查。
