## 适用于谁

- 搜「秘塔ai搜索怎么用」「秘塔搜索官网」「秘塔搜索网页版入口」的人；
- 查资料时受够了广告和营销号，想要一个直接给答案并带来源的搜索工具的人；
- 写论文、做行业研究，需要找文献和研报的学生和职场人。

本文根据秘塔 AI 搜索官网网页版（未登录状态下可见的界面）和 App Store 官方页面整理，资料核对于 2026-10-11，入口名称以实际界面为准。

## 结论先说

1. **官方入口是 metaso.cn**，由上海秘塔网络科技有限公司运营；手机有同名 App，官网左下角有「手机端」入口。
2. **它是「搜索 + 归纳」**：官方介绍会给出直接、结构化的答案并附引用来源，还能自动生成大纲、脑图和相关人物 / 事件表格。主打「没有广告，直达结果」。
3. **搜索强度三档**：简洁、深入、深度研究。越往后越慢，也越全面。
4. **搜索范围可切换**：全网、文库、学术、播客等。找论文切学术，找研报和课件切文库。
5. **App 免费，含内购**。App Store 页面列出了会员和积分等内购项目，具体权益以官方页面为准。

## 步骤

### 1. 打开网页版

浏览器打开 metaso.cn。未登录也能看到完整的首页，左上角是「登录 / 注册」。

![秘塔 AI 搜索网页版首页（未登录状态）：输入框上方是学点啥、视频生成、幻灯片、上传文件、API 等入口，输入框左下可切换搜索范围，下方是简洁 / 深入 / 深度研究三种模式](seed:g494-metaso-web-home.jpg)
*图片来源：[秘塔 AI 搜索 metaso.cn](https://metaso.cn/)，截取于 2026-10-11*

界面上的几个区域：

- **左侧栏**：主页、专题、今天学点啥、书架、设为默认、历史记录；
- **输入框上方**：学点啥、视频生成、幻灯片、上传文件、API，右侧「…」里还有事实核验等功能；
- **输入框左下**：搜索范围（默认「全网」）；
- **输入框下方**：简洁、深入、深度研究三个模式。

输入框的提示写着：回车发送，Shift + 回车换行，输入「/」打开自定义技能。

### 2. 选搜索强度

| 模式 | 适合 | 特点 |
| --- | --- | --- |
| 简洁 | 查一个事实、一个定义、一个数字 | 最快，答案短 |
| 深入 | 需要背景、多角度说明的问题 | 更长、更结构化，带大纲和脑图等整理形式 |
| 深度研究 | 开放性、需要多步推理和大量资料的课题 | 最慢，会进行更多轮搜索和分析 |

日常用「深入」就够；只想确认一个事实用「简洁」；写报告前的摸底用「深度研究」。

### 3. 选搜索范围

点输入框左下的「全网」切换。按官方介绍和界面选项：

- **全网**：普通网页搜索，覆盖面最广；
- **学术**：来源聚焦专业期刊和学术数据库，会直接给出论文摘要等关键信息，并提供规范格式的参考文献；官方介绍还可以自行配置中英文数据库；
- **文库**：搜索全网文档——行业研究报告、学术论文、学习课件等，支持查看和下载；
- **播客**：在播客内容里搜索；
- 列表里还有图片等其他范围，以实际界面为准。

### 4. 把问题问清楚

搜索类工具的提问要点是**给限定条件**：

```
2024 年以来中国 60 岁以上人口的数量和占比变化，只采用国家统计局和政府公报的数据，
按年份列表，并注明每个数字的出处。
```

```
（学术范围）近五年关于「间歇性禁食对二型糖尿病患者血糖控制」的随机对照试验，
列出样本量、干预方式、主要结论，按发表年份排序。
```

答案出来后做两件事：点开引用看原文是否支持这句话；对关键数字换一个来源交叉核对。

### 5. 追问和整理

- **追问**：结果页一般可以继续提问，接着上一轮往下查；
- **看结构**：深入模式的结果通常带大纲、脑图和相关事件 / 组织 / 人物表格，用来快速把握全貌；
- **导出**：官方介绍支持一键复制和导出搜索结果，可导出 Word、PDF 文档，也可以转到秘塔写作猫继续编辑。

### 6. 上传文件、幻灯片和「学点啥」

输入框上方的这几个入口，官方页面在未登录状态下只展示了名称，下面是从名称和官方介绍能确定的部分：

- **上传文件**：让它基于你上传的文档来回答问题。App Store 的内购项目里有「知识库额度」，说明长期存放资料有额度概念，具体以登录后的说明为准；
- **幻灯片**：生成演示文稿的入口；
- **学点啥 / 今天学点啥**：偏学习场景的入口，适合想系统了解一个主题的时候试试；
- **视频生成**：首页横幅提示其视频生成已支持 30 秒，属于创作功能；是否消耗积分以页面提示为准。

这几项的具体操作以登录后的界面为准。

### 7. 开发者：搜索 API

首页的「API」入口进入开放平台，页面显示提供搜索、读取网页、问答三类接口，并已支持 MCP 协议，可以把秘塔的搜索能力接到自己的应用或 AI 助手里。使用前需要在该页面创建 API Key，计费方式以页面说明为准。

## 常见问题

**Q：秘塔 AI 搜索是免费的吗？**
基础搜索可以免费使用。App Store 页面显示应用免费、含 App 内购买，内购项目包括月度 / 年度会员、积分、知识库额度和搜索额度等。免费用户每天能用多少次深入或深度研究，官方页面在未登录状态下没有写明，以登录后的提示为准。

**Q：秘塔是哪家公司的？**
上海秘塔网络科技有限公司，它还做了写作工具「秘塔写作猫」。

**Q：和直接问聊天类 AI 有什么区别？**
秘塔以搜索为核心，每个答案都基于实时搜到的资料并标出来源；聊天类 AI 更擅长写作、改写和推理。查事实、找资料用搜索，加工内容用聊天助手，两者配合用。

**Q：搜到的内容可以直接引用吗？**
引用时回到原始来源（论文、报告、官方网页），不要把 AI 的归纳当作出处。学术范围给出的参考文献条目也要逐条核对是否真实存在、信息是否准确。

**Q：怎么把秘塔设成浏览器默认搜索？**
左侧栏有「设为默认」入口，点开后按页面提示操作。

**Q：结果不准或跑题怎么办？**
加上时间、地域、来源类型等限定词重搜；换到更合适的搜索范围（比如找论文别用全网）；复杂问题拆成几个小问题分别搜。
