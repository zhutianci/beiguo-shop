## 适用于谁

- 搜「vidu怎么用」「vidu ai 教学」「vidu 是哪个公司的」「vidu 参考生视频」，第一次用 Vidu 的人；
- 想让同一个角色在多条视频里长得一样，听说 Vidu 的「参考生视频」适合做这件事的人。

本文根据 Vidu 官网（vidu.cn）的页面说明文字和 Vidu 开放平台文档整理，资料核对于 2026-10-11。起草时没有登录查看完整的创作界面，界面相关的说法取自官网页面里的说明和提示文字，**菜单名、模型名以你实际看到的界面为准**；开放平台文档里的参数限制是给开发者的，网页端可能略有不同。

## 结论先说

1. **官网是 vidu.cn**，另有 Vidu App。官网介绍 Vidu 是北京生数科技股份有限公司联合清华大学发布的视频大模型。
2. **视频有三种做法**：文生视频（只写文字）、图生视频（一张首帧，或首帧加尾帧）、参考生视频（给几张参考图，让里面的人和物出现在新视频里）。
3. **参考生视频是 Vidu 的特色**：不用先做首帧图，上传角色、物品、场景的参考图，再用文字描述剧情，就能生成主体一致的视频；常用的角色可以存进主体库。
4. **模型按 Q 系列区分**：核对时官网主推 Vidu Q4 和 Q3，各模型支持的功能、时长和清晰度不同。
5. **生成消耗积分**，页面提示生成失败积分退回；价格和套餐以官网为准。

## 步骤

### 1. 打开官网，进入创作页

浏览器打开 vidu.cn，点「立即体验」或「去创作」并登录。按核对时的页面文字，「产品功能」下列出了这些入口（以实际界面为准）：

- **参考生视频、图生视频、文生视频**：三种视频生成方式；
- **参考生图、文生图片**：图片生成；
- **Vidu Agent**：从一句话到完整作品的智能创作助手；
- **AI 工具、AI 模版**：单项工具和一键套用的特效模板。

手机上可以下载 Vidu App，官网的介绍是「一站式协同创作 App」。

### 2. 文生视频

选「文生视频」，在输入框里描述画面，再设置时长、分辨率、比例等参数后生成。提示词写清四样东西：谁、在做什么、在哪里、镜头怎么拍。

```
雨后的老街，一个撑着红伞的女孩从远处走来，路面积水映出霓虹灯，
镜头低机位缓慢后退，电影感
```

开放平台的介绍里提到，Vidu 的文生视频除了通用风格，还专门优化了动漫风格。想要动画效果，可以在提示词里直接写明画风。

### 3. 图生视频与首尾帧

选「图生视频」，上传一张图作为**首帧**；界面上的第二个位置是「**尾帧（可选）**」，传了就是首尾帧模式，Vidu 会生成从第一张到第二张的过渡。

- 图片格式：开放平台文档写的是 PNG、JPEG、JPG、WebP，单张不超过 50MB；
- 首尾帧两张图要「差不多大」：文档要求两张图的分辨率相近，比值在 0.8 到 1.25 之间；
- 官网的建议是使用清晰度高、主体明确、光线良好的图片，提示词保持简洁聚焦，避免画面跳动；图片模糊，生成的视频也会不清晰；
- 提示词只写画面里的东西怎么动、镜头怎么动。

按开放平台的模型地图，首尾帧不是每个模型都有：Q3 系列里的 Pro 和 Turbo 支持，Q4 预览版标注为暂不支持。在网页端选了尾帧后如果模型被自动切换，就是这个原因。

### 4. 参考生视频：让角色保持一致

这是很多人用 Vidu 的原因。它的逻辑是：**你给「演员」和「道具」，Vidu 负责拍**。

1. 选「参考生视频」；
2. 上传参考图。官网功能说明写的是 1～7 张，可以是自己的图，也可以从素材库里选；开放平台文档里，Q4 预览版的上限是 15 张图，还可以加最多 3 段参考音频；
3. 写提示词，说明每个参考分别是什么、在视频里做什么；
4. 设置比例、时长、分辨率后生成。

官网首页展示的参考生视频提示词，结构值得照着学：先声明「以参考图中的某某为唯一主体，保持面部、服装、道具一致」，再写总时长和比例，然后按时间段写镜头——

```
以参考图中的宇航员为唯一主体，保持面部、宇航服和头盔的一致性。10 秒，16:9，电影感。
0–3 秒：头盔面罩特写，面罩上映出星光。
3–7 秒：切到侧面中景，宇航员沿着舱壁缓慢向前移动。
7–10 秒：切到正面远景，宇航员朝镜头挥手。不新增其他人物和字幕。
```

**主体库**：经常要用的角色、物品或场景，可以创建成「主体」。页面的提示是上传一个人物、物体或场景的 1～3 张图片来创建，并可以「保存到主体库」方便下次使用；之后在提示词里用 @ 加名称调用。上传真人照片前，确认是本人或已取得授权。

### 5. 选模型和参数

按 Vidu 开放平台的模型地图（核对于 2026-10-11）：

| 模型系列 | 清晰度 | 时长 | 支持的生成方式 |
| --- | --- | --- | --- |
| Vidu Q4（预览版） | 540p 到 4K | 3～16 秒 | 图生视频、参考生视频 |
| Vidu Q3 | 540p 到 1080p（部分为 720p 起） | 多数为 1～16 秒 | 按具体型号分别支持文生、图生、首尾帧、参考生视频 |
| Vidu Q2 | 540p 到 1080p | 1～10 秒 | 按具体型号分别支持 |
| Vidu Q1 | 1080p | 5 秒 | 文生、图生、首尾帧、参考生视频 |

这是开放平台的规格，网页端的可选项和叫法（比如专业版、快速版）以界面为准。文档还说明 Q3、Q4 支持音画同出，即生成时直接带上台词和音效，可以在参数里开关。

其他常见参数：**运动幅度**控制画面动得多不多；**数量**决定一次生成几条。

### 6. 积分、闲时模式与下载

- **积分**：每次生成按模型、时长、清晰度消耗积分。页面提示「生成失败，积分已退回」，取消任务同样退回；
- **闲时模式**：页面的说明是任务在流量低峰时执行，排队更久但不消耗积分；能不能用、每天能提交多少，以界面和套餐说明为准；
- **下载**：下载选项里有带水印和无水印两种，各自是否可选以界面和套餐说明为准；
- 套餐价格和每档权益变化快，本文不列，以官网「订阅套餐」页为准。

## 常见问题

**Q：Vidu 是哪个公司的？**
生数科技。官网写明 Vidu 由北京生数科技股份有限公司联合清华大学发布。

**Q：参考生视频和图生视频有什么区别？**
图生视频是把你上传的那张图当作第一帧，视频从这个画面开始动；参考生视频只是「参考」图里的人和物，构图和场景由提示词重新安排，所以同一组参考图可以拍出很多不同的镜头。

**Q：Vidu 免费吗？**
官网说明提供免费体验，具体的生成次数、分辨率和高级功能因方案而异。以登录后的账户页为准。

**Q：还能做什么？**
开放平台的功能清单里还有对口型、数字人、视频延长、智能多帧（用多张关键帧续写长视频）、智能超清等。网页端的对应入口以「AI 工具」里的实际列表为准。

**Q：和可灵、即梦怎么选？**
三者基础功能相近，Vidu 的参考生视频和主体库是它着重介绍的能力。可以用同一组素材各试一次，对比方法见《可灵和即梦哪个好用》；另一个同类工具见《海螺AI怎么用》。
