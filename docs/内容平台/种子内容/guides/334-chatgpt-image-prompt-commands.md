## 适用于谁

- 搜「ChatGPT 生图提示词」「ChatGPT 改图指令」「ChatGPT 生成图片指令总整理」的人；
- 已经会在 ChatGPT 里画图（入口和编辑器用法见《gpt-image-2 怎么用》），但总写不出想要效果的人；
- 改图时经常遇到「只想换个背景，结果人脸也变了」的人。

本文根据 OpenAI 官方 API 文档《Image prompting》（GPT Image 2.5 / 2 提示指南）和 OpenAI Cookbook 图像提示指南整理改写，资料核对于 2026-10-07。ChatGPT 里的生图当前由 ChatGPT Images 2.5 提供，这些写法原则同样适用。

## 结论先说

OpenAI 官方的总原则一句话：**先说清你要的成品，再描述主体、构图、风格和约束；改图时说清哪里要改、哪里必须不变；一次只改一件事，看完结果再继续。**

## 官方 8 条写法原则（意译）

1. **定义成品**：写明主体和用途（商品照、广告、示意图），以及构图、画幅和关键元素的位置。复杂需求可以按「场景 / 主体 / 细节 / 约束」分段写。
2. **格式随意，好维护就行**：短句、段落、类 JSON 结构、清单都能表达同样的意图，不需要什么「神秘语法」。
3. **描述看得见的细节**：材质、光线、颜色、媒介。要写实就明确写「写实照片 / 真实拍摄」，再写取景和质感。相机参数只是「风格提示」，不保证物理精确。
4. **写清人物和动作**：取景范围（「全身入镜，包括双脚」）、视线方向（「低头看着摊开的书」）、和物体的互动（「双手自然握着车把」）。
5. **文字要精确**：要出现的文字放进引号，说明位置和字体；生僻词或品牌名可以逐个字母拼出来；要求「不要多余文字」，出图后检查拼写。
6. **把「改什么」和「不改什么」分开**：改图时说「只改 X」，并列出要保留的部分：身份、几何形状、版式、光线、标签……也写明不要出现的东西，如多余文字、logo、水印。
7. **给参考图分配角色**：按编号说明每张图的用途——主体、风格、服装还是背景，以及怎么组合。
8. **有意识地迭代**：把上一张结果作为下一次输入，每次只提一个修改，并重复强调要保留的细节；画面跑偏时重申关键约束。

官方还提醒：**多轮编辑仍可能改动你想保留的细节**；如果某个区域必须像素级不变，应该把满意的修改合成回原图，而不是只靠提示词。

## 12 个常用句式

### 生成类

**① 写实照片**

```
生成一张写实的抓拍照片：[主体及外观细节]，正在[动作]。
像 35mm 胶片拍摄，[景别]、平视，50mm 镜头。[光线]，浅景深，轻微胶片颗粒，自然色彩。
画面真实不摆拍，保留真实的皮肤纹理和物品磨损，不要过度美化和修图。
```

**② 讲清流程的信息图**

```
做一张竖版信息图，讲解[流程 / 原理]，面向[受众]。
从[第一步]到[最后一步]依次展示，每一步配简短标签和箭头。
风格：干净扁平，白色背景，文字清晰易读，不要多余装饰。
```

官方提示：信息图、示意图除了看外观，还要核对标签和事实关系；文字密集时用更高的质量档位。

**③ 带精确文案的广告**

```
为[品牌名]做一张[风格]的广告图，画面是[场景]，广告语为"[文案]"。
广告语只出现一次，清晰可读，融入版面。不要其他文字、水印或无关 logo。
```

**④ 原创 logo**

```
为[行业]品牌"[品牌名]"设计一个原创、不侵权的 logo。
感觉[温暖 / 科技 / 简约]，矢量风格的干净形状，轮廓鲜明，负空间平衡，小尺寸也清晰。
扁平设计，透明背景，居中，留足边距，不要背景、棋盘格或水印。
```

**⑤ 四格漫画**

```
画一个 4 格竖版漫画。
第 1 格：[画面]；第 2 格：[画面]；第 3 格：[画面]；第 4 格：[画面]。
每格只写一个清楚的视觉节拍，动作具体。
```

**⑥ 演示文稿页 / 图表**

```
做一页 16:9 的演示文稿，标题"[标题]"。白色背景，现代无衬线字体，极简版式。
包含：[图表类型]，数据为[具体数字]；底部脚注"[来源]"；右下角留 logo 占位。
文字清晰、层级分明，不要剪贴画、库存照片、渐变和阴影。
```

官方特别说明：示例里的数据是虚构的，用于正式场合前要换成核实过的数据。

### 改图类

**⑦ 只改局部**

```
在这张照片里，只把[对象]换成[新对象]。
保持机位、室内光线、地面阴影和周围物品不变，其他部分全部保持原样。
```

![官方示例：只把餐桌旁的白色椅子换成木椅，其余陈设、光线和机位不变](seed:g334-gpt-edit-kitchen-chairs.jpg)
*图片来源：[OpenAI API 文档 · Image prompting](https://developers.openai.com/api/docs/guides/image-prompting)*

**⑧ 删除物体**

```
去掉[人物]手里的[物体]。其他任何地方都不要改。
```

**⑨ 保留人物、只换衣服**

```
用提供的服装图片给图中人物换装。不要改变她的脸、五官、肤色、体型、姿势和身份，
保持完全一致的样貌、表情、发型和比例。只替换衣服，让衣服自然贴合现有姿势，面料表现真实。
光线、阴影、色温与原照片一致。不要改背景、机位、构图和画质，不要添加配饰、文字、logo 或水印。
```

涉及真人照片时，只处理你自己或已获同意的照片。

**⑩ 多图合成**

```
把第 2 张图里的[对象]放进第 1 张图的场景中，放在[位置]，
光线、构图和背景风格与第 1 张一致。其他内容不要改变。
```

**⑪ 商品抠图（透明背景）**

```
把图中的商品抠出来，放在完全透明的背景上。商品居中，轮廓清晰，没有白边或光晕。
商品的形状和标签文字保持完全一致，只做轻微润色。不要加纯色背景、棋盘格、场景或阴影。
```

官方提醒：「画出来的棋盘格」不是真透明；API 里要设 `background="transparent"` 并输出 PNG / WebP。

**⑫ 借用风格**

```
沿用输入图片的风格（配色、质感、媒介），生成[新主体]，白色背景。
```

## 常见问题

**Q：中文提示词效果和英文一样吗？**
官方文档示例为英文。中文描述可以正常使用；涉及专业术语（镜头、材质、排版）时中英并写更稳。图中要出现中文时见《ChatGPT 生成图片中文乱码怎么办》。

**Q：为什么改了几轮之后，人脸越来越不像？**
官方说明多轮编辑可能累积偏差。每轮都重申「不要改变脸和身份」，或者回到更早的满意版本重新改。

**Q：写「不要 XX」有用吗？**
在 ChatGPT 里可以明确写排除项（官方示例里就有「不要多余文字、水印、logo」）。但更有效的是把你想要的画面描述清楚。

**Q：Free 用户能用这些句式吗？**
能。句式本身和套餐无关，区别在额度和带思考生图等功能，见《ChatGPT 生图额度与限制》。如需开通 Plus，可前往 /chongzhi/chatgpt-plus。
