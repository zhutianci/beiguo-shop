## 二、官方限制和提醒

- **价格是美元标价、不含税**，实际以下单页面为准；
- **用量每家算法不同**：Gemini 按计算量折算，每 5 小时刷新、有周上限；Grok 是每周共享用量池；ChatGPT、Claude 官方对 Plus、Pro 都写「有限额」，具体看各自的用量页；
- **订阅和 API 不是一回事**：几家都是订阅与 API 分开计费，见各家的 API 文章；
- **Grok 官方声明**订阅只通过官方渠道直接销售，不授权任何转售方。

## 常见问题

**Q：只能订一家，选哪家？**
本文不做排名。先想清楚主要用途（见上表），再看官方页面里该用途对应的功能和用量。

**Q：能不能先用免费版比一比？**
四家都有免费档，功能范围不同：ChatGPT 免费版有无限文本聊天（受限）、Claude 免费版有聊天和联网搜索、Gemini 免费版有 Flash-Lite、Grok 免费版有限量。

**Q：几家的 API 价格怎么比？**
五家官方价格放在一起的速查见 [/guides/llm-api-price-comparison-official](/guides/llm-api-price-comparison-official)。
