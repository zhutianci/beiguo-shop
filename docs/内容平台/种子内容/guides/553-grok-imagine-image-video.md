> 本文根据 Grok 官网产品页、官方 FAQ 和 xAI 开发者文档的 Imagine 部分整理，资料核对于 2026-10-11。本文只讲官方允许范围内的正常使用；生成内容须遵守官方的使用政策和你所在地的法律。

## 适用于谁

- 想用 Grok 生成图片或短视频的人；
- 搜「grok 生图」「grok imagine」「grok 生图额度」「grok 生图限制」的人；
- 生成的视频分辨率变低了、想去水印的人（结论：不能去）。

## 结论先说

1. **Imagine 是 Grok 里的生图生视频功能**：用文字或参考照片生成图片和视频，可以在同一个对话里继续改。
2. **规格**（官网产品页）：图片最高 **2K** 分辨率；视频最长 **15 秒**，功能列表里写的是文生视频最高 720p。
3. **额度**：付费用户的 Imagine 和聊天、语音、Build **共用一个每周额度池**；生成高质量视频比发一条聊天消息消耗多得多。
4. **720p 变 480p 不是故障**：官方 FAQ 写明，达到所在档位的 720p 上限后，720p 视频会**自动降为 480p**。
5. **水印去不掉**：生成的图片和视频带 Grok 水印，没有关闭选项；去除、修改或遮挡水印违反官方的可接受使用政策。
6. 官网写的是「Upgrade to SuperGrok」才有更高上限；免费档能否使用 Imagine、能用多少，以你账号界面显示的为准。

## 能做什么

| 能力 | 说明 | 出处 |
| --- | --- | --- |
| 文生图 | 用文字描述生成图片 | 官网产品页 |
| 改图 | 对生成的内容继续用文字修改、换风格 | 官网产品页 |
| 参考照片生成 | 以上传的照片为参考 | 官网产品页 |
| 文生视频 | 文字直接生成视频，带生成的音频 | 官网产品页、开发者文档 |
| 图生视频 | 上传的静态图作为第一帧，文字描述接下来发生什么；输出比例自动与原图一致 | 开发者文档 |
| 多图编辑 | API 支持一次最多 5 张源图，用于组合主体、迁移风格、合成场景 | 开发者文档（API 规格） |
| 参考图生视频、首尾帧、关键帧 | API 的新视频模型支持，用参考图固定角色、产品和场景 | 开发者文档（API 规格） |

后两行是开发者 API 的规格，网页和 App 里不一定有一模一样的入口。

## 步骤：生成一张图

1. 打开 grok.com 或 Grok App 并登录；
2. 在输入框切换到 **Imagine**（或直接在对话里要求生成图片）；
3. 写提示词。把**主体、场景、构图、光线、风格、画幅**说清楚：

```text
一只橘猫坐在木质窗台上看雨，窗外是模糊的城市夜景；
近景，浅景深，暖色室内光与冷色窗外光对比；
写实摄影风格，3:2 横幅。
```

4. 不满意就接着改，一次只改一处：

```text
保持构图不变，把时间改成清晨，窗外有薄雾，整体色调更柔和。
```

通用的生图提示词结构见本站[《AI 绘画提示词怎么写》](/guides/ai-image-prompt-formula)，[提示词库](/prompts)里也有可直接套用的模板。

## 步骤：生成一段视频

**图生视频**（更可控）：先生成或上传一张满意的静态图，再描述运动。官方文档的说明是：静态图成为第一帧，提示词描述「接下来发生什么」。所以**提示词只写运动和镜头，不必重复描述画面**：

```text
镜头缓慢向前推进；猫转头看向镜头，尾巴轻轻摆动；窗外的雨持续落下，有轻微的雨声。
```

**文生视频**：官方文档的建议是描述这个镜头，**包括运镜、光线和声音**。

```text
清晨的海边栈道，一位跑步者从远处跑近；手持跟拍，镜头略有晃动；
逆光，画面偏暖；能听到海浪声和脚步声。时长 8 秒，16:9。
```

写运动和运镜的更多句式见[《图生视频提示词怎么写》](/guides/image-to-video-prompts)和[《AI 视频运镜提示词大全》](/guides/ai-video-camera-movement-prompts)。

## 规格与限制

| 项目 | 官方信息 |
| --- | --- |
| 图片分辨率 | 最高 2K（官网产品页） |
| 视频时长 | 最长 15 秒（官网产品页；API 文档为 1–15 秒） |
| 视频分辨率 | 官网功能列表写文生视频最高 720p；API 的新模型支持 480p / 720p / 1080p |
| 分辨率回落 | 达到所在档位的 720p 上限后，自动降为 480p |
| 画幅 | API 文档列出 1:1、16:9、9:16、4:3、3:4、3:2、2:3、21:9、5:2；图生视频自动匹配原图比例 |
| 音频 | 视频带生成的音频；API 的新模型支持对口型的语音 |
| 水印 | 有，不能关闭 |

## 额度怎么算

- 付费档的 Imagine 从**每周额度池**里扣，和聊天、语音、Build 共用。官方的说法是：不同产品按所需算力计费，生成高质量视频消耗远大于聊天。
- 在 **Settings → Usage** 可以看到 Imagine 占了多少比例，以及每周重置时间。
- 用完后可以在网页购买额外额度、升级，或等重置。详见[《Grok 怎么用》](/guides/grok-how-to-use-x-account-weekly-usage)。

省额度的顺序：先用图片把画面定下来（便宜），满意后再图生视频（贵）；视频先用较低分辨率和较短时长试方向，确定了再出高规格的版本。

## 水印与合规

官方 FAQ 的原话要点：

- 生成的图片和视频带 Grok 水印，用来表明内容由 AI 生成；
- **没有去除水印的设置**；
- 一些司法辖区在法律上要求标识 AI 生成内容；
- **去除、修改或遮挡水印及其他来源标识，违反可接受使用政策**。

在国内平台发布 AI 生成的图片和视频，还要遵守平台的 AI 内容标识要求，见[《AI 生成内容怎么标识》](/guides/ai-generated-content-label-rules)。商用前请阅读官方条款，通用的版权问题见[《AI 生成图片有版权吗》](/guides/ai-image-copyright-commercial)。

## 常见问题

**Q：生成失败或被拒绝？**
提示词或参考图触发了内容政策时会被拒绝。不要尝试绕过；换成合规的描述。不要用真实人物（尤其是公众人物和未成年人）的照片做生成素材。

**Q：视频突然变糊了？**
多半是 720p 额度到上限后自动降到了 480p。到 Settings → Usage 看用量，等重置或升级。

**Q：文件存哪了，怎么删？**
官方 FAQ 有「释放存储空间 / 删除文件和素材」一节；被删除的对话和文件会在标准保留期内从系统移除，除非因法律、合规或安全原因需要保留更久。

**Q：能把人物在多段视频里保持一致吗？**
开发者 API 的参考图生视频功能就是为此设计的（用参考图固定角色、产品和场景）。网页和 App 里的做法以界面为准；跨工具的思路见[《AI 角色一致性怎么做》](/guides/ai-character-consistency)。
