> 本文根据 OpenAI 官方《使用政策》（2025 年 10 月 29 日生效版本）和帮助中心《Why was my OpenAI account deactivated?》整理，资料核对于 2026-10-14。这两份官方文件没有界面截图，配图为本站整理的示意图。本文只引用官方说法，**不能据此判断某个具体账号为什么被停用**；已经被停用的，申诉步骤见 [/guides/chatgpt-account-deactivated-appeal](/guides/chatgpt-account-deactivated-appeal)。

## 适用于谁

- 搜「ChatGPT 封号原因」，想知道哪些使用方式有风险的人；
- 刚收到官方警告邮件，不知道意味着什么的人；
- 想在日常使用中避开官方明确禁止的事项的人。

## 结论先说

1. **官方的说法是「停用」，原因主要写在两份文件里**：《使用政策》（Usage Policies）和《服务条款》（Terms of Service）。官方帮助中心说，账号停用发生在**违反使用政策或服务条款**的时候。
2. **官方列出五类原因**：违反使用政策；违反服务条款；安全问题或未授权访问；收到警告后仍重复违规；没完成身份或年龄验证。
3. **有些停用不是你做了什么，而是账号可能被别人用了**：官方说，发现可疑活动、怀疑账号被盗时，可能暂时停用来保护你，建议改密码、更换 API 密钥。
4. **多数违规会先收到警告**：官方说，对某些违规会先发出警告，给你整改的机会；警告里的期限内没有处理，可能导致停用。
5. **使用政策本身分四个方向**：保护每个人、尊重隐私、保护未成年人、赋能每个人，下面逐项概括。
6. **没有「申诉一定成功」的保证**：官方只说申诉后会尽快审核并回复；步骤见 [/guides/chatgpt-account-deactivated-appeal](/guides/chatgpt-account-deactivated-appeal)。

## 一、官方的五类停用原因

按帮助中心文章，你的账号可能因为以下一项或多项被停用：

### 1. 违反使用政策

官方列出的常见违规类型包括：裸露和性内容、儿童剥削、暴力和自残、欺骗行为与诈骗、仇恨、骚扰和垃圾信息、其他不适当或违法的内容，以及其他知识产权问题。

### 2. 违反服务条款

官方举例：规避安全或访问限制；不恰当地共享你的账号或 API 密钥；以可能伤害他人或破坏服务完整性的方式使用服务。账号共享相关的说明见 [/guides/chatgpt-account-sharing-multiple-devices](/guides/chatgpt-account-sharing-multiple-devices)。

### 3. 安全问题或未授权访问

如果系统检测到的可疑活动提示你的账号可能被盗，可能会**暂时停用**账号，防止滥用。官方建议你：**更改密码**；**更换 API 密钥**。账号安全的更多设置见 [/guides/chatgpt-account-security-mfa](/guides/chatgpt-account-security-mfa)；看到「可疑活动」类提示时见 [/guides/chatgpt-suspicious-activity-alert](/guides/chatgpt-suspicious-activity-alert)。

### 4. 收到警告后仍重复违规

官方说，对某些违规会先发出警告，给用户改正使用方式的机会。**在规定的期限内没有处理这些警告，可能导致停用。**

### 5. 没完成身份或年龄验证

有些用户被要求验证身份或年龄才能继续使用，**不完成可能被停用**。收到年龄验证要求时，要按 ChatGPT 里的说明和期限完成，见 [/guides/chatgpt-age-verification](/guides/chatgpt-age-verification)。官方还特别说明：被放进「ChatGPT for Teens」体验，本身**不会**导致账号被停用。

## 二、官方使用政策：四个方向各禁止什么

官方《使用政策》的开头说：规则不能替代法律要求、专业职责或伦理义务；对不当使用服务的行为会追究责任；**违反或规避官方的规则和安全保障措施，可能导致失去对系统的访问权限，或受到其他处罚**。以下是各方向要点的概括（原文更完整，以官方为准）：

### 保护每个人

不得把服务用于：威胁、恐吓、骚扰或诽谤；宣扬或助长自杀、自残或饮食失调；性暴力或未经同意的私密内容；恐怖主义或暴力，包括基于仇恨的暴力；开发、采购或使用武器（含常规武器和化学、生物、放射性、核及爆炸物）；非法活动、商品或服务；入侵或破坏他人的系统或财产、恶意网络活动、侵犯他人知识产权；真钱赌博；在没有持证专业人员适当参与的情况下，提供需要执业许可的个性化建议，例如法律或医疗建议；未经请求的安全测试；规避官方的安全保障措施；未经审核批准的国家安全或情报用途。

### 尊重隐私

不允许任何试图侵犯他人隐私的行为，包括未经授权汇总、监控、建立画像或散布个人的私人或敏感信息；并且绝不得用于：未经数据主体同意的人脸识别数据库；公共场所的实时远程生物特征识别；未经本人同意，以可能让人混淆真伪的方式使用其可识别形象（含照片级逼真的图像或声音）；根据社会行为、个人特质或生物识别数据对个人评估或分类；对个人在工作场所和教育环境中的情绪作出推断（出于医疗或安全原因必需的除外）；仅根据个人特质或画像来评估或预测个人实施犯罪的风险。

### 保护未成年人

服务绝不得用于剥削、危害或性化任何未满 18 周岁的人。官方会把疑似儿童性虐待材料和危害儿童安全的行为报告给美国国家失踪与受剥削儿童中心。禁止的包括：儿童性虐待材料（无论是否 AI 生成）、诱骗未成年人、让未成年人接触不适合年龄的内容、向未成年人宣扬不健康的节食或运动行为、对未成年人的体型或外貌进行羞辱、面向未成年人的危险挑战、涉及未成年人的性或暴力角色扮演、让未成年人接触有年龄限制的商品或活动。

### 赋能每个人

不允许把服务用于操纵或欺骗人们、干扰其行使人权、利用人们的脆弱性，或干扰其接受教育或获取关键服务的能力，包括：**学术不端**；欺骗、欺诈、诈骗、垃圾信息或冒充他人；政治竞选、游说、干预选举；在**没有人工审核**的情况下，自动作出敏感领域（如教育、住房、就业、金融和信贷、保险、法律、医疗、基本政府服务、移民、执法等）的高风险决策。

关于学术不端和检测的说法，见 [/guides/chatgpt-writing-detected-ai-detector](/guides/chatgpt-writing-detected-ai-detector)；关于医疗、法律类的使用边界，官方是「没有持证专业人员适当参与的个性化建议」不允许，你可以把 ChatGPT 当作整理信息、准备向专业人士提问的工具。

## 三、怎么降低被停用的风险

官方给的预防建议是：

1. **看一遍并遵守《使用政策》和《服务条款》**；
2. **保管好账号凭证和 API 密钥**，不要把它们共享给别人；
3. 开发者可以用官方的 **Moderation 端点**过滤可能违规的内容；
4. 收到年龄或身份验证、警告邮件时，**按期限处理**。

再补几条本站的提醒（不是官方原文）：给账号开两步验证，见 [/guides/chatgpt-authenticator-app-setup-lost-phone](/guides/chatgpt-authenticator-app-setup-lost-phone)；一个账号只给自己用；看到登录提醒不是你操作的，立刻改密码。

## 四、被停用了怎么办

按官方的做法：

1. **收到过通知邮件**：用邮件里的链接提交申诉，这样官方能更准确地分流并更高效审核；
2. **进不去那封邮件**：通过官方申诉表单 openai.com/form/appeal 提交；
3. **没收到邮件却进不去账号**：通过帮助中心的聊天窗口联系客服；
4. 申诉时官方列出的要写的信息：你要申诉的用户 ID 和组织 ID、与你使用情况相关的背景说明、怀疑被盗的时间范围（如有）、如发现了未授权扣款：扣款日期、金额、卡的后四位、卡品牌、发卡行、账单邮编，以及你已采取的处理步骤。

完整的申诉步骤和需要准备的材料，见 [/guides/chatgpt-account-deactivated-appeal](/guides/chatgpt-account-deactivated-appeal)；官方客服联系方式见 [/guides/chatgpt-contact-support](/guides/chatgpt-contact-support)。

## 常见问题

**Q：ChatGPT 会封号吗？官方有没有一个明确的「红线清单」？**
官方有两份文件：《使用政策》和《服务条款》。上面的概括来自使用政策，原文更完整；服务条款是另一份文件，本文只引用了帮助中心文章里提到的几个例子。

**Q：我只是问了一个敏感问题，会被封号吗？**
官方的说法是账号停用发生在违反使用政策或服务条款时，并且会对某些违规先给警告。官方没有写「问一个敏感问题就会封号」，也没有公布触发停用的具体阈值，本文不做推测。

**Q：多人共用一个账号会怎样？**
官方把「不当共享账号或 API 密钥」列在违反服务条款的例子里；同时，被检测到异常登录时也可能出现安全保护措施。账号共享的详细说明见 [/guides/chatgpt-account-sharing-multiple-devices](/guides/chatgpt-account-sharing-multiple-devices)。

**Q：被封之后订阅的钱怎么办？**
官方帮助中心的这篇文章没有讲退款，退款政策见 [/guides/chatgpt-refund-request](/guides/chatgpt-refund-request)，具体情况联系官方客服。

**Q：申诉要多久？**
官方没有给出时长，只说团队会审核并尽快回复。

**Q：怎么避免因为年龄验证被停用？**
收到要求就按界面上的说明和期限完成，见 [/guides/chatgpt-age-verification](/guides/chatgpt-age-verification)。
