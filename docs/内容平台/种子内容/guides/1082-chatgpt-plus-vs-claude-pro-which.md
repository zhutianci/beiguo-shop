## 结论先说

1. **价格是一个量级。** 两家的主力档都是每月 $20（2026-10 查询）。区别是：Claude Pro 官方有**年付**，折合每月 $17（一次付 $200）；ChatGPT Plus 官方**只有月付**。
2. **编程智能体两边都有。** 价格页写 ChatGPT Plus 的 Codex 是「扩展用量」；Claude Pro 价格页写 **Claude Code 已包含**，免费版不含。
3. **生图在套餐表上的差别：** ChatGPT 的价格页列出生图，带思考的生图从 Plus 起；Claude 价格页的套餐表没有列出内置生图。
4. **办公软件和浏览器：** ChatGPT Plus 有 Excel、Word、PowerPoint、Google Sheets 的扩展；Claude Pro 有 Claude for Microsoft 365、Outlook 和 Claude in Chrome。
5. **更高一档都从 $100 起。** ChatGPT Pro 从 $100，分三档；Claude Max 从 $100，选 5x 或 20x 用量。**两家都没有公布具体次数**，别信网上的「每天多少条」。
6. 要开通哪个，可以看 [/chongzhi/chatgpt-plus](/chongzhi/chatgpt-plus) 或 [/chongzhi/claude-pro](/chongzhi/claude-pro)。**本文不建议你为了对比同时买两个，先用免费版跑同一批任务。**

## 一、并排看官方写了什么

### 价格和计费

- **ChatGPT Plus**：$20 每月。官方说 Plus 和 Pro 不支持年付，也不能一次预付多个月；
- **Claude Pro**：按年订阅折合每月 $17（一次付 $200），按月付 $20；价格页写 Pro 的计费周期是「月付和年付」，Max 是月付。

### 编程

- ChatGPT：Codex，Plus 有扩展用量，Pro 更多，用量规则与聊天分开，见 [/guides/codex-usage-limits](/guides/codex-usage-limits)；
- Claude：Claude 价格页写 Claude Code 包含在 Pro 和 Max 里，见 [/guides/claude-code-pro-max-or-api](/guides/claude-code-pro-max-or-api)。

### 研究、办公和多模态

- 深度研究：ChatGPT 的 Deep research，Plus 为扩展；Claude 的 Research，Pro 起有；
- 办公软件：见上表；
- 图片：ChatGPT 的生图和带思考的生图见 [/guides/chatgpt-image-generation-beginner-guide](/guides/chatgpt-image-generation-beginner-guide)；Claude 能不能生成图片，见 [/guides/claude-image-generation](/guides/claude-image-generation)；
- 语音：ChatGPT 聊天里的语音，Plus 是每滚动 24 小时 3 小时；Claude 价格页写语音模式各套餐都有。

### 上下文和模型

价格页写：ChatGPT 推理模型的总窗口 Plus 是 256K；Claude 各付费档写「最长 1M，视模型而定」。两家的模型名称和档位变化很快，**以你账号里的模型菜单为准**；Claude 价格页写 Pro 包含 Opus，部分最新模型按用量积分提供。
