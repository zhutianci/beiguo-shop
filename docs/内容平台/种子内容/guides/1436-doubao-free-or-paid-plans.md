## 结论先说

1. **豆包可以免费用**。免费版有「豆包体验额度」，可以在任务模式下做企业知识问答、深入研究、图片制作、视频生成、生成 AI PPT 和表格等，**有一定的次数或时长限制，用完要等额度恢复**。
2. **付费叫「豆包订阅」，分标准、加强、高级三档**。官方写明：标准套餐额度是免费版的 5 倍，加强是 20 倍，高级是 50 倍；付费版还享有**高峰期优先使用权**。
3. **价格官方帮助中心没写具体数字**，每档下面可选不同购买时长，以购买页面显示为准（2026-10 查询）。
4. 下载页（doubao.com/download/desktop）当天写着「新用户领 30 天免费体验套餐」，在桌面端下载并登录即可，这是活动，是否还在以页面为准。
5. 入口：在豆包工作桌面端点左下角的**个人头像 > 豆包订阅**，不要在不明网站付款。

## 一、免费版和付费版到底差在哪

| | 免费版 | 付费版（标准 / 加强 / 高级） |
| --- | --- | --- |
| 能用的功能 | 体验额度内的任务模式功能 | 包含免费版全部权益 |
| 额度 | 有一定次数或时长限制 | 更多高级功能额度，按实际消耗扣减 |
| 高峰期 | 部分功能可能受限 | 优先使用 |
| 视频生成 | 只有每日免费体验次数，用完不能继续，也不计入付费额度 | 与其余高级功能共用额度 |

要注意两点：

- **服务高峰期，官方为了稳定，免费版部分功能可能受限**，不是账号出了问题；
- 免费版的视频生成不能靠「等」之外的方式续，想多生成就要升级到标准、加强或高级。

付费并不等于不限量。官方对付费用户设了 **5 小时滚动限额和 7 天滚动限额**，短时间集中高频使用也会触发，升级更高档位可以提高这两个限额。怎么看、用完怎么办，见 [/guides/doubao-quota-used-up-check-usage](/guides/doubao-quota-used-up-check-usage)。

## 二、怎么买

![自助购买豆包个人订阅的步骤](seed:g1436-buy-steps.png)
*图：本站根据 [豆包工作帮助中心：自助购买豆包个人订阅](https://www.doubao.com/work/docs/zh-cn/articles/672868468340-personal-subscription) 整理的示意图*

1. 在豆包工作桌面端登录需要购买的账号（电脑版从官方下载页获取，见 [/guides/doubao-desktop-vs-web](/guides/doubao-desktop-vs-web)）；
2. 点击左下角个人头像，选择 **豆包订阅**；也可以用帮助中心里给出的购买链接；
3. 在标准、加强、高级中选一档，再选购买时长；
4. 点击 **立即升级**，按页面提示完成支付。

官方还提到：如果你用同一个手机号注册了飞书账号，购买后订阅里的额度可以同时用于豆包功能和飞书的 AI 个人功能（智能纪要、豆包工作伙伴和妙搭）。

## 三、改套餐、取消、开发票

入口都在：个人头像 > **额度状态** > **订阅记录**，点开已购买的套餐，在订阅详情里操作。

| 想做什么 | 官方说明 |
| --- | --- |
| 变更套餐 | 点「查看所有方案」，选新套餐并支付 |
| 升级（连续订阅之间） | 新权益立即生效，首月支付套餐差价；iOS 系统支付的订单以苹果结算规则为准 |
| 降级（连续订阅之间） | 新权益不立即生效，在当前套餐周期结束后生效，差价不予退还 |
| 单月 / 单年套餐 | 支持叠加购买 |
| 取消自动续费 | 买的是连续包月或连续包年时，点「取消订阅」；取消后改为固定周期，到期不再续费 |
| 重新订阅 | 点「再次订阅」重新购买 |
| 开发票 | 订阅记录页面底部「发票管理」，在「可开票订单」里勾选订单，点「去开票」 |

## 四、买了还是用不了某个功能？

官方在常见问题里列了四种可能：

1. 当前功能不在你开通的套餐范围内；
2. 相关功能的额度或次数已经用完（各套餐中不同功能有独立额度和上限）；
3. 功能仍在逐步开放中；
4. 页面或账号状态还没刷新，重新登录或刷新后再看。

## 常见问题

**Q：买了订阅为什么还提示余额不足？**
多半是触发了 5 小时或 7 天滚动限额，或者那个功能的独立额度用完，见 [/guides/doubao-quota-used-up-check-usage](/guides/doubao-quota-used-up-check-usage)。

**Q：豆包和 ChatGPT 的会员是一回事吗？**
不是，各家独立计费。如果你要用的是 ChatGPT，开通方式见 [/chongzhi/chatgpt-plus](/chongzhi/chatgpt-plus)；Kimi 的会员档位见 [/guides/kimi-membership-plans](/guides/kimi-membership-plans)。

**Q：豆包生成图片、视频要不要付费？**
官方写免费版有体验额度可以制作图片、生成视频，但视频只有每日免费体验次数。具体功能说明见 [/guides/doubao-image-generation](/guides/doubao-image-generation) 和 [/guides/doubao-video-generation](/guides/doubao-video-generation)。
