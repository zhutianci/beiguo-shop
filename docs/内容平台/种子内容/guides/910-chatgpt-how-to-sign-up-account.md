## 适用于谁

- 第一次想注册 ChatGPT，不知道选邮箱还是 Google、Apple 的人；
- 注册时遇到「This user already exists」之类提示的人；
- 想知道注册要不要手机号、多大年纪才能用的人；
- 刚注册完，不知道先设置什么的人。

## 结论先说

1. **不注册也能试用**：官方说，ChatGPT 免费使用，在 chatgpt.com 输入框里直接提问就能开始。但没有账号时，**对话不能保存**，同一时间只能有一个对话，对话只在当前浏览器的当前会话里能看到；想保存对话，要**登录或创建账号**。
2. **注册入口**：在 ChatGPT 或 API 平台的登录页选 **Sign up**。官方提到的方式有四种：邮箱加密码，或点 **Continue with Google / Microsoft / Apple**。
3. **以后登录必须沿用同一种方式**：用 Google、Microsoft 或 Apple 注册的，要继续选对应方式；不同方式可能产生各自独立的账号和订阅，OpenAI 不会自动合并。
4. **个人使用，用自己拥有和掌控的邮箱**：官方建议个人用途用你个人拥有的邮箱，工作用另一个工作邮箱；工作邮箱由雇主控制，离职后失去访问，对应的账号和数据也会跟着丢。
5. **年龄**：官方说，ChatGPT 不适合 13 岁以下儿童，13 至 18 岁需要先取得家长同意。
6. **手机号不是注册的通用条件**：官方说，手机验证一般不是创建账号或使用 ChatGPT 的必要条件，但在 ChatGPT 桌面 App 里使用 Codex 时可能被要求验证。

## 一、先认准官方入口

注册前，先确认你打开的是官方网站和官方 App。官方在《Verifying Communications from OpenAI》里列出了官方渠道：

- 网站：openai.com；ChatGPT 在 chatgpt.com；帮助中心是 help.openai.com；服务状态是 status.openai.com；
- App：iOS 的 App Store、Android 的 Google Play，以及 openai.com 上的 Mac、Windows 下载页；
- 官方说，不会通过社交媒体私信谈论你的账号细节，**不要在社交媒体上分享登录信息**。

更多下载入口和辨别真假，见 [/guides/chatgpt-official-website-app](/guides/chatgpt-official-website-app)。

## 二、注册方式怎么选

| 方式 | 适合谁 | 要记住的 |
| --- | --- | --- |
| 邮箱 + 密码 | 想用独立的账号、不想绑定第三方 | 以后用账号上的邮箱登录；会收到验证邮件，见下文 |
| Continue with Google | 平时就用 Google 账号的人 | 以后必须继续选 Google，用同一个 Google 账号 |
| Continue with Microsoft | 平时用微软账号的人 | 以后必须继续选 Microsoft |
| Continue with Apple | 用 iPhone、Mac 的人 | 以后必须继续选 Apple；注册时若选了 Hide My Email，账号可能用 @privaterelay.appleid.com 地址 |

选哪一种，官方没有「推荐」，选你自己最不容易丢的那一种（这是本站的建议）。**无论选哪种，记下你选的是什么**：官方说，如果登录时用错了方式，会看到 Wrong authentication method 或 There is already a user with email… 这类提示。

### 邮箱注册的大致流程

官方没有逐屏写邮箱注册，只提到了几个节点：在登录页选 Sign up、填写账号邮箱、按提示完成邮件验证。收不到验证邮件，见 [/guides/chatgpt-email-verification-code-not-received](/guides/chatgpt-email-verification-code-not-received)，官方的建议包括查垃圾箱、把 noreply@openai.com 加入白名单。

### 手机号单独注册（只在部分地区）

官方有一篇讲「手机号单独注册」的文章：这种方式主要向美国、荷兰、法国、西班牙、英国、波兰、德国、日本、印度、巴基斯坦、阿尔及利亚、乌兹别克斯坦、乌克兰的新用户推出，官方写明没有计划推广到其他地区。官方还说，这类账号重置密码要通过短信，而且要在**已经登录过的设备**上操作；想开 MFA，要先添加邮箱，位置是网页上的 **Settings → Account → Email → Add**。升级到 Plus、Pro、Team 等付费订阅，仍然要验证邮箱。

## 三、年龄要求

- 官方说，ChatGPT **不适合 13 岁以下儿童**，**13 至 18 岁的人需要先取得家长同意**；
- 官方还提醒，即便是符合年龄要求的孩子，也要谨慎使用；在教育场景下，13 岁以下儿童的实际操作要由成年人完成；
- 除了注册时的年龄信息，系统还可能通过年龄预测判断账号是否属于未成年人，并自动开启青少年体验；个别地区还有强制年龄验证。这一块见 [/guides/chatgpt-age-verification](/guides/chatgpt-age-verification)。

## 四、注册时遇到提示，怎么办

![注册时遇到「This user already exists」、收不到验证邮件等提示怎么办](seed:g910-signup-errors.png)
*图：本站根据 [OpenAI 帮助中心：Why can't I log in to ChatGPT?](https://help.openai.com/en/articles/7426629-why-cant-i-log-in-to-chatgpt) 与 [Creating a new ChatGPT account after deletion](https://help.openai.com/en/articles/9019931-creating-a-new-chatgpt-account-after-deletion) 整理的示意图*

官方列出的几种情形：

1. **「This user already exists」**：通常说明你之前开始过注册但没有完成。**不要再注册一次，直接去登录**。
2. **收到欢迎邮件，但没有验证邮件**：打开 chatgpt.com/auth/login，用你注册时的方式登录，需要时登录过程会提示你激活账号。
3. **「There is already a user with email…」或「Wrong authentication method」**：你用了和当初注册不同的方式。官方说，不确定当初用的什么，就把「用户名加密码」「Continue with Google」「Continue with Microsoft」「Continue with Apple」逐个试一遍，用无痕窗口更干净。
4. **提示账号已被删除或停用**：自己删除的账号无法恢复，**至少等 30 天**才能用同一个邮箱重新注册；想早点用，可以换一个邮箱，或用邮箱别名（如果你的邮箱服务支持）。不是你自己删的，先看 OpenAI 发来的邮件，里面会说明是停用、年龄验证还是违规。删除账号的更多说明见 [/guides/chatgpt-delete-account](/guides/chatgpt-delete-account)。
5. **注册时信息填错，无法完成**：官方说，联系官方客服，在 help.openai.com 用网站上的聊天窗口发起对话。见 [/guides/chatgpt-contact-support](/guides/chatgpt-contact-support)。

## 五、注册完成后先做这几件事

![注册完成后先做的 5 件事：看账号邮箱、用自己的邮箱、保持登录、数据控制、多重验证](seed:g910-after-signup.png)
*图：本站根据 [OpenAI 帮助中心：The ChatGPT home page](https://help.openai.com/en/articles/9125172-the-chatgpt-home-page) 与 [Why can't I log in to ChatGPT?](https://help.openai.com/en/articles/7426629-why-cant-i-log-in-to-chatgpt) 等整理的示意图*

1. **确认账号邮箱和登录方式**：网页版在 **Settings → Account** 里能看到账号邮箱。记下注册用的是邮箱还是哪家第三方，以后登录不会选错。
2. **保持登录，聊天记录才会保存**：官方说，创建账号后，最近一次对话会出现在页面左侧边栏，对话才能保存和继续。
3. **了解训练设置**：官方说，默认情况下个人账号的对话会用于改进模型；要关闭，到 **Settings → Data controls**，关掉 **Improve the model for everyone**，见 [/guides/chatgpt-data-controls-privacy](/guides/chatgpt-data-controls-privacy)。
4. **开启多重验证（MFA）**：账号安全设置里可以开启，见 [/guides/chatgpt-account-security-mfa](/guides/chatgpt-account-security-mfa)。
5. **想要中文界面，调整语言**：见 [/guides/chatgpt-language-settings](/guides/chatgpt-language-settings)。
6. **接着学怎么用**：从 [/guides/chatgpt-how-to-use-beginner](/guides/chatgpt-how-to-use-beginner) 开始；想知道免费版能用多少，见 [/guides/chatgpt-free-plan-limits](/guides/chatgpt-free-plan-limits)。

之后想升级，订阅步骤见 [/guides/chatgpt-how-to-upgrade-plus](/guides/chatgpt-how-to-upgrade-plus)；套餐的区别见 [/guides/chatgpt-plans-comparison](/guides/chatgpt-plans-comparison)。

## 常见问题

**Q：注册 ChatGPT 一定要手机号吗？**
官方说，手机验证一般不是创建 OpenAI 账号或使用 ChatGPT 的必要条件。但在 ChatGPT 桌面 App 里使用 Codex 时可能被要求验证手机号；API 平台生成第一个 API 密钥也要求手机验证。验证码只能通过短信或（部分地区的）WhatsApp 发送，邮件或身份验证器不能代替这一步。

**Q：我注册时用 Apple 的 Hide My Email，邮箱不对怎么办？**
官方说，账号可能用的是 @privaterelay.appleid.com 地址，登录时选 **Continue with Apple** 并用同一个 Apple 账号。

**Q：以前有 OpenAI API 账号，还要再注册 ChatGPT 吗？**
官方说，如果你已有 platform.openai.com 的账号，可以在 chatgpt.com 用同样的登录信息直接登录；没有账号才需要在 chatgpt.com 注册。

**Q：删除账号后，可以马上用同一个邮箱重新注册吗？**
官方说，自己删除账号的，要等至少 30 天；想更早注册，可以用别的邮箱或邮箱别名。已删除账号的聊天、文件和记忆不会恢复。想换账号邮箱而不是删号，见 [/guides/chatgpt-change-email-address](/guides/chatgpt-change-email-address)。

**Q：我所在的地区能不能注册？**
官方有一份支持的国家和地区名单，见 [/guides/chatgpt-supported-countries](/guides/chatgpt-supported-countries)。本文不讨论名单之外的办法。

**Q：注册完是免费账号吗？**
官方说，ChatGPT 免费使用，另有订阅套餐。开通会员见 [/chongzhi/chatgpt-plus](/chongzhi/chatgpt-plus)。
