## 适用于谁

- 搜「通义万相怎么用」「通义万相 3.0」「通义万相 视频」「通义万相 提示词」的人；
- 用过旧版通义万相，发现入口和名字变了的人；

本文根据万相官网（未登录状态下的页面）、官网定价页，以及阿里云百炼帮助中心的两篇官方 Prompt 指南整理，资料核对于 2026-10-11。创作框里的参数选项要登录后才能操作，本文只写页面上看得到的部分，其余以实际界面为准。

## 结论先说

1. **现在叫「万相」**，入口是 tongyi.aliyun.com/wan；原来的通义万相地址会跳转到这里。最新一代是万相 3.0。
2. **一个创作框，多种做法**：全能参考、首尾帧、视频编辑、图片生成、Agent，在创作框下方切换。
3. **消耗的是「灵感值」**：登录后每日可领免费灵感值，也可以订阅会员或单独购买。
4. **官方提示词基础公式**：视频是「主体 + 场景 + 运动」，图片是「主体 + 场景 + 风格」。
5. **图生视频只写运动和运镜**，不要把图里已经有的东西再描述一遍。

### 3. 文生视频：按官方公式写

阿里云百炼的《视频生成 Prompt 指南》给出两层公式：

- **基础公式**：主体 + 场景 + 运动；
- **进阶公式**：主体（加外观描述）+ 场景（加环境描述）+ 运动（加幅度、速度）+ 美学控制 + 风格化。

其中「美学控制」指光源、光线、景别、视角、镜头和运镜，「风格化」指赛博朋克、勾线插画、黏土风格这类画面风格。

把一句话扩成进阶写法的例子：

```
基础：一只橘猫在窗台上伸懒腰。

进阶：一只毛发蓬松的橘猫趴在老式木窗的窗台上，窗外是下着小雨的青瓦屋顶；
它缓慢地弓起背伸了个懒腰，然后打了个哈欠。
近景，侧光，暖色调，镜头缓慢推近，写实电影质感。
```

官方词典里可以直接取用的类别：光源（日光、火光）、光线（柔光、硬光、侧光）、景别（特写、近景、广角）、机位（过肩、高角度、航拍）、运镜（镜头拉远、向左移动、环绕运镜）、色调（暖色调、低饱和度）、视觉风格（3D 卡通、像素风格、黏土风格）。每一类挑一个就够，堆太多会互相冲突。

### 4. 图生视频、声音与多镜头

**图生视频**：官方公式是「运动 + 运镜」。图片已经确定了主体、场景和风格，提示词只说接下来发生什么、镜头怎么动：

```
她缓缓转头看向镜头并微笑，发丝被风吹动；镜头缓慢推近。
```

**带声音的视频**：官方的声音公式是在「主体 + 场景 + 运动」后面加声音描述，分三种——人声（台词内容，加情绪、语调、语速、音色）、音效（什么东西发出什么声音）、背景音乐（配乐和风格）。不写的话模型会自己发挥；不想要台词，官方给的写法是在提示词里写「无台词」；不想要配乐同理，明确写不要背景音乐。提示词里写了「某某说：……」这样的台词，模型会保持台词内容不变。

**多镜头**：官方的多镜头公式是「总体描述 + 镜头序号 + 时间戳 + 分镜内容」。例如：

```
一支咖啡店的短广告，暖色调，生活感。
镜头 1（0–3 秒）：特写，热水冲入滤杯，蒸汽升起。
镜头 2（3–7 秒）：中景，店员把杯子递给顾客，两人相视一笑。
镜头 3（7–10 秒）：定场镜头，清晨的街角小店，招牌灯亮起。
```

想要一镜到底，就写「生成单镜头」。

**多素材参考**：用「图 1」「图 2」「视频 1」这样的说法指代上传的素材，图片和视频分别编号，再写动作、场景，台词和配乐可选。

上面的声音、多镜头、参考写法在官方指南里是针对较新的模型版本列出的，万相 3.0 均在其列。

### 5. 文生图的写法

《文生图 Prompt 指南》的公式：

- **基础**：主体 + 场景 + 风格，例如「一只戴帽子的熊猫，雨后的街道，水彩风格」；
- **进阶**：再加镜头语言（景别、视角）、氛围词（梦幻、孤独、宏伟）、细节修饰（光源位置、道具、环境细节）。

官方词典的几个类别：景别（特写、近景、中景、远景）、视角（平视、俯视、仰视、航拍）、镜头（微距、超广角、长焦、鱼眼）、风格（3D 卡通、水彩、水墨、折纸、工笔）、光线（自然光、逆光、霓虹灯、氛围光）。更通用的写法可以对照《AI绘画提示词怎么写》。

### 6. 灵感值和会员

官网定价页 2026-10-11 显示的信息：

- **免费**：可同时提交 1 个视频任务和 1 个图片任务，每日签到获赠灵感值；
- **标准会员**：每月 300 灵感值，页面说明最多可加速生成 1200 张图片或 60 个视频；可同时提交 3 个视频任务和 3 个图片任务，可生成 1080p 和 10–30 秒的视频。页面标价 72 元 / 月，默认选中的连续包年方案折合 36 元 / 月；
- **高级会员**：每月 1200 灵感值，可同时提交 8 个视频任务和 5 个图片任务。页面标价 288 元 / 月，连续包年方案折合 145 元 / 月；
- **单独购买灵感值**：最小一档是 30 灵感值 10 元，页面注明充值后有效期 2 年，不可退换、转赠或提现。

页面同时注明会员是自动续费，可随时取消，但一经支付不可退款。价格和折扣会调整，下单前以定价页为准。

## 常见问题

**Q：通义万相和万相是一个东西吗？**
是。官网页面标题现在是「万相」，旧的通义万相地址会跳转到 tongyi.aliyun.com/wan。

**Q：不充钱能用吗？**
可以。免费档每日签到有灵感值，登录提示里写的是用灵感值可加速图片与视频生成。每天送多少、一次生成消耗多少，页面没有公开固定数字，以登录后显示为准。

**Q：提示词用中文还是英文？**
官方指南写明正向提示词支持中英文，示例大多是中文，直接用中文写即可。

**Q：一句话提示词太短怎么办？**
官方接口有智能改写功能，会自动把简短的提示词扩写，对短提示词效果较好。网页端是否默认开启以界面为准；自己按进阶公式补上景别、光线和运动，结果更可控。

**Q：生成的内容能直接发到平台上吗？**
AI 生成的图片和视频发布时有标识要求，见《AI生成内容标识规定》；商用前先读一遍官网的服务协议。

**Q：有 API 吗？**
有。万相的模型通过阿里云百炼提供 API，定价页注明网页端会员与 API 是分开购买的。开通和取 Key 的做法见《千问 API Key 怎么获取》。
