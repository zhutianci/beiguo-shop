## 适用于谁

- 搜「kimi会员价格」「kimi会员多少钱」「kimi 会员 额度」的人；
- 已经订阅，想知道额度为什么掉得快、用完了怎么办、怎么关掉自动续费的人。

本文根据 Kimi 官方帮助中心「会员订阅」栏目的文章整理，价格和权益核对于 2026-10-30。**价格和权益随时可能调整，下单前以 kimi.com 会员计划页面显示的为准。**

## 结论先说

1. **现在的档位是 Go、Plus、Pro、Max、Ultra 五档**（标题里的「四档」是旧说法）：官方帮助中心列出的连续包月价格分别是 49、99、199、699、1399 元（2026-10-30 核对），连续包年另有优惠；原来的 Andante、Moderato、Allegretto、Allegro 现在叫**老套餐**，已订阅的用户保留原来的名称、规则和自动续费，不需要切换。
2. **所有会员功能共用一个额度池**，按实际 token 消耗扣除；一个功能把额度用光，其他功能也用不了。
3. **额度按月刷新，不累计**。权益有效期是订阅生效起 30 天，没用完的到期清零。
4. **取消自动续费要去当初付款的渠道操作**，取消后当期权益保留到到期日。
5. 官方说明付费服务属于虚拟服务，开通后不可退费或转让（法律另有规定的除外），所以先从低档位试起。
6. 下单时看到的名称和价格如果与本文不同，以会员计划页面为准。

## 五档怎么选

官方帮助中心列出的主要差别（2026-10-30 核对）：

| | Go | Plus | Pro | Max | Ultra |
| --- | --- | --- | --- | --- | --- |
| 连续包月 | 49 元 | 99 元 | 199 元 | 699 元 | 1399 元 |
| 连续包年（合计） | 468 元 | 948 元 | 1908 元 | 6708 元 | 13428 元 |
| Agent 额度 | 基础档 | 2 倍 | 4 倍 | 14 倍 | 28 倍 |
| 并行 Agent 任务 | 1 | 2 | 2 | 4 | 4 |
| Kimi Code | 无 | 有 | 有 | 有 | 有 |
| Agent 集群 | 无 | 有 | 有 | 有 | 有 |
| 目标模式、专属 Kimi Claw | 无 | 无 | 有 | 有 | 有 |
| 定时任务 / 小组件任务 | 各 6 个 | 各 10 个 | 各 15 个 | 各 20 个 | 各 25 个 |
| 项目数 / 存储 | 20 个 / 20GB | 20 个 / 20GB | 20 个 / 20GB | 100 个 / 50GB | 100 个 / 50GB |

各档都包含：文档与 PPT、深度研究、网站部署。Kimi Code 从 Plus 起提供，Plus 及以上是滚动 5 小时限额、没有每周限额；官方说明老套餐（Andante 及以上）仍可使用 Kimi Code，是 5 小时加每周两个限额。**年付是一次性收取全年费用**，表里的合计价是官方页面给的数字，月均只供对比。

**老套餐：** Andante、Moderato、Allegretto、Allegro 是官方现在标注的老套餐，已订阅的用户可继续使用、续费或升级。官方现在的价格页不再列它们的价格（此前 2026-10-11 核对为 49、99、199、699 元），也没有写它们和新档位的一一对应关系，所以本文不做对应。

选择思路：

- **偶尔做个 PPT、跑一两次深度研究**：从 Go 开始，不够再升（Go 没有 Kimi Code）；
- **每周都要出报告、做 PPT，或者要用 Kimi Code、Agent 集群**：Plus；
- **重度使用 Agent、要用目标模式或 Kimi Claw**：Pro；
- **要更大额度和更高并行度**：Max、Ultra。
- **K3 的 100 万 token 上下文**：官方会员概览页目前没有写哪一档提供，请以 K3 与会员计划页面为准。

升级不亏：官方说明升级时会按当前会员剩余天数折算，新权益立即生效。

## 额度是怎么扣的

- **共用额度池**：网站部署、深度研究、PPT、Kimi Code、Kimi Work、Kimi Claw、K3 和 K3 集群都从同一个池子里扣；在会话入口用 K2.6 对话同样计费；
- **按 token 扣**：任务越复杂、思考强度越高，消耗越多；
- **Kimi Code 另有限额**：5 小时和每周两个限额，只作用于 Kimi Code。

下面是 2026-10-11 官方给过的消耗参考（占月度额度的比例；深度研究一项当时注明以 Moderato 套餐为参考）。**2026-10-30 核对时，官方会员概览页已不再给每项的具体比例**，只说按实际 token 消耗扣除、因模型、工具和任务复杂度而异，以下仅作旧参考：

| 任务 | 大约消耗 |
| --- | --- |
| 一份简单的 PPT | 1–2% |
| 一次深度研究 | 5–10% |
| 一次编写代码的任务 | 0.5–2% |
| 几百字的问答 | 几百到一千 token |

省额度的办法：简单问题把思考强度调到「标准」；不需要产出文件时不必用 K3；深度研究启动前把问题想清楚，中途停止的任务也算消耗。

## 步骤

### 1. 查看用量

- **网页版**：左下角头像 → 设置 → 订阅；
- **App**：我的 → 会员计划 → 订阅。

可以看到剩余额度百分比、下次刷新时间和最近的使用明细。官方提醒明细可能有短暂延迟，以当前额度显示为准。

### 2. 额度用完了怎么办

进行中的任务可以正常完成，新任务会提示额度不足。官方给了四个选择：

1. 等待按月刷新；
2. 升级到更高档位；
3. 购买「加油包」，开启后按实际用量付费，不用等刷新；
4. 参加官方活动获取赠送额度。

### 3. 购买和升级

打开 kimi.com，点左下角头像 → 会员计划，选择档位完成支付。请只在 Kimi 官方页面或官方 App 内购买。

### 4. 取消自动续费

可以随时取消，取消后当前计费周期内权益仍然有效，到期后不再扣费。在哪里付的款就在哪里取消：

- **Kimi 内**：登录 →「设置」→「订阅管理」→「取消自动续费」或「管理订阅」→ 确认；
- **微信支付**：「我」→「服务」→「钱包」→ 右上角「账单」→ 搜索「月之暗面」→「管理扣费服务」→ 选择对应项目 →「关闭扣费服务」；
- **支付宝**：「我的」→「设置」→「支付设置」→「免密支付 / 自动扣款」→ 找到「Kimi 会员」→「关闭服务」；
- **iPhone（Apple ID 订阅）**：「设置」→ 顶部 Apple ID 头像 →「订阅」→ 找到 Kimi →「取消订阅」；
- **Mac App Store**：打开 App Store → 左下角头像 →「账户设置」→「订阅」里找到 Kimi →「管理」→「取消订阅」。

不确定当初走的哪个渠道时，翻一下支付宝、微信和 App Store 的扣款记录。

### 5. 开发票

kimi.com → 左下角头像 → 设置 → 订阅 → 账单 → 开发票。发票邮箱填错了，可以在订阅界面点对应订单的「已开票」，更新邮箱后重新发送。

## 常见问题

**Q：不开会员能用吗？**
能。免费也可以对话和体验 Agent 功能，官方帮助中心提到每月有一定的免费额度，只是量少，具体数字页面没有给出。

**Q：会员额度能当 API 用吗？**
不能。开放平台 API 是单独的按量计费产品，见《Kimi API 怎么用》。

**Q：这个月没用完的额度能留到下个月吗？**
不能，到期清零。

**Q：开通后能退款吗？**
官方说明付费服务属于虚拟服务，成功开通后不可退费或转让，除非法律另有规定。有扣费争议按帮助中心「支付相关问题」里的方式联系官方。

**Q：未成年人可以购买吗？**
官方要求未满 18 周岁的用户在监护人指导下阅读协议，并经监护人同意后才能购买。

**Q：K3 一定要开会员吗？**
K3 按额度计费，有额度就能用；100 万 token 超长上下文属于哪一档，官方会员概览页目前没有写，以官方页面为准。
