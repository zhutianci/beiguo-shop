## 每条的处理方式

- 原提示词译为中文、可替换部分改成 `[变量]`；英文 / 日文 / 中文原文完整保留在正文"原版提示词"一节（CC BY 要求注明修改，`changes` 字段逐条写明）。
- `source.url` 写原帖（X）链接；`imageCredit.url` 写 YouMind 画廊条目链接（`?id=`），作者取仓库记录的作者名。
- 示例图：只用该条目自己的图（仓库 README 中同一条目下的图片），逐张用 Read 工具目检；长边 ≤1200 的 JPEG（≤250KB），成图在前、输入图在后。
