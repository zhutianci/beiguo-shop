这里收录「ai表情包制作」的提示词：用一个角色或自己的照片，一次生成一整套表情。

**好的表情包提示词要写清楚：**
- 宫格排列，比如「3×3 九宫格，每格一个表情」
- 每格的动作和配字，比如「开心比耶『好耶』、委屈『呜呜』」
- 统一角色：发型、服装、配色每格一致
- 纯色背景（方便抠图）、粗描边、动作夸张

**选哪个模型：** 宫格加配字的用 gpt-image-2；用自己的照片做 Q 版形象的，用 Nano Banana 或 gpt-image-2。

**注意：**
- AI 说的「透明背景」常常是画出来的棋盘格，需要自己抠图
- 要上架到微信等平台，尺寸、数量、格式按平台官方规范切图
- 不要使用他人的 IP 角色、明星或他人的肖像；要上架的，以平台对原创与授权的要求为准
