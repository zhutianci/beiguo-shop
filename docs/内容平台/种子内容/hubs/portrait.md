这里收录用自己的照片做 AI 写真、风格头像的提示词，比如胶片风、杂志封面、古风、二次元头像。

**好的写真提示词有四个要素：**
1. **风格**：如胶片、港风、日系清新、油画
2. **场景与服装**：在哪里、穿什么
3. **光线与镜头**：如窗边自然光、85mm 人像镜头、浅景深
4. **保持不变的部分**：写明「保持五官和脸型与参考照片一致」

**选哪个模型：** 要像本人，用 gpt-image-2 或 Nano Banana，上传 1–3 张清晰正脸照片；不需要像本人、只要好看的风格头像，可以用 Midjourney。

**注意：**
- 只用自己的照片，或者已经得到对方同意的照片；不做名人换脸
- 吉卜力等知名动画风格仅供学习交流，商用请注意版权
- 出图不像本人时，与其加形容词，不如换一张光线更好、更正面的参考照片
