## Claude 是什么

Claude 是 Anthropic 推出的 AI 助手，可以在网页 claude.ai、桌面 App（Mac / Windows）和手机 App 里使用。2026-09-16 起，原来的「Cowork」和普通聊天合并成了一个 Claude：同一个对话里，它会判断任务需要什么，可以直接写文档、做 PPT、做设计，不用再切换到不同的入口。

## 能做什么

- **对话与写作**：长文写作、改稿、翻译、总结长文档，支持联网搜索
- **文件与项目**：上传文档和表格分析；用「项目」把相关资料和对话放在一起
- **文档 / 幻灯片 / 设计**：Claude Docs、Claude Slides、Claude Design 可以在对话中直接调用
- **Skills 与连接器**：给 Claude 装上技能包，或连接你常用的应用
- **Claude Code**：编程 agent，能读懂整个代码库、改文件、运行命令；可以在终端、VS Code / JetBrains、桌面 App 和网页上使用

## 怎么用

注册登录 claude.ai，或从 claude.com/download 下载桌面 App 和手机 App。写代码的话，安装 Claude Code 后在项目目录运行 `claude`，用同一个 Claude 账号登录即可。

## 免费与付费的区别

按官方定价页（2026-10）：

| 方案 | 主要区别 |
|---|---|
| Free | 网页、桌面、手机都能聊天；联网搜索、记忆；最多 5 个项目；可用 Sonnet、Haiku 系列；**没有 Claude Code 和 Cowork** |
| Pro | 用量更多；包含 Claude Code、Cowork、Claude Design / Slides / Docs；可用 Opus 系列；可以安排和定时执行任务 |
| Max | 包含 Pro 的全部功能，每 5 小时的用量可选 Pro 的 5 倍或 20 倍，输出上限更高 |
| Team / Enterprise | 面向团队：组织内搜索、统一付费与管理、单点登录 |

需要开通 Pro 可以看本站 [/chongzhi/claude-pro](/chongzhi/claude-pro)。
