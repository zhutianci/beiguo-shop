## 可灵是什么

可灵（Kling）是快手推出的视频生成模型和创作平台，国内有可灵 App 和网页版，海外版网址是 klingai.com。2026 年 2 月发布的 3.0 系列包括 Video 3.0、Video 3.0 Omni 和 Image 3.0 等模型；按官方博客，可灵 4.0 于 2026-09-28 开放抢先体验，10 月正式上线。

## 能做什么

| | 可灵 3.0 | 可灵 4.0（官方博客） |
|---|---|---|
| 单次时长 | 最长约 15 秒 | 3–30 秒 |
| 镜头控制 | 一次生成多个镜头 | 最多 10 个关键帧 |
| 参考素材 | 图片、视频等多模态参考 | 最多 15 个（图片、视频、主体组合） |
| 声音 | 原生音频 | 双声道立体声，口型匹配更好 |
| 画质 | — | 支持 4K、21:9 宽银幕 |

常见用法有文生视频、图生视频、首尾帧过渡、多镜头短片和带对白的口播片段，也能生成图片。

## 怎么用

- **国内**：下载可灵 App，或打开可灵网页版登录
- **海外**：klingai.com
- **开发者**：可灵开放平台提供 API

进入「视频生成」后，先选模型版本，再选文生视频或图生视频，粘贴提示词、设置时长和比例即可。

## 免费与付费的区别

可灵按积分（灵感值）消耗计费，新模型、高画质、长时长消耗更多。具体送多少、会员档位的差别，本站没有找到可引用的官方说明，请以 App 内的会员页面为准。

## 本页的提示词怎么用

做视频时，提示词里写清景别（特写、中景、全景）和运镜（推、拉、摇、跟），比只写画面内容更好控制。多镜头条目会按「镜头 1 / 镜头 2」分段，可以整段粘贴后，只替换方括号里的角色和场景。
