# AI 学习平台改版 + 种子内容（2026-10-06）

> 分支 `feat/content-platform`，**未上线**。与 P0、P1 一起部署（见 [P0-部署说明](P0-部署说明.md)、[P1-部署说明](P1-部署说明.md)）。
> 站长 10-06 要求：学习平台的外观与架构不沿用论坛，要更美观、高级、流畅；并先把专题介绍与各类内容整理出来。

## 一、改版做了什么

### 架构：按「学什么」组织，不再是「板块 + 帖子列表」

| 地址 | 内容 |
|---|---|
| `/learn`（新） | 学习平台首页：首屏（最新出图拼贴）→ 四个入口 → 精选提示词瀑布流 → 按模型学 → 最新教程 → 按场景找 → 创作者榜 + 投稿 |
| `/prompts`、`/prompts/m/*`、`/prompts/t/*` | 画廊式瀑布流（按真实比例排布），吸顶筛选条带条数，专题介绍卡 |
| `/prompts/{id}` | 左：效果图查看器（缩略图条、全屏灯箱、←→ 与 Esc）；右：吸顶的提示词面板（变量高亮、复制、去开通）；下：心得、相关内容、评论 |
| `/guides`、`/guides/p/*` | 编辑型目录：头条大卡 + 编号列表 |
| `/guides/{id}` | 阅读型长文：大标题与导语、测试日期 / 账号 / 阅读时长，侧栏目录（滚动高亮），顶部阅读进度条 |
| `/u/{handle}` | 作者页：大标题 + 数据行 + 作品 |
| `/forum` | 保留为「讨论」，作为学习平台的一个入口 |

顶部导航「论坛」改为 **「AI学习」→ `/learn`**，在 `/prompts`、`/guides`、`/forum`、`/u` 下都高亮。
（这会和 `seo/restructure` 的导航重排冲突，合并时以「AI学习」这一项为准。）

### 设计语言（`globals.css`「AI 学习平台」一段 + `src/components/learn/`）

- **编辑型暗色**：大字号展示标题（clamp 字阶、负字距）、充足留白、发丝细线（white/8）、一种强调渐变只用在标题关键词上。
- **卡片**：`learn-card` 低对比底色 + 细边框，悬停只提亮边框和底色（不用发光）；图片卡悬停缓慢放大。
- **流畅**：
  - 每个栏目都有 `loading.tsx` 骨架屏，点下去立即有反馈；
  - 上传时记录图片宽高（`media_assets.width/height`），瀑布流按真实比例占位，图片加载时不跳；
  - 入场动画只动 transform（**首帧可见**，09-30 iPhone 事故的教训）；
  - 阅读进度条用 rAF + scaleX，目录高亮用 IntersectionObserver；
  - 点赞是乐观更新；复制有确认态。
- **手机端**：不用 backdrop-filter；吸顶条用近乎不透明的底色；`lite:` 轻量模式与「减弱动态」都照顾到了。
- 评论区从论坛详情里拆成独立组件（`components/forum/comments.tsx`），三种内容共用。

### 数据库变更（追加到 P0 / P1 之上）

```
media_assets + width INT NULL, + height INT NULL
```

只加可空列。已有图片没有宽高时按 4:5 兜底，不影响显示。

## 二、种子内容

都在 `docs/内容平台/种子内容/`，格式与来源规则见该目录的 `README.md`。

| 类别 | 数量 | 说明 |
|---|---|---|
| 专题介绍 `hubs/` | 22 | 8 个模型、4 个产品、10 个主题。每篇附官方来源与「待核对」清单 |
| 教程 `guides/` | 12 | ChatGPT 8 篇、Claude / Codex 3 篇、ChatGPT 与 Claude 对比 1 篇。全部按官方文档原创撰写，带【截图】占位与待核对清单 |
| 提示词 `prompts/` | 24 | gpt-image-2 14 条、nano-banana 6 条、视频 4 条。其中 19 条改编自许可证允许的开源仓库（CC0 / Apache-2.0 / CC BY 4.0 / MIT），5 条原创。许可证逐个核查过，见 `prompts/_来源与许可.md` |

**来源原则**：
- 论坛 / 博客 / 知乎等的帖子一律不搬运，只提炼可核实的事实，再按官方文档重写。
- 别人的出图一张不用。
- 许可证不明或保留权利的仓库一条不用（已排除 6 个仓库，理由见 `_来源与许可.md`）。

### 导入

```bash
npx tsx scripts/build-seed-bundle.ts          # 本地：校验并编译成 prisma/seed-content.json（已生成并提交）
DATABASE_URL=... npx tsx prisma/import-seed-content.ts --author <站方编辑账号邮箱> [--dry-run]
```

- 导入是幂等的（按「类型 + slug」去重）。专题介绍只写空的，`--force-intro` 才覆盖。
- 内容**全部建成「待审」**，待办清单写在审核备注里，后台列表直接可见（出图要求、截图位置、待核对事实）。
- 改编自仓库的提示词记为「转载 / 改编」并带原链接，因此**默认不会被收录**。站长补上自己的出图和心得后，可以在后台改为原创首发，正文末尾的署名与许可证行要保留。
- 生产环境：导入脚本放在 `prisma/` 里、只依赖 `@prisma/client`。按 `db push` 的同一种临时容器方式运行，挂载 `prisma/` 目录即可。

## 三、上线前站长必须处理的（按优先级）

1. **核对几条会直接影响业务的事实**（调研中发现，均**未经官方页面确认**——openai.com 与 help.openai.com 对抓取返回 403）：
   - ~~有搜索结果称 ChatGPT Pro 自 2026-09-10 起暂停新订阅与升级~~ —— **站长 10-06 确认：Pro 已重新开放**，此条作废。
   - **ChatGPT 默认生图已是 Images 2.5**（2026-09-08 发布），gpt-image-2 仍可在 API 使用。相关教程与「GPT-Image-2」专题已按此写；要不要新增「ChatGPT Images 2.5」模型标签，由你决定。
   - **ChatGPT Agent 模式已在 2026 年 7 月退役**，由 ChatGPT Work 取代。教程 03 已改为讲 Work。
   - **ChatGPT Skills 目前似乎只对 Business / Enterprise / Edu 开放**，个人 Plus / Pro 可能没有。教程 05 已如实写明。
   - Sora 独立 App 与 API 已关停；**ChatGPT 内是否有视频生成，无法确认**，Sora 专题已如实写。
2. **出图**：24 条提示词每条都写了 `imageBrief`（要生成什么样的图、几张）。没有出图的提示词公开后会显示「待出图」，也不会被收录。
3. **实测与截图**：12 篇教程都有【截图：…】占位和 `verify` 清单。实测后在编辑页填上测试日期（没有测试日期的教程不会被收录）。
4. **提示词的版权风险**：开源仓库里的条目多半是维护者从 X 上收集的，仓库许可证未必覆盖原作者。
   我们保留了原作者与原帖链接，并做了较大改写，每条 `verify` 里都写了「确认原帖仍可访问、作者未另行声明保留权利」。
   如果要零风险，先只公开 5 条原创（01、14、22、23、24）。第 02 条来自 MIT 仓库，页面上必须保留「Copyright (c) 2025 ZeroLu, MIT License」。
