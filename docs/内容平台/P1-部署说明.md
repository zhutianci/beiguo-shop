# 内容平台 P1（提示词库 + 教程）部署说明

> 分支 `feat/content-platform`，**未上线**。与 P0 一起部署（P0 说明见 [P0-部署说明.md](P0-部署说明.md)），
> 时机同样是 `seo/restructure` 批 1 上线之后（设计 §18 第 11 条）。设计依据见 [内容平台-设计.md](内容平台-设计.md) §14 P1。

## 一、这一包做了什么

### 新栏目（全部服务端直出，只在主站开放，渠道站 404）

| 地址 | 是什么 |
|---|---|
| `/prompts` | 提示词库：效果图卡片网格，按「模型 / 主题」筛选 |
| `/prompts/m/{slug}` | 模型专题（如 `gpt-image-2` →「GPT-Image-2 提示词大全」） |
| `/prompts/t/{slug}` | 主题专题（如 `id-photo` →「AI 证件照提示词」） |
| `/prompts/{id}-{slug}` | 单条提示词：效果图在前 → 提示词全文（`[变量]` 高亮）→【复制】+ 去开通 → 心得 → 相关内容 → 评论 |
| `/guides`、`/guides/p/{slug}`、`/guides/{id}-{slug}` | 教程总览、产品专题（chatgpt / claude / codex / gemini）、单篇教程 |
| `/u/{handle}` | 作者主页（随机 8 位短码，**不用自增用户 ID**，免得暴露注册人数，同审计 G48 的理由） |

- **URL 以 id 为准**：slug 由编辑在后台填，可有可无；地址里 slug 不对、或走错了栏目（`/guides/6` 其实是提示词），一律 308 到规范地址。
  P1 之前从论坛发出去的提示词 / 教程链接（`/forum/{id}`）也会 308 到新地址。
- **发帖表单**分三种类型：讨论 / 提示词 / 教程。
  - 提示词：至少 1 张**作者自己生成**的效果图、选 1 个模型、提示词全文、适合做什么；心得可空。
  - 教程：选产品、写正文；**测试日期和账号类型必填**（模型在变，日期就是可信度）。
  - 标签只能从后台建好的策展标签里选，作者不能自己造（防止空的、题文不符的聚合页）。
- **复制计数**：同一访客、同一条、同一天只计一次（`content_events` 唯一约束，不是先查后写）。
- **转化入口**：标签上登记了落地页的（默认 GPT-Image-2 / ChatGPT / Codex → `/chongzhi/chatgpt-plus`，Claude → `/chongzhi/claude-pro`），
  内容页上出现「ChatGPT Plus 充值 →」按钮。没登记的不出，不硬塞。
- **商品详情页**新增「相关教程与提示词」（按分类 / 名称匹配 ChatGPT、Claude、Gemini），没有公开内容时整块不渲染。
- **论坛列表页**顶部加了「AI 提示词库」「使用教程」两个入口；论坛列表只列讨论帖。
- Markdown 支持**表格**（教程与对比要用）。

### 后台（`/admin/forum`）

- 新增「策展标签与专题页」卡片：建标签、写**专题介绍**、配落地页、启停。默认 22 个标签首次访问时自动补齐（8 个模型、10 个主题、4 个产品）。
- 帖子列表：类型筛选；每条显示类型、标签、「不收录的原因」；提示词 / 教程多三个按钮——「实测可用」徽章、编辑 URL 后缀 slug、编辑摘要。
- 加精时记录精选时间（精选列表按它排序）。

### 收录（仍然全关）

`INDEXING_OPEN = false`（`src/lib/content/policy.ts`）。关着时所有内容页、专题页、作者页都是 `noindex, follow`，
`/sitemap-content.xml` 是空的，robots.txt 也不挂它，IndexNow 不推。

**打开之后**（2026-10-06 本地临时打开实测过）：
- 每条内容按类型过门槛：提示词要有模型、≥1 张图、提示词 ≥20 字（只有 1 张图时心得 ≥50 字）；教程要有测试日期、正文 ≥600 字；讨论 ≥300 字或 ≥3 条回复。
  另外都要「原创首发」「正文不是 AI 主笔」「已过审」。
- 专题页要**有站方写的介绍（≥200 字）**，且可收录条目够数（模型 / 产品 ≥3，主题 ≥8，总览 ≥5）。
- `/sitemap-content.xml` 只列合格的地址，提示词带 `image:image`；robots.txt 挂上它；过审、精选、改 slug、实质编辑、删除时推 IndexNow（复用新闻流水线那套 `lib/indexnow.ts` 与 `INDEXNOW_KEY`）。
- **注意**：打开后，合格的**讨论帖**（`/forum/{id}`）也会变成可收录、进内容 sitemap——页面级的 robots 会盖过
  `seo/restructure` 在 `/forum` layout 上写的 noindex。这是设计 §11.1 的本意（逐条放开），打开前要和 SEO 那边对齐一次。

## 二、数据库变更（只加，不删不改）

```
forum_posts      + type VARCHAR(16) NOT NULL DEFAULT 'DISCUSSION'
                 + slug VARCHAR(120) NULL
                 + excerpt VARCHAR(300) NULL
                 + featured_at DATETIME(3) NULL
                 + verified_at DATETIME(3) NULL
                 + tested_on DATE NULL
                 + account_tier VARCHAR(16) NULL
                 + copy_count INT NOT NULL DEFAULT 0
                 + INDEX (type, review_status, featured_at)
prompt_specs     新表（forum_posts 1:1 附表，级联删除）
tags             新表（策展标签；首次访问自动补默认 22 个）
post_tags        新表（复合主键，级联删除）
content_events   新表（复制去重，唯一约束）
creator_profiles 新表（作者主页短码，唯一约束）
```

存量帖子全部是 `type = DISCUSSION`，行为不变。和 P0 一样：**先 db push、再换镜像**，上线前用
`prisma migrate diff --script` 预览确认零 DROP。没有新的环境变量（IndexNow 复用已有的 `INDEXNOW_KEY`）。

## 三、上线前站长要做的（内容，不是代码）

1. **写专题介绍**：至少 `gpt-image-2`、`nano-banana`、`seedance` 三个模型，`chatgpt`、`claude`、`codex` 三个产品。
   每篇 400–800 字：是什么、怎么用、Free 与付费的区别、注明实测日期。**没有介绍的专题页永远不会被收录。**
2. **种子内容**（设计 §15.1，约 40 篇）：每条提示词都要有真实出图，教程要实测。文字我可以起草。
3. **导航入口**：这一包没改顶部导航（`seo/restructure` 正在重排导航，避免冲突）。合并 SEO 分支之后，
   在顶部导航加「提示词」「教程」两项（设计 §4.3 名称默认「AI 灵感库」）。
4. 种子内容就位、介绍写好、Search Console 验证完成之后，再决定是否把 `INDEXING_OPEN` 改成 `true`（设计 §11.1「慢放量」：先放 40–80 个 URL，观察 4 周）。
