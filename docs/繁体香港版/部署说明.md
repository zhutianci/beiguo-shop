# 繁体香港版 · 部署说明

> 设计见同目录 `设计.md`。本次**没有数据库改动**（不用 db push）。服务器操作的通用铁律（base64 传命令、耗时任务后台跑、绝不跑 `docker system df`）见 `docs/交接-进度与待办.md`。

## 一、改了什么（对线上的影响面）

| 位置 | 改动 | 总开关关着（不设 `ZHHK_ENABLED`）时 |
|---|---|---|
| `Dockerfile` | 多 COPY 一个 `zhhk/`；CMD 改为 `node zhhk/entry.cjs`（先起转换代理，再 `require('../server.js')`） | 入口直接加载 `server.js`，与原来相同 |
| `docker-compose.yml` | app 多 expose 3001；environment 加 `ZHHK_ENABLED` `ZHHK_AUTO_SWITCH` `ZHHK_HOSTS`（裸变量名） | 无影响 |
| `nginx/nginx.conf` | `upstream nextjs_zhhk`（app:3001）+ 按路径 / 请求头选上游的 map；主 location 改 `proxy_pass http://$app_upstream` | 只有 `/zh-hk`、`/_next-hk`、带 `x-bg-lang: zh-HK` 的 `/api` 会去 3001（没人发这些请求）；其余与原来相同 |
| `src/middleware.ts` | matcher 加「所有前台页面」 | 页面请求直接 `NextResponse.next()` |
| 根布局、页头页脚、7 个用 `usePathname` 的组件、`next/link` 别名、`auth-fetch-patch`、两个 sitemap、robots | 见设计 §6、§7 | 渲染结果与改造前相同（`lang` 恒为 zh-CN，链接不加前缀，切换按钮不出现，sitemap 原样） |

## 二、上线步骤

**顺序很重要：先 app（3001 有人听）、再 nginx。** 反过来的话 nginx 先把 `/zh-hk` 送到一个没人听的端口（只影响 `/zh-hk`，简体站不受影响，但没必要）。

0. **先给其他会话发占用通知**（多会话协作规则：对方发「结束」前不构建、不重启 app）。
1. 打回滚标签：`docker tag beiguo-shop-app:latest beiguo-shop-app:rollback-<当前线上 commit 短号>`。
2. `git pull`（服务器 `/opt/beiguo/beiguo-shop`）。
3. `.env.production` 加一行 `ZHHK_ENABLED=1`（**不要 chmod 600**，见 memory beiguo-sysb-2026-10-09）。`ZHHK_AUTO_SWITCH` 不写 = `redirect`（自动跳转）；站长若选「只提示不跳」就写 `ZHHK_AUTO_SWITCH=banner`。
4. 构建：用停 jishi 的服务器端 wrapper（`scripts/ops/build-stop-jishi.sh`，它报 `build_exit=4` 是 jishi 存活检查，不是失败；构建约 40～70 分钟），**确认构建真的结束、末尾没有 ERROR** 再往下。
5. 只重启 app：`docker compose up -d app`。验活：
   - `docker exec beiguo-nginx curl -s -o /dev/null -w '%{http_code}\n' -H 'Host: bigolab.com' http://app:3000/` → 200（简体）
   - `docker exec beiguo-nginx curl -s -D - -o /dev/null -H 'Host: bigolab.com' -H 'Cookie: bg_lang=zh-HK' http://app:3001/zh-hk/` → 200，且有 `x-zhhk: <词典版本>` 头
   - `docker logs beiguo-app 2>&1 | grep zhhk` → 「繁体转换代理已启动 0.0.0.0:3001」
6. nginx：配置是单文件 bind-mount，`git pull` 换了 inode，**必须** `docker compose up -d --force-recreate nginx`（不能只 reload）。先 `docker run --rm --add-host app:127.0.0.1 -v $PWD/nginx/nginx.conf:/etc/nginx/nginx.conf:ro nginx:alpine nginx -t` 检查语法。

## 三、冒烟（全部经公网域名）

```
UA='Mozilla/5.0 Chrome/120'
# 简体原样：没有 x-zhhk 头，<html lang="zh-CN">
curl -s -D - -o /tmp/cn.html -A "$UA" https://bigolab.com/ | grep -i x-zhhk ; grep -o '<html[^>]*>' /tmp/cn.html
# 繁体：lang=zh-HK、香港版标题、canonical 自指、hreflang 七条、脚本走 /_next-hk/
curl -s -o /tmp/hk.html -A "$UA" -H 'Cookie: bg_lang=zh-HK' https://bigolab.com/zh-hk/chongzhi/chatgpt-plus
grep -o '<html[^>]*>\|<title>[^<]*\|<link rel="canonical"[^>]*>' /tmp/hk.html ; grep -c 'hreflang=' /tmp/hk.html ; grep -o 'src="/_next-hk/[^"]*"' /tmp/hk.html | head -2
# 名单外的繁体页 noindex
curl -s -A "$UA" -H 'Cookie: bg_lang=zh-HK' https://bigolab.com/zh-hk/prompts | grep -o '<meta name="robots"[^>]*>'
# 接口：带头转繁体、不带头原样
curl -s -H 'x-bg-lang: zh-HK' https://bigolab.com/api/products | head -c 200 ; echo ; curl -s https://bigolab.com/api/products | head -c 200
# 自动识别：香港浏览器首访跳繁体、Googlebot 不跳
curl -s -o /dev/null -D - -A "$UA" -H 'Accept-Language: zh-HK' -H 'sec-fetch-dest: document' https://bigolab.com/products | grep -i '^location'
curl -s -o /dev/null -w '%{http_code}\n' -A 'Mozilla/5.0 (compatible; Googlebot/2.1)' https://bigolab.com/zh-hk/products
# 票据不转繁体、后台不提供
curl -s -o /dev/null -w '%{http_code} %{redirect_url}\n' https://bigolab.com/zh-hk/receipt/x ; curl -s -o /dev/null -w '%{http_code}\n' https://bigolab.com/zh-hk/admin
# 站点地图带 hreflang
curl -s https://bigolab.com/sitemaps/chongzhi.xml | grep -c 'xhtml:link'
# Cloudflare 有没有把访客国家传进来（应看到 cf-ipcountry）：任意一个请求后看 nginx 日志或 app 日志
```

浏览器里再点一遍：繁体首页 → 点「商品」（地址保持 `/zh-hk/products`、全繁体）→ 页脚「簡體中文」切回简体 → 再切回繁体；登录态两版通用；下单到收银台（繁体页面，金额与简体一致）。

## 四、回滚

- **只关繁体版（秒级）**：nginx.conf 里 `$app_upstream` 那段 map 的三行 `nextjs_zhhk` 改成 `nextjs` → `docker compose up -d --force-recreate nginx`。`/zh-hk` 变 404，简体站零影响。
- 再彻底一点：`.env.production` 删掉 `ZHHK_ENABLED` → `docker compose up -d app`（middleware、切换按钮、sitemap hreflang 全部恢复原样）。
- 镜像回滚：`docker tag beiguo-shop-app:rollback-<短号> beiguo-shop-app:latest && docker compose up -d app`；**同时**按上面把 nginx 的三行改回 nextjs（旧镜像没有 3001）。

## 五、上线后

1. Search Console / Bing：重新提交 `sitemap.xml`、`sitemap-content.xml`；4 周后看「国际定位」有没有 hreflang 报错、繁体页收录与点击。
2. 4 周后若繁体核心页表现正常，把 `/prompts/` 加进 `zhhk/policy.json` 的 `indexPrefixes`（随下次构建生效）。
3. 改词表：编辑 `zhhk/vocab-hk.tsv` → `npm i --no-save opencc-js@1.0.5 && node scripts/i18n/gen-zhhk-dict.mjs` → `npx tsx scripts/check-zhhk.ts` → 提交 `dict.json`，随下次构建生效。大批新内容入库后可重跑 `zhhk-review-candidates.mjs` + `zhhk-deepseek-review.mjs`（默认 2 元封顶；**这把 DeepSeek 密钥同时给 AI圈大事记 用**）+ `zhhk-collisions.mjs`。
