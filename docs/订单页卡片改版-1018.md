# 「我的订单」卡片改版 · 2026-10-18

> 站长原话：「个人订单页面感觉太乱了……很臃肿，不高级」。
> 只动 `/orders` 列表卡片的视觉与信息层级：**接口、订单状态判定、按钮通向的页面、弹窗（发货详情 / 发票收据 / 在线沟通 / 抽奖）一律没动**。
> 延续 [设计精修-1007](设计精修-1007.md) 的原则（一个主强调色、层级靠字号与明度、表面是实的、一张卡一个主动作）。
> 当时那一版明确跳过了订单页（「文件大、业务多，风险收益不对等」），这次补上。

## 1. 改版前为什么乱

截图走查（1440 / 375）出来五条，都是**同一张卡上同时喊话的东西太多**：

1. **五个同等分量的按钮**排成一排（去充值 / 兑换、发货详情（卡密）、开具发票 / 收据、与客服在线沟通、下单有奖），
   颜色还各不相同（翠绿渐变、玻璃、红底发光），没有主次 —— 买家不知道先点哪个。
2. **最多四个实心胶囊**挤在商品名后面：状态、客服新回复、可开发票、可开收据。
   其中「可开发票 / 可开收据」说的是「能做什么」，和下面的按钮重复。
3. **提示和按钮互相重复**：「请点击「支付宝或微信支付」完成付款」旁边就是那个按钮；
   「卡密已发放。还没充值的话，点「去充值 / 兑换」把卡密充到你的账号」是整整两句话。
4. **桌面端提示被挤成一列竖排字**（截图里最刺眼的那块）：提示与按钮组排在一行，
   按钮组是 `lg:shrink-0`、自身又不换行，宽度不够时只能把左边的提示压到几十像素宽，于是一个字一行。
5. **每张卡一个彩虹渐变方块**（按 productId 取 7 种渐变之一）+ 悬停彩色光晕，列表整体是花的；
   方块里永远是同一个 Sparkles 图标，不承载任何信息。

## 2. 改版后的卡片

```
┌───────────────────────────────────────────────────────────────────────┐
│ ChatGPT Plus自助充值｜信用卡冲   ● 已完成                      ¥135.00 │
│ 20261018P81KGU20 ⧉ · 2026/10/18 15:17 · 发票已开具                     │
│ ─────────────────────────────────────────────────────────────────────  │
│ 卡密已发放，还没充值就点「去充值 / 兑换」                                │
│                      发货详情 发票/收据 联系客服 [奖]  （去充值 / 兑换） │
└───────────────────────────────────────────────────────────────────────┘
```

- **状态改成「小圆点 + 彩色文字」**（`StatusDot`），不再是实心胶囊。状态、客服新回复用同一种写法，排在一起也不花。
- **票据只写「已经发生的事」**：发票已开具 / 待付税费 / 已提交、收据已开具，写成元信息行里的一小段字；
  「可开发票 / 可开收据」去掉（按钮上已经写着「发票 / 收据」）。
- **一张卡最多一句提示**，只说「下一步要做什么」；状态本身交给小圆点，不再用一句话重复一遍。
  去掉了「请点击…完成付款」「服务已交付」两条纯复读。
- **一张卡最多一个主按钮**：白色药丸 = 下一步（去充值 / 兑换、查看卡密、查看号码），蓝色 = 去付款。
  其余操作一律是安静的幽灵按钮（图标 + 13px 字，无边框无底色）。
  接码单原来「去付款（号码页）」和「查看号码」并排，两个按钮同一个地址，现在按状态只留一个。
- **彩虹方块与悬停光晕删掉**，卡片表面仍是 `ui-panel`（实心深色面：页面背景有两团模糊光斑，换成半透明的 `ui-card` 会整张卡透出紫 / 青色）。
- **提示永远压不坏**：提示是 `min-w-[180px] flex-1`，按钮组在 lg 起才同排且整行 `flex-wrap`，放不下时按钮组整体换行，不会再挤出竖排字。
- **手机端**：提示 → 幽灵按钮 → **整行主按钮**（拇指区）；元信息行的分隔点 `·` 在手机上隐藏，否则换行后行尾吊着一个点。
- 已取消 / 已退款的单整张压暗（标题 `text-white/65`、金额 `text-white/55`），列表里一眼能跳过。
- 容器从 `max-w-5xl xl:max-w-6xl` 收回 `max-w-5xl`：卡片内容变少后，1152px 只会让金额离商品名更远。

## 4. 刻意不动

- 四个弹窗（发货详情 / 发票收据 / 在线沟通 / 抽奖）、发票与收据表单、付款与兑换的全部逻辑。
- 付款按钮文案仍是「支付宝或微信支付」（10-18 刚统一过）、按钮色仍是 `#1677FF`。
- 页头眉标 +「我的订单」大标题、筛选胶囊、搜索框、未读提示条、底部客服卡（全站同款，单独改会和其它页面不像一家）。
- 服务端分页、筛选、未读轮询、付款后自动打开发货详情（`?paid=`）等所有行为。
