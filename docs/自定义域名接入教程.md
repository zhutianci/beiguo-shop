# 用自己的域名打开店铺：接入教程（给店铺客户）

> 这一页可以直接转发给要接入自定义域名的客户。站长侧的操作见《多渠道分销-部署说明》第十七节。
> 下文以域名 `tibo.pw`（在西部数码注册）为例，请换成你自己的域名。

## 这样做之后会怎样

- 买家在浏览器地址栏里看到的是 **`tibo.pw`**，不再是 `xxx.bigolab.com`。
- 以前的店铺地址仍然能打开，会自动跳到 `tibo.pw` 的同一页面；已经发出去的订单、收据、开票链接照常可用。
- 网站证书（小锁）由平台自动配置，你不用买证书，也不用管服务器。
- **域名仍在你自己的西部数码账号里**，续费、实名、转移都由你自己管。你只需要把域名的「DNS 服务器」交给平台管理，并遵守下文「请务必遵守」的几条约定。

## 开始之前请确认

1. 域名已完成**实名认证**，状态正常（没有被锁定、没有过期）。
2. 如果这个域名还有别的用途（例如企业邮箱、另一个网站），请先登录西部数码，打开这个域名的「域名解析」页面，把**全部解析记录截图**发给站长。
   换了 DNS 服务器之后，西部数码里的解析就不再生效，站长会把这些记录原样搬过去，避免你的邮箱等服务中断。
   如果这个域名只给店铺用，可以跳过这一步。
3. 从站长那里拿到**两个 DNS 服务器地址**，形如：
   ```
   xxxx.ns.cloudflare.com
   yyyy.ns.cloudflare.com
   ```
   以站长发给你的为准，一个字母都不能错。

## 第一步：登录西部数码，找到域名

1. 打开西部数码官网并登录。
2. 进入「管理中心」→「域名管理」（或「我的域名」），在列表里找到 `tibo.pw`，点「管理」。

> 网站改版后菜单名称可能略有不同，找「域名管理 / 我的域名」即可。

## 第二步：如果开了 DNSSEC，先关闭

在域名管理页里找「DNSSEC」。如果显示「已开启」，先关闭并保存。
开着 DNSSEC 换 DNS 服务器，域名会解析失败、网站打不开。没看到这一项或显示未开启，直接进行下一步。

## 第三步：修改 DNS 服务器

1. 在域名管理页找到「**修改 DNS 服务器**」（也可能叫「DNS 服务器设置」「更换 DNS」）。
2. 选择「**自定义 DNS**」（或「使用其他 DNS 服务器」），不要选「使用西部数码默认 DNS」。
3. 把原来的 DNS 服务器地址全部删掉，填入站长给的两个地址：
   - DNS1：`xxxx.ns.cloudflare.com`
   - DNS2：`yyyy.ns.cloudflare.com`
   如果页面有 DNS3、DNS4 等更多空格，留空即可。
4. 点「保存」或「确定修改」。部分情况下需要短信或邮箱验证码确认。

## 第四步：等待生效，然后通知站长

- 修改后一般**几分钟到几小时**生效，最长可能需要 48 小时。
- 可以自己检查：在电脑上打开「命令提示符」（Windows）或「终端」（Mac），输入：
  ```
  nslookup -type=ns tibo.pw
  ```
  结果里出现站长给的两个 `cloudflare.com` 地址，就说明已经生效。
- **生效后请告诉站长**。站长会完成剩下的配置并通知你，届时在浏览器打开 `https://tibo.pw` 就能看到店铺。

## 之后需要知道的事

- **不要再在西部数码里改「域名解析」**：从现在起，这个域名的解析由站长管理，在西部数码改了也不会生效。需要加记录（比如开通企业邮箱），请联系站长。
- **买家与后台成员需要在新域名上重新登录一次**：登录状态是按域名分开保存的，这是正常的安全设计。
- **续费**：域名到期仍在西部数码续费。**请开启自动续费**，域名过期后这个地址就打不开了。
- **不想用了**：先告诉站长把店铺地址切回原来的地址，然后在西部数码把 DNS 服务器改回「西部数码默认 DNS」即可。请按这个顺序操作，否则买家会有一段时间打不开店铺。

## 请务必遵守（接入即表示同意）

这个域名作为店铺地址期间，平台发给买家的订单邮件、收据与开票链接、登录入口都会指向它；买家账号在本平台通用。为了买家的账户与订单安全：

1. **不得在未提前告知站长的情况下**修改这个域名的 DNS 服务器、把它指向其他服务器，或让它过期、转移、被停用。
2. 需要做以上任何一件事，请**先通知站长**把店铺地址切回原来的地址，站长确认之后再操作。
3. 平台每 10 分钟自动检查一次这个域名是否仍然正常接入。检查连续失败时，系统会**自动把店铺地址切回原来的地址**、停止向这个域名跳转，并通知你与站长；域名恢复后自动切回。
   也就是说，域名出问题时店铺不会停摆，但这段时间地址栏会变回原来的地址。
4. 因违反第 1 条给买家或平台造成的损失，按双方的合作约定处理；站长也可以停用这个域名的接入。

## 常见问题

**问：改了一天还没生效？**
答：先确认第三步填的两个地址和站长给的完全一致、没有多余空格；再确认第二步的 DNSSEC 已关闭。都没问题的话，把西部数码「DNS 服务器」页面的截图发给站长。

**问：打开 `https://tibo.pw` 提示证书不安全？**
答：通常是刚生效、证书还在自动签发，等十几分钟再试。超过一小时仍然提示，请联系站长。

**问：`www.tibo.pw` 能用吗？**
答：能。站长会同时配置 `tibo.pw` 和 `www.tibo.pw`，打开 `www.tibo.pw` 会自动跳到 `tibo.pw`。
