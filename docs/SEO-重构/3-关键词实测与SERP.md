## 〇、一页结论（先看这里）

1. **最大的问题不是选词，是收录。** Google `site:bigolab.com/news` = **0 条**（AI 圈大事记零收录）；`site:bigolab.com/chongzhi` 只有 5 条，**被六家爬虫读、落地页里 OAI-SearchBot 抓得最多的 chatgpt-plus（第二十八节），以及 chatgpt-pro / claude-pro / claude-zhuce / hub 页都没出现在 Google 索引里**（`site:` 是近似值，最终以 GSC 为准）；还有 http+www 变体被收录。20 个主打词的 Google/Bing 前 10 里 bigolab 一次都没出现。**GSC 验证 + 提交 sitemap + 逐页请求编入索引 + 开 Always Use HTTPS**，优先级高于本文件里任何一个新词。
2. **支柱①（AI 会员）两条旧结论被新数据修正**：
   - 「会员」现在对 ChatGPT **也成立**：`chatgpt会员` Google 9 条（购买/价格/怎么买/订阅/拼车），09-19 时返回的是亚美尼亚语。
   - 「AI 会员**代充**」仍是零（G0），但 **「ai会员」G8、「ai订阅」G9，联想主体是「比价 / 价格对比 / 购买」** → 数据支持把现有 `/chongzhi` hub 改造成「AI 会员价格对比」页（不是新建「代充」品类页）。
   - 「代开 / 代购 / 代订阅」三家复测仍全为 0 或近 0，维持禁用。
3. **支柱①最值钱的新词**：`claude code 充值/购买/价格/会员/订阅`（Google 全部 8–9，目前没有承接页）、`chatgpt plus 信用卡`/`升级`/`怎么`/`国内`（G10）、`gpt充值`（G10，用户常写 gpt 不写 chatgpt）、`claude 封号`（G9）、`claude 发票`（G9，「能开增值税发票」是本站真差异点）、`ios 订阅 claude`（G8，与本站 Claude Pro 的 iOS 充值方式直接对口）。
4. **支柱②（AI 大事记）：栏目名本身是零需求词。** `ai大事记`、`ai圈大事记` 三家全 0；`ai动态` 虽 G9 但联想全是「动态壁纸/动态影片」——**现标题「每日 AI 动态聚合」里的「动态」是错词**。有量且合规的是：`ai资讯`（G9）、`今日ai`（今日ai新闻/资讯/热点）、`ai热点`，以及更肥的**「实体 × 最新/更新」**：`claude 最新`、`openai 最新`、`openai发布`、`chatgpt更新`、`gemini更新`、`claude opus`、`gpt5`、`大模型排行榜`（均 G9–10）。「人工智能新闻/最新消息」Google 几乎为 0（Google 用户写「ai」不写「人工智能」）。
5. **支柱③（接码）：品类词量大，但写法要避险。** `接码平台` 三家都满（G10），可 **Bing 国内版前 10 全是官媒犯罪报道**，百度联想高频「违法吗/犯法吗/运营主体如何追责」→ 标题别用「接码平台」当主词。`海外手机号 / 国外手机号 / 外国手机号`（G9，联想=接码平台/验证码/购买/注册）与 `接收验证码`（G10）是最干净的主词——**现 `/jiema` 标题「短信接码 - 海外手机号在线接收验证码」方向对**。
6. **接码服务页的真实需求句式是「{服务}注册手机号无法验证」**，不是「{服务} 接码」：`谷歌注册手机号无法进行验证 / 验证次数过多`（B10/D9）、`gmail注册手机号不能用于验证`、`chatgpt 注册 手机号无效`；只有 **Codex 例外**（`codex 接码` 9/11/8）。按合计热度：Codex、谷歌/Gmail、Telegram（tg/电报合计最高，但境内敏感需拍板）、WhatsApp、Claude/ChatGPT 注册验证、Instagram、亚马逊。**国家页只有美国值得单独做**（`美国 接码` 5/11/7；香港、日本次之）；印尼/泰国/菲律宾/荷兰是供给侧便宜国，搜索侧 Google「{国} 接码」为 0–1。
7. **竞品成熟打法**：①AI 会员——Google 前 10 被知乎/CSDN/掘金/segmentfault/什么值得买/GitHub README/sites.google 上的软文占满（**寄生 SEO**），自营独立站只在 Bing 国内版露头（xingqiaosub、payforchat、glouth、pluscosmo、dgtsell）；标题三件套 **「2026」+「国内/支付宝微信」+「N 种方式/亲测」**，Claude Max 竞品直接把「5x ¥989 / 20x ¥1877」写进标题。②AI 资讯——能上榜的小站都是**「每天一个带日期的 URL」**。③接码——tiger-sms/5sim/nexsms 等全是 **「服务×国家」程序化专页**。

2. Google SERP 出口定位在以色列，国内翻墙用户多落在美/港/日/新节点，排序会有差异；Bing 国内版 curl 连抓后有「退化成品牌页」现象，表中已标 ⚠。
3. 没拿到的：Bing site: 收录数（验证码）、百度 SERP（验证码）、Google「People also ask」（本次 IP 下未出现）。都没有尝试绕过。
4. 支柱① 的 Gemini / GitHub Copilot / Cursor 页是否值得做，取决于有没有在售 SKU——这是库里的事实，本文件未查库。
5. 原始数据可复跑：`seo/kw/seeds.py`（种子）→ `fetch.py`（抓取，带缓存）→ `analyze.py`/`generate.py`（计数、矩阵、TSV）；SERP：`serp.py`（Bing）与 `google_serp.txt`（Google 手抓记录）。
