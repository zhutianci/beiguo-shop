## 一、改了什么

### 教程页转化（`components/content/service-card.tsx`、`content-detail-page.tsx`）
- 去向：**标题意图 → 标签登记的落地页 → 充值总览**。意图规则只放有明确商品的（Claude Code、Codex 接码、Claude KYC / 注册、Claude Max、ChatGPT Pro、Grok、谷歌账号）。
- 服务卡：正文**第二个 H2 之前**一张（读者看完第一节、确认这篇对题之后），正文末尾一张完整版，侧栏补起价。
  卡上只有可核验事实：实时起价（与落地页价格表同源）、支付宝或微信支付、交付方式（不是每页都发卡密）、开票口径。标「本站服务 · 贝果科技」。
- AI 应用 / Skill 库只出末尾那张（正文中间插本站服务不对题）；渠道站不出（同原逻辑）。
- 归因沿用 `?from=c{id}`（`lib/content/attribution.ts`，7 天内下单记一行）：上线两周后对比 `content_attributions` 与 /chongzhi 的 `from` 进入量。

- 设计稿 §3.3 写的「支付宝付款」已过时，一律写「支付宝或微信支付」。hub 描述**不写「官方定价」**（hub 正文没有官方价表，写了就是一句对不上的话）。

- **/products 没改**（与设计不同）：它近一周有约 500 个搜索访客（Bing 394），换成设计稿的「全部商品与价格」有丢排名的风险；等 GSC 数据再定。
- 对照组 claude-kyc、google-zhanghao 一字未动；claude-zhuce 也没动。

### D2：/chongzhi/claude-code（新）
- 承接「Claude Code 订阅 / 价格 / 额度 / API 与订阅区别」。**不卖新东西**：registry `ownsProducts: false`，价格区只是 Pro / Max 摘要并链到两页，商品归属、hub 卡片档位行、/products 指南都不算它。
- 官方事实 2026-10-29 对照 support.claude.com（11145838）、claude.com/pricing、code.claude.com/docs 核实并外链：Free 不含、Pro / Max 含；5 小时 + 每周限额且网页端与 Claude Code 共用；
  `ANTHROPIC_API_KEY` 会让 Claude Code 按 API 计费；Max 附带的月度 API 额度不能用在 Claude Code；usage credits 按 API 标准价。**每月核对一次。**
- title / H1 里没有「Pro 还是 Max」；hub、页脚、相关链接、sitemap 由 registry 自动出现。

### Ha：数据层缓存
- 主站在售商品快照 `storefrontCached('landing-products', 60s)`（`lib/landing/products.ts`）。教程页起每次访问都要取起价，原来每个请求都查一次库。
- 只缓存主站分支；渠道站（带草稿预览、按店售价）不进。查询失败不缓存（外层降级 `[]`）。
- 后台新建 / 保存（`onProductSaved`）与删除商品时 `clearLandingProductsCache()`，改价、上下架即时生效；销量、库存的自然变化最多晚 60 秒。

### E1（收窄）：大事记分类分页与日报补全
- `/news/c/[category]?page=N`（6 类，SKILL §4 的固定分类）：**只列可索引事件**（粗筛 `detailState='DONE'`、精筛 `shouldNoindexEvent`，与详情页、sitemap 同一谓词）；
  `?page=1` 308 到无参，非数字 / 0 / 越界 404；canonical 指向自己；导语只在第 1 页；`<a rel=prev/next>` 分页；CollectionPage + ItemList + BreadcrumbList；`ai-generated` meta、AI 摘要徽章、AiNoticeBlock。
- /news 加「按分类回看」一排服务端链接（`components/news/category-nav.tsx`）；详情页面包屑与 BreadcrumbList 加分类一级。
- 日报补「当天其他动态」：当天有全文、不在榜单里的事件（薄页不列）。
- news-hub sitemap 加 6 个分类第 1 页（lastmod = 该类最新可索引事件）。
- **没做**（下一批）：月度归档改按天分组、周报补日报链接、日报 H1 改「AI 动态速览」、离题条目排查、IndexNow 补推、/news/t 话题页（E2）。

### HSTS
- `nginx/nginx.conf`：`max-age=300` → `86400`（站长 10-29 同意，观察两周再调到 15552000 或一年）。不加 includeSubDomains / preload。
  **要重建 nginx 容器才生效**：`docker compose --env-file .env.production up -d --no-deps --force-recreate nginx`（低峰、几秒）。
