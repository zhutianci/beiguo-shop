# hero-sms 国家代码与卡类代码速查

2026-09-22 用 `getCountries` / `getServicesList` / `getPrices` 实拉的，
不是抄文档——hero-sms 的文档站是 SPA，抓不到静态内容（见 `lib/herosms.ts` 顶部注释）。

协议是 SMS-Activate 的 `handler_api.php`，所有查询都是 GET：

```
https://hero-sms.com/stubs/handler_api.php?api_key=<KEY>&action=<ACTION>
```

**只读、不花钱的 action**：`getBalance`、`getCountries`、`getServicesList`、`getPrices`（可带 `&country=<id>`）。
⚠️ `getNumber` 是**真的取号、真的扣钱**，排查问题时不要拿它试手。

⚠️ 这个接口会拦 Python 的默认 User-Agent（403），用 curl 取、再交给脚本解析。

## 本站在用的卡类代码

| 代码 | 官方名称 | 用在哪 |
|---|---|---|
| `dr` | OpenAI | 商品 10（Codex 美区实体卡）、商品 28（Codex 随机地区） |
| `acz` | Claude | 商品 14（Claude 美区实体卡）、商品 15（Claude 荷兰） |

后台商品的 `smsService` 填卡类代码、`smsCountry` 填国家代码，
**`smsCountry` 留空 = 随机地区**（商品 28 就是这么配的）。
`smsMaxPrice` 是能接受的最高单价，超过就不取号——用来兜住成本。
